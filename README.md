# ケースで学ぶ簿記3級

身近な会社の21のケースを通じて、日商簿記3級の全範囲を学ぶ HTML 教科書です。

## 読み方

- `public/index.html` をブラウザで開くと、表紙と目次が表示されます（スマートフォン最適化済み）。
- `public/all.html` は全章を1ファイルにまとめた一気読み版です（オフライン閲覧や印刷向け）。
- 表示には Tailwind CSS（CDN）と Google Fonts を読み込むため、インターネット接続が必要です。

出題範囲は、2026年度（2027年3月まで）の試験に適用される出題区分表（2022年度適用版）を網羅し、2027年4月以降の改定点（2025年12月公表の暫定版）も併記しています。

## 公開（Cloudflare Pages）

サイトとして配信するのは `public/` の中身だけです。Cloudflare Pages のビルド設定は次のとおりにします。

| 項目 | 設定値 |
| --- | --- |
| Production branch | `main` |
| Framework preset | `None` |
| Build command | 空欄 |
| Build output directory | `public` |

`main` に push すると自動で再デプロイされます。

## 編集・再生成

本文は `_src/*.txt`（独自の軽量マークアップ）に書かれており、`build.pl` が Tailwind のクラス付き HTML を `public/` に生成します。追加モジュール不要の Perl 5 で動きます（Git Bash 同梱の Perl で可）。

```sh
perl build.pl
git add -A
git commit -m "変更内容"
git push
```

- 記法の一覧は `build.pl` 冒頭のコメントを参照してください。
- 章の並びは `_src/book.txt` で管理しています。
- ビルド時に、すべての仕訳の貸借一致、T字勘定の合計、`sum` 指定した帳簿・試算表・財務諸表の縦計、表の列数を自動で検証します。不一致があると警告を表示して終了コード1で終わります。
- ページの URL に `?selftest` を付けて開くと、そのページの演習・シミュレーター・用語ポップアップ・模擬試験の採点を自動で検査し、結果を画面上部に表示します。

### インタラクティブな要素

| 要素 | 書き方 | 内容 |
| --- | --- | --- |
| 仕訳の入力 | 例題・確認問題の解答に `::journal` があれば自動 | 勘定科目のドラッグ（またはタップ）＋金額入力＋答え合わせ。付けない問題は `<!-- notry -->` |
| 穴埋め | 問題文に `[[答え]]`、`[[ア:答え]]`、`[[答え@15・18]]` | 数値は入力欄、語句は選択式。同じ記号の欄は連動。`[[]]` は「空けておくのが正解」の欄（精算表・試算表）。`@` の後は間違えたときに復習する章。選択肢は答え＋`<!-- choices: A \| B -->` |
| 分類 | `::sort`（`@cats 分類1 \| 分類2` と `項目 => 分類`） | ドラッグで分類先へ移す |
| チェック表 | `::checks`（1行目が見出し、正解のマスに ✓） | 補助簿の選択など。1列が1設問 |
| シミュレーター | `::sim fifo` / `ccc` / `dep`（`@expect` に本文の数値） | 第6章（払出単価）・第7章（CCC）・第12章（減価償却）。自己テストで本文の数値と照合 |
| 用語 | 自動（付録Aの辞典から） | 本文の勘定科目を、見出しごとに最初の1回だけタップで説明 |
| 模擬試験 | `::mock 60`（`大問の見出し \| 配点`） | タイマー・自動採点・大問ごとの得点・復習する章 |

表は `split:N`（左N列と残りを分け、スマホでは上下に並べる）を指定すると、勘定式の財務諸表をスマホでも見やすく表示できます。

本書に登場する企業・人物・数値は、すべて学習用に設計した架空のものです。
