::mystery 値上げの通知を出すか、正午までに決めろ ― なのに、粗利が2つある
11月4日、朝9時。洛北ミートの社長室に、150通の封筒が積まれていた。得意先の飲食店すべてに宛てた「価格改定のお願い」だ。円安で、牛ばら肉の仕入値は1kg 1,000円から1,400円へ、この1か月で4割上がった。だが、値上げを頼めば、得意先は安い競合に乗り換えるかもしれない。
北村：「出すか、出さんか。正午に郵便局が来る。それまでに決める。決め手は、10月の牛ばら肉の粗利や」
ところが、経理課から上がってきた数字は、2つあった。
この道25年のベテラン、島田の計算では**400,000円**。4月に入社したばかりの新人、谷口の計算では**389,500円**。売上はどちらも同じ1,170,000円。仕入れた肉の量も、売った肉の量も、同じ伝票から拾っている。課長が1行ずつ検算したが、**どちらにも計算ミスは見つからなかった**。
北村：「40万も稼げとるなら、値上げなんか頼まんでええ。客を逃がすだけや。……せやけど、なんで数字が2つあるんや。数字が2つある会社の言うことを、誰が信じるんや」
月次巡回に来ていたひよりは、社長室の前の廊下で、谷口に袖を引かれた。同じ春に社会人になった者どうし、巡回のたびに話すようになっていた。
谷口：「大川さん、私、どこを間違えたんでしょうか。島田さんに『新人の数字は信用できん』って言われて……」
仕入値は上がり続けているのに、帳簿の粗利は「十分に稼げている」と言う。しかも、その数字が2つある。北村に報告すべきは、どちらの数字なのか。そして、洛北ミートは本当に、値上げをしなくていいほど稼げているのか？
::
## 商品有高帳 ― 品目ごとの「在庫の家計簿」

ひよりは、谷口と並んで、2人が使った帳簿を広げた。どちらも同じ形の帳簿だ。
ひより：「これ、何という帳簿ですか」
谷口：「**商品有高帳**（しょうひんありだかちょう）です。牛ばら肉なら牛ばら肉だけ、1冊にまとめて、何kgがいくらで入って、いくらで出ていったかを書くんです」
ひより：「仕入と売上の勘定だけじゃ、ダメなんですか」
谷口：「勘定には金額しか残りません。どの肉が何kg残っているかは、この帳簿を見ないと分からないんです」
谷口は、払出の欄を指さした。
谷口：「ここ、研修で一番怒られたところです。売った肉の欄でも、売った値段は書かない。仕入れた値段で書くんです」

::theory 商品有高帳は、すべて「原価」で記録する
商品有高帳の最大の注意点は、**払出欄も残高欄も、すべて原価（仕入単価）で記録する**ことだ。売った商品でも、売価（1kg 1,800円など）は書かない。
商品有高帳の目的は、「いま、いくら分の在庫があるか」と「売れた商品の原価（売上原価）はいくらか」を知ることだからだ。売価は売上帳に記録される。
::

ひより：「じゃあ、仕入れた値段が毎回違ったら？」
谷口は、少し言葉に詰まった。
谷口：「……そこなんです。10月は、仕入れるたびに値段が上がってて」
1kg 1,000円で買った肉と、1,200円で買った肉が、冷蔵庫の中で混ざっている。そこから400kgを出荷したとき、その原価は1kgいくらで計算すればよいのか。
この「払い出した商品の単価（**払出単価**）」の決め方として、3級では2つの方法を学ぶ。

## 島田の帳簿 ― 先入先出法

ひよりは、島田の席に向かった。島田は、ひよりが近づいても腕を組んだままだった。
ひより：「島田さん、払出の単価は、どうやって決めていますか」
島田：「冷蔵庫の肉は、古いものから出す。当たり前のことを、帳簿でもやるだけだ」
ひより：「古いものから……」
島田：「先に仕入れた肉から、先に売れたことにする。**先入先出法**（さきいれさきだしほう）だ。肉屋は25年、これでやってきた」

島田は、10月12日の行を太い指でたどった。
島田：「400kg出した。1,000円の肉が200kgしか残ってないから、まずそれを全部出す。足りない200kgは、次に古い1,200円の肉から出す。だから払出が2行になる」
ひより：「原価は、200,000円と240,000円で、440,000円」
島田：「27日も同じだ。残ってた1,200円の肉100kgを先に出して、足りない150kgを1,400円の肉から出す」
島田：「月末に残った肉は『次月繰越』として払出の欄に書いて、上と下の合計をそろえて締める。来月は『前月繰越』から始まる」

::point メモ ― 先入先出法の書き方
- 単価の違う在庫は、単価ごとに**行を分けて**残高を書く（実際の帳簿では中かっこ「｛」でくくる）。
- 払い出しが2つの単価にまたがるときは、払出欄も2行になる。
- 月末の在庫は「次月繰越」として**払出欄**に書き、受入欄と払出欄の合計を一致させて締め切る。
先入先出法による10月の売上原価は、440,000＋330,000＝**770,000円**。月末在庫は**210,000円**。
::

## 谷口の帳簿 ― 移動平均法

次は谷口の帳簿だ。谷口のノートには、研修で習ったという計算式が、きれいな字で書いてあった。
谷口：「私は、仕入れるたびに平均を出し直してました。研修でそう習ったので」
ひより：「平均？」
谷口：「冷蔵庫の中で、古い肉と新しい肉が混ざってるって考えるんです。だから、仕入れるたびに、残ってる肉と新しい肉の平均の値段を計算し直して、その値段で出していく。**移動平均法**（いどうへいきんほう）です」

::

谷口：「8日に300kg仕入れたので、（200,000＋360,000）÷（200＋300）で、1kg 1,120円。次に仕入れるまでは、この値段で出します」
ひより：「20日にまた仕入れたから、計算し直し」
谷口：「はい。残ってた100kgが112,000円、新しく300kgが420,000円。足して400kgで割ると、1,330円です」

::point メモ ― 移動平均法の結果
移動平均法による10月の売上原価は、448,000＋332,500＝**780,500円**。月末在庫は**199,500円**。

## 答え合わせ ― 「真実」は1つではない

ひよりは、2人の結果を1枚の表に並べた。そして、一番下に1行だけ足した。
課長と島田と谷口が、表をのぞきこんだ。

::table 払出単価の決め方による違い（10月・牛ばら肉）
| 項目 | 先入先出法（島田） | 移動平均法（谷口） |
| 売上高（650kg×1,800円） | 1,170,000 | 1,170,000 |
| 売上原価 | 770,000 | 780,500 |
|= 売上総利益 | 400,000 | 389,500 |
| 月末在庫 | 210,000 | 199,500 |
| 合計（売上原価＋月末在庫） | 980,000 | 980,000 |
::

谷口：「売上原価と月末在庫を足すと……どっちも980,000円？」
ひより：「はい。10月に売ることができた肉は、全部で980,000円分。月初の在庫200,000円と、10月の仕入780,000円です。2人とも、その980,000円を『売れた分』と『残った分』に分けていた。分け方が違っただけなんです」

::solve どちらも正しい。違うのは「仮定」だけだ
ベテランの島田は**先入先出法**で、新人の谷口は**移動平均法**で計算していた。洛北ミートが正式に採用しているのは先入先出法だが、谷口は研修で習った移動平均法で計算してしまったのだ。
表の最終行を見てほしい。どちらの方法でも、「売上原価＋月末在庫」は**980,000円**で同じだ。これは、10月に「売ることができた肉の原価の総額」（月初在庫200,000円＋仕入780,000円）にほかならない。払出単価の決め方とは、**この980,000円を、「売れた分（売上原価）」と「残った分（在庫）」にどう切り分けるか**のルールなのだ。
仕入値が上がり続けている局面では、先入先出法は「古くて安い肉から売れた」と仮定するので、売上原価が小さくなり、利益が大きく出る。移動平均法は新旧の単価をならすので、その中間になる。
どちらが「真実」か？　答えは、**どちらも真実**だ。会計の数字は、あらかじめ定めた仮定（会計方針）のもとで計算された結果である。だから大切なのは、どの方法を選ぶかよりも、**選んだ方法を毎期継続して使うこと**だ。
::

谷口：「間違いじゃなかったんだ……」
谷口は、大きく息を吐いた。島田は表の最終行をしばらく見て、低い声で言った。
島田：「方法が違ったなら、そう言えばいい」
谷口：「……すみません」
島田：「謝ることやない。うちは先入先出法や。それだけ覚えとけ」
島田は自分の椅子を引き寄せると、谷口の帳簿を先入先出法で計算し直すのを、黙って手伝い始めた。

::scene 11時30分 ― 社長室
ひよりは、表の下に、もう1行だけ書き足して、社長室に持っていった。
ひより：「社長。2つの数字は、どちらも正しいです。洛北ミートの正式な方法は先入先出法なので、報告する粗利は40万円です。ただ、1つだけ見ていただきたい行があります」
北村：「なんや」
ひより：「10月に売った650kgを、いま畜産会社から買い直したら、いくらかかるか。今の仕入値は1kg 1,400円です。650kgで910,000円。売上1,170,000円から引くと、粗利は**260,000円**しか残りません」
北村：「……40万と、26万？」
ひより：「差の14万円は、値上がりする前に安く買っておいた肉が、まだ冷蔵庫に残っていたおかげです。その肉は、もう今月で売り切れます。来月からは、40万円ではなく、26万円の商売になります」
北村は、長いあいだ表を見ていた。それから、机の上の封筒の束に手を置いた。
北村：「帳簿の40万は、去年の相場が稼いだ分か。……出すで。全部や」
正午、150通の封筒は郵便局の車に積まれた。ひよりは、石油会社が同じ理由で「在庫の影響を除いた利益」を別に発表していることを、あとで知った。
::

::sim fifo 仕入値が上がる月、下がる月で、2つの方法の利益はどう変わるか
@expect fifo.cogs=770000 fifo.gp=400000 fifo.end=210000 avg.cogs=780500 avg.gp=389500 avg.end=199500 fifo.total=980000 avg.total=980000

ひよりは、シミュレーターの値を動かしてみた。仕入値が下がる月にすると、今度は移動平均法のほうが利益が大きくなる。
ひより：「値段の上がり下がりで、どっちの方法が得かが入れ替わるんですね」
課長：「それやったら、毎月、得なほうを使えばええんちゃうか」
ひより：「それが、ダメなんです。一ノ瀬さんに、最初に釘を刺されました」

::theory 継続性の原則 ― 「都合のいいときだけ方法を変える」ことは許されない
もし会社が、利益を多く見せたい年は先入先出法、少なく見せたい年は別の方法、と自由に切り替えられたら、決算書を年ごとに比べる意味がなくなってしまう。
そこで会計には、一度採用した会計処理の方法は、正当な理由がない限り毎期継続して適用しなければならない、という**継続性の原則**がある。方法を変える場合は、その理由と影響を決算書の注記で開示しなければならない。
会計は「1つの正解」を求める学問ではない。**一貫したルールのもとで、比較可能な数字を作る**技術なのである。
::

::real 石油会社が「在庫の影響を除いた利益」を別に発表する理由
同じ問題は、日本を代表する大企業でも起きている。ENEOSホールディングスは決算の資料で、営業利益とは別に「**在庫影響を除いた営業利益相当額**」を示している。在庫影響とは、平均単価などで払い出す在庫の評価が、売上原価に与える影響のことだ。
2020年11月、同社は2021年3月期の営業利益の予想を、1,100億円から2,000億円へと**900億円**引き上げた。そのうち650億円は、原油価格の前提を引き上げたことによる「在庫影響」で、在庫影響を除いた上方修正は250億円にとどまっていた。値上がり前に安く仕入れた在庫が売上原価に混ざれば、そのぶん利益は膨らむ。洛北ミートの牛ばら肉とまったく同じ仕組みである。相場が大きく動く商品を扱う会社ほど、「相場のおかげの利益」と「本業で稼いだ利益」を切り分けて見せる必要がある。
::note
出典：[ENEOSホールディングス「2021年3月期通期連結業績予想の修正に関するお知らせ」（2020年11月11日）](https://www.hd.eneos.co.jp/newsrelease/20201111_02_1090046.pdf)
::
::


## 商品有高帳から売上原価と粗利を求める

翌月から、牛ばら肉の粗利の報告は谷口の担当になった。
谷口：「北村社長には、毎月、売上原価と粗利の2つを報告することになったんです。この帳簿から、どうやって拾えばいいですか」
ひよりは、払出欄を上から指でなぞった。答えは、もうこの帳簿の中に書いてある。
ひより：「払出欄の、売った行の金額を足せば売上原価。売上から引けば粗利。月末繰越の行は、売上原価に入れないこと」
谷口：「それ、試験にも出ますか」
ひより：「第2問の定番だそうです」

::steps 商品有高帳の問題の解き方
払出単価の決め方を確認する | 先入先出法か、移動平均法か。移動平均法の端数処理の指示も確認する
受入・払出・残高を1行ずつ記入する | 払出欄は「原価」で書く。売価は使わない（売価は売上高の計算に使う）
売上原価を集計する | 払出欄の合計から、次月繰越の金額を除く（＝月初在庫＋当月仕入－月末在庫）
売上高を計算する | 販売数量×売価。売上帳や問題文の資料から求める
売上総利益を計算する | 売上高－売上原価
::

::point 返品があったときの商品有高帳
- **仕入戻し**（仕入れた商品を返品した）：返品した商品の仕入単価で、**払出欄**に記入する。
- **売上戻り**（売った商品が返品された）：その商品を払い出したときの単価で、**受入欄**に記入する。
どちらも「在庫が減ったか、増えたか」で記入欄を判断すればよい。
::

## 仕入帳と売上帳 ― 取引の「明細」を残す補助簿

谷口：「商品有高帳のほかに、仕入帳と売上帳もつけてるんですけど、何が違うんですか」
ひより：「商品有高帳は、品目ごとの在庫の帳簿。仕入帳と売上帳は、取引そのものの帳簿です。誰から、どんな条件で、何をいくつ、いくらで。日付の順に書きます」

ひより：「そこを混ぜると、即失点だそうです」

| 帳簿 | 記録する内容 | 単価・金額 |
| 仕入帳 | 仕入取引の明細（取引先・条件・品名・数量） | 仕入価格 |
| 売上帳 | 売上取引の明細（取引先・条件・品名・数量） | 売価 |
| 商品有高帳 | 品目ごとの受入・払出・残高 | 原価 |

::danger 「帳簿上の在庫」と「冷蔵庫の中身」がズレたとき
商品有高帳の残高は、「理屈の上では、これだけあるはず」という在庫だ。だが現実の倉庫では、切り落としのロス、計量の誤差、期限切れの廃棄、盗難が起きる。帳簿と実地棚卸のズレを放置すると、売上原価は小さく、利益は大きく計算され続け、ある日まとめて「見えない赤字」が表面化する。商品有高帳と実地棚卸の突き合わせは、在庫を守る最も基本的な防衛線だ。
::

::cfo 値上げ幅は、どの原価をもとに決めるか
150通の通知を出すことは決まった。残るのは、牛ばら肉を1kgいくら値上げするかだ。いまの売値は1kg 1,800円。得意先には、1回の値上げで済ませると約束したい。
**前提**
- 先入先出法の帳簿では、10月の売上原価は1kgあたり約1,185円。移動平均法なら約1,201円
- 今の仕入値は1kg 1,400円。畜産会社は、12月に1,500円になると言っている
- 値上げは12月1日から。値上げのあとに売る肉は、12月以降に仕入れる肉になる
**考えるときの視点**
- 値上げのあとに売る肉は、いくらで仕入れた肉か
- 「1回で済ませる」なら、どの時点の原価を見ればよいか
::choice A. 帳簿の原価約1,185円をもとに、これまでの粗利率を保てる売値にする
**△ 過去の原価で、未来の値段を決めている。**1,185円には、値上がり前に安く買った肉が混ざっている。
::
::choice B. 移動平均法で計算し直した約1,201円をもとにする。今の値段に近いからだ
**△ 先入先出法よりは今に近いが、まだ過去の仕入値の平均だ。**しかも、帳簿の方法を都合で変えることになる（継続性の原則）。
::
::choice C. 今の仕入値1,400円をもとに、これまでの粗利率を保てる売値にする
**○ 今の値段を見ている点はよいが、値上げのあとの値段ではない。**12月以降に売る肉は、1,500円で仕入れることになる。1回で済ませたいなら、まだ足りない。
::
::choice D. 12月以降の仕入値1,500円をもとに、これまでの粗利率を保てる売値にする
**◎ 値上げのあとに売る肉の原価から考えている。**値段は未来の取引に付けるものだ。1回で済ませるなら、値上げの期間に仕入れる値段を見る。見込みが外れたときに備えて、1,400円と1,500円の両方で粗利を確かめておくとさらによい。
::
::answer 考え方の例を見る
- **帳簿の原価は過去の記録**：先入先出法でも移動平均法でも、過去の仕入値からできている
- **値段は未来に付ける**：値上げのあとに売る商品を、いくらで仕入れるかで考える
- **帳簿の方法は変えない**：値付けのために見る数字と、帳簿の方法は別もの
::
::

::exam 商品有高帳の急所
- 商品有高帳は**原価**で記録する。売上の行でも払出欄の単価は原価。売価を書いたら即失点。
- 先入先出法では、単価の異なる残高を**行を分けて**書く。払出しが2つの単価にまたがるときも2行に分ける。
- 移動平均法では、**仕入れのたびに**平均単価を計算し直す。払出しのときには計算し直さない。
- 月末の在庫は「次月繰越」として**払出欄**に書き、受入欄と払出欄の合計を一致させる。
- 売上原価＝月初在庫＋当月仕入－月末在庫。払出欄の合計から次月繰越を除いた金額と一致する。
- 物価上昇局面では、先入先出法のほうが売上原価が小さく、利益と期末在庫が大きくなる。
::

::next 「在庫の評価」は、会計の大きなテーマ
2級では**棚卸減耗損**や**商品評価損**を、1級では総平均法・売価還元法などの評価方法や、「取得原価か、時価か」という会計の根本的な論争に踏み込む。同じ利益でも、それが本業の稼ぐ力によるものか、相場の上昇によるものかを見分けられる人は、数字に騙されない。
::

::summary
- 商品有高帳は、品目ごとの受入・払出・残高を、数量・単価・金額で記録する補助簿。すべて「原価」で記入する
- 先入先出法：先に仕入れたものから払い出すと仮定。単価の違う残高は行を分ける
- 移動平均法：仕入れのたびに平均単価を計算し直し、その単価で払い出す
- 方法が違っても「売上原価＋期末在庫」の合計は同じ。違うのは、その切り分け方だけ
- 物価上昇局面では、先入先出法のほうが利益が大きく出る。ただし、その一部は相場上昇による見かけの利益
- 一度選んだ方法は継続して使う（継続性の原則）
- 仕入帳・売上帳は取引の明細を記録する補助簿。純仕入高＝総仕入高－仕入戻し高、純売上高＝総売上高－売上戻り高
::

## 確認問題

::quiz
::problem 次の資料にもとづき、(1)先入先出法と(2)移動平均法のそれぞれについて、11月の売上原価、月末在庫、売上総利益を求めなさい。
11/1 前月繰越 10個 @500円　11/5 仕入 20個 @530円　11/10 売上 25個（売価@800円）　11/20 仕入 15個 @560円　11/25 売上 12個（売価@800円）
::table 解答欄（単位：円）
| 項目 | (1) 先入先出法 | (2) 移動平均法 |
| 売上原価 | [[19,520]] | [[19,600]] |
| 月末在庫 | [[4,480]] | [[4,400]] |
| 売上総利益 | [[10,080]] | [[10,000]] |
::
::answer
**(1) 先入先出法**
11/10の払出：10個×500円＋15個×530円＝12,950円（残：5個@530円）
11/25の払出：5個×530円＋7個×560円＝6,570円（残：8個@560円）
売上原価＝12,950＋6,570＝**19,520円**、月末在庫＝8個×560円＝**4,480円**
**(2) 移動平均法**
11/5の平均単価：（5,000＋10,600）÷30個＝520円 → 11/10の払出：25個×520円＝13,000円（残：5個・2,600円）
11/20の平均単価：（2,600＋8,400）÷20個＝550円 → 11/25の払出：12個×550円＝6,600円（残：8個・4,400円）
売上原価＝13,000＋6,600＝**19,600円**、月末在庫＝**4,400円**
**売上総利益**
売上高＝37個×800円＝29,600円
先入先出法：29,600－19,520＝**10,080円**、移動平均法：29,600－19,600＝**10,000円**
検算：どちらも「売上原価＋月末在庫」＝24,000円（＝5,000＋10,600＋8,400）で一致する。

::problem 仕入単価が継続的に上昇しているとき、先入先出法と移動平均法では、どちらの売上総利益が大きくなるか。理由とともに答えなさい。

**先入先出法**のほうが大きくなる。先入先出法は、古くて安い単価の商品から払い出したと仮定するため、売上原価が小さく計算されるからだ。その分、期末の在庫は新しい（高い）単価で評価される。

純仕入高＝総仕入高－仕入戻し高＝1,250,000－34,000＝**1,216,000円**
引取運賃は仕入原価に含める付随費用なので、差し引かない。
