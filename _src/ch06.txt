## 商品有高帳 ― 品目ごとの「在庫の家計簿」

謎を解く舞台は、**商品有高帳**（しょうひんありだかちょう）という帳簿だ。
第5章で学んだ三分法では、仕入勘定と売上勘定に「金額」は記録されるが、「どの商品が、何個、いくらで、いつ入って、いつ出ていったか」は分からない。そこで、**商品の種類ごと**に、受け入れ（仕入）・払い出し（販売）・残高を、**数量・単価・金額**で記録する補助簿を設ける。これが商品有高帳である。

::theory 商品有高帳は、すべて「原価」で記録する
商品有高帳の最大の注意点は、**払出欄も残高欄も、すべて原価（仕入単価）で記録する**ことだ。売った商品でも、売価（1kg 1,800円など）は書かない。
商品有高帳の目的は、「いま、いくら分の在庫があるか」と「売れた商品の原価（売上原価）はいくらか」を知ることだからだ。売価は売上帳に記録される。
::

ここで問題が起きる。牛肉の仕入値は、毎回違う。1kg 1,000円で買った肉と、1,200円で買った肉が、冷蔵庫の中で混ざっている。そこから400kgを出荷したとき、その原価は1kgいくらで計算すればよいのか？
この「払い出した商品の単価（**払出単価**）」の決め方として、3級では2つの方法を学ぶ。

## 10月の牛ばら肉の動き

まず、洛北ミートの10月の牛ばら肉の動きを確認しよう。牛肉相場は上昇の一途で、仕入値は月の中でも上がり続けていた。

::table 洛北ミート・牛ばら肉の10月の取引
| 日付 | 取引 | 数量 | 単価 |
| 10/1 | 前月繰越（月初の在庫） | 200kg | 1,000円 |
| 10/8 | 畜産会社Aから仕入れ | 300kg | 1,200円 |
| 10/12 | 焼肉店に販売（売価1kgあたり1,800円） | 400kg | － |
| 10/20 | 畜産会社Bから仕入れ | 300kg | 1,400円 |
| 10/27 | おかわり堂に販売（売価1kgあたり1,800円） | 250kg | － |
::

## 先入先出法 ― 先に仕入れたものから先に払い出す

**先入先出法**（さきいれさきだしほう）は、「**先に仕入れた商品から、先に払い出した**」と仮定して払出単価を決める方法だ。生鮮食品のように、古いものから使うのが自然な商品の流れとよく合う。

::table compact sum 商品有高帳（先入先出法）　品名：牛ばら肉（単位：kg・円）
!! 日付 | 摘要 | 受入*3 | 払出*3 | 残高*3
| 数量 | 単価 | 金額 | 数量 | 単価 | 金額 | 数量 | 単価 | 金額 |
| 10/1 | 前月繰越 | 200 | 1,000 | 200,000 |  |  |  | 200 | 1,000 | 200,000 |
| 10/8 | 仕入 | 300 | 1,200 | 360,000 |  |  |  | 200 | 1,000 | 200,000 |
|  |  |  |  |  |  |  |  | 300 | 1,200 | 360,000 |
| 10/12 | 売上 |  |  |  | 200 | 1,000 | 200,000 |  |  |  |
|  |  |  |  |  | 200 | 1,200 | 240,000 | 100 | 1,200 | 120,000 |
| 10/20 | 仕入 | 300 | 1,400 | 420,000 |  |  |  | 100 | 1,200 | 120,000 |
|  |  |  |  |  |  |  |  | 300 | 1,400 | 420,000 |
| 10/27 | 売上 |  |  |  | 100 | 1,200 | 120,000 |  |  |  |
|  |  |  |  |  | 150 | 1,400 | 210,000 | 150 | 1,400 | 210,000 |
| 10/31 | 次月繰越 |  |  |  | 150 | 1,400 | 210,000 |  |  |  |
|= |  | 800 |  | 980,000 | 800 |  | 980,000 |  |  |  |
| 11/1 | 前月繰越 | 150 | 1,400 | 210,000 |  |  |  | 150 | 1,400 | 210,000 |
::

ポイントを順に見ていこう。

- **10/8**：単価の違う在庫が2種類になった。先入先出法では、単価ごとに**行を分けて**残高を記入する（実際の帳簿では中かっこ「｛」でくくる）。
- **10/12**：400kgの払い出し。先に仕入れた1,000円の肉200kgを全部出し、足りない200kgを1,200円の肉から出す。払出欄も2行になる。原価は200,000＋240,000＝440,000円。
- **10/27**：残っていた1,200円の肉100kgを先に出し、残り150kgを1,400円の肉から出す。原価は120,000＋210,000＝330,000円。
- **10/31**：月末の在庫を「次月繰越」として**払出欄**に記入し、受入欄と払出欄の合計を一致させて締め切る。翌月は「前月繰越」から始める。

先入先出法による10月の売上原価は、440,000＋330,000＝**770,000円**。月末在庫は**210,000円**だ。

## 移動平均法 ― 仕入れのたびに平均単価を計算し直す

**移動平均法**（いどうへいきんほう）は、仕入れるたびに、そのときの在庫と新たに仕入れた商品の**平均単価**を計算し直し、その単価で払い出す方法だ。

::formula 移動平均法の平均単価
平均単価 ＝ （残高の金額 ＋ 受入の金額）÷（残高の数量 ＋ 受入の数量）
::

::table compact sum 商品有高帳（移動平均法）　品名：牛ばら肉（単位：kg・円）
!! 日付 | 摘要 | 受入*3 | 払出*3 | 残高*3
| 数量 | 単価 | 金額 | 数量 | 単価 | 金額 | 数量 | 単価 | 金額 |
| 10/1 | 前月繰越 | 200 | 1,000 | 200,000 |  |  |  | 200 | 1,000 | 200,000 |
| 10/8 | 仕入 | 300 | 1,200 | 360,000 |  |  |  | 500 | 1,120 | 560,000 |
| 10/12 | 売上 |  |  |  | 400 | 1,120 | 448,000 | 100 | 1,120 | 112,000 |
| 10/20 | 仕入 | 300 | 1,400 | 420,000 |  |  |  | 400 | 1,330 | 532,000 |
| 10/27 | 売上 |  |  |  | 250 | 1,330 | 332,500 | 150 | 1,330 | 199,500 |
| 10/31 | 次月繰越 |  |  |  | 150 | 1,330 | 199,500 |  |  |  |
|= |  | 800 |  | 980,000 | 800 |  | 980,000 |  |  |  |
| 11/1 | 前月繰越 | 150 | 1,330 | 199,500 |  |  |  | 150 | 1,330 | 199,500 |
::

- **10/8**：（200,000＋360,000）÷（200＋300）＝ **1,120円**。以後、次に仕入れるまでこの単価で払い出す。
- **10/20**：残高112,000円・100kgに、420,000円・300kgが加わる。（112,000＋420,000）÷（100＋300）＝ **1,330円**。

移動平均法による10月の売上原価は、448,000＋332,500＝**780,500円**。月末在庫は**199,500円**だ。

## 謎解き ― 「真実」は1つではない

2つの方法の結果を並べてみよう。

::table 払出単価の決め方による違い（10月・牛ばら肉）
| 項目 | 先入先出法（島田） | 移動平均法（谷口） |
| 売上高（650kg×1,800円） | 1,170,000 | 1,170,000 |
| 売上原価 | 770,000 | 780,500 |
|= 売上総利益 | 400,000 | 389,500 |
| 月末在庫 | 210,000 | 199,500 |
| 合計（売上原価＋月末在庫） | 980,000 | 980,000 |
::

::solve どちらも正しい。違うのは「仮定」だけだ
ベテランの島田は**先入先出法**で、新人の谷口は**移動平均法**で計算していた。洛北ミートが正式に採用しているのは先入先出法だが、谷口は研修で習った移動平均法で計算してしまったのだ。
表の最終行を見てほしい。どちらの方法でも、「売上原価＋月末在庫」は**980,000円**で同じだ。これは、10月に「売ることができた肉の原価の総額」（月初在庫200,000円＋仕入780,000円）にほかならない。払出単価の決め方とは、**この980,000円を、「売れた分（売上原価）」と「残った分（在庫）」にどう切り分けるか**のルールなのだ。
仕入値が上がり続けている局面では、先入先出法は「古くて安い肉から売れた」と仮定するので、売上原価が小さくなり、利益が大きく出る。移動平均法は新旧の単価をならすので、その中間になる。
どちらが「真実」か？　答えは、**どちらも真実**だ。会計の数字は、あらかじめ定めた仮定（会計方針）のもとで計算された結果である。だから大切なのは、どの方法を選ぶかよりも、**選んだ方法を毎期継続して使うこと**だ。
::

::theory 継続性の原則 ― 「都合のいいときだけ方法を変える」ことは許されない
もし会社が、利益を多く見せたい年は先入先出法、少なく見せたい年は別の方法、と自由に切り替えられたら、決算書を年ごとに比べる意味がなくなってしまう。
そこで会計には、一度採用した会計処理の方法は、正当な理由がない限り毎期継続して適用しなければならない、という**継続性の原則**がある。方法を変える場合は、その理由と影響を決算書の注記で開示しなければならない。
会計は「1つの正解」を求める学問ではない。**一貫したルールのもとで、比較可能な数字を作る**技術なのである。
::

::cfo 先入先出法の「40万円の利益」は、本物の儲けか？
牛肉の仕入値は、今や1kg 1,400円。今後も上がり続ける見通しだ。先入先出法による10月の粗利は400,000円。社長は「先入先出法のほうが利益が大きいなら、ずっとこのままでいい」と満足している。あなたがCFOなら、この40万円をどう評価するか？
::answer
先入先出法の利益には、**「値上がり前に安く仕入れていた」ことによる見かけ上の利益**が含まれている。
10月に売った650kgを、もし月末の仕入値（1,400円）で仕入れ直すとしたら、コストは910,000円かかる。売上1,170,000円との差は260,000円。帳簿上の粗利400,000円との差額140,000円は、本業の「売る力」で稼いだというより、**在庫を持っていた間に相場が上がった**ことで生まれた利益（保有利得）だ。
これを「本当の儲け」と勘違いして、配当や賞与で全部配ってしまうと危険だ。次に同じ量の肉を仕入れるには、以前より多くの現金が必要になる。しかも、帳簿上の利益が大きくなる分、**税金も多く払う**ことになる。インフレ局面の先入先出法は、利益を大きく見せる一方で、現金を細らせやすいのだ。
CFOとしては、帳簿上の粗利とあわせて「最新の仕入値で計算した場合の粗利」も経営会議に報告し、販売価格の引き上げが必要かどうかを判断する材料にしたい。
::
::

## 商品有高帳から売上原価と粗利を求める

試験の第2問では、商品有高帳を作成させたうえで、売上原価や売上総利益を答えさせる問題がよく出る。手順は次のとおりだ。

::steps 商品有高帳の問題の解き方
払出単価の決め方を確認する | 先入先出法か、移動平均法か。移動平均法の端数処理の指示も確認する
受入・払出・残高を1行ずつ記入する | 払出欄は「原価」で書く。売価は使わない（売価は売上高の計算に使う）
売上原価を集計する | 払出欄の合計から、次月繰越の金額を除く（＝月初在庫＋当月仕入－月末在庫）
売上高を計算する | 販売数量×売価。売上帳や問題文の資料から求める
売上総利益を計算する | 売上高－売上原価
::

::point 返品があったときの商品有高帳
- **仕入戻し**（仕入れた商品を返品した）：返品した商品の仕入単価で、**払出欄**に記入する。
- **売上戻り**（売った商品が返品された）：その商品を払い出したときの単価で、**受入欄**に記入する。
どちらも「在庫が減ったか、増えたか」で記入欄を判断すればよい。
::

## 仕入帳と売上帳 ― 取引の「明細」を残す補助簿

商品有高帳が「品目ごとの在庫」を記録するのに対し、**仕入帳**と**売上帳**は、仕入と売上の取引そのものの明細（取引先、支払条件、品名、数量、単価）を日付順に記録する補助簿だ。

::table 仕入帳（洛北ミート・10月）
| 日付 | 摘要 | 内訳 | 金額 |
| 10/8 | 畜産会社A　掛け |  |  |
|  | 牛ばら肉　300kg　@1,200 |  | 360,000 |
| 10/20 | 畜産会社B　掛け |  |  |
|  | 牛ばら肉　300kg　@1,400 | 420,000 |  |
|  | 豚ロース　200kg　@900 | 180,000 | 600,000 |
| 10/22 | 畜産会社B　掛け返品 |  |  |
|  | 豚ロース　10kg　@900 |  | 9,000 |
| 10/31 | 総仕入高 |  | 960,000 |
|  | 仕入戻し高 |  | 9,000 |
|= | 純仕入高 |  | 951,000 |
::

::note
※1回の仕入れで複数の品目があるときは、品目ごとの金額を「内訳」欄に書き、合計を「金額」欄に書く。返品の行は、実際の帳簿では赤字で記入する。月末に、総仕入高から仕入戻し高を差し引いて**純仕入高**を求める。
::

::table 売上帳（洛北ミート・10月）
| 日付 | 摘要 | 内訳 | 金額 |
| 10/12 | 焼肉店X　掛け |  |  |
|  | 牛ばら肉　400kg　@1,800 |  | 720,000 |
| 10/27 | おかわり堂　掛け |  |  |
|  | 牛ばら肉　250kg　@1,800 |  | 450,000 |
| 10/31 | 総売上高 |  | 1,170,000 |
|= | 純売上高 |  | 1,170,000 |
::

::note
※売上帳では、総売上高から売上戻り高を差し引いて**純売上高**を求める（この月は売上戻りがないので総売上高と同じ）。仕入帳・売上帳は売価や仕入価格で、商品有高帳は原価で記録する。この違いを混同しないこと。
::

::table 商品売買に関する3つの補助簿
| 帳簿 | 記録する内容 | 単価・金額 |
| 仕入帳 | 仕入取引の明細（取引先・条件・品名・数量） | 仕入価格 |
| 売上帳 | 売上取引の明細（取引先・条件・品名・数量） | 売価 |
| 商品有高帳 | 品目ごとの受入・払出・残高 | 原価 |
::

::danger 「帳簿上の在庫」と「冷蔵庫の中身」がズレたとき
商品有高帳の残高は、「理屈の上では、これだけあるはず」という在庫だ。だが現実の倉庫では、肉の切り落としのロス、計量の誤差、賞味期限切れによる廃棄、そして盗難が起きる。
帳簿上の在庫と、実際に数えた在庫（実地棚卸）が大きくズレているのに放置すると、売上原価は小さく、利益は大きく計算され続ける。ある日まとめて損失が表面化したときには、すでに何年分もの「見えない赤字」が積み上がっている。
商品有高帳と実地棚卸を定期的に突き合わせることは、在庫という「現金が姿を変えたもの」を守るための、最も基本的な防衛線なのだ。
::

::exam 商品有高帳の急所
- 商品有高帳は**原価**で記録する。売上の行でも払出欄の単価は原価。売価を書いたら即失点。
- 先入先出法では、単価の異なる残高を**行を分けて**書く。払出しが2つの単価にまたがるときも2行に分ける。
- 移動平均法では、**仕入れのたびに**平均単価を計算し直す。払出しのときには計算し直さない。
- 月末の在庫は「次月繰越」として**払出欄**に書き、受入欄と払出欄の合計を一致させる。
- 売上原価＝月初在庫＋当月仕入－月末在庫。払出欄の合計から次月繰越を除いた金額と一致する。
- 物価上昇局面では、先入先出法のほうが売上原価が小さく、利益と期末在庫が大きくなる。
::

::next 「在庫の評価」は、会計の大きなテーマ
2級では、期末の在庫の実際の数量が帳簿より少ない場合の**棚卸減耗損**や、在庫の時価が原価を下回った場合の**商品評価損**を学ぶ。1級では、在庫の評価方法（総平均法・売価還元法など）や、「取得原価で評価するのか、時価で評価するのか」という会計の根本的な論争にも踏み込む。
また、本章のCFOの問いで見た「保有利得」の考え方は、インフレ時代の経営分析で欠かせない視点だ。同じ利益でも、それが本業の稼ぐ力によるものか、相場の上昇によるものかを見分けられる人は、数字に騙されない。
::

## 確認問題

::quiz
::problem 次の資料にもとづき、(1)先入先出法と(2)移動平均法のそれぞれについて、11月の売上原価、月末在庫、売上総利益を求めなさい。
11/1 前月繰越 10個 @500円　11/5 仕入 20個 @530円　11/10 売上 25個（売価@800円）　11/20 仕入 15個 @560円　11/25 売上 12個（売価@800円）
::answer
**(1) 先入先出法**
11/10の払出：10個×500円＋15個×530円＝12,950円（残：5個@530円）
11/25の払出：5個×530円＋7個×560円＝6,570円（残：8個@560円）
売上原価＝12,950＋6,570＝**19,520円**、月末在庫＝8個×560円＝**4,480円**
**(2) 移動平均法**
11/5の平均単価：（5,000＋10,600）÷30個＝520円 → 11/10の払出：25個×520円＝13,000円（残：5個・2,600円）
11/20の平均単価：（2,600＋8,400）÷20個＝550円 → 11/25の払出：12個×550円＝6,600円（残：8個・4,400円）
売上原価＝13,000＋6,600＝**19,600円**、月末在庫＝**4,400円**
**売上総利益**
売上高＝37個×800円＝29,600円
先入先出法：29,600－19,520＝**10,080円**、移動平均法：29,600－19,600＝**10,000円**
検算：どちらも「売上原価＋月末在庫」＝24,000円（＝5,000＋10,600＋8,400）で一致する。
::
::
::problem 仕入単価が継続的に上昇しているとき、先入先出法と移動平均法では、どちらの売上総利益が大きくなるか。理由とともに答えなさい。
::answer
**先入先出法**のほうが大きくなる。先入先出法は、古くて安い単価の商品から払い出したと仮定するため、売上原価が小さく計算されるからだ。その分、期末の在庫は新しい（高い）単価で評価される。
::

::problem 次の資料から、純仕入高を求めなさい。
総仕入高 1,250,000円、仕入戻し高 34,000円、仕入れの際に当社が負担した引取運賃（総仕入高に含まれている）12,000円
::answer
純仕入高＝総仕入高－仕入戻し高＝1,250,000－34,000＝**1,216,000円**
引取運賃は仕入原価に含める付随費用なので、差し引かない。

::summary
- 商品有高帳は、品目ごとの受入・払出・残高を、数量・単価・金額で記録する補助簿。すべて「原価」で記入する
- 先入先出法：先に仕入れたものから払い出すと仮定。単価の違う残高は行を分ける
- 移動平均法：仕入れのたびに平均単価を計算し直し、その単価で払い出す
- 方法が違っても「売上原価＋期末在庫」の合計は同じ。違うのは、その切り分け方だけ
- 物価上昇局面では、先入先出法のほうが利益が大きく出る。ただし、その一部は相場上昇による見かけの利益
- 一度選んだ方法は継続して使う（継続性の原則）
- 仕入帳・売上帳は取引の明細を記録する補助簿。純仕入高＝総仕入高－仕入戻し高、純売上高＝総売上高－売上戻り高
::
