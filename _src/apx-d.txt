::point 解答の見方
解答と解説は、各問題の下のボタンを開くと表示される。60分が経つまでは開かないこと。勘定科目は、本書で学んだ3級の標準的な勘定科目を使う。消費税は、問題文に指示があるときだけ税抜方式で処理する。

## 第1問（45点：各3点）

::quiz
::problem 商品450,000円（税抜価格）を仕入れ、代金のうち50,000円は注文時に支払った手付金と相殺し、残額は消費税（10%）とあわせて掛けとした。消費税は税抜方式で処理する。
::answer
::journal
仕入 450,000 | 前払金 50,000
仮払消費税 45,000 | 買掛金 445,000
::
消費税は450,000×10%＝45,000円。支払総額495,000円のうち、手付金50,000円を差し引いた445,000円が買掛金になる（第5・9・14章）。
::
::
::problem 商品380,000円をクレジットカード払いの条件で販売した。カード会社への手数料（販売代金の3%）は販売時に計上する。
::answer
::journal
クレジット売掛金 368,600 | 売上 380,000
支払手数料 11,400 |
::
手数料は380,000×3%＝11,400円。売上は総額で計上する（第7章）。
::
::
::problem 従業員の給料620,000円の支払いにあたり、所得税18,000円、住民税22,000円、社会保険料（本人負担分）64,000円を差し引き、残額を普通預金から振り込んだ。
::answer
::journal
給料 620,000 | 所得税預り金 18,000
 | 住民税預り金 22,000
 | 社会保険料預り金 64,000
 | 普通預金 516,000
::
給料は総支給額で計上し、天引き額は預り金とする（第10章）。
::
::
::problem 社会保険料について、従業員負担分64,000円と会社負担分64,000円を合わせて、普通預金から納付した。
::answer
::journal
社会保険料預り金 64,000 | 普通預金 128,000
法定福利費 64,000 |
::
会社負担分は法定福利費（第10章）。
::
::
::problem 業務用のオーブン1,200,000円を購入し、据付費30,000円とともに、代金は月末に支払うことにした（勘定科目は備品）。
::answer
::journal
備品 1,230,000 | 未払金 1,230,000
::
据付費は取得原価に含め、商品以外の後払いは未払金（第9・12章）。
::
::
::problem 9月30日に、備品（取得原価900,000円、期首の減価償却累計額540,000円、耐用年数5年、残存価額ゼロ、定額法、間接法）を200,000円で売却し、代金は翌月末に受け取ることにした。決算日は3月31日であり、当期分の減価償却費は月割で計上する。
::answer
::journal
備品減価償却累計額 540,000 | 備品 900,000
減価償却費 90,000 |
未収入金 200,000 |
固定資産売却損 70,000 |
::
当期の減価償却費＝900,000÷5年×6/12＝90,000円（4月〜9月）。帳簿価額＝900,000－540,000－90,000＝270,000円。200,000円で売ったので売却損70,000円（第12章）。
::
::
::problem 前期に発生した売掛金150,000円が、得意先の倒産により回収不能となった。貸倒引当金の残高は90,000円である。
::answer
::journal
貸倒引当金 90,000 | 売掛金 150,000
貸倒損失 60,000 |
::
前期発生の債権は、まず貸倒引当金を取り崩し、不足分を貸倒損失とする（第11章）。
::
::
::problem 決算において、現金過不足勘定の貸方残高4,500円の原因を調べたところ、受取手数料6,000円の記入漏れと、郵便切手代800円の記入漏れが判明した。残額は原因不明である。
::answer
::journal
現金過不足 4,500 | 受取手数料 6,000
通信費 800 |
雑損 700 |
::
貸方残高の現金過不足を借方に書いてゼロにし、判明した原因を仕訳したうえで、貸借差額700円（借方）を雑損とする（第3章）。
::
::
::problem 増資のため、株式300株を1株あたり50,000円で発行し、払込金額は普通預金に入金された。
::answer
::journal
普通預金 15,000,000 | 資本金 15,000,000
::
3級では払込金額の全額を資本金とする（第13章）。
::
::
::problem 株主総会で、繰越利益剰余金を財源として、株主配当金600,000円と利益準備金60,000円の積立てが決議された。
::answer
::journal
繰越利益剰余金 660,000 | 未払配当金 600,000
 | 利益準備金 60,000
::
決議の時点ではまだ支払っていないので未払配当金（第13章）。
::
::
::problem 買掛金280,000円の支払いのため、取引銀行を通じて電子記録債務の発生記録を行った。
::answer
::journal
買掛金 280,000 | 電子記録債務 280,000
::
（第8章）
::
::
::problem 銀行から、借入期間9か月、年利率3.2%で2,000,000円を借り入れ、利息を差し引かれた残額が普通預金に入金された。
::answer
::journal
普通預金 1,952,000 | 借入金 2,000,000
支払利息 48,000 |
::
利息＝2,000,000×3.2%×9/12＝48,000円（第9章）。
::
::
::problem 出張から戻った従業員から、タクシー代4,800円と宿泊費12,000円の領収書の提出を受け、出張前に渡していた概算額20,000円との差額を現金で受け取った。
::answer
::journal

現金 3,200 |
::
概算払いは仮払金で処理していたので、確定した旅費に振り替え、残額を回収する（第9章）。

::
::problem 店舗を賃借し、保証金400,000円、1か月分の家賃200,000円、不動産会社への仲介手数料200,000円を普通預金から支払った。
::answer
::journal
差入保証金 400,000 | 普通預金 800,000
支払家賃 200,000 |
支払手数料 200,000 |
::
保証金は返ってくる権利なので資産（第9章）。
::
::
::problem 得意先から商品の内金50,000円を現金で受け取った際に、誤って売上として処理していたことが判明した。これを訂正する。
::answer
::journal
売上 50,000 | 前受金 50,000
::
誤った仕訳「現金／売上」の逆仕訳「売上／現金」と、正しい仕訳「現金／前受金」を合算し、現金を相殺する（第16章）。

## 第2問（20点）

### 問1（10点：各2点）

当期（4月1日〜3月31日）の保険料勘定と前払保険料勘定の記入である。保険料は、毎年11月1日に1年分（216,000円）を普通預金から支払っている。前期末には、4月〜10月の7か月分を前払保険料として計上した。空欄（ア）〜（オ）に当てはまる勘定科目または金額を答えなさい。

::tgrid
::taccount 保険料
4/1 （ア） 126,000 | 3/31 前払保険料 （ウ）
11/1 普通預金 216,000 | 3/31 （エ） （オ）
= （イ） | （イ）
::
::taccount 前払保険料
4/1 前期繰越 126,000 | 4/1 保険料 126,000
3/31 保険料 （ウ） | 3/31 次期繰越 （ウ）
::
::

::quiz
::problem 第2問・問1の解答
::answer
（ア）**前払保険料**　（イ）**342,000**　（ウ）**126,000**　（エ）**損益**　（オ）**216,000**
::tgrid
::taccount 保険料
4/1 前払保険料 126,000 | 3/31 前払保険料 126,000
11/1 普通預金 216,000 | 3/31 損益 216,000
= 342,000 | 342,000
::
::taccount 前払保険料
4/1 前期繰越 126,000 | 4/1 保険料 126,000
3/31 保険料 126,000 | 3/31 次期繰越 126,000
= 252,000 | 252,000
::
::
- 4/1：前期末の前払分の再振替（保険料／前払保険料）。
- 3/31：11月1日に支払った1年分のうち、翌期4月〜10月の7か月分を繰り延べる。216,000×7/12＝126,000円。
- 3/31：当期の保険料（126,000＋216,000－126,000＝216,000円）を損益勘定に振り替えて締め切る（第15・19章）。
::
::
::

### 問2（10点：各2点）

次の文の空欄（ア）〜（オ）に当てはまる語句を、下の語群から選びなさい。

1. 仕訳帳に記入した取引を、総勘定元帳の各勘定に書き移す手続きを（ア）という。
2. すべての勘定の借方の合計と貸方の合計が一致することを、（イ）の原理という。
3. 期中に費用として処理した支払額のうち、次期以降の分を資産として繰り延べるときに用いる勘定を、まとめて（ウ）という。
4. 資産・負債・純資産の勘定に「次期繰越」と記入して締め切り、翌期首に「前期繰越」と記入する決算の方法を、（エ）決算法という。
5. 売掛金元帳や商品有高帳のように、特定の勘定の内訳を記録する補助簿を（オ）という。

語群：仕訳／転記／試算表／貸借平均／前払費用／未払費用／英米式／大陸式／補助元帳／補助記入帳

::quiz
::problem 第2問・問2の解答
::answer
（ア）**転記**　（イ）**貸借平均**　（ウ）**前払費用**　（エ）**英米式**　（オ）**補助元帳**
現金出納帳や仕入帳のように、取引の明細を発生順に記録する補助簿は「補助記入帳」。特定の勘定の内訳を記録するのが「補助元帳」だ（第2・15・16・19章）。
::
::

::table 配点と採点の目安
| 大問 | 配点 | 採点のしかた |

::steps 採点したら、次の順で復習する
70点以上なら合格圏 | 間違えた問題の章の「試験の急所」を読み直し、同じ問題をもう一度解く
第1問が36点未満なら | 付録Cの仕訳道場を、1問30秒になるまでくり返す

最後に | ネット試験の模擬問題や過去問で、別の問題を60分で解いて仕上げる

::summary 模擬試験のまとめ
- 解く順番は第1問→第3問→第2問。配点の大きい問題から確実に取る

- 月次決算の減価償却は決算月の分だけ、貸倒引当金は未処理事項を処理した後の残高で計算する
- 貸借対照表の繰越利益剰余金には当期純利益を加える
