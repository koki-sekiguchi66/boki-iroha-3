::mystery 経理部長は、なぜ社長の頼みを断ったのか
ナイトオウル交通の第2期が始まったばかりの4月。月次巡回で東京本社の経理室を訪ねたひよりは、その週に起きた3つの出来事を聞かされた。
1つ目。大手旅行会社と、年間**1億円**分の団体客を送り込んでもらう契約を結んだ。運転手不足でバスの席を確保しにくくなった旅行会社のほうから、頭を下げてきた話だ。
2つ目。バスメーカーに、3台目となる新車（**5,000万円**）を発注した。納車は半年後になる。
3つ目。月曜の未明、大阪営業所に空き巣が入り、金庫の現金**30万円**が盗まれた。
金曜の夕方、社長の三國は、翌週に控えた銀行との面談のために帳簿を開いた。そして眉をひそめた。「1億円の契約も、5,000万円の発注も、どこにも載っていない。載っているのは泥棒の30万円だけ。これでは、会社が勢いづいていることが銀行に伝わらないでしょう。契約の分を、売上に入れておいてもらえませんか」
ひよりは、内心でうなずいていた。1億円の契約は、どう見ても会社にとって最大のニュースだ。それが帳簿のどこにもないのは、おかしい。
だが、経理部長の柏木は違った。信用金庫で30年、融資の審査をしてきた人だ。老眼鏡を外し、静かに首を振った。「社長、それはできません。この帳簿は、これで正しいのです」
三國が出ていったあと、柏木はひよりのほうを向いた。「鴨川さんのところの新人さんでしたね。なぜ私が断ったのか、説明できますか」
ひよりは答えられなかった。
1億円の契約は記録せず、30万円の盗難だけを記録する。それが「正しい」とは、どういうことか？
::

## 簿記上の「取引」は、世間の取引と違う

その夜、京都へ帰る新幹線の中で、ひよりは一ノ瀬に電話をかけた。
「第1章で、5つのメガネを習いましたよね」と一ノ瀬は言った。「1億円の契約を結んだ瞬間、5つのうちどれかが増えたり減ったりしましたか。お金は入りましたか。バスは増えましたか」
ひより：「……何も、動いていません」
一ノ瀬：「では、30万円の盗難では？」
ひより：「現金が、減りました」
一ノ瀬：「それが答えです」
問いを解く鍵は、**簿記上の取引**という言葉にある。
簿記でいう取引とは、「**資産・負債・純資産・収益・費用のいずれかを増減させる出来事**」のことだ。そして、その増減を**金額で測定できる**ものに限られる。
この定義に照らすと、世間の感覚とのズレが見えてくる。

::table 「取引」の判定 ― 世間と簿記のズレ
| 出来事 | 世間の感覚 | 簿記上の取引 | 理由 |
| 年1億円の送客契約を結んだ | 取引 | ✗ | 契約しただけでは、お金も財産も動いていない |
| バスを発注した | 取引 | ✗ | 注文しただけでは、まだ何も受け取っていない |
| 店舗の賃貸借契約を結んだ | 取引 | ✗ | 契約だけでは財産は増減しない（保証金を払えば取引） |
| 従業員を採用した | 取引ではない | ✗ | 雇用契約だけでは財産は増減しない |
| 現金が盗まれた | 取引ではない | ○ | 現金（資産）が減少した |
| 車庫が火事で焼けた | 取引ではない | ○ | 建物や設備（資産）が減少した |
| バスが古くなり価値が減った | 取引ではない | ○ | 資産の価値の減少を費用にする（減価償却） |
::

::solve 経理部長が正しかった理由
1億円の契約を結んでも、その時点では、会社の財産は1円も動いていない。旅行会社がお客を送り込み、バスが走り、運賃を受け取って初めて、「売上（収益）」と「現金や預金（資産）」が増える。
5,000万円の発注も同じだ。バスが納車されて初めて「車両運搬具（資産）」が増え、代金を払えば「預金（資産）」が減る。
一方、30万円の盗難は、誰にも取引の意思はないが、**現金という資産が確実に30万円減った**。だから記録しなければならない。記録しなければ、帳簿の現金と金庫の現金が一致しなくなる。
簿記が記録するのは「約束」ではなく「**財産の増減という事実**」なのである。
::

翌月の巡回で、ひよりは柏木に答えを伝えた。柏木は小さくうなずき、盗難の記録を見せてくれた。

::journal 盗難の記録（現金という資産が減り、損失という費用が発生した）
雑損 300,000 | 現金 300,000
::

::note
※盗難による損失は「雑損」のほか「盗難損失」などの勘定科目で処理することもある。試験では問題文の指示に従う。
::

::cfo 帳簿に載らない「1億円の契約」を、銀行にどう見せるか
柏木に断られた三國は、それでも契約の価値を銀行に伝えたい。面談は来週の水曜日。柏木は、契約書の写しをひよりに渡した。「銀行は、まずここを読みます」。契約の要点は次のとおりだ。
::table 旅行会社との送客契約の要点
| 項目 | 内容 |
| 期間 | 4月から1年間 |
| 送客の見込み | 年間1億円分（月平均約833万円）。ただし**送客数の保証はない** |
| 解約 | 旅行会社は**3か月前に通知すれば、違約金なしで解約できる** |
| 支払い | 毎月末締め、翌月末に運行した分を支払う |
::
三國は4つの方法を考えた。次の視点で考えてから選んでほしい。
- その方法で、**帳簿は動くのか、動かないのか**。動くなら、どの勘定が動くのか
- 契約書を読んだ銀行は、受注残のうち**どれだけを「確実」と見るか**
- 銀行がいちばん嫌うのは何か
::choice A. 契約日付で「売掛金1億円／売上1億円」と記録し、利益の大きな試算表を見せる
**× 粉飾の入り口。**バスは1台も走っておらず、旅行会社に代金を請求する権利（売掛金）もまだない。存在しない財産と売上を帳簿に書き込むことになる。
しかも、この契約は3か月前の通知で違約金なしに解約できる。銀行の審査担当が契約書を読めば、「確実に入るのは、解約通知の期間にあたる3か月分にすぎない」と考える。入金のない売掛金1億円は一発で見抜かれ、会社の数字そのものが信用されなくなる。
::
::choice B. 帳簿はそのままにして、契約書の写しと、月ごとの送客予定・入金予定の表を添える
**○ 正攻法だが、この契約のままでは弱い。**帳簿という「事実」はそのままに、未来の売上の見込み（**受注残**）を別の資料で示すのは正しい。上場企業も、決算説明会で受注残高を示している。
ただ、この契約には送客の保証がなく、3か月前の通知で解約できる。銀行がこの受注残を「返済の当て」として数えるのは、せいぜい3か月分、約2,500万円だろう。資料の作り方は正しいが、資料に載せる**契約の中身**がまだ弱い。
::
::choice C. 旅行会社と条件を交渉し、「年6,000万円分は送客が少なくても支払う」最低保証と、「四半期ごとに3か月分を前払いする」条件を加えたうえで、Bの資料を作る
**◎ 契約の中身を、銀行が数えられる形に変える。**旅行会社はバスの席を確保したくて頭を下げてきた側だ。席を確保する代わりに最低保証と前払いを求める交渉は、十分に成り立つ。
前払いを受ければ、帳簿が動く。まだバスを走らせていないので、売上ではなく**前受金**（負債。第9章）だ。
::journal 4月1日：最初の四半期分（3か月分）2,500万円が前払いで普通預金に振り込まれた
普通預金 25,000,000 | 前受金 25,000,000
::
::journal 4月30日：4月に約833万円分を運行した（前受金を売上に振り替える）
前受金 8,330,000 | 売上 8,330,000
::
最低保証があっても、それ自体は売上ではない。売上になるのは、バスを走らせた分と、期間が終わって保証分の請求が確定した分だけだ。それでも銀行から見れば、「少なくとも年6,000万円は入る」と契約書で確かめられる受注残になる。
::
::choice D. 送客予定にもとづく見込みの売上を、月次の試算表に「未収入金／売上」で計上し、注記で「見込み」と説明する
**× 説明をつけても、見込みは記録できない。**未収入金は「商品以外のものを売った代金を受け取る権利」で、まだ何も提供していない取引に使う勘定ではない。注記で断ったつもりでも、試算表の売上と利益は水増しされる。銀行は注記ではなく、試算表の数字で前年と比べる。「見込み」を帳簿に入れる会社だと分かれば、ほかの数字まで疑われる。
::
::answer 考え方の例を見る
財務諸表は「過去に起きた財産の増減」の記録であって、未来の約束は映さない。これは会計の限界であり、同時に**信頼性の源泉**でもある。「契約しただけ」で売上を計上できるなら、いくらでも数字を作れてしまうからだ。
だから財務の担当者は、**財務諸表という「事実」を土台に、別の資料で未来を語る**（B）。そして実務では、もう一歩踏み込む。銀行は契約書の**解約条項・保証・支払条件**を読み、受注残のうち「どれだけ確実か」を割り引いて評価する。
::table 同じ「1億円の契約」でも、銀行が数える金額は条件で変わる
| 契約の条件 | 銀行が確実と見る金額の目安 | 帳簿 |
| 保証なし・3か月前に解約可 | 約2,500万円（解約通知の3か月分） | 動かない |
| 年6,000万円の最低保証つき | 6,000万円 | 動かない |
| 四半期ごとの前払いつき | 前払いを受けた分は、すでに預金にある | 普通預金／前受金 |
::
**さらに考えよう：前払いは「多ければ多いほどよい」か？**
仮に、旅行会社が1年分1億円を一括で前払いしてくれたとする。預金は増えるが、帳簿では1億円の**前受金**（負債）が立つ。旅行会社が途中で解約すれば、運行していない分は返さなければならない。そのお金を新車の購入などに使ってしまえば、返金の日に払えなくなる（第9章）。前払いは「借りたお金」に近い性質を持つ。銀行も、前受金の残高と手元の預金を並べて、使い込んでいないかを確かめる。だから実務では、四半期ごとのように、**サービスを提供する期間に合わせた前払い**を求めることが多い。
「契約の価値を上げたければ、帳簿を書き換えるのではなく、契約を書き換える」。三國はCの条件を旅行会社に持ちかけ、最低保証は年5,000万円で折り合った。翌週の面談で、村井は契約書の解約条項と保証条項を何度も読み返したあと、こう言った。「この条件なら、審査に回せます」。
::
::

## 1つの取引には、必ず「2つの側面」がある

その日、経理室にはもう1人の新人がいた。入社2週間目の森下だ。前の職場は家電量販店の売り場。ひよりと同じく、簿記は勉強を始めたばかりだという。柏木は2人を並べて座らせ、軽油の領収書を1枚、机に置いた。
柏木：「18万円。現金で払いました。これを帳簿に書いてください」
森下は「現金 －180,000」と書いた。お小遣い帳と同じ書き方だ。柏木は首を振った。「それでは、なぜ18万円が減ったのかが残りません」
簿記上の取引が起きたら、それを記録する。ここで簿記は、とても巧妙な方法をとる。**1つの取引を、必ず2つの側面から記録する**のだ。
軽油を18万円分、現金で買った取引には、2つの側面がある。

- 燃料費という**費用が18万円発生した**（なぜお金が減ったのか＝原因）
- 現金という**資産が18万円減った**（お金がどうなったのか＝結果）

このように、すべての取引を「原因」と「結果」のように2つの側面に分けて記録する方法を、**複式簿記**という。お小遣い帳のように「現金が18万円減った」とだけ書くのは単式簿記だ。

::theory 複式簿記 ― 500年以上使われ続ける「世界共通のOS」
複式簿記の起源は、中世イタリアの商人たちにさかのぼる。1494年、数学者ルカ・パチョーリが著書『スンマ（算術・幾何・比および比例全書）』の中で、ヴェネツィアの商人が使っていた複式簿記を体系的に紹介した。これが、現存する最古の複式簿記の解説書の1つとされている。
それから500年以上。コンピュータが生まれ、インターネットが普及し、AIが登場した今も、世界中の会社の会計システムの心臓部では、パチョーリが紹介したのと本質的に同じ仕組みが動いている。ドイツの文豪ゲーテは、作中の人物に複式簿記を「人間の精神が生んだ最も美しい発明の1つ」と語らせた。
なぜこれほど長く生き残ったのか。理由は、**2つの側面から記録するので、記録の誤りや不正を発見しやすい**からだ。左右の金額が一致しなければ、どこかが間違っている。この自己検証機能が、商売における「信用」を支えてきたのである。
::

## 借方と貸方 ― 左と右には「意味がない」

複式簿記では、取引の2つの側面を、**左側**と**右側**に分けて記録する。この左側を**借方**（かりかた）、右側を**貸方**（かしかた）と呼ぶ。

::taccount 勘定科目
借方（かりかた）＝左 | 貸方（かしかた）＝右
::

「借りてもいないのに、借方なんですか」と森下が聞いた。ひよりも同じことを思っていた。
柏木は笑った。「30年前の私も、同じことを聞きました」
「借」「貸」という漢字に引きずられてはいけない。これは歴史的な名残にすぎず、現代の簿記では**単に「左」「右」という意味しかない**。お金を借りたかどうかとは関係ない。

::point 借方・貸方の覚え方
ひらがなで書いたときの形で覚える。
**かり**かたの「**り**」は、最後の線が**左**に払う → 借方は**左**
**かし**かたの「**し**」は、最後の線が**右**に払う → 貸方は**右**
::

## 仕訳のルール ― ホームポジションで「増」、反対側で「減」

柏木は、森下が書いた「現金 －180,000」の横に、縦線を1本引いた。
柏木：「左と右、どちらに書くかは、気分で決めるわけではありません。決まりは1つだけです」
「1つだけ、ですか」と森下が聞き返した。ひよりは、第1章で紙ナプキンに描かれた図を思い出していた。

取引を借方と貸方に分けて記録することを**仕訳**（しわけ）という。仕訳には、たった1つのルールしかない。第1章で学んだ**ホームポジション**を思い出してほしい。

::theory 仕訳の唯一のルール
各要素が**増えたら（発生したら）ホームポジション側**に、**減ったら（取り消されたら）反対側**に書く。
資産・費用のホームポジションは**左（借方）**。負債・純資産・収益のホームポジションは**右（貸方）**。
::

::table 仕訳のルール一覧
| 要素 | 増加・発生したら | 減少・取消したら |
| 資産 | 借方（左） | 貸方（右） |
| 負債 | 貸方（右） | 借方（左） |
| 純資産 | 貸方（右） | 借方（左） |
| 収益 | 貸方（右） | 借方（左） |
| 費用 | 借方（左） | 貸方（右） |
::

::tgrid compact
::taccount 資産の勘定
増加 ＋ | 減少 －
::
::taccount 負債の勘定
減少 － | 増加 ＋
::
::taccount 純資産の勘定
減少 － | 増加 ＋
::
::taccount 費用の勘定
発生 ＋ | 取消 －
::
::taccount 収益の勘定
取消 － | 発生 ＋
::
::

さっきの軽油の取引に当てはめてみよう。費用（燃料費）が発生 → 費用のホームポジションは左 → **借方**。資産（現金）が減少 → 資産のホームポジションの反対側 → **貸方**。

::journal 軽油18万円を現金で購入した
燃料費 180,000 | 現金 180,000
::

仕訳を書くときは、次の4ステップで考えると迷わない。

::steps 仕訳の4ステップ
何が起きたか？ | 取引の事実をつかむ。「軽油を買って、現金を払った」
どの勘定科目か？ | 登場する勘定科目を特定する。「燃料費」と「現金」
増えたか、減ったか？ | 各勘定科目が5要素のどれで、増えたのか減ったのかを判断する。「費用の発生」「資産の減少」
左か、右か？ | ルールに従って借方・貸方に振り分け、金額を書く。左右の合計が一致すれば完成
::

## 取引の8要素と結合関係

仕訳の借方に来るのは「資産の増加」「負債の減少」「純資産の減少」「費用の発生」の4つ。貸方に来るのは「資産の減少」「負債の増加」「純資産の増加」「収益の発生」の4つだ。合わせて8つ。これを**取引の8要素**という。
すべての取引は、借方の要素と貸方の要素の組み合わせでできている。

::table 取引の8要素（借方の要素 × 貸方の要素）
| 借方（左）の要素 | 貸方（右）の要素 |
| 資産の増加 | 資産の減少 |
| 負債の減少 | 負債の増加 |
| 純資産の減少 | 純資産の増加 |
| 費用の発生 | 収益の発生 |
::

::table 結合関係の例（ナイトオウル交通）
| 取引 | 借方の要素 | 貸方の要素 |
| 株式を発行し、出資金が普通預金に入金された | 資産の増加 | 純資産の増加 |
| 銀行からお金を借り、普通預金に入金した | 資産の増加 | 負債の増加 |
| 普通預金から現金を引き出した | 資産の増加 | 資産の減少 |
| 貸切バスを運行し、代金を現金で受け取った | 資産の増加 | 収益の発生 |
| 借入金を普通預金から返済した | 負債の減少 | 資産の減少 |
| 運転士の給料を普通預金から支払った | 費用の発生 | 資産の減少 |
| 部品を購入し、代金は月末に支払うことにした | 費用の発生 | 負債の増加 |
::

::note
※収益の発生と費用の発生が直接結びつく取引は、通常は起こらない。また、純資産の減少は、株主への配当（第13章）などの限られた場面で登場する。
::

::example 同じ「お金が出ていく」取引でも、借方に来るものは3通りある
お金が出ていく取引は、貸方がどれも「現金」か「普通預金」（資産の減少）になる。違いが出るのは借方だ。ナイトオウル交通のこの1年の支払いを、借方の要素で分けてみよう。
::sort 支払いの内容を、借方に来る要素の箱へ移しなさい。
@cats 資産の増加 | 負債の減少 | 費用の発生
軽油を現金で買った => 費用の発生
納車された3台目のバスの代金を普通預金から支払った => 資産の増加
借入金の元金を返済した => 負債の減少
借入金の利息を支払った => 費用の発生
新しい営業所の敷金（保証金）を支払った => 資産の増加
先月、月末払いの約束で買った部品の代金を支払った => 負債の減少
運転士の給料を支払った => 費用の発生
普通預金から現金を引き出した => 資産の増加
::
::answer
**資産の増加**：バスの代金（車両運搬具）、敷金（差入保証金）、現金の引き出し（現金）
**負債の減少**：借入金の元金の返済（借入金）、部品の後払い代金の支払い（未払金）
**費用の発生**：軽油（燃料費）、利息（支払利息）、給料（給料）
このうち、利益を減らすのは**費用の発生**だけだ。資産の増加と負債の減少は、お金が出ていっても利益は1円も減らない。序章のまんぷく食堂で、設備・保証金・借入金の返済が「利益に表れないお金の出口」だった理由が、ここにある。
::trap
「お金が出ていく＝費用」と決めつけないこと。借方が資産の増加や負債の減少なら、お金が減っても利益は減らない。
まず「何が増えて、何が減ったか」を言葉にしてから、借方の要素を決めよう。
::
::
::

## ナイトオウル交通、第2期の最初の1か月を仕訳する

柏木は、4月の証ひょう（領収書や通帳の写し）の束を2つに分け、ひよりと森下に1つずつ渡した。「月末までに、2人で4月分を全部仕訳してください。答え合わせは、帳簿の左右が教えてくれます」
ナイトオウル交通の第2期（×2年4月）の取引だ。前期末の時点で、普通預金は4,000万円、借入金は7,000万円ある。借入金は1年間の返済猶予（据置期間）が終わり、この月から毎月100万円ずつ返済が始まる。

::example 次の取引を仕訳しなさい
4月1日　普通預金から現金300,000円を引き出した。
4月2日　大学の体育会の合宿送迎のため貸切バスを運行し、代金450,000円を現金で受け取った。
4月3日　軽油180,000円を現金で購入した。
4月10日　借入金の元金1,000,000円と、利息175,000円を普通預金から支払った。
4月20日　運転士の給料2,400,000円を普通預金から支払った。
4月25日　車庫の空きスペースを近隣の会社に駐車場として貸し、4月分の地代80,000円が普通預金に振り込まれた。
4月28日　バスの消耗部品120,000円を購入し、代金は月末に支払うことにした。
::answer
::journal 4月1日　資産（現金）の増加・資産（普通預金）の減少
現金 300,000 | 普通預金 300,000
::
::journal 4月2日　資産（現金）の増加・収益（売上）の発生
現金 450,000 | 売上 450,000
::
::journal 4月3日　費用（燃料費）の発生・資産（現金）の減少
燃料費 180,000 | 現金 180,000
::
::journal 4月10日　負債（借入金）の減少＋費用（支払利息）の発生・資産（普通預金）の減少
借入金 1,000,000 | 普通預金 1,175,000
支払利息 175,000 |
::
::journal 4月20日　費用（給料）の発生・資産（普通預金）の減少
給料 2,400,000 | 普通預金 2,400,000
::
::journal 4月25日　資産（普通預金）の増加・収益（受取地代）の発生
普通預金 80,000 | 受取地代 80,000
::
::journal 4月28日　費用（消耗品費）の発生・負債（未払金）の増加
消耗品費 120,000 | 未払金 120,000
::
4月10日のように、借方または貸方に複数の勘定科目が並ぶ仕訳を**複合仕訳**という。複合仕訳でも、借方の合計（1,000,000＋175,000）と貸方の合計（1,175,000）は必ず一致する。
利息は、元金7,000万円×年利3%×1/12か月＝175,000円。4月28日の「あとで支払う約束」は**未払金**という負債になる（第9章）。!!販売するための商品を後払いで仕入れたときは「買掛金」、それ以外のもの（部品・備品・車両など）を後払いで買ったときは「未払金」!!と使い分ける（第7章・第9章）。初学者が最も混同しやすい組み合わせの1つだ。
::trap
4月10日の支払額1,175,000円を、まるごと費用にしてはいけない。元金の返済は負債の減少で、費用になるのは利息の175,000円だけだ。
4月1日の預金の引き出しは、資産の中身が入れ替わっただけ。お金が手元に来ても、収益は発生していない。
::
::
::

::point 仕訳を書くときの約束ごと
- 借方と貸方の金額の合計は、必ず一致させる
- 1つの仕訳の中で、借方・貸方の同じ側に同じ勘定科目を2回書かない（金額を合計して1行にする）
- 借方・貸方それぞれの中の行の順番は、問われない
::

## 転記 ― 仕訳を「勘定」ごとに集計し直す

仕訳は、取引を時系列で記録したものだ。だが、仕訳を眺めているだけでは「いま現金がいくらあるのか」は分からない。そこで、仕訳を**勘定科目ごと**に集計し直す。この作業を**転記**（てんき）という。
勘定科目ごとの記録の場所を**勘定**（かんじょう）といい、学習ではアルファベットのTの形をした**T字勘定**を使う。

::steps 転記のルール
仕訳の借方の金額は、その勘定の借方（左）に書く | 4月1日の仕訳の借方「現金 300,000」は、現金勘定の左に書く
仕訳の貸方の金額は、その勘定の貸方（右）に書く | 4月1日の仕訳の貸方「普通預金 300,000」は、普通預金勘定の右に書く
日付と「相手の勘定科目」を添える | 現金勘定の左には「4/1 普通預金 300,000」と、仕訳の反対側の勘定科目を書く
相手の勘定科目が2つ以上なら「諸口」と書く | 4月10日の普通預金の相手は借入金と支払利息の2つなので、「4/10 諸口 1,175,000」とする
::

先ほどの仕訳を、現金勘定と普通預金勘定に転記すると次のようになる。

::tgrid
::taccount 現金
4/1 普通預金 300,000 | 4/3 燃料費 180,000
4/2 売上 450,000 |
::
::taccount 普通預金
4/1 前期繰越 40,000,000 | 4/1 現金 300,000
4/25 受取地代 80,000 | 4/10 諸口 1,175,000
 | 4/20 給料 2,400,000
::
::

現金勘定の借方合計は750,000円、貸方合計は180,000円。差し引き**570,000円**が、4月末の手許現金だ。普通預金は、借方合計40,080,000円－貸方合計3,875,000円＝**36,205,000円**が残っている。このように、勘定の借方合計と貸方合計の差額を**残高**という。
資産の勘定は、ふつう借方が大きくなる（借方残高）。資産のホームポジションが左だからだ。同様に、負債・純資産・収益の勘定は貸方残高、費用の勘定は借方残高になる。

::scene 4月30日、午後8時 ― 本社2階の経理室
柏木：「森下さん、大川さん、ちょっと来て」
柏木は、2人の新人をパソコンの前に呼んだ。画面には、会社が使っているクラウド会計ソフトの「自動で経理」の一覧が並んでいる。銀行口座の入出金の明細を読み込むと、ソフトが勘定科目を推測して、仕訳の候補を出してくれる仕組みだ。
柏木：「4月10日の117万5,000円の出金。ソフトの候補は『借入金 1,175,000』になっているでしょう。これ、そのまま登録していい？」
森下は明細を見つめた。「銀行への支払いだから……借入金、ですよね」
ひよりは、自分が紙に書いた4月10日の仕訳を見直した。借方が2行ある。
「半分正解」柏木は返済予定表を指さした。「元金は100万円で、残りの17万5,000円は利息。元金の返済は借入金を減らすけど、利息は支払利息という費用。全部を借入金にしたら、費用が17万5,000円消えて、そのぶん利益が大きく出てしまう」
ソフトは入力を速くしてくれる。だが、最後に「この仕訳は正しいか」を決めるのは人間だ。仕訳を読めない人に、帳簿の責任は持てない。
帰り際、柏木はひよりに言った。「仕訳は、会社の出来事を2行の文章に書くことです。文章が嘘だと、会社全体が嘘になる」
::

## 主要簿 ― 仕訳帳と総勘定元帳

4月の仕訳を終えた2人の前に、柏木は厚いバインダーを2冊置いた。背表紙には「仕訳帳」「総勘定元帳」とある。
柏木：「さっきまで紙に書いていた仕訳とT字勘定は、練習用の形です。会社が実際に残すのは、この2冊です」
ひよりは仕訳帳を開いた。自分たちが書いた4月の取引が、日付の順に並んでいた。

実務では、仕訳を**仕訳帳**（しわけちょう）という帳簿に記録し、それを**総勘定元帳**（そうかんじょうもとちょう）に転記する。この2つは、すべての取引を記録する最も重要な帳簿なので、**主要簿**と呼ばれる。

::table compact 仕訳帳の記入例
| 日付 | 摘要 | 元丁 | 借方 | 貸方 |
| 4/10 | 諸口 ／（普通預金） | 2 |  | 1,175,000 |
|  | （借入金） | 20 | 1,000,000 |  |
|  | （支払利息） | 41 | 175,000 |  |
|  | 借入金の返済と利息の支払い |  |  |  |
::

::note
※仕訳帳では、勘定科目を（　）で囲んで書き、借方科目を左寄せ、貸方科目を右寄せで記入する。複数の科目がある側には「諸口」と書く。「元丁」欄には、転記先の総勘定元帳のページ番号（勘定口座の番号）を書き、転記済みであることを示す。最終行の小書き（こがき）は取引の内容の簡単な説明。
::

総勘定元帳は、勘定科目ごとのページを集めた帳簿だ。T字勘定は、総勘定元帳を簡略化した学習用の形である。実際の総勘定元帳には、日付・摘要（相手科目）・仕丁（仕訳帳のページ）・借方・貸方の欄を設けた**標準式**と、それに残高欄を加えた**残高式**がある。

::table compact 総勘定元帳（残高式）の例 ― 現金勘定
| 日付 | 摘要 | 仕丁 | 借方 | 貸方 | 借／貸 | 残高 |
| 4/1 | 普通預金 | 1 | 300,000 |  | 借 | 300,000 |
| 4/2 | 売上 | 1 | 450,000 |  | 借 | 750,000 |
| 4/3 | 燃料費 | 1 |  | 180,000 | 借 | 570,000 |
::

::theory 貸借平均の原理 ― 簿記が「自己検証」できる理由
すべての仕訳は、借方と貸方の金額が等しい。それをそのまま転記するのだから、**すべての勘定の借方の合計と、すべての勘定の貸方の合計は、必ず一致する**。これを**貸借平均の原理**という。
この原理を使えば、何千件もの記録の中に転記ミスや計算ミスがないかを、一発で検証できる。それが第17章で学ぶ**試算表**だ。500年前のヴェネツィアの商人が手にしていたのは、まさにこの「誤りを自動で見つける仕組み」だった。
::

::danger 「簿記上の取引」を誤解した会社の末路
「契約したのだから売上に計上してよいだろう」。この誤解は、粉飾決算の典型的な入り口だ。
実際、まだサービスを提供していない契約や、架空の注文書をもとに売上を前倒しで計上し、利益を水増しした会社は、国内外で後を絶たない。発覚すれば、過去の決算の訂正、経営陣の辞任、上場企業なら株価の暴落や上場廃止の危機に直結する。
「財産の増減という事実だけを記録する」という簿記上の取引の定義は、こうした誘惑から会社を守るためのルールなのだ。
::

::real 上場から半年で消えた会社 ― 売上の97%が「存在しない取引」だった
2009年11月、半導体製造装置メーカーのエフオーアイが東証マザーズに上場した。上場前の決算では、年間100億円を超える売上を計上していた。
ところが翌2010年5月、証券取引等監視委員会の強制捜査が入る。明らかになったのは、売上高の**約97%が架空**だったという事実だった。実際には存在しない注文をもとに、売上と売掛金を帳簿に書き込み続けていたのだ。同社は2010年6月に上場廃止となった。上場からわずか約半年。元役員らは刑事責任を問われ、株主による損害賠償の訴訟は、上場を手伝った証券会社にまで及んだ。

**この章の道具で読む ― 架空の売上は、帳簿のどこに痕跡を残すか**
存在しない注文を売上にすると、仕訳は次の形になる。「代金はあとで受け取る」という形にすれば、お金が入らなくても売上を立てられるからだ（売掛金は第7章で詳しく学ぶ）。数字は、売上の97%が架空だった構図を、仕組みが分かるように簡略化したものだ（単位：百万円）。

::journal 架空の注文で、製造装置を「販売した」ことにする（存在しない取引）
売掛金 9,700 | 売上 9,700
::

損益計算書では、売上も利益も立派に見える。だが、複式簿記はもう1つの側面を必ず残す。売上の相手方である**売掛金**だ。本物の売上300は代金が回収されて消えていくが、架空の売上9,700は、払ってくれる相手がいないので、いつまでも回収されない。売掛金の勘定を転記すると、その姿がはっきり見える。

::taccount 売掛金（1年分を簡略化・単位：百万円）
本物の売上 300 | 回収（本物の売上の分） 300
架空の売上 9,700 | 次期繰越 9,700
= 10,000 | 10,000
::

売上が年1万の会社に、回収されない売掛金が9,700も積み上がる。ふつうの会社なら、売掛金は数か月分の売上ほどしか残らない。この不自然さを隠すには、偽の入金や偽の書類を作り続けるしかなく、嘘は年々大きくなる。監査では、取引先に売掛金の残高を直接問い合わせる「残高確認」などで、売掛金が本当に存在するかを確かめる。
「事実だけを記録する」というルールを破っても、複式簿記は、破ったことの痕跡を相手勘定に残してしまう。柏木が三國の頼みを断ったのは、会社をこの入り口に立たせないためだった。
::note
出典：[証券取引等監視委員会「告発の実施について」（2010年）](https://www.fsa.go.jp/sesc/actions/kokuhatu/10/main.pdf)、[PRESIDENT Online](https://president.jp/articles/-/3673)
::
::

::exam 第1問（仕訳15問・45点）の攻略の基本
- 勘定科目は、問題文で指定された語群（ネット試験ではプルダウン）から選ぶ。語群にない科目は使えない。「現金」と「普通預金」のように似た科目の選び間違いに注意。
- 金額は、問題文の数字から計算させるものも多い（利息の月割計算など）。計算過程を問題用紙にメモする習慣をつけよう。
- 「借方・貸方に同じ科目を2回書かない」「借方合計＝貸方合計」を必ず最後に確認する。これだけで防げる失点は多い。
- 「注文した」「契約した」だけの取引は仕訳不要。ただし手付金や保証金を払っていれば、その分は仕訳が必要になる（第9章）。
::

::next 仕訳は、あらゆる会計システムの「最小単位」
クラウド会計ソフトも、大企業の基幹システム（ERP）も、内部ではすべての取引を「借方・貸方・金額」の仕訳として保存している。売上データが入力されれば売上の仕訳が、給与計算が終われば給料の仕訳が、システムの中で自動的に生成される。
2級で学ぶ**連結会計**（グループ会社全体の決算書を作る技術）も、親会社と子会社の取引を打ち消す「連結修正仕訳」の積み重ねだ。M&Aの価値評価も、不正会計の調査も、最後は仕訳の1行1行にたどり着く。仕訳を読める人は、どんな会社のシステムの中身も読めるのである。
::

## 確認問題

::quiz
::problem 次の出来事を、簿記上の取引に当たるものと、当たらないものに分類しなさい。
::sort
@cats 簿記上の取引 | 簿記上の取引ではない
店舗の賃貸借契約を結んだ => 簿記上の取引ではない
倉庫の商品が盗まれた => 簿記上の取引
従業員を1名採用する契約を結んだ => 簿記上の取引ではない
借入金の利息を現金で支払った => 簿記上の取引
取引先に商品を注文した => 簿記上の取引ではない
建物が火災で焼失した => 簿記上の取引
::
::answer
**簿記上の取引**：倉庫の商品が盗まれた／借入金の利息を現金で支払った／建物が火災で焼失した
**簿記上の取引ではない**：店舗の賃貸借契約を結んだ／従業員を1名採用する契約を結んだ／取引先に商品を注文した
盗難と火災は、取引の意思はなくても資産が減少しているので簿記上の取引になる。契約や注文だけでは、財産の増減がない。

::summary
- 簿記上の取引とは、資産・負債・純資産・収益・費用を増減させる出来事。契約や注文だけでは取引にならないが、盗難や火災は取引になる
- 複式簿記は、1つの取引を2つの側面から記録する。左を借方、右を貸方という（漢字の意味は気にしない）
- 仕訳のルールは1つ：増えたらホームポジション側、減ったら反対側
- 取引は、借方の4要素と貸方の4要素の組み合わせ（取引の8要素）でできている
- 仕訳を勘定ごとに集計し直すことを転記という。相手科目が複数なら「諸口」
- 主要簿は仕訳帳と総勘定元帳。すべての勘定の借方合計と貸方合計は一致する（貸借平均の原理）
