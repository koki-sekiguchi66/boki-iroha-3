## 給料の「額面」と「手取り」

問いに入る前に、給料の仕組みを確認しよう。
会社が従業員に支払う給料には、**額面**（総支給額）と**手取り**がある。会社は、給料を支払うときに、従業員が納めるべき税金や社会保険料をあらかじめ差し引き（**天引き**）、残りを従業員の口座に振り込む。差し引いたお金は、会社が従業員から**預かり**、後日、従業員に代わって税務署や年金事務所などに納める。

::table ある社員の給料明細（月額）
| 項目 | 金額 | 説明 |
| 総支給額（額面） | 250,000 | 基本給・各種手当の合計 |
| －所得税（源泉徴収） | 5,800 | 会社が預かり、翌月10日までに税務署へ納付 |
| －社会保険料（本人負担分） | 37,500 | 健康保険・厚生年金・雇用保険。会社が預かり、納付する |
| －住民税（特別徴収） | 9,700 | 会社が預かり、翌月10日までに市区町村へ納付 |
|= 差引支給額（手取り） | 197,000 | 従業員の口座に振り込まれる金額 |
::

::note
※本章の税額・保険料は、学習用に単純化した金額。実際の金額は、給与額・扶養親族・年齢・地域・加入する保険の種類などによって異なる。
::

## 給料の仕訳 ― 天引きしたお金は「預り金」

給料の支払いでは、**総支給額**を**給料**（費用）として計上する。天引きした税金や社会保険料は、会社が一時的に預かっているお金なので、**預り金**（負債）で処理する。3級では、内容ごとに次の勘定科目を使う。

::table 給料の天引きで使う勘定科目
| 天引きするもの | 勘定科目 | 要素 |
| 源泉所得税 | 所得税預り金 | 負債 |
| 社会保険料（健康保険・厚生年金・雇用保険の本人負担分） | 社会保険料預り金 | 負債 |
| 住民税 | 住民税預り金（または預り金） | 負債 |
| 従業員から預かる積立金など（社員旅行の積立金など） | 従業員預り金（または預り金） | 負債 |
::

::journal 従業員10人の給料総額2,800,000円から、所得税80,000円と社員旅行の積立金50,000円（1人5,000円）を差し引き、残額を普通預金から振り込んだ
給料 2,800,000 | 所得税預り金 80,000
 | 従業員預り金 50,000
 | 普通預金 2,670,000
::

::journal 給料250,000円の支払いにあたり、所得税5,800円、社会保険料37,500円、住民税9,700円を差し引き、残額を普通預金から振り込んだ
給料 250,000 | 所得税預り金 5,800
 | 社会保険料預り金 37,500
 | 住民税預り金 9,700
 | 普通預金 197,000
::

::theory 「給料」は総額で計上する理由
給料勘定に記録するのは、手取りの197,000円ではなく、総支給額の250,000円だ。なぜなら、会社が従業員の労働の対価として負担した費用は250,000円だからである。
差し引いた53,000円も、本来は従業員に支払った給料の一部だ。それを従業員の代わりに国や自治体に納めるために、会社が一時的に預かっているにすぎない。だから「預り金」という**負債**になる。預かったお金は、期限までに必ず納めなければならない。
::

### 預り金の納付

預かった税金や保険料を納付したら、預り金を減らす。

::journal 翌月10日、預かっていた所得税5,800円と住民税9,700円を、現金で納付した
所得税預り金 5,800 | 現金 15,500
住民税預り金 9,700 |
::

## 法定福利費 ― 社会保険料は「会社も払う」

ここからが問いの核心だ。健康保険や厚生年金の保険料は、従業員だけが払うものではない。原則として、**会社と従業員が半分ずつ負担する**（労使折半）。雇用保険料も、会社のほうが多く負担する。さらに、労災保険料は全額が会社の負担だ。
会社が負担する社会保険料は、**法定福利費**（費用）で処理する。法律で負担が義務づけられた福利厚生の費用、という意味だ。

::journal 月末、社会保険料の本人負担分37,500円と、会社負担分37,500円を合わせて、普通預金から納付した
社会保険料預り金 37,500 | 普通預金 75,000
法定福利費 37,500 |
::

::point 納付のときに「法定福利費」が登場する
社会保険料の納付額75,000円のうち、37,500円は給料から預かっていた本人負担分（預り金の減少）、残りの37,500円は会社自身の負担（法定福利費の発生）だ。給料を払ったときではなく、**納付のとき**に会社負担分を費用として計上するのが、3級の基本パターンである。
::

## 答え合わせ ― 求人票の時給は「氷山の一角」

::solve 店長の電卓に入っていなかった、2つのコスト
店長の計算には、2つのコストが抜けていた。
1つ目は**深夜割増賃金**。労働基準法により、22時から翌朝5時までの深夜労働には、通常の賃金の**25%以上の割増賃金**を支払わなければならない。浅井のシフトは22時〜翌3時。5時間すべてが深夜労働だ。時給1,250円は、実際には**1,562円50銭**になる。
2つ目は、**社会保険料の会社負担**（法定福利費）。週25時間働く浅井は、社会保険の加入対象になる。会社は、浅井の給料の約15%に相当する保険料を、自ら負担しなければならない。

::table 浅井1人あたりの月の人件費（深夜5時間×月22日）
| 項目 | 計算 | 金額 |
| 基本の賃金 | 1,250円×110時間 | 137,500 |
| 深夜割増賃金（25%） | 1,250円×25%×110時間 | 34,375 |
|= 給料（総支給額） |  | 171,875 |
| 法定福利費（会社負担分・約15%と仮定） | 171,875円×15% | 25,781 |
|= 会社が負担する人件費の合計 |  | 197,656 |
::
会社の本当のコストは、時給から計算した金額の**約1.44倍**だった。しかも、これは最低限の金額だ。実際には、通勤手当、制服、採用広告費、研修中の人件費なども上乗せされる。
求人票の時給は、人件費という氷山の、海面から出ている部分にすぎない。給料・預り金・法定福利費を正しく仕訳できる人だけが、海面下の本当の大きさを知ることができる。
::

::note
※社会保険の加入要件（労働時間・賃金・企業規模・学生でないことなど）や保険料率は、法令や加入する制度によって異なる。ここでは、会社負担の合計を給料の約15%と仮定して試算している。
::

## 立替金 ― 本人が払うべきものを、会社が一時的に払う

従業員や取引先が本来負担すべき支払いを、会社が一時的に代わりに支払うことがある。このとき、後で返してもらう権利を**立替金**（資産）で処理する。従業員に対するものは、**従業員立替金**として区別することもある。

::example 制服代の立替え
(1) おかわり堂は、アルバイトの浅井が個人で購入を希望した防寒用インナー（私物）の代金8,000円を、制服の業者に現金で立て替えて支払った。
(2) 月末の給料171,875円の支払いにあたり、(1)の立替額8,000円、所得税3,500円、社会保険料25,800円を差し引き、残額を普通預金から振り込んだ。
::answer
::journal (1) 従業員が負担すべき支払いの立替え
従業員立替金 8,000 | 現金 8,000
::
::journal (2) 給料から立替額を差し引いて回収する
給料 171,875 | 従業員立替金 8,000
 | 所得税預り金 3,500
 | 社会保険料預り金 25,800
 | 普通預金 134,575
::
::
::

::point 「立替金」と「預り金」は表裏の関係
- **立替金**：本来は相手が払うべきお金を、会社が先に払った → 後で返してもらう権利（資産）
- **預り金**：本来は相手のお金を、会社が一時的に預かっている → 後で返す（納める）義務（負債）
どちらも「一時的な」貸し借りであり、いずれ必ず解消される。
::

::danger 「預かったお金」を使い込むな
給料から天引きした所得税や社会保険料は、会社のお金ではない。従業員から預かった、国や自治体に納めるべきお金だ。
資金繰りが苦しくなった会社は、ここに手を出しやすい。「今月は納付を少し待ってもらおう」。だが、源泉所得税を期限までに納めなければ、本来の税額に加えて不納付加算税や延滞税が課される。社会保険料の滞納が続けば、最終的には**財産の差し押さえ**に至る。しかも、天引きしておきながら納めないことは、従業員の信頼を根底から裏切る行為だ。
預り金は、帳簿の上で「これは預かったお金だ」と常に見えるようにするための勘定科目である。預り金の残高は、**手をつけてはいけないお金のリスト**なのだ。
::

## 深夜人件費のジレンマ ― 深夜営業は続けるべきか

最後に、おかわり堂が抱える経営課題を見ておこう。深夜帯は、割増賃金で人件費が25%以上も高くなる。一方で、客数は昼のピークに比べて少ない。それでも、京都の学生街の深夜には、根強い需要がある。

::kpi 百万遍店・深夜帯（22時〜翌3時）の1日あたりの数字
深夜帯の売上 | 60,000円 | 客数120人×客単価500円
食材費（原価率35%） | 21,000円 | 売上に比例して増減
深夜スタッフ2名の人件費 | 17,969円 | 割増・法定福利費込み
深夜帯の光熱費の増加分 | 3,000円 | 営業を続けることで増える分
::

::cfo 深夜営業を続けるか、やめるか
社長は言う。「深夜は人件費が高すぎる。全店、深夜1時で閉店しよう」。店長たちは「深夜の常連さんが離れてしまう」と反対している。上の数字をもとに、あなたなら、百万遍店の深夜営業をどう判断するか？
::answer
判断の軸は、**深夜営業を続けることで増える収益と、増える費用だけを比べる**ことだ。
深夜帯の売上60,000円から、深夜営業をすることで発生する費用（食材費21,000円、深夜スタッフの人件費17,969円、光熱費の増加分3,000円）を引くと、1日あたり**18,031円**が残る。月30日なら約54万円だ。
ここで、店舗の家賃や、厨房設備の減価償却費を深夜帯に割り振って「深夜は赤字だ」と考えてはいけない。家賃は、深夜に店を閉めても1円も減らないからだ。深夜営業の追加的な収支がプラスである限り、深夜営業は**店全体の利益を押し上げている**。
ただし、条件は2つある。
- **売上が損益の分岐点を下回っていないか**：深夜の売上が1日35,000円まで落ちると、残りはわずか約1,800円になる。店舗ごとに深夜帯の売上を毎月追跡し、分岐点を割り込む店は閉店時間の繰り上げを検討する。
- **安全と人の持続可能性**：利益が出ても、深夜の1人勤務（ワンオペ）は防犯面でも労務面でも大きなリスクを抱える。かつて外食業界では、深夜の1人勤務が社会問題となり、多くの店舗が深夜営業の休止に追い込まれた。2名体制の維持は、利益計算の前提条件だ。
全店一律ではなく、**店舗ごとに、数字で決める**。それがこの問いへの答えだ。
::
::

::exam 給料・預り金・立替金の急所
- 給料は**総支給額**で計上する。天引き額は所得税預り金・社会保険料預り金など（負債）。差額が手取りの支払額。
- 社会保険料の納付時：本人負担分は社会保険料預り金の減少、会社負担分は**法定福利費**（費用）。
- 立替金（従業員立替金）は資産。給料から差し引いて回収する仕訳がよく出る。
- 社員旅行の積立金など、従業員から預かったお金は「従業員預り金」（負債）。
- 「預り金」「仮受金」「前受金」を混同しない。天引き＝預り金、内容不明の入金＝仮受金、商品代金の前受け＝前受金。
- 所得税の納付期限（原則として翌月10日）などの実務知識は問われないが、「預かったものを納めると預り金が減る」という流れは確実に。
::

::next 人件費の「未来の支払い」 ― 引当金の世界へ
2級では、来期に支払う賞与のうち当期に属する分を見積もって計上する**賞与引当金**や、将来の退職金に備える**退職給付引当金**を学ぶ。1級では、数十年先の退職金支払いを現在価値に割り引いて計算する**退職給付会計**という、会計の中でも特に高度な論点に挑む。
本章の判断問題で使った「深夜営業で増える収益と費用だけを比べる」という考え方は、2級の工業簿記で学ぶ**CVP分析（損益分岐点分析）**や**業務的意思決定**の入り口だ。どの費用が売上に比例し（変動費）、どの費用が売上に関係なく発生するか（固定費）を見分ける力は、経営判断の基本となる思考法である。
::
