::mystery 店長の計算より、6万円近く高い人件費
百万遍の交差点。ひよりは、この角を曲がるたびに少しだけ足が重くなる。父のまんぷく食堂1号店があった場所は、いまはコインランドリーになっている。その斜め向かいで、おかわり堂・百万遍店の看板が深夜まで光っている。
百万遍店の深夜帯は、22時から翌3時まで。試験期間の学生と、バイト帰りの若者でにぎわう時間帯だ。
その深夜帯が、回らなくなっていた。4年生の主力が2人、就職活動でシフトを減らしたのだ。店長の岡崎は、ひよりが学生時代に出町柳店で働いていたころの店長だ。岡崎は、求人サイトに急いで募集を出した。「時給1,200円」。2025年11月に上がった京都府の最低賃金1,122円を、少し上回る金額だ。
応募してきたのは、28歳のフリーター、浅井だった。週5日、1日5時間、22時から3時まで。面接のあと、岡崎は電卓をたたいた。
岡崎：「1,200円×5時間×月22日で、月**13万2,000円**。これなら深夜帯の売上で十分まかなえる」
ところが、採用の稟議を見た本部の経理部が弾き出した「浅井1人あたりの月の人件費」は、約**19万1,000円**だった。店長の計算より、6万円近くも高い。
月次巡回の帰りに店へ寄ったひよりに、岡崎は稟議書のコピーを突き出した。
岡崎：「大川、本部の計算、おかしいやろ。6万も上乗せして、深夜帯は赤字や、採用は見送れ、やて。浅井くん、ええ子やねん。来週から来てもらうつもりやったのに」
岡崎：「会計事務所の人間やろ。どっちが正しいか見てくれ」
経理部の計算ミスか？　いや、経理部は正しかった。岡崎の計算には、何が抜けていたのか？
::

## 給料の「額面」と「手取り」

ひよりは、カウンターの端に稟議書を広げた。それから、自分の財布の中を探った。学生時代の給料明細が、1枚だけ残っていた。
ひより：「岡崎さん、私が出町柳店にいたころの明細です。覚えてますか。時給かける時間より、振り込まれる額がいつも少し少なかった」
岡崎：「税金やら何やら、引かれとるからな」
ひより：「その『何やら』が、今日の答えに関係あるんです」
会社が払う給料には、**額面**（総支給額）と**手取り**がある。会社は給料を払うとき、従業員が納めるべき税金や社会保険料を先に差し引いて（**天引き**）、残りを振り込む。差し引いたお金は、会社が従業員から預かって、あとで代わりに税務署や年金事務所に納める。

::table ある社員の給料明細（月額）
| 項目 | 金額 | 説明 |
| 総支給額（額面） | 250,000 | 基本給・各種手当の合計 |
| －所得税（源泉徴収） | 5,800 | 会社が預かり、翌月10日までに税務署へ納付 |
| －社会保険料（本人負担分） | 37,500 | 健康保険・厚生年金・雇用保険。会社が預かり、納付する |
| －住民税（特別徴収） | 9,700 | 会社が預かり、翌月10日までに市区町村へ納付 |
|= 差引支給額（手取り） | 197,000 | 従業員の口座に振り込まれる金額 |
::

::note
※本章の税額・保険料は、学習用に単純化した金額。実際の金額は、給与額・扶養親族・年齢・地域・加入する保険の種類などによって異なる。
::

## 給料の仕訳 ― 天引きしたお金は「預り金」

ひよりは、稟議書に添えられた浅井の給与計算の見込みを、岡崎の前に広げた。
ひより：「岡崎さん、浅井さんに振り込む金額と、会社が費用にする金額は、同じだと思いますか」
岡崎：「同じやろ。払うた分が費用や」
ひより：「実は、違うんです。会社が費用にするのは、手取りじゃなくて額面のほうです。振り込む前に引いた分は、会社が浅井さんから預かっているだけ。預かったお金だから、**預り金**という負債になります」
岡崎：「預かっとる金が、借金なんか」
ひより：「いつか納めなきゃいけないお金ですから」

::table 給料の天引きで使う勘定科目
| 天引きするもの | 勘定科目 | 要素 |
| 源泉所得税 | 所得税預り金 | 負債 |
| 社会保険料（健康保険・厚生年金・雇用保険の本人負担分） | 社会保険料預り金 | 負債 |
| 住民税 | 住民税預り金（または預り金） | 負債 |
| 従業員から預かる積立金など（社員旅行の積立金など） | 従業員預り金（または預り金） | 負債 |
::

::journal 従業員10人の給料総額2,800,000円から、所得税80,000円と社員旅行の積立金50,000円（1人5,000円）を差し引き、残額を普通預金から振り込んだ
給料 2,800,000 | 所得税預り金 80,000
 | 従業員預り金 50,000
 | 普通預金 2,670,000
::

::journal 給料250,000円の支払いにあたり、所得税5,800円、社会保険料37,500円、住民税9,700円を差し引き、残額を普通預金から振り込んだ
給料 250,000 | 所得税預り金 5,800
 | 社会保険料預り金 37,500
 | 住民税預り金 9,700
 | 普通預金 197,000
::

::theory 「給料」は総額で計上する理由
給料勘定に記録するのは、手取りの197,000円ではなく、総支給額の250,000円だ。なぜなら、会社が従業員の労働の対価として負担した費用は250,000円だからである。
差し引いた53,000円も、本来は従業員に支払った給料の一部だ。それを従業員の代わりに国や自治体に納めるために、会社が一時的に預かっているにすぎない。だから「預り金」という**負債**になる。預かったお金は、期限までに必ず納めなければならない。
::

### 預り金の納付

岡崎：「預かった、いうことは、どこかへ持っていくんやな」
ひより：「はい。税金は税務署へ、保険料は年金事務所へ、会社がまとめて納めます」
岡崎：「うちの店の金やないのに、いったん店の口座を通るわけか」
ひよりはうなずいた。預かったお金を納めたら、預り金を減らす。

::journal 翌月10日、預かっていた所得税5,800円と住民税9,700円を、現金で納付した
所得税預り金 5,800 | 現金 15,500
住民税預り金 9,700 |
::

## 法定福利費 ― 社会保険料は「会社も払う」

ひよりは、稟議書の真ん中あたりにある行を指さした。「法定福利費」。岡崎の電卓には、この行がなかった。
岡崎：「なんや、それ」
ひより：「社会保険料の、会社の分です。健康保険や厚生年金の保険料は、浅井さんだけが払うんじゃありません。原則として、会社と浅井さんで半分ずつ払うんです」
岡崎：「半分ずつ？」
ひより：「浅井さんの給料から37,500円預かったら、会社も自分のお金から37,500円を出して、一緒に納めます。雇用保険も、会社のほうが多く払います。労災保険は全額が会社です」
岡崎は、腕を組んだまま黙った。
ひより：「会社が払うこの保険料は、**法定福利費**という費用になります。法律で払うことが決まっている、福利厚生のお金です」

::journal 月末、社会保険料の本人負担分37,500円と、会社負担分37,500円を合わせて、普通預金から納付した
社会保険料預り金 37,500 | 普通預金 75,000
法定福利費 37,500 |
::

::point 納付のときに「法定福利費」が登場する
社会保険料の納付額75,000円のうち、37,500円は給料から預かっていた本人負担分（預り金の減少）、残りの37,500円は会社自身の負担（法定福利費の発生）だ。給料を払ったときではなく、**納付のとき**に会社負担分を費用として計上するのが、3級の基本パターンである。
::

## 答え合わせ ― 求人票の時給は「氷山の一角」

ひより：「それと、もう1つ。浅井さんのシフト、22時から3時までですよね」
岡崎：「深夜帯の募集やからな」
ひより：「夜10時から朝5時までは、深夜の割増賃金がつきます。25%以上。浅井さんの5時間は、全部が深夜です」
岡崎の手が止まった。
岡崎：「……あ」

::solve 店長の電卓に入っていなかった、2つのコスト
岡崎の計算には、2つのコストが抜けていた。
1つ目は**深夜割増賃金**。労働基準法により、22時から翌朝5時までの深夜労働には、通常の賃金の**25%以上の割増賃金**を支払わなければならない。浅井のシフトは22時〜翌3時。5時間すべてが深夜労働だ。時給1,200円は、実際には**1,500円**になる。
2つ目は、**社会保険料の会社負担**（法定福利費）。週25時間働く浅井は、学生ではなく、会社の規模の条件も満たすので、社会保険の加入対象になる。健康保険と厚生年金の保険料は会社と本人で半分ずつ。さらに雇用保険や労災保険などの会社負担もある。合わせると、浅井の給料の**約16%**を、会社が自ら負担しなければならない。

::table 浅井1人あたりの月の人件費（深夜5時間×月22日）
| 項目 | 計算 | 金額 |
| 基本の賃金 | 1,200円×110時間 | 132,000 |
| 深夜割増賃金（25%） | 1,200円×25%×110時間 | 33,000 |
|= 給料（総支給額） |  | 165,000 |
| 法定福利費（会社負担分・約16%） | 165,000円×16% | 26,400 |
|= 会社が負担する人件費の合計 |  | 191,400 |
::
会社の本当のコストは、時給から計算した金額の**約1.45倍**だった。しかも、これは最低限の金額だ。実際には、通勤手当、制服、採用広告費、研修中の人件費なども上乗せされる。
求人票の時給は、人件費という氷山の、海面から出ている部分にすぎない。給料・預り金・法定福利費を正しく仕訳できる人だけが、海面下の本当の大きさを知ることができる。
::

ひよりの説明を聞き終えた岡崎は、しばらく天井を見ていた。
岡崎：「俺が店長になってからずっと、時給×時間で計算しとった。深夜の人件費、ずっと安く見積もってたんやな」
ひより：「本部の数字のほうが、正しかったんです」
岡崎：「ほな、浅井くんは、雇えへんのか」
ひより：「それは、計算してから決めることです。深夜帯で本当にいくら稼いでいるのか。本部と一緒に、数字を並べてみませんか」
岡崎は、少しだけ笑った。
岡崎：「お前に計算を教わる日が来るとはな」

::note
※会社負担の約16%は、2026年度の料率をもとにした概算。健康保険（都道府県ごとに異なり約10%。その半分）、厚生年金（18.3%の半分）、子ども・子育て支援金（0.23%の半分、2026年4月分から）、子ども・子育て拠出金（0.36%、会社のみ）、雇用保険（会社負担0.85%）、労災保険（飲食店0.3%、会社のみ）を合わせた。実際の保険料は「標準報酬月額」にもとづいて計算し、40歳以上は介護保険料も加わる。短時間で働く人の社会保険の加入要件（週20時間以上、学生でないこと、会社の規模など）は法令で定められている。
::

::real 時給の「下限」と、学生アルバイトの「壁」が動いた
おかわり堂のような学生街の飲食店にとって、ここ数年の制度の変化は大きい。
- **最低賃金**：2025年度の全国加重平均は1,121円で、過去最大の66円の引き上げ。京都府は2025年11月21日から**1,122円**。深夜帯は25%増しなので、1,403円未満では雇えない。
- **所得税の「壁」**：2025年の税制改正で、所得税がかからない年収の目安が103万円から**160万円**に引き上げられた。19歳以上23歳未満の子が働く場合、年収150万円までなら、親は新しい**特定親族特別控除**を満額で受けられる。
- **社会保険料**：2026年4月分からは、健康保険料に「子ども・子育て支援金」が上乗せされた。
昼間の大学に通う学生は社会保険や雇用保険の加入対象から外れるので、同じ時給・同じ時間でも、会社が負担する法定福利費は浅井よりずっと小さい。人件費を「時給×時間」だけで見積もる店は、ますます読み違える時代になった。
::note
出典：[京都労働局（京都府最低賃金）](https://jsite.mhlw.go.jp/kyoto-roudoukyoku/hourei_seido_tetsuzuki/tingin_kanairoudou.html)、[秋田魁新報（共同通信、2025年9月5日）](https://www.sakigake.jp/news/article/20250905CO0200/)、[国税庁「令和7年度税制改正による所得税の基礎控除の見直し等について」](https://www.nta.go.jp/users/gensen/2025kiso/index.htm)、[協会けんぽ「令和8年度の保険料率」](https://www.kyoukaikenpo.or.jp/g7/cat330/sb3130/r08/)

## 立替金 ― 本人が払うべきものを、会社が一時的に払う

結局、浅井の採用は決まった。最初の週、浅井は岡崎に相談した。
浅井：「店長、深夜の仕込み、冷えますね。制服の下に着るインナー、制服屋さんでまとめて買えませんか」
岡崎：「私物やけど、業者への支払いは店でまとめてしとくわ。代金は給料から引かせてもらうで」
岡崎から電話でその話を聞いたひよりは、すぐに勘定科目を1つ思い浮かべた。
ひより：「それは**立替金**です。本当は浅井さんが払うお金を、店が先に払っておく。あとで返してもらう権利だから、資産です」
岡崎：「さっきの預り金の、逆やな」
ひより：「はい。預り金は、人のお金を預かっている。立替金は、人の分を先に払ってあげている」

::example 制服代の立替え
(1) おかわり堂は、アルバイトの浅井が個人で購入を希望した防寒用インナー（私物）の代金8,000円を、制服の業者に現金で立て替えて支払った。
(2) 月末の給料165,000円の支払いにあたり、(1)の立替額8,000円、所得税3,000円、社会保険料（本人負担分）24,400円を差し引き、残額を普通預金から振り込んだ。
::answer
::journal (1) 従業員が負担すべき支払いの立替え
従業員立替金 8,000 | 現金 8,000
::
::journal (2) 給料から立替額を差し引いて回収する
給料 165,000 | 従業員立替金 8,000
 | 所得税預り金 3,000
 | 社会保険料預り金 24,400
 | 普通預金 129,600
::
::trap
給料は、振り込んだ手取りの129,600円ではなく、**総額の165,000円**で計上する。
貸方の科目を取り違えないこと。従業員立替金は資産の減少（貸したお金の回収）、預り金は負債の増加（あとで代わりに納めるお金）だ。
::
::
::

::point 「立替金」と「預り金」は表裏の関係
- **立替金**：本来は相手が払うべきお金を、会社が先に払った → 後で返してもらう権利（資産）
- **預り金**：本来は相手のお金を、会社が一時的に預かっている → 後で返す（納める）義務（負債）
どちらも「一時的な」貸し借りであり、いずれ必ず解消される。
::

::danger 「預かったお金」を使い込むな
給料から天引きした所得税や社会保険料は、会社のお金ではない。資金繰りが苦しい会社ほど、「今月は納付を少し待ってもらおう」と手を出しやすい。だが期限までに納めなければ加算税や延滞税が課され、滞納が続けば財産の差し押さえに至る。預り金の残高は、**手をつけてはいけないお金のリスト**なのだ。
::

::exam 給料・預り金・立替金の急所
- 給料は**総支給額**で計上する。天引き額は所得税預り金・社会保険料預り金など（負債）。差額が手取りの支払額。
- 社会保険料の納付時：本人負担分は社会保険料預り金の減少、会社負担分は**法定福利費**（費用）。
- 立替金（従業員立替金）は資産。給料から差し引いて回収する仕訳がよく出る。
- 社員旅行の積立金など、従業員から預かったお金は「従業員預り金」（負債）。
- 「預り金」「仮受金」「前受金」を混同しない。天引き＝預り金、内容不明の入金＝仮受金、商品代金の前受け＝前受金。
- 所得税の納付期限（原則として翌月10日）などの実務知識は問われないが、「預かったものを納めると預り金が減る」という流れは確実に。
::

::next 人件費の「未来の支払い」 ― 引当金の世界へ
2級では、来期に支払う賞与のうち当期に属する分を計上する**賞与引当金**や、将来の退職金に備える**退職給付引当金**を学ぶ。人件費を「時給×時間」ではなく、会社が本当に負担する総額で見る力は、2級の工業簿記や経営分析の土台にもなる。
::

::summary
- 給料は総支給額で「給料」（費用）に計上し、天引きした税金・保険料は預り金（負債）で処理する
- 預り金は従業員から預かったお金。納付したら預り金を減らす。手をつけてはいけないお金である
- 社会保険料の会社負担分は「法定福利費」（費用）。納付時に計上するのが基本
- 従業員などが負担すべき支払いを会社が立て替えたら立替金（資産）。給料から差し引いて回収することが多い
- 時給だけでは人件費は語れない。深夜割増（25%以上）と法定福利費を含めた「本当のコスト」で考える
- 深夜営業のような判断は、それによって増える収益と費用だけを比べる
::
