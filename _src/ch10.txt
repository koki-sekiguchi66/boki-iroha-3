経理部の計算ミスか？　いや、経理部は正しかった。岡崎の計算には、何が抜けていたのか？

## 給料の「額面」と「手取り」

ひよりは、自分の学生時代の給料明細を思い出した。時給と働いた時間を掛けた金額より、振り込まれる金額はいつも少し少なかった。まずは、その「差」の正体から確認しよう。
会社が従業員に支払う給料には、**額面**（総支給額）と**手取り**がある。会社は、給料を支払うときに、従業員が納めるべき税金や社会保険料をあらかじめ差し引き（**天引き**）、残りを従業員の口座に振り込む。差し引いたお金は、会社が従業員から**預かり**、後日、従業員に代わって税務署や年金事務所などに納める。

::table ある社員の給料明細（月額）
| 項目 | 金額 | 説明 |
| 総支給額（額面） | 250,000 | 基本給・各種手当の合計 |
| －所得税（源泉徴収） | 5,800 | 会社が預かり、翌月10日までに税務署へ納付 |
| －社会保険料（本人負担分） | 37,500 | 健康保険・厚生年金・雇用保険。会社が預かり、納付する |
| －住民税（特別徴収） | 9,700 | 会社が預かり、翌月10日までに市区町村へ納付 |
|= 差引支給額（手取り） | 197,000 | 従業員の口座に振り込まれる金額 |
::

::note
※本章の税額・保険料は、学習用に単純化した金額。実際の金額は、給与額・扶養親族・年齢・地域・加入する保険の種類などによって異なる。
::

## 給料の仕訳 ― 天引きしたお金は「預り金」

給料の支払いでは、**総支給額**を**給料**（費用）として計上する。天引きした税金や社会保険料は、会社が一時的に預かっているお金なので、**預り金**（負債）で処理する。3級では、内容ごとに次の勘定科目を使う。

::table 給料の天引きで使う勘定科目
| 天引きするもの | 勘定科目 | 要素 |
| 源泉所得税 | 所得税預り金 | 負債 |
| 社会保険料（健康保険・厚生年金・雇用保険の本人負担分） | 社会保険料預り金 | 負債 |
| 住民税 | 住民税預り金（または預り金） | 負債 |
| 従業員から預かる積立金など（社員旅行の積立金など） | 従業員預り金（または預り金） | 負債 |
::

::journal 従業員10人の給料総額2,800,000円から、所得税80,000円と社員旅行の積立金50,000円（1人5,000円）を差し引き、残額を普通預金から振り込んだ
給料 2,800,000 | 所得税預り金 80,000
 | 従業員預り金 50,000
 | 普通預金 2,670,000
::

::journal 給料250,000円の支払いにあたり、所得税5,800円、社会保険料37,500円、住民税9,700円を差し引き、残額を普通預金から振り込んだ
給料 250,000 | 所得税預り金 5,800
 | 社会保険料預り金 37,500
 | 住民税預り金 9,700
 | 普通預金 197,000
::

::theory 「給料」は総額で計上する理由
給料勘定に記録するのは、手取りの197,000円ではなく、総支給額の250,000円だ。なぜなら、会社が従業員の労働の対価として負担した費用は250,000円だからである。
差し引いた53,000円も、本来は従業員に支払った給料の一部だ。それを従業員の代わりに国や自治体に納めるために、会社が一時的に預かっているにすぎない。だから「預り金」という**負債**になる。預かったお金は、期限までに必ず納めなければならない。
::

### 預り金の納付

預かった税金や保険料を納付したら、預り金を減らす。

::journal 翌月10日、預かっていた所得税5,800円と住民税9,700円を、現金で納付した
所得税預り金 5,800 | 現金 15,500
住民税預り金 9,700 |
::

## 法定福利費 ― 社会保険料は「会社も払う」

ここからが問いの核心だ。ひよりは、稟議書の「法定福利費」という行を指さした。岡崎の電卓には、この行がなかった。健康保険や厚生年金の保険料は、従業員だけが払うものではない。原則として、**会社と従業員が半分ずつ負担する**（労使折半）。雇用保険料も、会社のほうが多く負担する。さらに、労災保険料は全額が会社の負担だ。
会社が負担する社会保険料は、**法定福利費**（費用）で処理する。法律で負担が義務づけられた福利厚生の費用、という意味だ。

::journal 月末、社会保険料の本人負担分37,500円と、会社負担分37,500円を合わせて、普通預金から納付した
社会保険料預り金 37,500 | 普通預金 75,000
法定福利費 37,500 |
::

::point 納付のときに「法定福利費」が登場する
社会保険料の納付額75,000円のうち、37,500円は給料から預かっていた本人負担分（預り金の減少）、残りの37,500円は会社自身の負担（法定福利費の発生）だ。給料を払ったときではなく、**納付のとき**に会社負担分を費用として計上するのが、3級の基本パターンである。
::

## 答え合わせ ― 求人票の時給は「氷山の一角」

::solve 店長の電卓に入っていなかった、2つのコスト
岡崎の計算には、2つのコストが抜けていた。
1つ目は**深夜割増賃金**。労働基準法により、22時から翌朝5時までの深夜労働には、通常の賃金の**25%以上の割増賃金**を支払わなければならない。浅井のシフトは22時〜翌3時。5時間すべてが深夜労働だ。時給1,200円は、実際には**1,500円**になる。
2つ目は、**社会保険料の会社負担**（法定福利費）。週25時間働く浅井は、学生ではなく、会社の規模の条件も満たすので、社会保険の加入対象になる。健康保険と厚生年金の保険料は会社と本人で半分ずつ。さらに雇用保険や労災保険などの会社負担もある。合わせると、浅井の給料の**約16%**を、会社が自ら負担しなければならない。

::table 浅井1人あたりの月の人件費（深夜5時間×月22日）
| 項目 | 計算 | 金額 |
| 基本の賃金 | 1,200円×110時間 | 132,000 |
| 深夜割増賃金（25%） | 1,200円×25%×110時間 | 33,000 |
|= 給料（総支給額） |  | 165,000 |
| 法定福利費（会社負担分・約16%） | 165,000円×16% | 26,400 |
|= 会社が負担する人件費の合計 |  | 191,400 |
::
会社の本当のコストは、時給から計算した金額の**約1.45倍**だった。しかも、これは最低限の金額だ。実際には、通勤手当、制服、採用広告費、研修中の人件費なども上乗せされる。
求人票の時給は、人件費という氷山の、海面から出ている部分にすぎない。給料・預り金・法定福利費を正しく仕訳できる人だけが、海面下の本当の大きさを知ることができる。
::

ひよりの説明を聞き終えた岡崎は、しばらく天井を見ていた。「俺が店長になってからずっと、時給×時間で計算しとった。深夜の人件費、ずっと安く見積もってたんやな」

::note
※会社負担の約16%は、2026年度の料率をもとにした概算。健康保険（都道府県ごとに異なり約10%。その半分）、厚生年金（18.3%の半分）、子ども・子育て支援金（0.23%の半分、2026年4月分から）、子ども・子育て拠出金（0.36%、会社のみ）、雇用保険（会社負担0.85%）、労災保険（飲食店0.3%、会社のみ）を合わせた。実際の保険料は「標準報酬月額」にもとづいて計算し、40歳以上は介護保険料も加わる。短時間で働く人の社会保険の加入要件（週20時間以上、学生でないこと、会社の規模など）は法令で定められている。
::

::real 時給の「下限」と、学生アルバイトの「壁」が動いた
おかわり堂のような学生街の飲食店にとって、ここ数年の制度の変化は大きい。
- **最低賃金**：2025年度の全国加重平均は1,121円で、前年度より66円上がり、過去最大の引き上げになった。京都府は2025年11月21日から**1,122円**。深夜帯は25%増しなので、1,403円未満では雇えない。
- **所得税の「壁」**：2025年の税制改正で、給与所得者に所得税がかからない年収の目安（課税最低限）が、103万円から**160万円**に引き上げられた。さらに、19歳以上23歳未満の子が働く場合、年収150万円までなら、親は新しくできた**特定親族特別控除**（最高63万円）を満額で受けられる。
- **社会保険料**：2026年4月分からは、健康保険料に「子ども・子育て支援金」（0.23%を会社と本人で折半）が上乗せされた。一方、雇用保険料率は2026年度、会社負担が0.85%、本人負担が0.5%へと引き下げられた。
学生がシフトを増やしやすくなった一方で、時給と保険料の負担は上がり続けている。人件費を「時給×時間」だけで見積もる店は、ますます読み違える時代になった。

**この章の道具で読む ― 同じ時給1,200円でも、法定福利費が違う**
浅井と同じ深夜5時間×月22日を、昼間の大学に通う学生アルバイトが働いた場合と比べてみよう。学生は、短時間で働く人の社会保険の加入対象から外れ、昼間の学生は原則として雇用保険にも入らない。会社が負担するのは、ほぼ労災保険料（飲食店は0.3%）だけになる。

::table 深夜5時間×月22日の、会社の月の人件費（単位：円）
| 項目 | 浅井（週25時間・社会保険に加入） | 昼間の学生 |
| 給料（深夜割増を含む） | 165,000 | 165,000 |
| 法定福利費（会社負担） | 26,400 | 495 |
|= 合計 | 191,400 | 165,495 |
::
浅井の分の法定福利費は、本人から預かった保険料と一緒に、翌月末に納める。仕訳にすると、預り金と法定福利費が並んで出ていく形になる（労働保険の分も含めて単純化）。

::journal 翌月末、浅井の社会保険料を納付した（本人負担分24,400円は給料から預かっていた）
社会保険料預り金 24,400 | 普通預金 50,800
法定福利費 26,400 |
::

学生の年収の壁が150万円に上がったことで、学生は年に約1,000時間（150万円÷時給1,500円）まで、親の控除を気にせず深夜に働けるようになった。同じ深夜帯を回すなら、会社の負担は学生のほうが月2万6,000円ほど軽い。ただし、学生は試験や就職活動でシフトが抜けやすい。4年生が抜けた百万遍店の深夜帯に、浅井のような人が必要だったのも事実だ。人件費の数字は、誰を雇うかの判断と、切り離せない。
::note
出典：[京都労働局（京都府最低賃金）](https://jsite.mhlw.go.jp/kyoto-roudoukyoku/hourei_seido_tetsuzuki/tingin_kanairoudou.html)、[秋田魁新報（共同通信、2025年9月5日）](https://www.sakigake.jp/news/article/20250905CO0200/)、[国税庁「令和7年度税制改正による所得税の基礎控除の見直し等について」](https://www.nta.go.jp/users/gensen/2025kiso/index.htm)、[財務省「令和7年度税制改正」](https://www.mof.go.jp/tax_policy/publication/brochure/zeisei2025/01.html)、[協会けんぽ「令和8年度の保険料率」](https://www.kyoukaikenpo.or.jp/g7/cat330/sb3130/r08/)、[山形労働局（令和8年度の雇用保険料率）](https://jsite.mhlw.go.jp/yamagata-roudoukyoku/koyouhoken-20260316.html)

## 立替金 ― 本人が払うべきものを、会社が一時的に払う

従業員や取引先が本来負担すべき支払いを、会社が一時的に代わりに支払うことがある。このとき、後で返してもらう権利を**立替金**（資産）で処理する。従業員に対するものは、**従業員立替金**として区別することもある。

::example 制服代の立替え
(1) おかわり堂は、アルバイトの浅井が個人で購入を希望した防寒用インナー（私物）の代金8,000円を、制服の業者に現金で立て替えて支払った。
(2) 月末の給料165,000円の支払いにあたり、(1)の立替額8,000円、所得税3,000円、社会保険料（本人負担分）24,400円を差し引き、残額を普通預金から振り込んだ。
::answer
::journal (1) 従業員が負担すべき支払いの立替え
従業員立替金 8,000 | 現金 8,000
::
::journal (2) 給料から立替額を差し引いて回収する
給料 165,000 | 従業員立替金 8,000
 | 所得税預り金 3,000
 | 社会保険料預り金 24,400
 | 普通預金 129,600
::
::
::

::point 「立替金」と「預り金」は表裏の関係
- **立替金**：本来は相手が払うべきお金を、会社が先に払った → 後で返してもらう権利（資産）
- **預り金**：本来は相手のお金を、会社が一時的に預かっている → 後で返す（納める）義務（負債）
どちらも「一時的な」貸し借りであり、いずれ必ず解消される。
::

::danger 「預かったお金」を使い込むな
給料から天引きした所得税や社会保険料は、会社のお金ではない。従業員から預かった、国や自治体に納めるべきお金だ。
資金繰りが苦しくなった会社は、ここに手を出しやすい。「今月は納付を少し待ってもらおう」。だが、源泉所得税を期限までに納めなければ、本来の税額に加えて不納付加算税や延滞税が課される。社会保険料の滞納が続けば、最終的には**財産の差し押さえ**に至る。しかも、天引きしておきながら納めないことは、従業員の信頼を根底から裏切る行為だ。
預り金は、帳簿の上で「これは預かったお金だ」と常に見えるようにするための勘定科目である。預り金の残高は、**手をつけてはいけないお金のリスト**なのだ。
::

## 深夜人件費のジレンマ ― 深夜営業は続けるべきか

岡崎の一件は、本部の経営会議にまで届いた。社長の大森が「そもそも深夜営業は割に合うのか」と言い出したのだ。佐伯は、ひよりに深夜帯の数字の整理を頼んだ。深夜帯は、割増賃金で人件費が25%以上も高くなる。一方で、客数は昼のピークに比べて少ない。それでも、京都の学生街の深夜には、根強い需要がある。

::real 深夜の「1人勤務」が、1,000店以上の深夜営業を止めた
2014年、牛丼チェーンのすき家で、深夜に従業員1人だけで店を回す「ワンオペ」が社会問題になった。運営会社のゼンショーホールディングスが設けた第三者委員会は、7月末に公表した報告書で、1人勤務の過酷さを指摘し、「深夜時間帯における一人勤務体制の解消を早急に実現すべき」と提言した。
同社は8月、深夜に複数の従業員を配置できない店舗の深夜営業を休止する方針を決める。10月1日から、全店の約6割にあたる**1,167店**で、主に午前0時から5時までの営業が止まった。人を確保できないまま深夜営業を続けることが、もはや許されなくなった瞬間だった。
::note
出典：[東洋経済オンライン「すき家､『ワンオペ解消』の目算が外れたワケ」（2014年10月10日）](https://toyokeizai.net/articles/-/49938)
::
::

本部では、深夜帯（22時〜翌3時）を営業している店舗のうち、3店の1日あたりの数字をまとめた。深夜スタッフは各店2名。1人あたりの人件費は、時給1,500円に会社負担の保険料約16%を加えて1時間1,740円。2名×5時間で17,400円になる。

::table 深夜帯（22時〜翌3時）の1日あたりの数字（単位：円）
| 項目 | 百万遍店 | 今出川店 | 衣笠店 |
| 深夜帯の売上（客単価500円） | 60,000 | 45,000 | 28,000 |
| 食材費（売上の35%） | 21,000 | 15,750 | 9,800 |
| 深夜スタッフ2名の人件費 | 17,400 | 17,400 | 17,400 |

::cfo 深夜営業を続けるか、やめるか ― 「割り振られた費用」に惑わされない
社長の大森は、本部の経営企画が作った「時間帯別の損益表」を会議に持ち込んだ。「見てみろ。深夜帯は3店とも赤字だ。全店、22時で閉めよう」
::table 経営企画の資料：深夜帯（22時〜翌3時）の1日あたりの損益（単位：円）
| 項目 | 百万遍店 | 今出川店 | 衣笠店 |
| 売上 | 60,000 | 45,000 | 28,000 |
| 食材費（売上の35%） | △21,000 | △15,750 | △9,800 |
| 深夜スタッフ2名の人件費 | △17,400 | △17,400 | △17,400 |
| 深夜帯の光熱費の増加分 | △3,000 | △3,000 | △3,000 |
| 家賃・厨房設備の減価償却費（営業時間の比率で深夜帯に割り振った分） | △25,000 | △25,000 | △25,000 |
|= 深夜帯の損益 | △6,400 | △16,150 | △27,200 |
::
佐伯は、ひよりに検討を頼んだ。2人で調べると、次のことが分かった。
- 家賃と厨房設備の減価償却費は、深夜に閉めても**1円も減らない**
- 営業時間を短くした他のチェーンの例では、深夜の客の**約3割**が、閉店前の夕方〜22時に来店時間を移した。夕方の時間帯は今のスタッフで回せるので、移ってきた客の分は、売上の65%（食材費を引いた残り）がそのまま利益になる
- 深夜の2名体制は、防犯と安全のための前提条件だ（下の「実際にあった話」）
各店について、**深夜営業をやめた場合に、店全体の1日の利益がいくら増えるか（減るか）**を計算してから、方針を選んでほしい。
::choice A. 資料のとおり、深夜帯は3店とも赤字なので、全店22時で閉める
**× 割り振られた費用に惑わされ、稼いでいる店の利益まで捨てる。**家賃と減価償却費は、閉めても減らない。それを引く前の数字で見れば、深夜営業で残る金額は百万遍店18,600円、今出川店8,850円、衣笠店△2,200円だ。
百万遍店を閉めると、この18,600円を失う。夕方に移ってくる客の分（60,000円×30%×65%＝11,700円）を取り戻しても、1日**6,900円**、年に約250万円の損になる。
::
::choice B. 衣笠店だけ深夜営業を休止し、百万遍店と今出川店は続ける
**◎ 店ごとに、増える分と減る分だけを比べた答え。**衣笠店を閉めると、深夜帯の△2,200円がなくなり、夕方に移る客の分（28,000円×30%×65%＝5,460円）が加わって、1日**＋7,660円**。年に約280万円、店全体の利益が増える。
今出川店は、閉めても△8,850円＋8,775円＝△75円とほぼ変わらない。変わらないなら、常連客と深夜スタッフの雇用を守れる「続ける」を選ぶのが自然だ。百万遍店は閉めると損をする。
::
::choice C. 深夜帯は1人勤務にして、人件費を半分にする
**× 数字は良くなるが、続けられない。**人件費が1日8,700円減り、衣笠店の深夜帯も＋6,500円になる。だが深夜の1人勤務は、強盗やトラブル、急病のときに従業員を守れない。上の「実際にあった話」のとおり、外食大手でさえ、ワンオペを理由に1,000店以上の深夜営業を止めた。2名体制は、利益計算の前提条件である。
::
::choice D. 衣笠店と今出川店の2店を閉める。今出川店も、客が夕方に移れば損はしない
**△ 計算は合っているが、得るものがない。**今出川店を閉めた場合の変化は1日△75円で、ほぼゼロだ。損はしないが、得もしない。それなのに、深夜の常連客を失い、深夜スタッフ2名の働き口もなくなる。「3割が夕方に移る」はほかのチェーンの例にすぎず、今出川店で2割しか移らなければ、△8,850円＋5,850円で1日約3,000円の損になる。数字が同じなら、取り返しのつかない選択は避ける。
::
::answer 考え方の例を見る
::table 深夜営業をやめた場合の、店全体の1日の利益の変化（単位：円）
| 店舗 | 深夜帯で失う金額 | 夕方に移る客の分 | 店全体の変化 |
| 百万遍店 | △18,600 | ＋11,700 | △6,900 |
| 今出川店 | △8,850 | ＋8,775 | △75 |
| 衣笠店 | ＋2,200（赤字がなくなる） | ＋5,460 | ＋7,660 |
::
（深夜帯で失う金額は、売上から食材費・人件費・光熱費を引いた金額。家賃と減価償却費は、閉めても減らないので含めない。）
この問題には、店舗や事業の撤退を判断するときの3つの鉄則が詰まっている。
- **やめても減らない費用は、判断に入れない**：本部が営業時間の比率で割り振った家賃や減価償却費は、閉めても1円も減らない。割り振った後の「部門別の損益」が赤字でも、その部門が会社の利益を押し上げていることはよくある。
- **やめたときに「戻ってくる分」も数える**：閉店で客がすべて消えるとは限らない。別の時間帯や別の店に移る客の分は、撤退の損を小さくする。
- **差がわずかなら、取り返しのつかない選択は避ける**：見積りには幅がある。今出川店のように計算上ほぼ同じなら、元に戻しにくいほう（閉店・解雇）は選ばない。
大森は全店一律の閉店をやめ、衣笠店だけ深夜営業を休止した。衣笠店の深夜スタッフ2名は、人手の足りない百万遍店の深夜帯に移ってもらった。そして毎月、各店の深夜帯の売上が、閉めた場合との損得の分かれ目を割り込んでいないかを確かめることにした。

::exam 給料・預り金・立替金の急所
- 給料は**総支給額**で計上する。天引き額は所得税預り金・社会保険料預り金など（負債）。差額が手取りの支払額。
- 社会保険料の納付時：本人負担分は社会保険料預り金の減少、会社負担分は**法定福利費**（費用）。
- 立替金（従業員立替金）は資産。給料から差し引いて回収する仕訳がよく出る。
- 社員旅行の積立金など、従業員から預かったお金は「従業員預り金」（負債）。
- 「預り金」「仮受金」「前受金」を混同しない。天引き＝預り金、内容不明の入金＝仮受金、商品代金の前受け＝前受金。
- 所得税の納付期限（原則として翌月10日）などの実務知識は問われないが、「預かったものを納めると預り金が減る」という流れは確実に。
::

::next 人件費の「未来の支払い」 ― 引当金の世界へ
2級では、来期に支払う賞与のうち当期に属する分を見積もって計上する**賞与引当金**や、将来の退職金に備える**退職給付引当金**を学ぶ。1級では、数十年先の退職金支払いを現在価値に割り引いて計算する**退職給付会計**という、会計の中でも特に高度な論点に挑む。
本章の判断問題で使った「深夜営業で増える収益と費用だけを比べる」という考え方は、2級の工業簿記で学ぶ**CVP分析（損益分岐点分析）**や**業務的意思決定**の入り口だ。どの費用が売上に比例し（変動費）、どの費用が売上に関係なく発生するか（固定費）を見分ける力は、経営判断の基本となる思考法である。
::

::summary
- 給料は総支給額で「給料」（費用）に計上し、天引きした税金・保険料は預り金（負債）で処理する
- 預り金は従業員から預かったお金。納付したら預り金を減らす。手をつけてはいけないお金である
- 社会保険料の会社負担分は「法定福利費」（費用）。納付時に計上するのが基本
- 従業員などが負担すべき支払いを会社が立て替えたら立替金（資産）。給料から差し引いて回収することが多い
- 時給だけでは人件費は語れない。深夜割増（25%以上）と法定福利費を含めた「本当のコスト」で考える
- 深夜営業のような判断は、それによって増える収益と費用だけを比べる
::
