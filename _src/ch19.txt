::mystery 決算日の深夜、帳簿の半分が「ゼロ」になる
3月31日、深夜。おかわり堂ケータリングの経理担当者は、総勘定元帳を1ページずつ締め切っていた。
売上の勘定。1年間で1,860万円が積み上がった勘定に、彼女は最後の記入をして、残高を**ゼロ**にした。給料の勘定も、仕入の勘定も、支払家賃の勘定も、次々とゼロになっていく。1年分の記録が、帳簿の上から消えていく。
ところが、現金の勘定、売掛金の勘定、借入金の勘定、資本金の勘定は、ゼロにしない。残高に「次期繰越」と書き添えて、そのまま翌年のページへと引き継いでいく。
同じ総勘定元帳の中で、ある勘定は毎年ゼロに戻され、ある勘定は何十年も残高を引き継いでいく。この違いは、いったい何なのか？　そして、ゼロにされた1年分の売上や費用は、どこへ消えたのか？
::

## 2種類の勘定 ― 「フロー」と「ストック」

問いの答えは、勘定の性質の違いにある。

::theory フローの勘定と、ストックの勘定
**収益・費用**の勘定は、「1年間にどれだけ稼ぎ、どれだけ使ったか」という**期間の流れ（フロー）**を測る勘定だ。今年の売上と来年の売上を混ぜてしまっては、各年の成績が分からない。だから、期末には必ずゼロに戻し、翌年はゼロから数え直す。陸上のタイムを、レースごとにリセットするのと同じだ。
**資産・負債・純資産**の勘定は、「ある時点で、何をどれだけ持ち、誰にいくら返す義務があるか」という**残高（ストック）**を測る勘定だ。3月31日に金庫にある現金は、4月1日になっても金庫にある。借金は年が変わっても消えない。だから、残高をそのまま次の期へ引き継ぐ。
損益計算書はフローを、貸借対照表はストックを報告する。第1章で「動画」と「写真」にたとえたのは、この違いだ。
::

では、ゼロにされた1年分の収益と費用はどこへ行くのか。答えは、**損益**という勘定を経由して、**繰越利益剰余金**へ流れ込む。

## 決算振替 ― 収益と費用を「損益」に集める

帳簿の締切は、次の3つのステップで行う。第18章で決算整理を終えたおかわり堂ケータリングの数字で見ていこう。

::steps 収益・費用の締切の手順
収益の勘定の残高を、損益勘定の貸方に振り替える | 売上や受取手数料の勘定は、借方に同額を書いてゼロになる
費用の勘定の残高を、損益勘定の借方に振り替える | 仕入や給料の勘定は、貸方に同額を書いてゼロになる
損益勘定の残高（当期純利益）を、繰越利益剰余金勘定に振り替える | 損益勘定もゼロになり、利益は純資産として次期へ引き継がれる
::

::solve 消えた売上は、「純資産」の中で生きている
1年分の売上や費用の勘定がゼロになるのは、記録を捨てるためではない。その1年間の成績を**損益勘定に集約し、差額である当期純利益だけを、純資産（繰越利益剰余金）として次期へ引き継ぐ**ためだ。
売上1,860万円も、仕入946万円も、給料360万円も、個々の勘定としては消える。だが、それらが生み出した「140万円の利益」という成果は、繰越利益剰余金の中に積み上がり、会社の財産として生き続ける。
毎年リセットされるフローの勘定と、永遠に引き継がれるストックの勘定。その2つをつなぐ唯一の橋が、損益勘定から繰越利益剰余金への振替なのだ。おかわり堂ケータリングの繰越利益剰余金は、創業以来の利益の蓄積である158万円に、今期の140万円が加わり、**298万円**になった。
::

## 英米式決算法 ― 資産・負債・純資産を締め切る

資産・負債・純資産の勘定は、残高を次期に繰り越して締め切る。3級では、仕訳をせずに、勘定の上で直接「次期繰越」と記入して締め切る**英米式決算法**を学ぶ。

::steps 英米式決算法による締切
残高の反対側に「次期繰越」と記入する | 資産の勘定（借方残高）なら貸方に、負債・純資産の勘定（貸方残高）なら借方に、残高と同額を「次期繰越」として記入する（実務では赤字で書く）
借方と貸方の合計を一致させて締め切る | 合計額を記入し、二重線を引いて締め切る
翌期首に「前期繰越」と記入する | 次期の最初の日付で、もとの側に「前期繰越」として残高を記入する（開始記入）
::

::tgrid
::taccount 現金
4/1 前期繰越 380,000 | 期中の支払い 2,968,000
期中の入金 3,000,000 | 3/31 次期繰越 412,000
= 3,380,000 | 3,380,000
4/1 前期繰越 412,000 |
::
::taccount 繰越利益剰余金
3/31 次期繰越 2,980,000 | 4/1 前期繰越 1,580,000
 | 3/31 損益 1,400,000
= 2,980,000 | 2,980,000
 | 4/1 前期繰越 2,980,000
::
::

::note
※現金勘定の期中の入出金は、紙面の都合で合計額にまとめている。英米式決算法では、資産・負債・純資産の締切に仕訳は行わない。締め切った後、各勘定の次期繰越の金額を集めて**繰越試算表**を作り、借方合計と貸方合計の一致を確かめる。
::

## 財務諸表の表示ルール ― 「勘定科目」と「表示科目」は違う

財務諸表では、帳簿の勘定科目をそのまま使わず、読み手に分かりやすい**表示科目**に置き換えるものがある。第3問で最も点差がつくのが、この表示のルールだ。

::table 勘定科目と表示科目の主な違い
| 勘定科目 | 財務諸表での表示 | 注意点 |
| 売上 | 売上高 | 損益計算書 |
| 仕入（決算整理後） | 売上原価 | 損益計算書。整理後の仕入勘定の残高 |
| 繰越商品 | 商品 | 貸借対照表 |
| 現金・普通預金・当座預金 | 現金預金 | まとめて表示することが多い |
| 貸倒引当金 | 売掛金などから控除して表示 | 「売掛金 2,800,000 貸倒引当金 △56,000 → 2,744,000」 |
| 減価償却累計額 | 各固定資産から控除して表示 | 固定資産ごとに差し引く |
| 前払保険料・前払家賃など | 前払費用 | 貸借対照表 |
| 未収利息・未収家賃など | 未収収益 | 貸借対照表 |
| 未払利息・未払給料など | 未払費用 | 貸借対照表 |
| 前受家賃・前受手数料など | 前受収益 | 貸借対照表 |
| 当座借越 | 借入金 | 貸借対照表 |
| 繰越利益剰余金 | 繰越利益剰余金（当期純利益を加えた金額） | 試算表の金額＋当期純利益 |
::

::exam 財務諸表作成の急所
- 貸借対照表の**繰越利益剰余金は、試算表の金額に当期純利益を加えた金額**。試算表の金額をそのまま書くのは、第3問で最も多い失点パターンだ。（当期純損失なら差し引く）
- 損益計算書の当期純利益は**借方（左側）**に書く。純損失なら貸方（右側）。
- 「仕入」は「売上原価」、「売上」は「売上高」、「繰越商品」は「商品」と書き換える。
- 経過勘定は、問題の解答用紙の科目名（前払費用・未払費用など）に合わせる。
- 貸倒引当金と減価償却累計額は、対象の資産から控除する形式で書く。
- 最後に、損益計算書と貸借対照表の両方で、左右の合計が一致するかを確認する。
::

::cfo 投資家と銀行は、最初にどちらの決算書を開くのか？
おかわり堂ケータリングの社長が尋ねてきた。「来月、新しいメインバンク候補の銀行と、出資を検討している投資ファンドの両方に決算書を見せることになった。彼らは、損益計算書と貸借対照表の、どちらを先に見るのかな？」。あなたなら、どう答え、どんな準備をするか？
::answer
答えは「**相手によって違う。そして、プロは必ず2枚をつなげて読む**」だ。
**銀行**は、多くの場合、**貸借対照表**から開く。銀行の最大の関心は「貸したお金が返ってくるか」だからだ。純資産は十分か（債務超過ではないか）、借入金は過大ではないか、手元の現金預金は十分か。そのうえで損益計算書を見て、返済の原資となる利益とキャッシュを生む力を確かめる。
**投資家**は、多くの場合、**損益計算書**から開く。売上の成長率と利益率から、会社の稼ぐ力と将来性を見るためだ。そのうえで貸借対照表と組み合わせて、預けたお金がどれだけ効率よく利益を生んでいるかを確かめる。

::kpi おかわり堂ケータリングの主な経営指標
売上総利益率 | 49.1% | （18,600,000－9,460,000）÷18,600,000
当期純利益率 | 7.5% | 1,400,000÷18,600,000
自己資本比率 | 63.0% | 純資産7,980,000÷総資産12,665,000
ROE（自己資本利益率） | 17.5% | 1,400,000÷7,980,000（期末の純資産で計算）
::
準備としては、この4つの指標を前期と比べた資料を用意したい。自己資本比率63%は、銀行に対して「財務の安全性は高い」と示す材料になる。ROE17.5%は、投資家に対して「預かったお金を効率よく増やしている」と示す材料になる。
ただし、どちらの相手にも必ず聞かれる質問がある。「この利益は、来年も続くのか？」。決算書は過去の通知表だ。財務の仕事は、通知表を正確に作ったうえで、そこから**これから先の見通し**を数字で語ることである。
::
::

::danger 「繰越利益剰余金の書き忘れ」が、決算書を壊す
損益勘定から繰越利益剰余金への振替を忘れると、貸借対照表の左右は一致しない。純資産が、当期純利益の分だけ少なく表示されるからだ。逆に言えば、貸借対照表の貸借が当期純利益の金額だけずれていたら、真っ先にこの振替を疑うべきである。
実務でも、決算書の数字を手作業で転記していた時代には、こうしたミスで決算発表の直前に大騒ぎになることがあった。損益計算書と貸借対照表は、繰越利益剰余金という1本の糸でつながっている。その糸を結び忘れた決算書は、どれほど美しく作っても、正しくない。
::

::next 損益計算書は「段階」に分かれる ― 2級の報告式へ
2級では、損益計算書を上から下へ順に読む**報告式**で作成し、利益を段階的に計算する。
売上高－売上原価＝**売上総利益**、そこから販売費及び一般管理費を引いて**営業利益**（本業の利益）、受取利息や支払利息を加減して**経常利益**（いつもの活動による利益）、臨時の損益を加減して**税引前当期純利益**、税金を引いて**当期純利益**。
貸借対照表も、資産と負債を**流動**と**固定**に分けて表示し、会社の短期的な支払能力（流動比率など）を分析できるようにする。そして1級では、第3の財務諸表である**キャッシュ・フロー計算書**を学ぶ。序章で私たちが手計算で追いかけた「利益と現金のズレ」を、公式の財務諸表として表現する技術だ。ここまで来れば、上場企業の有価証券報告書を、自分の力で読み解けるようになる。
::

::summary
- 収益・費用はフローの勘定。期末に損益勘定へ振り替えてゼロにし、毎年数え直す
- 損益勘定の残高（当期純利益）は、繰越利益剰余金へ振り替える。これがフローとストックをつなぐ唯一の橋
- 資産・負債・純資産はストックの勘定。英米式決算法で「次期繰越」と記入して締め切り、翌期首に「前期繰越」と記入する
- 財務諸表は決算整理後残高試算表から作る。売上→売上高、仕入→売上原価、繰越商品→商品などの表示ルールに注意
- 貸借対照表の繰越利益剰余金＝試算表の金額＋当期純利益
- 銀行は貸借対照表から、投資家は損益計算書から読み始めることが多い。プロは必ず2枚をつなげて読む
::
