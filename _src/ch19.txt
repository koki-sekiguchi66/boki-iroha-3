::mystery 9時30分の役員会まで、あと1時間。貸借対照表が140万円合わない
4月1日、朝8時30分。徹夜明けのひよりが、ケータリングの事務所のソファで目を覚ますと、スマートフォンが震えていた。親会社おかわり堂の佐伯からだ。
佐伯：「大川さん、夜中に送ってもらったケータリングの決算書、拝見しました。貸借対照表の左と右が、合っていません」
ひより：「え……」
佐伯：「資産の合計が12,665,000円。負債と純資産の合計が11,265,000円。ちょうど**140万円**、右側が足りません。9時30分の役員会で、グループの決算として報告する予定なんです」
ひよりは跳ね起きて、パソコンを開いた。決算整理の仕訳は、昨夜、小野と2人で1本ずつ確かめた。精算表の左右も合っていた。転記も、締切も、全部済ませた。それなのに、最後の1枚だけが合わない。
しかも、足りない140万円には見覚えがあった。昨夜、精算表の最終行に現れた、**当期純利益**と同じ金額だ。
小野は、明け方に熱を出して帰っていた。電話は、つながらない。
仕訳は1本も間違っていない。なのに、なぜ貸借対照表だけが、ちょうど利益の分だけ合わないのか？
::

## 6時間前 ― 帳簿の半分が「ゼロ」になる夜

時計を、前の晩に戻そう。
3月31日、深夜。精算表を完成させたあとも、ひよりはケータリングの事務所に残っていた。経理担当の小野が、総勘定元帳を1ページずつ締め切っていくのを、隣で見せてもらうためだ。
売上の勘定。1年間で1,860万円が積み上がった勘定に、小野は最後の記入をして、残高を**ゼロ**にした。給料の勘定も、仕入の勘定も、支払家賃の勘定も、次々とゼロになっていく。
ひより：「小野さん、消しちゃって、いいんですか。1年分の売上ですよ」
小野たちが毎朝、弁当を積んで走り回った成果だ。ところが、現金、売掛金、借入金、資本金の勘定は、ゼロにしない。残高に「次期繰越」と書き添えて、翌年のページへと引き継いでいく。
小野：「消えるんじゃないの。引っ越すのよ」
ひより：「引っ越す？」
小野：「あとで分かるわ。最後まで見てて」

### 2種類の勘定 ― 「フロー」と「ストック」

小野は、ペンを置いて、熱いお茶を2つ淹れた。
小野：「大川さん、陸上部だった？」
ひより：「いえ、文芸部です」
小野：「私は短距離だったの。100mのタイムって、レースのたびに0秒から測り直すでしょう。前のレースのタイムに足していったら、わけが分からなくなる」
ひより：「売上や費用も、同じ……」
小野：「そう。今年いくら稼いだかを知りたいのに、去年の売上が混ざってたら困る。だから毎年0に戻すの。こういう、1年間の流れを測る勘定を、**フロー**っていうの」
小野：「でも、金庫の現金は違う。3月31日に41万円あったら、4月1日になっても41万円ある。借金も、年が変わったって消えない。こういう、ある時点の残高を測る勘定は、**ストック**。こっちは、ずっと引き継ぐの」

::theory フローの勘定と、ストックの勘定
**収益・費用**の勘定は、「1年間にどれだけ稼ぎ、どれだけ使ったか」という**期間の流れ（フロー）**を測る勘定だ。今年の売上と来年の売上を混ぜてしまっては、各年の成績が分からない。だから、期末には必ずゼロに戻し、翌年はゼロから数え直す。陸上のタイムを、レースごとにリセットするのと同じだ。
**資産・負債・純資産**の勘定は、「ある時点で、何をどれだけ持ち、誰にいくら返す義務があるか」という**残高（ストック）**を測る勘定だ。3月31日に金庫にある現金は、4月1日になっても金庫にある。借金は年が変わっても消えない。だから、残高をそのまま次の期へ引き継ぐ。
損益計算書はフローを、貸借対照表はストックを報告する。第1章で「動画」と「写真」にたとえたのは、この違いだ。
::

ひより：「じゃあ、ゼロにした1年分の売上と費用は、どこへ行くんですか」
小野：「それが、引っ越し先。**損益**っていう勘定に、いったん全部集めるの」

## 決算振替 ― 収益と費用を「損益」に集める

小野は、総勘定元帳の最後のほうのページを開いた。「損益」と書かれた、まだ何も記入されていないページだ。
小野：「手順は3つ。売上や受取手数料を、ここの右側に集める。仕入や給料を、左側に集める。そして、左右の差を、繰越利益剰余金に送る。それでおしまい」

::steps 収益・費用の締切の手順
収益の勘定の残高を、損益勘定の貸方に振り替える | 売上や受取手数料の勘定は、借方に同額を書いてゼロになる
費用の勘定の残高を、損益勘定の借方に振り替える | 仕入や給料の勘定は、貸方に同額を書いてゼロになる
損益勘定の残高（当期純利益）を、繰越利益剰余金勘定に振り替える | 損益勘定もゼロになり、利益は純資産として次期へ引き継がれる
::

::point メモ ― 消えた売上は、「純資産」の中で生きている
1年分の売上や費用の勘定がゼロになるのは、記録を捨てるためではない。その1年間の成績を**損益勘定に集約し、差額である当期純利益だけを、純資産（繰越利益剰余金）として次期へ引き継ぐ**ためだ。
売上1,860万円も、仕入946万円も、給料360万円も、個々の勘定としては消える。だが、それらが生み出した「140万円の利益」という成果は、繰越利益剰余金の中に積み上がり、会社の財産として生き続ける。
毎年リセットされるフローの勘定と、永遠に引き継がれるストックの勘定。その2つをつなぐ唯一の橋が、損益勘定から繰越利益剰余金への振替なのだ。おかわり堂ケータリングの繰越利益剰余金は、創業以来の利益の蓄積である158万円に、今期の140万円が加わり、**298万円**になった。
::

小野が最後の振替を記入したのは、午前2時を回ったころだった。繰越利益剰余金の勘定の残高が、158万円から298万円に変わる。
小野：「ほら、ちゃんと引っ越してきたでしょう」
ひより：「1年分の売上は、140万円の利益になって、ここに住んでるんですね」
小野：「そう。創業から2年、私たちが稼いだ分が、全部ここにいるの」
ひよりは、その数字を見ながら、父の店のことを考えていた。まんぷく食堂の繰越利益剰余金も、毎年きちんと増えていたはずだ。帳簿の上の「利益の蓄積」は、最後の日まで残っていた。お金だけが、なかった。

## 英米式決算法 ― 資産・負債・純資産を締め切る

小野：「次は、引き継ぐほうの勘定ね。こっちは仕訳はいらないの。元帳の上で、直接『次期繰越』って書くだけ」
ひより：「仕訳をしないで、いいんですか」
小野：「3級で習う**英米式決算法**っていうやり方。残高の反対側に次期繰越と書いて、左右の合計をそろえて締める。翌朝、4月1日の行に前期繰越と書けば、引き継ぎは完了」

::steps 英米式決算法による締切
残高の反対側に「次期繰越」と記入する | 資産の勘定（借方残高）なら貸方に、負債・純資産の勘定（貸方残高）なら借方に、残高と同額を「次期繰越」として記入する（実務では赤字で書く）
借方と貸方の合計を一致させて締め切る | 合計額を記入し、二重線を引いて締め切る
翌期首に「前期繰越」と記入する | 次期の最初の日付で、もとの側に「前期繰越」として残高を記入する（開始記入）
::

::tgrid
::taccount 現金
4/1 前期繰越 380,000 | 期中の支払い 2,968,000
期中の入金 3,000,000 | 3/31 次期繰越 412,000
= 3,380,000 | 3,380,000
4/1 前期繰越 412,000 |
::
::taccount 繰越利益剰余金
3/31 次期繰越 2,980,000 | 4/1 前期繰越 1,580,000
 | 3/31 損益 1,400,000
= 2,980,000 | 2,980,000
 | 4/1 前期繰越 2,980,000
::
::

::note
※現金勘定の期中の入出金は、紙面の都合で合計額にまとめている。英米式決算法では、資産・負債・純資産の締切に仕訳は行わない。締め切った後、各勘定の次期繰越の金額を集めて**繰越試算表**を作り、借方合計と貸方合計の一致を確かめる。
::

## 財務諸表の作成 ― 決算整理後残高試算表から

午前2時半。締め切った元帳を閉じると、小野はもう1枚、表を印刷した。決算整理を終えたあとの、すべての勘定の残高が並んでいる。
小野：「ここからが、本当の最後。この表を2つに切り分けると、決算書になるの」
ひより：「2つに、ですか」
小野：「そう。引っ越した勘定と、残った勘定に。引っ越した収益と費用からは損益計算書。残った資産と負債と純資産からは貸借対照表」
小野：「……ごめん、ちょっと寒気がする。続きは、お願いしていい？」
小野は、額に手を当てて立ち上がった。熱が出始めていた。タクシーを見送ったあと、ひよりは1人で、印刷された表の前に座った。

### 貸借対照表（勘定式）

続けて、資産・負債・純資産の残高を並べた。最後の行、繰越利益剰余金。ひよりは、試算表の**1,580,000円**をそのまま書き写した。午前4時。資産の側の合計を確かめたところで、目が閉じかけた。ひよりはPDFにして、佐伯に送った。

## 答え合わせ ― 引っ越しの「最後の1回」を、決算書に写し忘れた

朝8時40分。佐伯との電話を切ったひよりは、自分の送った貸借対照表を、右下から1行ずつ指でたどった。資本金5,000,000円。繰越利益剰余金1,580,000円。
1,580,000円。それは、試算表に載っていた数字だ。試算表は、決算整理のあとの残高を集めた表だが、そこにある繰越利益剰余金は、まだ今年の利益を受け取る前の金額だった。
ひよりの頭に、昨夜の小野の声がよみがえった。
小野：「ほら、ちゃんと引っ越してきたでしょう」
元帳の上では、小野が損益勘定から140万円を繰越利益剰余金へ引っ越させていた。残高は158万円から298万円になっていた。その最後の引っ越しを、ひよりは決算書に写し忘れたのだ。
ひよりは、繰越利益剰余金の欄を**2,980,000円**に直した。右側の合計が、12,665,000円になった。左右が、ぴたりとそろった。9時10分、訂正版が佐伯に届いた。

::solve 足りなかった140万円は、「今年の利益」そのものだった
決算整理後残高試算表の繰越利益剰余金（1,580,000円）は、**当期純利益を振り替える前**の金額だ。貸借対照表には、それに今年の当期純利益1,400,000円を加えた**2,980,000円**を書かなければならない。
損益計算書の収益と費用は、損益勘定を経由して、最後は繰越利益剰余金に流れ込む。この「最後の引っ越し」を貸借対照表に反映しなければ、純資産がちょうど当期純利益の分だけ少なくなり、左右が合わない。逆に言えば、貸借対照表が**当期純利益と同じ金額だけ**ずれていたら、真っ先にここを疑えばよい。
これは、試験の第3問で最も多い失点のパターンでもある。
::

※現金と普通預金は「現金預金」としてまとめて表示している（問題で別々の科目が指定されていれば、それに従う）。借入金2,150,000円は、借入金2,000,000円と当座借越150,000円の合計。
::

## 財務諸表の表示ルール ― 「勘定科目」と「表示科目」は違う

その日の昼、熱の下がった小野から電話がかかってきた。ひよりが訂正版を送ると、小野は少しして、1か所を指摘した。
小野：「140万円は、よく自分で見つけたわね。それと、もう1つ。『繰越商品』のままになってる」
小野：「『繰越商品』は、帳簿の中だけの名前。決算書に載せるときは『商品』と書くの」
ひより：「同じものなのに、名前が変わるんですか」
小野：「読むのは、簿記を知らない人かもしれないでしょう。だから、外に出すときの名前に着替えさせるの。売上は売上高、仕入は売上原価。前払保険料は前払費用」
ひより：「帳簿の中の名前と、外に出すときの名前」
小野：「試験でも、ここがいちばん点差がつくそうよ」

::table 勘定科目と表示科目の主な違い
| 勘定科目 | 財務諸表での表示 | 注意点 |
| 売上 | 売上高 | 損益計算書 |
| 仕入（決算整理後） | 売上原価 | 損益計算書。整理後の仕入勘定の残高 |
| 繰越商品 | 商品 | 貸借対照表 |
| 現金・普通預金・当座預金 | 現金預金 | まとめて表示することが多い |
| 貸倒引当金 | 売掛金などから控除して表示 | 「売掛金 2,800,000 貸倒引当金 △56,000 → 2,744,000」 |
| 減価償却累計額 | 各固定資産から控除して表示 | 固定資産ごとに差し引く |
| 前払保険料・前払家賃など | 前払費用 | 貸借対照表 |
| 未収利息・未収家賃など | 未収収益 | 貸借対照表 |
| 未払利息・未払給料など | 未払費用 | 貸借対照表 |
| 前受家賃・前受手数料など | 前受収益 | 貸借対照表 |
| 当座借越 | 借入金 | 貸借対照表 |
| 繰越利益剰余金 | 繰越利益剰余金（当期純利益を加えた金額） | 試算表の金額＋当期純利益 |
::

::exam 財務諸表作成の急所
- 貸借対照表の**繰越利益剰余金は、試算表の金額に当期純利益を加えた金額**。試算表の金額をそのまま書くのは、第3問で最も多い失点パターンだ。（当期純損失なら差し引く）
- 損益計算書の当期純利益は**借方（左側）**に書く。純損失なら貸方（右側）。
- 「仕入」は「売上原価」、「売上」は「売上高」、「繰越商品」は「商品」と書き換える。
- 経過勘定は、問題の解答用紙の科目名（前払費用・未払費用など）に合わせる。
- 貸倒引当金と減価償却累計額は、対象の資産から控除する形式で書く。
- 最後に、損益計算書と貸借対照表の両方で、左右の合計が一致するかを確認する。
::


::real 日本企業が積み上げた「繰越利益」は600兆円を超えた
財務省の法人企業統計によると、金融・保険業を除く国内企業の**利益剰余金**（いわゆる内部留保）は、2023年度末に**600兆9,857億円**となり、初めて600兆円を超えた。12年連続で過去最高の更新だ。
「内部留保をため込みすぎだ。賃金に回すべきだ」という批判もある。だが、利益剰余金は金庫にしまわれた現金ではない。それは貸借対照表の右側、つまり「お金の出どころ」の記録であり、実際のお金は、工場や設備、在庫、売掛金など、左側のさまざまな資産に姿を変えている。おかわり堂ケータリングの繰越利益剰余金298万円も、どれか1つの資産に色をつけて取ってあるわけではない。現金で配送車を買っても、繰越利益剰余金は1円も変わらない。
::note
出典：[税理士ドットコム「史上初の600兆円超え。企業が抱える『内部留保』の意義とリスク」（財務省の法人企業統計にもとづく）](https://www.zeiri4.com/c_1076/n_1193/)
::
::

::danger 「繰越利益剰余金の書き忘れ」が、決算書を壊す
損益勘定から繰越利益剰余金への振替を忘れると、純資産が当期純利益の分だけ少なくなり、貸借対照表の左右が一致しない。貸借が当期純利益の金額だけずれていたら、真っ先にこの振替を疑おう。損益計算書と貸借対照表は、繰越利益剰余金という1本の糸でつながっている。
::

::next 損益計算書は「段階」に分かれる ― 2級の報告式へ
2級では、損益計算書を上から下へ順に読む**報告式**で作成し、利益を段階的に計算する。
売上高－売上原価＝**売上総利益**、そこから販売費及び一般管理費を引いて**営業利益**（本業の利益）、受取利息や支払利息を加減して**経常利益**（いつもの活動による利益）、臨時の損益を加減して**税引前当期純利益**、税金を引いて**当期純利益**。
貸借対照表も、資産と負債を**流動**と**固定**に分けて表示し、会社の短期的な支払能力（流動比率など）を分析できるようにする。そして1級では、第3の財務諸表である**キャッシュ・フロー計算書**を学ぶ。序章で私たちが手計算で追いかけた「利益と現金のズレ」を、公式の財務諸表として表現する技術だ。ここまで来れば、上場企業の有価証券報告書を、自分の力で読み解けるようになる。
::

::summary
- 収益・費用はフローの勘定。期末に損益勘定へ振り替えてゼロにし、毎年数え直す
- 損益勘定の残高（当期純利益）は、繰越利益剰余金へ振り替える。これがフローとストックをつなぐ唯一の橋
- 資産・負債・純資産はストックの勘定。英米式決算法で「次期繰越」と記入して締め切り、翌期首に「前期繰越」と記入する
- 財務諸表は決算整理後残高試算表から作る。売上→売上高、仕入→売上原価、繰越商品→商品などの表示ルールに注意
- 貸借対照表の繰越利益剰余金＝試算表の金額＋当期純利益
- 銀行は貸借対照表から、投資家は損益計算書から読み始めることが多い。プロは必ず2枚をつなげて読む
::
