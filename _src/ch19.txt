::mystery 決算日の深夜、帳簿の半分が「ゼロ」になる
3月31日、深夜。精算表を完成させたあとも、ひよりはケータリングの事務所に残っていた。経理担当の小野が、総勘定元帳を1ページずつ締め切っていくのを、隣で見せてもらうためだ。
売上の勘定。1年間で1,860万円が積み上がった勘定に、彼女は最後の記入をして、残高を**ゼロ**にした。給料の勘定も、仕入の勘定も、支払家賃の勘定も、次々とゼロになっていく。1年分の記録が、帳簿の上から消えていく。
「消しちゃって、いいんですか」。ひよりは思わず聞いた。1年分の売上。小野たちが毎朝、弁当を積んで走り回った成果だ。
ところが、現金の勘定、売掛金の勘定、借入金の勘定、資本金の勘定は、ゼロにしない。残高に「次期繰越」と書き添えて、そのまま翌年のページへと引き継いでいく。
小野は手を止めずに言った。「消えるんじゃないの。引っ越すのよ」
同じ総勘定元帳の中で、ある勘定は毎年ゼロに戻され、ある勘定は何十年も残高を引き継いでいく。この違いは、いったい何なのか？　そして、ゼロにされた1年分の売上や費用は、どこへ消えたのか？
::

## 2種類の勘定 ― 「フロー」と「ストック」

小野の言う「引っ越し」の意味を知るには、勘定の性質の違いを見る必要がある。

::theory フローの勘定と、ストックの勘定
**収益・費用**の勘定は、「1年間にどれだけ稼ぎ、どれだけ使ったか」という**期間の流れ（フロー）**を測る勘定だ。今年の売上と来年の売上を混ぜてしまっては、各年の成績が分からない。だから、期末には必ずゼロに戻し、翌年はゼロから数え直す。陸上のタイムを、レースごとにリセットするのと同じだ。
**資産・負債・純資産**の勘定は、「ある時点で、何をどれだけ持ち、誰にいくら返す義務があるか」という**残高（ストック）**を測る勘定だ。3月31日に金庫にある現金は、4月1日になっても金庫にある。借金は年が変わっても消えない。だから、残高をそのまま次の期へ引き継ぐ。
損益計算書はフローを、貸借対照表はストックを報告する。第1章で「動画」と「写真」にたとえたのは、この違いだ。
::

では、ゼロにされた1年分の収益と費用はどこへ行くのか。答えは、**損益**という勘定を経由して、**繰越利益剰余金**へ流れ込む。

## 決算振替 ― 収益と費用を「損益」に集める

帳簿の締切は、次の3つのステップで行う。第18章で決算整理を終えたおかわり堂ケータリングの数字で見ていこう。

::steps 収益・費用の締切の手順
収益の勘定の残高を、損益勘定の貸方に振り替える | 売上や受取手数料の勘定は、借方に同額を書いてゼロになる
費用の勘定の残高を、損益勘定の借方に振り替える | 仕入や給料の勘定は、貸方に同額を書いてゼロになる
損益勘定の残高（当期純利益）を、繰越利益剰余金勘定に振り替える | 損益勘定もゼロになり、利益は純資産として次期へ引き継がれる
::

売上 18,600,000 | 損益 18,645,000
受取手数料 45,000 |
::

::journal ② 費用の勘定を損益勘定へ振り替える
損益 17,245,000 | 仕入 9,460,000
 | 給料 3,600,000
 | 支払家賃 1,320,000

 | 雑損 2,000
 | 法人税、住民税及び事業税 600,000
::

::journal ③ 当期純利益を繰越利益剰余金へ振り替える
損益 1,400,000 | 繰越利益剰余金 1,400,000
::

::taccount 損益

3/31 給料 3,600,000 | 3/31 受取手数料 45,000

::note
※「その他の費用」は、支払家賃から法人税、住民税及び事業税までの11の費用（合計4,185,000円）を、紙面の都合でまとめたもの。実際の損益勘定には、勘定科目ごとに記入する。当期純損失の場合は、③が「繰越利益剰余金／損益」となる。
::

::solve 消えた売上は、「純資産」の中で生きている
1年分の売上や費用の勘定がゼロになるのは、記録を捨てるためではない。その1年間の成績を**損益勘定に集約し、差額である当期純利益だけを、純資産（繰越利益剰余金）として次期へ引き継ぐ**ためだ。
売上1,860万円も、仕入946万円も、給料360万円も、個々の勘定としては消える。だが、それらが生み出した「140万円の利益」という成果は、繰越利益剰余金の中に積み上がり、会社の財産として生き続ける。
毎年リセットされるフローの勘定と、永遠に引き継がれるストックの勘定。その2つをつなぐ唯一の橋が、損益勘定から繰越利益剰余金への振替なのだ。おかわり堂ケータリングの繰越利益剰余金は、創業以来の利益の蓄積である158万円に、今期の140万円が加わり、**298万円**になった。
::

小野が最後の振替を記入したのは、午前2時を回ったころだった。繰越利益剰余金の勘定の残高が、158万円から298万円に変わる。「ほら、ちゃんと引っ越してきたでしょう」
ひよりは、その数字を見ながら、父の店のことを考えていた。まんぷく食堂の繰越利益剰余金も、毎年きちんと増えていたはずだ。帳簿の上の「利益の蓄積」は、最後の日まで残っていた。

## 英米式決算法 ― 資産・負債・純資産を締め切る

資産・負債・純資産の勘定は、残高を次期に繰り越して締め切る。3級では、仕訳をせずに、勘定の上で直接「次期繰越」と記入して締め切る**英米式決算法**を学ぶ。

::steps 英米式決算法による締切
残高の反対側に「次期繰越」と記入する | 資産の勘定（借方残高）なら貸方に、負債・純資産の勘定（貸方残高）なら借方に、残高と同額を「次期繰越」として記入する（実務では赤字で書く）
借方と貸方の合計を一致させて締め切る | 合計額を記入し、二重線を引いて締め切る
翌期首に「前期繰越」と記入する | 次期の最初の日付で、もとの側に「前期繰越」として残高を記入する（開始記入）
::

::tgrid
::taccount 現金
4/1 前期繰越 380,000 | 期中の支払い 2,968,000
期中の入金 3,000,000 | 3/31 次期繰越 412,000
= 3,380,000 | 3,380,000
4/1 前期繰越 412,000 |
::
::taccount 繰越利益剰余金
3/31 次期繰越 2,980,000 | 4/1 前期繰越 1,580,000
 | 3/31 損益 1,400,000
= 2,980,000 | 2,980,000
 | 4/1 前期繰越 2,980,000
::
::

::note
※現金勘定の期中の入出金は、紙面の都合で合計額にまとめている。英米式決算法では、資産・負債・純資産の締切に仕訳は行わない。締め切った後、各勘定の次期繰越の金額を集めて**繰越試算表**を作り、借方合計と貸方合計の一致を確かめる。
::

「ここからが、本当の最後。この表を2つに切り分けると、決算書になるの」
「2つに、ですか」
「そう。引っ越した勘定と、残った勘定に」

## 財務諸表の表示ルール ― 「勘定科目」と「表示科目」は違う

朝になって、ひよりは清書した貸借対照表を小野に渡した。小野は1か所に赤い丸をつけた。
「『繰越商品』は、帳簿の中だけの名前。決算書に載せるときは『商品』と書くの」
「同じものなのに、名前が変わるんですか」
「読むのは、簿記を知らない人かもしれないでしょう。だから、外に出すときの名前に着替えさせるの」

財務諸表では、帳簿の勘定科目をそのまま使わず、読み手に分かりやすい**表示科目**に置き換えるものがある。第3問で最も点差がつくのが、この表示のルールだ。

::table 勘定科目と表示科目の主な違い
| 勘定科目 | 財務諸表での表示 | 注意点 |
| 売上 | 売上高 | 損益計算書 |
| 仕入（決算整理後） | 売上原価 | 損益計算書。整理後の仕入勘定の残高 |
| 繰越商品 | 商品 | 貸借対照表 |
| 現金・普通預金・当座預金 | 現金預金 | まとめて表示することが多い |
| 貸倒引当金 | 売掛金などから控除して表示 | 「売掛金 2,800,000 貸倒引当金 △56,000 → 2,744,000」 |
| 減価償却累計額 | 各固定資産から控除して表示 | 固定資産ごとに差し引く |
| 前払保険料・前払家賃など | 前払費用 | 貸借対照表 |
| 未収利息・未収家賃など | 未収収益 | 貸借対照表 |
| 未払利息・未払給料など | 未払費用 | 貸借対照表 |
| 前受家賃・前受手数料など | 前受収益 | 貸借対照表 |
| 当座借越 | 借入金 | 貸借対照表 |
| 繰越利益剰余金 | 繰越利益剰余金（当期純利益を加えた金額） | 試算表の金額＋当期純利益 |
::

::exam 財務諸表作成の急所
- 貸借対照表の**繰越利益剰余金は、試算表の金額に当期純利益を加えた金額**。試算表の金額をそのまま書くのは、第3問で最も多い失点パターンだ。（当期純損失なら差し引く）
- 損益計算書の当期純利益は**借方（左側）**に書く。純損失なら貸方（右側）。
- 「仕入」は「売上原価」、「売上」は「売上高」、「繰越商品」は「商品」と書き換える。
- 経過勘定は、問題の解答用紙の科目名（前払費用・未払費用など）に合わせる。
- 貸倒引当金と減価償却累計額は、対象の資産から控除する形式で書く。
- 最後に、損益計算書と貸借対照表の両方で、左右の合計が一致するかを確認する。
::

::cfo あなたが銀行の融資担当なら ― 決算書を「実態」に引き直して読む
4月、完成した決算書を持って信用金庫を訪ねた片山とひよりは、担当者から、こんな話を聞いた。「同じ業種の2社から、1,000万円の融資の申し込みが来ているんです。期間は3年。決算書の要点はこうです」
- **X社**：売上も利益も大きく、利益率は高い。ただし借入金がとても多く、しかもすべて1年以内に返す約束になっている。手元の現金は少ない
- **Y社**：売上も利益もX社より小さい。借入金は少なく、手元の現金は借入金を大きく上回る。ただし注記によると、売掛金の半分以上は、社長の親族が経営する会社に対するもので、**1年以上回収されていない**
次の視点で考えてから選んでほしい。
- 1年以内に払わなければならないお金を、**1年以内にお金になる資産**でまかなえるか
- 借金を返すお金は、**利益から**出てくるのか、**次の借入れ（借り換え）から**出てくるのか
- 回収されていない売掛金は、本当に「資産」と呼べるか。そう呼べないなら、**除いて計算し直しても**結論は変わらないか
::choice A. X社。利益が大きく、売上高も多いから
**× 損益計算書だけを見ている。**仮の設定（下の「考え方の例」）では、利益率は7.5%と立派で、債務償還年数も（12,000－500）÷1,800＝約6.4年と、目安の10年以内に収まって見える。だが流動比率は6,000÷13,800＝約**43%**。1年以内に返す借入金1億2,000万円を、利益で返すことはできず、毎年の借り換えに頼っている。自己資本比率はわずか8%。借り換えが1回でも断られれば、その場で資金が尽きる会社だ。
::
::choice B. Y社。ただし、親族の会社への売掛金1,500万円は資産から除いて審査し、回収の計画を条件にする
**◎ 割り引いても、返す力は十分にある。**仮の設定で、親族の会社への1,500万円を除くと、純資産は2,900万円、資産合計は6,500万円で、自己資本比率は約**45%**。流動比率は（3,000＋1,000）÷3,600＝約**111%**で、100%を上回る。借入金1,000万円に対して現金預金が3,000万円あり、実質無借金だ。
疑わしい部分を**数字で割り引いても結論が変わらない**なら、貸してよい。そのうえで、1,500万円の回収の計画を出してもらい、融資の条件にすれば、会社のお金が親族の会社に流れ続けることも防げる。
::
::choice C. 2社に500万円ずつ貸して、リスクを分ける
**△ 分けても、X社の危うさは消えない。**分散は大切な考え方だが、返ってこない可能性が高い相手に貸す理由にはならない。X社に貸した500万円は、X社の借り換えが途切れた時点で回収が危うくなる。
::
::choice D. Y社は親族の会社への売掛金が1年以上回収されていない。決算書を信用できないので、どちらにも貸さない
**△ 気づいたのは満点だが、結論が早すぎる。**回収されない関係会社への売掛金は、実質的には社長の親族への貸付けであり、決算書を読む人が最も警戒すべき項目の1つだ。それに気づいたのは審査担当として正しい。
だが、その1,500万円を全額除いても、Y社の数字は健全だ。安全な貸出先に貸さなければ、銀行も利息を得られない。疑いは「断る理由」ではなく、「割り引いて計算し直し、条件をつける理由」にする。
::
::answer 考え方の例を見る
**仮の設定**として、2社の決算書の要点を数字で置いてみよう。
::table 2社の決算書の要点（単位：万円）
| 項目 | X社 | Y社 |
| 売上高 | 20,000 | 12,000 |
| 当期純利益 | 1,500 | 400 |
| 減価償却費 | 300 | 600 |
| 現金預金 | 500 | 3,000 |
| 売掛金 | 3,000 | 2,500 |
| 商品 | 2,500 | 0 |
| 固定資産 | 9,000 | 2,500 |
|= 資産合計 | 15,000 | 8,000 |
| 借入金（すべて1年以内に返済） | 12,000 | 1,000 |
| 買掛金などその他の負債（1年以内に支払い） | 1,800 | 2,600 |
| 純資産 | 1,200 | 4,400 |
::
物差しは次の3つ。
- **流動比率**：（現金預金＋売掛金＋商品）÷1年以内に支払う負債。目安は100%以上
- **自己資本比率**：純資産÷資産合計
- **債務償還年数**：（借入金－現金預金）÷（当期純利益＋減価償却費）。マイナスなら実質無借金
::table 2社を、帳簿の数字と実態の数字で比べる
| 物差し | X社 | Y社（帳簿） | Y社（実態） |
| 流動比率 | 約43% | 約153% | 約111% |
| 自己資本比率 | 8% | 55% | 約45% |
| 債務償還年数 | 約6.4年 | 実質無借金 | 実質無借金 |
| 当期純利益率 | 7.5% | 約3.3% | 約3.3% |
::
（Y社の実態の数字は、親族の会社への売掛金1,500万円を、資産と純資産から除いて計算した。）
答えは「**相手によって見る順番は違う。そして、プロは必ず2枚をつなげ、実態に引き直して読む**」だ。
**銀行**は、多くの場合、**貸借対照表**から開く。銀行の最大の関心は「貸したお金が返ってくるか」だからだ。純資産は十分か、1年以内の支払いを1年以内に入るお金でまかなえるか、回収の見込みのない資産が混じっていないか。そのうえで損益計算書を見て、返済の原資となる利益とキャッシュを生む力を確かめる。X社の債務償還年数6.4年は、一見合格に見える。だが借入金がすべて1年以内の返済である以上、問題は「何年で返せるか」ではなく「来年も借り換えられるか」だ。1つの物差しだけでは、会社は読めない。
**投資家**は、多くの場合、**損益計算書**から開く。売上の成長率と利益率から、会社の稼ぐ力と将来性を見るためだ。X社のROE（当期純利益÷純資産）は125%と驚くほど高い。だがそれは、純資産が極端に薄く、借入金で事業を回しているからだ。投資家にとっては魅力的に見えても、銀行にとっては危うい。同じ決算書でも、読む人の立場で見え方が変わる。
**さらに考えよう：X社の借入金が、すべて5年返済だったら？**
同じ1億2,000万円の借金でも、毎年の返済は2,400万円になり、1年以内の支払いは大きく減る。1年以内に払う負債は2,400万円＋1,800万円＝4,200万円になり、流動比率は約143%と目安を超える。「来年も借り換えられるか」という不安は消える。本業で生む現金（年1,800万円）で、毎年の返済の大半をまかなえる。それでも自己資本比率8%の薄さは変わらないので、景気が悪くなれば真っ先に危うくなる。**借金の大きさだけでなく、返す期限の並び方（期間の構成）で、同じ会社の危うさは大きく変わる。**
片山は、自分の会社の数字も同じ物差しで並べてみた。

::kpi おかわり堂ケータリングの主な経営指標
売上総利益率 | 49.1% | （18,600,000－9,460,000）÷18,600,000
当期純利益率 | 7.5% | 1,400,000÷18,600,000
自己資本比率 | 63.0% | 純資産7,980,000÷総資産12,665,000
ROE（自己資本利益率） | 17.5% | 1,400,000÷7,980,000（期末の純資産で計算）
::
自己資本比率63%は、銀行に対して「財務の安全性は高い」と示す材料になる。ROE17.5%は、投資家に対して「預かったお金を効率よく増やしている」と示す材料になる。
ただし、どちらの相手にも必ず聞かれる質問がある。「この利益は、来年も続くのか？」。決算書は過去の通知表だ。財務の仕事は、通知表を正確に作ったうえで、そこから**これから先の見通し**を数字で語ることである。
::

::real 日本企業が積み上げた「繰越利益」は600兆円を超えた
1社の帳簿で、毎年の当期純利益が繰越利益剰余金に積み上がっていくように、日本全体でも企業の利益の蓄積は膨らみ続けている。財務省が2024年9月2日に公表した法人企業統計によると、金融・保険業を除く国内企業の**利益剰余金**（いわゆる内部留保）は、2023年度末に**600兆9,857億円**となり、初めて600兆円を超えた。前年度より8.3%多く、12年連続で過去最高を更新している。
「内部留保をため込みすぎだ。賃金や投資に回すべきだ」という批判もある。だが、利益剰余金は金庫にしまわれた現金ではない。この章で見たとおり、それは貸借対照表の右側、つまり「お金の出どころ」の記録であり、実際のお金は、工場や設備、在庫、売掛金など、左側のさまざまな資産に姿を変えている。決算書の仕組みを知ると、ニュースの数字の意味も、正しく読めるようになる。

**この章の道具で読む ― 298万円の「内部留保」は、どこにあるのか**
おかわり堂ケータリングの貸借対照表で確かめてみよう。この章の振替で、繰越利益剰余金は298万円になった。

::journal 3月31日：当期純利益を、損益勘定から繰越利益剰余金へ振り替える
損益 1,400,000 | 繰越利益剰余金 1,400,000
::

貸方の繰越利益剰余金は、貸借対照表の右側に載る。では左側を見ると、現金預金は約577万円、そのほかに売掛金、商品、厨房の備品や配送の車がある。298万円という「利益の蓄積」は、どれか1つの資産に色をつけて取ってあるわけではない。借入金や資本金で集めたお金と混ざり合って、左側の資産全体に姿を変えている。
仮に来月、新しい配送車を現金で買えば、現金預金は減り、車両運搬具が増える。それでも繰越利益剰余金は1円も変わらない。逆に言えば、繰越利益剰余金が600兆円あっても、日本企業がその額の現金を持っているわけではない。「内部留保を賃金に回せ」という議論を読むときも、まず確かめるべきは、貸借対照表の右側ではなく、左側にある現金預金のほうだ。
::note
出典：[税理士ドットコム「史上初の600兆円超え。企業が抱える『内部留保』の意義とリスク」（財務省の法人企業統計にもとづく）](https://www.zeiri4.com/c_1076/n_1193/)
::

::danger 「繰越利益剰余金の書き忘れ」が、決算書を壊す
損益勘定から繰越利益剰余金への振替を忘れると、貸借対照表の左右は一致しない。純資産が、当期純利益の分だけ少なく表示されるからだ。逆に言えば、貸借対照表の貸借が当期純利益の金額だけずれていたら、真っ先にこの振替を疑うべきである。
実務でも、決算書の数字を手作業で転記していた時代には、こうしたミスで決算発表の直前に大騒ぎになることがあった。損益計算書と貸借対照表は、繰越利益剰余金という1本の糸でつながっている。その糸を結び忘れた決算書は、どれほど美しく作っても、正しくない。
::

::next 損益計算書は「段階」に分かれる ― 2級の報告式へ
2級では、損益計算書を上から下へ順に読む**報告式**で作成し、利益を段階的に計算する。
売上高－売上原価＝**売上総利益**、そこから販売費及び一般管理費を引いて**営業利益**（本業の利益）、受取利息や支払利息を加減して**経常利益**（いつもの活動による利益）、臨時の損益を加減して**税引前当期純利益**、税金を引いて**当期純利益**。
貸借対照表も、資産と負債を**流動**と**固定**に分けて表示し、会社の短期的な支払能力（流動比率など）を分析できるようにする。そして1級では、第3の財務諸表である**キャッシュ・フロー計算書**を学ぶ。序章で私たちが手計算で追いかけた「利益と現金のズレ」を、公式の財務諸表として表現する技術だ。ここまで来れば、上場企業の有価証券報告書を、自分の力で読み解けるようになる。
::
