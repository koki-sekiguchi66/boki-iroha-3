## 帳簿の体系 ― 主要簿と補助簿

一ノ瀬は、おかわり堂の帳簿の一覧を、会議室の机に並べた。
一ノ瀬：「なぜ3年間も見つからなかったのか。それを知るには、帳簿の全体像から確かめ直す必要があります。大川さん、これまでに出てきた帳簿を、全部言えますか」
ひより：「仕訳帳と総勘定元帳。現金出納帳、当座預金出納帳、小口現金出納帳。仕入帳、売上帳、商品有高帳。売掛金元帳、買掛金元帳。手形の記入帳。固定資産台帳……」
一ノ瀬：「すべての取引が載るのが**主要簿**、特定の取引や勘定を詳しく書くのが**補助簿**です。補助簿のうち、取引を起きた順に書くものを**補助記入帳**、勘定の内訳を相手ごとに書くものを**補助元帳**と呼びます」

::table 帳簿の体系
| 分類 | 帳簿 | 役割 |
| 主要簿 | 仕訳帳 | すべての取引を日付順に仕訳する |
| 主要簿 | 総勘定元帳 | すべての取引を勘定科目ごとに集計する |
| 補助記入帳 | 現金出納帳・当座預金出納帳・小口現金出納帳 | 現金・預金の入出金の明細を記録する |
| 補助記入帳 | 仕入帳・売上帳 | 仕入・売上の取引の明細を記録する |
| 補助記入帳 | 受取手形記入帳・支払手形記入帳 | 手形の明細を記録する |
| 補助元帳 | 売掛金元帳・買掛金元帳 | 取引先ごとの売掛金・買掛金を記録する |
| 補助元帳 | 商品有高帳 | 商品の種類ごとの受入・払出・残高を記録する |
| 補助元帳 | 固定資産台帳 | 固定資産を1つずつ管理する |
::

## 取引ごとに、どの補助簿に記入するか

一ノ瀬：「丹波青果への支払いは、どの帳簿に載っていたと思いますか」
ひより：「仕入だから、仕入帳と商品有高帳。普通預金から払ったから……」
一ノ瀬：「普通預金には、補助簿を作っていません。では、商品有高帳には？」
ひよりは、商品有高帳を開いた。丹波青果からの仕入の行は、どこにもなかった。
ひより：「……仕入帳には載ってるのに、商品有高帳には載ってない」
一ノ瀬：「野菜が届いていないので、店では誰も商品有高帳に書けなかったんです。帳簿どうしのずれは、そこに出ていました。3年間、誰もそれを突き合わせなかった」
試験の第2問でも、「この取引はどの補助簿に記入されるか」を問う問題がよく出る。コツは、まず仕訳を書き、出てきた勘定科目ごとに補助簿を探すことだ。

::table 勘定科目と補助簿の対応
| 仕訳に登場する勘定科目 | 記入する補助簿 |
| 現金 | 現金出納帳 |
| 当座預金 | 当座預金出納帳 |
| 小口現金 | 小口現金出納帳 |
| 仕入 | 仕入帳 ＋ 商品有高帳 |
| 売上 | 売上帳 ＋ 商品有高帳 |
| 売掛金 | 売掛金元帳 |
| 買掛金 | 買掛金元帳 |
| 受取手形 | 受取手形記入帳 |
| 支払手形 | 支払手形記入帳 |
| 建物・備品・車両運搬具・土地 | 固定資産台帳 |
::

::example 補助簿の選択
<!-- notry -->
次の4つの取引が、それぞれどの補助簿に記入されるかを確かめる。
(1) 商品400,000円を仕入れ、代金のうち半額は約束手形を振り出し、残額は掛けとした。
(2) 商品250,000円を売り上げ、代金は得意先振出の小切手で受け取った。
(3) 掛けで仕入れた商品のうち、20,000円を品違いのため返品した。
(4) 業務用の冷蔵庫300,000円を購入し、代金は翌月末に支払うこととした。
::checks 取引(1)〜(4)のそれぞれについて、記入する補助簿の欄をすべてチェックしよう。まず頭の中で仕訳を書くのがコツだ。
| 補助簿 | (1) | (2) | (3) | (4) |
| 現金出納帳 |  | ✓ |  |  |
| 当座預金出納帳 |  |  |  |  |
| 仕入帳 | ✓ |  | ✓ |  |
| 売上帳 |  | ✓ |  |  |
| 商品有高帳 | ✓ | ✓ | ✓ |  |
| 売掛金元帳 |  |  |  |  |
| 買掛金元帳 | ✓ |  | ✓ |  |
| 受取手形記入帳 |  |  |  |  |
| 支払手形記入帳 | ✓ |  |  |  |
| 固定資産台帳 |  |  |  | ✓ |
::
::answer
::journal (1)
仕入 400,000 | 支払手形 200,000
 | 買掛金 200,000
::
→ **仕入帳、商品有高帳、支払手形記入帳、買掛金元帳**
::journal (2)
現金 250,000 | 売上 250,000
::
→ **現金出納帳、売上帳、商品有高帳**
::journal (3)
買掛金 20,000 | 仕入 20,000
::
→ **仕入帳、商品有高帳、買掛金元帳**（返品も、仕入帳と商品有高帳に記入する）
::journal (4)
備品 300,000 | 未払金 300,000
::
→ **固定資産台帳**のみ（未払金には補助簿がない）
::trap
見落としやすい点が3つある。
- 商品有高帳には、仕入・売上・返品のすべてを記入する
- 他人が振り出した小切手は現金なので、当座預金出納帳ではなく現金出納帳に記入する
- 備品の購入は、仕入帳には記入しない。仕入帳に記入するのは、商品の仕入だけだ
::
::
::

## 伝票 ― 仕訳を「1取引1枚」の紙に書く

一ノ瀬が次に開いたのは、経理部の棚に並ぶ伝票のファイルだった。1枚に1つの取引。作成者の欄には、木島の印が並んでいる。
一ノ瀬：「おかわり堂では、仕訳を伝票に書きます。書く人と承認する人を分けるための仕組みです」
ひよりは、承認者の欄を見た。そこにも、同じ印が押されていた。
ひより：「書いた人と、承認した人が、同じ……」
一ノ瀬：「木島さんの上司は、月末の忙しいときに、木島さんに承認の印を預けていたそうです」
ひより：「仕組みはあったのに、1人で回っていたんですね」
3級では、伝票を3種類に分ける**3伝票制**を学ぶ。

::table 3伝票制
| 伝票 | 使う取引 | 記入のしかた |
| 入金伝票 | 現金が増える取引 | 借方は必ず「現金」なので、貸方の勘定科目と金額だけを書く |
| 出金伝票 | 現金が減る取引 | 貸方は必ず「現金」なので、借方の勘定科目と金額だけを書く |
| 振替伝票 | 現金が動かない取引 | 借方・貸方の両方を書く（ふつうの仕訳と同じ） |
::

::table 起票の例（おかわり堂・本部）
| 取引 | 伝票 | 記入する内容 |
| 学会の弁当代100,000円を現金で受け取った | 入金伝票 | 売上 100,000 |
| 店舗の消耗品5,000円を現金で購入した | 出金伝票 | 消耗品費 5,000 |
| 牛肉300,000円を掛けで仕入れた | 振替伝票 | 仕入 300,000 ／ 買掛金 300,000 |
::

### 一部現金取引 ― 2つの起票方法

伝票をめくっていくと、1つの取引が2枚に分かれているものがあった。
ひより：「この売上、1枚目が入金伝票で、2枚目が振替伝票です」
一ノ瀬：「一部だけ現金で受け取った取引ですね。現金が動く部分と動かない部分が混ざっていると、伝票の書き方が2通りあります」

::example 一部現金取引の起票
商品300,000円を売り上げ、代金のうち100,000円は現金で受け取り、残額は掛けとした。方法①（取引を分解する方法）と方法②（いったん全額を掛け取引とみなす方法）の2つで起票する。
::answer
**方法①：取引を分解して起票する**
現金で受け取った部分と、掛けの部分に分けて、2枚の伝票を書く。
::journal 【方法① 1枚目（現金で受け取った部分）】入金伝票（借方は現金）
現金 100,000 | 売上 100,000
::
::journal 【方法① 2枚目（掛けの部分）】振替伝票
売掛金 200,000 | 売上 200,000
::
**方法②：いったん全額を掛け取引とみなして起票する**
全額をいったん掛けで売り上げたと考え、その直後に掛け代金の一部を現金で回収したと考える。
::journal 【方法② 1枚目（全額を掛けとみなす）】振替伝票
売掛金 300,000 | 売上 300,000
::
::journal 【方法② 2枚目（代金の一部を現金で回収）】入金伝票
現金 100,000 | 売掛金 100,000
::
どちらの方法でも、2枚の伝票を合計すると「現金100,000・売掛金200,000／売上300,000」になる。試験では、すでに記入されている伝票（たとえば入金伝票の科目が「売上」か「売掛金」か）から、どちらの方法で起票したのかを判断させる問題が出る。
::trap
2つの方法を混ぜないこと。入金伝票に「売上 100,000」、振替伝票に「売掛金 300,000／売上 300,000」と書くと、売上が400,000円になってしまう。
見分ける手がかりは、入金伝票の相手科目だ。「売上」なら方法①、「売掛金」なら方法②である。
::
::
::

### 仕訳日計表 ― 1日分の伝票を集計する

ひより：「1日に、どれくらいの伝票が出るんですか」
佐伯：「多い日は300枚です。1枚ずつ元帳に書き写していたら、それだけで1日が終わります」
ひより：「じゃあ、どうしているんですか」
佐伯：「1日の終わりに、伝票を勘定科目ごとに足し上げた表を1枚作って、その合計だけを元帳に写します。**仕訳日計表**です」

::example 仕訳日計表の作成
ある日の伝票は次の5枚だった。これを仕訳日計表にまとめる。
入金伝票：売上 120,000　／　入金伝票：売掛金 80,000　／　出金伝票：仕入 50,000　／　出金伝票：旅費交通費 3,000　／　振替伝票：仕入 200,000 ／ 買掛金 200,000
::answer
::table sum 仕訳日計表
| 借方 | 勘定科目 | 貸方 |
| 200,000 | 現金 | 53,000 |
|  | 売掛金 | 80,000 |
|  | 買掛金 | 200,000 |
|  | 売上 | 120,000 |
| 250,000 | 仕入 |  |
| 3,000 | 旅費交通費 |  |
|= 453,000 | 合計 | 453,000 |
::
- 現金の借方は、入金伝票の合計（120,000＋80,000）。貸方は、出金伝票の合計（50,000＋3,000）。
- 仕入の借方は、出金伝票50,000円と振替伝票200,000円の合計。
- 借方合計と貸方合計は必ず一致する（貸借平均の原理）。
::trap
入金伝票と出金伝票には、「現金」という文字が書かれていない。現金の借方に入金伝票の合計、貸方に出金伝票の合計を集計するのを忘れないこと。
振替伝票は、現金の動かない取引だ。現金の行には足さない。
::
::
::

::point 仕訳日計表から、どこへ転記するか
仕訳日計表の合計額は**総勘定元帳**へ転記する。一方、売掛金元帳・買掛金元帳などの補助元帳へは、取引先ごとの明細が必要なので、**個々の伝票から直接**転記する。この2つのルートを区別しよう。
::

## 証ひょう ― 取引の「証拠」から仕訳を起こす

いよいよ、ひよりが気づいた「紙」の話だ。
一ノ瀬：「伝票は、何をもとに書くと思いますか」
ひより：「請求書や、領収書……」
一ノ瀬：「取引があったことを証明する書類を、**証ひょう**（しょうひょう）といいます。証ひょうのない仕訳は、原則として認められません。木島さんは、その証ひょうを自分で作っていた」

::table 主な証ひょう
| 証ひょう | 内容 | 仕訳のヒント |
| 納品書 | 商品やサービスを納めたことを示す | 仕入・売上の数量と金額 |
| 請求書 | 代金の支払いを求める | 掛けの金額、消費税、支払期日 |
| 領収書 | 代金を受け取ったことを示す | 現金などで支払った費用 |
| 振込依頼書 | 銀行での振込を依頼する | 支払いと振込手数料 |
| 通帳・当座勘定照合表 | 口座の入出金の記録 | 入金・引落しの内容 |
::

佐伯：「大川さん、試しに、この請求書から仕訳を起こしてみてください。先月、厨房機器メーカーから届いたものです」

::example 請求書から仕訳を起こす
おかわり堂は、厨房機器メーカーから業務用冷凍庫を購入し、次の請求書を受け取った。代金は翌月末に支払う。消費税は税抜方式で処理する。
::table 請求書（株式会社おかわり堂 御中）
| 品名 | 数量 | 単価 | 金額 |
| 業務用冷凍庫 FZ-900 | 1 | 600,000 | 600,000 |
| 配送・設置費 | 1 | 20,000 | 20,000 |
|  |  | 小計 | 620,000 |
|  |  | 消費税（10%） | 62,000 |
|= |  | 合計 | 682,000 |
::
::answer
::journal 配送・設置費は取得原価に含める。後払いなので未払金
備品 620,000 | 未払金 682,000
仮払消費税 62,000 |
::
冷凍庫は商品ではなく備品なので、買掛金ではなく**未払金**（第9章）。配送・設置費は付随費用として備品の取得原価に含める（第12章）。消費税は仮払消費税（第14章）。1枚の請求書に、これまでの章の知識が詰まっている。
::trap
備品の取得原価に、消費税を含めないこと。税抜方式では、取得原価は620,000円、消費税62,000円は仮払消費税として分ける。
一方、未払金は、相手に実際に支払う税込の682,000円になる。
::
::
::

佐伯：「銀行の通帳も、立派な証ひょうです。洛北ミートさんの通帳なら、こう読みます」

::example 通帳の記録から仕訳を起こす
洛北ミートの普通預金の通帳に、次の記録があった。
::table 普通預金 入出金明細
| 日付 | 摘要 | お支払金額 | お預り金額 |
| 10/31 | 振込　ヤキニクホムラ |  | 720,000 |
| 10/31 | 振込　チクサンカイシャB | 600,000 |  |
| 10/31 | 振込手数料 | 660 |  |
::
焼肉店「炎」は得意先（売掛金）、畜産会社Bは仕入先（買掛金）である。
::answer
::journal 【10/31 ヤキニクホムラからの入金】得意先からの入金は売掛金の回収
普通預金 720,000 | 売掛金 720,000
::
::journal 【10/31 チクサンカイシャBへの振込と手数料】仕入先への振込と、振込手数料
買掛金 600,000 | 普通預金 600,660
支払手数料 660 |
::
::trap
通帳の「お支払金額」は預金の減少（貸方）、「お預り金額」は預金の増加（借方）だ。左右を逆にしないこと。
振込手数料を買掛金に含めてはいけない。消える買掛金は、振り込んだ600,000円だけである。
::
::
::

## 訂正仕訳 ― 間違えた仕訳の直し方

不正の調査では、過去3年分の伝票をすべて見直した。横領とは関係のない、単純な記入の誤りもいくつか見つかった。
ひより：「間違えたところを消して、書き直せばいいですか」
佐伯：「消しません。間違えた記録も、直した記録も、両方残します。それが帳簿です」
ひより：「じゃあ、どうやって直すんですか」
佐伯：「間違いを打ち消す仕訳と、正しい仕訳を、新しく書き足します。**訂正仕訳**です」

::steps 訂正仕訳の3ステップ
誤った仕訳の「逆仕訳」を書く | 誤った記録を取り消す
正しい仕訳を書く | 本来あるべき記録を加える
2つを合算して、相殺できる部分を消す | 同じ勘定科目が借方と貸方にあれば相殺し、最小限の仕訳にまとめる
::

::example 訂正仕訳
次の2つの誤りを訂正する。(1)は、①誤った仕訳の逆仕訳、②正しい仕訳、③①と②を合わせた訂正仕訳の3段階で考える。
(1) 店舗用の冷蔵庫（備品）150,000円を掛けで購入した際に、「仕入／買掛金」と処理していた。
(2) 得意先から売掛金98,000円が普通預金に振り込まれた際に、金額を89,000円と記録していた。
::answer
**(1)**
::journal 【(1)① 逆仕訳】誤った仕訳の逆仕訳
買掛金 150,000 | 仕入 150,000
::
::journal 【(1)② 正しい仕訳】
備品 150,000 | 未払金 150,000
::
::journal 【(1)③ 訂正仕訳】①と②を合わせたもの。相殺できる科目はない
備品 150,000 | 仕入 150,000
買掛金 150,000 | 未払金 150,000
::
**(2)** 正しい金額98,000円と、記録した89,000円の差額9,000円だけを追加すればよい。
::journal 【(2) 訂正仕訳】不足していた9,000円を追加
普通預金 9,000 | 売掛金 9,000
::
::trap
(1)で、正しい仕訳を書き足すだけでは訂正にならない。誤って記録した仕入と買掛金が、帳簿に残ったままになる。必ず逆仕訳で取り消すこと。
(2)で、正しい金額の98,000円をもう一度計上しないこと。すでに89,000円は記録されているので、足りない9,000円だけを追加する。
::
::
::

::point 訂正仕訳で迷ったら
金額だけの誤りなら「差額を追加・削除する」。勘定科目の誤りなら「逆仕訳＋正しい仕訳」で考え、同じ勘定科目が左右に出てきたら相殺する。迷ったら、必ず3ステップを紙に書くこと。
::

## 答え合わせ ― 3つの書類の「照合」が網になる

::scene 3か月前 ― 佐伯の新しいルール
話は、発覚の3か月前にさかのぼる。
佐伯：「来月から、仕入代金を払う前に、3つの紙をそろえてもらいます。発注書、納品書、請求書。それと、店の受入の記録。全部が合ったものだけを払います」
経理部員：「そんなの、毎月何百件もあるんですよ」
佐伯：「月次巡回のときに、鴨川さんのところにも手伝ってもらいます」
こうして、ひよりは毎月、本部の会議室で、紙の山を突き合わせることになった。
3か月目のある日。ひよりは、丹波青果の請求書を手に、首をかしげた。
ひより：「佐伯さん。丹波青果さんの請求書だけ、どの店舗にも納品書がありません」
佐伯：「……店の受入の記録は？」
ひより：「ありません。1件も」
その日の帰り、ひよりは念のため、丹波青果の住所を地図アプリで調べた。亀岡市内の、田んぼの真ん中の空き地だった。
::

::solve 請求書はあった。だが「納品書」と「受入の記録」がなかった
木島が偽造したのは、請求書だけだった。架空の「丹波青果」は実在しないので、店舗には野菜が1箱も届いていない。当然、店舗が作る納品書の控えもなければ、商品の受入記録もない。
3年間、不正が見つからなかったのは、**請求書の作成から支払いまでを、1人で完結できる仕組み**だったからだ。帳簿の数字の合計はいつも合っていた。架空の仕入れは、「仕入／普通預金」という形式的には完璧な仕訳として記録されていたからだ。
不正を暴いたのは、帳簿の数字ではない。**異なる部署が作る複数の証ひょうを照らし合わせる仕組み**だった。複式簿記が「2つの側面」で記録の誤りを見つけるように、証ひょうの照合は「複数の書類」で取引の嘘を見つける。
::

木島は、佐伯に呼ばれた会議室で、すべてを認めた。
木島：「最初は、親の介護のお金が足りなくて、1回だけのつもりでした。2回目からは……誰も見ていないことに、慣れてしまいました」
会議室を出てきた木島は、廊下でひよりとすれ違った。何も言わずに、小さく頭を下げた。
ひよりは、所長が最初の日に言った言葉を思い出していた。帳簿は会社の日記。嘘を書けば、いつか自分が読む。

::danger 「1人に任せきり」が、不正の温床になる
横領の多くは、取引の開始から記録、支払いまでを1人で行っている職場で起きる。長年の担当者ほど信頼され、誰もチェックしなくなる。そして本人は休まない。休むと不正が見つかるからだ。防ぐ基本は、発注・検収・記帳・支払いの担当を分ける**職務分掌**と、定期的な担当替えや連続休暇である。
::

::real 証ひょうは「紙の束」から「データ」へ
2023年10月に始まったインボイス制度では、仕入れにかかった消費税（仮払消費税）を差し引くために、登録番号などを記載した適格請求書の保存が必要になった。登録番号は、国税庁の公表サイトで誰でも事業者の名前と所在地を確かめられる。架空の取引先の請求書には、正しい登録番号を書けない。インボイス制度は不正を見つけるための制度ではないが、証ひょうに「外部で確かめられる番号」が1つ増えたことは、照合の網の目を細かくした。
さらに電子帳簿保存法の改正で、2024年1月1日以降、メールやWebで受け取った請求書などの電子データは、電子データのまま保存することが義務づけられた。発注・納品・請求のデータをシステムが自動で突き合わせる3点照合は、いまやソフトウェアの標準機能になりつつある。
::note
出典：[弥生「電子帳簿保存法の宥恕期間の終了」](https://www.yayoi-kk.co.jp/denchoho/oyakudachi/yujokikan-enki)、[マイナビニュース（2024年1月4日）](https://news.mynavi.jp/techplus/article/20240104-2853373/)
::

::cfo 人を増やさずに、どの仕組みを入れるか ― 何を物差しにするか
横領事件を受けて、大森は佐伯に言った。
大森：「二度と同じことが起きない仕組みを作ってほしい。ただし、経理部の人数は増やせない」
**前提**
- 今回の不正は、架空の取引先を登録し、偽の請求書で支払うものだった
- 支払いは月に約800件。新しい取引先の登録は、月に3件ほど
- 経理部は5人。3点照合を全件に行うと、1人分の仕事が増える
**考えるときの視点**
- 今回の不正は、どの段階を通り抜けたか
- 件数の少ない入り口と、件数の多い支払い。どちらを押さえるほうが手間あたりの効き目が大きいか
::choice A. 新しい取引先の登録に、別の人の承認を入れる
**◎ 月3件の入り口を押さえるだけで、今回の手口の出発点をふさいでいる。**手間がほとんど増えず、人を増やさずに続けられる。照合は、新しい取引先や高額の支払いに絞って組み合わせればさらに強い。
::
::choice B. 3点照合を、すべての支払いに入れる
**○ 効き目は大きいが、1人分の仕事が増え、人を増やせない条件と合わない。**続かない仕組みは、やがて形だけになる。
::
::choice C. すべての支払いを、社長が承認する
**△ 月800件を社長が見ることはできず、形だけの承認になる。**偽の請求書は、社長が見ても見抜けない。
::
::choice D. 経理部員に、年1回の連続5日の休暇を義務づける
**○ 安くて効き目のある仕組みだが、不正が見つかるのは休んだときだけだ。**入り口をふさぐ仕組みと組み合わせたい。
::
::answer 考え方の例を見る
- **どこを通り抜けたかを考える**：今回の不正は、取引先の登録から始まった
- **手間あたりの効き目で比べる**：件数の少ない入り口を押さえると、少ない手間で多くを防げる
- **続けられるかを確かめる**：人を増やせない条件で、仕組みが形だけにならないか
::

::exam 帳簿・伝票・証ひょうの急所
- 補助簿の選択：まず仕訳を書き、勘定科目ごとに補助簿を当てはめる。仕入・売上は「仕入帳／売上帳」と「商品有高帳」の2つに記入。未払金・未収入金・消耗品費などには補助簿がない。
- 入金伝票は借方が現金、出金伝票は貸方が現金。現金を含まない取引は振替伝票。
- 一部現金取引は「分解する方法」と「全額を掛けとみなす方法」。入金伝票（出金伝票）の相手科目が「売掛金（買掛金）」なら、全額を掛けとみなす方法。
- 仕訳日計表の合計は総勘定元帳へ。売掛金元帳・買掛金元帳へは個々の伝票から転記する。
- 証ひょう問題では、消費税（税抜方式）、付随費用、未払金と買掛金の区別が同時に問われやすい。
- 訂正仕訳は「逆仕訳＋正しい仕訳」を合算して相殺。金額の誤りは差額だけを修正する。
::

::next 紙の伝票から、デジタルの「証跡」へ
いまは請求書の多くが電子データで届き、会計システムが自動で仕訳を作る。上場企業には、財務報告に関する内部統制を経営者が評価し、監査人がそれを監査する制度（J-SOX）がある。「誰が、いつ、何を根拠に、どの仕訳を承認したか」という**証跡**を残すことは、会社の数字の信頼性を外部に証明する技術なのである。
::

::summary
- 帳簿は主要簿（仕訳帳・総勘定元帳）と補助簿（補助記入帳・補助元帳）からなる
- 補助簿の選択は「仕訳を書き、勘定科目ごとに対応する帳簿を探す」
- 3伝票制：入金伝票（借方は現金）、出金伝票（貸方は現金）、振替伝票（現金なし）。一部現金取引は2つの起票方法がある
- 仕訳日計表で1日分の伝票を集計し、合計を総勘定元帳に転記する
- 証ひょう（請求書・領収書・通帳など）にもとづいて仕訳を起こす。証ひょうの照合は不正を防ぐ網になる
- 訂正仕訳は「逆仕訳＋正しい仕訳」を合算して相殺する
::
