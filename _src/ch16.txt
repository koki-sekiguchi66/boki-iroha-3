## 帳簿の体系 ― 主要簿と補助簿

これまでの章で、さまざまな帳簿が登場した。ここで全体を整理しておこう。

::table 帳簿の体系
| 分類 | 帳簿 | 役割 |
| 主要簿 | 仕訳帳 | すべての取引を日付順に仕訳する |
| 主要簿 | 総勘定元帳 | すべての取引を勘定科目ごとに集計する |
| 補助記入帳 | 現金出納帳・当座預金出納帳・小口現金出納帳 | 現金・預金の入出金の明細を記録する |
| 補助記入帳 | 仕入帳・売上帳 | 仕入・売上の取引の明細を記録する |
| 補助記入帳 | 受取手形記入帳・支払手形記入帳 | 手形の明細を記録する |
| 補助元帳 | 売掛金元帳・買掛金元帳 | 取引先ごとの売掛金・買掛金を記録する |
| 補助元帳 | 商品有高帳 | 商品の種類ごとの受入・払出・残高を記録する |
| 補助元帳 | 固定資産台帳 | 固定資産を1つずつ管理する |
::

主要簿は、すべての取引を記録する「骨格」だ。補助簿は、特定の取引や勘定の明細を記録する「詳細」である。補助簿のうち、取引の明細を発生順に記録するものを**補助記入帳**、特定の勘定の内訳を項目別に記録するものを**補助元帳**という。

## 取引ごとに、どの補助簿に記入するか

試験の第2問では、「この取引は、どの補助簿に記入されるか」を問う問題がよく出る。解き方のコツは、**まず仕訳を書き、仕訳に登場した勘定科目ごとに対応する補助簿を探す**ことだ。

::table 勘定科目と補助簿の対応
| 仕訳に登場する勘定科目 | 記入する補助簿 |
| 現金 | 現金出納帳 |
| 当座預金 | 当座預金出納帳 |
| 小口現金 | 小口現金出納帳 |
| 仕入 | 仕入帳 ＋ 商品有高帳 |
| 売上 | 売上帳 ＋ 商品有高帳 |
| 売掛金 | 売掛金元帳 |
| 買掛金 | 買掛金元帳 |
| 受取手形 | 受取手形記入帳 |
| 支払手形 | 支払手形記入帳 |
| 建物・備品・車両運搬具・土地 | 固定資産台帳 |
::

::example 補助簿の選択
<!-- notry -->

## 伝票 ― 仕訳を「1取引1枚」の紙に書く

実務では、仕訳帳に直接仕訳を書く代わりに、取引ごとに**伝票**という紙片（またはシステムの入力画面）に仕訳を書くことが多い。伝票なら、1枚ずつ担当者が分担して作成し、上司が承認し、証拠書類と一緒に保管できる。
3級では、3種類の伝票を使う**3伝票制**を学ぶ。

::table 3伝票制
| 伝票 | 使う取引 | 記入のしかた |
| 入金伝票 | 現金が増える取引 | 借方は必ず「現金」なので、貸方の勘定科目と金額だけを書く |
| 出金伝票 | 現金が減る取引 | 貸方は必ず「現金」なので、借方の勘定科目と金額だけを書く |
| 振替伝票 | 現金が動かない取引 | 借方・貸方の両方を書く（ふつうの仕訳と同じ） |
::

::table 起票の例（おかわり堂・本部）
| 取引 | 伝票 | 記入する内容 |
| 学会の弁当代100,000円を現金で受け取った | 入金伝票 | 売上 100,000 |
| 店舗の消耗品5,000円を現金で購入した | 出金伝票 | 消耗品費 5,000 |
| 牛肉300,000円を掛けで仕入れた | 振替伝票 | 仕入 300,000 ／ 買掛金 300,000 |
::

### 一部現金取引 ― 2つの起票方法

1つの取引の中に、現金の部分とそうでない部分が混ざっていることがある。たとえば「商品300,000円を売り上げ、100,000円は現金で受け取り、残額は掛けとした」。これを**一部現金取引**という。起票の方法は2つある。

::example 一部現金取引の起票
商品300,000円を売り上げ、代金のうち100,000円は現金で受け取り、残額は掛けとした。2つの方法で起票しなさい。
::answer
**方法①：取引を分解して起票する**
現金で受け取った部分と、掛けの部分に分けて、2枚の伝票を書く。
::journal 入金伝票（借方は現金）
現金 100,000 | 売上 100,000
::
::journal 振替伝票
売掛金 200,000 | 売上 200,000
::
**方法②：いったん全額を掛け取引とみなして起票する**
全額をいったん掛けで売り上げたと考え、その直後に掛け代金の一部を現金で回収したと考える。
::journal 振替伝票（全額を掛けとみなす）
売掛金 300,000 | 売上 300,000
::
::journal 入金伝票（掛け代金の一部を回収）
現金 100,000 | 売掛金 100,000
::
どちらの方法でも、2枚の伝票を合計すると「現金100,000・売掛金200,000／売上300,000」になる。試験では、すでに記入されている伝票（たとえば入金伝票の科目が「売上」か「売掛金」か）から、どちらの方法で起票したのかを判断させる問題が出る。
::
::

### 仕訳日計表 ― 1日分の伝票を集計する

伝票は1日に何十枚、何百枚と作られる。1枚ずつ総勘定元帳に転記していては手間がかかりすぎる。そこで、1日分の伝票を勘定科目ごとに集計した**仕訳日計表**を作り、その合計額を総勘定元帳にまとめて転記する。

::example 仕訳日計表の作成
ある日の伝票は次の5枚だった。仕訳日計表を作成しなさい。
入金伝票：売上 120,000　／　入金伝票：売掛金 80,000　／　出金伝票：仕入 50,000　／　出金伝票：旅費交通費 3,000　／　振替伝票：仕入 200,000 ／ 買掛金 200,000
::answer
::table sum 仕訳日計表
| 借方 | 勘定科目 | 貸方 |
| 200,000 | 現金 | 53,000 |
|  | 売掛金 | 80,000 |
|  | 買掛金 | 200,000 |
|  | 売上 | 120,000 |
| 250,000 | 仕入 |  |
| 3,000 | 旅費交通費 |  |
|= 453,000 | 合計 | 453,000 |
::
- 現金の借方は、入金伝票の合計（120,000＋80,000）。貸方は、出金伝票の合計（50,000＋3,000）。
- 仕入の借方は、出金伝票50,000円と振替伝票200,000円の合計。
- 借方合計と貸方合計は必ず一致する（貸借平均の原理）。
::
::

::point 仕訳日計表から、どこへ転記するか
仕訳日計表の合計額は**総勘定元帳**へ転記する。一方、売掛金元帳・買掛金元帳などの補助元帳へは、取引先ごとの明細が必要なので、**個々の伝票から直接**転記する。この2つのルートを区別しよう。
::

## 証ひょう ― 取引の「証拠」から仕訳を起こす

**証ひょう**（しょうひょう）とは、取引の事実を証明する書類のことだ。納品書、請求書、領収書、振込依頼書、銀行の通帳や当座勘定照合表などがある。経理担当者は、証ひょうにもとづいて仕訳を起こす。証ひょうのない仕訳は、原則として認められない。

::table 主な証ひょう
| 証ひょう | 内容 | 仕訳のヒント |
| 納品書 | 商品やサービスを納めたことを示す | 仕入・売上の数量と金額 |
| 請求書 | 代金の支払いを求める | 掛けの金額、消費税、支払期日 |
| 領収書 | 代金を受け取ったことを示す | 現金などで支払った費用 |
| 振込依頼書 | 銀行での振込を依頼する | 支払いと振込手数料 |
| 通帳・当座勘定照合表 | 口座の入出金の記録 | 入金・引落しの内容 |
::

::example 請求書から仕訳を起こす
おかわり堂は、厨房機器メーカーから業務用冷凍庫を購入し、次の請求書を受け取った。代金は翌月末に支払う。消費税は税抜方式で処理する。
::table 請求書（株式会社おかわり堂 御中）
| 品名 | 数量 | 単価 | 金額 |
| 業務用冷凍庫 FZ-900 | 1 | 600,000 | 600,000 |
| 配送・設置費 | 1 | 20,000 | 20,000 |
|  |  | 小計 | 620,000 |
|  |  | 消費税（10%） | 62,000 |
|= |  | 合計 | 682,000 |
::
::answer
::journal 配送・設置費は取得原価に含める。後払いなので未払金
備品 620,000 | 未払金 682,000
仮払消費税 62,000 |
::
冷凍庫は商品ではなく備品なので、買掛金ではなく**未払金**（第9章）。配送・設置費は付随費用として備品の取得原価に含める（第12章）。消費税は仮払消費税（第14章）。1枚の請求書に、これまでの章の知識が詰まっている。
::
::

::example 通帳の記録から仕訳を起こす
洛北ミートの普通預金の通帳に、次の記録があった。
::table 普通預金 入出金明細
| 日付 | 摘要 | お支払金額 | お預り金額 |
| 10/31 | 振込　ヤキニクホムラ |  | 720,000 |
| 10/31 | 振込　チクサンカイシャB | 600,000 |  |
| 10/31 | 振込手数料 | 660 |  |
::
焼肉店「炎」は得意先（売掛金）、畜産会社Bは仕入先（買掛金）である。
::answer
::journal 得意先からの入金は売掛金の回収
普通預金 720,000 | 売掛金 720,000
::
::journal 仕入先への振込と、振込手数料
買掛金 600,000 | 普通預金 600,660
支払手数料 660 |
::

## 訂正仕訳 ― 間違えた仕訳の直し方

帳簿に誤った仕訳を記録してしまったことが分かったら、誤った記録を消しゴムで消したり、上書きしたりしてはいけない。誤りを正すための新たな仕訳、**訂正仕訳**を記録する。

::steps 訂正仕訳の3ステップ
誤った仕訳の「逆仕訳」を書く | 誤った記録を取り消す
正しい仕訳を書く | 本来あるべき記録を加える
2つを合算して、相殺できる部分を消す | 同じ勘定科目が借方と貸方にあれば相殺し、最小限の仕訳にまとめる
::

::example 訂正仕訳
次の誤りを訂正する仕訳をしなさい。
(1) 店舗用の冷蔵庫（備品）150,000円を掛けで購入した際に、「仕入／買掛金」と処理していた。
(2) 得意先から売掛金98,000円が普通預金に振り込まれた際に、金額を89,000円と記録していた。
::answer
**(1)**
::journal ① 誤った仕訳の逆仕訳
買掛金 150,000 | 仕入 150,000
::
::journal ② 正しい仕訳
備品 150,000 | 未払金 150,000
::
::journal ③ 訂正仕訳（①と②を合わせたもの。相殺できる科目はない）
備品 150,000 | 仕入 150,000
買掛金 150,000 | 未払金 150,000
::
**(2)** 正しい金額98,000円と、記録した89,000円の差額9,000円だけを追加すればよい。
::journal 訂正仕訳（不足していた9,000円を追加）
普通預金 9,000 | 売掛金 9,000
::
::
::

::point 訂正仕訳で迷ったら
金額だけの誤りなら「差額を追加・削除する」。勘定科目の誤りなら「逆仕訳＋正しい仕訳」で考え、同じ勘定科目が左右に出てきたら相殺する。迷ったら、必ず3ステップを紙に書くこと。
::

## 答え合わせ ― 3つの書類の「照合」が網になる

::solve 請求書はあった。だが「納品書」と「受入の記録」がなかった
佐伯が導入したルールは、シンプルなものだった。
「仕入代金を支払う前に、**発注書・納品書・請求書の3つ**と、**店舗の商品の受入記録**を突き合わせ、すべて一致したものだけを支払う」
木島が偽造したのは、請求書だけだった。架空の「丹波青果」は実在しないので、店舗には野菜が1箱も届いていない。当然、店舗が作成する納品書の控えもなければ、商品の受入記録もない。
導入から3か月後、照合を担当した新人が気づいた。「丹波青果さんの請求書だけ、どの店舗にも納品書がありません」。
3年間、不正が見つからなかったのは、**請求書の作成から支払いまでを、1人で完結できる仕組み**だったからだ。帳簿の数字の合計はいつも合っていた。架空の仕入れは、「仕入／普通預金」という形式的には完璧な仕訳として記録されていたからだ。
不正を暴いたのは、帳簿の数字ではない。**異なる部署が作る複数の証ひょうを照らし合わせる仕組み**だった。複式簿記が「2つの側面」で記録の誤りを見つけるように、証ひょうの照合は「複数の書類」で取引の嘘を見つける。
::

::danger 「1人に任せきり」が、不正の温床になる
横領や着服の多くは、特定の担当者が、取引の開始から記録、支払い、照合までを1人で行っている職場で起きる。長年の担当者ほど信頼され、誰もチェックしなくなる。そして、本人が休まない。休むと、代わりの担当者に不正が見つかってしまうからだ。
これを防ぐ基本が**職務分掌**だ。発注する人、検収する人、記帳する人、支払う人を分ける。1人で取引を完結させない。さらに、定期的な担当替えや、連続休暇の義務づけも有効だ。休暇中に別の担当者が業務を代行すれば、隠れた不正は表に出てくる。
::

::real 証ひょうは「紙の束」から「データ」へ
証ひょうの扱いは、この数年で大きく変わった。2023年10月に始まったインボイス制度では、仕入れにかかった消費税を差し引くために、登録番号などを記載した適格請求書（インボイス）の保存が必要になった。さらに電子帳簿保存法の改正で、メールやWebで受け取った請求書や領収書などの電子データは、2023年末で猶予期間が終わり、**2024年1月1日以降は電子データのまま保存すること**が完全に義務づけられた。印刷した紙だけを保存しても、正式な書類とは認められない。
証ひょうがデータになると、照合も機械で行えるようになる。発注データ、納品データ、請求データをシステムが自動で突き合わせ、一致しない支払いを止める。この章の3点照合は、いまやソフトウェアの標準機能になりつつある。ただし、取引先の登録や照合のルールを決めるのは人間だ。仕組みに穴があれば、データも嘘をつく。
::note
出典：[弥生「電子帳簿保存法の宥恕期間の終了」](https://www.yayoi-kk.co.jp/denchoho/oyakudachi/yujokikan-enki)、[マイナビニュース（2024年1月4日）](https://news.mynavi.jp/techplus/article/20240104-2853373/)
::

::cfo 人を増やさずに、1つだけ導入するなら ― どれが木島の手口を止められたか
横領事件を受けて、社長の大森から佐伯に依頼があった。「二度と同じことが起きない仕組みを作ってほしい。ただし、経理部の人数は増やせない」。まず1つだけ導入するとしたら、どれが最も効くか。木島の手口（架空の取引先の登録→偽の請求書→自分で振込）を1つずつたどって考えてほしい。
::choice A. 振込データを作る人と、銀行で振込を承認する人を分ける
**○ 有効だが、偽の請求書の前では弱い。**承認する人は、木島が作った振込データと、添付された請求書を見て判断する。請求書が本物そっくりなら、承認者は「丹波青果への支払い」をそのまま通してしまうだろう。1人で完結しなくなる意味は大きいが、承認者が請求書以外の証拠を見なければ、架空の取引は止まらない。
::
::choice B. 発注書・納品書（店舗の受入記録）・請求書の3点がそろわない支払いは、実行しない
**◎ 手口の「穴」を正面から突く。**偽造されたのは請求書だけで、店舗には野菜が1箱も届いていない。納品書と受入記録は、仕入れを担当しない店舗のスタッフが作るので、木島1人では偽造できない。3点照合なら、架空の取引先だけでなく、実在する業者の請求額を水増しする手口も、数量や金額のずれとして見つけられる。実際にこの不正を暴いたのも、この照合だった。
::
::choice C. 新しい取引先の登録と、振込先口座の変更は、支払担当以外の人が承認する
**○ 入口を固める有力な手。**架空の「丹波青果」の登録そのものを止められる。ただし、すでに登録されている実在の取引先を使った水増し請求や、正規の取引先の口座を不正に書き換える手口には、別の守りが要る。Bと組み合わせたい。
::
::choice D. 経理部の全員に、年1回5日以上の連続休暇を義務づける
**○ じわじわ効くが、即効性はない。**木島が休めば、代わりの担当者が支払いを処理する。そのとき「丹波青果の担当者に連絡が取れない」といった違和感から、不正が見つかる可能性は高い。15年間休まなかったこと自体が、危険のサインだった。ただし、見つかるのは休暇のときだけで、それまでの被害は防げない。
::
::answer 考え方の例を見る
ポイントは、「人を増やす」のではなく「1人で完結できない流れを作る」ことだ。木島の手口を段階ごとに分けると、どの仕組みがどこで効くかが見える。
::table 手口の段階と、それを止める仕組み
| 手口の段階 | 止める仕組み |
| 架空の取引先を登録する | C 取引先の登録・口座変更の承認 |
| 偽の請求書で支払いを依頼する | B 3点照合（納品書・受入記録との突き合わせ） |
| 自分で振込を実行する | A 振込の二重承認 |
| 長年、誰にも業務を見せない | D 連続休暇と担当替え |
::
1つだけ選ぶならBだが、実際の会社では4つを重ねる。どれか1つが破られても、次の仕組みが止めるようにしておく。内部統制の目的は、社員を疑うことではない。**誠実な社員が、疑われずに済む仕組みを作ること**である。
::
::

::exam 帳簿・伝票・証ひょうの急所
- 補助簿の選択：まず仕訳を書き、勘定科目ごとに補助簿を当てはめる。仕入・売上は「仕入帳／売上帳」と「商品有高帳」の2つに記入。未払金・未収入金・消耗品費などには補助簿がない。
- 入金伝票は借方が現金、出金伝票は貸方が現金。現金を含まない取引は振替伝票。
- 一部現金取引は「分解する方法」と「全額を掛けとみなす方法」。入金伝票（出金伝票）の相手科目が「売掛金（買掛金）」なら、全額を掛けとみなす方法。
- 仕訳日計表の合計は総勘定元帳へ。売掛金元帳・買掛金元帳へは個々の伝票から転記する。
- 証ひょう問題では、消費税（税抜方式）、付随費用、未払金と買掛金の区別が同時に問われやすい。
- 訂正仕訳は「逆仕訳＋正しい仕訳」を合算して相殺。金額の誤りは差額だけを修正する。
::

::next 紙の伝票から、デジタルの「証跡」へ
現代の会社では、伝票や証ひょうの多くが電子化されている。請求書はPDFや電子データで届き、会計システムが自動で仕訳を作る。2023年には、消費税の仕入税額控除に適格請求書（インボイス）の保存を求める制度が始まり、電子帳簿保存法により、電子で受け取った請求書は電子のまま保存することが求められるようになった。
上場企業には、財務報告に関する内部統制を経営者が評価し、監査人がそれを監査する制度（いわゆるJ-SOX）がある。本章で学んだ3点照合や職務分掌は、まさにその中核だ。「誰が、いつ、何を根拠に、どの仕訳を承認したか」という**証跡**を残すこと。それは、不正を防ぐと同時に、会社の数字の信頼性を外部に証明する技術なのである。
::

::summary
- 帳簿は主要簿（仕訳帳・総勘定元帳）と補助簿（補助記入帳・補助元帳）からなる
- 補助簿の選択は「仕訳を書き、勘定科目ごとに対応する帳簿を探す」
- 3伝票制：入金伝票（借方は現金）、出金伝票（貸方は現金）、振替伝票（現金なし）。一部現金取引は2つの起票方法がある
- 仕訳日計表で1日分の伝票を集計し、合計を総勘定元帳に転記する
- 証ひょう（請求書・領収書・通帳など）にもとづいて仕訳を起こす。証ひょうの照合は不正を防ぐ網になる
- 訂正仕訳は「逆仕訳＋正しい仕訳」を合算して相殺する
