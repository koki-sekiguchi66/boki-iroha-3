その紙とは何だったのか？

発覚の翌日、所長室に呼ばれたのは一ノ瀬だった。扉の外まで、鴨川の低い声が聞こえた。「3年間、うちは何を見とったんや」。出てきた一ノ瀬は、ひよりの机の前で足を止めた。「よく気づきました。そして、私たちが見落としていたことも、よく見ておいてください」

## 帳簿の体系 ― 主要簿と補助簿

「なぜ3年間も見つからなかったのか。それを知るには、帳簿の全体像から確かめ直す必要があります」。一ノ瀬は、おかわり堂の帳簿の一覧を机に並べた。これまでの章で、さまざまな帳簿が登場した。ここで全体を整理しておこう。

::table 帳簿の体系
| 分類 | 帳簿 | 役割 |
| 主要簿 | 仕訳帳 | すべての取引を日付順に仕訳する |
| 主要簿 | 総勘定元帳 | すべての取引を勘定科目ごとに集計する |
| 補助記入帳 | 現金出納帳・当座預金出納帳・小口現金出納帳 | 現金・預金の入出金の明細を記録する |
| 補助記入帳 | 仕入帳・売上帳 | 仕入・売上の取引の明細を記録する |
| 補助記入帳 | 受取手形記入帳・支払手形記入帳 | 手形の明細を記録する |
| 補助元帳 | 売掛金元帳・買掛金元帳 | 取引先ごとの売掛金・買掛金を記録する |
| 補助元帳 | 商品有高帳 | 商品の種類ごとの受入・払出・残高を記録する |
| 補助元帳 | 固定資産台帳 | 固定資産を1つずつ管理する |
::

主要簿は、すべての取引を記録する「骨格」だ。補助簿は、特定の取引や勘定の明細を記録する「詳細」である。補助簿のうち、取引の明細を発生順に記録するものを**補助記入帳**、特定の勘定の内訳を項目別に記録するものを**補助元帳**という。

## 取引ごとに、どの補助簿に記入するか

試験の第2問では、「この取引は、どの補助簿に記入されるか」を問う問題がよく出る。解き方のコツは、**まず仕訳を書き、仕訳に登場した勘定科目ごとに対応する補助簿を探す**ことだ。

::table 勘定科目と補助簿の対応
| 仕訳に登場する勘定科目 | 記入する補助簿 |
| 現金 | 現金出納帳 |
| 当座預金 | 当座預金出納帳 |
| 小口現金 | 小口現金出納帳 |
| 仕入 | 仕入帳 ＋ 商品有高帳 |
| 売上 | 売上帳 ＋ 商品有高帳 |
| 売掛金 | 売掛金元帳 |
| 買掛金 | 買掛金元帳 |
| 受取手形 | 受取手形記入帳 |
| 支払手形 | 支払手形記入帳 |
| 建物・備品・車両運搬具・土地 | 固定資産台帳 |
::

::example 補助簿の選択
<!-- notry -->
次の取引が記入される補助簿をすべて答えなさい。
(1) 商品400,000円を仕入れ、代金のうち半額は約束手形を振り出し、残額は掛けとした。
(2) 商品250,000円を売り上げ、代金は得意先振出の小切手で受け取った。
(3) 掛けで仕入れた商品のうち、20,000円を品違いのため返品した。
(4) 業務用の冷蔵庫300,000円を購入し、代金は翌月末に支払うこととした。
::checks 取引(1)〜(4)のそれぞれについて、記入する補助簿の欄をすべてチェックしよう。まず頭の中で仕訳を書くのがコツだ。
| 補助簿 | (1) | (2) | (3) | (4) |
| 現金出納帳 |  | ✓ |  |  |
| 当座預金出納帳 |  |  |  |  |
| 仕入帳 | ✓ |  | ✓ |  |
| 売上帳 |  | ✓ |  |  |
| 商品有高帳 | ✓ | ✓ | ✓ |  |
| 売掛金元帳 |  |  |  |  |
| 買掛金元帳 | ✓ |  | ✓ |  |
| 受取手形記入帳 |  |  |  |  |
| 支払手形記入帳 | ✓ |  |  |  |
| 固定資産台帳 |  |  |  | ✓ |
::
::answer
::journal (1)
仕入 400,000 | 支払手形 200,000
 | 買掛金 200,000
::
→ **仕入帳、商品有高帳、支払手形記入帳、買掛金元帳**
::journal (2)
現金 250,000 | 売上 250,000
::
→ **現金出納帳、売上帳、商品有高帳**
::journal (3)
買掛金 20,000 | 仕入 20,000
::
→ **仕入帳、商品有高帳、買掛金元帳**（返品も、仕入帳と商品有高帳に記入する）
::journal (4)
備品 300,000 | 未払金 300,000
::
→ **固定資産台帳**のみ（未払金には補助簿がない）
::trap
見落としやすい点が3つある。
- 商品有高帳には、仕入・売上・返品のすべてを記入する
- 他人が振り出した小切手は現金なので、当座預金出納帳ではなく現金出納帳に記入する
- 備品の購入は、仕入帳には記入しない。仕入帳に記入するのは、商品の仕入だけだ
::

## 伝票 ― 仕訳を「1取引1枚」の紙に書く

実務では、仕訳帳に直接仕訳を書く代わりに、取引ごとに**伝票**という紙片（またはシステムの入力画面）に仕訳を書くことが多い。伝票なら、1枚ずつ担当者が分担して作成し、上司が承認し、証拠書類と一緒に保管できる。
3級では、3種類の伝票を使う**3伝票制**を学ぶ。

::table 3伝票制
| 伝票 | 使う取引 | 記入のしかた |
| 入金伝票 | 現金が増える取引 | 借方は必ず「現金」なので、貸方の勘定科目と金額だけを書く |
| 出金伝票 | 現金が減る取引 | 貸方は必ず「現金」なので、借方の勘定科目と金額だけを書く |
| 振替伝票 | 現金が動かない取引 | 借方・貸方の両方を書く（ふつうの仕訳と同じ） |
::

::table 起票の例（おかわり堂・本部）
| 取引 | 伝票 | 記入する内容 |
| 学会の弁当代100,000円を現金で受け取った | 入金伝票 | 売上 100,000 |
| 店舗の消耗品5,000円を現金で購入した | 出金伝票 | 消耗品費 5,000 |
| 牛肉300,000円を掛けで仕入れた | 振替伝票 | 仕入 300,000 ／ 買掛金 300,000 |
::

### 一部現金取引 ― 2つの起票方法

1つの取引の中に、現金の部分とそうでない部分が混ざっていることがある。たとえば「商品300,000円を売り上げ、100,000円は現金で受け取り、残額は掛けとした」。これを**一部現金取引**という。起票の方法は2つある。

::example 一部現金取引の起票
商品300,000円を売り上げ、代金のうち100,000円は現金で受け取り、残額は掛けとした。方法①（取引を分解する方法）と方法②（いったん全額を掛け取引とみなす方法）の2つで起票し、それぞれ2枚の伝票の内容を仕訳の形で答えなさい。
::answer
**方法①：取引を分解して起票する**
現金で受け取った部分と、掛けの部分に分けて、2枚の伝票を書く。
::journal 【方法① 1枚目（現金で受け取った部分）】入金伝票（借方は現金）
現金 100,000 | 売上 100,000
::
::journal 【方法① 2枚目（掛けの部分）】振替伝票
売掛金 200,000 | 売上 200,000
::
**方法②：いったん全額を掛け取引とみなして起票する**
全額をいったん掛けで売り上げたと考え、その直後に掛け代金の一部を現金で回収したと考える。
::journal 【方法② 1枚目（全額を掛けとみなす）】振替伝票
売掛金 300,000 | 売上 300,000
::
::journal 【方法② 2枚目（代金の一部を現金で回収）】入金伝票
現金 100,000 | 売掛金 100,000
::
どちらの方法でも、2枚の伝票を合計すると「現金100,000・売掛金200,000／売上300,000」になる。試験では、すでに記入されている伝票（たとえば入金伝票の科目が「売上」か「売掛金」か）から、どちらの方法で起票したのかを判断させる問題が出る。
::trap
2つの方法を混ぜないこと。入金伝票に「売上 100,000」、振替伝票に「売掛金 300,000／売上 300,000」と書くと、売上が400,000円になってしまう。
見分ける手がかりは、入金伝票の相手科目だ。「売上」なら方法①、「売掛金」なら方法②である。
::
::
::

### 仕訳日計表 ― 1日分の伝票を集計する

伝票は1日に何十枚、何百枚と作られる。1枚ずつ総勘定元帳に転記していては手間がかかりすぎる。そこで、1日分の伝票を勘定科目ごとに集計した**仕訳日計表**を作り、その合計額を総勘定元帳にまとめて転記する。

::example 仕訳日計表の作成
ある日の伝票は次の5枚だった。仕訳日計表を作成しなさい。
入金伝票：売上 120,000　／　入金伝票：売掛金 80,000　／　出金伝票：仕入 50,000　／　出金伝票：旅費交通費 3,000　／　振替伝票：仕入 200,000 ／ 買掛金 200,000
::answer
::table sum 仕訳日計表
| 借方 | 勘定科目 | 貸方 |
| 200,000 | 現金 | 53,000 |
|  | 売掛金 | 80,000 |
|  | 買掛金 | 200,000 |
|  | 売上 | 120,000 |
| 250,000 | 仕入 |  |
| 3,000 | 旅費交通費 |  |
|= 453,000 | 合計 | 453,000 |
::
- 現金の借方は、入金伝票の合計（120,000＋80,000）。貸方は、出金伝票の合計（50,000＋3,000）。
- 仕入の借方は、出金伝票50,000円と振替伝票200,000円の合計。
- 借方合計と貸方合計は必ず一致する（貸借平均の原理）。
::trap
入金伝票と出金伝票には、「現金」という文字が書かれていない。現金の借方に入金伝票の合計、貸方に出金伝票の合計を集計するのを忘れないこと。
振替伝票は、現金の動かない取引だ。現金の行には足さない。
::
::
::

::point 仕訳日計表から、どこへ転記するか
仕訳日計表の合計額は**総勘定元帳**へ転記する。一方、売掛金元帳・買掛金元帳などの補助元帳へは、取引先ごとの明細が必要なので、**個々の伝票から直接**転記する。この2つのルートを区別しよう。
::

## 証ひょう ― 取引の「証拠」から仕訳を起こす

いよいよ、ひよりが気づいた「紙」の話だ。**証ひょう**（しょうひょう）とは、取引の事実を証明する書類のことだ。納品書、請求書、領収書、振込依頼書、銀行の通帳や当座勘定照合表などがある。経理担当者は、証ひょうにもとづいて仕訳を起こす。証ひょうのない仕訳は、原則として認められない。

::table 主な証ひょう
| 証ひょう | 内容 | 仕訳のヒント |
| 納品書 | 商品やサービスを納めたことを示す | 仕入・売上の数量と金額 |
| 請求書 | 代金の支払いを求める | 掛けの金額、消費税、支払期日 |
| 領収書 | 代金を受け取ったことを示す | 現金などで支払った費用 |
| 振込依頼書 | 銀行での振込を依頼する | 支払いと振込手数料 |
| 通帳・当座勘定照合表 | 口座の入出金の記録 | 入金・引落しの内容 |
::

::example 請求書から仕訳を起こす
おかわり堂は、厨房機器メーカーから業務用冷凍庫を購入し、次の請求書を受け取った。代金は翌月末に支払う。消費税は税抜方式で処理する。
::table 請求書（株式会社おかわり堂 御中）
| 品名 | 数量 | 単価 | 金額 |
| 業務用冷凍庫 FZ-900 | 1 | 600,000 | 600,000 |
| 配送・設置費 | 1 | 20,000 | 20,000 |
|  |  | 小計 | 620,000 |
|  |  | 消費税（10%） | 62,000 |
|= |  | 合計 | 682,000 |
::
::answer
::journal 配送・設置費は取得原価に含める。後払いなので未払金
備品 620,000 | 未払金 682,000
仮払消費税 62,000 |
::
冷凍庫は商品ではなく備品なので、買掛金ではなく**未払金**（第9章）。配送・設置費は付随費用として備品の取得原価に含める（第12章）。消費税は仮払消費税（第14章）。1枚の請求書に、これまでの章の知識が詰まっている。
::trap
備品の取得原価に、消費税を含めないこと。税抜方式では、取得原価は620,000円、消費税62,000円は仮払消費税として分ける。
一方、未払金は、相手に実際に支払う税込の682,000円になる。
::
::
::

::example 通帳の記録から仕訳を起こす
洛北ミートの普通預金の通帳に、次の記録があった。
::table 普通預金 入出金明細
| 日付 | 摘要 | お支払金額 | お預り金額 |
| 10/31 | 振込　ヤキニクホムラ |  | 720,000 |
| 10/31 | 振込　チクサンカイシャB | 600,000 |  |
| 10/31 | 振込手数料 | 660 |  |
::
焼肉店「炎」は得意先（売掛金）、畜産会社Bは仕入先（買掛金）である。
::answer
::journal 【10/31 ヤキニクホムラからの入金】得意先からの入金は売掛金の回収
普通預金 720,000 | 売掛金 720,000
::
::journal 【10/31 チクサンカイシャBへの振込と手数料】仕入先への振込と、振込手数料
買掛金 600,000 | 普通預金 600,660
支払手数料 660 |
::
::trap
通帳の「お支払金額」は預金の減少（貸方）、「お預り金額」は預金の増加（借方）だ。左右を逆にしないこと。
振込手数料を買掛金に含めてはいけない。消える買掛金は、振り込んだ600,000円だけである。
::
::
::

## 訂正仕訳 ― 間違えた仕訳の直し方

帳簿に誤った仕訳を記録してしまったことが分かったら、誤った記録を消しゴムで消したり、上書きしたりしてはいけない。誤りを正すための新たな仕訳、**訂正仕訳**を記録する。

::steps 訂正仕訳の3ステップ
誤った仕訳の「逆仕訳」を書く | 誤った記録を取り消す
正しい仕訳を書く | 本来あるべき記録を加える
2つを合算して、相殺できる部分を消す | 同じ勘定科目が借方と貸方にあれば相殺し、最小限の仕訳にまとめる
::

::example 訂正仕訳
次の誤りを訂正する仕訳をしなさい。(1)は、①誤った仕訳の逆仕訳、②正しい仕訳、③①と②を合わせた訂正仕訳の3段階で答えること。
(1) 店舗用の冷蔵庫（備品）150,000円を掛けで購入した際に、「仕入／買掛金」と処理していた。
(2) 得意先から売掛金98,000円が普通預金に振り込まれた際に、金額を89,000円と記録していた。
::answer
**(1)**
::journal 【(1)① 逆仕訳】誤った仕訳の逆仕訳
買掛金 150,000 | 仕入 150,000
::
::journal 【(1)② 正しい仕訳】
備品 150,000 | 未払金 150,000
::
::journal 【(1)③ 訂正仕訳】①と②を合わせたもの。相殺できる科目はない
備品 150,000 | 仕入 150,000
買掛金 150,000 | 未払金 150,000
::
**(2)** 正しい金額98,000円と、記録した89,000円の差額9,000円だけを追加すればよい。
::journal 【(2) 訂正仕訳】不足していた9,000円を追加
普通預金 9,000 | 売掛金 9,000
::
::trap
(1)で、正しい仕訳を書き足すだけでは訂正にならない。誤って記録した仕入と買掛金が、帳簿に残ったままになる。必ず逆仕訳で取り消すこと。
(2)で、正しい金額の98,000円をもう一度計上しないこと。すでに89,000円は記録されているので、足りない9,000円だけを追加する。
::
::
::

::point 訂正仕訳で迷ったら
金額だけの誤りなら「差額を追加・削除する」。勘定科目の誤りなら「逆仕訳＋正しい仕訳」で考え、同じ勘定科目が左右に出てきたら相殺する。迷ったら、必ず3ステップを紙に書くこと。
::

## 答え合わせ ― 3つの書類の「照合」が網になる

::solve 請求書はあった。だが「納品書」と「受入の記録」がなかった
佐伯が導入したルールは、シンプルなものだった。
「仕入代金を支払う前に、**発注書・納品書・請求書の3つ**と、**店舗の商品の受入記録**を突き合わせ、すべて一致したものだけを支払う」
木島が偽造したのは、請求書だけだった。架空の「丹波青果」は実在しないので、店舗には野菜が1箱も届いていない。当然、店舗が作成する納品書の控えもなければ、商品の受入記録もない。
佐伯は、この照合を月次巡回のときに一緒に確かめてほしいと、鴨川会計事務所に頼んでいた。導入から3か月後、照合を手伝っていたひよりが気づいた。「丹波青果さんの請求書だけ、どの店舗にも納品書がありません」。
ひよりは、念のため丹波青果の住所を地図で調べた。亀岡市内の、田んぼの真ん中の空き地だった。
3年間、不正が見つからなかったのは、**請求書の作成から支払いまでを、1人で完結できる仕組み**だったからだ。帳簿の数字の合計はいつも合っていた。架空の仕入れは、「仕入／普通預金」という形式的には完璧な仕訳として記録されていたからだ。
不正を暴いたのは、帳簿の数字ではない。**異なる部署が作る複数の証ひょうを照らし合わせる仕組み**だった。複式簿記が「2つの側面」で記録の誤りを見つけるように、証ひょうの照合は「複数の書類」で取引の嘘を見つける。
::

木島は、佐伯に呼ばれた会議室で、すべてを認めた。最初は、親の介護費用が足りなかった1回だけのつもりだったという。2回目からは、「誰も見ていない」ことに慣れていった。
ひよりは、所長が最初の日に言った言葉を思い出していた。帳簿は会社の日記。嘘を書けば、いつか自分が読む。

::danger 「1人に任せきり」が、不正の温床になる
横領や着服の多くは、特定の担当者が、取引の開始から記録、支払い、照合までを1人で行っている職場で起きる。長年の担当者ほど信頼され、誰もチェックしなくなる。そして、本人が休まない。休むと、代わりの担当者に不正が見つかってしまうからだ。
これを防ぐ基本が**職務分掌**だ。発注する人、検収する人、記帳する人、支払う人を分ける。1人で取引を完結させない。さらに、定期的な担当替えや、連続休暇の義務づけも有効だ。休暇中に別の担当者が業務を代行すれば、隠れた不正は表に出てくる。
::

::real 証ひょうは「紙の束」から「データ」へ
証ひょうの扱いは、この数年で大きく変わった。2023年10月に始まったインボイス制度では、仕入れにかかった消費税を差し引くために、登録番号などを記載した適格請求書（インボイス）の保存が必要になった。さらに電子帳簿保存法の改正で、メールやWebで受け取った請求書や領収書などの電子データは、2023年末で猶予期間が終わり、**2024年1月1日以降は電子データのまま保存すること**が完全に義務づけられた。印刷した紙だけを保存しても、正式な書類とは認められない。
**この章の道具で読む ― インボイスの登録番号は、架空の取引先を見つけられたか**
インボイス制度のもとで、丹波青果からの仕入（税込33万円）を正しく記録すると、次の仕訳になる（税抜方式）。

::journal 適格請求書（インボイス）にもとづいて、仕入代金を振り込んだ
仕入 300,000 | 普通預金 330,000
仮払消費税 30,000 |
::

この仕訳の借方の「仮払消費税3万円」を差し引くには、請求書に、税務署から交付された**登録番号**が書かれていなければならない（第14章）。そして登録番号は、国税庁の公表サイトで、誰でも事業者の名前と所在地を確かめられる。
木島が偽造した請求書に登録番号がなければ、仮払消費税は差し引けず、経理の誰かが「この取引先はなぜインボイスを出さないのか」と気づくきっかけになる。架空の番号を書けば、公表サイトで照会した瞬間に、名前が一致しない。インボイス制度は不正を見つけるための制度ではないが、証ひょうに「外部で確かめられる番号」が1つ増えたことは、照合の網の目を細かくした。
証ひょうがデータになると、照合も機械で行えるようになる。発注データ、納品データ、請求データをシステムが自動で突き合わせ、一致しない支払いを止める。この章の3点照合は、いまやソフトウェアの標準機能になりつつある。ただし、取引先の登録や照合のルールを決めるのは人間だ。仕組みに穴があれば、データも嘘をつく。
::note
出典：[弥生「電子帳簿保存法の宥恕期間の終了」](https://www.yayoi-kk.co.jp/denchoho/oyakudachi/yujokikan-enki)、[マイナビニュース（2024年1月4日）](https://news.mynavi.jp/techplus/article/20240104-2853373/)
::

::cfo 人を増やさずに、どの仕組みを入れるか ― 防げる損失と、かかる時間
横領事件を受けて、社長の大森から佐伯に依頼があった。佐伯は、その検討を鴨川会計事務所にも頼んだ。3年間見落としていた事務所にとって、それは借りを返す仕事でもあった。「二度と同じことが起きない仕組みを作ってほしい。ただし、経理部の人数は増やせない」
経理部が新しい仕組みに使える時間は、**月20時間まで**だ。木島の不正を暴いた3点照合も、いまは佐伯とひよりが手作業で行っていて、続けるなら経理部の作業になる。支払いをめぐる不正やミスには、次の4つの手口がある。
- ① 架空の取引先を登録し、そこへ支払う（木島の手口）
- ② 実在の取引先の請求額を水増しし、差額を受け取る
- ③ 取引先の振込口座を不正に書き換える（取引先を装ったメールによる変更依頼を含む）
- ④ 同じ請求書に二重に支払う（ミス）
::table 導入できる仕組み
| 仕組み | 月の作業時間 | 止められる手口 |
| 振込データを作る人と、振込を承認する人を分ける | 5時間 | ④（承認のときに重複に気づく） |
| 発注書・納品書（店舗の受入記録）・請求書の3点照合（手作業） | 18時間 | ①②④ |
| 3点照合を、店舗の受入記録をPOSから自動で取り込む形にする（初期費用80万円） | 10時間 | ①②④ |
| 取引先の新規登録と口座の変更は支払担当以外が承認し、変更のときは取引先に電話で確かめる | 3時間 | ①③ |
::
次の視点で考えてから選んでほしい。
- それぞれの仕組みは、4つの手口の**どれを止め、どれを素通りさせるか**
- 1つの仕組みですべてを止められないなら、**どう重ねれば穴がふさがるか**
- 時間の上限を超えるとき、諦めるのか、**作業そのものを減らす**方法はないか
::choice A. 振込データの作成と承認を分ける（月5時間）
**△ 必要な仕組みだが、防げるのはミスだけ。**承認する人は、木島が作った振込データと、添付された請求書を見て判断する。請求書が本物そっくりなら、架空の取引先への支払いもそのまま通ってしまう。止められるのは④の二重払いだけだ。
::
::choice B. 3点照合を、手作業のまま経理部の仕事にする（月18時間）
**○ 木島の手口は止まるが、時間を使い切る。**①②④を止めて、仮の設定では防げる損失は700＋300＋150＝1,150万円。だが月18時間を使うので、残りは2時間。③の口座の書き換えを止める仕組み（月3時間）を入れる余地がない。なりすましメールによる口座の変更依頼は、いま最も増えている手口の1つだ。
::
::choice C. 取引先の登録・口座変更の承認と、振込の承認の分離を組み合わせる（月8時間）
**○ 時間あたりの効果は高いが、水増しが素通りする。**①③④を止めて、仮の設定では防げる損失は700＋400＋150＝1,250万円。Bより多く、時間も少ない。入口（取引先の登録）を固めれば、木島のような架空の取引先は作れない。
だが、実在の取引先の請求を水増しする②は、請求書と実際に届いた商品を突き合わせなければ見つからない。
::
::choice D. 手作業の3点照合と、取引先の登録・口座変更の承認を組み合わせる（月21時間）
**× 4つの手口をすべて止められるが、時間の上限を超える。**仮の設定では、防げる損失は1,550万円と最大だ。だが月21時間で、上限の20時間を1時間超える。「1時間くらいなら」と無理をすれば、月末の繁忙期に照合が手抜きになり、仕組みが形だけになる。人を増やせない以上、上限は守らなければならない。
::
::choice E. 3点照合を自動化し（初期費用80万円）、取引先の登録・口座変更の承認と組み合わせる（月13時間）
**◎ 時間の上限の中で、4つの手口をすべて止める。**3点照合を自動にすれば、作業は月10時間に減る。取引先の登録・口座変更の承認（月3時間）と合わせて13時間で、上限に7時間の余裕が残る。止められるのは①②③④のすべてで、仮の設定では防げる損失は1,550万円。初期費用80万円を差し引いても、1年目に**1,470万円**を防げる。
余った7時間で、振込の承認の分離（月5時間）も加えれば、承認の段階で「もう1つの目」が入る。
::
::answer 考え方の例を見る
ひよりが同じ規模の会社の事例から見積もった、何も手を打たなかった場合の損失を**仮の設定**として試算してみよう。
::table 支払いをめぐる手口と、1年あたりの損失の見積り
| 手口 | 1年あたりの損失 |
| ① 架空の取引先を登録し、そこへ支払う（木島の手口） | 700万円 |
| ② 実在の取引先の請求額を水増しし、差額を受け取る | 300万円 |
| ③ 取引先の振込口座を不正に書き換える（取引先を装ったメールによる変更依頼を含む） | 400万円 |
| ④ 同じ請求書に二重に支払う（ミス） | 150万円 |
::
::table 組み合わせごとの効果（1年目）
| 組み合わせ | 月の作業時間 | 止められる手口 | 防げる損失（初期費用を差し引き） |
| A　振込の承認の分離 | 5時間 | ④ | 150万円 |
| B　手作業の3点照合 | 18時間 | ①②④ | 1,150万円 |
| C　取引先の承認＋振込の承認 | 8時間 | ①③④ | 1,250万円 |
| D　手作業の3点照合＋取引先の承認 | 21時間（上限超え） | ①②③④ | ― |
| E　自動の3点照合＋取引先の承認 | 13時間 | ①②③④ | 1,470万円 |
::
内部統制を設計するときは、次の順番で考える。
- **手口を分解する**：不正は1つの手口ではない。架空の取引先、水増し、口座の書き換え、ミス。それぞれ止める仕組みが違う。
- **仕組みごとに「どの手口を止めるか」を対応させる**：1つの仕組みですべてを止めることはできない。重ねて、穴をふさぐ。
- **限られた人手の中で、効果を最大にする**：作業時間が足りなければ、システムで作業そのものを減らす。人を増やせないことは、仕組みを諦める理由にはならない。
**さらに考えよう：仕組みを入れたら、それで終わりか？**
仕組みは、時間がたつと形だけになる。3点照合も、忙しい月末に「いつもの取引先だから」と確認を飛ばせば、穴が開く。だから実務では、仕組みが本当に動いているかを、別の人が定期的に抜き打ちで確かめる（**モニタリング**）。たとえば月に1回、支払いを10件選んで、3点がそろっていたかを確認する。仕組みを作る人と、仕組みを確かめる人を分けることも、内部統制の一部だ。
内部統制の目的は、社員を疑うことではない。**誠実な社員が、疑われずに済む仕組みを作ること**である。佐伯はEを採用し、余った時間で振込の承認の分離も加えた。翌年、取引先を装った「口座変更のお願い」のメールが届いたとき、電話で確かめた担当者が、それが偽物だと気づいた。
::

::exam 帳簿・伝票・証ひょうの急所
- 補助簿の選択：まず仕訳を書き、勘定科目ごとに補助簿を当てはめる。仕入・売上は「仕入帳／売上帳」と「商品有高帳」の2つに記入。未払金・未収入金・消耗品費などには補助簿がない。
- 入金伝票は借方が現金、出金伝票は貸方が現金。現金を含まない取引は振替伝票。
- 一部現金取引は「分解する方法」と「全額を掛けとみなす方法」。入金伝票（出金伝票）の相手科目が「売掛金（買掛金）」なら、全額を掛けとみなす方法。
- 仕訳日計表の合計は総勘定元帳へ。売掛金元帳・買掛金元帳へは個々の伝票から転記する。
- 証ひょう問題では、消費税（税抜方式）、付随費用、未払金と買掛金の区別が同時に問われやすい。
- 訂正仕訳は「逆仕訳＋正しい仕訳」を合算して相殺。金額の誤りは差額だけを修正する。
::

::next 紙の伝票から、デジタルの「証跡」へ
現代の会社では、伝票や証ひょうの多くが電子化されている。請求書はPDFや電子データで届き、会計システムが自動で仕訳を作る。2023年には、消費税の仕入税額控除に適格請求書（インボイス）の保存を求める制度が始まり、電子帳簿保存法により、電子で受け取った請求書は電子のまま保存することが求められるようになった。
上場企業には、財務報告に関する内部統制を経営者が評価し、監査人がそれを監査する制度（いわゆるJ-SOX）がある。本章で学んだ3点照合や職務分掌は、まさにその中核だ。「誰が、いつ、何を根拠に、どの仕訳を承認したか」という**証跡**を残すこと。それは、不正を防ぐと同時に、会社の数字の信頼性を外部に証明する技術なのである。
::
