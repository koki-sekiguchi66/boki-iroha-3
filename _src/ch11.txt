::mystery 消えた1,000万円と、計上されなかった450万円
5月20日の朝。洛北ミートの社長のスマートフォンに、1本のニュース速報が届いた。
「焼肉チェーン『牛将（ぎゅうしょう）』、破産手続き開始を申し立て」
京都と滋賀に12店舗を展開する、洛北ミートの大口得意先だった。洛北ミートが牛将に対して持っている売掛金は、ちょうど**1,000万円**。2月と3月に納めた肉の代金だ。破産となれば、ほぼ回収できない。
社長は頭を抱えた。「今期の利益から、1,000万円がまるごと吹き飛ぶ……」
だが、報告に来た経理部長の答えは意外なものだった。
「社長、今期の損益計算書に載る損失は、**550万円**です」
1,000万円の売掛金が紙くずになったのに、損失は550万円。残りの450万円は、いったいどこへ消えたのか？
::

## 貸倒れ ― 売った代金が、二度と戻らないとき

得意先の倒産などによって、売掛金や受取手形などの債権が回収できなくなることを、**貸倒れ**（かしだおれ）という。
第7章で見たとおり、掛けで売ることは「得意先にお金を貸している」のと同じだ。貸したお金が返ってこなければ、それは会社にとっての損失になる。

### 当期に発生した債権が貸し倒れたら ― 貸倒損失

**当期に**販売して発生した売掛金が、当期中に貸し倒れた場合は、その金額を**貸倒損失**（費用）として処理する。

::journal 当期に掛けで販売した得意先が倒産し、売掛金300,000円が回収不能になった
貸倒損失 300,000 | 売掛金 300,000
::

ここまでは素直な処理だ。問題は、**前期に**販売した代金が、当期になって貸し倒れた場合である。問いの鍵は、そこにある。

## 貸倒引当金 ― 「まだ起きていない損失」を先に費用にする

### なぜ、起きていない損失を記録するのか

洛北ミートの得意先は約150店。毎年、そのうちの何店かは、残念ながら倒産したり夜逃げしたりして、代金が回収できなくなる。過去の実績を調べると、期末の売掛金のおよそ**2%**が、翌期に貸し倒れていた。
つまり、期末に2億2,500万円の売掛金があれば、そのうち450万円くらいは、来期のどこかで回収できなくなる可能性が高い。どの得意先が倒れるかは分からない。だが、**全体としては、それくらいの損失が出ることがほぼ確実に予想できる**。
この予想される損失を、**今期の費用**として先に計上し、同時に「売掛金のうち回収できないと見込まれる額」を記録しておく。そのための勘定が**貸倒引当金**（かしだおれひきあてきん）だ。

::theory 費用収益対応の原則 ― 損失は「原因が生まれた期」に負担させる
来期に起きる貸倒れの原因は、**今期に掛けで販売したこと**にある。今期の売上には、「一部は回収できないかもしれない」というリスクがもともと含まれているのだ。
だとすれば、そのリスクのコスト（貸倒れの見込み額）は、売上を計上した今期の費用として負担させるのが筋である。売上という収益と、それを得るために生じた費用（貸倒れのリスク）を、同じ期間に対応させる。これを**費用収益対応の原則**という。
また、将来の損失に早めに備えるという点で、**保守主義**（慎重な会計処理）の考え方にも沿っている。
::

### 差額補充法 ― 不足分だけを補充する

3級では、貸倒引当金を**差額補充法**で設定する。決算日に、期末の売掛金などの残高に**貸倒実績率**をかけて、必要な貸倒引当金の額（設定額）を計算する。そして、すでにある貸倒引当金の残高との**差額だけ**を補充する。

::formula 差額補充法
設定額 ＝ 期末の売上債権の残高 × 貸倒実績率
繰入額 ＝ 設定額 － 貸倒引当金の期末残高（決算整理前）
::

::example 洛北ミート・前期末の決算整理
前期末（3月31日）の売掛金の残高は225,000,000円。貸倒実績率2%で貸倒引当金を差額補充法により設定する。決算整理前の貸倒引当金の残高は1,200,000円だった。
::answer
設定額 ＝ 225,000,000 × 2% ＝ 4,500,000円
繰入額 ＝ 4,500,000 － 1,200,000 ＝ 3,300,000円
::journal 不足分を補充する
貸倒引当金繰入 3,300,000 | 貸倒引当金 3,300,000
::
**貸倒引当金繰入**は費用、**貸倒引当金**は売掛金のマイナスを表す勘定（貸方残高）だ。これで、貸倒引当金の残高は設定額の4,500,000円になった。
::
::

設定額より、すでにある残高のほうが大きいこともある。その場合は、多すぎる分を取り崩して、**貸倒引当金戻入**（収益）とする。

::journal 設定額が400,000円、決算整理前の貸倒引当金残高が550,000円の場合（150,000円を戻し入れる）
貸倒引当金 150,000 | 貸倒引当金戻入 150,000
::

::theory 貸倒引当金は「評価勘定」 ― 売掛金の価値を正しく見せる
貸倒引当金は、資産のようにも負債のようにも見えるが、どちらでもない。売掛金などの資産の金額を修正する、**評価勘定**と呼ばれる勘定だ。
貸借対照表では、売掛金から差し引く形で表示する。

::table 貸借対照表での表示（前期末）
| 資産の部 | 金額 | 金額 |
| 売掛金 | 225,000,000 |  |
| 貸倒引当金 | △4,500,000 | 220,500,000 |
::

額面2億2,500万円の売掛金のうち、実際に回収が見込めるのは2億2,050万円。貸倒引当金は、売掛金の「本当の価値」を読み手に伝えるための勘定なのである。
::

## 前期以前の債権が貸し倒れたら ― 引当金を取り崩す

さて、5月20日の牛将の破産に戻ろう。牛将の売掛金1,000万円は、**前期**の2月と3月に販売した代金だ。そして前期末に、洛北ミートは貸倒引当金を450万円設定していた。
前期以前に発生した債権が貸し倒れたときは、**まず貸倒引当金を取り崩して充てる**。引当金で足りない分だけを、貸倒損失とする。

::journal 5月20日：前期に発生した牛将への売掛金10,000,000円が貸し倒れた（貸倒引当金の残高は4,500,000円）
貸倒引当金 4,500,000 | 売掛金 10,000,000
貸倒損失 5,500,000 |
::

::tgrid
::taccount 貸倒引当金（前期）
 | 前期繰越 1,200,000
次期繰越 4,500,000 | 3/31 貸倒引当金繰入 3,300,000
= 4,500,000 | 4,500,000
::
::taccount 貸倒引当金（当期）
5/20 売掛金 4,500,000 | 4/1 前期繰越 4,500,000
::
::

::solve 450万円は「去年」すでに費用になっていた
1,000万円の売掛金が紙くずになったのに、今期の損失が550万円だったのは、残りの**450万円が、前期の決算ですでに費用として計上されていた**からだ。
前期末、洛北ミートは「来期、売掛金の2%くらいは回収できなくなるだろう」と見込み、貸倒引当金を450万円まで積み増した。そのとき「貸倒引当金繰入」という費用が前期の損益計算書に計上され、前期の利益はその分だけ小さくなっていた。
今期、実際に貸倒れが起きたとき、その備えを取り崩して損失に充てた。だから今期の損益計算書に新たに載るのは、備えを超えた部分、つまり550万円の**貸倒損失**だけなのだ。
牛将への販売で生まれた売上は前期のもの。その売上が抱えていたリスクのコストも、可能な限り前期に負担させる。貸倒引当金は、**損失を「起きた日」ではなく「原因が生まれた期」に記録する**ための、会計上の工夫である。
::

::note
※当期に発生した債権が当期中に貸し倒れた場合は、貸倒引当金の残高があっても取り崩さず、全額を貸倒損失とする。貸倒引当金は「前期末の債権」に対する備えだからだ。
::

## 償却債権取立益 ― 諦めた代金が戻ってきたら

半年後、牛将の破産手続きが進み、残っていた財産が債権者に分配された。洛北ミートにも、1,000万円の債権のうち**3%**、30万円が普通預金に振り込まれた。
前期以前に貸倒れとして処理した債権が、後になって回収できた場合は、**償却債権取立益**（しょうきゃくさいけんとりたてえき・収益）で処理する。

::journal 前期に貸倒れとして処理した売掛金のうち300,000円が、普通預金に入金された
普通預金 300,000 | 償却債権取立益 300,000
::

::point なぜ売掛金を減らさないのか
貸し倒れた売掛金は、貸倒れの処理をした時点で、すでに帳簿から消えている。消えた債権を再び減らすことはできない。そこで、戻ってきたお金を「予想外の収益」として記録するのである。
::

::danger 引当金は「利益の調整弁」にもなりうる
貸倒引当金は「見積り」だ。貸倒実績率を何%と見積もるかには、経営者の判断が入る。そこに誘惑が生まれる。
業績のよい年に引当金を多めに積んで利益を抑え、業績の悪い年に取り崩して利益をかさ上げする。逆に、利益を大きく見せたいときに、必要な引当金を積まずに済ませる。こうした操作は、決算書の読み手を欺く行為だ。
とりわけ深刻だったのが、1990年代の日本の金融危機だ。バブル崩壊後、多くの銀行が回収の見込みの立たない不良債権を抱えながら、十分な引当金を積まずに問題を先送りした。損失が表面化したときには手遅れで、大手金融機関の破綻が相次ぎ、日本経済は長い停滞に沈んだ。
引当金は、将来のリスクを**正直に**数字にするための道具だ。その正直さが失われたとき、決算書は会社の危機を隠す仮面に変わる。
::

::cfo 牛将の次は、どこが倒れるか
牛将の破産で、洛北ミートの経営陣は震え上がった。売掛金の残高上位10社の中には、ほかにも急拡大を続けるチェーン店がいくつかある。あなたなら、二度と同じ目に遭わないために、どんな手を打つか？
::answer
貸倒引当金は、損失を「記録」する道具であって、損失を「防ぐ」道具ではない。本当にすべきは、**貸倒れそのものを減らす与信管理**だ。
- **与信限度額の設定**：得意先ごとに、売掛金の上限（与信枠）を決める。財務内容や支払実績をもとに、限度額を超える注文は前払いや短いサイトでしか受けない。
- **早期警戒サインの監視**：支払いの遅れ、支払サイトの延長の申し入れ、急な大量注文、経理担当者の頻繁な交代、取引銀行の変更。倒産する会社には、たいてい前兆がある。牛将も、倒れる3か月前から支払いが遅れがちだった。売掛金元帳を毎週チェックしていれば、気づけたはずだ。
- **集中リスクの分散**：1社への売上が大きすぎると、その1社の倒産が致命傷になる。上位得意先への依存度を下げる。
- **保険と担保**：取引信用保険への加入や、保証金の預かりも検討する。
- **会計上の見直し**：景気の悪化や業界の異変が見えたら、過去の実績率にとらわれず、貸倒実績率の見直しや、リスクの高い得意先への個別の引当て（2級以降で学ぶ）を検討する。
数字は過去の結果だが、与信管理は未来の損失を防ぐ。両方がそろって初めて、売掛金は「安全な資産」になる。
::
::

::exam 貸倒れの急所
- **当期発生の債権**の貸倒れ → 全額「貸倒損失」。
- **前期以前発生の債権**の貸倒れ → まず「貸倒引当金」を取り崩し、不足分を「貸倒損失」。
- 決算の差額補充法：設定額＝（売掛金＋受取手形＋クレジット売掛金＋電子記録債権など）の期末残高×実績率。残高との差額を「貸倒引当金繰入」。残高のほうが多ければ「貸倒引当金戻入」。
- 期中に貸倒れで引当金を取り崩していると、決算整理前の残高が減っている。精算表の問題では、整理前の残高を必ず確認しよう。
- 前期以前に貸倒れ処理した債権の回収 → 「償却債権取立益」。
- 貸倒引当金は貸方残高の評価勘定。貸借対照表では売掛金などから控除する形で表示する。
::

::next 引当金の4要件と、「予想信用損失」の時代
2級では、貸倒引当金のほかに、修繕引当金、賞与引当金、退職給付引当金などを学ぶ。会計上、引当金を計上できるのは、(1)将来の特定の費用または損失であって、(2)その発生が当期以前の事象に起因し、(3)発生の可能性が高く、(4)金額を合理的に見積もれる場合だ。
1級では、債権を「一般債権」「貸倒懸念債権」「破産更生債権等」に分類し、それぞれに異なる方法で引当金を見積もる。国際会計基準（IFRS）では、将来の予想に基づいて損失を見積もる**予想信用損失モデル**が採用され、銀行の決算に大きな影響を与えた。「未来のリスクをどう数字にするか」は、会計の最前線のテーマなのである。
::

::summary
- 売掛金などが回収不能になることを貸倒れという。当期発生の債権の貸倒れは全額「貸倒損失」
- 決算では、期末の債権に貸倒実績率をかけて貸倒引当金を設定する（差額補充法）。不足は「繰入」、超過は「戻入」
- 前期以前に発生した債権の貸倒れは、まず貸倒引当金を取り崩し、不足分を貸倒損失とする
- 前期以前に貸倒れ処理した債権を回収したら「償却債権取立益」
- 貸倒引当金は、損失を「原因が生まれた期」に負担させるための評価勘定（費用収益対応・保守主義）
- 引当金は見積りであり、操作の誘惑もある。正直な見積りと、日々の与信管理がセットで会社を守る
::
