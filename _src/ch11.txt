::mystery 消えた1,000万円と、計上されなかった450万円
5月20日の朝7時。洛北ミートの社長・北村のスマートフォンに、1本のニュース速報が届いた。
**焼肉チェーン「牛将（ぎゅうしょう）」、破産手続き開始を申し立て　食材高と人手不足で資金繰り悪化**
京都と滋賀に12店舗を展開する、洛北ミートの大口得意先だった。2年前から猛烈な勢いで出店を続け、そのたびに洛北ミートへの注文も増えた。牛将に対して持っている売掛金は、ちょうど**1,000万円**。2月と3月に納めた肉の代金だ。破産となれば、ほぼ回収できない。
北村は、ネクタイも締めずに事務所へ飛び込んだ。
北村：「今期の利益から、1,000万円がまるごと吹き飛ぶ……。中西くん、すぐ計算してくれ」
9時。報告に来た経理の中西の答えは、意外なものだった。
中西：「社長、今期の損益計算書に載る損失は、**550万円**です」
北村：「550万？　1,000万の売掛金が、紙くずになったんやぞ」
中西：「はい。それでも、550万円です」
同じ朝、中西からひよりにメッセージが届いていた。
中西：「牛将が破産しました。でも、3月の決算で大川さんたちが言ってくれたこと、効きました」
ひよりは、2か月前の決算の打ち合わせを思い出した。売上の急成長で預金が減った、あの3月の決算だ（第7章）。一ノ瀬が北村に、ある費用を計上するよう勧め、北村は渋い顔をした。その費用の計算表を作ったのは、ひよりだった。
1,000万円の売掛金が紙くずになったのに、損失は550万円。残りの450万円は、いったいどこへ消えたのか？
::

## 貸倒れ ― 売った代金が、二度と戻らないとき

その日の午後、ひよりは洛北ミートの事務所で、中西と並んで牛将の売掛金元帳を開いた。2月と3月の納品の行が、回収されないまま残っている。
中西：「肉は、ちゃんと届けたんです。牛将さんのお客さんが、その肉を食べた。なのに、代金だけが返ってこない」
得意先の倒産などで、売掛金や受取手形が回収できなくなることを、**貸倒れ**（かしだおれ）という。第7章で見たとおり、掛けで売ることは、得意先にお金を貸しているのと同じだ。貸したお金が返ってこなければ、それは会社の損失になる。

### 今期に売った代金なら ― 貸倒損失

中西：「まず、簡単なほうから確かめましょう」
元帳には、もう1件、回収できなかった売掛金があった。この4月に取引を始めたばかりの居酒屋が、先週、連絡もなく店を閉めていたのだ。金額は30万円。
中西：「こちらは、今期に売った代金です。今期に売って、今期に回収できなくなった。だから、全額を**貸倒損失**という費用にします」

::journal 当期に掛けで販売した得意先が倒産し、売掛金300,000円が回収不能になった
貸倒損失 300,000 | 売掛金 300,000
::

ひより：「じゃあ、牛将さんの1,000万円も、貸倒損失で1,000万円……」
中西：「それが、違うんです。牛将さんの代金は、前の期に売った分です。前の期の決算で、私たちは、もう手を打っていました」

## 3月の決算会議 ― 「まだ起きていない損失」を先に費用にする

::scene 2か月前、3月の決算会議 ― 洛北ミートの社長室
決算の打ち合わせの終わりぎわ、一ノ瀬は1枚の紙を北村の前に置いた。ひよりが前の晩に作った計算表だ。
一ノ瀬：「社長、貸倒引当金を、450万円まで積んでおきましょう」
北村：「かしだおれ……なんやて？」
一ノ瀬：「来期、売掛金のうち回収できなくなりそうな分を、今期のうちに費用にしておくんです」
北村：「まだ、どこも潰れてへんやろ。なんで損を先に出すんや。利益が減るやないか」
一ノ瀬：「掛けで売った代金の何%かは、毎年必ず返ってきません。過去の実績がそう言っています。この5年、期末の売掛金の約2%が、翌年に回収できなくなっている」
北村：「どこが潰れるかも分からんのにか」
一ノ瀬：「どこが倒れるかは、分かりません。でも、全体でどれくらい倒れるかは、ほぼ分かります。その損失の原因は、今期に掛けで売ったことです。だとすれば、今期の費用です」
北村は、長いあいだ紙を見ていた。それから、ため息をついた。
北村：「……分かった。好きにせえ」
::

ひより：「あのとき社長が渋々うなずいた450万円が、今日、効いたんですね」
中西：「はい。あのとき積んだ備えを、今日、取り崩せるんです」

::theory 費用収益対応の原則 ― 損失は「原因が生まれた期」に負担させる
来期に起きる貸倒れの原因は、**今期に掛けで販売したこと**にある。今期の売上には、「一部は回収できないかもしれない」というリスクがもともと含まれているのだ。
だとすれば、そのリスクのコスト（貸倒れの見込み額）は、売上を計上した今期の費用として負担させるのが筋である。売上という収益と、それを得るために生じた費用（貸倒れのリスク）を、同じ期間に対応させる。これを**費用収益対応の原則**という。
また、将来の損失に早めに備えるという点で、**保守主義**（慎重な会計処理）の考え方にも沿っている。
::

::point メモ ― 貸倒引当金とは
予想される貸倒れの損失を、**今期の費用**として先に計上し、同時に「売掛金のうち回収できないと見込まれる額」を記録しておく。そのための勘定が**貸倒引当金**（かしだおれひきあてきん）だ。費用の側の勘定科目は**貸倒引当金繰入**という。
::

### 差額補充法 ― 不足分だけを補充する

ひよりは、3月の決算で自分が作った計算表を、鞄から出した。売掛金の残高に2%を掛けた、ただ1行の計算だ。
ひより：「あのとき、北村社長は450万円を全部、新しく費用にすると思っておられました」
中西：「違うんですか」
ひより：「引当金には、前の年に積んだ残りがあります。足すのは、足りない分だけです。**差額補充法**といいます」
中西：「前の年の残りは、120万円でしたね」
ひより：「だから、3月に費用にしたのは、450万円から120万円を引いた330万円です」

::formula 差額補充法
設定額 ＝ 期末の売上債権の残高 × 貸倒実績率
繰入額 ＝ 設定額 － 貸倒引当金の期末残高（決算整理前）
::

::example 洛北ミート・前期末の決算整理
前期末（3月31日）の売掛金の残高は225,000,000円。貸倒実績率2%で貸倒引当金を差額補充法により設定する。決算整理前の貸倒引当金の残高は1,200,000円だった。
::answer
設定額 ＝ 225,000,000 × 2% ＝ 4,500,000円
繰入額 ＝ 4,500,000 － 1,200,000 ＝ 3,300,000円
::journal 不足分を補充する
貸倒引当金繰入 3,300,000 | 貸倒引当金 3,300,000
::
**貸倒引当金繰入**は費用、**貸倒引当金**は売掛金のマイナスを表す勘定（貸方残高）だ。これで、貸倒引当金の残高は設定額の4,500,000円になった。
::trap
設定額の4,500,000円を、そのまま繰入額にしないこと。差額補充法では、すでにある残高1,200,000円との**差額だけ**を繰り入れる。
残高のほうが設定額より多いときは、多すぎる分を減らし、貸倒引当金戻入（収益）とする。
::
::
::

中西：「逆に、残りのほうが多かったら？」
ひより：「多すぎる分を取り崩して、**貸倒引当金戻入**という収益にします」

::journal 設定額が400,000円、決算整理前の貸倒引当金残高が550,000円の場合（150,000円を戻し入れる）
貸倒引当金 150,000 | 貸倒引当金戻入 150,000
::

::theory 貸倒引当金は「評価勘定」 ― 売掛金の価値を正しく見せる
貸倒引当金は、資産のようにも負債のようにも見えるが、どちらでもない。売掛金などの資産の金額を修正する、**評価勘定**と呼ばれる勘定だ。
貸借対照表では、売掛金から差し引く形で表示する。

::table 貸借対照表での表示（前期末）
| 資産の部 | 金額 | 金額 |
| 売掛金 | 225,000,000 |  |
| 貸倒引当金 | △4,500,000 | 220,500,000 |
::

額面2億2,500万円の売掛金のうち、実際に回収が見込めるのは2億2,050万円。貸倒引当金は、売掛金の「本当の価値」を読み手に伝えるための勘定なのである。
::

## 前期の代金が貸し倒れたら ― 引当金を取り崩す

ひより：「では、牛将さんの分をやってみましょう」
牛将の売掛金1,000万円は、**前期**の2月と3月に販売した代金だ。そして前期末に、洛北ミートは貸倒引当金を450万円設定していた。
中西：「前の期に売った代金が倒れたときは、まず引当金を取り崩す。足りない分だけを、貸倒損失にする」
ひより：「1,000万円のうち、450万円は引当金で埋めて、残りの550万円が貸倒損失」

::journal 5月20日：前期に発生した牛将への売掛金10,000,000円が貸し倒れた（貸倒引当金の残高は4,500,000円）
貸倒引当金 4,500,000 | 売掛金 10,000,000
貸倒損失 5,500,000 |
::

::tgrid
::taccount 貸倒引当金（前期）
 | 前期繰越 1,200,000
次期繰越 4,500,000 | 3/31 貸倒引当金繰入 3,300,000
= 4,500,000 | 4,500,000
::
::taccount 貸倒引当金（当期）
5/20 売掛金 4,500,000 | 4/1 前期繰越 4,500,000
::
::

::solve 450万円は「去年」すでに費用になっていた
1,000万円の売掛金が紙くずになったのに、今期の損失が550万円だったのは、残りの**450万円が、前期の決算ですでに費用として計上されていた**からだ。
前期末、洛北ミートは「来期、売掛金の2%くらいは回収できなくなるだろう」と見込み、貸倒引当金を450万円まで積み増した。そのとき「貸倒引当金繰入」という費用が前期の損益計算書に計上され、前期の利益はその分だけ小さくなっていた。
今期、実際に貸倒れが起きたとき、その備えを取り崩して損失に充てた。だから今期の損益計算書に新たに載るのは、備えを超えた部分、つまり550万円の**貸倒損失**だけなのだ。
牛将への販売で生まれた売上は前期のもの。その売上が抱えていたリスクのコストも、可能な限り前期に負担させる。貸倒引当金は、**損失を「起きた日」ではなく「原因が生まれた期」に記録する**ための、会計上の工夫である。
::

夕方、北村は事務所に顔を出した。
北村：「3月に、あんたらの言うとおりにしといてよかったわ」
それから、少し照れたように付け加えた。
北村：「450万円、あのときは損した気分やったけどな」
一ノ瀬：「損は、あのときに半分済ませていたんです。今日は、残りを払っただけです」

::note
※当期に発生した債権が当期中に貸し倒れた場合は、貸倒引当金の残高があっても取り崩さず、全額を貸倒損失とする。貸倒引当金は「前期末の債権」に対する備えだからだ。
::

## 償却債権取立益 ― 諦めた代金が戻ってきたら

半年後、牛将の破産手続きが進み、残っていた財産が債権者に分配された。洛北ミートにも、1,000万円の債権のうち**3%**、30万円が普通預金に振り込まれた。
中西：「大川さん、30万円、戻ってきました。売掛金を30万円減らせばいいですか」
ひより：「牛将さんの売掛金は、5月にもう全部消してあります。消したものは、もう減らせません」
中西：「じゃあ……」
ひより：「思いがけず戻ってきたお金として、収益にします。**償却債権取立益**という勘定です」

::journal 前期に貸倒れとして処理した売掛金のうち300,000円が、普通預金に入金された
普通預金 300,000 | 償却債権取立益 300,000
::

::point なぜ売掛金を減らさないのか
貸し倒れた売掛金は、貸倒れの処理をした時点で、すでに帳簿から消えている。消えた債権を再び減らすことはできない。そこで、戻ってきたお金を「予想外の収益」として記録するのである。
::

::danger 引当金は「利益の調整弁」にもなりうる
貸倒引当金は「見積り」だ。業績のよい年に多めに積んで利益を抑え、悪い年に取り崩してかさ上げする。逆に、利益を大きく見せたいときに必要な引当金を積まずに済ませる。こうした操作は決算書の読み手を欺く行為だ。1990年代の日本の金融危機では、多くの銀行が不良債権に十分な引当金を積まずに問題を先送りし、損失が表面化したときには手遅れだった。引当金は、将来のリスクを**正直に**数字にするための道具である。
::

::real 「回収できない貸付金」が、名門メーカーを倒した
2024年10月24日、テレビなどで知られた船井電機が、東京地裁から破産手続きの開始決定を受けた。東京商工リサーチの分析によると、試算表上の負債は474億円。だが同社は、親会社に**253億円**を貸し付けており、関係会社の借入金の保証や株式の損失も抱えていた。これらの損失への備えを正しく見積もると、実質的な負債は**約800億円**に膨らみ、債務超過だったという。計上されていた引当金は200億円に満たなかった。
回収できない見込みの貸付金253億円には、本来「貸倒引当金繰入 253／貸倒引当金 253」の仕訳が必要だ。この仕訳を切らなければ、帳簿の上には「253億円の資産」が残り続け、会社は実際よりはるかに豊かに見える。牛将の1,000万円に備えて洛北ミートが前の期に450万円を積んでいたのと、仕組みは同じだ。違うのは、積むべきものを積んでいたかどうかである。
::note
出典：[東京商工リサーチ「船井電機の実質負債800億円、多額の引当不足が露呈」（2024年10月29日）](https://www.tsr-net.co.jp/data/detail/1199022_1527.html)
::
::


::cfo 危ない得意先の兆しは、何を見張るか
牛将の破産のあと、北村は中西に、得意先の「危なさ」を毎月見張る仕組みを作らせた。見張れるのは1つの兆しだけ。中西は、過去3年に倒れた得意先6社の元帳を、4つの兆しで数え直した。
**前提**
- 中西が詳しく調べられるのは、月に1社ほど（年に12社）。取引を絞るには、倒れる2か月前に気づけば間に合う
- 注文の急な増加：年に20社ほどに出る。倒れた6社のうち2社に、倒れる6か月前に出ていた
- 支払いの遅れ（1日でも）：年に40社ほどに出る。倒れた6社すべてに、倒れる3か月前には出ていた
- 2か月続けての支払いの遅れ：年に5社ほどに出る。倒れた6社のうち5社に、倒れる2か月半前には出ていた
- 支払条件の変更の依頼：年に3社ほどに出る。倒れた6社のうち4社に、倒れる1か月半前に出ていた
::choice A. 注文の急な増加。最も早く、6か月前に気づける
**△ 早いが、見逃しも空振りも多い。**倒れた6社のうち4社には出ず、出た年20社のほとんどは、順調に成長している得意先だ。
::
::choice B. 支払いの遅れ（1日でも）。倒れた6社すべてに出ていた
**○ 見逃しはないが、年に40社に出る。**調べられるのは年12社。残りの28社は調べないまま流れ、警報は鳴っていないのと同じになる。
::
::choice C. 2か月続けての支払いの遅れ。年に5社ほどにしか出ない
**◎ 早さ、見逃し、手の数の3つを、同時に満たしている。**2か月半前に出るので、対応に要る2か月に間に合う。6社のうち5社をとらえ、年5社なら全部を詳しく調べられる。
::
::choice D. 支払条件の変更の依頼。出たときに倒れる割合が最も高い
**○ 確かな合図だが、1か月半前では間に合わない。**取引を絞るのに2か月かかる。確かさを追うと、手を打つ時間を失う。
::
::answer 考え方の例を見る
- **早さ・見逃し・空振りの3つで測る**：どれか1つで選ぶと、残りで失敗する
- **見張る人の手の数に合わせる**：調べきれない数の警報は、鳴っていないのと同じ
- **確かさより、間に合うか**：手を打つのに2か月要るなら、1か月半前の確かな合図は遅い
- **前提が変われば**：年に50社調べられる体制があれば、B が最善になる
::
::

::exam 貸倒れの急所
- **当期発生の債権**の貸倒れ → 全額「貸倒損失」。
- **前期以前発生の債権**の貸倒れ → まず「貸倒引当金」を取り崩し、不足分を「貸倒損失」。
- 決算の差額補充法：設定額＝（売掛金＋受取手形＋クレジット売掛金＋電子記録債権など）の期末残高×実績率。残高との差額を「貸倒引当金繰入」。残高のほうが多ければ「貸倒引当金戻入」。
- 期中に貸倒れで引当金を取り崩していると、決算整理前の残高が減っている。精算表の問題では、整理前の残高を必ず確認しよう。
- 前期以前に貸倒れ処理した債権の回収 → 「償却債権取立益」。
- 貸倒引当金は貸方残高の評価勘定。貸借対照表では売掛金などから控除する形で表示する。
::

::next 引当金の4要件と、「予想信用損失」の時代
2級では、修繕引当金や賞与引当金なども学ぶ。引当金を計上できるのは、(1)将来の特定の費用または損失で、(2)当期以前の事象が原因で、(3)発生の可能性が高く、(4)金額を合理的に見積もれる場合だ。1級では、債権の種類ごとに異なる方法で貸倒引当金を見積もる。
::

::summary
- 売掛金などが回収不能になることを貸倒れという。当期発生の債権の貸倒れは全額「貸倒損失」
- 決算では、期末の債権に貸倒実績率をかけて貸倒引当金を設定する（差額補充法）。不足は「繰入」、超過は「戻入」
- 前期以前に発生した債権の貸倒れは、まず貸倒引当金を取り崩し、不足分を貸倒損失とする
- 前期以前に貸倒れ処理した債権を回収したら「償却債権取立益」
- 貸倒引当金は、損失を「原因が生まれた期」に負担させるための評価勘定（費用収益対応・保守主義）
- 引当金は見積りであり、操作の誘惑もある。正直な見積りと、日々の与信管理がセットで会社を守る
::
