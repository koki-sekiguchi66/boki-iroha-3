::mystery 5,000万円を払ったのに、利益が減らない
4月1日、ナイトオウル交通は、福岡線の増便のために新車を1台購入した。3列独立シートの最新型で、価格は**5,000万円**。代金は、その日のうちに普通預金から支払った。東京―福岡は片道1,000kmを超える。運転手の休息のルールが厳しくなったいま、交替の運転手を乗せて走らせる、会社の看板路線だ。
この年の決算。ナイトオウル交通の当期純利益は、前期とほぼ同じ水準を保っていた。損益計算書のどこを探しても、「バス代5,000万円」という費用は見当たらない。代わりに載っていたのは、「減価償却費」という見慣れない費用だった。新車の分は、わずか**1,000万円**。
6月の取締役会。この春に就任したばかりの社外取締役、大手旅行会社で営業ひと筋に歩んできた西條が、決算書から顔を上げた。
西條：「5,000万円も払ったのに、費用は1,000万円？　残りの4,000万円はどこへ行ったんですか」
会議室が静まり返った。
西條：「失礼ですが、利益を良く見せるための操作ではありませんよね？」
社長の三國は、経理部長の柏木と顔を見合わせた。決算の説明のために呼ばれていた一ノ瀬が、隣の席のひよりに小さくうなずいた。
一ノ瀬：「大川さん、お願いします」
ひより：「わ、私ですか」
会議室の全員の目が、いちばん若いひよりに集まった。
5,000万円のバスを買った年、なぜ会社は赤字にならないのか？
::

## 有形固定資産 ― 何年も使い続ける「稼ぐ道具」

ひよりは立ち上がり、ホワイトボードの前に立った。前の晩、夜行バスの中で何度も練習した説明だ。最初に書いたのは、バスの絵だった。
ひより：「西條さん。このバスは、何年走ると思われますか」
西條：「さあ。5年か、10年か」
ひより：「会社は、5年走らせる計画です。バスや建物のように、1年を超えて使う、形のある資産を、**有形固定資産**といいます。何年も使い続けて、お金を稼ぐための道具です」

::table 3級で学ぶ有形固定資産
| 勘定科目 | 具体例 | 減価償却 |
| 建物 | 本社ビル、店舗、車庫、倉庫 | する |
| 備品 | パソコン、机、厨房機器、冷蔵庫、トレーニングマシン | する |
| 車両運搬具 | バス、トラック、営業車 | する |
| 土地 | 店舗や車庫の敷地 | しない |
::

### 取得原価 ― 「使える状態にするまで」の費用はすべて含める

最初の質問は、西條から出た。
西條：「そもそも、5,000万円というのは、車両の値段ですか」
柏木：「いいえ。車両の本体は4,600万円です。3列独立シートへの架装と、登録の手数料を合わせて、5,000万円になります」
ひよりは、バスの絵の横に、3つの金額を縦に並べて書いた。
ひより：「架装をしなければ、OWL LINERとしては走れません。登録しなければ、道路を走れません。だから、走れる状態にするまでにかかった費用は、全部バスの値段に含めます。これを**取得原価**といいます」
西條：「仕入れの運賃を、商品の値段に入れるのと同じですね」
ひより：「はい、まったく同じ考え方です」

::formula 固定資産の取得原価
取得原価 ＝ 購入代価 ＋ 付随費用
::

::table 主な付随費用の例
| 固定資産 | 付随費用 |
| 建物 | 仲介手数料、登記料 |
| 土地 | 仲介手数料、登記料、整地費用 |
| 備品 | 運送費、据付費、試運転費 |
| 車両運搬具 | 架装費（座席や設備の取り付け）、登録手数料 |
::

::example ナイトオウル交通の新車購入
4月1日、新車を購入した。車両本体価格は46,000,000円。3列独立シートとカーテン、USB電源の架装費3,000,000円、登録手数料1,000,000円とともに、普通預金から支払った。
::answer
::journal 架装費・登録手数料も取得原価に含める
車両運搬具 50,000,000 | 普通預金 50,000,000
::
3列独立シートの架装をしなければ、OWL LINERとして走らせることはできない。だから架装費は、バスという資産の値段の一部になる。
::trap
架装費や登録手数料を、支払手数料などの費用にしないこと。資産を使える状態にするまでにかかった付随費用は、**取得原価に含める**。
取得原価が変われば、毎年の減価償却費も変わる。最初の金額を間違えると、その後の計算がすべてずれる。
::
::
::

::note
※固定資産を後払いで購入したときは、買掛金ではなく未払金を使う（第9章）。
::

## 減価償却 ― 5,000万円を「5年」に配分する

### バスは「5年間」稼ぎ続ける

ひよりは、ホワイトボードに5本の棒を描いた。1年目から5年目まで、同じ高さの棒だ。
ひより：「このバスは、5年間、毎晩福岡線を走って、運賃を稼ぎます。もし、買った年に5,000万円を全部費用にしたら、どうなるでしょう」
三國：「1年目は大赤字ね」
ひより：「はい。そして2年目から5年目は、バスの費用がゼロの大黒字です。バスは毎年同じように働いているのに、利益だけがめちゃくちゃに上下してしまう」
西條：「それでは、会社の本当の実力が分からない」
ひより：「だから、5,000万円を、バスが働く5年間に分けて費用にします。この手続きを**減価償却**（げんかしょうきゃく）、毎年の費用を**減価償却費**といいます。使う年数のことは、**耐用年数**と呼びます」

::theory 費用配分の原則 ― 「稼いだ期間」に「使った分」を負担させる
減価償却の本質は、**費用配分**だ。5,000万円のバスは、5年間にわたって収益を生む。だから、その取得原価も5年間に配分し、各年の収益と対応させる。第11章で学んだ**費用収益対応の原則**が、ここでも働いている。
「減価」という言葉から、バスの値打ち（時価）が下がった分を測る手続きだと誤解されやすい。だが、減価償却は時価を評価する手続きではない。あくまで、**取得原価を、使用する期間に合理的に配分する**手続きなのである。
::

### 定額法 ― 毎年同じ金額を費用にする

ひより：「分け方はいくつかありますが、いちばん基本は、毎年同じ金額にする方法です。**定額法**といいます」

::formula 定額法
減価償却費（1年分）＝（取得原価 － 残存価額）÷ 耐用年数
::

ひより：「最後に残る価値、残存価額は、今はゼロにすることが多いです。だから、5,000万円を5年で割ると――」

::example ナイトオウル交通の新車の減価償却費
取得原価50,000,000円、耐用年数5年、残存価額ゼロ、定額法。
このバスの1年分の減価償却費を計算する。
::answer
50,000,000 ÷ 5年 ＝ **10,000,000円**（1年分）
::trap
割り算の前に、残存価額の指示を確かめること。ゼロでないときは、取得原価から残存価額を引いた金額を耐用年数で割る。
::
::
::

::boxes 5,000万円の支出を、5年間の費用に配分する
H 支出（1年目に一括） | 費用（5年に配分）
L d 100 普通預金から支払い<br>5,000万円
R x 20 1年目 1,000万円
R x 20 2年目 1,000万円
R x 20 3年目 1,000万円
R x 20 4年目 1,000万円
R x 20 5年目 1,000万円
::

## 答え合わせ ― 残りの4,000万円は「資産」として眠っている

::solve 4,000万円は、消えたのではなく「来年以降の費用」として待機している
5,000万円のうち、1年目の費用は1,000万円。残りの4,000万円は、まだ費用になっていない。貸借対照表の上で、**車両運搬具という資産**として残っているのだ。
これは利益操作ではない。バスはこれから4年間、毎晩福岡線を走り、運賃を稼ぐ。その4年間に、残りの4,000万円が1,000万円ずつ費用になっていく。5年間を通算すれば、費用の合計はきっちり5,000万円。費用が「消えた」のではなく、**バスが働く期間に合わせて、正しい年に割り振られている**だけなのだ。
社外取締役の疑問はもっともだった。だが、もし買った年に5,000万円を全額費用にしていたら、そちらのほうが、バスの稼ぐ力を正しく表さない「ゆがんだ」決算書になっていたのである。
::

西條は、ホワイトボードの5本の棒グラフをしばらく見ていた。
西條：「旅行の商品でいえば、5年分の宿泊を一括で仕入れたようなものですね。仕入れた年に全部を原価にしたら、1年目の商品だけが大赤字に見える」
ひより：「はい、まさにその考え方です」
西條は、初めて笑った。
西條：「失礼な質問をしました。よく分かりました」
会議のあと、柏木が小声で言った。
柏木：「旅行業の人に、旅行のたとえで返されましたね」
ひより：「完全に、負けました」

## 記帳方法 ― 直接法と間接法

取締役会のあと、西條は廊下でひよりを呼び止めた。
西條：「もう1つだけ。5年たったバスは、帳簿の上でどうなるんですか。消えてしまう？」
ひより：「書き方が2つあります。バスの金額を直接減らしていく方法と、バスの金額はそのままにして、横に『これだけ使った』という記録を積み上げていく方法です」

::table 減価償却の2つの記帳方法
| 方法 | 仕訳 | 特徴 |
| 直接法 | 減価償却費 ／ 車両運搬具 | 固定資産の勘定を直接減らす。帳簿に取得原価が残らない |
| 間接法 | 減価償却費 ／ 減価償却累計額 | 固定資産の勘定は取得原価のまま。減価償却の累計額を別の勘定に記録する |
::

::journal 直接法：決算日に、新車の減価償却費10,000,000円を計上した
減価償却費 10,000,000 | 車両運搬具 10,000,000
::

::journal 間接法：決算日に、新車の減価償却費10,000,000円を計上した
減価償却費 10,000,000 | 減価償却累計額 10,000,000
::

ひより：「2つ目の書き方では、**減価償却累計額**という勘定に、毎年の減価償却費を積み上げていきます。貸倒引当金と同じで、資産から差し引くための勘定です」

::note
※出題区分表（2022年度適用）では、3級の記帳方法は**間接法**のみで、直接法は2級の範囲とされている。3級の試験は間接法で解けばよい。直接法は考え方の比較として押さえておこう。
::

::tgrid
::taccount 車両運搬具（間接法・2年目末）
4/1 前期繰越 50,000,000 | 3/31 次期繰越 50,000,000
::
::taccount 減価償却累計額（2年目末）
次期繰越 20,000,000 | 前期繰越 10,000,000
 | 3/31 減価償却費 10,000,000
= 20,000,000 | 20,000,000
::
::

::table 貸借対照表での表示（2年目末・間接法）
| 資産の部 | 金額 | 金額 |
| 車両運搬具 | 50,000,000 |  |
| 減価償却累計額 | △20,000,000 | 30,000,000 |
::

西條：「なるほど。5,000万円で買って、2,000万円分使って、あと3,000万円。一目で分かりますね」
ひより：「その残りの3,000万円を、**帳簿価額**と呼びます」

## 期中に取得したら ― 月割で計算する

西條：「去年の7月に買ったバスも、同じ1,000万円でしたか」
決算書の注記を、もう先まで読んでいる。
柏木：「いいえ、750万円です」
西條：「同じ値段のバスなのに？」
ひよりは、ホワイトボードに12か月のマス目を描き、7月から先だけを塗った。
ひより：「7月に買ったバスは、この年、9か月しか走っていません。だから、1年分の1,000万円の、12分の9だけを費用にします」

::example 7月に取得した場合
7月1日に、取得原価50,000,000円のバスを購入した。耐用年数5年、残存価額ゼロ、定額法。決算日は3月31日。
::answer
7月から3月までは**9か月**。
50,000,000 ÷ 5年 × 9/12 ＝ **7,500,000円**
::journal 間接法
減価償却費 7,500,000 | 減価償却累計額 7,500,000
::
月数は「取得月を含めて数える」。7月1日取得なら、7・8・9・10・11・12・1・2・3月の9か月だ。
::trap
期中に取得したのに、1年分の10,000,000円を計上しないこと。使った月数の分だけを月割で計上する。
月数は指で数えよう。7月1日から3月31日までは9か月で、取得した月も1か月に含める。
::
::
::

## 固定資産の売却 ― 「帳簿価額」と「売った値段」の差が損益になる

取締役会の翌週、柏木の机に1通の見積書が届いた。海外の中古車業者が、4年走ったバスを買い取りたいという。日本の中古バスは、品質の高さから東南アジアなどで人気がある。
柏木：「1,500万円か。悪くない値段ですね。大川さん、これを売ると、会社は儲かりますか、損をしますか」
ひよりは、すぐには答えられなかった。
ひより：「何と比べればいいんでしょう」
柏木：「5,000万円と比べたら、大損に見えます。でも、このバスは、もう4年分を費用にしています」
ひより：「あ……帳簿の上のバスの値段は、もう5,000万円じゃない。帳簿価額と比べるんですね」
柏木：「そうです。帳簿価額より高く売れれば**固定資産売却益**、安ければ**固定資産売却損**です」

::formula 固定資産の売却損益
売却価額 － 帳簿価額（取得原価 － 減価償却累計額）＝ 売却益（マイナスなら売却損）
::

## 固定資産台帳 ― 1台ごとの「戸籍」

柏木：「売る前に、このバスの帳簿価額を確かめましょう」
柏木は、棚から1冊のファイルを出した。20台のバスが、1台ずつ1ページになっている。買った日、買った値段、これまでの減価償却費。
ひより：「バスの戸籍みたいですね」
柏木：「**固定資産台帳**といいます。20台もあると、どのバスがいつ買われて、どこまで償却が進んでいるか、これがないと誰にも分かりません」

::table compact sum 固定資産台帳（車両運搬具・抜粋）　×6年3月31日現在
| 取得年月日 | 名称 | 耐用年数 | 取得原価 | 期首減価償却累計額 | 差引期首帳簿価額 | 当期減価償却費 |
| ×2年4月1日 | 3列シート車 A号 | 5年 | 50,000,000 | 30,000,000 | 20,000,000 | 10,000,000 |
| ×4年4月1日 | 3列シート車 K号 | 5年 | 50,000,000 | 10,000,000 | 40,000,000 | 10,000,000 |
| ×5年7月1日 | 3列シート車 S号 | 5年 | 50,000,000 | 0 | 50,000,000 | 7,500,000 |
|= | 合計 |  | 150,000,000 | 40,000,000 | 110,000,000 | 27,500,000 |
::

::note
※第2問では、固定資産台帳の記入から、減価償却累計額勘定や減価償却費の金額を読み取らせる問題が出る。期中に取得した資産の月割計算（S号は×5年7月1日取得なので9か月分）を見落とさないこと。
::

ひよりは、4年前に買ったバスのページを開いた。減価償却累計額は4,000万円。帳簿価額は1,000万円だった。
ひより：「1,500万円で売れたら、500万円の儲けです」

::example 期首に売却した場合
ナイトオウル交通は、4年前に50,000,000円で取得したバス（減価償却累計額40,000,000円、間接法）を、期首の4月1日に海外の中古車業者に15,000,000円で売却した。代金は月末に受け取る。
::answer
帳簿価額 ＝ 50,000,000 － 40,000,000 ＝ 10,000,000円
売却益 ＝ 15,000,000 － 10,000,000 ＝ 5,000,000円
::journal バスと累計額を帳簿から消し、差額を売却益とする
減価償却累計額 40,000,000 | 車両運搬具 50,000,000
未収入金 15,000,000 | 固定資産売却益 5,000,000
::
売却代金の後日受取りは、商品の売上ではないので**未収入金**（第9章）。
::trap
売却代金の15,000,000円を、そのまま売却益にしないこと。売却損益は、売却代金と**帳簿価額**（取得原価－減価償却累計額）の差だ。
売ったバスは会社からなくなる。車両運搬具と減価償却累計額の両方を、帳簿から消すことを忘れない。
::
::
::

柏木：「では、もし売るのが期首ではなく、9月末だったら？」
ひより：「4月から9月までも、バスは走ってます。その半年分の減価償却費を、先に計上しないといけない……」
柏木：「それを忘れると、売却益を間違えます。試験でも、いちばん狙われるところだそうですよ」

::example 期中に売却した場合 ― 試験で最も狙われるパターン
同じバスを、期首ではなく9月30日に12,000,000円で売却し、代金は月末に受け取ることにした。決算日は3月31日、年間の減価償却費は10,000,000円（定額法・間接法）、期首の減価償却累計額は40,000,000円。
::answer
期中に売却したときは、**期首から売却した月までの減価償却費を月割で計上してから**、売却損益を計算する。
当期の減価償却費 ＝ 10,000,000 × 6/12 ＝ 5,000,000円（4月〜9月の6か月）
売却時の帳簿価額 ＝ 50,000,000 － 40,000,000 － 5,000,000 ＝ 5,000,000円
売却益 ＝ 12,000,000 － 5,000,000 ＝ 7,000,000円
::journal 当期分の減価償却費も同時に計上する
減価償却累計額 40,000,000 | 車両運搬具 50,000,000
減価償却費 5,000,000 | 固定資産売却益 7,000,000
未収入金 12,000,000 |
::
::trap
当期分の減価償却費を忘れると、帳簿価額が10,000,000円のままになり、売却益を2,000,000円と誤ってしまう。
売却した日が期首でなければ、「期首から売却月までの月割」が必要だ。売却の日付を必ず確かめよう。
::
::
::

その月、アイアンワークスでも1台、古いトレッドミルが売られた。こちらは、帳簿価額より安い値段だった。

::example 売却損が出る場合（IRONWORKS 24のトレッドミル）
期首に、取得原価1,200,000円、減価償却累計額720,000円のトレッドミル（備品）を、300,000円で売却し、代金は現金で受け取った。
::answer
帳簿価額 ＝ 1,200,000 － 720,000 ＝ 480,000円 → 300,000円で売ったので、180,000円の売却損
::journal
減価償却累計額 720,000 | 備品 1,200,000
現金 300,000 |
固定資産売却損 180,000 |
::
::trap
売却損と売却益を取り違えないこと。帳簿価額より安く売れば損、高く売れば益だ。
迷ったら、先にほかの科目を書いてしまう。貸借の差額が借方に出れば売却損（費用）、貸方に出れば売却益（収益）になる。

## 修繕か、改良か ― 資本的支出と収益的支出

ファイルには、整備工場からの請求書も2枚はさまっていた。1枚は、故障したエンジンの修理。もう1枚は、古い座席を新型のシートに入れ替えた工事だ。
柏木：「どちらもバスにかけたお金ですが、帳簿の上では行き先が違います。元に戻しただけか、前より良くなったか、で分けるんです」
ひより：「元に戻しただけなら？」
柏木：「**修繕費**という費用です。これを**収益的支出**といいます。前より良くなったり、長く使えるようになったりしたら、バスの値段に足します。こちらは**資本的支出**。3級では、修繕費のほうを押さえておけば十分です」

::journal バスのエアコンの故障を修理し、修理代300,000円を普通預金から支払った（収益的支出）
修繕費 300,000 | 普通預金 300,000

## 減価償却は「お金が出ていかない費用」である

その夜、事務所に戻ったひよりに、一ノ瀬は最後に1つだけ付け加えた。
一ノ瀬：「減価償却費には、ほかの費用と決定的に違うところがあります。分かりますか」
ひより：「……お金が、出ていかない？」
一ノ瀬：「そうです。バスの代金5,000万円は、買った日に払い終わっています。2年目以降の1,000万円は、帳簿の上で費用になるだけで、その年にお金は1円も出ていきません」
ひより：「じゃあ、本業でいくらお金を稼いだかは……」
一ノ瀬：「おおまかには、利益に減価償却費を足して見ます。序章のまんぷく食堂で、『減価償却費（費用だが、お金は出ていかない）』という行があったのを覚えていますか」

::danger 減価償却の「2つの罠」
**罠1：耐用年数で利益を作る**　5年で償却するバスを「10年使える」と見積もれば、減価償却費は半分になり、利益は大きく見える。だから一度決めた方法や耐用年数は、正当な理由なく変更できない（継続性の原則）。
**罠2：減価償却費の分のお金を使い切る**　減価償却費の分だけ、利益より多くのお金が手元に残る。だがそれは「将来バスを買い替えるための原資」だ。使い切ってしまえば、バスが一斉に寿命を迎えたとき、買い替えるお金がない。
::

::real 「耐用年数」を過ぎた水道管が、日本中に埋まっている
日本の水道管の総延長は約74万km、地球を18周半する長さだ。厚生労働省のデータによると、法定耐用年数の40年を超えた管路は、2021年度の時点で全体の**2割**を超えている。一方、1年間に更新された管路は全体の**0.64%**にすぎず、このペースではすべてを更新するのに130年かかるという試算もある。
取得原価400億円の水道管を、耐用年数40年・残存価額ゼロの定額法で償却すれば、毎年「減価償却費 10億円／減価償却累計額 10億円」の仕訳が繰り返され、40年後に帳簿価額はゼロになる。帳簿の上では「価値を使い切った」管が、地面の下では今も水を運んでいる。減価償却費は「お金が出ていかない費用」だ。その分のお金を将来の買い替えのために残しておかなければ、いつか必ず「更新の崖」に突き当たる。20台のバスを5年ごとに買い替えるナイトオウル交通も、同じ崖の手前を走っている。
::note
出典：[マネー現代「日本のインフラ老朽化」（2025年2月11日、厚生労働省のデータを引用）](https://gendai.media/articles/-/146695)
::
::


## {{new:2027年度〜}} 定率法と、固定資産の除却・廃棄

2027年4月以降の試験では、2級で学んでいた次の論点が、3級の範囲に加わる予定だ（暫定版）。

### 定率法 ― 最初に多く、後になるほど少なく

同じ月、ひよりはアイアンワークスの巡回で、経理部長の松尾から相談を受けた。
松尾：「トレッドミルは、買って1、2年がいちばん会員に喜ばれます。3年もすると、もう型落ちなんです」
ひより：「それなのに、毎年同じ金額を費用にするのは、実感と合わない、ということですね」
松尾：「そうなんです。最初の年に、もっと費用にできればいいのに」
ひより：「その方法、あります。**定率法**です。毎年、残っている帳簿価額に同じ率を掛けるので、最初の年がいちばん多くて、だんだん減っていきます」

::formula 定率法
減価償却費 ＝（取得原価 － 期首の減価償却累計額）× 償却率
::

::example トレッドミルを定率法で償却する
IRONWORKS 24は、取得原価1,000,000円のトレッドミル（備品）を、償却率40%の定率法で償却している。1年目から3年目までの減価償却費は、次のようになる。
::table 解答欄
| 年 | 期首の帳簿価額 | 減価償却費（×40%） | 期末の帳簿価額 |
| 1年目 | 1,000,000 | [[400,000]] | [[600,000]] |
| 2年目 | [[600,000]] | [[240,000]] | [[360,000]] |
| 3年目 | [[360,000]] | [[144,000]] | [[216,000]] |
::
::answer
::table 定率法による減価償却費
| 年 | 期首の帳簿価額 | 減価償却費（×40%） | 期末の帳簿価額 |
| 1年目 | 1,000,000 | 400,000 | 600,000 |
| 2年目 | 600,000 | 240,000 | 360,000 |
| 3年目 | 360,000 | 144,000 | 216,000 |
::
トレーニングマシンやパソコンのように、新しいうちに価値が大きく下がり、性能の陳腐化も早い資産には、定率法のほうが実態に合うと考えられている。
::trap
毎年、取得原価の1,000,000円に40%を掛けてはいけない。定率法で率を掛ける相手は、**期首の帳簿価額**（まだ償却していない残り）だ。
だから、減価償却費は年々小さくなる。毎年同じ金額になるのは定額法である。
::
::
::

::note
※実務の「200%定率法」で使う保証率・改定償却率は、3級では出題しないことが示されている（基礎的な仕組みの理解を目的とした簡易な出題）。
::

::sim dep 定額法と定率法で、毎年の減価償却費を比べてみよう
@expect sl.1=200000 sl.5=200000 slbook.5=0 db.1=400000 db.2=240000 db.3=144000 dbbook.5=77760

### 除却と廃棄 ― 使わなくなった固定資産を帳簿から消す

京都本店の倉庫には、役目を終えたトレッドミルが2台、壁ぎわに寄せてあった。
松尾：「1台は、部品として業者が引き取ってくれます。もう1台は、お金を払って処分するしかありません」
ひより：「使わなくなった資産を、帳簿に残しておくわけにはいかないですね」
使うのをやめて帳簿から取り除くことを**除却**（じょきゃく）という。まだ売れる価値が見込めるなら、その見積額を**貯蔵品**（資産）として残し、帳簿価額との差を**固定資産除却損**とする。価値がなく捨ててしまうのは**廃棄**で、帳簿価額と廃棄にかかった費用の合計が**固定資産廃棄損**になる。

::example IRONWORKS 24の古いマシン
(1) 取得原価1,200,000円、減価償却累計額1,080,000円のトレッドミルを除却した。部品として売却できる見込額は20,000円である。
(2) 取得原価1,200,000円、減価償却累計額1,080,000円のトレッドミルを廃棄した。廃棄費用30,000円は現金で支払った。
::answer
::journal (1) 除却：処分見込額は貯蔵品、残りは除却損
減価償却累計額 1,080,000 | 備品 1,200,000
貯蔵品 20,000 |
固定資産除却損 100,000 |
::
::journal (2) 廃棄：帳簿価額120,000円＋廃棄費用30,000円＝廃棄損150,000円
減価償却累計額 1,080,000 | 備品 1,200,000
固定資産廃棄損 150,000 | 現金 30,000
::
::trap
除却と廃棄を区別すること。
- 除却 → 処分できる見込額を貯蔵品（資産）として残す。現金にはしない
- 廃棄 → 何も残らない。廃棄にかかった費用も、廃棄損に含める
::
::
::

::cfo 「今期は利益が足りない」― 銀行との約束を前に、何をするか
今期のナイトオウル交通は、軽油の値上がりで営業利益の見込みが500万円にとどまりそうだ。借入の契約には「2期続けて営業利益が赤字になったら、銀行と返済条件を見直す」という約束がある。
柏木：「バスの耐用年数を5年から8年に延ばせば、減価償却費が年に7,500万円減ります。利益はすぐ大きく見えますが……」
**前提**
- 保有するバス20台の減価償却費は年2億円
- 実際のバスは、走行距離や整備の状況から、5〜6年で入れ替えている
- 銀行は、決算書の数字をそのまま見るだけでなく、耐用年数などの変更の理由も確かめる
**考えるときの視点**
- 耐用年数を変えると、お金の動きは変わるか
- その変更に、実態の裏づけはあるか。銀行はどこを見るか
::choice A. 耐用年数はそのままにして、軽油の値上がり分を運賃に転嫁できるか、燃費の改善でどこまで吸収できるかを見積もる
**◎ 帳簿の数字ではなく、稼ぐ力そのものに手を打とうとしている。**減価償却費を減らしても、お金は1円も増えない。燃料費の上昇をどこで吸収するかを見積もり、そのうえで、銀行には事情と対策を早めに説明する。
::
::choice B. 耐用年数を8年に延ばす。会計のルールの範囲内の変更なので問題ない
**× 実態と合わない変更で、利益だけを動かそうとしている。**実際には5〜6年で入れ替えているのに8年とすれば、理由を説明できない。継続性の原則にも反し、銀行の信頼を失う。
::
::choice C. 今期は新しいバスの購入を見送り、減価償却費の増加を抑える
**△ 費用は抑えられるが、古いバスの整備費が増え、安全や快適さにも響く。**利益のために必要な投資を止めると、将来の稼ぐ力が落ちる。
::
::choice D. 銀行に事情を説明する前に、まずは決算の数字を固める
**△ 順番が遅い。**約束に触れそうなときは、早めに説明し、対策を一緒に示すほうが信頼を保てる。決算が出てからでは、選べる手段が減る。
::
::answer 考え方の例を見る
- **帳簿の数字を動かしても、お金は増えない**：減価償却費は「お金が出ていかない費用」。減らしても、会社の稼ぐ力は変わらない
- **見積りの変更には実態の裏づけが要る**：耐用年数は、実際に使う年数にもとづく。都合で変えれば信頼を失う
- **原因に手を打つ**：利益が足りない原因（燃料費の上昇）を、価格や燃費でどこまで吸収できるかを見積もる
- **早めに説明する**：約束に触れそうなときは、数字が固まる前に事情と対策を伝える
::
::

::exam 固定資産の急所
- 取得原価＝購入代価＋付随費用（仲介手数料・登記料・運送費・据付費・架装費など）。後払いは**未払金**。
- 定額法：（取得原価－残存価額）÷耐用年数。残存価額がゼロか10%かを必ず確認。
- 期中取得は「取得月から決算月まで」の月割。期中売却は「期首から売却月まで」の月割の減価償却費を計上してから売却損益を出す。
- 間接法の売却仕訳では、固定資産を**取得原価**で、減価償却累計額を**期首の累計額**で消す。
- **土地は減価償却しない**。土地の売却も「売却価額－帳簿価額」で損益を出す。
- 3級の記帳方法は**間接法**（減価償却累計額を使う）。直接法は2級の範囲。
- 減価償却費を毎月の月次決算で計上している場合は、決算では未計上の月の分だけを追加で計上する（第18章）。
- 原状回復のための修理は修繕費。
- 2027年度以降は、定率法（簡易な出題）、除却（固定資産除却損・貯蔵品）、廃棄（固定資産廃棄損）も3級の範囲に入る予定。
::

::next 形のない資産 ― ソフトウェアは「資産」か「費用」か
研究開発の段階の支出は、将来の収益が不確実なので、原則として発生した年の**費用**になる。一方、完成したソフトウェアは**無形固定資産**として計上し、償却していく。2級では社内で使うソフトウェア（原則5年以内の定額法）を学ぶ。SaaS企業やゲーム会社の決算書を読むとき、「何が資産になり、何が費用になっているか」を見抜く力が効いてくる。
::

::summary
- 有形固定資産（建物・備品・車両運搬具・土地）は、購入代価＋付随費用で取得原価を記録する
- 減価償却は、取得原価を耐用年数にわたって費用に配分する手続き。時価の評価ではない
- 定額法：（取得原価－残存価額）÷耐用年数。期中取得・期中売却は月割で計算する
- 間接法では減価償却累計額（評価勘定）を使い、取得原価－累計額＝帳簿価額
- 売却損益＝売却価額－帳簿価額。売却代金の後受けは未収入金
- 減価償却費は「お金が出ていかない費用」。そのお金は、将来の設備更新の原資である
- 2027年度からは、定率法・除却（除却損・貯蔵品）・廃棄（廃棄損）も3級に加わる予定
::

::problem {{new:2027年度〜}} 取得原価500,000円の備品を、償却率25%の定率法で償却する。2年目の減価償却費を求めなさい。
2年目の減価償却費：[[93,750]] 円
::answer
1年目：500,000×25%＝125,000円
2年目：（500,000－125,000）×25%＝**93,750円**
