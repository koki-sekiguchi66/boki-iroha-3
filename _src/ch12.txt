## 有形固定資産 ― 何年も使い続ける「稼ぐ道具」

会社が長期間（1年を超えて）使うために持っている、形のある資産を**有形固定資産**という。3級で登場するのは、次の4つだ。

::table 3級で学ぶ有形固定資産
| 勘定科目 | 具体例 | 減価償却 |
| 建物 | 本社ビル、店舗、車庫、倉庫 | する |
| 備品 | パソコン、机、厨房機器、冷蔵庫、トレーニングマシン | する |
| 車両運搬具 | バス、トラック、営業車 | する |
| 土地 | 店舗や車庫の敷地 | しない |
::

### 取得原価 ― 「使える状態にするまで」の費用はすべて含める

固定資産を買ったときは、購入代価に、使える状態にするまでにかかった**付随費用**を加えた金額を、**取得原価**とする。第5章の商品と同じ考え方だ。

::formula 固定資産の取得原価
取得原価 ＝ 購入代価 ＋ 付随費用
::

::table 主な付随費用の例
| 固定資産 | 付随費用 |
| 建物 | 仲介手数料、登記料 |
| 土地 | 仲介手数料、登記料、整地費用 |
| 備品 | 運送費、据付費、試運転費 |
| 車両運搬具 | 架装費（座席や設備の取り付け）、登録手数料 |
::

::example ナイトオウル交通の新車購入
4月1日、新車を購入した。車両本体価格は46,000,000円。3列独立シートとカーテン、USB電源の架装費3,000,000円、登録手数料1,000,000円とともに、普通預金から支払った。
::answer
::journal 架装費・登録手数料も取得原価に含める
車両運搬具 50,000,000 | 普通預金 50,000,000
::
3列独立シートの架装をしなければ、OWL LINERとして走らせることはできない。だから架装費は、バスという資産の値段の一部になる。
::
::

::note
※固定資産を後払いで購入したときは、買掛金ではなく未払金を使う（第9章）。
::

## 減価償却 ― 5,000万円を「5年」に配分する

### バスは「5年間」稼ぎ続ける

5,000万円のバスは、買った年だけ使って捨てるものではない。ナイトオウル交通は、このバスを**5年間**、毎晩福岡線で走らせ、運賃を稼ぎ続ける。
もし5,000万円を買った年に全額費用にしたら、どうなるか。1年目は巨額の赤字、2年目から5年目は、バスの費用がゼロの「大黒字」。バスは毎年同じように働いているのに、利益はめちゃくちゃに乱高下してしまう。これでは、会社の本当の稼ぐ力が分からない。
そこで会計は、固定資産の取得原価を、それを使う期間（**耐用年数**）にわたって、少しずつ費用として配分する。この手続きを**減価償却**（げんかしょうきゃく）といい、各期に配分された費用を**減価償却費**という。

::theory 費用配分の原則 ― 「稼いだ期間」に「使った分」を負担させる
減価償却の本質は、**費用配分**だ。5,000万円のバスは、5年間にわたって収益を生む。だから、その取得原価も5年間に配分し、各年の収益と対応させる。第11章で学んだ**費用収益対応の原則**が、ここでも働いている。
「減価」という言葉から、バスの値打ち（時価）が下がった分を測る手続きだと誤解されやすい。だが、減価償却は時価を評価する手続きではない。あくまで、**取得原価を、使用する期間に合理的に配分する**手続きなのである。
::

### 定額法 ― 毎年同じ金額を費用にする

3級では、毎年同じ金額ずつ減価償却費を計上する**定額法**を学ぶ。

::formula 定額法
減価償却費（1年分）＝（取得原価 － 残存価額）÷ 耐用年数
::

**残存価額**とは、耐用年数が終わったときに残ると見込まれる価値のことだ。現在の実務では残存価額を**ゼロ**とすることが多いが、試験では「取得原価の10%」と指示されることもある。問題文の指示に従おう。

::example ナイトオウル交通の新車の減価償却費
取得原価50,000,000円、耐用年数5年、残存価額ゼロ、定額法。
::answer
50,000,000 ÷ 5年 ＝ **10,000,000円**（1年分）
::
::

::boxes 5,000万円の支出を、5年間の費用に配分する
H 支出（1年目に一括） | 費用（5年に配分）
L d 100 普通預金から支払い<br>5,000万円
R x 20 1年目 1,000万円
R x 20 2年目 1,000万円
R x 20 3年目 1,000万円
R x 20 4年目 1,000万円
R x 20 5年目 1,000万円
::

## 答え合わせ ― 残りの4,000万円は「資産」として眠っている

::solve 4,000万円は、消えたのではなく「来年以降の費用」として待機している
5,000万円のうち、1年目の費用は1,000万円。残りの4,000万円は、まだ費用になっていない。貸借対照表の上で、**車両運搬具という資産**として残っているのだ。
これは利益操作ではない。バスはこれから4年間、毎晩福岡線を走り、運賃を稼ぐ。その4年間に、残りの4,000万円が1,000万円ずつ費用になっていく。5年間を通算すれば、費用の合計はきっちり5,000万円。費用が「消えた」のではなく、**バスが働く期間に合わせて、正しい年に割り振られている**だけなのだ。
社外取締役の疑問はもっともだった。だが、もし買った年に5,000万円を全額費用にしていたら、そちらのほうが、バスの稼ぐ力を正しく表さない「ゆがんだ」決算書になっていたのである。
::

## 記帳方法 ― 直接法と間接法

減価償却費の記帳には、2つの方法がある。

::table 減価償却の2つの記帳方法
| 方法 | 仕訳 | 特徴 |
| 直接法 | 減価償却費 ／ 車両運搬具 | 固定資産の勘定を直接減らす。帳簿に取得原価が残らない |
| 間接法 | 減価償却費 ／ 減価償却累計額 | 固定資産の勘定は取得原価のまま。減価償却の累計額を別の勘定に記録する |
::

::journal 直接法：決算日に、新車の減価償却費10,000,000円を計上した
減価償却費 10,000,000 | 車両運搬具 10,000,000
::

::journal 間接法：決算日に、新車の減価償却費10,000,000円を計上した
減価償却費 10,000,000 | 減価償却累計額 10,000,000
::

間接法では、**減価償却累計額**（げんかしょうきゃくるいけいがく）という勘定に、これまでの減価償却費の合計を積み上げていく。減価償却累計額は、第11章の貸倒引当金と同じく、資産のマイナスを表す**評価勘定**だ（貸方残高）。試験では、間接法がよく出題される。

::tgrid
::taccount 車両運搬具（間接法・2年目末）
4/1 前期繰越 50,000,000 | 3/31 次期繰越 50,000,000
::
::taccount 減価償却累計額（2年目末）
次期繰越 20,000,000 | 前期繰越 10,000,000
 | 3/31 減価償却費 10,000,000
= 20,000,000 | 20,000,000
::
::

::table 貸借対照表での表示（2年目末・間接法）
| 資産の部 | 金額 | 金額 |
| 車両運搬具 | 50,000,000 |  |
| 減価償却累計額 | △20,000,000 | 30,000,000 |
::

取得原価から減価償却累計額を差し引いた金額を**帳簿価額**（簿価）という。間接法なら、「もともと5,000万円で買ったバスを、2年分（2,000万円）償却し、帳簿価額は3,000万円」という情報が、一目で分かる。

## 期中に取得したら ― 月割で計算する

固定資産を期の途中で買ったときは、**使い始めた月から決算月まで**の月数に応じて、減価償却費を月割で計算する。

::example 7月に取得した場合
7月1日に、取得原価50,000,000円のバスを購入した。耐用年数5年、残存価額ゼロ、定額法。決算日は3月31日。当期の減価償却費を求めなさい。
::answer
7月から3月までは**9か月**。
50,000,000 ÷ 5年 × 9/12 ＝ **7,500,000円**
::journal 間接法
減価償却費 7,500,000 | 減価償却累計額 7,500,000
::
月数は「取得月を含めて数える」。7月1日取得なら、7・8・9・10・11・12・1・2・3月の9か月だ。
::
::

## 固定資産の売却 ― 「帳簿価額」と「売った値段」の差が損益になる

5年後。役目を終えたバスは、廃車にされるとは限らない。日本の中古バスは、品質の高さから東南アジアなどで人気があり、海外の業者に売却されることも多い。
固定資産を売却したときは、売却価額と**帳簿価額**を比べる。売却価額のほうが大きければ**固定資産売却益**（収益）、小さければ**固定資産売却損**（費用）だ。

::formula 固定資産の売却損益
売却価額 － 帳簿価額（取得原価 － 減価償却累計額）＝ 売却益（マイナスなら売却損）
::

::example 期首に売却した場合
ナイトオウル交通は、4年前に50,000,000円で取得したバス（減価償却累計額40,000,000円、間接法）を、期首の4月1日に海外の中古車業者に15,000,000円で売却した。代金は月末に受け取る。
::answer
帳簿価額 ＝ 50,000,000 － 40,000,000 ＝ 10,000,000円
売却益 ＝ 15,000,000 － 10,000,000 ＝ 5,000,000円
::journal バスと累計額を帳簿から消し、差額を売却益とする
減価償却累計額 40,000,000 | 車両運搬具 50,000,000
未収入金 15,000,000 | 固定資産売却益 5,000,000
::
売却代金の後日受取りは、商品の売上ではないので**未収入金**（第9章）。
::
::

::example 期中に売却した場合 ― 試験で最も狙われるパターン
同じバスを、期首ではなく9月30日に12,000,000円で売却し、代金は月末に受け取ることにした。決算日は3月31日、年間の減価償却費は10,000,000円（定額法・間接法）、期首の減価償却累計額は40,000,000円。
::answer
期中に売却したときは、**期首から売却した月までの減価償却費を月割で計上してから**、売却損益を計算する。
当期の減価償却費 ＝ 10,000,000 × 6/12 ＝ 5,000,000円（4月〜9月の6か月）
売却時の帳簿価額 ＝ 50,000,000 － 40,000,000 － 5,000,000 ＝ 5,000,000円
売却益 ＝ 12,000,000 － 5,000,000 ＝ 7,000,000円
::journal 当期分の減価償却費も同時に計上する
減価償却累計額 40,000,000 | 車両運搬具 50,000,000
減価償却費 5,000,000 | 固定資産売却益 7,000,000
未収入金 12,000,000 |
::
::
::

::example 売却損が出る場合（IRONWORKS 24のトレッドミル）
期首に、取得原価1,200,000円、減価償却累計額720,000円のトレッドミル（備品）を、300,000円で売却し、代金は現金で受け取った。
::answer
帳簿価額 ＝ 1,200,000 － 720,000 ＝ 480,000円 → 300,000円で売ったので、180,000円の売却損
::journal
減価償却累計額 720,000 | 備品 1,200,000
現金 300,000 |
固定資産売却損 180,000 |
::
::
::

## 固定資産台帳 ― 1台ごとの「戸籍」

ナイトオウル交通は20台のバスを持っている。それぞれ取得した時期も、取得原価も、減価償却の進み具合も違う。そこで、固定資産を1つずつ管理する補助簿として**固定資産台帳**を設ける。

::

## 修繕か、改良か ― 資本的支出と収益的支出

バスのエンジンを修理したら、その費用はどうなるか。故障した部分を元の状態に戻すための支出（**収益的支出**）は、**修繕費**（費用）として処理する。
一方、座席をフルフラットに近いものに交換して価値を高めたり、改造によって耐用年数を延ばしたりする支出（**資本的支出**）は、固定資産の取得原価に加える。3級では修繕費の処理を押さえ、資本的支出の詳しい計算は2級で学ぶ。

::journal バスのエアコンの故障を修理し、修理代300,000円を普通預金から支払った（収益的支出）
修繕費 300,000 | 普通預金 300,000
::

## 減価償却は「お金が出ていかない費用」である

ここで、経営の視点から最も重要なことを伝えておきたい。減価償却費は、**お金が出ていかない費用**だということだ。
バスの代金5,000万円は、買った日にすでに支払っている。2年目以降に計上される減価償却費1,000万円は、帳簿の上で費用になるだけで、その年に新たにお金が出ていくわけではない。だから、会社が本業で生み出すお金は、おおまかに言えば「利益＋減価償却費」で見積もることができる。

::theory EBITDA ― 「減価償却の前」の稼ぐ力
投資やM&Aの世界では、**EBITDA**（イービットディーエー）という指標がよく使われる。営業利益に減価償却費を足し戻したもので、会社が本業で生み出すキャッシュの大きさの目安になる。
EBITDA ＝ 営業利益 ＋ 減価償却費
バス会社やジムのように、高額な設備を使うビジネスは、減価償却費が大きいので、利益が小さく見えてもEBITDAは大きいことが多い。ただし、それは「設備の更新にお金がかからない」という意味ではない。5年後にはバスを買い替えなければならないのだから、EBITDAから将来の設備投資を差し引いて考えなければならない。
::

::danger 減価償却の「2つの罠」
**罠1：耐用年数で利益を作る**
5年で償却するバスを「10年使える」と見積もれば、年間の減価償却費は半分になり、利益は大きく見える。耐用年数の見積りには判断の余地があり、そこが利益操作の入り口になりうる。だから、一度決めた方法や耐用年数は、正当な理由なく変更できない（継続性の原則）。また、業績を良く見せようと減価償却そのものを計上しない中小企業もあるが、銀行は審査の際に、計上すべき減価償却費を差し引いて実態の利益を計算し直している。
**罠2：減価償却費の分のお金を使い切る**
減価償却費の分だけ、利益より多くのお金が手元に残る。だが、そのお金は「5年後にバスを買い替えるための原資」だ。これを配当や本業以外の投資に使い切ってしまうと、5年後、20台のバスが一斉に寿命を迎えたとき、買い替えるお金がない。会社は、利益を出しながら、静かに「設備の寿命」という時限爆弾を抱えることになる。
::

::cfo 社長「今期は利益が足りない。減価償却を減らせないか？」
今期のナイトオウル交通は、燃料費の高騰で利益が伸び悩んでいる。銀行に提出する決算書を前に、社長がつぶやいた。「バスはまだまだ走れる。耐用年数を5年から8年に延ばせば、減価償却費が減って利益が出るだろう？」。あなたなら、どう答えるか？
::answer
まず、会計のルールとして答える。「耐用年数は、経済的に使用できる期間を合理的に見積もって決めるものです。利益を出すために延ばすことはできません」。実際にバスの使用期間が延びる根拠（車両の改良、整備体制の強化など）があれば見直しはありうるが、その場合も理由と影響を説明する必要がある。
次に、銀行の視点で答える。「減価償却費を減らしても、銀行は見抜きます。そして、会社が現金を生み出す力（EBITDA）は1円も変わりません」。耐用年数をいじって作った利益は、銀行の信頼を失うリスクに見合わない。
そして、本当に伝えたいのはここだ。「利益が足りない本当の原因は、燃料費の高騰です。そちらに手を打ちましょう」。燃料費の上昇分を運賃に反映する時期、燃費の良い運転の徹底、路線ごとの採算の見直し。数字をいじるのではなく、事業を変える。それが、決算書を本当に良くする唯一の方法である。
::
::

## {{new:2027年度〜}} 定率法と、固定資産の除却・廃棄

2027年4月以降の試験では、2級で学んでいた次の論点が、3級の範囲に加わる予定だ（暫定版）。

### 定率法 ― 最初に多く、後になるほど少なく

**定率法**は、毎期の期首の帳簿価額（未償却残高）に一定の**償却率**をかけて、減価償却費を計算する方法だ。最初の年に最も多く償却し、年が経つほど償却額が減っていく。

::formula 定率法
減価償却費 ＝（取得原価 － 期首の減価償却累計額）× 償却率
::

::example トレッドミルを定率法で償却する
IRONWORKS 24は、取得原価1,000,000円のトレッドミル（備品）を、償却率40%の定率法で償却している。1年目〜3年目の減価償却費を求めなさい。
::answer
::table 定率法による減価償却費
| 年 | 期首の帳簿価額 | 減価償却費（×40%） | 期末の帳簿価額 |
| 1年目 | 1,000,000 | 400,000 | 600,000 |
| 2年目 | 600,000 | 240,000 | 360,000 |
| 3年目 | 360,000 | 144,000 | 216,000 |
::
トレーニングマシンやパソコンのように、新しいうちに価値が大きく下がり、性能の陳腐化も早い資産には、定率法のほうが実態に合うと考えられている。
::
::

::note
※実務の「200%定率法」で使う保証率・改定償却率は、3級では出題しないことが示されている（基礎的な仕組みの理解を目的とした簡易な出題）。
::

### 除却と廃棄 ― 使わなくなった固定資産を帳簿から消す

固定資産を使うのをやめて、帳簿から取り除くことを**除却**（じょきゃく）という。除却した資産にまだ売れる価値（スクラップとしての価値など）が見込まれる場合は、その見積額を**貯蔵品**（資産）とし、帳簿価額との差額を**固定資産除却損**（費用）とする。
処分する価値がなく、捨ててしまうことを**廃棄**という。廃棄したときは、帳簿価額と廃棄にかかった費用の合計を**固定資産廃棄損**（費用）とする。

::example IRONWORKS 24の古いマシン
(1) 取得原価1,200,000円、減価償却累計額1,080,000円のトレッドミルを除却した。部品として売却できる見込額は20,000円である。
(2) 取得原価1,200,000円、減価償却累計額1,080,000円のトレッドミルを廃棄した。廃棄費用30,000円は現金で支払った。
::answer
::journal (1) 除却：処分見込額は貯蔵品、残りは除却損
減価償却累計額 1,080,000 | 備品 1,200,000
貯蔵品 20,000 |
固定資産除却損 100,000 |
::
::journal (2) 廃棄：帳簿価額120,000円＋廃棄費用30,000円＝廃棄損150,000円
減価償却累計額 1,080,000 | 備品 1,200,000
固定資産廃棄損 150,000 | 現金 30,000
::
::
::

::exam 固定資産の急所
- 取得原価＝購入代価＋付随費用（仲介手数料・登記料・運送費・据付費・架装費など）。後払いは**未払金**。
- 定額法：（取得原価－残存価額）÷耐用年数。残存価額がゼロか10%かを必ず確認。
- 期中取得は「取得月から決算月まで」の月割。期中売却は「期首から売却月まで」の月割の減価償却費を計上してから売却損益を出す。
- 間接法の売却仕訳では、固定資産を**取得原価**で、減価償却累計額を**期首の累計額**で消す。
- **土地は減価償却しない**。土地の売却も「売却価額－帳簿価額」で損益を出す。
- 原状回復のための修理は修繕費。
- 2027年度以降は、定率法（簡易な出題）、除却（固定資産除却損・貯蔵品）、廃棄（固定資産廃棄損）も3級の範囲に入る予定。
::

::next 形のない資産 ― ゲーム開発費は「資産」か「費用」か
京都のインディーゲームスタジオ「ピクセルドラゴン」は、3年かけて開発したゲームをSteamで発売した。開発にかかった人件費は1億2,000万円。この1億2,000万円は、バスと同じように資産にして、何年かかけて償却すべきだろうか？
会計の答えは「場合による」だ。研究開発の段階の支出は、将来の収益が不確実なので、原則として発生した年の**費用**（研究開発費）になる。一方、製品として完成した後の機能改良などの支出は、**ソフトウェア**という**無形固定資産**として計上し、見込販売数量などに応じて償却する。2級では社内で使うソフトウェア（原則5年以内の定額法）を、1級では販売目的のソフトウェアを本格的に学ぶ。
SaaS企業やゲーム会社の決算書を読むとき、「何が資産になり、何が費用になっているか」を見抜く力は、投資判断を左右する。形のある資産を学んだあなたは、もう形のない資産の世界の入り口に立っている。
::

::summary
- 有形固定資産（建物・備品・車両運搬具・土地）は、購入代価＋付随費用で取得原価を記録する
- 減価償却は、取得原価を耐用年数にわたって費用に配分する手続き。時価の評価ではない
- 定額法：（取得原価－残存価額）÷耐用年数。期中取得・期中売却は月割で計算する
- 間接法では減価償却累計額（評価勘定）を使い、取得原価－累計額＝帳簿価額
- 売却損益＝売却価額－帳簿価額。売却代金の後受けは未収入金
- 減価償却費は「お金が出ていかない費用」。そのお金は、将来の設備更新の原資である
- 2027年度からは、定率法・除却（除却損・貯蔵品）・廃棄（廃棄損）も3級に加わる予定
::
