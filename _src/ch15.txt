近所に月額3,000円台の低価格ジムが次々とできて、IRONWORKS 24の会員は伸び悩んでいた。3月、社長の真壁は大勝負に出た。決算月に合わせた「年払いプラン、2か月分無料」キャンペーン。通常なら月7,980円×12か月の会費が、年払いなら10か月分の**79,800円**で1年間使い放題になる。
キャンペーンは大当たりした。駅前で配ったチラシとSNSの広告が当たり、3月だけで**3,000人**が年払いプランに申し込んだ。**2億3,940万円**が一気に口座に振り込まれた。
「これで今期は過去最高の売上だ！」
4月の決算の打ち合わせ。アイアンワークスの会議室には、真壁と松尾、そして顧問の一ノ瀬とひよりが座っていた。真壁は満面の笑みを浮かべていた。だが、経理部長の松尾の答えは冷ややかだった。
「社長。この2億3,940万円のうち、今期の売上にできるのは**1,995万円**だけです」
真壁は、助けを求めるようにひよりを見た。「会計事務所さんも、そう思うの？　お金は入ってるんだよ」
ひよりは、自分の財布の中の会員証を思い出した。学生時代、年払いで入った近所のジムには、結局4か月しか通わなかった。
お金は確かに、今期のうちに口座に入っている。それなのに、なぜ売上にできないのか？
::

## 発生主義 ― 「お金が動いた日」ではなく「価値が生まれた日」

「大川さん、真壁社長に説明してみてください」と一ノ瀬が言った。ひよりは深呼吸をして、ホワイトボードに12個のマス目を描いた。1つが1か月だ。
問いを解く鍵は、会計の根本原則の1つ、**発生主義**だ。

::theory 現金主義と発生主義
**現金主義**は、お金を受け取ったときに収益を、お金を支払ったときに費用を計上する考え方だ。家計簿やお小遣い帳の発想である。
**発生主義**は、お金の動きとは関係なく、**サービスや商品を提供したとき（価値が生まれたとき）**に収益を、**サービスや商品を使ったとき（価値を費やしたとき）**に費用を計上する考え方だ。
会社の会計は、発生主義にもとづいて損益を計算する。現金主義では、前払い・後払いのタイミングによって利益がいくらでも変わってしまい、「この期間に、本当にどれだけ稼いだのか」が分からなくなるからだ。
::

期中の仕訳は、ふつう、お金が動いたときに行う。だから決算日には、お金の動きと「その期に本当に発生した収益・費用」との間に、ずれが残っている。このずれを修正するために使う勘定を**経過勘定**という。経過勘定は、次の4つだ。

::table 経過勘定の4つの勘定
| 分類 | 勘定 | 要素 | どんなときに使うか |
| 繰延べ | 前払費用 | 資産 | 費用を支払ったが、まだサービスを受けていない部分がある |
| 繰延べ | 前受収益 | 負債 | 収益を受け取ったが、まだサービスを提供していない部分がある |
| 見越し | 未払費用 | 負債 | サービスを受けたが、まだ費用を支払っていない |
| 見越し | 未収収益 | 資産 | サービスを提供したが、まだ収益を受け取っていない |
::

::point 覚え方
「**前払**」と「**未収**」は、将来サービスを受け取る権利・お金を受け取る権利なので**資産**。「**前受**」と「**未払**」は、将来サービスを提供する義務・お金を支払う義務なので**負債**。
実際の勘定科目は、前払保険料、前受家賃、未払給料、未収利息のように、「前払・前受・未払・未収」＋「もとの勘定科目の名前」で表す。
::

## 前払費用 ― 払いすぎた費用を、来期に繰り延べる

ひよりは、ほかの顧問先の帳簿にも、同じ形の取引があることに気づいた。まず、お金を「先に払った」側だ。ナイトオウル交通は、バスの車両保険の保険料を、1年分まとめて前払いしている。

::example 前払保険料（ナイトオウル交通）
12月1日、バスの車両保険料1年分（12月1日〜翌年11月30日）2,400,000円を普通預金から支払った。決算日は3月31日である。
::answer
::journal 12月1日：支払時（ふつうに費用で処理する）
保険料 2,400,000 | 普通預金 2,400,000
::
3月31日の時点で、保険のサービスを受けたのは12月〜3月の**4か月分**だけ。4月〜11月の**8か月分**は、来期のための支払いだ。その分を当期の費用から取り除き、**前払保険料**（資産）として来期に繰り延べる。
前払分 ＝ 2,400,000 × 8/12 ＝ 1,600,000円
::journal 3月31日：決算整理（前払分を資産に振り替える）
前払保険料 1,600,000 | 保険料 1,600,000
::
これで、当期の保険料は800,000円（4か月分）になった。
::
::

::boxes 2,400,000円の保険料を、当期と来期に分ける
H 支払った保険料（12か月分） | 行き先
L x 100 保険料<br>2,400,000円<br>（12/1〜11/30）
R x 33 当期の費用<br>800,000円<br>（12月〜3月）
R a 67 前払保険料（資産）<br>1,600,000円<br>（4月〜11月）
::

## 前受収益 ― 受け取りすぎた収益を、来期に繰り延べる

次は、お金を「先に受け取った」側。年払いの会費と同じ形だが、3級の試験でよく出る家賃の例で確かめておこう。IRONWORKS 24の京都本店には、入口の一角を、プロテインスムージーのスタンドに貸しているスペースがある。家賃は半年分の前払いだ。

::example 前受家賃（IRONWORKS 24）
2月1日、スムージースタンドから、6か月分（2月1日〜7月31日）の家賃600,000円が普通預金に振り込まれた。決算日は3月31日である。
::answer
::journal 2月1日：受取時（ふつうに収益で処理する）
普通預金 600,000 | 受取家賃 600,000
::
3月31日の時点で、場所を貸したのは2月・3月の**2か月分**。4月〜7月の**4か月分**は、来期に場所を貸す義務が残っている。その分を当期の収益から取り除き、**前受家賃**（負債）として繰り延べる。
前受分 ＝ 600,000 × 4/6 ＝ 400,000円
::journal 3月31日：決算整理（前受分を負債に振り替える）
受取家賃 400,000 | 前受家賃 400,000
::
::
::

::solve 2億3,940万円のうち、11か月分は「これから提供するサービス」の代金
年払いプランの会費79,800円は、**12か月分**のジムの利用サービスの対価だ。3月に入会した会員に、3月31日までに提供したサービスは、**3月の1か月分**だけ。残りの11か月分は、来期にジムを使わせる義務が残っている。
発生主義では、収益は「お金を受け取ったとき」ではなく「サービスを提供したとき」に計上する。だから、今期の売上にできるのは、1か月分だけなのだ。

::table 年払いプランの会費の行方
| 項目 | 計算 | 金額 |
| 3月に受け取った会費 | 79,800円×3,000人 | 239,400,000 |
| うち今期の収益（3月の1か月分） | 239,400,000×1/12 | 19,950,000 |
|= うち来期以降の収益（前受収益） | 239,400,000×11/12 | 219,450,000 |
::
::journal 3月31日：決算整理（会費を「受取会費」で処理している場合）
受取会費 219,450,000 | 前受会費 219,450,000
::
2億1,945万円は、帳簿の上では「お客様に1年間ジムを使わせる約束」という**負債**だ。もし来月ジムが閉鎖されれば、返金しなければならないお金である。真壁が見ていた「過去最高の売上」は、来期の売上の前借りにすぎなかった。
::

ホワイトボードの12個のマス目のうち、ひよりは1つだけを塗りつぶした。「今期、お客様にお渡しできたのは、このひと月分だけです」
真壁は腕を組んだまま、しばらく黙っていた。「つまり、残りの11マス分は、まだ借りてるお金ってことか」

::note
※会費の勘定科目は会社が定める（ここでは「受取会費」）。3級の試験では、前受収益は主に受取家賃・受取地代・受取利息などで出題される。また、2級以降で学ぶ収益認識の基準では、こうした前受けの対価は「契約負債」として扱われる。
::

## 未払費用 ― まだ払っていない費用を、当期に見越す

帰り道、一ノ瀬は言った。「前払いと前受けの『繰延べ』が分かったら、逆の『見越し』も同じ図で解けます」。今度は、お金がまだ動いていないのに、費用や収益だけが先に生まれているケースだ。おかわり堂の給料は、**20日締め・25日払い**。毎月21日から翌月20日までの労働に対する給料を、翌月25日に支払う。

::example 未払給料（おかわり堂）
おかわり堂の給料は20日締め・25日払いである。決算日の3月31日時点で、3月21日〜31日の11日分の給料8,800,000円（深夜帯の割増分を含む）が、まだ支払われていない。
::answer
3月21日〜31日の労働は、すでに当期に提供されている。給料を払うのは4月25日でも、費用はすでに**当期に発生している**。だから、当期の費用として**見越し**計上し、まだ払っていない義務を**未払給料**（負債）とする。
::journal 3月31日：決算整理（当期の費用として見越す）
給料 8,800,000 | 未払給料 8,800,000
::
::
::

::point 「未払金」と「未払費用」は違う
どちらも「まだ払っていないお金」だが、意味が違う。
- **未払金**：商品以外の物品の購入代金など、**支払う金額と時期がすでに確定した**債務（第9章）。期中の取引で発生する。
- **未払費用**：家賃・給料・利息など、**継続的にサービスを受ける契約**で、すでに受けたサービスに対する、支払期日が来ていない対価。決算整理で計上する。
同じように、未収入金と未収収益、前払金と前払費用、前受金と前受収益も、それぞれ区別しよう。
::

## 未収収益 ― まだ受け取っていない収益を、当期に見越す

::example 未収利息（洛北ミート）
洛北ミートは、10月1日に取引先に5,000,000円を年利率3%で貸し付けた。利息は1年分を翌年9月30日に後払いで受け取る約束である。決算日は3月31日。
::answer
10月1日〜3月31日の**6か月分**の利息は、お金はまだ受け取っていないが、お金を貸すというサービスはすでに提供済みだ。当期の収益として見越し計上し、**未収利息**（資産）とする。
未収分 ＝ 5,000,000 × 3% × 6/12 ＝ 75,000円
::journal 3月31日：決算整理（当期の収益として見越す）
未収利息 75,000 | 受取利息 75,000
::
::
::

::table 4つの経過勘定の決算整理仕訳
| 種類 | 決算整理仕訳 | 当期の損益への影響 |
| 前払費用 | 前払〇〇 ／ 〇〇（費用） | 費用を減らす |
| 前受収益 | 〇〇（収益） ／ 前受〇〇 | 収益を減らす |
| 未払費用 | 〇〇（費用） ／ 未払〇〇 | 費用を増やす |
| 未収収益 | 未収〇〇 ／ 〇〇（収益） | 収益を増やす |
::

## 再振替仕訳 ― 翌期首に「元に戻す」

経過勘定は、決算日の損益を正しく計算するための、一時的な修正だ。そこで、**翌期の期首**に、決算整理仕訳と**逆の仕訳**を行い、もとの費用・収益の勘定に戻す。これを**再振替仕訳**という。第4章の当座借越でも登場した手続きだ。

::journal 翌期4月1日：前払保険料の再振替仕訳
保険料 1,600,000 | 前払保険料 1,600,000
::

::journal 翌期4月1日：未払給料の再振替仕訳
未払給料 8,800,000 | 給料 8,800,000
::

::theory なぜ元に戻すのか ― 二重計上を防ぐ
未払給料の例で考えよう。4月25日に、3月21日〜4月20日分の給料を支払うと、期中の仕訳は「給料／普通預金」となり、給料の全額が翌期の費用に計上される。だが、そのうち3月21日〜31日の11日分は、すでに当期の費用として計上済みだ。このままでは**二重に費用になる**。
期首に「未払給料／給料」と再振替しておくと、翌期の給料勘定は、期首に11日分の**マイナス**からスタートする。そこに4月25日の支払額が加わるので、結果として翌期の給料は、正しく「4月1日以降の分」だけになる。
再振替仕訳は、期中の仕訳をいつもどおり単純に行うための、よくできた仕掛けなのである。
::

::tgrid
::taccount 保険料（翌期）
4/1 前払保険料 1,600,000 |
12/1 普通預金 2,400,000 |
::
::taccount 前払保険料（翌期）
4/1 前期繰越 1,600,000 | 4/1 保険料 1,600,000
::
::

::note
※翌期の12月1日に、また1年分2,400,000円を支払えば、翌期の決算でも同じように8か月分を前払保険料に振り替える。翌期の保険料は、4月〜11月の8か月分（前期からの再振替分1,600,000円）と、12月〜3月の4か月分（800,000円）の合計2,400,000円となり、ちょうど12か月分になる。
::

## 勘定記入 ― 第2問の定番を1年分たどる

試験の第2問では、経過勘定に関係する勘定に1年分の記入をさせ、締め切らせる問題がよく出る。期首の再振替、期中の支払い、決算整理、損益への振替、次期繰越が、1つの勘定に順番に並ぶ。

## 貯蔵品 ― 使い残した切手と収入印紙

第14章で、郵便切手は購入時に**通信費**、収入印紙は**租税公課**として費用処理すると学んだ。だが、決算日に使わずに残っている切手や印紙は、来期に使える「資産」だ。そこで、未使用分を**貯蔵品**（資産）に振り替える。

::example 貯蔵品（ナイトオウル交通）
決算日に、郵便切手8,400円分と収入印紙20,000円分が未使用で残っていた。
::answer
::journal 3月31日：決算整理
貯蔵品 28,400 | 通信費 8,400
 | 租税公課 20,000
::
::journal 翌期4月1日：再振替仕訳
通信費 8,400 | 貯蔵品 28,400
租税公課 20,000 |
::
::
::

::note
※事務用品などの消耗品は、3級では購入時に「消耗品費」として費用処理し、期末に未使用分があっても原則として資産に振り替えない。貯蔵品に振り替えるのは、主に郵便切手・収入印紙など、換金性の高いものである。
::

::danger 「売上の前倒し」は、粉飾の王道
年払いの会費を受け取った月に全額を売上にすれば、その期の売上と利益は大きく膨らむ。翌期の売上は小さくなるが、翌期にまた大きなキャンペーンを打てば、穴は埋められる……。
こうして将来の売上を前借りし続ける会計処理は、成長が止まった瞬間に破綻する。前倒しで計上した売上は、実際にはまだ提供していないサービスの代金であり、事業が止まれば返金しなければならない負債だからだ。
国内外の粉飾事件で最も多い手口の1つが、まさにこの**収益の前倒し計上**だ。経過勘定は、「いつの売上か」を厳格に区切ることで、この誘惑から会社と投資家を守る仕組みなのである。
::

::real 120万人が前払いした脱毛サロンの破産
2025年8月18日、脱毛サロン「ミュゼプラチナム」を運営していたMPHが、東京地裁から破産手続きの開始決定を受けた。負債は約260億円。東京商工リサーチによると、前払いで契約していた利用者は**120万人**を超える。
脱毛サロンは、何回分もの施術の代金を先に受け取り、施術はあとから少しずつ提供するビジネスだ。受け取った代金には、まだ提供していない「将来の施術」の分が含まれている。同社は、契約者から受け取ったお金を広告や出店に充てて事業を広げていたという。2024年11月からは従業員の給料の遅れが始まり、最後は従業員が債権者として破産を申し立てた。
まだサービスを提供していない分の代金は、会社の「稼ぎ」ではなく、利用者に対する「借り」である。帳簿の上で前受けの負債として区別し、その分のお金を残しておかなければ、新しい契約が止まった瞬間に、施術も返金もできなくなる。

**この章の道具で読む ― 10回コースの代金を、1回ずつ売上にする**
脱毛サロンの取引を、IRONWORKS 24の年払い会費と同じ考え方で記録してみよう。1人の客が、10回分の施術の代金20万円を契約時に一括で払ったとする（金額は例）。

::journal 契約時：10回分の代金を受け取った（まだ1回も施術していない）
普通預金 200,000 | 前受金 200,000
::
::journal 施術を1回行うごとに：1回分の2万円だけを売上にする
前受金 20,000 | 売上 20,000
::

3回通った時点の決算なら、売上は6万円、残りの14万円は前受金（負債）として貸借対照表に残る。この14万円は、あと7回施術する義務であり、店がなくなれば返すべきお金だ。
規模に置き直してみよう。仮に、契約者1人あたりの未消化の施術が平均1万円分だけだったとしても、120万人なら120億円の負債になる。帳簿の上でこの負債が正しく見えていれば、「預かった代金に見合うお金が残っているか」を経営者も取引先も確かめられる。契約時に全額を売上にしてしまえば、この120億円は帳簿から消え、利益だけが大きく見える。下の「判断してみよう」で、真壁が年払いの代金をマシン購入に回そうとしているのは、まさにこの境目の判断だ。
::note
出典：[東京商工リサーチ「ミュゼ破産で浮き彫り、勝者なき脱毛サロンの消耗戦」（2025年8月20日）](https://www.tsr-net.co.jp/data/detail/1201677_1527.html)
::

::cfo 年払いキャンペーンを、来年も続けるか ― 1人あたりの手取りと「使ってよいお金」
年払いプランは、通常価格の約17%引きだ。しかも売上は来期に繰り延べられ、今期の業績にはほとんど効かない。真壁は「割引しただけで、会社は損をしたのでは？」と不安になってきた。一方で「入ってきた2億3,940万円のうち、1億5,000万円で新店のマシン一式を買いたい」とも言う。松尾とひよりは、判断の材料を集めた。
- 月払いの会員は、平均すると**8か月**で退会する
- 年払いの会員のうち**15%**が途中で退会し、その人たちには平均で**残り6か月分**（1か月あたり79,800円÷12＝6,650円）を返金している
- 会員1人を1か月受け入れるのにかかる運営費（家賃・人件費・光熱費などを会員数で割ったもの）は、約**4,000円**
- 年払い会員3,000人からは、この先11か月、追加のお金は1円も入ってこない。だが運営費は毎月かかる
- ジムが2か月休業すると（感染症の流行など）、年払い会員には2か月分を返金する決まりだ
まず、プランごとの**会員1人あたりの手取り（返金を差し引いた金額）**を計算する。次に、2億3,940万円のうち、これから11か月の運営費と返金に充てるために残すべき金額を計算してから選んでほしい。
::choice A. 割引は損なので、キャンペーンをやめる
**× 返金を差し引いても、1人あたりの手取りは月払いより多い。**月払いは平均8か月で退会するので、1人から受け取るのは7,980円×8か月＝63,840円。年払いは79,800円から、平均の返金（15%×6,650円×6か月＝5,985円）を引いて**73,815円**。割引しても、月払いより約1万円（約16%）多い。17%の割引は、「途中でやめる自由」を手放してもらう代わりの値引きで、退会の多いジムでは元が取れている。
::
::choice B. 続ける。11か月分の運営費と返金見込みは預金で残し、マシンはリースで用意する
**◎ 続ける価値があり、お金の使い道も前受けの性質に合っている。**3,000人×4,000円×11か月＝1億3,200万円は、これから11か月、会費が入ってこない会員にサービスを提供するための運営費だ。返金見込みは3,000人×15%×6,650円×6か月＝約1,796万円。合わせて約1億5,000万円は、使ってはいけないお金になる。
自由に使えるのは残りの約8,944万円で、2か月の休業に備えた払い戻し（3,000人×6,650円×2か月＝3,990万円）まで残せば、約4,954万円。1億5,000万円のマシンは、とても買えない。5年使うマシンは、5年のリースや借入れでまかなうのが筋だ。
::
::choice C. 続け、集まった2億3,940万円から1億5,000万円を新店のマシンに使う
**× 「入ってきたお金」と「使ってよいお金」を取り違えている。**マシンを買うと、残りは8,940万円。ところが、これから11か月の運営費1億3,200万円と返金見込み約1,796万円を払うには、約**6,000万円足りない**。足りない分は、来年また年払いキャンペーンで新しい前受けを集めて埋めるしかなくなる。新しい契約が止まった瞬間に立ち行かなくなる構図は、上の「実際にあった話」と同じだ。
::
::choice D. 割引を4か月分に広げ、もっと会員を集める
**× 返金まで含めると、月払いより手取りが減る。**4か月分無料なら、年払いの会費は8か月分の63,840円。途中退会の返金は1か月あたり5,320円になり、平均の返金は15%×5,320円×6か月＝4,788円。手取りは**59,052円**と、月払い（63,840円）より約4,800円少ない。会員1人から受け取るお金は減るのに、1年間サービスを提供する義務だけが残る。割引の幅は、退会の多さと返金の見込みとの兼ね合いで決まるのである。
::
::answer 考え方の例を見る
::table 会員1人あたりの手取り（返金を差し引いた金額）
| プラン | 受け取る会費 | 平均の返金 | 手取り |
| 月払い（平均8か月で退会） | 63,840円 | なし | 63,840円 |
| 年払い（2か月分無料） | 79,800円 | 5,985円 | 73,815円 |
| 年払い（4か月分無料） | 63,840円 | 4,788円 | 59,052円 |
::
::table 2億3,940万円のうち、使ってよいお金（単位：万円）
| 項目 | 金額 |
| 3月に受け取った年払いの会費 | 23,940 |
| これから11か月の運営費（3,000人×4,000円×11か月） | △13,200 |
| 途中退会の返金見込み | △約1,796 |
| 2か月休業したときの払い戻しへの備え | △3,990 |
|= 自由に使えるお金 | 約4,954 |
::
前受けのお金について、実務で必ず押さえることは2つある。
- **損得は、返金まで含めた「手取り」で比べる**：割引の幅は、顧客の行動（退会の多さ）と返金の見込みで、得にも損にもなる。
- **前受けのお金は「来年の収入の前倒し」でもある**：帳簿では前受収益（負債）として繰り延べるが、資金繰りの上では「この先11か月、この会員からは入金がない」ことを意味する。その間の運営費を払うお金を残さずに使えば、次の前受けで穴を埋め続けるしかなくなる。
会計上、売上が来期に繰り延べられるのは、損でも得でもない。**正しい時期に正しく計上される**というだけのことだ。その正しい記録が、使ってよいお金と、残しておくべきお金の境界線を示してくれる。真壁はキャンペーンを続け、新店のマシンは5年のリースで用意することにした。
::

::exam 経過勘定の急所
- 4つの決算整理仕訳の形を確実に覚える。「前払・未収」は資産、「前受・未払」は負債。
- 月数の計算が勝負。「12月1日に1年分支払い、決算は3月31日」なら、当期4か月・前払8か月。
- 再振替仕訳は、翌期首に決算整理仕訳の逆を行う。第2問の勘定記入問題では、期首の再振替・期中の支払い・期末の決算整理の3つが1つの勘定に並ぶ。
- 未払金と未払費用、未収入金と未収収益、前払金と前払費用、前受金と前受収益を混同しない。
- 精算表・財務諸表では、前払保険料などは「前払費用」、前受家賃などは「前受収益」、未払給料などは「未払費用」、未収利息などは「未収収益」と表示されることが多い。
- 未使用の切手・収入印紙は貯蔵品へ振り替える。
::

::next 「いつ売上になるのか」をめぐる、終わりなき問い
2級・1級で学ぶ**収益認識に関する会計基準**は、「顧客との契約を識別し、履行義務を特定し、取引価格を算定し、配分し、履行義務を充足したときに収益を認識する」という5つのステップで、あらゆる取引の売上の計上時期と金額を定めている。ジムの年会費、ソフトウェアのサブスクリプション、ポイント付きの販売、保守サービス付きの機械の販売……。
本章で学んだ「お金を受け取った日ではなく、価値を提供した日に収益を計上する」という発生主義の考え方は、その巨大な体系の出発点だ。SaaS企業の決算書で、前受収益（契約負債）が売上と同じくらい注目されるのは、それが「すでに契約済みで、これから売上になるお金」を表しているからである。
::

::summary
- 会計は発生主義。収益は価値を提供したとき、費用は価値を費やしたときに計上する
- 繰延べ：前払費用（資産）・前受収益（負債）は、当期の費用・収益から来期分を取り除く
- 見越し：未払費用（負債）・未収収益（資産）は、まだお金が動いていない当期分を計上する
- 翌期首には、決算整理仕訳の逆の再振替仕訳を行い、二重計上を防ぐ
- 未使用の切手・収入印紙は貯蔵品（資産）に振り替える
- 前受けの売上を受取時に全額計上するのは、粉飾の王道。経過勘定は「いつの売上か」を厳格に区切るための仕組みである
::
