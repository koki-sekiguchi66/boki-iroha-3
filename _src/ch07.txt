ところが3月の半ば、社長の北村は、決算前に確かめておこうと開いたネットバンキングの画面の前で、言葉を失った。

その日の夕方、ひよりの携帯が鳴った。中西からだ。
中西：「大川さん、またです。今度は小切手じゃなくて、預金そのものが消えているんです」
ひより：「消えてる……って、いくらですか」

利益が3,000万円出ているのに、お金が3,100万円減っている。売上が伸びるほど、お金が消えていく。
電話を切ったひよりの頭に、序章のホワイトボードがよみがえった。「黒字なのに、お金が減る」。父の店と同じ言葉だった。
いったい、お金はどこへ行ったのか？

## 掛取引 ― 「信用」で売り、「信用」で買う

翌朝、ひよりは一ノ瀬と洛北ミートに向かった。社用車のハンドルを握ったまま、一ノ瀬は1つだけ聞いた。
一ノ瀬：「洛北ミートは、肉を売った日に、代金を受け取っていますか」
ひより：「いえ。中西さんが、月末に締めて、翌月末に払ってもらうって言ってました」
一ノ瀬：「そう。**掛け**です。肉は先に渡して、お金はあとでまとめてもらう。相手を信用して、代金を待つ取引です」
ひより：「信用で、売る」
一ノ瀬：「逆に、仕入れるときも掛けです。畜産会社から肉を先にもらって、代金はあとで払う。売る側に生まれるのが、あとで代金をもらう権利。買う側に生まれるのが、あとで払う義務です」

::table 掛取引で使う2つの勘定科目
| 勘定科目 | 要素 | 意味 |
| 売掛金 | 資産 | 商品を掛けで売ったときの、後で代金を受け取る権利 |
| 買掛金 | 負債 | 商品を掛けで仕入れたときの、後で代金を支払う義務 |
::

事務所に着くと、中西が10月の伝票を用意して待っていた。

::example 洛北ミートの掛取引
(1) 焼肉店「炎（ほむら）」に牛ばら肉720,000円を掛けで販売した。
(2) 畜産会社Bから牛ばら肉420,000円を掛けで仕入れた。
(3) 焼肉店「炎」から、前月分の売掛金980,000円が普通預金に振り込まれた。
(4) 畜産会社Bに、買掛金600,000円を普通預金から振り込んで支払った。
::answer
::journal (1) 掛け売上：売掛金（資産）の増加
売掛金 720,000 | 売上 720,000
::
::journal (2) 掛け仕入：買掛金（負債）の増加
仕入 420,000 | 買掛金 420,000
::
::journal (3) 売掛金の回収：売掛金の減少
普通預金 980,000 | 売掛金 980,000
::
::journal (4) 買掛金の支払い：買掛金の減少
買掛金 600,000 | 普通預金 600,000
::
::trap
(3)と(4)で、売上や仕入をもう一度計上してはいけない。収益と費用は、商品を引き渡した(1)(2)の時点で記録済みだ。
代金のやり取りでは、売掛金・買掛金が消えるだけである。
::
::
::

中西：「でも、きれいな金額で振り込んでくれるお店ばかりじゃないんです。振込手数料を引いて、入れてくるところもあって」

::example 振込手数料を差し引いて振り込まれた売掛金
焼肉店「炎」から、10月分の売掛金720,000円が、振込手数料660円を差し引いて普通預金に振り込まれた。振込手数料は、洛北ミートが負担する約束になっている。
::answer
::journal 差し引かれた手数料は、当社負担なので支払手数料
普通預金 719,340 | 売掛金 720,000
支払手数料 660 |
::
口座に入ったのは719,340円でも、売掛金は720,000円全額が消える。差額の660円は、洛北ミートが負担した振込手数料（**支払手数料**、費用）だ。もし手数料は得意先の負担という約束なのに差し引かれていたら、660円はまだ回収できていない売掛金として残し、得意先に請求する。約束を確かめずに支払手数料で処理すると、毎月少しずつ、受け取るべきお金を取りこぼすことになる。
::trap
売掛金を、入金された719,340円だけ減らしてはいけない。それでは660円の売掛金が帳簿に残り続ける。
消すのは請求額の720,000円全額で、入金額との差が支払手数料になる。
::
::
::

::point 売掛金・買掛金は「商品売買」専用
売掛金と買掛金を使うのは、**本業の商品売買**から生じた債権・債務だけだ。商品以外のもの（バス、パソコン、不要になった備品など）を後払いで売買したときは、**未収入金**・**未払金**という別の勘定科目を使う（第9章）。試験で頻出のひっかけポイントだ。
::

## 売掛金元帳と買掛金元帳 ― 取引先ごとの「貸し借り台帳」

中西：「売掛金が増えたのは分かりました。でも、どこで増えたんでしょう」
中西は、総勘定元帳の売掛金のページを開いた。得意先は約150店。ページには、全部を合わせた金額しか書いていない。
ひより：「どのお店に、いくら貸しているのかは……」
中西：「ここからは、分かりません」
一ノ瀬：「だから、取引先ごとにページを分けた帳簿を、もう1冊持ちます。得意先ごとの**売掛金元帳**と、仕入先ごとの**買掛金元帳**です」

::table compact sum 売掛金元帳（得意先元帳）　焼肉店「炎」
| 日付 | 摘要 | 借方 | 貸方 | 借／貸 | 残高 |
| 10/1 | 前月繰越 | 980,000 |  | 借 | 980,000 |
| 10/12 | 売上 | 720,000 |  | 借 | 1,700,000 |
| 10/31 | 普通預金で回収 |  | 980,000 | 借 | 720,000 |
| 10/31 | 次月繰越 |  | 720,000 |  |  |
|= |  | 1,700,000 | 1,700,000 |  |  |
::

::theory 総勘定元帳の売掛金 ＝ 売掛金元帳の合計
総勘定元帳の売掛金勘定は、すべての得意先の売掛金をまとめた「合計」の勘定だ。そのため、**売掛金勘定の残高は、売掛金元帳の各得意先の残高の合計と必ず一致する**。このような関係にある総勘定元帳の勘定を、**統制勘定**と呼ぶ。
もし一致しなければ、どちらかに記入漏れや誤りがある。合計と内訳を突き合わせることで、記録の正しさを確かめられる。買掛金勘定と買掛金元帳も、まったく同じ関係だ。
::

::note
※売掛金・買掛金の代わりに、取引先の名前（例：「焼肉店炎」）をそのまま勘定科目として使う方法を**人名勘定**という。日本商工会議所の勘定科目表では「〇〇商店」が売掛金・買掛金の許容科目とされているが、ふつうは売掛金・買掛金を使えばよい。
::

中西が、得意先ごとの残高を一覧にして印刷した。上のほうに並ぶのは、この1年で取引を始めた新しい店ばかりだった。

::table sum 10月末の売掛金の内訳（抜粋）
| 得意先 | 10月末残高 | 回収条件 |
| 焼肉店「炎」 | 720,000 | 月末締め・翌月末払い |
| おかわり堂 | 18,500,000 | 月末締め・翌月末払い |
| 居酒屋チェーンA | 12,400,000 | 月末締め・翌々月末払い |
| その他 約150店 | 193,380,000 | 店ごとに異なる |
|= 合計（＝売掛金勘定の残高） | 225,000,000 | 月商の1.5か月分 |
::

## クレジット売掛金 ― カード払いは「カード会社への売掛金」

掛けで売る相手は、飲食店だけではない。同じ週、ひよりはIRONWORKS 24を運営するアイアンワークスの巡回で、経理部長の松尾から質問を受けた。
松尾：「会員さんの多くは、月会費をカードで払います。カードで払ってもらった会費は、いつ、何として記録すればいいでしょう」
ひより：「カードで払ってもらったら、もう入金されたんじゃないんですか」
松尾：「それが、入金は翌月末なんです。しかも、カード会社の手数料を引かれて入ってきます」
一ノ瀬：「つまり、ジムがあとでお金をもらう相手は、会員さんではなく、カード会社です。この権利は、ふつうの売掛金と分けて、**クレジット売掛金**にします。カード会社に払う手数料は、売った時点で支払手数料にします」

::example IRONWORKS 24のカード決済
(1) 6月分の月会費のうち、クレジットカード決済分は2,000,000円だった。カード会社への決済手数料は売上の3%である。
(2) 7月末、カード会社から、手数料を差し引いた金額が普通預金に入金された。
::answer
::journal (1) 販売時：手数料を差し引いた額をクレジット売掛金とする
クレジット売掛金 1,940,000 | 売上 2,000,000
支払手数料 60,000 |
::
::journal (2) 入金時
普通預金 1,940,000 | クレジット売掛金 1,940,000
::
売上は手数料を差し引く前の**総額**（2,000,000円）で計上する。手数料60,000円（2,000,000円×3%）は費用。クレジット売掛金は、実際に入金される1,940,000円になる。
::trap
売上を、手数料を差し引いた後の1,940,000円にしないこと。売上は客に請求した総額で計上する。
手数料を計上するのは、入金時ではなく**販売時**だ。入金時の仕訳には支払手数料は出てこない。
::
::
::

::point {{new:2027年度〜}} キャッシュレス決済も同じ考え方
2027年度以降の出題区分表（暫定版）では、クレジット売掛金に「キャッシュレス決済を含む」と明記される予定だ。QRコード決済や電子マネーで支払われた代金も、決済事業者から後日入金される債権として、クレジットカードと同じように処理すると考えればよい。
::

## 受取商品券 ― 他社が発行した商品券は「代金を受け取る権利」

その帰り道に寄ったおかわり堂の出町柳店では、坂口がレジの引き出しから紙の束を見せてくれた。
坂口：「ひよりさん、これ。お食事券と、地域振興券です。この前、別の封筒に分けるって話になったやつ」
ひより：「現金じゃないから、だよね。じゃあ、これは何なんだろう」
坂口：「月末に、券を発行元に送ると、お金に換えてもらえます」
ひよりは、手帳に書いた。他社の商品券を受け取ったら、あとで発行元から代金をもらえる権利。**受取商品券**という資産だ。

::example おかわり堂の商品券払い
(1) 学生グループの宴会代金35,000円のうち、30,000円は地域振興券で、残りは現金で受け取った。
(2) 月末に、受け取った地域振興券30,000円を発行元に送付して精算を依頼し、同額が普通預金に入金された。
::answer
::journal (1) 受け取った商品券は「受取商品券」
受取商品券 30,000 | 売上 35,000
現金 5,000 |
::
::journal (2) 精算されたとき
普通預金 30,000 | 受取商品券 30,000
::
::trap
受け取った商品券を「現金」としないこと。商品券は、発行元にあとで代金を請求できる権利なので、**受取商品券**（資産）で記録する。
商品券と現金を合わせて受け取ったときは、売上を2つに分けず、1本の仕訳にまとめる。
::
::
::

::note
※自社が発行した商品券を販売したときは、将来その商品券で商品を引き渡す義務が生じる。これは負債となるが、2級以降の論点である。3級で扱うのは、他社が発行した商品券を受け取る側の処理だ。
::

## 答え合わせ ― お金は「売掛金」に姿を変えていた

::scene 3月18日、午後9時 ― 洛北ミートの事務所
ひよりの提案で、中西は売掛金元帳を得意先ごとに1枚ずつ印刷し、会議テーブルに並べていた。150店分。テーブルの端から端まで、紙が埋めつくしている。北村が腕を組んで見下ろしている。
北村：「こんなもん並べて、何が分かるんや。わしは、金がどこへ消えたか聞いとるんや」
中西：「社長、去年の今ごろ、売掛金の合計は1億5,000万円でした。いまは2億2,500万円です」
北村：「売れとるんやから、増えるのは当然やろ」
中西：「はい。でも、売掛金は『まだ受け取っていない代金』です。新しいお店に肉を納めるたびに、うちは代金の45日分を立て替えている。お店が増えるほど、立て替えも増えるんです」
中西は、テーブルの端の1枚を指さした。開店したばかりの居酒屋チェーンの元帳だ。
中西：「このお店は、翌々月末の支払いです。売上が増えた分、うちのお金が、ここに眠っています」
北村は、しばらく黙って元帳の束を見ていた。
北村：「……誰も、盗んでへんかったんか」
ひより：「はい。お金は、消えたんじゃなくて、形を変えていたんです」
ひよりは、元帳の上に、自分で計算した1枚の表を置いた。
::

::solve 成長は、現金を食べる
洛北ミートのお金は、消えたのではない。**売掛金と在庫に姿を変えていた**のだ。
洛北ミートは、売った代金を平均**45日後**に受け取る。一方、仕入れた肉の代金は、畜産会社に平均**20日後**に支払わなければならない。さらに、肉を仕入れてから売るまで、平均**10日**は在庫として冷蔵庫に眠っている。
つまり洛北ミートは、肉の代金を払ってから回収するまでの間、ずっと自分のお金で立て替え続けている。そして売上が増えると、この「立て替え」の金額も比例して膨らむ。

::table 1年間で膨らんだ「立て替え」（運転資金）
| 項目 | 1年前 | 現在 | 増減 |
| 月商 | 1億円 | 1億5,000万円 | ＋5,000万円 |
| 売掛金（売上の約45日分） | 1億5,000万円 | 2億2,500万円 | ＋7,500万円 |
| 在庫（仕入の約10日分） | 2,700万円 | 4,000万円 | ＋1,300万円 |
| 買掛金（仕入の約20日分） | 5,300万円 | 8,000万円 | ＋2,700万円 |
|= 運転資金（売掛金＋在庫－買掛金） | 1億2,400万円 | 1億8,500万円 | ＋6,100万円 |
::
売上の伸びに合わせて、立て替えなければならないお金（**運転資金**）が6,100万円も増えた。税引後利益3,000万円をすべてつぎ込んでも、まだ3,100万円足りない。その不足分だけ、預金が減ったのである。
（6,000万円＋3,000万円－6,100万円＝2,900万円）
掛けで売るということは、**取引先に無利息でお金を貸している**のと同じだ。売上が伸びるほど、貸しているお金も膨らむ。これが「売れたのに、お金がない」の正体だ。
::

北村は、表の最後の行を、指で何度もなぞった。
北村：「売れば売るほど、立て替えが増える。わしは、儲けるほど貧乏になる商売をしとったんか」
一ノ瀬：「成長している会社は、どこもそうです。だから、どれくらいの期間立て替えているのかを、日数で見る方法があります」

::theory キャッシュ・コンバージョン・サイクル（CCC）
「仕入代金を支払ってから、売上代金を回収するまでの日数」を、**キャッシュ・コンバージョン・サイクル（CCC）**という。
CCC ＝ 売上債権の回収日数 ＋ 在庫の保有日数 － 仕入債務の支払日数
洛北ミートのCCCは、45日＋10日－20日＝**35日**。売上の約35日分のお金を、常に立て替えている計算になる。CCCが長い会社ほど、成長するときに多くの資金が必要になる。
逆に、CCCが**マイナス**の会社もある。客から先に代金を受け取り、仕入先には後で払うビジネスだ。現金で売る飲食店や、会費を前払いでもらうジム、乗車券を先に売る夜行バスがそうだ。こうした会社は、成長するほど手元のお金が増える。ビジネスモデルの違いが、資金繰りの運命を分けるのである。
::

::sim ccc 回収・在庫・支払の日数を変えて、立て替えているお金を見てみよう
@expect ccc=35 ar=22500 stock=4000 ap=8000 wc=18500 grow=9250
::

::real 世界最大級の小売企業は、仕入先より先にお金を受け取っている
CCCがマイナスの代表例が、アマゾンだ。公認会計士の岡野貴幸氏の解説によると、2017年度のアマゾンのCCCは**マイナス34日**だった。客からは注文の時点でカード払いなどの代金を受け取り、仕入先には一定の期間をおいて支払う。売上が伸びるほど、仕入先に払う前の現金が手元に積み上がり、それを次の投資に回せる。
**この章の道具で読む ― CCCがマイナスだと、仕訳の順番が入れ替わる**
アマゾンの取引を、この章の勘定科目で書くと次のようになる（金額は例）。

::journal ① 客がカードで支払う（カード会社から数日で入金される）
クレジット売掛金 1,000,000 | 売上 1,000,000
::
::journal ② 仕入先から商品を仕入れる（代金は、一定の期間をおいて支払う）
仕入 800,000 | 買掛金 800,000
::

どちらも、洛北ミートと同じ「掛け」の仕訳だ。違うのは、それぞれが現金に変わるまでの日数である。①のクレジット売掛金は数日で現金になり、②の買掛金は、それよりずっと後に支払われる。先に現金が入り、後で出ていく。だから、売上が伸びるほど手元の現金が増える。
同じ規模で比べてみよう。日商（1日あたりの売上）が500万円の会社が、CCC35日なら、500万円×35日＝**1億7,500万円**を常に立て替えている。CCCがマイナス34日なら、逆に約**1億7,000万円**を、仕入先に払う前の現金として手元に持っている。仕訳の形は同じでも、日数の差が、3億円を超える資金の差になる。
洛北ミートのような卸売業は、ちょうどその逆の立場にある。得意先の飲食店に代金を待ってもらい、仕入先の畜産会社には先に払う。同じ「成長」でも、CCCがプラスの会社はお金を食い、マイナスの会社はお金を生む。どちらの立場にいるかを知らずに成長を急ぐことが、いちばん危ない。
::note

::danger 「売上」はあるのに「売掛金」が膨らみ続ける会社
売掛金が売上以上のペースで増えている会社は、要注意だ。理由はおおむね3つしかない。
- 得意先の支払いが遅れている（回収できない債権が増えている。第11章の貸倒れの予兆）
- 売上を伸ばすために、支払条件を甘くしている（無理な販売）
- **架空の売上を計上している**（粉飾）
3つ目は特に深刻だ。存在しない取引で「売掛金／売上」の仕訳を切れば、売上と利益はいくらでも水増しできる。だが、架空の売掛金は永遠に回収されない。そのため、粉飾企業では「売上は伸びているのに、売掛金ばかりが積み上がり、現金が増えない」という特徴的なパターンが現れる。アナリストや監査人が真っ先に**売上債権の回収日数**を確認するのは、このためだ。
::

::cfo 来期は月商2億円 ― 増える運転資金を、どこから生み出すか
来期も、月商は1億5,000万円から**2億円**まで伸びる見通しだ。利益も増える見込みだが、北村はもう「利益が出ればお金も増える」とは思っていない。中西とひよりは、お金を生み出す4つの方法を並べた。
- **A　足りない分だけ、銀行から運転資金を借りる**（金利は低い）
- **B　15日早く払ってくれた得意先に、代金の1%を値引きする**（回収が45日から30日に早まる）
- **C　請求書の発行を早め、口座振替での回収に切り替える**（回収が45日から38日に早まる。システムの費用がかかる。遅れがちな得意先の売掛金も減る見込み）
- **D　畜産会社への支払いを20日から30日に延ばしてもらう**（代わりに仕入値を0.5%上げる）
次の視点で考えてから選んでほしい。
- 売上が伸びると、**売掛金・在庫・買掛金**はそれぞれどう動き、手元のお金はどうなるか
- 「1%値引き」「0.5%上乗せ」のような小さな数字は、**1年あたりの金利**に直すと何%にあたるか
- その手は今年だけ効くのか、**来年以降も効き続ける**のか
::choice A. 足りない分だけ銀行から借りる
**○ 今年だけなら最も安い。だが、成長が続く限り借金も増え続ける。**金利は4案で最も低い。仮の設定では、来期の運転資金は6,000万円以上増え、期末の預金は最低ラインの2,000万円を約1,300万円下回る。それを借りても、利息は年20万円台だ。
ただ、回収45日のまま売上が伸びれば、来年も再来年も同じことが起きる。借入金は毎年積み上がり、期末の預金はいつも「ぎりぎり」。入金が1社遅れるだけで割り込む。遅れがちな売掛金の貸倒れのリスクも、そのまま残る。
::
::choice B. 早く払ってくれた得意先に1%値引きする
**× 最も多くのお金を生むが、最も高くつく。**「15日早くもらうために1%を払う」を年率に直すと、1%×365日÷15日＝**約24%**の借金と同じだ。仮の設定では、値引きは年2,400万円にもなる。値引きは利益を直接削り、一度始めるとやめにくい。
::
::choice C. 請求と回収の仕組みを変え、銀行の借入枠は予備として確保しておく
**◎ 安く、毎年効き続け、貸倒れも減らす。**回収が7日早まるだけで、仮の設定では運転資金の増加は約1,500万円に縮み、借りなくても期末の預金は5,000万円を超える。費用は年率にすると約2.6%で、銀行の金利より少し高いが、遅れがちな売掛金が減って貸倒れも減る見込みだ。
何より、一度仕組みを変えれば、来年以降も毎年効き続ける。銀行の借入枠は「使わない予備」として持っておけばよい。
::
::choice D. 支払いを延ばしてもらう代わりに、仕入値を上げる
**△ 預金は増えるが、割高で、関係も傷みかねない。**「10日待ってもらう」ために0.5%を払うのは、0.5%×365日÷10日＝**約18%**の借金にあたる。それに、畜産会社にとっては入金が遅れて資金繰りが苦しくなる話だ。相手もまた、誰かに代金を待ってもらっている。
::
::answer 考え方の例を見る
**仮の設定**で、来期末の運転資金と預金を試算してみよう。
- 月商2億円、原価率80%、1か月30日。回収45日・在庫10日・支払20日（何もしなければ今と同じ）
- 来期の税引後利益は4,000万円、期首の預金は2,900万円、期末に最低2,000万円は残したい
- 費用が増える案では、その30%だけ税金が減る。今期末の運転資金は1億8,500万円
::table 来期末の運転資金と預金（仮の設定、単位：万円）
| 案 | 売掛金 | 在庫 | 買掛金 | 運転資金 | 増加額 | 期末の預金（借入前） | 実質的な金利 |
| 何もしない | 30,000 | 5,333 | 10,667 | 24,667 | 6,167 | 733 | ― |
| A　不足分を借入れ | 30,000 | 5,333 | 10,667 | 24,667 | 6,167 | 733（約1,300万円を借りて約2,030） | 1.8% |
| B　1%値引き | 20,000 | 5,333 | 10,667 | 14,667 | △3,833 | 9,053 | 約24% |
| C　請求と回収の改善 | 25,333 | 5,333 | 10,667 | 20,000 | 1,500 | 5,316 | 約2.6% |
| D　支払いの延長 | 30,000 | 5,333 | 16,000 | 19,333 | 833 | 5,395 | 約18% |
::
（期末の預金は、2,900万円＋税引後利益4,000万円－費用の税引後の額－運転資金の増加額で計算した。）
この試算から、運転資金の管理の3つの原則が見えてくる。
- **成長は、運転資金を食う**：月商が3割強伸びると、運転資金はそれ以上に増える。利益4,000万円が出ても、預金はほとんど残らない。
- **お金を生む方法は「年率」に直して比べる**：値引き1%や仕入値0.5%は、小さく見えても年率では18〜24%の高利の借金になる。
- **一度きりの手当てより、毎年効く仕組み**：借入れは今年の穴を埋めるだけだが、回収の仕組みは成長が続く限り毎年お金を生む。
**さらに考えよう：銀行の金利が年1.8%ではなく年8%だったら？**
金利が上がれば、比べる物差しそのものが変わる。年8%なら、Cの約2.6%は銀行よりずっと安い。年18%のDも、銀行から借りられない会社にとっては「借りられるだけまし」な選択肢になりうる。逆に、銀行がほぼ0%で貸してくれる時代なら、Cの手間をかけずにAで済ませる会社が増える。**どの手が安いかは、その時の金利と、その会社が借りられる条件で決まる。**だからこそ、すべての手を「年何%か」という同じ物差しに直しておくことが大切だ。
北村は中西の表を持って信用金庫を訪ね、運転資金の借入枠を予備として設定してもらった。その足で、主要な得意先を回り、口座振替への切り替えを頼んだ。「**売上の成長率に、資金の成長が追いつかない成長は、会社を殺す**」。序章のまんぷく食堂と同じ道を、洛北ミートはぎりぎりで避けた。
::

::exam 掛取引・クレジット・商品券の急所
- 商品売買の後払い → 売掛金・買掛金。商品以外の後払い → 未収入金・未払金（第9章）。
- クレジット売掛金は、**販売時に**手数料（支払手数料）を計上し、手数料を差し引いた額をクレジット売掛金とする。売上は総額で計上する。
- 他社発行の商品券を受け取ったら受取商品券。精算して入金されたら受取商品券を減らす。
- 売掛金元帳・買掛金元帳は補助簿（補助元帳）。総勘定元帳の売掛金・買掛金と、元帳の残高合計は一致する。
- 第2問では、売掛金元帳の空欄補充や、勘定記入の問題がよく出る。前月繰越・次月繰越の位置（売掛金は借方残高）を正確に押さえよう。
::

::next 運転資金は「第3の財務諸表」で見える
1級で学ぶ**キャッシュ・フロー計算書**では、営業活動によるキャッシュ・フローを「当期純利益＋減価償却費－売上債権の増加－棚卸資産の増加＋仕入債務の増加……」という形で計算する（間接法）。本章の問いで私たちが計算したのは、まさにこの計算そのものだ。
2級では、売掛金や電子記録債権を期日前に売却・譲渡する取引（**債権の譲渡**、**電子記録債権の割引・譲渡**）や、海外の取引先との**外貨建取引**も学ぶ。CCCの管理は、上場企業が投資家から説明を求められる重要テーマであり、「運転資金の改善」は最も即効性のある財務改善策の1つだ。
::

::problem 次の資料から、得意先「居酒屋A」に対する11月末の売掛金残高を求めなさい。
11/1 前月繰越 400,000円　11/8 掛け売上 250,000円　11/10 返品（11/8の売上分）20,000円　11/30 普通預金への入金（前月分の回収）400,000円

::problem 売上債権の回収日数60日、在庫の保有日数15日、仕入債務の支払日数30日の会社のキャッシュ・コンバージョン・サイクル（CCC）は何日か。また、この会社の売上が急増したとき、資金繰りはどうなりやすいか。
CCC：[[45]] 日（資金繰りへの影響は、自分の言葉で考えてから解説を開こう）

CCC＝60＋15－30＝**45日**。
仕入代金を払ってから売上代金を回収するまで45日分を立て替えているため、売上が急増すると、売掛金と在庫が膨らみ、**必要な運転資金が増えて資金繰りが苦しくなりやすい**（利益が出ていても現金が不足する）。

::summary
- 商品売買の後払いは、売る側が売掛金（資産）、買う側が買掛金（負債）
- 売掛金元帳（得意先元帳）・買掛金元帳（仕入先元帳）は、取引先ごとの補助簿。合計は総勘定元帳の勘定残高と一致する
- カード払いはクレジット売掛金。販売時に手数料を支払手数料として計上し、売上は総額で計上する
- 他社発行の商品券を受け取ったら受取商品券。精算時に入金処理する
- 掛け売りは「無利息で貸している」のと同じ。売上が伸びると運転資金が膨らみ、利益が出ても現金が減る
- CCC＝回収日数＋在庫日数－支払日数。CCCが長い会社ほど、成長に多くの資金が必要
::
