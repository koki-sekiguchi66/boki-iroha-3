翌朝、佐伯から事務所に電話が入った。受話器を置いた一ノ瀬は、ひよりのほうを向いた。

## 商品売買を記録する2つの方法 ― 分記法と三分法

一ノ瀬：「商品を仕入れて売る。この記録のしかたには、大きく2つの方法があります。1つ目から」

### 分記法 ― 売るたびに利益を計算する

一ノ瀬：「1つ目は**分記法**（ぶんきほう）。仕入れた商品を『商品』という資産で記録して、売れるたびに、原価と儲けを分けて書きます」

::journal 分記法：商品（牛肉）30,000円分を現金で仕入れた
商品 30,000 | 現金 30,000
::

::journal 分記法：原価30,000円の商品を50,000円で売り上げ、現金を受け取った
現金 50,000 | 商品 30,000
 | 商品売買益 20,000
::

ひより：「売るたびに、いくら儲けたかが分かる。分かりやすいですね」
一ノ瀬：「理屈としては美しい方法です。では、おかわり堂で使えると思いますか」
ひよりは、深夜の出町柳店を思い浮かべた。12店舗で、1日に何千杯もの牛丼が売れる。
ひより：「1杯ごとに、この牛肉は何グラムで、いくらで仕入れたものか、なんて……レジが止まります」

::note
※分記法は、2022年度の出題区分表の改定で3級の出題範囲から外れた。ここでは三分法の考え方を理解するための比較として紹介している。試験の商品売買は三分法で解く。
::

### 三分法 ― 3つの勘定で、原価は「期末にまとめて」計算する

一ノ瀬：「そこで2つ目、**三分法**（さんぶんぽう）です。3つの勘定だけで記録します。おかわり堂も、この方法です」

::table 三分法で使う3つの勘定
| 勘定科目 | 要素 | 使う場面 |
| 仕入 | 費用 | 商品を仕入れたとき（仕入れた金額＝原価で記録） |
| 売上 | 収益 | 商品を売ったとき（売った金額＝売価で記録） |
| 繰越商品 | 資産 | 決算日に売れ残っている商品（期末の在庫）を記録する |
::

::theory 三分法の発想 ― 「売るたびの原価計算」をやめる
三分法では、商品を売ったときに原価を一切考えない。仕入れたら「仕入」、売ったら売価で「売上」と書くだけだ。
では、売れた商品の原価（**売上原価**）はどうやって知るのか。答えは「**期末に、売れ残った商品を数えて逆算する**」。1年間に仕入れた商品のうち、期末に残っていないものは売れたはずだ、と考えるのである。
日々の記録の手間を最小限にし、原価の計算を年に1回（実務では月に1回）の棚卸しに集約する。この割り切りこそが、三分法が世界中の商売で使われてきた理由だ。そして同時に、今回の問いの舞台裏でもある。
::

一ノ瀬：「1杯売るたびに原価を記録していたら、深夜のレジは回りません。その代わり、年に1度だけ、冷凍庫を開けて数える必要がある」
ひより：「それが、昨夜の棚卸し……」
一ノ瀬：「そうです。あなたがやったことです」

## 仕入の仕訳 ― 運賃も「仕入原価」に含める

一ノ瀬：「三分法では、商品を仕入れたら『仕入』という費用を左に書きます。おかわり堂が洛北ミートから肉を仕入れた日なら、こうです」

::journal おかわり堂は、洛北ミートから牛肉300,000円を仕入れ、代金は掛けとした
仕入 300,000 | 買掛金 300,000
::

::note
※「掛け」とは、代金を後日まとめて支払う約束で取引すること。後払いの義務は**買掛金**（負債）、後で受け取る権利は**売掛金**（資産）になる（第7章）。
::

一ノ瀬は、洛北ミートの請求書をもう1枚出した。運送会社のスタンプが押してある。
一ノ瀬：「この日は、肉を運んでもらった運賃も払っています。この8,000円は、何だと思いますか」
ひより：「運賃だから……運送の費用、ですか」
一ノ瀬：「運賃を払わなければ、肉は店に届きません。届かない肉は、売れません。だから運賃は、肉の値段の一部です。仕入の金額に含めます。こういう付随する費用を、**仕入諸掛**（しいれしょがかり）といいます」

::journal 商品400,000円を掛けで仕入れ、引取運賃8,000円を現金で支払った
仕入 408,000 | 買掛金 400,000
 | 現金 8,000
::

::theory 取得原価 ＝ 購入代価 ＋ 付随費用
商品を手に入れ、売れる状態にするまでにかかった費用は、すべてその商品の原価（**取得原価**）に含める。運賃を払わなければ、その商品は店に届かないのだから、運賃も商品の値段の一部と考えるのだ。
この「購入代価＋付随費用＝取得原価」という考え方は、第12章で学ぶ建物やバスなどの固定資産でも、まったく同じように使われる。
::

ひより：「でも、運賃って、毎回おかわり堂が払うんですか」
一ノ瀬：「いい質問です。誰が払うかは、取引のたびに決める約束ごとです。約束が変われば、同じ4,000円でも仕訳が変わります」

::example 引取運賃は「誰が負担するか」で3通りに分かれる
おかわり堂は、洛北ミートから牛肉200,000円を掛けで仕入れ、運送会社に引取運賃4,000円を現金で支払った。
(1) 運賃はおかわり堂が負担する約束の場合
(2) 運賃は洛北ミートが負担する約束で、おかわり堂が立て替えて支払い、立替金で処理する場合
(3) (2)と同じ約束で、立て替えた額を買掛金から差し引くことにした場合
::answer
::journal (1) 当社負担の運賃は、仕入の金額に含める
仕入 204,000 | 買掛金 200,000
 | 現金 4,000
::
::journal (2) 先方負担の運賃を立て替えた → 立替金（あとで返してもらう権利）
仕入 200,000 | 買掛金 200,000
立替金 4,000 | 現金 4,000
::
::journal (3) 立て替えた分だけ、支払う買掛金を減らす
仕入 200,000 | 買掛金 196,000
 | 現金 4,000
::
(2)と(3)では、運賃は洛北ミートの負担なので、おかわり堂の仕入（原価）には含めない。立て替えた4,000円は、洛北ミートから返してもらう権利（**立替金**、資産。第10章）として持つか、支払う買掛金から差し引いて精算する。どちらでも、最終的におかわり堂が負担するお金はゼロになる。
::trap
当社が負担する引取運賃を、「発送費」や「支払運賃」といった別の費用にしないこと。仕入れるためにかかった費用は、**仕入の金額に含める**。
反対に、先方が負担する運賃を仕入に含めてもいけない。「誰の負担か」を先に確かめよう。
::
::
::

## 売上の仕訳 ― 発送費の2つのパターン

大森への説明の準備は、夜まで続いた。一ノ瀬は、おかわり堂に肉を納めている洛北ミートの請求書を1枚、机に置いた。
一ノ瀬：「同じ取引を、売った側から見てみましょう。おかわり堂の仕入は、洛北ミートにとっては何ですか」
ひより：「売上、です」
一ノ瀬：「そのとおり。売ったら、売った値段で『売上』という収益を右に書きます」

::journal 洛北ミートは、飲食店に豚肉500,000円を販売し、代金は掛けとした
売掛金 500,000 | 売上 500,000
::

一ノ瀬：「そして、売る側にも運賃の問題があります。洛北ミートが自分のお金で飲食店まで届けたら、その送料は**発送費**という費用です」
ひより：「さっきは、運賃を肉の値段に含めましたよね」
一ノ瀬：「仕入れるときの運賃は、商品の値段の一部でした。でも、売るときの運賃は、もう売れた商品を届けるための費用です。商品の値段には入れません」

::journal 洛北ミートは、商品500,000円を掛けで販売し、配送業者に送料6,000円を現金で支払った（送料は当社負担）
売掛金 500,000 | 売上 500,000
発送費 6,000 | 現金 6,000
::

一ノ瀬：「では、送料もお客さんからもらう約束だったら？」
ひより：「もらった送料は……収益、ですか」
一ノ瀬：「お客さんから見れば、届けてもらうところまでが1つの買い物です。だから、もらった送料は売上に含めます」

::journal 商品500,000円を販売し、送料6,000円を加えた合計額を掛けとした。配送業者には送料6,000円を現金で支払った
売掛金 506,000 | 売上 506,000
発送費 6,000 | 現金 6,000
::

::point 送料を受け取るなら「売上」に含める理由
顧客から見れば「商品を届けてもらう」ことまでが1つの買い物だ。だから、受け取った送料も商品を届けるサービスの対価として売上に含める。一方、配送業者に払う送料は、そのサービスを提供するための費用（発送費）になる。
::

## 返品 ― 取り消すなら「逆仕訳」

請求書の束の中に、1枚だけ赤い字で書かれた伝票があった。金額の前に、マイナスの記号がついている。
ひより：「これは何ですか」
一ノ瀬：「返品です。配送中に解凍しかけた牛肉を、おかわり堂が送り返しました。取り消したい取引があるとき、簿記では消しゴムを使いません」
ひより：「じゃあ、どうするんですか」
一ノ瀬：「最初の仕訳を、左右ひっくり返して書きます。**逆仕訳**です」

::example 解凍しかけた牛肉の返品
おかわり堂は、洛北ミートから掛けで仕入れた牛肉のうち、配送中の温度管理の不備で品質が劣化していた20,000円分を返品した。
返品した側（おかわり堂）と、返品された側（洛北ミート）の両方で処理が必要になる。
::answer
::journal (1) おかわり堂（仕入の取り消し＝仕入戻し）
買掛金 20,000 | 仕入 20,000
::
::journal (2) 洛北ミート（売上の取り消し＝売上戻り）
売上 20,000 | 売掛金 20,000
::
仕入れたときの「仕入／買掛金」、売ったときの「売掛金／売上」を、それぞれ左右逆にしている。
::trap
返品は、最初の仕訳の**逆仕訳**を、返品した金額の分だけ行う。新しい勘定科目は使わない。
代金を現金で返したと書かれていない限り、減らすのは買掛金・売掛金だ。現金を動かさないこと。
::
::
::

## 売上原価の計算 ― 「しーくりくりしー」

時計は夜10時を回っていた。ひよりは、大森が毎月見ていた試算表を、もう一度開いた。
ひより：「社長が見ていた『仕入 4億300万円』。これって、1年間に仕入れた金額ですよね」
一ノ瀬：「そうです」
ひより：「でも、仕入れた肉が、全部売れたとは限らない。冷凍庫に残ってる分もある。それに……」
ひよりは、冷凍庫の段ボールの日付を思い出した。去年の秋の日付が、いくつもあった。
ひより：「去年から残ってた肉も、今年使ってます」
一ノ瀬：「そこまで気づけば、もう式は書けます」
一ノ瀬：「本当に売れた商品の原価を、**売上原価**といいます。最初に残っていた分と、今年仕入れた分を足して、最後に残った分を引く。それだけです」

::formula 売上原価の計算式
売上原価 ＝ 期首商品棚卸高 ＋ 当期商品仕入高 － 期末商品棚卸高
::

::boxes 売上原価のボックス図 ― 左の合計と右の合計は一致する
H 手元にあった商品（原価） | その行き先
L s 20 期首商品棚卸高<br>（前期の売れ残り）
L a 80 当期商品仕入高<br>（今期仕入れた分）
R x 85 売上原価<br>（売れた分）
R s 15 期末商品棚卸高<br>（売れ残り）
::

ひより：「最後に残った分を数えるのが、棚卸し」
一ノ瀬：「はい。期末に売れ残った商品を数えて、原価をかける。それが期末商品棚卸高です」

### 決算整理仕訳 ― 仕入勘定を「売上原価」に変える

一ノ瀬：「では、この式を帳簿の上でやってみましょう。仕入の勘定を、売上原価に作り変えます。仕訳は2本だけ。通称『**しーくりくりしー**』です」
ひより：「呪文みたいですね」
一ノ瀬：「呪文です。でも、意味の分かる呪文です」

::journal ① 期首商品棚卸高を、繰越商品から仕入に振り替える（しー・くり）
仕入 ××× | 繰越商品 ×××
::

::journal ② 期末商品棚卸高を、仕入から繰越商品に振り替える（くり・しー）
繰越商品 ××× | 仕入 ×××
::

一ノ瀬：「1本目で、去年からの在庫を仕入に足す。2本目で、今年の売れ残りを仕入から引く。これで仕入の勘定が、売れた分の原価になります」
ひより：「左の頭文字が、し、く。右が、く、し。だから、しーくり・くりしー」

::example おかわり堂・第8期の決算整理
期首商品棚卸高　80,000,000円
当期商品仕入高　403,000,000円
期末商品棚卸高　20,000,000円
この3つの数字から、決算整理仕訳で売上原価を計算する。
::answer
::journal ① 期首商品を仕入へ（しー・くり）
仕入 80,000,000 | 繰越商品 80,000,000
::
::journal ② 期末商品を繰越商品へ（くり・しー）
繰越商品 20,000,000 | 仕入 20,000,000
::
::tgrid
::taccount 仕入
当期仕入高 403,000,000 | 繰越商品 20,000,000
繰越商品 80,000,000 | （売上原価） 463,000,000
= 483,000,000 | 483,000,000
::
::taccount 繰越商品
前期繰越 80,000,000 | 仕入 80,000,000
仕入 20,000,000 | （次期繰越） 20,000,000
= 100,000,000 | 100,000,000
::
::
売上原価 ＝ 80,000,000 ＋ 403,000,000 － 20,000,000 ＝ **463,000,000円**
仕入勘定の残高（借方483,000,000－貸方20,000,000）が、そのまま売上原価になる。繰越商品勘定には、期末の在庫20,000,000円が残り、次期に繰り越される。
::trap
2本の仕訳の順番と金額を入れ違えないこと。**期首の金額は「仕入／繰越商品」、期末の金額は「繰越商品／仕入」**だ。
決算整理前の残高試算表に載っている繰越商品は、期首の金額である。期末の金額は、問題文の決算整理事項から読み取る。
::
::
::

### もう1つの方法 ― 「売上原価」勘定で計算する

「しーくりくりしー」をノートに3回書いたところで、ひよりは首をかしげた。
ひより：「売上原価を出したいのに、どうして『仕入』という名前の勘定で計算するんでしょう。分かりにくくないですか」
一ノ瀬は少し笑った。
一ノ瀬：「同じ疑問を持った人が、昔からいたんです。だから、名前どおりの『売上原価』という勘定を使う方法もあります。仕訳は3本になります」

::journal ① 期首商品棚卸高を売上原価へ
売上原価 80,000,000 | 繰越商品 80,000,000
::

::journal ② 当期商品仕入高を売上原価へ
売上原価 403,000,000 | 仕入 403,000,000
::

::journal ③ 期末商品棚卸高を売上原価から繰越商品へ
繰越商品 20,000,000 | 売上原価 20,000,000
::

ひより：「463,000,000円。さっきと同じになりました」
一ノ瀬：「どちらの道を通っても、答えは同じです」

::point 試験では「どの行で計算するか」の指示を確認する
精算表の問題では「売上原価は『仕入』の行で計算すること」または「『売上原価』の行で計算すること」と指示される。仕入の行で計算するなら2本の仕訳（しーくりくりしー）、売上原価の行で計算するなら3本の仕訳を使う。どちらの方法でも、損益計算書に表示する「売上原価」の金額は同じだ。
::

## 答え合わせ ― 「仕入」は「原価」ではない

::scene 3月31日、午後11時 ― セントラルキッチンの冷凍庫前
時間を、決算の夜に戻そう。
マイナス20度の冷凍庫から出てきたアルバイトの手には、霜のついたバーコードリーダーが握られていた。段ボールを1箱ずつ読み取り、品名と重さを入力していく。12店舗と、食材を加工するセントラルキッチン。全部を数え終えたのは、日付が変わる直前だった。
冷凍庫の扉の外で、ひよりは記録用紙の数字を本部に送った。本部の会議室で、財務担当役員の佐伯は、届いた数字を表計算ソフトに打ち込んだ。期末の在庫は2,000万円。去年の今ごろ、この冷凍庫には8,000万円分の牛肉が眠っていた。
佐伯は、「しーくりくりしー」の2行の仕訳を入力した。仕入勘定の残高が、4億300万円から4億6,300万円に変わる。画面の営業利益の欄が、1億700万円から4,700万円に書き換わった。
佐伯は時計を見て、大森の携帯番号を押した。
佐伯：「社長、夜分に申し訳ありません。決算の速報です。……座って、聞いていただけますか」
::

::solve 消えた6,000万円の正体は、去年の冷凍庫の中にあった
大森が毎月見ていた「仕入4億300万円」は、**今期に買った食材の金額**にすぎない。売れた商品の原価（売上原価）ではなかった。
実は前期の秋、輸入牛肉の卸値が1年で2倍近くに跳ね上がるのを見たおかわり堂は、「まだ上がる」と読んで、通常の4倍にあたる**8,000万円分の牛肉を冷凍で買いだめ**していた。今期は、その在庫を使いながら営業していたため、新たな仕入は少なくて済んでいた。仕入率31%という「好成績」の正体は、前期に買った肉を食べていたことによる錯覚だったのだ。
決算で在庫を数えると、冷凍庫に残っていたのは2,000万円分。買いだめ分の差額6,000万円が、今期の原価に加わった。

::table 社長の頭の中と、決算書の真実
| 項目 | 社長の見込み | 決算書の真実 |
| 売上高 | 13億円 | 13億円 |
| 原価 | 4億300万円（仕入） | 4億6,300万円（売上原価） |
| 売上総利益 | 8億9,700万円 | 8億3,700万円 |
| 人件費・家賃などの経費 | 7億9,000万円 | 7億9,000万円 |
|= 営業利益 | 1億700万円 | 4,700万円 |
::
本当の原価率は**35.6%**（4億6,300万円÷13億円）。業界平均並みどころか、過去最悪の水準だった。決算賞与の約束は、存在しない利益の上に立っていたのである。
「しーくりくりしー」は、試験のための呪文ではない。**買った金額と、使った金額は違う**という当たり前の事実を、帳簿に反映させるための仕訳なのだ。
::

::scene 翌日の午後 ― 社長室
社長室の空気は重かった。大森は腕を組み、窓の外を見たまま、ひよりのほうを見ようとしなかった。
大森：「会計事務所の新人さんが、わしの1億円を消した理由を説明してくれるんやな」
ひよりは、ホワイトボードに売上原価のボックス図を描いた。手が少し震えた。左上に「期首 8,000万円」と書き込む。
ひより：「社長が毎月ご覧になっていた仕入は、今期に買った肉の代金です。でも、今期に使った肉には、去年の秋に買って冷凍庫に入れた肉が含まれています」
大森：「去年の肉……」
ひより：「はい。去年の秋、値上がりの前に、8,000万円分を買いだめされました。今年はそれを使っていたから、新しい仕入は少なくて済んだんです。でも、使った肉の原価は、ちゃんと今年の費用になります」
大森は、長いあいだ図を見ていた。それから、ぽつりと言った。
大森：「去年の肉を、今年の利益で食べとったわけか」
::

決算賞与は、約束の半分に減らして支給された。大森は全店長を集め、自分の言葉で理由を説明した。
大森：「わしが数字を読み違えた。すまん。その代わり、来年からは毎月、本当の原価を見る」
翌月から、おかわり堂の月次の試算表には、毎月の棚卸しを反映した「売上原価」の行が加わった。
夏、出町柳店の焼肉は、少しだけ安い店で開かれた。坂口からのメッセージには、写真が1枚添えてあった。岩井店長が、トングを持って笑っていた。

::real 牛丼の値段を動かした「ミートショック」
おかわり堂が買いだめに走った背景には、現実の出来事がある。2021年、世界的な牛肉需要の高まりと物流の混乱で、輸入牛肉の価格が急騰した。牛丼に使われる米国産のバラ肉（ショートプレート）の卸値は、前年の1kgあたり600円台から、2021年夏には1,100円台に達した。2倍近い上昇である。
大手牛丼チェーンの吉野家は、2021年10月29日、牛丼並盛（店内）を387円から426円に値上げした。1杯に使う牛肉を90gと仮定すると、牛肉の原価は約59円から約104円へ、およそ45円増える計算になる。値上げ幅の39円は、この増加分をほぼ価格に転嫁した水準と読める。
ただし三分法では、高く買った肉がすぐに売上原価になるとは限らない。値上がり前に安く買って冷凍しておいた肉があれば、それを使い切るまでは原価の上昇は遅れて表れる。おかわり堂の仕入率31%の「好成績」は、まさにこの遅れだった。
::note
出典：[東洋経済オンライン（2021年）](https://toyokeizai.net/articles/-/476457)、[吉野家ニュースリリース（2021年10月18日）](https://www.yoshinoya.com/wp-content/uploads/2021/10/18114230/news_202110181.pdf)、[KSB瀬戸内海放送（2024年）](https://news.ksb.co.jp/article/15328841)
::

::danger 期末在庫を「水増し」すると、利益が湧いてくる
期末商品棚卸高は、売上原価の式の「マイナス」の項目だ。つまり、**期末の在庫を多く数えれば数えるほど、売上原価は小さくなり、利益は大きくなる**。存在しない在庫を帳簿に載せる「架空在庫」は、粉飾決算の古典的な手口だ。だからこそ上場企業の監査では、監査人が決算日の棚卸しに立ち会い、**その在庫が本当にそこにあるか**を確かめる。
::

::real 「在庫の水増し」は、大企業でも起きた
2019年11月、液晶パネル大手のジャパンディスプレイ（JDI）に、元幹部社員から「経営陣の指示で、過去の決算で不適切な会計処理を行っていた」という通知が届いた。2020年4月に公表された第三者委員会の報告では、架空の在庫の計上や、売れ残った在庫の評価減を不正に避けていたことなどが指摘された。
期末の在庫を水増しすると、「くり・しー」の仕訳が大きくなり、売上原価が小さく、利益が大きく見える。だが翌期には、その在庫が「しー・くり」で仕入に戻ってきて、翌期の利益を同じだけ押し下げる。隠すには、翌期末にもう一度水増しするしかない。在庫の水増しは、続けるほど嘘を大きくしなければならない「前借り」なのだ。だから監査人は、決算日の倉庫に足を運び、在庫が本当にそこにあるかを自分の目で確かめる。
::note
出典：[税務研究会「開示DB」](https://www.zeiken.co.jp/kaijidb/article/cat-1/1654.php)、[東洋経済オンライン（2020年）](https://toyokeizai.net/articles/-/345639)
::
::

## 売上総利益と原価率 ― 経営者が毎月見る数字

説明を聞き終えた大森は、ホワイトボードの前から動かなかった。
大森：「わしは毎月、売上と仕入だけを見とった。ほな、これからは何を見たらええんや」
ひよりは、ボックス図の横に、割り算を1つ書いた。
ひより：「売上から売上原価を引いたものが、**売上総利益**、いわゆる粗利です。そして、売上原価を売上で割ったものが**原価率**です。社長が見るべきなのは、仕入率ではなく、この原価率です」

::formula 売上総利益と原価率
売上総利益 ＝ 売上 － 売上原価
原価率 ＝ 売上原価 ÷ 売上
::

佐伯：「飲食業では、原価率は30〜35%前後がひとつの目安です。それに人件費を足した割合、**FL比率**も見ます。食材のFoodと、人のLabor。60%を超えると、家賃と光熱費を払ったあとに、ほとんど何も残りません」
大森：「うちは、いくつや」
佐伯は、黙って数字を書いた。

::kpi おかわり堂・第8期の収益構造
売上高 | 13億円 | 過去最高
原価率（F） | 35.6% | 前期は33%
人件費率（L） | 30.0% | 深夜帯の割増賃金が重い
FL比率 | 65.6% | 目安の60%を大きく超過
::


## {{new:2027年度〜}} 売上原価対立法 ― 売るたびに原価を記録する方法

帰り道、ひよりは一ノ瀬に聞いた。
ひより：「毎月の棚卸しって、大変じゃないですか。売るたびに原価が分かれば、こんなことにはならなかったのに」
一ノ瀬：「その方法もあります。**売上原価対立法**です。2027年4月からは、3級の範囲にも入る予定です」
一ノ瀬：「商品は『商品』という資産で記録して、売れた瞬間に、その原価を売上原価に移します。今はレジと在庫のシステムがつながっているので、昔ほど手間ではありません」

::journal 売上原価対立法：商品300,000円を掛けで仕入れた
商品 300,000 | 買掛金 300,000
::

::journal 売上原価対立法：原価200,000円の商品を280,000円で掛け販売した
売掛金 280,000 | 売上 280,000
売上原価 200,000 | 商品 200,000
::

ひより：「これなら、商品の勘定を見れば、いつでも在庫がいくらか分かりますね」
一ノ瀬：「ええ。しーくりくりしーも要りません」

::table 3つの記帳方法の比較
| 項目 | 分記法 | 三分法 | 売上原価対立法 |
| 仕入時 | 商品 ／ 買掛金など | 仕入 ／ 買掛金など | 商品 ／ 買掛金など |
| 販売時 | 現金など ／ 商品・商品売買益 | 現金など ／ 売上 | 現金など ／ 売上、売上原価 ／ 商品 |
| 売上原価の把握 | 販売のつど（利益のみ記録） | 期末の棚卸しで一括計算 | 販売のつど |
| 決算整理（売上原価） | 不要 | 必要（しーくりくりしー） | 不要 |
| 向いている業態 | 少量・高額の商品 | 多品種・大量販売 | POSや在庫システムで原価を即時把握できる会社 |
::

::point 売上原価対立法が広がる背景
売るたびに原価を記録するには、1つ1つの商品の原価をすぐに調べられる仕組みが必要だ。かつては手間がかかりすぎたが、POSレジと在庫管理システムが普及した現在では、販売の瞬間に原価を自動で記録できる。今回のケースのような「決算の日のサプライズ」も起きにくい。技術の進歩が、簿記の標準を動かしているのである。
::

::exam 商品売買の急所
- 三分法：仕入れたら「仕入」、売ったら売価で「売上」。商品勘定は使わない（繰越商品は決算で使う）。
- 当社負担の引取運賃などの**仕入諸掛は仕入に含める**。当社負担の**発送費は「発送費」**（費用）。
- 送料を顧客から受け取る場合は、送料込みの金額で売上を計上し、支払った送料は発送費。
- 返品は、もとの仕訳の逆仕訳。
- 決算整理は「仕入／繰越商品（期首）」「繰越商品／仕入（期末）」。精算表や損益計算書では、整理後の仕入勘定の残高が「売上原価」になり、貸借対照表では繰越商品が「**商品**」と表示される。
- 「売上原価の行で計算する」と指示されたら、「売上原価／繰越商品」「売上原価／仕入」「繰越商品／売上原価」の3本の仕訳を使う。
- 分記法は現在の3級の出題範囲外。商品売買は三分法で処理する。
- 2027年度以降は売上原価対立法も出題範囲に入る予定。販売時に「売上原価／商品」を同時に記録する。
::

::next 原価の「中身」を分解する ― 2級の工業簿記へ
2級では、帳簿上の在庫と実際の在庫のズレ（**棚卸減耗損**）や、値下がりした在庫の評価損（**商品評価損**）を学ぶ。さらに、おかわり堂がセントラルキッチンでたれや惣菜を自社で製造するようになれば、材料費・労務費・経費を集計して製品の原価を計算する**工業簿記**の世界に入る。
::

::summary
- 分記法は販売のつど利益を計算する方法、三分法は「仕入・売上・繰越商品」の3勘定で記録し、原価を期末にまとめて計算する方法
- 当社負担の仕入諸掛は仕入に含める（取得原価＝購入代価＋付随費用）。当社負担の発送費は費用
- 送料を顧客から受け取るときは売上に含め、支払った送料は発送費とする。返品は逆仕訳
- 売上原価＝期首商品棚卸高＋当期商品仕入高－期末商品棚卸高。決算整理は「しーくりくりしー」
- 「仕入」は今期に買った額、「売上原価」は今期に売れた商品の原価。この2つは違う
- 期末在庫を多く数えると利益が増える。だから棚卸しは厳格に行われる
- 2027年度からは、販売のつど「売上原価／商品」と記録する売上原価対立法も3級の範囲に入る予定
::
