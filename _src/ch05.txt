3月31日、午後10時。マイナス20度の冷凍庫の中で、ひよりの吐く息は真っ白だった。おかわり堂の決算棚卸し。会計事務所の人間として、数え方に誤りがないかを見届ける「立会い」が、ひよりの仕事だ。段ボールを1箱ずつ開け、品名と重さを読み上げるアルバイトの声に合わせて、記録用紙にチェックを入れていく。
数か月前まで、ひよりはこの段ボールを運ぶ側だった。
おかわり堂の第8期は、絶好調に見えた。
売上は**13億円**。前期から8%伸びて、過去最高を更新した。毎月の試算表を見るたび、創業社長の大森は上機嫌だった。食材の購入額、つまり「仕入」は累計で4億300万円。売上に対してわずか**31%**。輸入牛肉の値段が跳ね上がり、同業の牛丼チェーンが軒並み値上げに追い込まれるなかで、業界でも指折りの低さだ。
「今期の利益は1億円を超える。全店に決算賞与を出そう」
2月の店長会議で、大森はそう約束した。会議室に拍手が起きた。出町柳店の岩井店長が、うれしそうにその話をしていたのを、ひよりは坂口から聞いていた。
その夜、全店の冷凍庫と倉庫の在庫を数え終えた経理部から、日付が変わる直前に1枚の速報が上がってきた。そこに書かれた営業利益は、**4,700万円**。大森が見込んでいた1億700万円の半分にも届かない。
売上も、仕入も、毎月の数字どおりだった。誰も不正などしていない。なのに、なぜ6,000万円もの利益が、決算の日に消えたのか？
翌朝、佐伯から事務所に電話が入った。受話器を置いた一ノ瀬は、ひよりに言った。「明日の午後、大森社長に説明に行きます。説明するのは、あなたです」
::

ひよりに残された時間は、1日半。一ノ瀬は「答えは、あなたが冷凍庫で数えた数字の中にあります」とだけ言って、商品売買の帳簿のつけ方を1つずつ見せていった。

## 商品売買を記録する2つの方法 ― 分記法と三分法

「商品を仕入れて売る」取引を、会社はどう記録しているのか。方法は大きく2つある。

### 分記法 ― 売るたびに利益を計算する

**分記法**（ぶんきほう）は、商品を**商品勘定（資産）**で記録し、売れるたびに、その商品の原価と利益を分けて記録する方法だ。

::journal 分記法：商品（牛肉）30,000円分を現金で仕入れた
商品 30,000 | 現金 30,000
::

::journal 分記法：原価30,000円の商品を50,000円で売り上げ、現金を受け取った
現金 50,000 | 商品 30,000
 | 商品売買益 20,000
::

売るたびに「原価いくらの商品を、いくらで売り、いくら儲けたか」が分かる。理屈としては美しい。
だが、おかわり堂を考えてみてほしい。12店舗で1日に何千杯もの牛丼が売れる。その1杯ごとに「この牛肉は何グラムで、いくらで仕入れたものか」を調べて仕訳するのは、現実的ではない。

::note
※分記法は、2022年度の出題区分表の改定で3級の出題範囲から外れた。ここでは三分法の考え方を理解するための比較として紹介している。試験の商品売買は三分法で解く。
::

### 三分法 ― 3つの勘定で、原価は「期末にまとめて」計算する

そこで、実務で広く使われているのが**三分法**（さんぶんぽう）だ。商品売買を、次の3つの勘定で記録する。

::table 三分法で使う3つの勘定
| 勘定科目 | 要素 | 使う場面 |
| 仕入 | 費用 | 商品を仕入れたとき（仕入れた金額＝原価で記録） |
| 売上 | 収益 | 商品を売ったとき（売った金額＝売価で記録） |
| 繰越商品 | 資産 | 決算日に売れ残っている商品（期末の在庫）を記録する |
::

::theory 三分法の発想 ― 「売るたびの原価計算」をやめる
三分法では、商品を売ったときに原価を一切考えない。仕入れたら「仕入」、売ったら売価で「売上」と書くだけだ。
では、売れた商品の原価（**売上原価**）はどうやって知るのか。答えは「**期末に、売れ残った商品を数えて逆算する**」。1年間に仕入れた商品のうち、期末に残っていないものは売れたはずだ、と考えるのである。
日々の記録の手間を最小限にし、原価の計算を年に1回（実務では月に1回）の棚卸しに集約する。この割り切りこそが、三分法が世界中の商売で使われてきた理由だ。そして同時に、今回の問いの舞台裏でもある。
::

「1杯売るたびに、牛肉の原価を記録していたら、深夜のレジは回りません」と一ノ瀬は言った。「だから、おかわり堂も三分法です。その代わり、年に1度だけ、冷凍庫を開けて数える必要がある。昨夜、あなたがやったことです」

## 仕入の仕訳 ― 運賃も「仕入原価」に含める

三分法では、商品を仕入れたら**仕入**（費用）の発生として借方に記録する。

::journal おかわり堂は、洛北ミートから牛肉300,000円を仕入れ、代金は掛けとした
仕入 300,000 | 買掛金 300,000
::

::note
※「掛け」とは、代金を後日まとめて支払う約束で取引すること。後払いの義務は**買掛金**（負債）、後で受け取る権利は**売掛金**（資産）になる（第7章）。
::

商品を仕入れるときに、運送料や運送保険料などの費用がかかることがある。これを**仕入諸掛**（しいれしょがかり）という。当社が負担する仕入諸掛は、**仕入の金額に含める**。

::journal 商品400,000円を掛けで仕入れ、引取運賃8,000円を現金で支払った
仕入 408,000 | 買掛金 400,000
 | 現金 8,000
::

::theory 取得原価 ＝ 購入代価 ＋ 付随費用
商品を手に入れ、売れる状態にするまでにかかった費用は、すべてその商品の原価（**取得原価**）に含める。運賃を払わなければ、その商品は店に届かないのだから、運賃も商品の値段の一部と考えるのだ。
この「購入代価＋付随費用＝取得原価」という考え方は、第12章で学ぶ建物やバスなどの固定資産でも、まったく同じように使われる。
::

運賃を「どちらが負担するか」は、取引のたびに決める約束ごとだ。負担する側が変われば、同じ4,000円の支払いでも仕訳が変わる。

::example 引取運賃は「誰が負担するか」で3通りに分かれる
おかわり堂は、洛北ミートから牛肉200,000円を掛けで仕入れ、運送会社に引取運賃4,000円を現金で支払った。
(1) 運賃はおかわり堂が負担する約束の場合
(2) 運賃は洛北ミートが負担する約束で、おかわり堂が立て替えて支払い、立替金で処理する場合
(3) (2)と同じ約束で、立て替えた額を買掛金から差し引くことにした場合
::answer
::journal (1) 当社負担の運賃は、仕入の金額に含める
仕入 204,000 | 買掛金 200,000
 | 現金 4,000
::
::journal (2) 先方負担の運賃を立て替えた → 立替金（あとで返してもらう権利）
仕入 200,000 | 買掛金 200,000
立替金 4,000 | 現金 4,000
::
::journal (3) 立て替えた分だけ、支払う買掛金を減らす
仕入 200,000 | 買掛金 196,000
 | 現金 4,000
::
(2)と(3)では、運賃は洛北ミートの負担なので、おかわり堂の仕入（原価）には含めない。立て替えた4,000円は、洛北ミートから返してもらう権利（**立替金**、資産。第10章）として持つか、支払う買掛金から差し引いて精算する。どちらでも、最終的におかわり堂が負担するお金はゼロになる。
::trap
当社が負担する引取運賃を、「発送費」や「支払運賃」といった別の費用にしないこと。仕入れるためにかかった費用は、**仕入の金額に含める**。
反対に、先方が負担する運賃を仕入に含めてもいけない。「誰の負担か」を先に確かめよう。
::
::
::

## 売上の仕訳 ― 発送費の2つのパターン

商品を売ったら、**売った金額（売価）**で売上（収益）を記録する。

::journal 洛北ミートは、飲食店に豚肉500,000円を販売し、代金は掛けとした
売掛金 500,000 | 売上 500,000
::

売るときに当社が負担する配送料は、**発送費**（費用）として処理する。仕入諸掛と違い、商品の原価には含めない。

::journal 洛北ミートは、商品500,000円を掛けで販売し、配送業者に送料6,000円を現金で支払った（送料は当社負担）
売掛金 500,000 | 売上 500,000
発送費 6,000 | 現金 6,000
::

一方、**送料を顧客から受け取る**約束の場合は、受け取る送料を**売上に含めて**処理し、配送業者に支払った送料は発送費とする。

::journal 商品500,000円を販売し、送料6,000円を加えた合計額を掛けとした。配送業者には送料6,000円を現金で支払った
売掛金 506,000 | 売上 506,000
発送費 6,000 | 現金 6,000
::

::point 送料を受け取るなら「売上」に含める理由
顧客から見れば「商品を届けてもらう」ことまでが1つの買い物だ。だから、受け取った送料も商品を届けるサービスの対価として売上に含める。一方、配送業者に払う送料は、そのサービスを提供するための費用（発送費）になる。
::

## 返品 ― 取り消すなら「逆仕訳」

品違いや品質不良で商品を返品することがある。返品は、仕入（または売上）の取り消しだから、**もとの仕訳の逆**を書けばよい。

::example 解凍しかけた牛肉の返品
おかわり堂は、洛北ミートから掛けで仕入れた牛肉のうち、配送中の温度管理の不備で品質が劣化していた20,000円分を返品した。
(1) おかわり堂の仕訳　(2) 洛北ミートの仕訳
::answer
::journal (1) おかわり堂（仕入の取り消し＝仕入戻し）
買掛金 20,000 | 仕入 20,000
::
::journal (2) 洛北ミート（売上の取り消し＝売上戻り）
売上 20,000 | 売掛金 20,000
::
仕入れたときの「仕入／買掛金」、売ったときの「売掛金／売上」を、それぞれ左右逆にしている。
::trap
返品は、最初の仕訳の**逆仕訳**を、返品した金額の分だけ行う。新しい勘定科目は使わない。
代金を現金で返したと書かれていない限り、減らすのは買掛金・売掛金だ。現金を動かさないこと。
::
::
::

## 売上原価の計算 ― 「しーくりくりしー」

いよいよ問いの核心だ。ひよりは、大森が毎月見ていた試算表を思い浮かべた。「仕入 4億300万円」。三分法では、仕入勘定には「1年間に仕入れた金額」が集まる。だが、仕入れた商品が全部売れたとは限らない。期首に倉庫に残っていた商品もある。
そこで、本当の原価である**売上原価**（実際に売れた商品の原価）を、次の式で計算する。

::formula 売上原価の計算式
売上原価 ＝ 期首商品棚卸高 ＋ 当期商品仕入高 － 期末商品棚卸高
::

::boxes 売上原価のボックス図 ― 左の合計と右の合計は一致する
H 手元にあった商品（原価） | その行き先
L s 20 期首商品棚卸高<br>（前期の売れ残り）
L a 80 当期商品仕入高<br>（今期仕入れた分）
R x 85 売上原価<br>（売れた分）
R s 15 期末商品棚卸高<br>（売れ残り）
::

期首に残っていた商品と、今期に仕入れた商品。これが今期に「売ることができた商品」のすべてだ。そのうち、期末に売れ残った分を差し引けば、売れた分の原価が出る。シンプルな理屈である。
期末に売れ残っている商品の金額を調べることを**棚卸し**（たなおろし）という。実際に倉庫や冷凍庫の商品を数え、原価をかけて期末商品棚卸高を求める。

### 決算整理仕訳 ― 仕入勘定を「売上原価」に変える

3級では、主に仕入勘定の中で売上原価を計算する（「売上原価」勘定を使う方法は後述）。そのための決算整理仕訳が、通称「**しーくりくりしー**」だ。

::journal ① 期首商品棚卸高を、繰越商品から仕入に振り替える（しー・くり）
仕入 ××× | 繰越商品 ×××
::

::journal ② 期末商品棚卸高を、仕入から繰越商品に振り替える（くり・しー）
繰越商品 ××× | 仕入 ×××
::

①で、前期から繰り越された在庫（繰越商品）を仕入に加える。②で、売れ残った在庫を仕入から差し引き、繰越商品として次期に繰り越す。この2本の仕訳を終えると、仕入勘定の残高は「期首＋当期仕入－期末」、つまり**売上原価**になる。
借方の頭文字が「し（仕入）」「く（繰越商品）」、貸方が「く（繰越商品）」「し（仕入）」。だから「しーくり・くりしー」と覚えるのだ。

::example おかわり堂・第8期の決算整理
期首商品棚卸高　80,000,000円
当期商品仕入高　403,000,000円
期末商品棚卸高　20,000,000円
売上原価を計算するための決算整理仕訳を行い、売上原価を求めなさい。
::answer
::journal ① 期首商品を仕入へ（しー・くり）
仕入 80,000,000 | 繰越商品 80,000,000
::
::journal ② 期末商品を繰越商品へ（くり・しー）
繰越商品 20,000,000 | 仕入 20,000,000
::
::tgrid
::taccount 仕入
当期仕入高 403,000,000 | 繰越商品 20,000,000
繰越商品 80,000,000 | （売上原価） 463,000,000
= 483,000,000 | 483,000,000
::
::taccount 繰越商品
前期繰越 80,000,000 | 仕入 80,000,000
仕入 20,000,000 | （次期繰越） 20,000,000
= 100,000,000 | 100,000,000
::
::
売上原価 ＝ 80,000,000 ＋ 403,000,000 － 20,000,000 ＝ **463,000,000円**
仕入勘定の残高（借方483,000,000－貸方20,000,000）が、そのまま売上原価になる。繰越商品勘定には、期末の在庫20,000,000円が残り、次期に繰り越される。
::trap
2本の仕訳の順番と金額を入れ違えないこと。**期首の金額は「仕入／繰越商品」、期末の金額は「繰越商品／仕入」**だ。
決算整理前の残高試算表に載っている繰越商品は、期首の金額である。期末の金額は、問題文の決算整理事項から読み取る。
::
::
::

### もう1つの方法 ― 「売上原価」勘定で計算する

売上原価を計算するための専用の勘定、**売上原価**（費用）を設けて計算する方法もある。期首商品と当期仕入高を売上原価勘定に集め、期末商品を差し引く。3つの仕訳になる。

::journal ① 期首商品棚卸高を売上原価へ
売上原価 80,000,000 | 繰越商品 80,000,000
::

::journal ② 当期商品仕入高を売上原価へ
売上原価 403,000,000 | 仕入 403,000,000
::

::journal ③ 期末商品棚卸高を売上原価から繰越商品へ
繰越商品 20,000,000 | 売上原価 20,000,000
::

売上原価勘定の残高は、80,000,000＋403,000,000－20,000,000＝**463,000,000円**。仕入勘定で計算した場合と同じ金額になる。仕入勘定の残高はゼロになる。

::point 試験では「どの行で計算するか」の指示を確認する
精算表の問題では「売上原価は『仕入』の行で計算すること」または「『売上原価』の行で計算すること」と指示される。仕入の行で計算するなら2本の仕訳（しーくりくりしー）、売上原価の行で計算するなら3本の仕訳を使う。どちらの方法でも、損益計算書に表示する「売上原価」の金額は同じだ。
::

## 答え合わせ ― 「仕入」は「原価」ではない

::scene 3月31日、午後11時 ― セントラルキッチンの冷凍庫前
マイナス20度の冷凍庫から出てきたアルバイトの手には、霜のついたバーコードリーダーが握られていた。段ボールを1箱ずつ読み取り、品名と重さを入力していく。12店舗と、食材を加工するセントラルキッチン。全部を数え終えたのは、日付が変わる直前だった。
冷凍庫の扉の外で、ひよりは記録用紙の数字を本部に送った。本部の会議室で、財務担当役員の佐伯は、届いた数字を表計算ソフトに打ち込んだ。期末の在庫は2,000万円。去年の今ごろ、この冷凍庫には8,000万円分の牛肉が眠っていた。
佐伯は、「しーくりくりしー」の2行の仕訳を入力した。仕入勘定の残高が、4億300万円から4億6,300万円に変わる。画面の営業利益の欄が、1億700万円から4,700万円に書き換わった。
佐伯は時計を見て、大森の携帯番号を押した。
::

::solve 消えた6,000万円の正体は、去年の冷凍庫の中にあった
大森が毎月見ていた「仕入4億300万円」は、**今期に買った食材の金額**にすぎない。売れた商品の原価（売上原価）ではなかった。
実は前期の秋、輸入牛肉の卸値が1年で2倍近くに跳ね上がるのを見たおかわり堂は、「まだ上がる」と読んで、通常の4倍にあたる**8,000万円分の牛肉を冷凍で買いだめ**していた。今期は、その在庫を使いながら営業していたため、新たな仕入は少なくて済んでいた。仕入率31%という「好成績」の正体は、前期に買った肉を食べていたことによる錯覚だったのだ。
決算で在庫を数えると、冷凍庫に残っていたのは2,000万円分。買いだめ分の差額6,000万円が、今期の原価に加わった。

::table 社長の頭の中と、決算書の真実
| 項目 | 社長の見込み | 決算書の真実 |
| 売上高 | 13億円 | 13億円 |
| 原価 | 4億300万円（仕入） | 4億6,300万円（売上原価） |
| 売上総利益 | 8億9,700万円 | 8億3,700万円 |
| 人件費・家賃などの経費 | 7億9,000万円 | 7億9,000万円 |
|= 営業利益 | 1億700万円 | 4,700万円 |
::
本当の原価率は**35.6%**（4億6,300万円÷13億円）。業界平均並みどころか、過去最悪の水準だった。決算賞与の約束は、存在しない利益の上に立っていたのである。
「しーくりくりしー」は、試験のための呪文ではない。**買った金額と、使った金額は違う**という当たり前の事実を、帳簿に反映させるための仕訳なのだ。
::

翌日の午後、社長室。ひよりはホワイトボードに売上原価のボックス図を描き、左上に「期首 8,000万円」と書き込んだ。「社長が毎月ご覧になっていた仕入は、今期に買った肉の代金です。でも、今期に使った肉には、去年の秋に買って冷凍庫に入れた肉が含まれています」
大森は長いあいだ図を見ていた。それから、ぽつりと言った。「去年の肉を、今年の利益で食べとったわけか」
決算賞与は、約束の半分に減らして支給された。大森は全店長を集め、自分の言葉で理由を説明した。翌月から、おかわり堂の月次の試算表には、毎月の棚卸しを反映した「売上原価」の行が加わった。

::real 牛丼の値段を動かした「ミートショック」
おかわり堂が買いだめに走った背景には、現実の出来事がある。2021年、世界的な牛肉需要の高まりと物流の混乱で、輸入牛肉の価格が急騰した。牛丼に使われる米国産のバラ肉（ショートプレート）の卸値は、前年に1kgあたり600円台だったものが、2021年4月以降は1,000円を超え、夏には1,100円台に達した。2倍近い上昇である。
大手牛丼チェーンの吉野家は、2021年10月29日、牛丼並盛（店内）を387円から426円に値上げした。理由は輸入牛肉の高騰に、原油高による物流費と包装材のコスト増が重なったことだった。その後も円安が続き、2024年5月には米国産バラ肉の卸値が1kgあたり1,436円と、前年の約1.6倍になった。牛丼チェーン各社は、その後も値上げを重ねていく。
**この章の道具で読む ― 牛丼1杯の「売上原価」は、いくら上がったのか**
報道された卸値を使って、牛丼1杯あたりの牛肉の原価を計算してみよう。1杯に使う牛肉を、仮に90gとする（実際の量は各社で異なる）。

::table 牛丼1杯に使う牛肉の原価（牛肉90gと仮定）
| 時期 | 米国産バラ肉の卸値（1kg） | 1杯あたりの牛肉の原価 | 並盛387円に対する割合 |
| 2020年 | 600円台（650円で計算） | 約59円 | 約15% |
| 2021年夏 | 1,100円台（1,150円で計算） | 約104円 | 約27% |
::
1杯あたりの原価は、およそ45円増える。牛肉だけで、原価率が12ポイントも上がる計算だ。吉野家の値上げ幅39円（387円→426円）は、この増加分をほぼ価格に転嫁した水準と読める。
仕入の仕訳で見ると、同じ1トンの牛肉でも、2020年なら「仕入 650,000／買掛金 650,000」、2021年夏なら「仕入 1,150,000／買掛金 1,150,000」になる。ただし、三分法では、その仕入がすぐに売上原価になるとは限らない。値上がりの前に安く買って冷凍しておいた肉があれば、それを使い切るまでは、売上原価の上昇は遅れて表れる。おかわり堂の仕入率31%の「好成績」は、まさにこの遅れだった。仕入値がこれほど動くと、「いつ買い、いつ使ったか」で、毎月の利益の見え方が大きく変わる。売上原価を正しく計算することは、値上げの判断そのものの前提になる。
::note

::danger 期末在庫を「水増し」すると、利益が湧いてくる
売上原価の式をもう一度見てほしい。期末商品棚卸高は「マイナス」の項目だ。つまり、**期末の在庫を多く数えれば数えるほど、売上原価は小さくなり、利益は大きくなる**。
存在しない在庫を帳簿に載せる「架空在庫」は、粉飾決算の古典的な手口だ。倉庫の中を誰も確かめなければ、在庫を1億円水増しするだけで、利益を1億円作り出せてしまう。逆に、在庫を少なく数えれば利益が小さくなり、税金を逃れようとする不正にもつながる。
だからこそ上場企業の監査では、監査人が決算日の棚卸しに立ち会い、実際に商品を数える（**実地棚卸の立会**）。数字が合っているかではなく、**その在庫が本当にそこにあるか**を確かめるのだ。
::

::real 「在庫の水増し」は、大企業でも起きた
2019年11月、液晶パネル大手のジャパンディスプレイ（JDI）に、管理部門の幹部だった元社員から通知が届いた。「当時の経営陣の指示を受け、過去の決算で不適切な会計処理を行っていた」。社内の調査では、過去の決算で累計100億円程度の在庫を資産として過大に計上していた疑いが浮上し、調査は外部の専門家だけで構成する第三者委員会に引き継がれた。
2020年4月に公表された報告では、架空の在庫の計上や、売れ残った在庫の評価減を不正に避けていたことなどが指摘された。在庫を多く見せれば、売上原価が小さくなり、利益が大きく見える。上の式のとおりの手口である。

**この章の道具で読む ― 在庫の水増しは「しーくりくりしー」をどう狂わせるか**
期末の在庫を100億円多く数えると、決算整理の「くり・しー」の仕訳が、本来より100億円大きくなる（単位：億円、仕組みを示すために簡略化）。

::journal 水増しした年：期末商品を繰越商品へ（本来の在庫に、存在しない100を上乗せ）
繰越商品 100 | 仕入 100
::

貸方の仕入が100多く減るので、売上原価が100小さくなり、利益が100大きくなる。ここまでは「上の式のとおり」だ。だが、話はここで終わらない。翌期の決算では、この在庫が期首の在庫として「しー・くり」で仕入に戻ってくる。

::journal 翌期：期首商品を仕入へ（水増しした100も一緒に戻ってくる）
仕入 100 | 繰越商品 100
::

翌期の売上原価は、存在しない在庫の分だけ100大きくなり、利益は100小さくなる。これを隠すには、翌期末にもう一度、100以上の在庫を水増しするしかない。在庫の水増しは、1年限りの「前借り」であり、続けるほど嘘を大きくしなければならない仕組みなのだ。だから監査人は、決算日の倉庫に足を運び、在庫が本当にそこにあるかを自分の目で確かめる。ひよりが冷凍庫で記録用紙にチェックを入れていたのは、この確認の小さな一部だった。
::note
出典：[税務研究会「開示DB」](https://www.zeiken.co.jp/kaijidb/article/cat-1/1654.php)、[東洋経済オンライン（2020年）](https://toyokeizai.net/articles/-/345639)
::

## 売上総利益と原価率 ― 経営者が毎月見る数字

売上から売上原価を差し引いた利益を**売上総利益**（粗利）という。売上総利益を売上で割ったものが**売上総利益率**（粗利率）、売上原価を売上で割ったものが**原価率**だ。

::formula 売上総利益と原価率
売上総利益 ＝ 売上 － 売上原価
原価率 ＝ 売上原価 ÷ 売上
::

飲食業では、原価率は30〜35%前後がひとつの目安と言われる。さらに外食産業でよく使われるのが、食材費（Food）と人件費（Labor）の合計が売上に占める割合、**FL比率**だ。一般に60%以下に抑えたいとされ、これを超えると、家賃や光熱費を払った後に利益がほとんど残らなくなる。

::kpi おかわり堂・第8期の収益構造
売上高 | 13億円 | 過去最高
原価率（F） | 35.6% | 前期は33%
人件費率（L） | 30.0% | 深夜帯の割増賃金が重い
FL比率 | 65.6% | 目安の60%を大きく超過
::

::cfo 牛肉相場が読めない ― 最初の1手をどう選ぶか
おかわり堂が1年に使う牛肉は、今の値段で1億8,000万円分。来期の相場について、洛北ミートの北村はこう話した。「1割くらい上がるのが本線やろう。けど円安と干ばつが重なったら、2割5分上がってもおかしない。逆に、少し下がる可能性もゼロやない」
決算賞与の約束を果たせなかった大森は、銀行に「来期の利益は、今期から**1,000万円以上は下げない**」と約束している。大森が佐伯に見せた案は4つ。佐伯はそれを、ひよりに回してきた。
- **A　今の値段で、牛肉を半年分先に買って冷凍しておく**（外部の冷凍倉庫の保管料、買うための借入れの利息、冷凍焼けによるロスがかかる）
- **B　看板の牛すき丼を480円から520円に値上げする**（競合も値上げすれば客は少し減るだけだが、競合が値上げしなければ、客は大きく減る）
- **C　鶏と豚のメニューを増やし、牛肉の使用量を2割減らす**（置き換えた分の食材費は、牛肉より安い）
- **D　洛北ミートと、1年間の数量と価格を固定する契約を結ぶ**（価格は今より3%高い）
次の視点で、それぞれの案を考えてから選んでほしい。
- 相場が**上がったとき・下がったとき**で、その案の結果はどう変わるか
- 平均的に見た効果（**期待値**）と、**最悪の場合**の結果は、それぞれどうか
- 銀行との約束のように、**絶対に割ってはいけない線**があるとき、どちらを優先すべきか
::choice A. 牛肉を半年分、先に買いだめする
**× 相場が上がれば少し得をするが、下がれば大きく損をする。しかも見えないコストが重い。**値上がりの前に買うので、上がるほど得をする。だが、保管料・利息・ロスは相場と関係なく必ずかかる。相場が下がれば、市場より高く買ったうえに、それらのコストを払うことになる。
仮の設定で試算すると、期待値で見た改善はわずか170万円ほど、相場が下がれば1,000万円を超える悪化になる。しかも大量の現金が冷凍庫で眠り、来期の毎月の試算表では「仕入」が少なく見える。この章の問いそのものの錯覚を、もう一度作ることになる。
::
::choice B. 牛すき丼を40円値上げする
**○ 平均的には最も効くが、最悪の場合に約束を割る。**値上げは、牛肉の値上がりそのものを止める手ではなく、利益の幅を広げる手だ。相場とは関係なく効くので、平均的に見れば4案で最も利益を増やす。
だが、相場が大きく上がり、しかも競合が値上げに追随しない、という悪いことが重なったときを考えてほしい。仮の設定では、利益は今期より約3,900万円下がり、銀行との約束を大きく割る。期待値だけで選ぶと、この「起こりうる最悪」を見落とす。
::
::choice C. 牛肉の使用量を2割減らす
**△ どの相場でも効くが、最悪の場合を救えない。**牛肉を安い食材に置き換えれば、相場がどう動いても食材費は下がる。ただ、牛肉の使用量の8割はそのまま相場の影響を受ける。仮の設定では、相場が大きく上がったときの利益の悪化は約2,700万円で、やはり約束を割る。
しかも「牛すき丼の店」という看板を削る手で、客の反応は試してみないとわからない。
::
::choice D. 1年間の固定価格契約を結ぶ
**◎ 最初に打つべき手。結果を「確定」させる。**相場がどう動いても、牛肉代は今より3%高い金額で決まる。仮の設定では、利益への影響はどの相場でも**△540万円**に固定される。相場が下がれば「何もしなかったほうが得だった」ことになるが、それは結果の振れ幅を消すための保険料だ。
平均的な効果（期待値）はBより低い。それでも、銀行との約束を**どの相場でも守れる唯一の案**だ。そのうえでBの値上げを重ねれば、平均的な利益を大きく伸ばしつつ、最悪の場合でも約束を守れる。
::
::answer 考え方の例を見る
北村の見通しを、**仮の設定**として数字に置き直して試算してみよう。
- 来期の相場：今より10%上がる（確率60%）、25%上がる（20%）、5%下がる（20%）
- A：半年分9,000万円を今の値段で買う。保管料・利息・ロスで計730万円かかる
- B：競合が追随すれば（確率70%）利益が約3,600万円増え、追随しなければ（30%）約600万円の増加にとどまる。期待値は約2,700万円
- C：置き換えた分の食材費は牛肉の6割ですむ
- D：牛肉代は1億8,540万円で固定
::table シナリオ別の利益への影響（今期との比較、仮の設定。単位：万円）
| 案 | 10%上昇（60%） | 25%上昇（20%） | 5%下落（20%） | 期待値 | 最悪の場合 |
| 何もしない | △1,800 | △4,500 | ＋900 | △1,800 | △4,500 |
| A　買いだめ | △1,630 | △2,980 | △280 | △1,630 | △2,980 |
| B　値上げ | 約＋900 | 約△1,800 | 約＋3,600 | 約＋900 | 約△3,900 |
| C　牛肉を2割減らす | 約△220 | △2,700 | 約＋2,270 | 約△220 | △2,700 |
| D　固定価格契約 | △540 | △540 | △540 | △540 | △540 |
::
（Bの各シナリオは、値上げの効果の期待値2,700万円を加えたもの。最悪の場合は、25%上昇と競合の非追随が重なったとき。）
この表から、実務の判断の2つの軸が見えてくる。
- **期待値**：平均すれば、どれだけ良くなるか。期待値だけならBが最善だ。
- **最悪の場合（下振れ）**：守らなければならない約束や、会社が耐えられる損失の限度を超えないか。銀行との約束、借入金の財務制限条項（第12章）、賞与の約束などが、この「限度」を決める。
限度を守れる手で**まず下振れを止め**、そのうえで期待値を上げる手を重ねる。D→Bの順番だ。相場の変動を契約で固定することを、実務では**ヘッジ**という。ヘッジは得をする手ではなく、「読み違えたときの損の幅を小さくする手」である。
**さらに考えよう：固定価格は「3%高」でなく「8%高」を求められたら？**
仮の設定では、牛肉代は1億9,440万円に固定され、利益への影響はどの相場でも△1,440万円。これでは、ヘッジをしても約束（△1,000万円以内）を割ってしまう。それでも最悪の場合（何もしなければ△4,500万円）よりはずっと小さい。この場合は、固定する量を半分にしてヘッジの費用を抑え、値上げ（B）と牛肉の削減（C）を組み合わせて、どのシナリオでも約束の線を守れる組み合わせを探すことになる。**ヘッジの値段しだいで、最善の手の組み合わせは変わる。**
そして、どの案を選んでも、その効果を毎月正しく測れなければ意味がない。おかわり堂は第9期から、**毎月末に主要食材を数え、「仕入」ではなく「売上原価」で原価率を見る**ことを始めた。
::

## {{new:2027年度〜}} 売上原価対立法 ― 売るたびに原価を記録する方法

2027年4月以降の試験では、2級で学んでいた**売上原価対立法**（販売のつど売上原価勘定に振り替える方法）が、3級の出題範囲に加わる予定だ（暫定版）。
売上原価対立法では、商品を**商品勘定（資産）**で記録し、売ったときに、売価で売上を計上すると**同時に**、その商品の原価を商品勘定から**売上原価勘定（費用）**へ振り替える。

::journal 売上原価対立法：商品300,000円を掛けで仕入れた
商品 300,000 | 買掛金 300,000
::

::journal 売上原価対立法：原価200,000円の商品を280,000円で掛け販売した
売掛金 280,000 | 売上 280,000
売上原価 200,000 | 商品 200,000
::

売るたびに原価を振り替えるので、商品勘定の残高は常に「いま手元にあるはずの在庫」を、売上原価勘定の残高は「これまでに売れた商品の原価」を示す。三分法のような「しーくりくりしー」の決算整理は不要になる。

::table 3つの記帳方法の比較
| 項目 | 分記法 | 三分法 | 売上原価対立法 |
| 仕入時 | 商品 ／ 買掛金など | 仕入 ／ 買掛金など | 商品 ／ 買掛金など |
| 販売時 | 現金など ／ 商品・商品売買益 | 現金など ／ 売上 | 現金など ／ 売上、売上原価 ／ 商品 |
| 売上原価の把握 | 販売のつど（利益のみ記録） | 期末の棚卸しで一括計算 | 販売のつど |
| 決算整理（売上原価） | 不要 | 必要（しーくりくりしー） | 不要 |
| 向いている業態 | 少量・高額の商品 | 多品種・大量販売 | POSや在庫システムで原価を即時把握できる会社 |
::

::point 売上原価対立法が広がる背景
売るたびに原価を記録するには、1つ1つの商品の原価をすぐに調べられる仕組みが必要だ。かつては手間がかかりすぎたが、POSレジと在庫管理システムが普及した現在では、販売の瞬間に原価を自動で記録できる。今回のケースのような「決算の日のサプライズ」も起きにくい。技術の進歩が、簿記の標準を動かしているのである。
::

::exam 商品売買の急所
- 三分法：仕入れたら「仕入」、売ったら売価で「売上」。商品勘定は使わない（繰越商品は決算で使う）。
- 当社負担の引取運賃などの**仕入諸掛は仕入に含める**。当社負担の**発送費は「発送費」**（費用）。
- 送料を顧客から受け取る場合は、送料込みの金額で売上を計上し、支払った送料は発送費。
- 返品は、もとの仕訳の逆仕訳。
- 決算整理は「仕入／繰越商品（期首）」「繰越商品／仕入（期末）」。精算表や損益計算書では、整理後の仕入勘定の残高が「売上原価」になり、貸借対照表では繰越商品が「**商品**」と表示される。
- 「売上原価の行で計算する」と指示されたら、「売上原価／繰越商品」「売上原価／仕入」「繰越商品／売上原価」の3本の仕訳を使う。
- 分記法は現在の3級の出題範囲外。商品売買は三分法で処理する。
- 2027年度以降は売上原価対立法も出題範囲に入る予定。販売時に「売上原価／商品」を同時に記録する。
::

::next 原価の「中身」を分解する ― 2級の工業簿記へ
2級では、帳簿上の在庫と実際の在庫のズレ（**棚卸減耗損**）や、値下がりした在庫の評価損（**商品評価損**）を学ぶ。冷凍庫で霜焼けした牛肉や、賞味期限が近づいた食材の価値をどう測るか、という問題だ。
さらに、おかわり堂が将来セントラルキッチン（集中調理工場）を作り、たれや惣菜を自社で製造するようになれば、原価は「仕入れた値段」だけでは決まらない。材料費・労務費・経費を集計して製品の原価を計算する**工業簿記**の世界だ。2級の約4割を占めるこの分野は、製造業の経理・財務の仕事に欠かせない知識だ。
::

::problem 期末商品棚卸高を、実際より50,000円多く数えてしまった。売上原価と売上総利益は、正しい金額と比べてどうなるか。

期末商品棚卸高は売上原価の式でマイナスする項目なので、多く数えると**売上原価は50,000円小さく**なり、**売上総利益は50,000円大きく**なる。
これが「在庫の水増しで利益が増える」仕組みだ。

::summary
- 分記法は販売のつど利益を計算する方法、三分法は「仕入・売上・繰越商品」の3勘定で記録し、原価を期末にまとめて計算する方法
- 当社負担の仕入諸掛は仕入に含める（取得原価＝購入代価＋付随費用）。当社負担の発送費は費用
- 送料を顧客から受け取るときは売上に含め、支払った送料は発送費とする。返品は逆仕訳
- 売上原価＝期首商品棚卸高＋当期商品仕入高－期末商品棚卸高。決算整理は「しーくりくりしー」
- 「仕入」は今期に買った額、「売上原価」は今期に売れた商品の原価。この2つは違う
- 期末在庫を多く数えると利益が増える。だから棚卸しは厳格に行われる
- 2027年度からは、販売のつど「売上原価／商品」と記録する売上原価対立法も3級の範囲に入る予定
