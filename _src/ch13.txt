::mystery 累積赤字10億円の会社に、30億円が集まった日
飲食店向けのシフト管理クラウド「シフトクラウド」。ひよりが学生時代、出町柳店のシフトの希望をスマートフォンから出していたのも、このアプリだった。創業者の早瀬は、学生時代に居酒屋の店長代理として、毎週日曜の夜を手書きのシフト表づくりに費やしていた。その面倒をスマートフォンで片づけるサービスを作って4年。会社を作るときの登記の書類から、一ノ瀬が手伝ってきた顧問先だ。売上は毎年1.5倍のペースで伸び、年間の契約売上（ARR）は**6億円**に達した。
だが、決算書の最終行は、創業以来ずっと赤字だ。今期の当期純損失は**4億円**。4年間の赤字を積み上げた累積赤字は**10億円**。預金の残高は4億円しかなく、このままのペースでお金を使い続ければ、**約1年で資金が尽きる**。
メインバンクの応接室。融資の相談に来た早瀬に、担当者は言った。
担当者：「赤字が4期続いて、累積赤字が10億円。正直、今の決算書では難しいです」
早瀬：「来年には、売上が9億円になります」
担当者：「来年の数字は、まだ決算書に載っていませんので」
その面談に同席していたひよりは、銀行の担当者の言い分がよく分かった。第1章で村井に教わった物差しで測れば、赤字が続いて純資産を削り続ける会社は、貸しにくい相手そのものだ。
ところが、この年の秋、シフトクラウドはベンチャーキャピタル数社から、**30億円**の出資を受けることに成功した。
銀行が貸さなかった会社に、なぜプロの投資家たちは30億円もの大金を投じたのか？
ひより：「赤字の会社に、どうして……」
一ノ瀬：「9月の投資家との面談に、一緒に来てください。答えは、損益計算書の最終行ではないところにあります」
::

## 株式会社 ― 「お金を出す人」と「経営する人」を分ける発明

東京へ向かう新幹線の中で、一ノ瀬はシフトクラウドの登記簿の写しを広げた。
一ノ瀬：「まず、銀行と投資家の違いを、株式会社の仕組みから押さえておきましょう。銀行は、お金を貸す人です。投資家は、お金を出して会社の持ち主になる人です」
ひより：「持ち主？」
一ノ瀬：「会社にお金を出すと、その証として**株式**がもらえます。株式を持っている人が**株主**、つまり会社の持ち主です。早瀬さんは社長ですが、会社のすべてを持っているわけではありません」

::table 株式会社の主な登場人物
| 登場人物 | 役割 |
| 株主 | 会社にお金を出資し、株式を持つ。会社の持ち主。株主総会で重要な事項を決める |
| 株主総会 | 株主が集まる、会社の最高意思決定機関。取締役の選任や配当の決定などを行う |
| 取締役 | 株主から経営を任された人。会社の業務を決定・執行する |
::

::theory 有限責任と「所有と経営の分離」
株式会社の株主は、会社が倒産しても、**出資した金額以上の責任を負わない**。これを**有限責任**という。会社がどれだけ借金を抱えても、株主が自分の財産で弁済する義務はない。失うのは出資したお金だけだ。
この仕組みがあるからこそ、人々は安心して見知らぬ会社にお金を出せる。そして、出資する人（株主）と経営する人（取締役）を分けることで、お金はあるが経営の才能がない人と、才能はあるがお金がない人が、手を組めるようになった。これを**所有と経営の分離**という。
株式会社は、現代の経済活動を支える、最も基本的な仕組みなのである。
::

ひより：「銀行は、貸したお金が返ってくるかを見る。株主は……」
一ノ瀬：「会社がこれから、どれだけ大きくなるかを見ます。返してもらうつもりは、最初からありません」

## 株式の発行 ― 出資されたお金は「資本金」

一ノ瀬は、登記簿の「発行済株式の総数」の欄を指さした。
一ノ瀬：「設立のとき、早瀬さんたちは200株を発行しました。1株5万円です」
ひより：「合わせて1,000万円。それが、最初の資本金ですか」
一ノ瀬：「そうです。株を発行して受け取ったお金は、**資本金**という純資産になります。今回の30億円も、帳簿の上では同じ形の仕訳になります」
ひより：「1株、いくらなんですか」
一ノ瀬：「150万円です」
ひよりは、思わず登記簿を見直した。
ひより：「5万円が、4年で150万円……30倍？」
一ノ瀬：「投資家は、会社の価値が30倍になったと見ているんです」

::example シフトクラウドの設立と増資
(1) 創業時、株式200株を1株あたり50,000円で発行し、全額の払込みを受けて普通預金とした。
(2) 4年後、ベンチャーキャピタル数社に対して、株式2,000株を1株あたり1,500,000円で発行し、払込金額は普通預金に入金された。
::answer
::journal (1) 設立時：200株×50,000円＝10,000,000円
普通預金 10,000,000 | 資本金 10,000,000
::
::journal (2) 増資：2,000株×1,500,000円＝3,000,000,000円
普通預金 3,000,000,000 | 資本金 3,000,000,000
::
同じ会社の株式が、創業時は1株5万円、4年後は1株150万円。投資家は、4年間で会社の価値が30倍になったと評価したことになる。
※創業から今回の増資までの間にも2回の増資を行っており、増資直前の資本金は12億円になっていた。
::trap
株式を発行して受け取ったお金を、売上や借入金にしないこと。株主から預かった元手なので、**資本金**（純資産）の増加だ。
金額は「発行した株数×1株あたりの払込金額」。株数だけ、単価だけで仕訳を書かないように。
::
::
::

::note
※2級では、払込金額のうち2分の1までを資本金としないで「資本準備金」とする処理を学ぶ。3級では、問題文に特に指示がない限り、全額を資本金とする。
::

## 繰越利益剰余金 ― 会社が稼いだ利益の「貯金箱」

ひより：「株主が出したお金が資本金なら、会社が自分で稼いだ利益は、どこに入るんですか」
一ノ瀬：「**繰越利益剰余金**です。毎年の利益が、この貯金箱に貯まっていきます。赤字なら、貯金箱から減ります」

::journal 決算：当期純利益5,000,000円を、繰越利益剰余金に振り替えた（損益勘定から振り替える）
損益 5,000,000 | 繰越利益剰余金 5,000,000
::

::journal 決算：当期純損失400,000,000円を、繰越利益剰余金に振り替えた
繰越利益剰余金 400,000,000 | 損益 400,000,000
::

::note
※「損益」は、決算のときに収益と費用をすべて集めて当期純損益を計算するための勘定（第19章）。
::

一ノ瀬：「シフトクラウドの貯金箱は、4年分の赤字で、マイナス10億円です。株主から集めたお金のうち、10億円分を事業に使い切った状態です」

::boxes シフトクラウドの貸借対照表（増資の直前）
H 資産 5億円 | 負債・純資産 5億円
L a 80 普通預金<br>4億円
L s 20 その他の資産 1億円
R l 40 前受金 2億円
R l 20 その他の負債 1億円
R e 40 純資産 2億円<br>（資本金12億円－<br>繰越利益剰余金△10億円）
::

ひより：「純資産が2億円しか残ってない。銀行が渋るのも分かります」
一ノ瀬：「銀行の目で見れば、そうです。では、投資家の目で見たらどうなるか。明日、見に行きましょう」

## 答え合わせ ― 投資家は「決算書」ではなく「未来の利益」を買っている

::scene 9月、東京・六本木 ― ベンチャーキャピタルの会議室
ガラス張りの会議室に、早瀬と一ノ瀬、ひより、そして投資家が3人。早瀬が損益計算書のスライドを開こうとすると、投資家の1人が手で制した。
投資家：「赤字なのは知っています。それより、解約率を見せてください。月に何%の店がやめていますか」
早瀬：「月1%です。100店のうち、やめるのは月に1店です」
投資家：「1店を獲得するのに、広告と営業でいくらかかっていますか」
早瀬：「約18万円です」
投資家は、手元のメモに数字を書き込んだ。月額1万5,000円、粗利率80%、平均で100か月使い続ける。
投資家：「つまり、18万円で、120万円の粗利を生む店を1つ買っている。それを今期は1,800店買った。その代金を全部、今期の費用として払ったから赤字になっている。そういうことですね」
早瀬：「はい」
会議室の空気が変わった。投資家たちは、顔を見合わせてうなずいた。
ひよりは、手元のノートに書いた数字を見つめた。18万円の広告費。会計のルールでは、使った年の費用だ。けれど投資家は、それを「店を1つ買った代金」と呼んだ。
同じ数字が、読む人によって、違うものに見えている。
::

::solve 赤字の正体は「将来の売上を買うための投資」だった
投資家たちが見ていたのは、損益計算書の最終行ではない。**赤字の中身**だ。
シフトクラウドの費用の多くは、新しい顧客を獲得するための広告費や営業担当者の人件費、そしてサービスを改良する開発者の人件費だった。会計のルールでは、これらは使った年の**費用**になる。だが、その効果は何年にもわたって続く。
1店舗の顧客を獲得するのにかかる費用は約18万円。一方、獲得した店舗は月額15,000円を払い、平均で約100か月（8年以上）使い続ける。サーバー代などを差し引いた粗利は、1店舗あたり約120万円だ。

::kpi シフトクラウドの「1店舗あたり」の経済性（ユニットエコノミクス）
顧客獲得コスト（CAC） | 18万円 | 獲得した年に全額費用になる
月額利用料 | 15,000円 | 粗利率80%
平均利用期間 | 約100か月 | 月間解約率1%
顧客生涯の粗利（LTV） | 120万円 | 15,000円×80%×100か月
LTV÷CAC | 約6.7倍 | 3倍以上なら優秀とされる
::

今期、シフトクラウドは約1,800店舗を新たに獲得し、そのための費用3億円以上を、今期の費用として計上した。会計上は大赤字だ。だが、その1,800店舗は、これから何年もかけて、獲得費用の数倍の粗利を生み出し続ける。
つまり、シフトクラウドの赤字は、「お金を失った」赤字ではなく、「将来の売上を前払いで買った」赤字なのだ。成長を速めるほど、目先の赤字は大きくなる。投資家は、この**赤字の「質」**を見抜き、30億円という燃料を注ぎ込んだのである。
増資によって、貸借対照表の資本金は42億円に、純資産は32億円に回復した。預金は34億円。約1年だった資金の余命は、一気に数年に延びた。
::

帰りの新幹線で、ひよりは一ノ瀬に聞いた。
ひより：「会計のルールが、間違ってるんでしょうか。将来も稼げる広告費なら、バスみたいに何年かに分けて費用にすればいいのに」
一ノ瀬：「バスは、目の前にあります。でも、広告で獲得したお客さんが本当に8年使い続けるかは、誰にも約束できません。だから会計は、慎重に、使った年の費用にする。間違っているのではなく、慎重なんです」
ひより：「だから、決算書を読み替える人が必要になる」
一ノ瀬：「そうです。読み替えるためには、まず、決算書が何をどう記録しているかを知らなければなりません」

::theory 会計上の利益と、企業価値はイコールではない
会計は、過去の取引を、慎重なルールで記録する。広告費や開発費のように、効果が将来に及ぶかどうか不確実な支出は、原則として発生した期の費用にする。これは、利益の水増しを防ぐための保守的なルールだ。
その結果、成長のための投資を大量に行う会社ほど、会計上の利益は小さく、あるいは赤字になりやすい。一方、投資家が評価するのは、その会社が**将来生み出すキャッシュ**の大きさだ。
だからこそ、投資家は決算書を「読み替える」。どの費用が将来への投資なのか。顧客1人あたりの経済性は成り立っているのか。簿記の知識は、この読み替えの出発点になる。決算書を正確に読める人だけが、決算書の「その先」を読めるのだ。
::

::danger 資金の「余命」が尽きる日
赤字のスタートアップには、常に**ランウェイ**（資金が尽きるまでの期間）という時計が動いている。月に約3,300万円の現金を使うシフトクラウドなら、預金4億円で余命は約1年だ。解約率が上がる、顧客獲得コストが膨らむ。1店舗から得る粗利が獲得コストを下回れば、「成長するほど損をする」ビジネスになり、赤字は投資ではなく、ただの出血になる。
::

::real 大企業が、資本金を「1億円」に減らした理由
資本金の大きさは、会社の格を表すものだと思われがちだ。ところが2020年度、資本金を1億円以下に減らし、税制上「中小企業」として扱われるようになった大企業が**997社**にのぼった（東京商工リサーチの集計）。旅行大手のJTBは23億400万円から、航空会社のスカイマークは90億円から、それぞれ資本金を1億円に減らした。
狙いは税金だ。資本金1億円以下の会社には、法人税の軽減税率が使えるほか、赤字でも納める法人事業税の「外形標準課税」がかからない。減資の仕訳は「資本金／資本剰余金」で、借方も貸方も純資産の勘定だ。お金は1円も動かず、純資産の「中の区分」が入れ替わるだけである。それでも、資本金という1つの勘定の金額が、税金の扱いを大きく変える。
::note
出典：[Business Journal「大企業、資本金1億円に減資の“中小企業化”急増」（2021年8月11日、東京商工リサーチの集計）](https://biz-journal.jp/company/post_243714.html)
::

## 剰余金の配当 ― 株主への「利益の分配」

東京から戻った翌週、ひよりはおかわり堂の本部で、6月の株主総会の資料づくりを手伝っていた。
ひより：「シフトクラウドの株主は、配当を1円も受け取っていません。おかわり堂の株主は、どうですか」
佐伯は、議案書の1行を見せた。
佐伯：「うちは毎年、利益の一部を株主にお返ししています。**剰余金の配当**です。ただし、全部は出しません」
ひより：「配当って、株主総会で決めたら、すぐに払うんですか」
佐伯：「決めるのは6月の総会、払うのは7月です。決めた日には、まだお金は出ていない。だから、払う約束として**未払配当金**という負債を立てておきます」

::table 配当で使う勘定科目
| 勘定科目 | 要素 | 内容 |
| 繰越利益剰余金 | 純資産 | 配当の原資。配当すると減る |
| 未払配当金 | 負債 | 決議された配当金のうち、まだ支払っていない額 |
| 利益準備金 | 純資産 | 配当にあわせて、会社法の規定により積み立てる準備金 |
::

::example おかわり堂の株主総会
(1) 6月の定時株主総会で、繰越利益剰余金を財源として、株主配当金3,000,000円を支払うことと、利益準備金300,000円を積み立てることが決議された。
(2) 7月、株主配当金3,000,000円を普通預金から支払った。
::answer
::journal (1) 決議時：繰越利益剰余金を減らし、未払配当金と利益準備金に振り替える
繰越利益剰余金 3,300,000 | 未払配当金 3,000,000
 | 利益準備金 300,000
::
::journal (2) 支払時
未払配当金 3,000,000 | 普通預金 3,000,000
::
::trap
決議の時点では、まだお金は出ていっていない。貸方は普通預金ではなく、**未払配当金**（負債）だ。
繰越利益剰余金が減る金額は、配当金と利益準備金の合計になる。配当金は費用ではないので、損益計算書には載らない。
::
::
::

ひより：「配当とは別に、利益準備金を30万円積み立てていますね。これは？」
佐伯：「法律で決まっている、会社の中に残しておくお金です。株主は、会社が潰れても出したお金以上の責任は負いません。だから、銀行や取引先を守るために、利益の一部を外に出さないようにしているんです」

::theory 利益準備金 ― 配当で会社を「空っぽ」にしないための安全装置
会社法では、剰余金を配当するときに、配当額の10分の1を、資本準備金と利益準備金の合計額が資本金の4分の1に達するまで、**準備金として積み立てる**ことを求めている。利益準備金は、配当として社外に流出させず、会社の中に留めておくための純資産だ。
なぜか。株主は有限責任なので、会社が倒産しても会社の借金を肩代わりしない。だから債権者（銀行や取引先）にとっては、会社の中に残っている財産だけが頼りだ。もし利益をすべて配当で吐き出せたら、債権者は丸裸になってしまう。利益準備金は、**有限責任の株主と、債権者の利害を調整するための仕組み**なのである。
3級では、積み立てる金額は問題文で与えられる。積立額の計算は2級で学ぶ。
::

::table 3級で登場する純資産の勘定
| 勘定科目 | 内容 |
| 資本金 | 株主が払い込んだ金額 |
| 利益準備金 | 配当にあわせて積み立てた準備金（会社の利益が原資） |
| 繰越利益剰余金 | 会社が稼いだ利益の蓄積のうち、配当などに使っていない部分 |
::


::cfo 7,000万円の利益をどう使うか
おかわり堂は今期、7,000万円の当期純利益を出す見込みだ。大森は配当の倍増（3,000万円→6,000万円）、店舗開発部長は出店（1店5,000万円）、佐伯は手元に残すことを主張している。
**前提**
- 手元の預金は1億円。来期の法人税等の支払いで約3,000万円が出ていく。月の途中で残高は3,000万円ほど下がる
- 出店は、銀行が1店あたり半額の2,500万円を貸すと言っている
- 株主は創業家と社員持株会で、配当の増額を特に求めてはいない
- 牛肉の相場の急騰には、前もって3か月分を買う方針で備えている
**考えるときの視点**
- 預金1億円のうち、自由に使えるお金はいくらか
- 3つの使い道のうち、借入と組み合わせられるのはどれか
::choice A. 配当を6,000万円に倍増する
**△ 自由に使えるお金を超えている。**預金1億円から、税金3,000万円と月の途中の谷3,000万円を引くと、自由に使えるのは約4,000万円だ。
::
::choice B. 配当は据え置き、銀行の融資を使って1店出す
**◎ 自由に使えるお金の範囲で、借入と組み合わせられる使い道を選んでいる。**自己負担は2,500万円で、約4,000万円の範囲に収まる。配当の増額は求められておらず、相場には別の方針で備えている。
::
::choice C. 銀行の融資を使って2店出す
**○ 攻めとしては魅力的だが、自己負担5,000万円は自由に使えるお金を超える。**谷が深くなりすぎる。
::
::choice D. すべて手元に残し、来期の状況を見て決める
**○ 安全だが、自由に使えるお金を見積もれば、1店は無理なく出せる。**相場への備えは別にある。
::
::answer 考え方の例を見る
- **自由に使えるお金を先に出す**：預金から、決まっている支払いと月の途中の谷を引く
- **借入と組み合わせる**：出店のように借入が使える投資は、自己負担の分だけで考える
- **求められていないことに使わない**：配当の増額は、株主が求めているかを確かめてから
::
::

::exam 純資産の急所
- 株式を発行したら、3級では払込金額の**全額を資本金**とする（設立時も増資時も同じ）。株数×1株あたりの払込金額を正確に計算する。
- 当期純利益は「損益／繰越利益剰余金」、当期純損失は「繰越利益剰余金／損益」で振り替える。
- 配当の決議時：「繰越利益剰余金／未払配当金・利益準備金」。支払時：「未払配当金／普通預金など」。決議時と支払時を混同しない。
- 利益準備金の積立額は、3級では問題文で与えられる。
- 繰越利益剰余金が借方残高（マイナス）のとき、貸借対照表では純資産の部にマイナスで表示される。
::

::next 純資産の部は、もっと奥が深い
2級では、増資の際に資本金と**資本準備金**に分ける処理や、純資産の1年間の変動をまとめた**株主資本等変動計算書**を学ぶ。1級では、自己株式や新株予約権など、株式をめぐる高度な論点に進む。
::

::summary
- 株式会社は、株主（出資者・有限責任）と取締役（経営者）を分けて、大きな資金を集める仕組み
- 株式を発行したら、3級では払込金額の全額を資本金（純資産）とする
- 当期純利益は繰越利益剰余金を増やし、当期純損失は減らす。繰越利益剰余金は利益の蓄積
- 配当の決議時は「繰越利益剰余金／未払配当金・利益準備金」、支払時は「未払配当金／預金」
- 利益準備金は、配当で会社の財産を空っぽにしないための安全装置
- 会計上の赤字でも、その中身が将来の売上を生む投資なら、投資家は資金を出す。赤字の「質」を見抜くことが大切
::

::problem 1店舗あたりの顧客獲得コストが30万円、月額利用料が1万円（粗利率80%）、平均利用期間が30か月のサービスがある。LTV（顧客生涯の粗利）とLTV÷CACを求め、このサービスの成長について考えを述べなさい。
LTV：[[24]] 万円　LTV÷CAC：[[0.8]] 倍
::answer
LTV＝1万円×80%×30か月＝**24万円**。LTV÷CAC＝24万円÷30万円＝**0.8倍**。
1店舗を獲得するたびに、獲得費用を回収できずに損をする構造になっている。この状態で広告費を増やして成長を速めると、赤字は「投資」ではなく「出血」になる。解約率を下げて平均利用期間を延ばすか、獲得コストを下げるか、利用料を見直すなど、成長の前にユニットエコノミクスの改善が必要だ。
