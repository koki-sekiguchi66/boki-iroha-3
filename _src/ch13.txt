::mystery 累積赤字10億円の会社に、30億円が集まった日
飲食店向けのシフト管理クラウド「シフトクラウド」。創業者の早瀬は、学生時代に居酒屋の店長代理として、毎週日曜の夜を手書きのシフト表づくりに費やしていた。その面倒をスマートフォンで片づけるサービスを作って4年。売上は毎年1.5倍のペースで伸び、年間の契約売上（ARR）は**6億円**に達した。
だが、決算書の最終行は、創業以来ずっと赤字だ。今期の当期純損失は**4億円**。4年間の赤字を積み上げた累積赤字は**10億円**。預金の残高は4億円しかなく、このままのペースでお金を使い続ければ、**約1年で資金が尽きる**。
メインバンクの担当者は、融資の相談に来た早瀬に言った。「赤字が4期続いて、累積赤字が10億円。正直、今の決算書では難しいです」
ところが、この年の秋、シフトクラウドはベンチャーキャピタル数社から、**30億円**の出資を受けることに成功した。
銀行が貸さなかった会社に、なぜプロの投資家たちは30億円もの大金を投じたのか？

## 株式会社 ― 「お金を出す人」と「経営する人」を分ける発明

問いを解く前に、株式会社の仕組みを押さえておこう。
株式会社は、多くの人から少しずつお金を集めて、1人では始められない大きな事業を行うための仕組みだ。会社にお金を出した人には、その証として**株式**が発行される。株式を持つ人を**株主**という。

::table 株式会社の主な登場人物
| 登場人物 | 役割 |
| 株主 | 会社にお金を出資し、株式を持つ。会社の持ち主。株主総会で重要な事項を決める |
| 株主総会 | 株主が集まる、会社の最高意思決定機関。取締役の選任や配当の決定などを行う |
| 取締役 | 株主から経営を任された人。会社の業務を決定・執行する |
::

::theory 有限責任と「所有と経営の分離」
株式会社の株主は、会社が倒産しても、**出資した金額以上の責任を負わない**。これを**有限責任**という。会社がどれだけ借金を抱えても、株主が自分の財産で弁済する義務はない。失うのは出資したお金だけだ。
この仕組みがあるからこそ、人々は安心して見知らぬ会社にお金を出せる。そして、出資する人（株主）と経営する人（取締役）を分けることで、お金はあるが経営の才能がない人と、才能はあるがお金がない人が、手を組めるようになった。これを**所有と経営の分離**という。
株式会社は、現代の経済活動を支える、最も基本的な仕組みなのである。
::

## 株式の発行 ― 出資されたお金は「資本金」

株式会社が株式を発行して出資を受けたら、払い込まれた金額を**資本金**（純資産）として処理する。会社の設立時に株式を発行する場合も、設立後に新たに株式を発行する場合（**増資**）も、3級では**払込金額の全額を資本金**とする。

::example シフトクラウドの設立と増資
(1) 創業時、株式200株を1株あたり50,000円で発行し、全額の払込みを受けて普通預金とした。
(2) 4年後、ベンチャーキャピタル数社に対して、株式2,000株を1株あたり1,500,000円で発行し、払込金額は普通預金に入金された。
::answer
::journal (1) 設立時：200株×50,000円＝10,000,000円
普通預金 10,000,000 | 資本金 10,000,000
::
::journal (2) 増資：2,000株×1,500,000円＝3,000,000,000円
普通預金 3,000,000,000 | 資本金 3,000,000,000
::
同じ会社の株式が、創業時は1株5万円、4年後は1株150万円。投資家は、4年間で会社の価値が30倍になったと評価したことになる。
※創業から今回の増資までの間にも2回の増資を行っており、増資直前の資本金は12億円になっていた。
::
::

::note
※2級では、払込金額のうち2分の1までを資本金としないで「資本準備金」とする処理を学ぶ。3級では、問題文に特に指示がない限り、全額を資本金とする。
::

## 繰越利益剰余金 ― 会社が稼いだ利益の「貯金箱」

株主が出したお金が資本金なら、会社が自分で稼いだ利益はどこへ行くのか。答えは**繰越利益剰余金**（くりこしりえきじょうよきん・純資産）だ。
決算で計算された当期純利益は、繰越利益剰余金に振り替えられ、純資産を増やす。逆に当期純損失が出れば、繰越利益剰余金を減らす。詳しい手続きは第19章で学ぶが、ここでは流れだけを押さえておこう。

::journal 決算：当期純利益5,000,000円を、繰越利益剰余金に振り替えた（損益勘定から振り替える）
損益 5,000,000 | 繰越利益剰余金 5,000,000
::

::journal 決算：当期純損失400,000,000円を、繰越利益剰余金に振り替えた
繰越利益剰余金 400,000,000 | 損益 400,000,000
::

::note
※「損益」は、決算のときに収益と費用をすべて集めて当期純損益を計算するための勘定（第19章）。
::

赤字が続けば、繰越利益剰余金はマイナス（借方残高）になる。シフトクラウドの繰越利益剰余金は、4年間の赤字が積み重なって**△10億円**。株主が出した資本金のうち、10億円分を事業のために「使い果たした」状態だ。

::boxes シフトクラウドの貸借対照表（増資の直前）
H 資産 5億円 | 負債・純資産 5億円
L a 80 普通預金<br>4億円
L s 20 その他の資産 1億円
R l 40 前受金 2億円
R l 20 その他の負債 1億円
R e 40 純資産 2億円<br>（資本金12億円－<br>繰越利益剰余金△10億円）
::

## 答え合わせ ― 投資家は「決算書」ではなく「未来の利益」を買っている

::scene 9月、東京・六本木 ― ベンチャーキャピタルの会議室
早瀬が損益計算書のスライドを開こうとすると、投資家の1人が手で制した。
「赤字なのは知っています。それより、解約率を見せてください。月に何%の店がやめていますか」
「月1%です。100店のうち、やめるのは月に1店です」
「1店を獲得するのに、広告と営業でいくらかかっていますか」
「約18万円です」
投資家は、手元のメモに数字を書き込んだ。月額1万5,000円、粗利率80%、平均で100か月使い続ける。「つまり、18万円で、120万円の粗利を生む店を1つ買っている。それを今期は1,800店買った。その代金を全部、今期の費用として払ったから赤字になっている。そういうことですね」
早瀬はうなずいた。会議室の空気が変わった。
::

::solve 赤字の正体は「将来の売上を買うための投資」だった
投資家たちが見ていたのは、損益計算書の最終行ではない。**赤字の中身**だ。
シフトクラウドの費用の多くは、新しい顧客を獲得するための広告費や営業担当者の人件費、そしてサービスを改良する開発者の人件費だった。会計のルールでは、これらは使った年の**費用**になる。だが、その効果は何年にもわたって続く。
1店舗の顧客を獲得するのにかかる費用は約18万円。一方、獲得した店舗は月額15,000円を払い、平均で約100か月（8年以上）使い続ける。サーバー代などを差し引いた粗利は、1店舗あたり約120万円だ。

::kpi シフトクラウドの「1店舗あたり」の経済性（ユニットエコノミクス）
顧客獲得コスト（CAC） | 18万円 | 獲得した年に全額費用になる
月額利用料 | 15,000円 | 粗利率80%
平均利用期間 | 約100か月 | 月間解約率1%
顧客生涯の粗利（LTV） | 120万円 | 15,000円×80%×100か月
LTV÷CAC | 約6.7倍 | 3倍以上なら優秀とされる
::

今期、シフトクラウドは約1,800店舗を新たに獲得し、そのための費用3億円以上を、今期の費用として計上した。会計上は大赤字だ。だが、その1,800店舗は、これから何年もかけて、獲得費用の数倍の粗利を生み出し続ける。
つまり、シフトクラウドの赤字は、「お金を失った」赤字ではなく、「将来の売上を前払いで買った」赤字なのだ。成長を速めるほど、目先の赤字は大きくなる。投資家は、この**赤字の「質」**を見抜き、30億円という燃料を注ぎ込んだのである。
増資によって、貸借対照表の資本金は42億円に、純資産は32億円に回復した。預金は34億円。約1年だった資金の余命は、一気に数年に延びた。
::

::theory 会計上の利益と、企業価値はイコールではない
会計は、過去の取引を、慎重なルールで記録する。広告費や開発費のように、効果が将来に及ぶかどうか不確実な支出は、原則として発生した期の費用にする。これは、利益の水増しを防ぐための保守的なルールだ。
その結果、成長のための投資を大量に行う会社ほど、会計上の利益は小さく、あるいは赤字になりやすい。一方、投資家が評価するのは、その会社が**将来生み出すキャッシュ**の大きさだ。
だからこそ、投資家は決算書を「読み替える」。どの費用が将来への投資なのか。顧客1人あたりの経済性は成り立っているのか。簿記の知識は、この読み替えの出発点になる。決算書を正確に読める人だけが、決算書の「その先」を読めるのだ。
::

::danger 資金の「余命」が尽きる日
赤字のスタートアップには、常に**ランウェイ**（資金が尽きるまでの期間）という時計が動いている。シフトクラウドは月に約3,300万円の現金を使っていた。預金4億円なら、余命は約1年だ。
次の資金調達ができなければ、どれほど将来有望な事業でも、会社は止まる。そして投資家は、ユニットエコノミクスが崩れた瞬間に手を引く。解約率が上がる、顧客獲得コストが膨らむ、競合が値下げを仕掛ける。LTV÷CACが1倍を割れば、「成長するほど損をする」ビジネスになり、赤字は投資ではなく、ただの出血になる。
赤字が「投資」なのか「出血」なのか。それを見極められなかったスタートアップは、市場の資金が冷え込んだ局面で、次々と姿を消していった。
::

::real 大企業が、資本金を「1億円」に減らした理由
資本金の大きさは、会社の格を表すものだと思われがちだ。ところが2020年度（2020年4月〜2021年3月）、資本金を1億円以下に減らし、税制上「中小企業」として扱われるようになった大企業が**997社**にのぼった。前年度より39.4%多い。東京商工リサーチの集計である。
新型コロナで業績が落ち込んだ企業が目立つ。旅行大手のJTBは23億400万円から、毎日新聞社は41億円から、航空会社のスカイマークは90億円から、それぞれ資本金を1億円に減らした。
狙いは税金だ。資本金1億円以下の会社には、法人税の軽減税率が使えるほか、赤字でも納める必要がある法人事業税の「外形標準課税」がかからない。手元のお金を少しでも残したい会社にとっては、大きな違いになる。一方で、体力のある大企業が中小企業向けの優遇を受けることには批判もあり、税制の見直しが議論されてきた。
なお、資本金を減らしても、純資産の合計は変わらない。減らした資本金は、純資産の中の別の項目（資本剰余金）に移るだけだ。株主が払い込んだお金が消えるわけではないのである（資本剰余金は2級で学ぶ）。
::note
出典：[Business Journal「大企業、資本金1億円に減資の“中小企業化”急増」（2021年8月11日、東京商工リサーチの集計）](https://biz-journal.jp/company/post_243714.html)
::

## 剰余金の配当 ― 株主への「利益の分配」

最後に、黒字の会社の話をしよう。おかわり堂は、毎年安定して利益を出し、繰越利益剰余金を積み上げてきた。株主総会で、株主に利益の一部を分配することが決まった。これを**剰余金の配当**という。
配当は、株主総会の決議によって決まり、その後に支払われる。決議の時点では、まだお金は支払っていないので、株主に支払う義務を**未払配当金**（負債）として計上する。

::table 配当で使う勘定科目
| 勘定科目 | 要素 | 内容 |
| 繰越利益剰余金 | 純資産 | 配当の原資。配当すると減る |
| 未払配当金 | 負債 | 決議された配当金のうち、まだ支払っていない額 |
| 利益準備金 | 純資産 | 配当にあわせて、会社法の規定により積み立てる準備金 |
::

::example おかわり堂の株主総会
(1) 6月の定時株主総会で、繰越利益剰余金を財源として、株主配当金3,000,000円を支払うことと、利益準備金300,000円を積み立てることが決議された。
(2) 7月、株主配当金3,000,000円を普通預金から支払った。
::answer
::journal (1) 決議時：繰越利益剰余金を減らし、未払配当金と利益準備金に振り替える
繰越利益剰余金 3,300,000 | 未払配当金 3,000,000
 | 利益準備金 300,000
::
::journal (2) 支払時
未払配当金 3,000,000 | 普通預金 3,000,000
::
::
::

::theory 利益準備金 ― 配当で会社を「空っぽ」にしないための安全装置
会社法では、剰余金を配当するときに、配当額の10分の1を、資本準備金と利益準備金の合計額が資本金の4分の1に達するまで、**準備金として積み立てる**ことを求めている。利益準備金は、配当として社外に流出させず、会社の中に留めておくための純資産だ。
なぜか。株主は有限責任なので、会社が倒産しても会社の借金を肩代わりしない。だから債権者（銀行や取引先）にとっては、会社の中に残っている財産だけが頼りだ。もし利益をすべて配当で吐き出せたら、債権者は丸裸になってしまう。利益準備金は、**有限責任の株主と、債権者の利害を調整するための仕組み**なのである。
3級では、積み立てる金額は問題文で与えられる。積立額の計算は2級で学ぶ。
::

::table 3級で登場する純資産の勘定
| 勘定科目 | 内容 |
| 資本金 | 株主が払い込んだ金額 |
| 利益準備金 | 配当にあわせて積み立てた準備金（会社の利益が原資） |
| 繰越利益剰余金 | 会社が稼いだ利益の蓄積のうち、配当などに使っていない部分 |
::

::cfo 7,000万円の利益をどう使うか ― 配当か、出店か、返済か
おかわり堂は今期、7,000万円の当期純利益を出す見込みだ。経営会議では意見が割れた。社長の大森は「株主に報いたい。配当を倍にしよう」。営業担当の役員は「京都市外に3店を出すべきだ」。財務担当の佐伯は「借入金を前倒しで返したい」。佐伯は判断の材料を次のようにまとめた。
- 今の配当は年1,500万円（当期純利益の約2割）。株主は、投資した金額に対して年8%程度のリターンを期待している
- 新店1店の投資額は3,500万円（内装・設備3,000万円、保証金500万円）
- 市外の候補地は3か所。大学のそばのA地区は、既存店並みの年600万円の利益が見込める。B・C地区は初めての商圏で、年0円〜900万円と見込みの幅が大きい
- 借入金は2億円で、金利は年1.5%
- 手元の預金は3億円。序章の教訓から、少なくとも月商2か月分（約2億円）は手元に残すと決めている
::choice A. 配当を倍の3,000万円にする
**△ 株主は喜ぶが、伸びる機会を手放すかもしれない。**利益の約4割を配ることになる。お金を株主に返すのは、会社の中にそれ以上のリターンを生む使い道がないときの選択だ。しかも配当は、一度増やすと減らしにくい。来期に牛肉がさらに高騰して利益が落ちても、株主は同じ配当を期待する。
::
::choice B. 3店をまとめて出す（1億500万円）
**○ 攻めすぎ。**A地区の店は、3,500万円で年600万円の利益（投資額の約17%）を生み、株主が期待する8%を大きく上回る。だが、B・C地区は見込みの幅が大きく、悪ければ利益ゼロだ。しかも1億500万円を使えば、預金は1億9,500万円と、自分で決めた最低限の2億円を割る。まんぷく食堂が3号店と4号店を同時に出したときと、同じ形になる。
::
::choice C. 借入金2億円のうち1億円を前倒しで返す
**△ 安全だが、リターンは低い。**浮く利息は年150万円（1億円×1.5%）。1億円に対して年1.5%にしかならず、株主の期待する8%にはまったく届かない。金利の低い借金を急いで返すより、もっと稼げる使い道があるなら、そちらが優先だ。
::
::choice D. 見込みの固いA地区に1店だけ出し、配当は今のまま、残りは手元に置く
**◎ 数字で優先順位をつけた答え。**年17%のリターンが見込めるA地区だけに投資し、株主の期待を上回る価値を生む。配当は方針どおりに保ち、預金は2億6,500万円と、安全の目安を十分に上回る。A地区の結果を見てから、B・C地区に進むかを決めればよい。
::
::answer 考え方の例を見る
これは**資本配分**と呼ばれる、経営の最も重要な判断の1つだ。判断の軸は「その1円を、どこに使えば最も価値を生むか」である。
::table 1円あたりのリターンで並べる
| 使い道 | 投資額 | 年間の効果 | 1年あたりのリターン |
| A地区への出店 | 3,500万円 | 利益600万円 | 約17% |
| B・C地区への出店 | 7,000万円 | 利益0円〜1,800万円 | 0%〜約26%（不確か） |
| 借入金の繰上げ返済 | 1億円 | 利息150万円 | 1.5% |
| 配当の増額 | 1,500万円 | 株主の手元に戻る | 株主が自分で8%の運用先を探す |
::
株主が期待するリターン（8%）を上回る使い道があれば、そこに使う。なければ株主に返す。そして、どの選択でも、手元の安全資金は割り込まない。この3つのルールで並べると、答えはDになる。
大森は経営会議で「配当を倍に」の提案を取り下げた。代わりに、利益に対する配当の割合（**配当性向**）を毎期2割程度に保つ方針を決め、株主に説明した。配当の方針を一貫させることも、株主の信頼を得る大切な方法だ。
::
::

::exam 純資産の急所
- 株式を発行したら、3級では払込金額の**全額を資本金**とする（設立時も増資時も同じ）。株数×1株あたりの払込金額を正確に計算する。
- 当期純利益は「損益／繰越利益剰余金」、当期純損失は「繰越利益剰余金／損益」で振り替える。
- 配当の決議時：「繰越利益剰余金／未払配当金・利益準備金」。支払時：「未払配当金／普通預金など」。決議時と支払時を混同しない。
- 利益準備金の積立額は、3級では問題文で与えられる。
- 繰越利益剰余金が借方残高（マイナス）のとき、貸借対照表では純資産の部にマイナスで表示される。
::

::next 純資産の部は、もっと奥が深い
2級では、増資の際に資本金と**資本準備金**に分ける処理や、配当の際の利益準備金の積立額の計算（配当額の10分の1、ただし上限あり）、そして純資産の1年間の変動をまとめた**株主資本等変動計算書**を学ぶ。1級では、自己株式、新株予約権、ストック・オプションなど、株式をめぐる高度な論点に進む。
また、本章の問いで使った**ユニットエコノミクス**（LTV、CAC）や**ARR**は、SaaS企業の経営や投資の現場で日常的に使われる指標だ。企業価値の評価（バリュエーション）では、将来のキャッシュ・フローを現在の価値に割り引く**DCF法**などが使われる。会計の数字を出発点に、未来の価値を見積もる。それが、投資や企業価値評価の仕事の中心にある技術なのである。
::

::answer
::journal 純損失は繰越利益剰余金を減らす（借方）

::problem 1店舗あたりの顧客獲得コストが30万円、月額利用料が1万円（粗利率80%）、平均利用期間が30か月のサービスがある。LTV（顧客生涯の粗利）とLTV÷CACを求め、このサービスの成長について考えを述べなさい。
LTV：[[24]] 万円　LTV÷CAC：[[0.8]] 倍
::answer
LTV＝1万円×80%×30か月＝**24万円**。LTV÷CAC＝24万円÷30万円＝**0.8倍**。
1店舗を獲得するたびに、獲得費用を回収できずに損をする構造になっている。この状態で広告費を増やして成長を速めると、赤字は「投資」ではなく「出血」になる。解約率を下げて平均利用期間を延ばすか、獲得コストを下げるか、利用料を見直すなど、成長の前にユニットエコノミクスの改善が必要だ。

::summary
- 株式会社は、株主（出資者・有限責任）と取締役（経営者）を分けて、大きな資金を集める仕組み
- 株式を発行したら、3級では払込金額の全額を資本金（純資産）とする
- 当期純利益は繰越利益剰余金を増やし、当期純損失は減らす。繰越利益剰余金は利益の蓄積
- 配当の決議時は「繰越利益剰余金／未払配当金・利益準備金」、支払時は「未払配当金／預金」
- 利益準備金は、配当で会社の財産を空っぽにしないための安全装置
- 会計上の赤字でも、その中身が将来の売上を生む投資なら、投資家は資金を出す。赤字の「質」を見抜くことが大切
::
