<h2 class="mt-3 font-serif text-[1.65rem] font-black leading-snug text-[#1B2430] text-balance [word-break:auto-phrase] sm:text-[2.1rem] lg:text-[2.4rem]">このテキストの特徴</h2>

</div></div>
<div class="mt-8 min-w-0 lg:col-span-8 lg:mt-1">

日商簿記3級の出題範囲を、すべてカバーしている。そのうえで目指しているのは、試験の合格だけではない。**数字の裏にある「会社の生と死」を読めるようになること**だ。
1人の新人の1年間を追う物語になっている。父の定食屋が黒字のまま倒産したことをきっかけに、京都の鴨川会計事務所に入った大川ひより。簿記の知識ゼロから出発した彼女は、夜行バス、学生街の牛丼チェーン、24時間ジム、食肉卸、赤字のSaaS企業という5つの顧問先で起きる事件を、帳簿の中から解いていく。あなたも、ひよりと一緒に仕訳を切りながら、簿記のルールがなぜそうなっているのかを1章ずつ確かめてほしい。読み終えたとき、あなたは3級の仕訳と決算を自分の手で組み立てられるだけでなく、ニュースで見る「黒字倒産」や「粉飾決算」の意味を、勘定科目の言葉で説明できるようになっている。
経理・会計の仕事への転職を考えている人には、とくに終章と各章の「判断してみよう」を読んでほしい。3級の知識が、職場でどんな判断に使われるのかが見えてくる。

<p class="flex items-center gap-3 text-[11px] font-bold tracking-[0.35em]" style="color:#3E7C7A"><span aria-hidden="true" class="h-2 w-2 flex-none" style="background:#3E7C7A"></span><span>HOW IT COVERS</span></p>
<h2 class="mt-3 font-serif text-[1.65rem] font-black leading-snug text-[#1B2430] text-balance [word-break:auto-phrase] sm:text-[2.1rem] lg:text-[2.4rem]">3級の範囲を、どう解説するか</h2>
<p class="mt-4 max-w-sm text-sm leading-relaxed text-[#6A707A]">本試験の3つの大問と、本書の章の対応。読み進めるだけで、必要な力がそろう。</p>
</div></div>
<div class="mt-8 min-w-0 lg:col-span-8 lg:mt-1">

本試験は、第1問（仕訳）・第2問（帳簿など）・第3問（決算）の3つの大問でできている。本書は、物語の順に読み進めるだけで、3つの大問に必要な力がそろうように章を並べている。

::table 試験の大問と、本書の章の対応
| 大問（配点） | 問われること | 本書で学ぶ場所 |
| 第1問（45点） | 仕訳15問 | 第1〜2章で仕訳のルールを学び、第3〜16章で取引の種類ごとに仕訳を身につける。仕上げは付録C「仕訳道場」64問 |
| 第2問（20点） | 勘定記入・補助簿・伝票・語句など | 商品有高帳（第6章）、売掛金元帳（第7章）、手形記入帳（第8章）、固定資産台帳（第12章）、勘定記入と再振替（第15章）、補助簿・伝票（第16章）、試算表（第17章） |
| 第3問（35点） | 精算表・財務諸表・決算整理後残高試算表 | 第18章（決算整理と精算表）、第19章（帳簿の締切と財務諸表）。仕上げは付録D「模擬試験」 |
::

1つの章は、次の流れでできている。

::steps 1つの章の流れ
問い | 身近な会社で起こる、直感に反する出来事から始まる。「黒字なのに、なぜ倒産したのか？」
解説 | その答えに必要な簿記のルールを、仕訳とT字勘定で1つずつ学ぶ
答え合わせ | 学んだルールで、冒頭の問いを解く
実際にあった話 | 現実の事件を、その章の仕訳で再現する
判断してみよう | 経営者や銀行員の立場で判断する、実務の発展問題に挑む
試験の急所と確認問題 | 出題のポイントを押さえ、入力式の問題で手を動かして確かめる
::

<h2 class="mt-3 font-serif text-[1.65rem] font-black leading-snug text-[#1B2430] text-balance [word-break:auto-phrase] sm:text-[2.1rem] lg:text-[2.4rem]">おすすめの学習の進め方</h2>
<p class="mt-4 max-w-sm text-sm leading-relaxed text-[#6A707A]">物語として読み、手で書き、反復し、本番形式で仕上げる。</p>

<div class="mt-8 min-w-0 lg:col-span-8 lg:mt-1">

::steps 合格までの4ステップ
1周目：物語として通読する | 確認問題は飛ばしてよい。まずは「なぜそうなるのか」をつかむ。序章から終章まで、一気に読み切ることを優先しよう

仕訳道場で反復する | 付録Cの仕訳問題を、1問30秒以内で解けるまで繰り返す。第1問（45点）はここで決まる
決算問題と模擬試験で仕上げる | 第18・19章の総合例題と付録Bの攻略法を確認したら、付録Dの模擬試験を「模擬試験モード」で60分で解き、間違えた章を復習する。そのうえで、ネット試験の模擬問題や過去問で時間配分を体に覚え込ませる

<p class="mt-4 max-w-sm text-sm leading-relaxed text-[#6A707A]">各章は、色分けしたボックスを組み合わせて作られている。色と役割を覚えておくと、復習のときに目的の情報へすぐたどり着ける。押すと、見本つきの説明が開く。</p>

::mystery 各章は「問い」から始まる
身近な会社で起こる、直感に反する出来事。その理由を考えることが、各章の入り口になる。答えは、章の後半の「答え合わせ」で明かされる。
::

::theory 重要理論は青いボックスに
簿記のルールの「なぜ」を説明する、最も大切な理論。2級・1級でもそのまま使う知識なので、ここだけは必ず理解してから先へ進もう。
::

::danger 「経営の落とし穴」は赤いボックスに
会計処理を誤ったり、数字の裏の事実を見落としたりしたとき、会社がどんな危機に陥るかを描く。ルールが生まれた理由は、たいていここにある。
::

::real 「実際にあった話」は、上に黒い線の入った白いボックスに
物語の会社は架空だが、そこで起きる出来事には、現実の手本がある。黒字のまま倒産した上場企業、客の前払い金を使い込んで破綻した旅行会社、在庫の水増しが発覚したメーカー。各章のテーマにつながる実際の事件を、報道・統計資料へのリンクつきで紹介し、「この章の道具で読む」で、その事件の取引をその章の仕訳とT字勘定で再現する。
::

::cfo 「判断してみよう」は黄色のボックスに
数字のついた資料を読んで、経営者や経理担当者、銀行員の立場で判断する**実務の発展問題**。3級の試験範囲を超えて、資金繰り表、ストレステスト、財務制限条項、与信管理、内部統制の設計など、現場で実際に求められる判断に踏み込む。選択肢には、どれも「もっともらしい理由」がついている。細かい計算は要らない。問題文の「考えるときの視点」に沿って、各案で何が良くなり、何がリスクとして残るかを考えてから選ぶ。1つ選ぶと、仮の数字を置いた試算で、その判断がどんな結果を招くかが分かり、「考え方の例」では判断の原則と、条件が変わったら答えがどう変わるか（さらに考えよう）まで解説する。
試験対策だけが目的なら後回しにしてもよいが、ここで迷った経験は、2級・1級や実務で必ず生きる。1問10分ほど、自分の考えを言葉にしてから解説を開いてほしい。
::choice A. 選ぶ前に、自分の判断の理由を一言メモしておく
**◎ それがいちばん効く。**解説を読んだとき、自分の考えのどこが違っていたのかが、はっきり分かる。理由を言葉にできたなら、もう本書の狙いどおりだ。
::
::choice B. 考えずに、とりあえず選んで解説を読む
**△ もったいない。**解説は読める。だが、迷わずに選んだ答えからは、ほとんど何も残らない。どの問題にも、よく考えないと見えない「落とし穴」が仕込んである。視点に沿って考えてから選んでみよう。
::
::answer
こんなふうに、どれかを選ぶと、その結果と考え方の例が開く。まず自分の頭で考えることが、最も効果的な学習法だ。
::
::

::exam 試験の急所は緑のボックスに
出題パターン、ひっかけ、時間短縮のテクニック。試験直前は、緑のボックスだけを拾い読みするのも効果的だ。
::

::next 2級・1級・実務へのつながりは紫のボックスに
3級の知識が、上の級や実際のビジネスでどう発展するかを予告する。今は読み飛ばしてもかまわない。
::

::point 例題と確認問題は「TRY」で手を動かして解ける
- **仕訳**：勘定科目をドラッグで記入欄へ入れ（またはタップしてから記入欄をタップ）、金額を入力して「答え合わせ」する。
- **空欄**：計算問題や、帳簿・精算表・財務諸表の空欄に数字を入力する。勘定科目や語句の空欄は、タップして選択肢から選ぶ。
- **分類・チェック表**：項目をドラッグで分類先へ移したり、当てはまるマスにチェックをつけたりする。
ネット試験と同じように、自分の手で答えを作ってから解説を開こう。
::

本文には、ほかにも次のような仕掛けがある。

- **勘定科目をタップ**：本文で点線の下線がついた勘定科目をタップすると、読み方・5つの要素のどれか・意味を確認できる。
- **シミュレーター**：第6章（先入先出法と移動平均法）、第7章（CCCと運転資金）、第12章（定額法と定率法）では、数字を動かして結果がどう変わるかを確かめられる。
- **模擬試験モード**：付録Dでは、60分のタイマーで本試験形式の問題を解き、大問ごとの得点と、復習すべき章をその場で確認できる。

仕訳とT字勘定は、次のような表で示す。左の青い列が**借方**、右の赤い列が**貸方**だ。
