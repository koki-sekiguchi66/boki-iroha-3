## この本が約束すること

この本は、試験に受かるためだけの教科書ではない。もちろん、日商簿記3級の出題範囲はすべてカバーしている。だが、それ以上に目指しているのは、あなたが**数字の裏にある「会社の生と死」を読めるようになること**だ。
深夜の高速バス、京都の学生街の牛丼チェーン、24時間ジム、食肉卸、そして赤字のSaaS企業。本書の舞台は、あなたが明日にでも目にする身近なビジネスばかりだ。その裏側で、簿記のルールがどのように会社を守り、あるいは見落とされたときにどう会社を殺すのかを、1章ずつ解き明かしていく。

## 本書の読み方 ― 6種類の「ボックス」

各章は、次のボックスを組み合わせて構成されている。色と役割を覚えておくと、復習のときに目的の情報へ一瞬でたどり着ける。

::mystery 各章は「謎」から始まる
直感に反するビジネスの謎。答えを知りたくてたまらなくなったら、それが学習のエンジンだ。謎の答えは、章の後半の「謎解き」で明かされる。
::

::theory 重要理論は青いボックスに
簿記のルールの「なぜ」を説明する、最も大切な理論。2級・1級でもそのまま使う知識なので、ここだけは必ず理解してから先へ進もう。
::

::danger 「死の谷」は赤いボックスに
会計処理を誤ったり、数字の裏の事実を見落としたりしたとき、会社がどんな危機に陥るかを描く。ルールが生まれた理由は、たいていここにある。
::

::cfo 「あなたがCFOなら？」は黄色のボックスに
経営判断を迫る問い。自分なりの答えを考えてから、下のボタンを開いてCFOの思考プロセスと照らし合わせてほしい。
::answer
こんなふうに、解答や解説は折りたたまれている。まず自分の頭で考えるのが、最強の学習法だ。
::
::

::exam 試験の急所は緑のボックスに
出題パターン、ひっかけ、時間短縮のテクニック。試験直前は、緑のボックスだけを拾い読みするのも効果的だ。
::

::next 2級・1級・実務への伏線は紫のボックスに
3級の知識が、上の級や実際のビジネスでどう発展するかを予告する。今は読み飛ばしてもかまわない。
::

仕訳とT字勘定は、次のような表で示す。左の青い列が**借方**、右の赤い列が**貸方**だ。

::journal 例：牛肉30万円分を、代金は後払い（掛け）で仕入れた
仕入 300,000 | 買掛金 300,000
::

::taccount 現金

売上 380,000 | 次期繰越 760,000

## おすすめの学習の進め方

::steps 合格までの4ステップ
1周目：物語として通読する | 確認問題は飛ばしてよい。まずは「なぜそうなるのか」をつかむ。序章から終章まで、一気に読み切ることを優先しよう
2周目：仕訳を手で書く | 各章の例題と確認問題を、紙に仕訳を書きながら解く。解答を見る前に必ず自分で書くこと
仕訳道場で反復する | 付録Cの仕訳問題を、1問30秒以内で解けるまで繰り返す。第1問（45点）はここで決まる

::
