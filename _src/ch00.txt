::mystery 行列の絶えない定食屋は、なぜ「黒字」のまま死んだのか
京都・百万遍。深夜まで学生の声が響くこの街に、行列の絶えない定食屋があった。
店の名は「まんぷく食堂」。から揚げ定食650円、ご飯おかわり無料。試験前の京大生が深夜1時に駆け込み、運動部員が大盛りをかき込む。開店から3年で4店舗。決算書の最終行には、毎年きっちり**黒字**の二文字が並んでいた。
そして4年目の秋。まんぷく食堂は、倒産した。
不正はなかった。食中毒もなかった。ライバルの値下げ攻勢も、客離れもなかった。利益は、最後まで出ていた。
**では、なぜ死んだのか？**
この謎が解けたとき、あなたはもう「数字が苦手な人」ではない。資本主義というゲームの、裏側のルールが見える人になっている。
::

## 「利益」と「お金」は、まったくの別物である

最初に、あなたの頭の中にある常識をひとつ壊しておきたい。
多くの人は「儲かっている会社には、お金がある」と思っている。「利益が出た」とは「お金が増えた」ことだと。
**これは間違いだ。**
利益とは、会計のルールに従って計算された「成績」にすぎない。一方、お金（キャッシュ）とは、いま金庫と銀行口座に実際にある「残高」だ。この2つは、驚くほど一致しない。
そして会社が死ぬのは、成績が悪いときではない。**支払うべき日に、支払うお金がないとき**だ。従業員の給料、店の家賃、銀行への返済、食材の仕入代金。どれか1つでも払えなければ、その瞬間にゲームオーバーになる。利益がいくら出ていようと、関係ない。
これを「黒字倒産」と呼ぶ。

::theory 利益は「意見」、現金は「事実」
会計の世界には、こんな格言がある。
==「利益は意見であり、現金は事実である」==
利益は、「この支出を今年の費用にするか、来年以降に回すか」といった会計上の判断によって変わる。だから「意見」だ。一方、口座の残高は誰がどう計算しても同じ。だから「事実」だ。
簿記とは、この「意見」と「事実」の両方を、1つのルールで同時に記録する技術である。
::

## まんぷく食堂の3年間を、数字で追いかける

では、まんぷく食堂に何が起きたのか。当時の数字を再現してみよう。
1号店の月商は約600万円。原価と経費を差し引いても、毎月60万円ほどの利益が残る優良店だった。自信をつけたオーナーは、出店を加速させる。

::timeline まんぷく食堂、拡大の軌跡
1年目 | 百万遍に1号店オープン | 自己資金と借入金で開業。初年度から黒字
2年目 | 出町柳に2号店 | 内装・厨房設備2,500万円、保証金500万円。銀行から2,000万円を借入
3年目 | 今出川に3号店オープン、北白川で4号店に着工 | 2店舗分の設備5,000万円と保証金1,000万円を支払う。追加で4,000万円を借入
!4年目・春 | 4号店の工事が2か月遅延 | 売上ゼロのまま、家賃と研修中スタッフの給料が出ていく
!4年目・秋 | 月末の支払いに300万円足りず、事業停止 | 決算書の上では、最後まで黒字だった
::

3年目の決算書（損益計算書）を見てみよう。

::table 3年目の損益計算書（要約）
| 項目 | 金額 |
| 売上高 | 2億円 |
| 食材費・人件費・家賃などの費用 | 1億8,800万円 |
|= 当期純利益 | 1,200万円 |
::

文句なしの黒字だ。銀行の担当者も「順調ですね」と笑っていた。
ところが同じ年、**銀行口座の残高**はこう動いていた。

::table 3年目の「お金」の動き
| 項目 | 金額 |
| 期首の現金残高 | 900万円 |
| ＋ 本業で稼いだ利益 | 1,200万円 |
| ＋ 減価償却費（費用だが、お金は出ていかない） | 1,000万円 |
| － 新店2店舗の内装・厨房設備 | △5,000万円 |
| － 新店2店舗の保証金（敷金） | △1,000万円 |
| － 借入金の元本返済 | △800万円 |
| － 食材在庫の増加 | △200万円 |
| － 前年度分の法人税などの納付 | △300万円 |
| ＋ 銀行からの新規借入 | 4,000万円 |
|= 期末の現金残高 | △200万円 |
::

計算上、期末の残高は**マイナス200万円**。もちろん、口座がマイナスになることはない。実際には、その手前のある月末に「払えない日」が来た。それが4年目の秋だった。
利益は1,200万円出ているのに、お金は1,100万円も減っている。この「ズレ」の正体が、今回の謎の答えだ。

::danger 利益に表れない、5つの「お金の出口」
- **設備投資**：5,000万円の内装・厨房設備は、買った年に全額が費用になるわけではない。数年かけて少しずつ費用にする（減価償却 → 第12章）。だから利益はほとんど減らないのに、お金は一気に出ていく。
- **保証金（敷金）**：店舗を借りるときに大家に預けるお金は、そもそも費用ではない（差入保証金 → 第9章）。利益は1円も減らないが、お金は確実に消える。
- **借入金の元本返済**：借りたお金を返すことは「費用」ではない（借入金 → 第9章）。利益計算には一切表れないが、毎月お金は出ていく。
- **在庫**：冷凍庫に積まれた牛肉は、売れるまで「お金が肉の形で眠っている」状態（商品 → 第5章）。
- **税金**：利益が出れば、翌年に法人税の請求が来る（第14章）。成長期ほど、これが重くのしかかる。
::

まんぷく食堂のオーナーは、損益計算書しか見ていなかった。「利益が出ているから大丈夫」と信じて、次々に店を出した。
もし彼が、もう1枚の決算書——**貸借対照表**——を読めていたら。現金がみるみる減り、代わりに「建物」「備品」「差入保証金」という、すぐにはお金に戻らない資産と、「借入金」という返済義務が膨れ上がっていく様子が、はっきり見えたはずだ。

::solve 「黒字倒産」の正体
まんぷく食堂を殺したのは、赤字ではない。**利益とキャッシュの「時間差」**だ。
出店のための支出は「今」出ていく。しかし、それが費用として利益計算に反映されるのは「何年もかけて少しずつ」であり、保証金や借入返済に至っては、利益計算に一度も表れない。
損益計算書は「この1年の成績」を映す。貸借対照表は「いま会社が何を持ち、誰にいくら借りているか」を映す。この2枚をセットで読めなかったことが、まんぷく食堂の命取りになった。
そして、この2枚の決算書を作り、読むための技術こそが——**簿記**である。
::

## 簿記とは「会社のカルテ」を書き、読む技術である

簿記（ぼき）とは「帳簿記入」の略だ。会社で起きたお金とモノの動きを、一定のルールで記録し、最終的に**財務諸表**（決算書）という報告書にまとめる技術である。
こう書くと地味に聞こえるだろう。だが、私はCFO（最高財務責任者）として何十社もの財務諸表を見てきたが、断言できる。
**簿記とは、資本主義というゲームの「スコアボード」を読み書きする技術だ。**
株価は財務諸表をもとに動く。銀行は財務諸表を見て融資を決める。税務署は財務諸表をもとに税金を計算する。経営者は財務諸表を見て、出店するか撤退するかを決める。このゲームのプレイヤー全員が、同じスコアボードを見て動いている。
そのスコアボードを読めない人は、ルールを知らずにゲームに参加しているのと同じだ。逆に、読める人にとっては、他人が見えないものが見える。まさに**チートコード**である。

::table 財務諸表を「読む人」と、その目的
| 誰が | 何を知りたいか |
| 経営者 | どの店が儲かっているか。次の出店資金はあるか |
| 銀行 | この会社に貸したお金は、ちゃんと返ってくるか |
| 投資家（株主） | この会社の株は、将来もっと価値が上がるか |
| 取引先 | 掛けで売っても、代金を払ってもらえるか |
| 税務署 | 正しく利益を計算し、正しく税金を納めているか |
| 就職・転職する人 | この会社は5年後も存在しているか |
::

## 簿記3級で手に入る、6つの武器

日商簿記3級は、この「スコアボードの読み書き」の基礎を、**株式会社**を舞台に学ぶ資格だ。本書を読み終えたとき、あなたは次の武器を手にしている。

::kpi
武器1 | 仕訳 | 世界共通のビジネス言語（第1〜2章）
武器2 | キャッシュ管理 | 現金・預金を守る技術（第3〜4章）
武器3 | 利益の源泉 | 商品売買と売上原価（第5〜6章）
武器4 | 信用の管理 | 債権・債務・貸倒れ（第7〜11章）
武器5 | 投資と所有 | 固定資産・株式・税金（第12〜15章）
武器6 | 決算 | 財務諸表を完成させる（第16〜19章）
::

これらはすべて、2級（工業簿記・連結会計）、1級（会計基準の理論）、そして実際の経営判断やM&A、資金調達の現場へとまっすぐにつながっている。3級は「入門」ではあるが、決して「おまけ」ではない。**ここで手に入れるOSの上に、すべての上級スキルがインストールされる**のだ。

## 簿記の全体像 ― 1年間の「ゲームの流れ」

簿記の仕事は、1年間（会計期間）を単位としたサイクルで回っている。まずは全体の地図を頭に入れておこう。細部は各章で1つずつ攻略していく。

::steps 簿記の1年間（会計期間）の流れ
取引が発生する | 商品を仕入れる、売る、給料を払う、バスを買う……会社の日常のすべてが出発点（第2章）
仕訳（しわけ）をする | 取引を「借方」と「貸方」に分解して記録する。簿記のすべての土台（第2章〜第15章）
総勘定元帳に転記する | 仕訳を「勘定」ごとに整理し直す（第2章・第16章）
試算表で検算する | 記録に誤りがないかを、貸借の一致で確かめる（第17章）
決算整理をする | 期末に「本当の利益」を計算するための修正を加える（第18章）
財務諸表を作る | 損益計算書と貸借対照表を完成させ、帳簿を締め切る（第19章）
::

::point 3級の舞台は「株式会社」
日商簿記3級は、2019年度の改定以降、個人商店ではなく**小規模な株式会社**を前提にしている。だから本書のケースも、すべて株式会社だ。法人税の計算や、株主への配当といった「会社ならでは」の論点も、3級の範囲に含まれている。
::

## 試験の概要 ― 敵を知る

詳しい攻略法は「付録B 試験攻略マニュアル」で解説するが、ここで試験の輪郭をつかんでおこう。

::table 日商簿記3級の試験概要
| 項目 | 内容 |
| 試験方式 | 統一試験（ペーパー：例年6月・11月・2月）／ネット試験（CBT：随時） |
| 試験時間 | 60分 |
| 配点・合格基準 | 100点満点中、70点以上で合格 |
| 第1問（45点） | 仕訳問題 15問 |
| 第2問（20点） | 勘定記入、補助簿、伝票、語句選択など |
| 第3問（35点） | 決算：財務諸表・精算表・決算整理後残高試算表の作成 |
::

::exam 合否を決めるのは「仕訳」と「決算」
配点を見れば一目瞭然だ。第1問の仕訳（45点）と第3問の決算（35点）だけで80点。この2つを確実に取れれば、合格ラインの70点を超えられる。
そして第3問の決算問題も、中身は「決算整理仕訳」の積み重ねだ。つまり、**仕訳を制する者が3級を制する**。本書が全章を通じて、ひたすら仕訳をテーブルで示し続けるのはそのためだ。
::

::note
※2027年4月1日以降の試験では、紙の手形・小切手の廃止などにあわせて出題区分が改定される予定です（2025年12月公表の暫定版）。本書は、2026年度（2027年3月まで）の試験に適用される現行の出題区分を完全にカバーしたうえで、2027年度からの変更点（{{new:2027年度〜}}・{{old:2027年度〜範囲外}}）も併記しています。
::

最後に、ひとつだけ約束してほしい。
本書を「暗記の教科書」としてではなく、「ビジネスの推理小説」として読んでほしい。各章の冒頭には、必ず1つの謎がある。その謎を解く鍵は、必ずその章の簿記のルールの中にある。
ルールを覚えるのではない。**ルールが生まれた理由**を理解するのだ。そうすれば、試験の仕訳は「暗記」ではなく「当たり前」に変わる。

::summary 序章のまとめ
- 利益（成績）と現金（残高）は別物。会社は「赤字」ではなく「支払えないこと」で死ぬ
- 設備投資・保証金・借入金の返済・在庫・税金は、利益と現金のズレを生む5大要因
- 損益計算書は「1年間の成績」、貸借対照表は「いまの財産と借金」を映す。2枚セットで読む
- 簿記とは、この財務諸表を作り、読むための技術。資本主義のスコアボードを読むチートコードである
- 3級の試験は「仕訳（45点）」と「決算（35点）」が勝負どころ
::
