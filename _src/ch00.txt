::mystery 行列の絶えない定食屋は、なぜ「黒字」のまま死んだのか
11月の最初の月曜日、朝7時。大学4年の大川ひよりは、京都・百万遍の交差点で自転車を止めた。
父の店「まんぷく食堂」1号店のシャッターに、A4の紙が1枚貼られている。
「誠に勝手ながら、10月31日をもちまして全店の営業を停止いたしました」
閉店する前の週も、店は毎晩満席だった。から揚げ定食650円、ご飯おかわり無料。試験前の学生が深夜1時に駆け込み、運動部員が大盛りをかき込む。大手チェーンの店長だった父・大川健司が独立して3年、店は4つに増えた。決算書には、毎年きっちり**黒字**の二文字が並んでいた。
その夜、実家の台所で、父は同じ言葉を何度も繰り返した。「ずっと黒字やったんや。利益は、ちゃんと出とったんや」
不正はなかった。食中毒もなかった。客も減っていなかった。最後の決算でも、利益は出ていた。
それなのに、店は消えた。
**利益が出ていた会社が、なぜ死んだのか？**
ひよりには、父の言葉の意味も、店が消えた理由も分からなかった。この問いの答えが分かったとき、あなたにも、決算書の数字の裏側にあるお金の動きが見えるようになっている。
::

## 10日前 ― 信用金庫の応接室で

時計を少し戻そう。店が止まる4日前、ひよりは父に付き添って、取引先の信用金庫を訪ねていた。ここ数週間、父の顔色が悪いのが気になっていたからだ。

::scene 10月27日、午前9時40分 ― 信用金庫の応接室
父：「300万円、月末までに何とかなりませんか」
父は、膝の上で手を組んだまま頭を下げた。4号店の工事は、職人が集まらず2か月遅れている。そのあいだも、店舗の家賃と、開店に備えて雇ったスタッフの研修中の給料は出ていく。工事業者への残金550万円の支払日は、10月31日だ。
担当者は、去年の決算書をめくった。「黒字ですね。利益は1,200万円」
父：「ええ、ずっと黒字です」
担当者：「では、今月の試算表と、来月までの資金繰り表を見せていただけますか」
父は言葉に詰まった。帳簿は、年に一度の決算のときに税理士がまとめてくれる。月ごとの数字を、自分の目で確かめたことは一度もなかった。
担当者は、静かに決算書を閉じた。「借入金は、すでに6,000万円を超えています。4号店がいつ開店して、いつから返済に回せるお金が生まれるのか。それを数字で示していただけないと、追加のご融資は難しいです」
帰り道、ひよりは聞いた。「シサンヒョウって、なに？」
父は答えなかった。たぶん、父にも分からなかったのだ。
::

## 1月 ― 鴨川会計事務所

年が明けた1月。ひよりは、丸太町通りに面した古い3階建てのビルの階段を上っていた。2階の扉に、「鴨川会計事務所」の真鍮の表札がかかっている。
卒業までの3か月をアルバイトとして働き、4月からは正式に職員になる。文学部の学生が会計事務所に入ると聞いて、友人たちは首をかしげた。だが、ひよりには理由があった。

::scene 面接 ― 所長室
鴨川：「なんで、うちなんや？」
所長の鴨川は、67歳の税理士だ。白髪まじりの眉の下から、ひよりの履歴書を見ていた。
ひより：「父の店が、黒字のまま潰れました。どうしてそうなったのか、自分で説明できるようになりたいんです」
鴨川はしばらく黙り、それから内線で誰かを呼んだ。入ってきたのは、紺のカーディガンを羽織った職員だった。
鴨川：「一ノ瀬くん。この子、あんたに預けるわ」
一ノ瀬律。公認会計士で税理士。監査法人で上場企業の監査を10年続けたあと、この事務所に来たという。
「うちのルールは1つだけや」と鴨川は言った。「1年目のうちに、日商簿記の3級に受かること。それと――」
所長は、窓の外の鴨川の方角を見た。「帳簿は会社の日記や。嘘を書いたら、いつか自分が読むことになる。覚えとき」
::

その日の午後、一ノ瀬は会議室のホワイトボードの前に立った。ひよりが持ってきた、まんぷく食堂の3年目の決算書のコピーが机に広げてある。
一ノ瀬：「最初の授業。お父さんの店の謎から始めましょう」

## 「利益」と「お金」は、まったくの別物である

一ノ瀬：「この決算書、利益はいくらですか」
ひよりは損益計算書の一番下の行を指さした。「1,200万円です」
一ノ瀬：「では、この1年で、お店の口座のお金はいくら増えましたか」
ひより：「……1,200万円、じゃないんですか」
一ノ瀬は首を横に振った。「多くの人がそう思います。『儲かっている会社には、お金がある』『利益が出た、とはお金が増えたことだ』と。**それは間違いです**」
利益とは、会計のルールに従って計算された「成績」にすぎない。一方、お金（キャッシュ）とは、いま金庫と銀行口座に実際にある「残高」だ。この2つは、驚くほど一致しない。
そして会社が死ぬのは、成績が悪いときではない。**支払うべき日に、支払うお金がないとき**だ。従業員の給料、店の家賃、銀行への返済、食材の仕入代金。どれか1つでも払えなければ、その瞬間に会社は立ち行かなくなる。利益がいくら出ていようと、関係ない。
これを「黒字倒産」と呼ぶ。

::theory 利益は「意見」、現金は「事実」
一ノ瀬は、ホワイトボードに1行だけ書いた。
==「利益は意見であり、現金は事実である」==
利益は、「この支出を今年の費用にするか、来年以降に回すか」といった会計上の判断によって変わる。だから「意見」だ。一方、口座の残高は誰がどう計算しても同じ。だから「事実」だ。
簿記とは、この「意見」と「事実」の両方を、1つのルールで同時に記録する技術である。
::

## まんぷく食堂の3年間を、数字で追いかける

一ノ瀬：「お父さんの店の歩みを、思い出せるだけ話してください」
ひよりは記憶をたどった。百万遍の1号店は、開店の日から行列ができた。月商は約600万円。原価と経費を差し引いても、毎月60万円ほどが残る優良店だった。父は自信を深め、出店を加速させた。2号店の内装工事のとき、父が「保証金だけで500万円や」とこぼしていたのを覚えている。

::timeline まんぷく食堂、拡大の軌跡
1年目 | 百万遍に1号店オープン | 自己資金と借入金で開業。初年度から黒字
2年目 | 出町柳に2号店 | 内装・厨房設備2,500万円、保証金500万円。銀行から2,000万円を借入
3年目 | 今出川に3号店オープン、北白川で4号店に着工 | 2店舗分の設備5,000万円と保証金1,000万円を支払う。追加で4,000万円を借入
!4年目・夏 | 4号店の工事が遅れ始める | 職人が集まらない。売上ゼロのまま、家賃と研修中スタッフの給料が出ていく
!4年目・秋 | 月末の支払いに300万円足りず、事業停止 | 決算書の上では、最後まで黒字だった
::

一ノ瀬は、3年目の損益計算書を要約して書き出した。

::table 3年目の損益計算書（要約）
| 項目 | 金額 |
| 売上高 | 2億円 |
| 食材費・人件費・家賃などの費用 | 1億8,800万円 |
|= 当期純利益 | 1,200万円 |
::

一ノ瀬：「文句なしの黒字です。銀行の担当者も、この年は『順調ですね』と言ったはずです」
それから一ノ瀬は、決算書の後ろのページ――貸借対照表と、勘定科目の内訳――を1枚ずつめくり、同じ年の**銀行口座の残高**の動きを組み立て直した。

::table 3年目の「お金」の動き
| 項目 | 金額 |
| 期首の現金残高 | 900万円 |
| ＋ 本業で稼いだ利益 | 1,200万円 |
| ＋ 減価償却費（費用だが、お金は出ていかない） | 1,000万円 |
| － 新店2店舗の内装・厨房設備 | △5,000万円 |
| － 新店2店舗の保証金（敷金） | △1,000万円 |
| － 借入金の元本返済 | △800万円 |
| － 食材在庫の増加 | △200万円 |
| － 前年度分の法人税などの納付 | △300万円 |
| ＋ 銀行からの新規借入 | 4,000万円 |
|= 期末の現金残高 | △200万円 |
::

一ノ瀬：「計算上、期末の残高は**マイナス200万円**です」
ひより：「口座がマイナスになんて、なるんですか」
一ノ瀬：「なりません。だから実際には、年度末の直前に、取引先への支払いを数週間待ってもらって、どうにか4年目に持ち越したはずです」
ひよりは息をのんだ。父が年末に、仕入先へ何度も電話をかけていた姿を思い出したからだ。
利益は1,200万円出ているのに、お金は1,100万円も減っている。この「ズレ」の正体が、今回の問いの答えだ。

## 最後の10月 ― 資金繰り表で、倒れる瞬間を再生する

一ノ瀬：「次は、最後の10月です。通帳のコピーはありますか」
ひよりは、父から預かった通帳の束を出した。一ノ瀬は、入金と出金を日付順に並べ、その月の残高の動きを1枚の表にした。月ごとのお金の出入りを予定として並べたこの表を、**資金繰り表**という。父が一度も作ったことのない表だ。

::table 4年目10月のお金の出入り（3店舗が営業中、4号店は工事中）
| 日付 | 内容 | 入金 | 出金 | 残高 |
| 10/1 | 月初の残高 |  |  | 380万円 |
| 10/1〜9 | 3店舗の売上の入金 | 520万円 |  | 900万円 |
| 10/10 | 前月分の源泉所得税・社会保険料の納付 |  | 190万円 | 710万円 |
| 10/10〜14 | 売上の入金 | 290万円 |  | 1,000万円 |
| 10/15 | 牛肉・米など9月分の仕入代金 |  | 650万円 | 350万円 |
| 10/15〜24 | 売上の入金 | 580万円 |  | 930万円 |
| 10/25 | 社員・アルバイト約80人の給料 |  | 560万円 | 370万円 |
| 10/27 | 借入金の返済（元本と利息） |  | 180万円 | 190万円 |
| 10/25〜30 | 売上の入金 | 350万円 |  | 540万円 |
| 10/31 | 4店舗分の家賃（1店は未開業） |  | 290万円 | 250万円 |
|= 10/31 | 4号店の内装工事の残金 |  | 550万円 | △300万円 |
::

10月の売上は1,740万円。3店舗とも、いつもどおり繁盛していた。それでも、月末の最後の支払いに**300万円**が足りなかった。
「10月27日。お父さんが信用金庫で頭を下げた日の残高は、190万円です」と一ノ瀬は言った。「この表が9月のうちにできていれば、300万円足りなくなることは、1か月前に分かっていました。1か月あれば、打てる手はいくつもあった」
仕入先への支払いを待ってもらう交渉は、すでに前の年に使ってしまっていた。10月31日の夜、父は全店の営業停止を決めた。

::danger 利益に表れない、5つの「お金の出口」
- **設備投資**：5,000万円の内装・厨房設備は、買った年に全額が費用になるわけではない。数年かけて少しずつ費用にする（減価償却 → 第12章）。だから利益はほとんど減らないのに、お金は一気に出ていく。
- **保証金（敷金）**：店舗を借りるときに大家に預けるお金は、そもそも費用ではない（差入保証金 → 第9章）。利益は1円も減らないが、お金は確実に消える。
- **借入金の元本返済**：借りたお金を返すことは「費用」ではない（借入金 → 第9章）。利益計算には一切表れないが、毎月お金は出ていく。
- **在庫**：冷凍庫に積まれた牛肉は、売れるまで「お金が肉の形で眠っている」状態（商品 → 第5章）。
- **税金**：利益が出れば、翌年に法人税の請求が来る（第14章）。成長期ほど、これが重くのしかかる。
::

父は、損益計算書しか見ていなかった。「利益が出ているから大丈夫」と信じて、次々に店を出した。
もし父が、もう1枚の決算書――**貸借対照表**――を読めていたら。現金がみるみる減り、代わりに「建物」「備品」「差入保証金」という、すぐにはお金に戻らない資産と、「借入金」という返済義務が膨れ上がっていく様子が、はっきり見えたはずだ。

::solve 「黒字倒産」の正体
まんぷく食堂を殺したのは、赤字ではない。**利益とキャッシュの「時間差」**だ。
出店のための支出は「今」出ていく。しかし、それが費用として利益計算に反映されるのは「何年もかけて少しずつ」であり、保証金や借入返済に至っては、利益計算に一度も表れない。そして工事の遅れのような予定外の出来事は、売上が入る前に支出だけを先に連れてくる。
損益計算書は「この1年の成績」を映す。貸借対照表は「いま会社が何を持ち、誰にいくら借りているか」を映す。資金繰り表は「来月、いくら払えるか」を映す。父には、そのどれもが手元になかった。
そして、これらの表のもとになる記録を正しくつけ、読むための技術こそが――**簿記**である。
::

ホワイトボードの前で、ひよりは長いあいだ黙っていた。父が嘘をついていたわけではなかった。利益は、本当に出ていたのだ。ただ、それだけを見ていた。

::real 黒字のまま倒れる会社は、珍しくない
父の店だけが特別だったわけではない。東京商工リサーチが、2017年に倒産した企業のうち3期分の決算が確認できた348社を分析したところ、倒産直前の決算が赤字だった会社は**53.7%**だった。裏を返せば、**残りのほぼ半数は、最後の決算で黒字を出しながら倒産していた**ことになる。
規模の大きな例もある。不動産会社のアーバンコーポレイションは、2008年3月期に**311億円**の当期純利益を計上した。ところがそのわずか5か月後の8月13日、東京地裁に民事再生法の適用を申し立てる。負債総額は**2,558億円**。上場企業の倒産としては、その年で最大だった。

**この章の道具で読む ― 不動産会社の「仕入」と「お金」**
不動産会社にとって、売るために買う土地やビルは、定食屋の食材と同じ「商品」だ。ここで、まんぷく食堂と同じ「利益の計算」と「お金の動き」の2つの表に、仕組みを当てはめてみよう。数字は、仕組みを示すために簡略化したものだ（単位：億円）。

::table 物件を1,500億円仕入れ、そのうち原価800億円分を1,100億円で売った年
| 項目 | 利益の計算 | お金の動き |
| 物件を売った | 売上 1,100 | 入金 1,100 |
| 売った物件の仕入値 | 原価 △800 | ― |
| 物件を仕入れた（まだ売れていない分を含む） | ― | 出金 △1,500 |
|= 合計 | 利益 300 | 現金 △400 |
::
利益の計算に入るのは、「売れた物件」の仕入値だけだ。売れ残った700億円分は「まだ売れていない商品」として資産に残り、費用にはならない。だが、お金は仕入れた全額が出ていく。だから、仕入を増やして事業を伸ばすほど、**利益は増えるのに、現金は減っていく**。不足分は借入金で埋めるしかない。
市況が良く、物件が次々に売れているあいだは、これでも回る。だが市況が冷え込み、物件が売れなくなり、銀行や市場からの資金調達も止まると、利益の数字は支払いの役に立たない。同社の営業活動によるキャッシュ・フロー（本業で現金が増えたか減ったか。終章で学ぶ）は、倒産前の数年間、大きなマイナスが続いていたと指摘されている。「売れたら利益、買ったら出金」。まんぷく食堂の新店と、同じ時間差である。

倒産そのものも、いまは増えている。2025年度の企業倒産は1万505件で、2年連続で1万件を超えた。物価高と人手不足が、中小企業の資金繰りを締めつけている。

::cfo 時計を1年戻せるなら ― 期末残高ではなく「期中の谷」を見よ
「最後に、宿題です」と一ノ瀬は言った。「時計を1年戻して、3年目の春に行けるとします。お父さんは、3号店と4号店の同時出店を決めかけている」
上の「3年目のお金の動き」の表では、期末の現金は△200万円だった。だが一ノ瀬は、表の数字そのものより、**お金が出ていく時期と入ってくる時期**を気にしていた。
- 3号店の設備と保証金は、年度の初めにまとめて出ていく。4号店の支払いは、保証金・着手金・残金と、年度の後半にかけて分かれて出ていく
- 4号店の融資は、銀行が**工事の完成を確認してから**実行する約束になっている
- 工事は遅れることがある。遅れれば、開店前の家賃や研修中の給料が余計にかかる
- 月の支払いが集中する週があるので、手元の現金はいつでもある程度残しておきたい
打てる手は4つある。
- **A　4号店の出店を1年延ばす**
- **B　期首に運転資金を別に借りておく**
- **C　Bに加えて、4号店の融資を「完成後に一括」から「着手金・残金の支払いに合わせた分割実行」に変えてもらう**
- **D　全店で定食を650円から700円に値上げする**
計算はしなくてよい。次の3つの視点で、それぞれの案を考えてから選んでほしい。
- 年度末ではなく、**年度の途中で、お金が最も少なくなるのはいつか**
- 工事が遅れたとき、**何が一緒に遅れて、何は遅れずに出ていくか**
- その手の効果は、**いつ、どれくらいの速さで**現れるか
::choice A. 4号店の出店を1年延ばす
**△ 年度末は安全になるが、年度の初めの谷は残る。**4号店の支出がなくなるので、年度の後半は楽になり、工事遅れの心配もなくなる。
だが、3号店の設備と保証金は年度の初めにまとめて出ていく。仮に四半期ごとに試算すると（下の「考え方の例」の設定）、第1四半期末の残高は**0円**で、目安の500万円を大きく割る。「年度末にプラスだから安全」とは言えない。しかも4号店が稼いだはずの利益も、1年あきらめることになる。
::
::choice B. 期首に運転資金を借りておく
**× 年度末は大きくプラスなのに、途中で一度、ほぼ底をつく。**仮に1,500万円借りると、年度末の残高は約1,270万円と十分に見える。だが、4号店の着手金が出ていく第3四半期末には200万円まで落ちる。
そして工事が遅れると、第4四半期に入るはずだった融資2,000万円が来ない。残金の支払いも延びるが、遅れによる追加の家賃・給料は出ていくので、第4四半期末は**約20万円**。足りないのは金額ではなく、**融資が入るタイミング**だ。
::
::choice C. 運転資金を借り、4号店の融資を分割実行にしてもらう
**◎ 期中の谷を埋め、遅延にも耐える。**融資が着手金と残金の支払日に合わせて入るので、大きな支出の直前に必ずお金が入る。仮の設定で試算すると、四半期末の残高は1,500・1,200・1,200・1,270万円。工事が遅れても、残金と2回目の融資が**一緒に**翌年度へずれるだけなので、残高は約1,020万円残る。
ポイントは「融資の実行日を、支出の日にそろえる」こと。完成後の一括実行は銀行には安全だが、借り手には、工事が遅れたときに最も苦しい時期にお金が入らない条件になる。この交渉は、出店の**前**にしかできない。
::
::choice D. 定食を700円に値上げする
**× 効果の出る速さが、谷に間に合わない。**値上げの効果は、毎日の売上を通じて少しずつしか入ってこない。数千万円の支出が一度に出ていく「谷」を埋めるのには向かない。仮の設定で試算すると、客数が変わらなくても第3四半期末に資金が尽きる。客数が減れば、何もしない場合とほとんど変わらない。
まんぷく食堂の問題は利益の不足ではなく、**お金の出入りのタイミング**だった。
::
::answer 考え方の例を見る
「3年目のお金の動き」の表を、四半期ごとに分けた**仮の設定**で試算してみよう（単位：万円）。年間の合計は、上の表と同じだ。
::table 仮の設定：3年目のお金の動き（四半期ごと）
| 項目 | 第1 | 第2 | 第3 | 第4 | 年間 |
| 本業で増える現金 | 300 | 400 | 450 | 550 | 1,700 |
| 3号店の設備・保証金 | △3,000 |  |  |  | △3,000 |
| 4号店の保証金・着手金・残金 |  | △500 | △1,250 | △1,250 | △3,000 |
| 借入金の元本返済 | △200 | △200 | △200 | △200 | △800 |
| 新規借入（3号店分・4号店分） | 2,000 |  |  | 2,000 | 4,000 |
::
（期首の現金900万円。Bの運転資金は1,500万円・年2%。工事が2か月遅れると、4号店の残金と融資が翌年度にずれ、第4四半期に500万円が余計にかかる。Dは客数が変わらなければ四半期400万円ずつ現金が増えるとした。）
::table 四半期末の現金残高の試算（500万円を下回る数字が危険信号）
| 案 | 第1 | 第2 | 第3 | 第4 | 遅れたときの第4 |
| 何もしない | 0 | △300 | △1,300 | △200 | △1,450 |
| A　4号店を延期 | 0 | 200 | 450 | 800 | 800 |
| B　1,500万円を追加借入 | 1,500 | 1,200 | 200 | 1,270 | 20 |
| C　Bと分割実行 | 1,500 | 1,200 | 1,200 | 1,270 | 1,020 |
| D　値上げ（客数不変） | 400 | 500 | △100 | 1,400 | 150 |
::
この試算から、実務の資金繰りの3つの原則が見えてくる。
- **年度末の残高ではなく、期中の最低残高（谷）を見る**：年間の表では「△200万円」だった3年目は、期中には△1,300万円まで落ち込む。実務では月ごと、支払いの集中する月は日ごとに確かめる。
- **最悪のシナリオで試す（ストレステスト）**：工事の遅れのような「よくある不運」が起きたとき、何が一緒にずれるのかを洗い出す。完成後に実行される融資は、遅れと一緒に遅れる。
- **資金の手当ては、困る前に、支出のタイミングに合わせて交渉する**：お金に困ってから頼む融資が、いちばん通りにくい。10月27日の応接室で、父が身をもって知ったとおりだ。
**さらに考えよう：銀行が分割実行を断ったら？**
Cが使えないなら、次善の策はAとBの組み合わせだ。4号店を1年延ばし、運転資金も借りておけば、四半期末の残高は1,500・1,700・1,950・約2,270万円と、どの時点でも余裕がある。その代わり、成長は1年遅れる。「安全」と「成長」のどちらをどれだけ取るかは、試算表を並べて初めて、数字で議論できる。
損益計算書の「黒字」しか見ていなかった父には、この表を作るという発想そのものがなかった。月ごとのお金の出入りを予測する**資金繰り表**と、それを支える**正確な帳簿**があって初めて、この4つの選択肢を比べることができる。

## 簿記とは「会社のカルテ」を書き、読む技術である

「会計事務所の仕事って、帳簿をつけることですよね」とひよりは聞いた。
「半分は正解です」と一ノ瀬は答えた。「記録をつけるのは手段です。目的は、その記録から会社の状態を読み、手遅れになる前に手を打つこと。医者がカルテを書くのと同じです」
簿記（ぼき）とは「帳簿記入」の略だ。会社で起きたお金とモノの動きを、一定のルールで記録し、最終的に**財務諸表**（決算書）という報告書にまとめる技術である。
こう書くと地味に聞こえるかもしれない。だが、簿記が扱っているのは、会社の成績と財産そのものだ。
**簿記とは、会社の成績表である財務諸表を作り、読み解くための技術だ。**
株価は財務諸表をもとに動く。銀行は財務諸表を見て融資を決める。税務署は財務諸表をもとに税金を計算する。経営者は財務諸表を見て、出店するか撤退するかを決める。会社に関わる人の多くが、同じ財務諸表を見て判断している。
財務諸表を読めないままお金の判断をするのは、地図を持たずに知らない土地を歩くようなものだ。逆に、読める人には、他の人には見えない会社の実態が見えてくる。

::table 財務諸表を「読む人」と、その目的
| 誰が | 何を知りたいか |
| 経営者 | どの店が儲かっているか。次の出店資金はあるか |
| 銀行 | この会社に貸したお金は、ちゃんと返ってくるか |
| 投資家（株主） | この会社の株は、将来もっと価値が上がるか |
| 取引先 | 掛けで売っても、代金を払ってもらえるか |
| 税務署 | 正しく利益を計算し、正しく税金を納めているか |
| 就職・転職する人 | この会社は5年後も存在しているか |
::

日商簿記3級は、財務諸表の読み書きの基礎を、**株式会社**を舞台に学ぶ資格だ。本書を読み終えたとき、あなたは次の力を身につけている。

## 試験の概要 ― 敵を知る

詳しい攻略法は「付録B 試験攻略マニュアル」で解説するが、ここで試験の輪郭をつかんでおこう。

::table 日商簿記3級の試験概要
| 項目 | 内容 |
| 試験方式 | 統一試験（ペーパー：例年6月・11月・2月）／ネット試験（CBT：随時） |
| 試験時間 | 60分 |
| 配点・合格基準 | 100点満点中、70点以上で合格 |
| 第1問（45点） | 仕訳問題 15問 |
| 第2問（20点） | 勘定記入、補助簿、伝票、語句選択など |
| 第3問（35点） | 決算：財務諸表・精算表・決算整理後残高試算表の作成 |
::

合格率は、ネット試験が**40.8%**（2025年4〜12月、受験者約19万人）、統一試験が**34.5%**（2025年11月の第171回）。受験者の6割前後が不合格になる試験だが、出題の型ははっきりしている。型を知って練習すれば、確実に届く。

::exam 合否を決めるのは「仕訳」と「決算」
配点を見れば一目瞭然だ。第1問の仕訳（45点）と第3問の決算（35点）だけで80点。この2つを確実に取れれば、合格ラインの70点を超えられる。
そして第3問の決算問題も、中身は「決算整理仕訳」の積み重ねだ。つまり、**仕訳を制する者が3級を制する**。本書が全章を通じて、ひたすら仕訳をテーブルで示し続けるのはそのためだ。
::

::note
※2027年4月1日以降の試験では、紙の手形・小切手の廃止などにあわせて出題区分が改定される予定です（2025年12月公表の暫定版）。本書は、2026年度（2027年3月まで）の試験に適用される現行の出題区分を完全にカバーしたうえで、2027年度からの変更点（{{new:2027年度〜}}・{{old:2027年度〜範囲外}}）も併記しています。合格率は日本商工会議所の公表データによる。

最後に、本書の読み方について。
各章の冒頭では、ひよりが顧問先で1つの「事件」に出会う。その答えは、必ずその章で学ぶ簿記のルールの中にある。物語を追いながら、ひよりと一緒に仕訳を切り、帳簿の中から答えを探してほしい。
ルールを覚えるだけでなく、**ルールが生まれた理由**まで理解してほしい。そうすれば、試験の仕訳は「暗記」ではなく「当たり前」に変わる。
各章の「判断してみよう」は、試験の範囲を超えた実務の発展問題だ。各案で何が良くなり、何がリスクとして残るかを考え、必ず1つ選んでから解説を開いてほしい。間違えた選択こそ、いちばん記憶に残る。

::summary 序章のまとめ
- 利益（成績）と現金（残高）は別物。会社は「赤字」ではなく「支払えないこと」で死ぬ。倒産企業の約半数は、最後の決算で黒字だった
- 設備投資・保証金・借入金の返済・在庫・税金は、利益と現金のズレを生む5大要因
- 損益計算書は「1年間の成績」、貸借対照表は「いまの財産と借金」、資金繰り表は「来月払えるか」を映す
- 黒字倒産を防ぐのは、利益を増やす手ではなく、お金の出入りのタイミングを管理する手。年度末の残高ではなく期中の最低残高を見て、融資の実行日を支出の日にそろえる
- 簿記とは、財務諸表を作り、読むための技術。会社に関わるあらゆる判断の土台になる
- 3級の試験は「仕訳（45点）」と「決算（35点）」が勝負どころ
::
