::mystery 深夜3時、消えた3,200円
深夜3時半。枕元のスマートフォンが震えた。差出人は坂口。ひよりが学生時代にアルバイトをしていた、おかわり堂・出町柳店の後輩だ。レジ締めのやり方を教えたのは、ひより自身だった。
「ひよりさん、夜分すみません。レジが3,200円合わないんです。2回数えました。たぶん、俺が疑われます」
30分前の出町柳店。最後の客がのれんをくぐって出ていくと、アルバイトリーダーで法学部3年の坂口が、レジ締めを始めた。
この店の支払いの6割はQRコードとカードだ。それでも深夜の学生客には、千円札と小銭で払う人がまだ多い。POSレジが印字した点検レシートの「現金在高（あるべき現金）」は**412,800円**。坂口は1万円札から1円玉まで、トレーに並べて2回数えた。ドロワーの中には**409,600円**しかない。
**3,200円が、消えていた。**
その夜のシフトは3人。翌朝、報告を受けた店長の岩井は、険しい顔でスマートフォンを握った。「3人とも呼び出す。誰かが抜いたに決まってる」
その朝、ひよりはちょうど、一ノ瀬と一緒におかわり堂本部の月次巡回に来ていた。岩井の電話を止めたのは、本部で経理を統括する役員の佐伯だった。
「坂口くんは、そんなことをする子じゃありません」と、ひよりは思わず口をはさんだ。
佐伯は穏やかに首を振った。「信じるのも、疑うのも、記録を見てからにしましょう。犯人探しの前に、帳簿の上でやるべきことがあります」
はたして、3,200円を盗んだ「犯人」はいるのか？
::

## 金庫の中の「紙」 ― 簿記の現金は、お札と硬貨だけではない

「帳簿の上でやるべきこと、というのは何ですか」
ひよりが聞くと、佐伯は答える代わりに、本部の金庫を開けた。取り出したのは、お札でも硬貨でもない。1枚の細長い紙だった。
「先週、近くの大学の学会に弁当を500食納めました。その代金として受け取った小切手です。金額は40万円」
佐伯は、小切手をひよりの前に置いた。
「大川さん、これは現金ですか」
「紙ですよね……現金ではないと思います」
「簿記では、現金です」
ひよりは小切手を見直した。数字と、学会の事務局の名前と、銀行の名前が印刷してある。どう見ても、お金には見えない。
「銀行の窓口に持っていけば、その場でお札に換えてもらえます」と佐伯は言った。「すぐにお金に換えられる紙は、お金と同じに扱う。それが簿記の決まりです」
隣で聞いていた一ノ瀬が、口を開いた。
「現金が合わない、という話をする前に、何を現金として数えるのかをそろえておく必要があります。数える範囲が人によって違えば、合うはずがありませんから」

::point 解説 ― 簿記の「現金」と通貨代用証券
簿記の**現金**には、紙幣や硬貨といった**通貨**に加えて、銀行などに持ち込めば**すぐに通貨に換えられる証券**も含まれる。これを**通貨代用証券**という。
::

::table 簿記上の「現金」に含まれるもの
| 種類 | 内容 |
| 通貨 | 紙幣・硬貨 |
| 他人振出小切手 | 取引先などが振り出した小切手。銀行に持ち込めば換金できる |
| 送金小切手 | 銀行が送金のために発行する小切手 |
| 郵便為替証書 | 普通為替証書・定額小為替証書。郵便局で換金できる |
| 配当金領収証 | 株式の配当金を受け取るための証書 |
| 期限の到来した公社債の利札 | 国債・社債などの利息を受け取る権利。期限が来れば換金できる |
::

表を見ていたひよりは、金庫の棚にある別の束に気づいた。郵便切手のシートと、地域振興券だ。
「じゃあ、あの切手や商品券も現金ですか。お金の代わりに使えますよね」
「いい質問です」と一ノ瀬は言った。「切手は、銀行に持っていってもお札には換えてもらえません。手紙を送るために使うものです。商品券も、発行元に請求して初めてお金になります。『すぐに換えられる』とは言えないものは、現金には入れません」

::table まぎらわしいが「現金」ではないもの
| もの | 正しい勘定科目 | 詳しくは |
| 自分（自社）が振り出した小切手 | 当座預金 | 第4章 |
| 普通預金・定期預金 | 普通預金・定期預金 | 第4章 |
| 郵便切手・収入印紙 | 通信費・租税公課（期末に未使用なら貯蔵品） | 第14・15章 |
| 他社が発行した商品券 | 受取商品券 | 第7章 |
| クレジットカードでの売上 | クレジット売掛金 | 第7章 |
| 約束手形 | 受取手形 | 第8章 |
::

「では、この小切手を受け取った日の仕訳を書いてみてください」
佐伯に言われて、ひよりはノートを開いた。小切手、と聞いて最初に浮かんだ勘定科目は、当座預金だった。だが、さっきの話のとおりなら、答えは違う。

::example 学会の弁当500食の代金を、小切手で受け取った
おかわり堂は、近くの大学で開かれた学会から、弁当500食（1食800円、合計400,000円）の注文を受けて納品した。代金は、学会の事務局が振り出した小切手で受け取った。
::answer
::journal 他人が振り出した小切手は、すぐに換金できるので「現金」
現金 400,000 | 売上 400,000
::
「小切手を受け取った」と聞くと、つい「当座預金」としたくなる。だが、**他人が振り出した小切手を受け取ったら現金**だ。当座預金を使うのは、自社が振り出した小切手に関する取引である（第4章）。
::trap
「小切手＝当座預金」と反射的に書かないこと。判断の基準は**誰が振り出した小切手か**だ。
ただし、他人振出の小切手でも「ただちに当座預金に預け入れた」と書かれていれば、借方は当座預金になる。問題文の最後まで読もう。
::
::

## あの夜のレジを再生する ― 現金出納帳

「現金の範囲はそろいました。次は、あの夜の現金の動きを、最初から並べてみましょう」
佐伯は、出町柳店から届いた帳簿を開いた。レジの現金が、いつ、何で増え、何で減ったか。1行ずつ日付の順に書いてある。
「これ、私がバイトのときに書いていた帳面です」とひよりは言った。
「名前は知っていましたか」
「いえ。店では『レジのノート』と呼んでいました」
「正式には、現金出納帳といいます」
ひよりは、前の日のページを指でたどった。朝、レジに入っているのは釣銭用の5万円。そこに1日の現金売上が加わる。閉店後、売上の分だけを銀行の夜間金庫に預け、レジには5万円だけを残す。毎日、同じ形の繰り返しだ。

::table compact sum 現金出納帳（おかわり堂・出町柳店）
| 日付 | 摘要 | 収入 | 支出 | 残高 |
| 5/31 | 前日繰越（釣銭準備金） | 50,000 |  | 50,000 |
| 5/31 | 本日の現金売上 | 341,500 |  | 391,500 |
| 5/31 | 普通預金へ預け入れ |  | 341,500 | 50,000 |
| 5/31 | 次日繰越 |  | 50,000 |  |
|= | 合計 | 391,500 | 391,500 |  |
::

「仕訳帳と総勘定元帳にも、現金の動きは書いてありますよね。どうして、もう1冊あるんですか」
「現金は、1日に何十回も出入りするからです」と一ノ瀬が答えた。「元帳の現金勘定だけでは、細かい動きを追いきれません。だから、現金だけを詳しく書く帳簿を別に持つ。なくなったお金を探すとき、最初に開くのはこの帳簿です」
ひよりは、5月31日のページをもう一度見た。この日は、残高の欄と、実際に数えたお金が一致していた。合わなくなったのは、次の日の夜だ。

::point 解説 ― 現金出納帳と補助簿
**現金出納帳**（げんきんすいとうちょう）は、現金の入出金だけを日付順に詳しく記録する帳簿だ。このように、主要簿（仕訳帳・総勘定元帳）を補って、特定の取引を詳しく記録する帳簿を**補助簿**という（第16章）。
1日の終わりには、残高を「次日繰越」として支出欄に記入し、収入と支出の合計を一致させて締め切る。翌日は「前日繰越」から始める。実際の店舗では、日々の売上はPOSレジで集計され、本部の経理がまとめて仕訳を行うことが多い。
::

## 3,200円を、帳簿にどう書くか ― 現金過不足

佐伯は、出町柳店から届いた2枚の紙を並べた。POSレジの点検レシートと、坂口が手で書いた現金の計数表だ。
点検レシートの現金在高は412,800円。計数表の合計は409,600円。
「左が、帳簿の上であるはずの現金です。右が、実際に数えた現金です」と佐伯は言った。「どちらが正しいと思いますか」
ひよりは少し考えた。「数えたほう、です。お金は、目の前にある分しかありませんから」
「そのとおりです。では、この3,200円の差を、いま帳簿にどう書きますか。盗まれた、と書きますか。お釣りの渡し間違い、と書きますか」
ひよりは答えられなかった。どちらも、まだ分からない。
「分からないことを、分かったように書いてはいけません」と佐伯は言った。「かといって、何も書かなければ、帳簿は412,800円のままです。金庫には409,600円しかないのに」
「じゃあ、どうするんですか」
「分かっていることだけを書きます。現金が3,200円減った。これは事実です。理由は、まだ分からない。だから、理由の欄には『分からない』と書いておくんです」
一ノ瀬が、ホワイトボードに勘定科目を1つ書いた。現金過不足。
「『分からない』と書くための勘定科目です。原因が見つかるまで、ズレをここに預けておきます」

::theory 「現実」に帳簿を合わせ、ズレは一時的に預けておく
帳簿上の現金残高を**帳簿残高**、実際に数えた現金の金額を**実際有高**（じっさいありだか）という。
帳簿の目的は、現実を正しく映すことだ。だから、ズレが見つかったら、**まず帳簿の現金を実際有高に合わせる**。
ただし、なぜズレたのかはまだ分からない。原因が分からないまま「雑損」などの費用にしてしまうのは早すぎる。そこで、ズレの金額を**現金過不足**（げんきんかふそく）という一時的な勘定に預けておき、原因を調べる。
現金過不足は、原因が分かるまでの「仮置き場」だ。資産でも負債でもなく、決算までに必ず整理されて消える。
::

「大川さん、仕訳にしてみてください」
ひよりは、第2章で柏木に教わった順番で考えた。現金は資産だ。資産が減ったのだから、ホームポジションの反対側、貸方に書く。相手は、現金過不足。

::journal 6月1日　現金の実際有高が帳簿残高より3,200円少なかった（不足）
現金過不足 3,200 | 現金 3,200
::

「これで、帳簿の現金は409,600円になりました。金庫の中身と同じです」
佐伯はうなずき、受話器を取った。相手は岩井だ。
「3人を呼び出すのは、待ってください。ズレは記録しました。次は、原因を調べる番です。あの夜、レジからお金を出した人がいないか、店の全員に確かめてもらえますか。もちろん、店長ご自身も含めてです」

::scene 2日後
6月3日の昼、事務所のひよりの席に、佐伯から内線が回ってきた。岩井店長から電話があったという。声が上ずっていたらしい。
「すみません……犯人、俺でした」
あの夜の0時過ぎ、岩井は仕込みの確認に店へ立ち寄った。ゴミ袋と食器用洗剤が切れていた。レジから2,400円を取り出し、向かいのコンビニで買ってきて、そのまま帰った。レシートは、制服のエプロンのポケットに入ったままだった。洗濯に出そうとして、紙の感触に気づいたのだという。
電話を切ったあと、ひよりは坂口にメッセージを送った。返事は1分で来た。泣き顔の絵文字が3つ並んでいた。
::

その日の夕方、ひよりは一ノ瀬と仕訳を確かめた。
「2,400円の正体が分かりました。何に使われたお金でしたか」
「ゴミ袋と洗剤です。消耗品費、ですね」
「では、預けておいた現金過不足から、本来の勘定科目に移しましょう」
消耗品費は費用だ。費用が発生したのだから、借方に書く。預けておいた現金過不足は、借方に3,200円ある。それを減らすのだから、今度は貸方だ。

::journal 6月3日　不足額のうち2,400円は、消耗品の購入の記入漏れと判明した
消耗品費 2,400 | 現金過不足 2,400
::

「残りの800円は、どうなるんですか」
「調べ続けます。それでも決算の日まで分からなければ、そのとき初めて、会社の損として認めます」
結局、800円の原因は、最後まで分からなかった。混雑した時間帯に、お釣りを渡しすぎたのかもしれない。翌年の3月31日、ひよりは決算の作業の中で、この800円に再会した。

::journal 3月31日（決算日）　残りの不足額800円は、原因が判明しなかった
雑損 800 | 現金過不足 800
::

::point 解説 ― 決算日まで原因が分からなかったら
決算日になっても原因が分からない不足額は**雑損**（ざっそん・費用）に、超過額は**雑益**（ざつえき・収益）に振り替えて、現金過不足をゼロにする。現金過不足は「仮置き場」なので、次の期には持ち越さない。
::

3つの仕訳を1つの勘定に集めると、3,200円がたどった道が1枚で見える。

::taccount 現金過不足
6/1 現金 3,200 | 6/3 消耗品費 2,400
 | 3/31 雑損 800
= 3,200 | 3,200
::

::solve 犯人は「人」ではなく「記録されなかった取引」だった
消えた3,200円のうち、2,400円は店長自身が消耗品の購入に使い、記録を忘れていたものだった。残る800円も、盗まれたという証拠はない。お釣りの渡し間違いである可能性が高い。
もし佐伯が電話を止めず、岩井が3人を問い詰めていたら、無実のアルバイトを疑い、信頼を失い、ただでさえ人が集まらない深夜帯のシフトに穴を開けていたかもしれない。
現金過不足という勘定科目は、**「ズレがあった」という事実だけを先に記録し、原因の判断を保留する**ための道具だ。疑うより先に、記録する。調べる。それでも分からなければ、雑損として正直に処理する。この順番が、会社の数字と、そこで働く人の両方を守るのである。
::

## お金が「多い」夜もある ― 超過のときは逆になる

次の巡回の日、佐伯はひよりに1つ質問をした。
「今回は足りませんでした。では、数えたら多かったときは、どうしますか」
「多いなら、困らないのでは……」
「いいえ。多いのも、記録が間違っている合図です。お客様からお釣りを多く預かったままかもしれません。売上を打ち忘れたのかもしれません」
ひよりは、不足のときの仕訳を思い出した。あのときは、現金を減らした。
「多いときは、帳簿の現金を増やして、実際のお金に合わせます。現金を借方に。相手は、やっぱり現金過不足です」
「そのとおりです。不足のときと、左右がそっくり逆になります」

::table 現金過不足の仕訳パターン
| 場面 | 不足（実際＜帳簿）のとき | 超過（実際＞帳簿）のとき |
| ①ズレを発見した | 現金過不足 ／ 現金 | 現金 ／ 現金過不足 |
| ②原因が判明した | 正しい費用など ／ 現金過不足 | 現金過不足 ／ 正しい収益など |
| ③決算日まで原因不明 | 雑損 ／ 現金過不足 | 現金過不足 ／ 雑益 |
::

「では、超過のまま決算日になったら、最後は雑益ですね」
ひよりがそう言うと、佐伯は少し笑った。
「そう思いますよね。去年の決算で、私もそう思って、間違えかけました」
佐伯は、去年の決算の資料を1枚出した。ある店で、期中に5,000円の超過が見つかっていた。決算で調べ直すと、記入漏れが2つ出てきた。ところが、その2つを帳簿に書き足すと、話がひっくり返ったのだという。

::example 超過なのに「雑損」？ ― 試験で最も狙われるパターン
期中に、現金の実際有高が帳簿残高より5,000円多かったため、現金過不足で処理していた。決算日に調べたところ、受取手数料8,000円の入金と、旅費交通費2,000円の支払いの記入漏れが判明した。残額は原因不明である。決算日の仕訳をしなさい。
::answer
::journal 期中（超過の発見）
現金 5,000 | 現金過不足 5,000
::
::journal 決算日
現金過不足 5,000 | 受取手数料 8,000
旅費交通費 2,000 |
雑損 1,000 |
::
考え方は「まず判明した原因を正しく仕訳し、最後に差額を埋める」。
- 現金過不足（貸方残高5,000円）をゼロにするため、借方に5,000円
- 受取手数料の記入漏れ → 収益の発生なので貸方に8,000円
- 旅費交通費の記入漏れ → 費用の発生なので借方に2,000円
- この時点で借方7,000円、貸方8,000円。差額1,000円を借方に入れて一致させる。借方に来る差額は費用なので**雑損**
現金全体は「超過」だったのに、原因を調べたら、説明できない「不足」が1,000円残った。超過＝雑益と決めつけず、必ず貸借差額で判断しよう。
::trap
現金過不足が借方と貸方のどちらに残っているかを、最初に確かめること。超過を見つけたときは**貸方**に記録しているので、決算では借方に書いて消す。
雑損か雑益かは、暗記ではなく、最後に残った貸借の差額がどちら側に来るかで決める。
::
::
::

「8,000円入って、2,000円出ていた。それなら、お金は6,000円多いはずです。でも、実際に多かったのは5,000円だけ……」
ひよりは、自分で計算して気がついた。
「1,000円、どこかへ消えているんですね。全体では多く見えていたのに」
「ええ。だから、最後の1行は、計算してみるまで決めないことです」

その週、出町柳店でもう1つ、小さな事件が起きた。6月5日の深夜、坂口からまたメッセージが届いたのだ。
「ひよりさん、今度は4,800円足りません。でも、今回は誰もレジからお金を出していません」
翌朝、ひよりは坂口と電話をつないだまま、POSの記録を1件ずつ確かめた。現金の会計に、4,800円ちょうどのものが1件あった。同じ時刻に、カード会社の明細にも4,800円の決済がある。
「坂口くん、この会計、カード払いじゃなかった？」
しばらく沈黙があった。
「……新人の子が、レジのボタンを押し間違えたんだと思います。カードで払ってもらったのに、『現金』で打ってます」
お金は盗まれていなかった。そもそも、レジに入っていなかったのだ。

::example キャッシュレス時代の現金過不足 ― カード払いを「現金」で打っていた
6月5日の深夜、出町柳店のレジ締めで、現金の実際有高が帳簿残高より4,800円少なかった。原因が分からないため、現金過不足で処理した。
翌日、POSの記録とカード会社の売上明細を照らし合わせたところ、ある客のカード払い4,800円を、アルバイトが誤って「現金」のボタンで会計していたことが判明した。6月5日と6月6日の仕訳をしなさい（カード会社への手数料は考えなくてよい）。
::answer
::journal 6月5日　不足を発見した（帳簿の現金を実際有高に合わせる）
現金過不足 4,800 | 現金 4,800
::
::journal 6月6日　原因が判明した（本当はカード会社から後で受け取る代金だった）
クレジット売掛金 4,800 | 現金過不足 4,800
::
レジで「現金」を押したので、帳簿には「現金 4,800／売上 4,800」と記録されていた。売上そのものは正しいが、受け取ったのは現金ではなく、カード会社から後日入金される権利（**クレジット売掛金**、第7章）だった。だから判明したときは、預けておいた現金過不足を、本来の勘定であるクレジット売掛金に振り替える。
支払い手段が増えるほど、「お金は受け取ったが、現金ではなかった」というズレが増える。レジ締めでは、現金だけでなく、カード・QRコード・電子マネーの決済額も、決済会社の明細と突き合わせるのが今の常識だ。
::trap
原因が分かったときに、売上をもう一度計上してはいけない。売上は6月5日のレジですでに記録されている。
直すのは「何で受け取ったか」だけだ。現金過不足を消して、正しい受取手段（クレジット売掛金）に振り替える。
::
::
::

報告を聞いた一ノ瀬は、最後にもう1つだけ付け加えた。
「現金過不足は、原因を調べる時間があるから使う勘定です。では、ズレが見つかったのが決算日の当日だったら、どうしますか」
「調べる時間が、もうありません」
「そうです。だから、そのときは仮置き場を通しません」

::point 解説 ― 決算日当日にズレが見つかったら
決算日に現金の実際有高を確認してズレが見つかり、原因が分からない場合は、現金過不足を使わずに、直接「雑損」または「雑益」で処理する。原因を調べる時間がもう残っていないからだ。
::

::journal 決算日に、現金の実際有高が帳簿残高より1,500円多いことが判明し、原因は不明だった
現金 1,500 | 雑益 1,500
::

## 人を疑う前に、仕組みを疑え ― 内部統制

6月の終わり、岩井が本部にやって来た。頭を下げたあと、少し言いにくそうに切り出した。
「佐伯さん、正直に言います。800円くらいの違いなら、その日の売上を800円少なく打ち直せば済む、と思っていました。前の店では、みんなそうしていたんです」
佐伯は、首を横に振った。
「それをすると、何が消えると思いますか」
「……800円のズレ、ですか」
「ズレがあった、という事実そのものです。事実が消えれば、誰も調べません。毎月少しずつお金を抜く人がいても、売上を少しずつ書き換えれば、帳簿の上では何も起きていないことになります」
岩井は黙った。ひよりは、所長の言葉を思い出していた。帳簿は会社の日記。嘘を書けば、いつか自分が読むことになる。

::danger 帳簿を「現金に合わせて書き換える」という誘惑
「たった800円の違いなら、売上を800円少なく入力し直せば済む」。現場では、こうした処理が驚くほど簡単に行われてしまう。
だが、それは**記録の改ざん**だ。一度これを許すと、ズレがあったという事実そのものが帳簿から消える。毎月数千円ずつ現金を抜き取る不正があっても、売上を少しずつ書き換えれば、帳簿の上では何も起きていないように見えてしまう。小さな着服は、発覚しないまま何年も続き、気づいたときには数百万円の損害になっていることも珍しくない。
現金過不足という勘定科目は、**ズレを「なかったこと」にしないため**に存在する。ズレは消すものではなく、記録し、追跡するものなのだ。
::

「今回の件で悪かったのは、岩井さんではありません」と佐伯は続けた。「店の経費をレジから出せる仕組みのほうです。出せるようになっていれば、誰かが必ず出します。そして、いつか必ず書き忘れます」
「人を責めても、同じことがまた起きる、ということですか」とひよりは聞いた。
「ええ。だから、仕組みのほうを変えます」
佐伯は、全12店舗に配る新しいルールの案を見せた。

::table 現金を守る内部統制の例
| 仕組み | ねらい |
| レジ締めを2人で行い、双方が署名する | 1人による着服や数え間違いを防ぐ |
| 釣銭準備金を毎日同じ額（例：5万円）に戻す | 日々の売上と、店に置く現金を明確に分ける |
| 店の経費はレジから出さず、小口現金を使う | 売上の現金と経費の現金を混ぜない（第4章） |
| 現金過不足を毎日記録し、本部が店舗別に集計する | 特定の店・時間帯に偏ったズレを早期に発見する |
| 券売機・セルフレジ・キャッシュレス決済の導入 | 人が現金に触れる回数そのものを減らす |
::

「最後の行は、お金がかかりますね」と岩井が言った。
「かかります。ただ、券売機を入れる理由は、人件費を減らすことだけではありません」と佐伯は答えた。「人の手がお金に触れる回数が減れば、数え間違いも、お釣りの渡し間違いも、魔が差すことも、まとめて減ります」

::point 解説 ― 内部統制と、現金のいま
会社が「人が誠実であること」に頼らず、「間違いや不正が起きにくい仕組み」を作ることを、**内部統制**という。現金は、会社の資産の中で最も盗まれやすく、最もミスが起きやすいので、内部統制の出発点になる。
経済産業省によると、2025年の日本のキャッシュレス決済比率は**58.0%**（新しい国内指標。従来の国際比較の指標では46.3%）。裏を返せば、支払いの4割以上は今も現金だ。現金は減りつつあるが、消えてはいない。
::

帰り道、ひよりは一ノ瀬に聞いた。
「現金過不足を毎日つけていれば、不正は全部見つかりますか」
「見つからない手口もあります」と一ノ瀬は言った。「レジ締めの数字がぴったり合ったまま、お金だけが消える方法です」

::real 不正の4割は「通報」で見つかる
世界の不正調査の専門家団体ACFE（公認不正検査士協会）が2024年にまとめた報告書によると、職場で起きた不正のうち約9割は、現金や商品などの**資産の横領**だった。不正が見つかったきっかけで最も多いのは、同僚や取引先からの**通報（43%）**で、内部監査や外部監査（17%）、上司による確認（13%）を大きく上回る。
日本の上場企業も例外ではない。東京商工リサーチの集計では、2025年度に不適切な会計・経理を開示した上場企業は35社41件。そのうち8件（19.5%）が、従業員などによる**着服横領**だった。
不正の多くは、帳簿の数字より先に、まわりの人の「違和感」に表れる。だから会社は、通報の窓口を設け、現金のズレを毎日記録して、違和感を数字で裏づけられるようにしておく。

**この章の道具で読む ― 現金過不足が「ゼロ」でも安心できない理由**
飲食店のレジで知られた横領の手口に、「会計後の取消」がある。客から代金を受け取ってレジに記録したあと、客が帰ってから、その会計をレジ上で取り消し、同じ額の現金を抜き取る。1,200円の会計で行われたとき、帳簿には次の2つの仕訳が残る。

::journal ① 客の会計（POSレジが自動で記録）
現金 1,200 | 売上 1,200
::
::journal ② 客が帰ったあと、会計を取り消した（このとき現金1,200円を抜き取る）
売上 1,200 | 現金 1,200
::

①と②で、売上も現金も差し引きゼロになる。帳簿の現金は抜き取ったあとの実際有高とぴったり一致するので、**現金過不足は1円も出ない**。この章で学んだレジ締めの照合を、すり抜けてしまうのだ。
では、痕跡はどこに残るか。②の取消の記録そのものだ。取消は誰でもいつでもできる操作ではなく、その件数・時刻・担当者がPOSに残る。だから、現金過不足の記録と並べて**取消の件数**を毎日見る。取消が特定の人やシフトに偏っていれば、それがシグナルになる。下の「判断してみよう」で、佐伯が取消の件数を表に入れたのは、このためだ。
::note
出典：[ACFE「Occupational Fraud 2024: A Report to the Nations」の概要](https://cshco.com/insights/breaking-down-the-acfes-latest-fraud-report)、[LOGISTICS TODAY（2026年4月20日、東京商工リサーチの調査）](https://www.logi-today.com/941190)、[経済産業省の公表（Impress Watch、2026年3月31日）](https://www.watch.impress.co.jp/docs/news/2099068.html)
::
::

::cfo 12店舗の中で、1店舗だけ毎月数千円が足りない ― 次の一手は？
出町柳店の一件から半年後の巡回で、佐伯はひよりに1枚の表を見せた。おかわり堂の本部には、12店舗の現金過不足の月次データが集まってくる。11店舗は毎月±1,000円以内に収まっている。だが衣笠店だけが、この半年間、毎月3,000〜5,000円の不足を出し続けている。佐伯は、衣笠店の深夜シフトの記録を、勤務した2人の組み合わせ別に並べ直していた。
::table 衣笠店・深夜シフトの半年分の記録（組み合わせ別）
| 曜日 | 2人の組み合わせ | 勤務回数 | 不足が出た回数 | 不足額の合計 | 会計後の取消 |
| 木 | 田村（3年目）＋新人A | 18 | 17 | 21,600円 | 160件 |
| 木 | 田村＋新人B | 8 | 5 | 2,400円 | 20件 |
| 日 | 田村＋店長 | 26 | 1 | 300円 | 12件 |
| 月〜水・金・土 | そのほかの組み合わせ | 104 | 4 | 1,800円 | 30件 |
::
POSのログを確かめると、会計後の取消は**すべて店長のIDで**操作されていた。店長は木曜の深夜には勤務していない。店では、店長が休みの日に取消が必要になったとき、店長のIDとパスワードを口頭で教えていたという。
「大川さんなら、次に何をしますか」
細かい計算は要らない。次の視点で表を読んでから選んでほしい。
- 不足は、**曜日**で偏っているのか、**人の組み合わせ**で偏っているのか
- 同じ人が別の人と組んだ日には、何が起きているか
- 今の記録から、**「誰が」取消をしたかを証明できるか**
::choice A. 不足が出た日には、必ず田村さんがいる。田村さんを呼んで事情を聞く
**× データが示していないことを、データが示したと思い込んでいる。**田村さんが店長と組んだ日曜は、26回中、不足は1回だけ。不足が集中しているのは「田村さん＋新人A」の木曜だ。このデータだけでは、田村さんか新人Aか、あるいは店長のIDを知っている別の誰かかを区別できない。
しかも、取消はすべて店長のIDで操作されている。ログからは「誰が取り消したか」が分からない。証拠のないまま話を聞けば、無実の人を傷つけ、本当の原因を警戒させるだけだ。
::
::choice B. まずIDを1人ずつ分け、取消を店長の承認制にする。そのうえで1か月分のデータを取り直し、取消の時刻と防犯カメラの映像を照合する
**◎ 証拠を取れる状態を先に作る。**今の記録の最大の欠陥は、店長のIDが共有されていて、取消の操作者が特定できないことだ。IDを個人ごとに分け、取消には別の人の承認を必要にすれば、不正でもミスでも、次からは「誰が・いつ・何を」が記録に残る。
不足が止まれば、それ自体が答えになる。止まらなければ、個人のIDと時刻、カメラの映像という事実をそろえてから話を聞く。仕組みの手当てと事実の確認を、同時に進めるのがポイントだ。
::
::choice C. 1回あたりの金額は小さいので、雑損として処理し続ける
**× いちばん高くつく。**半年の不足は合計26,100円。金額だけ見れば小さい。だが表を見れば、ズレは偶然ではなく、特定の組み合わせに集中している。会計後の取消も、木曜の「田村＋新人A」だけで160件と桁違いに多い。これを放置すれば、「この会社では現金が合わなくても誰も調べない」という空気が全店に広がる。不正であれば、金額は時間とともに大きくなるのがふつうだ。
::
::choice D. 衣笠店の不足額は「店の責任」として、毎月、店長の賞与から差し引く
**× 法律に触れるおそれがあり、真相にも近づかない。**あらかじめ「不足が出たら弁償させる」と決めることは、労働基準法が禁じる「損害賠償額の予定」にあたるおそれがある。賞与や給料から一方的に差し引けば、賃金の全額払いの原則にも反する。
店長がIDを共有していたことは確かに問題だが、責任を問うべきなのは「管理のやり方」であって、原因の分からない現金の不足ではない。
::
::answer 考え方の例を見る
まず、**データの「層」を分けて読む**。曜日だけで見ると「木曜に不足が多い」。組み合わせで分けると「田村＋新人Aに集中している」。さらに、田村さんが店長と組んだ日にはほとんど不足がないことから、田村さん1人に原因があるとは言えないことも分かる。1つの切り口だけで結論を出すと、無実の人を疑うことになる。
次に、**記録そのものの信頼性を疑う**。取消の操作者が店長のIDになっているのは、IDが共有されていたからだ。内部統制の言葉で言えば、「取引の記録から、操作した人を追えない（証跡がない）」状態である。これでは不正を見つけることも、無実を証明することもできない。
::table 現金の不正・ミスを防ぐ仕組みと、そのねらい
| 仕組み | ねらい |
| IDを個人ごとに分け、パスワードの共有を禁止する | 誰が操作したかを記録に残す |
| 会計後の取消は、別の人の承認を必要にする | 1人で取消と抜き取りを完結させない |
| 取消の件数・時刻を、店舗別・担当者別に毎週集計する | 偏りを早く見つける |
| レジ締めを2人で行い、双方が署名する | 数え間違いと着服を同時に防ぐ |
::
**さらに考えよう：仕組みを変えても、不足が止まらなかったら？**
IDを分け、取消を承認制にしても不足が続くなら、原因は「会計後の取消」ではない別の手口か、ミスだ。たとえば、会計そのものをレジに通さずに現金を受け取る手口なら、取消の記録には何も残らない。そのときは、POSの客数と、食材の使用量（売れた牛丼の数から逆算した牛肉の量）を突き合わせる。お金の記録が消されても、**モノの記録は残る**。複数の記録を照らし合わせるのが、不正を見つける基本だ（第16章）。
1か月後、IDを分けて取消を承認制にした衣笠店では、木曜の不足がぴたりと止まった。取消の件数も、ほかの曜日と変わらない水準に落ちた。誰がやっていたのかは、最後まで分からなかった。佐伯は言った。「それでいいんです。止まったことが大事で、止められる仕組みができたことが、もっと大事です」
**人を疑う前に、記録と仕組みを疑う。**月数千円の損失そのものより、「この会社では現金のズレが放置される」という空気が広がることのほうが、はるかに高くつく。
::
::

::exam 現金・現金過不足の急所
- **他人振出小切手を受け取ったら「現金」**。自己振出小切手（自社が振り出した小切手）が戻ってきたら「当座預金」。この区別は頻出。
- 郵便切手は現金ではない。購入時は「通信費」、収入印紙は「租税公課」。
- 現金過不足は、まず「現金を実際有高に合わせる」。不足なら貸方に現金、超過なら借方に現金。
- 決算で原因不明の残額は、貸借差額が借方なら雑損、貸方なら雑益。超過＝雑益と決めつけない。
- 決算日に発見したズレは、現金過不足を使わず直接、雑損・雑益へ。
- 現金過不足勘定は、決算整理後の試算表や貸借対照表には残らない。
::

::next 預金にも「ズレ」は起きる ― 銀行勘定調整表
2級では、会社の帳簿上の当座預金残高と、銀行が発行する残高証明書の金額のズレを調べる**銀行勘定調整表**を学ぶ。「小切手を振り出したが、相手がまだ銀行に持ち込んでいない」といった時間差が、ズレの原因になる。現金過不足と同じく「ズレを記録し、原因を突き止める」という発想だ。
さらに実務では、企業グループ全体の現金を一元管理する**キャッシュ・マネジメント・システム（CMS）**や、毎日の入出金予定を管理する**資金繰り表**へと発展する。財務の仕事の半分は、「いま、どこに、いくら現金があるか」を正確に把握し続けることだと言っても過言ではない。
::

**現金**：他人振出小切手、送金小切手、配当金領収証、普通為替証書
自己振出小切手は当座預金、郵便切手は通信費（期末に未使用なら貯蔵品）、収入印紙は租税公課（同）、他社が発行した商品券は受取商品券で処理する。
::
::
::problem 次の一連の取引を仕訳しなさい。
(1) 現金の実際有高を調べたところ85,000円で、帳簿残高は90,000円だった。
(2) (1)の不足額のうち3,000円は、郵便切手の購入（通信費）の記入漏れであることが判明した。
(3) 決算日になっても、残りの不足額の原因は判明しなかった。
::answer
::journal (1) 帳簿の現金を5,000円減らして実際有高に合わせる
現金過不足 5,000 | 現金 5,000
::
::journal (2) 判明した分を本来の勘定に振り替える
通信費 3,000 | 現金過不足 3,000
::
::journal (3) 残額2,000円を雑損に振り替える
雑損 2,000 | 現金過不足 2,000
::

::problem 決算日に、現金過不足勘定の借方残高が4,000円あった。調査の結果、水道光熱費6,000円の支払いと、受取利息3,000円の受け取りの記入漏れが判明した。残額は原因不明である。決算整理仕訳をしなさい。
::answer
::journal
水道光熱費 6,000 | 現金過不足 4,000
雑損 1,000 | 受取利息 3,000
::
現金過不足の借方残高4,000円をゼロにするため、貸方に4,000円。水道光熱費（費用）は借方に6,000円、受取利息（収益）は貸方に3,000円。この時点で借方6,000円、貸方7,000円なので、差額1,000円を借方に入れる。借方の差額は**雑損**となる。
::
::
::problem 決算日に現金の実際有高を確認したところ、帳簿残高より700円少なかった。原因は不明である。仕訳をしなさい。
::answer
::journal 決算日当日の発見なので、現金過不足を使わず直接「雑損」とする
雑損 700 | 現金 700

::summary
- 簿記の「現金」は、通貨＋通貨代用証券（他人振出小切手、送金小切手、郵便為替証書、配当金領収証、期限到来の公社債利札）
- 自己振出小切手は当座預金、切手は通信費、収入印紙は租税公課。現金と混同しない
- 現金出納帳は、現金の入出金を時系列で詳しく記録する補助簿
- 現金のズレは、まず帳簿を実際有高に合わせ、差額を「現金過不足」に仮置きする
- 原因が判明したら本来の勘定へ振り替え、決算日まで不明なら雑損・雑益へ。最後の差額は貸借差額で判断する
- ズレは消さずに記録する。人を疑う前に、仕組み（内部統制）を疑う
::
