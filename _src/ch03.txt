::mystery 深夜3時、消えた3,200円
深夜3時半。枕元のスマートフォンが震えた。差出人は坂口。ひよりが学生時代にアルバイトをしていた、おかわり堂・出町柳店の後輩だ。レジ締めのやり方を教えたのは、ひより自身だった。
坂口：「ひよりさん、夜分すみません。レジが3,200円合わないんです。2回数えました。たぶん、俺が疑われます」
30分前の出町柳店。最後の客がのれんをくぐって出ていくと、アルバイトリーダーで法学部3年の坂口が、レジ締めを始めた。
この店の支払いの6割はQRコードとカードだ。それでも深夜の学生客には、千円札と小銭で払う人がまだ多い。POSレジが印字した点検レシートの「現金在高（あるべき現金）」は**412,800円**。坂口は1万円札から1円玉まで、トレーに並べて2回数えた。ドロワーの中には**409,600円**しかない。
**3,200円が、消えていた。**
その夜のシフトは3人。坂口と、2年生の三好と、入って1か月の新人だ。翌朝、報告を受けた店長の岩井は、険しい顔でスマートフォンを握った。
岩井：「3人とも呼び出す。誰かが抜いたに決まってる」
その朝、ひよりはちょうど、一ノ瀬と一緒におかわり堂本部の月次巡回に来ていた。スピーカーから流れる岩井の声を聞いて、思わず口をはさんだ。
ひより：「坂口くんは、そんなことをする子じゃありません」
電話を引き取ったのは、本部で経理を統括する役員の佐伯だった。
佐伯：「信じるのも、疑うのも、記録を見てからにしましょう。犯人探しの前に、帳簿の上でやるべきことがあります」
はたして、3,200円を盗んだ「犯人」はいるのか？
::

## 金庫の中の「紙」 ― 簿記の現金は、お札と硬貨だけではない

電話が切れると、ひよりは鞄をつかんで立ち上がった。
ひより：「出町柳店に行かせてください。坂口くんと一緒に、もう一度数えます」
一ノ瀬：「行きましょう。ただし、その前に1つだけ。大川さんは、何を数えるつもりですか」
ひより：「何を、って……レジのお金です」
一ノ瀬：「お金とは、どこまでですか」
ひよりは答えに詰まった。お金はお金だ。それ以外に何があるというのだろう。
佐伯が、本部の金庫を開けた。取り出したのは、お札でも硬貨でもない。1枚の細長い紙だった。
佐伯：「先週、近くの大学の学会に弁当を500食納めました。その代金として受け取った小切手です。金額は40万円」
佐伯：「大川さん、これは現金ですか」
ひより：「紙ですよね……現金ではないと思います」
佐伯：「簿記では、現金です」
ひよりは小切手を見直した。数字と、学会の事務局の名前と、銀行の名前が印刷してある。どう見ても、お金には見えない。
佐伯：「銀行の窓口に持っていけば、その場でお札に換えてもらえます。すぐにお金に換えられる紙は、お金と同じに扱う。それが簿記の決まりです」
一ノ瀬：「数える範囲が人によって違えば、合うはずがありません。だから、数える前に、範囲をそろえるんです」

::point メモ ― 簿記の「現金」と通貨代用証券
簿記の**現金**には、紙幣や硬貨といった**通貨**に加えて、銀行などに持ち込めば**すぐに通貨に換えられる証券**も含まれる。これを**通貨代用証券**という。
::

::table 簿記上の「現金」に含まれるもの
| 種類 | 内容 |
| 通貨 | 紙幣・硬貨 |
| 他人振出小切手 | 取引先などが振り出した小切手。銀行に持ち込めば換金できる |
| 送金小切手 | 銀行が送金のために発行する小切手 |
| 郵便為替証書 | 普通為替証書・定額小為替証書。郵便局で換金できる |
| 配当金領収証 | 株式の配当金を受け取るための証書 |
| 期限の到来した公社債の利札 | 国債・社債などの利息を受け取る権利。期限が来れば換金できる |
::

金庫の棚には、ほかにも紙の束があった。郵便切手のシートと、客が支払いに使った地域振興券だ。
ひより：「じゃあ、あの切手や商品券も現金ですか。お金の代わりに使えますよね」
一ノ瀬：「切手は、銀行に持っていってもお札には換えてもらえません。手紙を送るために使うものです。商品券も、発行元に請求して初めてお金になります。『すぐに換えられる』と言えないものは、現金には入れません」

::table まぎらわしいが「現金」ではないもの
| もの | 正しい勘定科目 | 詳しくは |
| 自分（自社）が振り出した小切手 | 当座預金 | 第4章 |
| 普通預金・定期預金 | 普通預金・定期預金 | 第4章 |
| 郵便切手・収入印紙 | 通信費・租税公課（期末に未使用なら貯蔵品） | 第14・15章 |
| 他社が発行した商品券 | 受取商品券 | 第7章 |
| クレジットカードでの売上 | クレジット売掛金 | 第7章 |
| 約束手形 | 受取手形 | 第8章 |
::

佐伯：「出かける前に、この小切手を受け取った日の仕訳を書いてみてください。30秒で」
ひよりはノートを開いた。小切手、と聞いて最初に浮かんだ勘定科目は、当座預金だった。ペンが止まる。さっきの話のとおりなら、答えは違う。

::example 学会の弁当500食の代金を、小切手で受け取った
おかわり堂は、近くの大学で開かれた学会から、弁当500食（1食800円、合計400,000円）の注文を受けて納品した。代金は、学会の事務局が振り出した小切手で受け取った。
::answer
::journal 他人が振り出した小切手は、すぐに換金できるので「現金」
現金 400,000 | 売上 400,000
::
「小切手を受け取った」と聞くと、つい「当座預金」としたくなる。だが、**他人が振り出した小切手を受け取ったら現金**だ。当座預金を使うのは、自社が振り出した小切手に関する取引である（第4章）。
::trap
「小切手＝当座預金」と反射的に書かないこと。判断の基準は**誰が振り出した小切手か**だ。
ただし、他人振出の小切手でも「ただちに当座預金に預け入れた」と書かれていれば、借方は当座預金になる。問題文の最後まで読もう。
::
::
::

## 午後2時、出町柳店 ― 現金出納帳であの夜を再生する

昼の営業が落ち着いた午後2時。出町柳店の裏口を開けると、休憩室のパイプ椅子に坂口が座っていた。目の下が黒い。授業を休んで、朝からここにいるという。
坂口：「ひよりさん、すみません。教わったとおりにやったんです。本当に、2回数えました」
ひより：「分かってる。だから、3回目を一緒に数えよう」
佐伯の立ち会いのもと、2人は金庫から昨夜のドロワーを出した。1万円札、5千円札、千円札。硬貨は種類ごとにトレーに並べる。ひよりが読み上げ、坂口が計数表に書く。
レジの下の引き出しには、封筒がもう1つあった。客が使った地域振興券が、輪ゴムで束ねてある。
坂口：「これは数に入れていません。別の封筒に分けろって、ひよりさんに教わったので」
ひより：「それで合ってる。商品券は、現金じゃないから」
言いながら、ひよりは少し驚いていた。学生のころは理由も知らずに分けていた。その理由を、今朝、金庫の前で教わったばかりだ。
3回目の合計も、409,600円だった。数え間違いではない。
佐伯：「では、お金のほうではなく、記録のほうを見ましょう」
佐伯は、レジの横に立てかけてある帳簿を開いた。レジの現金が、いつ、何で増え、何で減ったか。1行ずつ日付の順に書いてある。
ひより：「これ、私がバイトのときに書いていた帳面です。店では『レジのノート』と呼んでいました」
佐伯：「正式には、現金出納帳といいます」
ひよりは、前の日のページを指でたどった。朝、レジに入っているのは釣銭用の5万円。そこに1日の現金売上が加わる。閉店後、売上の分だけを銀行の夜間金庫に預け、レジには5万円だけを残す。毎日、同じ形の繰り返しだ。

::table compact sum 現金出納帳（おかわり堂・出町柳店）
| 日付 | 摘要 | 収入 | 支出 | 残高 |
| 5/31 | 前日繰越（釣銭準備金） | 50,000 |  | 50,000 |
| 5/31 | 本日の現金売上 | 341,500 |  | 391,500 |
| 5/31 | 普通預金へ預け入れ |  | 341,500 | 50,000 |
| 5/31 | 次日繰越 |  | 50,000 |  |
|= | 合計 | 391,500 | 391,500 |  |
::

坂口：「前の日は、ぴったり合ってるんです。おかしくなったのは、昨日の夜だけで」
ひより：「佐伯さん、仕訳帳や元帳にも、現金の動きは書いてありますよね。どうして、店にもう1冊あるんですか」
佐伯：「現金は、1日に何十回も出入りするからです。元帳の現金勘定だけでは、細かい動きを追いきれません。なくなったお金を探すとき、最初に開くのはこの帳簿です」
5月31日は、残高の欄と、数えたお金が一致している。合わなくなったのは、6月1日の閉店までのどこかだ。範囲は、1日分に絞られた。

::point メモ ― 現金出納帳と補助簿
**現金出納帳**（げんきんすいとうちょう）は、現金の入出金だけを日付順に詳しく記録する帳簿だ。このように、主要簿（仕訳帳・総勘定元帳）を補って、特定の取引を詳しく記録する帳簿を**補助簿**という（第16章）。
1日の終わりには、残高を「次日繰越」として支出欄に記入し、収入と支出の合計を一致させて締め切る。翌日は「前日繰越」から始める。実際の店舗では、日々の売上はPOSレジで集計され、本部の経理がまとめて仕訳を行うことが多い。
::

## 「盗難」とは書かない ― 現金過不足

休憩室のドアが開いて、岩井が入ってきた。腕を組んだまま、坂口のほうは見ない。
岩井：「数え直しても足りないんでしょう。だったら、帳簿には『盗難』と書くしかない。警察に届けるかどうかは、そのあとで決めます」
坂口の肩が、小さく震えた。ひよりは何か言おうとしたが、言葉が出てこなかった。
佐伯は、2枚の紙を机に並べた。POSレジの点検レシートと、さっき書き上げた計数表だ。点検レシートの現金在高は412,800円。計数表の合計は409,600円。
佐伯：「岩井さん。この2つの数字のうち、確かなのはどちらですか」
岩井：「……数えたほうです。金は、目の前にある分しかない」
佐伯：「そのとおりです。現金が3,200円少ない。これは事実です。では、盗まれたというのは、事実ですか」
岩井：「それは……まだ」
佐伯：「分からないことを、分かったように書いてはいけません。帳簿に『盗難』と書けば、それは会社の公式な記録になります」
ひより：「でも、何も書かなければ、帳簿は412,800円のままです。金庫には409,600円しかないのに」
佐伯：「ええ。だから、分かっていることだけを書きます。現金が減った。理由は、まだ分からない。理由の欄には、『分からない』と書いておくんです」
佐伯は、計数表の余白に勘定科目を1つ書いた。現金過不足。
佐伯：「『分からない』と書くための勘定科目です。原因が見つかるまで、ズレをここに預けておきます」

::theory 「現実」に帳簿を合わせ、ズレは一時的に預けておく
帳簿上の現金残高を**帳簿残高**、実際に数えた現金の金額を**実際有高**（じっさいありだか）という。
帳簿の目的は、現実を正しく映すことだ。だから、ズレが見つかったら、**まず帳簿の現金を実際有高に合わせる**。
ただし、なぜズレたのかはまだ分からない。原因が分からないまま「雑損」などの費用にしてしまうのは早すぎる。そこで、ズレの金額を**現金過不足**（げんきんかふそく）という一時的な勘定に預けておき、原因を調べる。
現金過不足は、原因が分かるまでの「仮置き場」だ。資産でも負債でもなく、決算までに必ず整理されて消える。
::

佐伯：「大川さん、仕訳にしてみてください」
ひよりは、第2章で柏木に教わった順番で考えた。現金は資産だ。資産が減ったのだから、ホームポジションの反対側、貸方に書く。相手は、現金過不足。

::journal 6月1日　現金の実際有高が帳簿残高より3,200円少なかった（不足）
現金過不足 3,200 | 現金 3,200
::

ひより：「これで、帳簿の現金は409,600円になりました。金庫の中身と同じです」
坂口：「……俺が盗った、とは書かないんですね」
佐伯：「書きません。あなたは疑われているのではなく、調べられているだけです。調べるのは、人ではなく記録です」
佐伯は、岩井のほうを向いた。
佐伯：「次は、原因を調べる番です。昨日、レジからお金を出した人がいないか、店の全員に確かめてください。もちろん、店長ご自身も含めてです」
岩井は一瞬、むっとした顔をした。それから、黙ってうなずいた。

::scene 2日後
6月3日の昼、事務所のひよりの席に、佐伯から内線が回ってきた。岩井店長から電話があったという。声が上ずっていたらしい。
岩井：「すみません……犯人、俺でした」
あの夜の0時過ぎ、岩井は仕込みの確認に店へ立ち寄った。ゴミ袋と食器用洗剤が切れていた。レジから2,400円を取り出し、向かいのコンビニで買ってきて、そのまま帰った。レシートは、制服のエプロンのポケットに入ったままだった。洗濯に出そうとして、紙の感触に気づいたのだという。
電話を切ったあと、ひよりは坂口にメッセージを送った。返事は1分で来た。泣き顔の絵文字が3つ並んでいた。
::

その日の夕方、ひよりは一ノ瀬と仕訳を確かめた。
一ノ瀬：「2,400円の正体が分かりました。何に使われたお金でしたか」
ひより：「ゴミ袋と洗剤です。消耗品費、ですね」
一ノ瀬：「では、預けておいた現金過不足から、本来の勘定科目に移しましょう」
消耗品費は費用だ。費用が発生したのだから、借方に書く。預けておいた現金過不足は、借方に3,200円ある。それを減らすのだから、今度は貸方だ。

::journal 6月3日　不足額のうち2,400円は、消耗品の購入の記入漏れと判明した
消耗品費 2,400 | 現金過不足 2,400
::

ひより：「残りの800円は、どうなるんですか」
一ノ瀬：「調べ続けます。それでも決算の日まで分からなければ、そのとき初めて、会社の損として認めます」
結局、800円の原因は、最後まで分からなかった。混雑した時間帯に、お釣りを渡しすぎたのかもしれない。翌年の3月31日、ひよりは決算の作業の中で、この800円に再会した。

::journal 3月31日（決算日）　残りの不足額800円は、原因が判明しなかった
雑損 800 | 現金過不足 800
::

::point メモ ― 決算日まで原因が分からなかったら
決算日になっても原因が分からない不足額は**雑損**（ざっそん・費用）に、超過額は**雑益**（ざつえき・収益）に振り替えて、現金過不足をゼロにする。現金過不足は「仮置き場」なので、次の期には持ち越さない。
::

3つの仕訳を1つの勘定に集めると、3,200円がたどった道が1枚で見える。

::taccount 現金過不足
6/1 現金 3,200 | 6/3 消耗品費 2,400
 | 3/31 雑損 800
= 3,200 | 3,200
::

::solve 犯人は「人」ではなく「記録されなかった取引」だった
消えた3,200円のうち、2,400円は店長自身が消耗品の購入に使い、記録を忘れていたものだった。残る800円も、盗まれたという証拠はない。お釣りの渡し間違いである可能性が高い。
もし佐伯が電話を止めず、岩井が3人を問い詰めていたら、無実のアルバイトを疑い、信頼を失い、ただでさえ人が集まらない深夜帯のシフトに穴を開けていたかもしれない。
現金過不足という勘定科目は、**「ズレがあった」という事実だけを先に記録し、原因の判断を保留する**ための道具だ。疑うより先に、記録する。調べる。それでも分からなければ、雑損として正直に処理する。この順番が、会社の数字と、そこで働く人の両方を守るのである。
::

### 試験で狙われるパターン ― 超過・原因の一部判明・決算日当日

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 数えたら多かった（超過）**　考え方は不足のときと同じで、帳簿の現金を実際有高に合わせ、相手を現金過不足とする。仕訳の左右が、不足のときとちょうど逆になる。

::table 現金過不足の仕訳パターン
| 場面 | 不足（実際＜帳簿）のとき | 超過（実際＞帳簿）のとき |
| ①ズレを発見した | 現金過不足 ／ 現金 | 現金 ／ 現金過不足 |
| ②原因が判明した | 正しい費用など ／ 現金過不足 | 現金過不足 ／ 正しい収益など |
| ③決算日まで原因不明 | 雑損 ／ 現金過不足 | 現金過不足 ／ 雑益 |
::

**② 超過なのに、最後は雑損になる**　決算で原因の一部が判明したら、判明した分を正しい勘定で仕訳し、最後に残った**貸借差額**で雑損か雑益かを決める。「超過＝雑益」と決めつけないこと。

::example 超過なのに「雑損」になる ― 試験で最も狙われるパターン
期中に、現金の実際有高が帳簿残高より5,000円多かったため、現金過不足で処理していた。決算日に調べたところ、受取手数料8,000円の入金と、旅費交通費2,000円の支払いの記入漏れが判明した。残額は原因不明である。
::answer
::journal 期中（超過の発見）
現金 5,000 | 現金過不足 5,000
::
::journal 決算日
現金過不足 5,000 | 受取手数料 8,000
旅費交通費 2,000 |
雑損 1,000 |
::
考え方は「まず判明した原因を正しく仕訳し、最後に差額を埋める」。
- 現金過不足（貸方残高5,000円）をゼロにするため、借方に5,000円
- 受取手数料の記入漏れ → 収益の発生なので貸方に8,000円
- 旅費交通費の記入漏れ → 費用の発生なので借方に2,000円
- この時点で借方7,000円、貸方8,000円。差額1,000円を借方に入れて一致させる。借方に来る差額は費用なので**雑損**
現金全体は「超過」だったのに、原因を調べたら、説明できない「不足」が1,000円残った。超過＝雑益と決めつけず、必ず貸借差額で判断しよう。
::trap
現金過不足が借方と貸方のどちらに残っているかを、最初に確かめること。超過を見つけたときは**貸方**に記録しているので、決算では借方に書いて消す。
雑損か雑益かは、暗記ではなく、最後に残った貸借の差額がどちら側に来るかで決める。
::
::
::

**③ 受け取ったのは現金ではなかった**　キャッシュレス決済が増えた今、レジの打ち間違いが現金過不足の原因になることが多い。原因が分かったら、現金過不足を本来の勘定に振り替える。

::example キャッシュレス時代の現金過不足 ― カード払いを「現金」で打っていた
6月5日の深夜、出町柳店のレジ締めで、現金の実際有高が帳簿残高より4,800円少なかった。原因が分からないため、現金過不足で処理した。
翌日、POSの記録とカード会社の売上明細を照らし合わせたところ、ある客のカード払い4,800円を、アルバイトが誤って「現金」のボタンで会計していたことが判明した（カード会社への手数料は考えない）。
::answer
::journal 6月5日　不足を発見した（帳簿の現金を実際有高に合わせる）
現金過不足 4,800 | 現金 4,800
::
::journal 6月6日　原因が判明した（本当はカード会社から後で受け取る代金だった）
クレジット売掛金 4,800 | 現金過不足 4,800
::
レジで「現金」を押したので、帳簿には「現金 4,800／売上 4,800」と記録されていた。売上そのものは正しいが、受け取ったのは現金ではなく、カード会社から後日入金される権利（**クレジット売掛金**、第7章）だった。だから判明したときは、預けておいた現金過不足を、本来の勘定であるクレジット売掛金に振り替える。
支払い手段が増えるほど、「お金は受け取ったが、現金ではなかった」というズレが増える。レジ締めでは、現金だけでなく、カード・QRコード・電子マネーの決済額も、決済会社の明細と突き合わせるのが今の常識だ。
::trap
原因が分かったときに、売上をもう一度計上してはいけない。売上は6月5日のレジですでに記録されている。
直すのは「何で受け取ったか」だけだ。現金過不足を消して、正しい受取手段（クレジット売掛金）に振り替える。
::
::
::

**④ 決算日当日に見つかった**　原因を調べる時間がないので、現金過不足を通さずに直接、雑損・雑益とする。

::point メモ ― 決算日当日にズレが見つかったら
決算日に現金の実際有高を確認してズレが見つかり、原因が分からない場合は、現金過不足を使わずに、直接「雑損」または「雑益」で処理する。原因を調べる時間がもう残っていないからだ。
::

::journal 決算日に、現金の実際有高が帳簿残高より1,500円多いことが判明し、原因は不明だった
現金 1,500 | 雑益 1,500
::

## 「書き換え」はしない ― ズレは記録して追う

6月の終わり、岩井が本部にやって来た。
岩井：「正直に言います。800円くらいの違いなら、その日の売上を打ち直せば済むと思っていました」
佐伯：「それをすると、ズレがあったという事実そのものが消えます。事実が消えれば、誰も調べません」

::danger 帳簿を「現金に合わせて書き換える」という誘惑
ズレを消すために売上を打ち直すのは、**記録の改ざん**だ。毎月少しずつ現金を抜く不正があっても、売上を書き換えれば帳簿の上では何も起きていないように見えてしまう。現金過不足は、ズレを「なかったこと」にしないための勘定である。
::

佐伯は、店の経費をレジから出すのをやめ、レジ締めを2人で行うルールを全店に広げた。人の誠実さに頼らず、間違いや不正が起きにくい仕組みを作ることを**内部統制**という（試験には直接出ないが、現金過不足を記録する目的はここにある）。

::real 不正の多くは「通報」と「違和感」で見つかる
公認不正検査士協会（ACFE）の2024年の報告書によると、職場の不正の約9割は現金や商品などの**資産の横領**で、発見のきっかけの最多は同僚や取引先からの**通報（43%）**だった。東京商工リサーチの集計では、2025年度に不適切な会計を開示した上場企業41件のうち、8件が従業員などによる着服横領だった。
::note
出典：[ACFE「Occupational Fraud 2024」の概要](https://cshco.com/insights/breaking-down-the-acfes-latest-fraud-report)、[LOGISTICS TODAY（2026年4月20日、東京商工リサーチの調査）](https://www.logi-today.com/941190)
::
::

::cfo 決算日に、原因不明の不足が3,000円残った ― 何を手がかりに追うか
3月31日。出町柳店の現金過不足に、原因の分からない不足が3,000円残っている。決算ではルールどおり雑損にする。佐伯は、原因を追うかどうかと、追うなら何から手をつけるかを、ひよりに任せた。
**前提**
- 出町柳店の現金過不足は、この1年、月に数百円の不足と超過が交互に出る程度だった
- 今月は不足が3回。すべて木曜の23時台のレジ締め。不足額は800円、1,000円、1,200円
- 木曜の23時台は、カード払いが多い大学の部活の団体客が来る時間帯でもある
**考えるときの視点**
- 「同じ曜日・同じ時間帯」という偏りから、どんな原因が考えられるか
- 人を疑う前に、記録で確かめられることは何か
::choice A. 金額が小さく、決算にも影響しないので、追わずに雑損で終える
**△ 処理としては正しいが、偏りを見逃している。**1年間で初めて、同じ曜日の同じ時間帯に3回続いた。偶然とは言いにくい。
::
::choice B. 木曜の23時台に入っていたアルバイトのシフトを確かめ、共通する人がいないかを見る
**○ 記録を使っている点はよいが、人から先に絞ろうとしている。**同じ人がいたとしても、それだけで原因とは言えない。もう1つの前提、団体客のカード払いを先に確かめたい。
::
::choice C. 木曜の23時台の会計を、POSの記録とカード会社の明細で1件ずつ突き合わせる
**◎ 前提の「団体客のカード払い」から、最もありそうな原因を記録で確かめている。**第3章の4,800円と同じく、カード払いを「現金」で打った誤りなら、明細との突き合わせで見つかる。人を疑う前に、まず打ち間違いの可能性をつぶす。
::
::choice D. 来月から木曜の夜のレジ締めを2人で行い、不足が止まるかを見る
**○ 仕組みの手当てとしては有効だが、今月の原因はわからないままだ。**止まれば数え間違いだったと推測はできるが、打ち間違いなら2人で数えても止まらない。
::
::answer 考え方の例を見る
- **偏りに注目する**：金額の大小より、曜日・時間帯・担当の偏りが原因の手がかりになる
- **ありそうな原因から確かめる**：前提（団体客・カード払い）から、最もありそうな原因（打ち間違い）を先に記録で確かめる
- **人は最後**：記録で説明できる原因をつぶしてから、人の問題を考える
::
::

::exam 現金・現金過不足の急所
- **他人振出小切手を受け取ったら「現金」**。自己振出小切手（自社が振り出した小切手）が戻ってきたら「当座預金」。この区別は頻出。
- 郵便切手は現金ではない。購入時は「通信費」、収入印紙は「租税公課」。
- 現金過不足は、まず「現金を実際有高に合わせる」。不足なら貸方に現金、超過なら借方に現金。
- 決算で原因不明の残額は、貸借差額が借方なら雑損、貸方なら雑益。超過＝雑益と決めつけない。
- 決算日に発見したズレは、現金過不足を使わず直接、雑損・雑益へ。
- 現金過不足勘定は、決算整理後の試算表や貸借対照表には残らない。
::

::next 預金にも「ズレ」は起きる ― 銀行勘定調整表
2級では、帳簿上の当座預金残高と銀行の残高証明書のズレを調べる**銀行勘定調整表**を学ぶ。「小切手を振り出したが、相手がまだ銀行に持ち込んでいない」といった時間差がズレの原因になる。現金過不足と同じく、ズレを記録し、原因を突き止める発想だ。
::

::summary
- 簿記の「現金」は、通貨＋通貨代用証券（他人振出小切手、送金小切手、郵便為替証書、配当金領収証、期限到来の公社債利札）
- 自己振出小切手は当座預金、切手は通信費、収入印紙は租税公課。現金と混同しない
- 現金出納帳は、現金の入出金を時系列で詳しく記録する補助簿
- 現金のズレは、まず帳簿を実際有高に合わせ、差額を「現金過不足」に仮置きする
- 原因が判明したら本来の勘定へ振り替え、決算日まで不明なら雑損・雑益へ。最後の差額は貸借差額で判断する
- ズレは消さずに記録する。人を疑う前に、仕組み（内部統制）を疑う
::
