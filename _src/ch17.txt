10月の月末。鴨川会計事務所の2階で、ひよりは青ざめていた。
消費税の一件のあと、麺屋とりの巣は、毎月の記帳を事務所に任せることにした。電話口で、鳥羽はこう言った。
鳥羽：「数字のことは、大川さんに全部任せる。あんたが一番、うちの店のことを分かってくれとるからな」
担当は、ひより。初めて1人で受け持った顧問先だ。その月次の**残高試算表**を作ったところ、借方の合計と貸方の合計が一致しない。差額は**9,000円**。貸方のほうが少ない。
5店舗の1か月分の仕訳は約1,000件。ひよりは、仕訳帳と総勘定元帳を1行ずつ突き合わせ始めた。一ノ瀬は出張で東京にいる。夜10時を過ぎても、原因は見つからない。終電がなくなり、ひよりは事務所のソファで朝を迎えた。
翌朝、いつもより早く出てきた鴨川所長は、机に突っ伏したひよりと、差額のメモを見比べた。
鴨川：「徹夜か。……9,000円か」
ひより：「すみません。まだ、3分の1しか確かめられてなくて」
鴨川：「9で割り切れるな。数字の並びが逆になっとるとこを探してみ。たぶん、クレジット売掛金の貸方や」
ひより：「え？」
5分後、所長の言葉どおりの場所から、ミスが見つかった。
なぜ所長は、差額を見ただけで、ミスの種類と場所まで言い当てられたのか？
::

## 試算表 ― 帳簿の「健康診断」

鴨川は、給湯室で湯を沸かし、湯のみを2つ持って戻ってきた。
鴨川：「合わへんかったんは、災難やない。合わへんと教えてくれるのが、この表の仕事や」
ひよりは、自分が一晩にらみ続けた表を見た。
ひより：「この表って、そもそも何のために作るんですか。元帳があれば、残高は分かりますよね」
鴨川：「元帳は、勘定ごとにページが分かれとる。全部の勘定を1枚に並べてみんと、左と右が本当に合っとるかは分からん。総勘定元帳の全部の勘定を、1枚に集めた表。それが**試算表**（しさんひょう）や」
鴨川：「仕事は2つある。1つは、記録の間違いを見つけること。もう1つは、会社の今の姿を、1枚で見せることや」

::table 試算表の2つの目的
| 目的 | 内容 |
| ①記録の検証 | 貸借平均の原理により、借方合計と貸方合計は必ず一致する。一致しなければ、仕訳や転記のどこかに誤りがある |
| ②全体像の把握 | すべての勘定の残高が1枚にまとまるので、月末や期末の時点の財産と損益の状況が一目で分かる。決算の出発点にもなる |
::

鴨川：「仕訳は、左と右が必ず同じ金額や。それを元帳に写すんやから、全部の勘定の左を足したもんと、右を足したもんは、必ず同じになる。合わへんかったら、どこかで写し間違えとる。帳簿の健康診断やな」

## 試算表の3つの形

鴨川：「大川さんが作ったんは、残高試算表やな。探しものをするときは、もう1つの形のほうが便利なことがある」
ひより：「形が、いくつもあるんですか」
鴨川：「3つある。集める数字が違うだけや」

::table 試算表の種類
| 種類 | 集める金額 | 特徴 |
| 合計試算表 | 各勘定の借方合計と貸方合計 | 取引の総量が分かる。転記の検証に向く |
| 残高試算表 | 各勘定の残高（借方残高または貸方残高） | 財産と損益の状態が分かる。決算で使う |
| 合計残高試算表 | 合計と残高の両方 | 両方の情報を1枚で示す |
::

鴨川は、本棚からアイアンワークスのファイルを出した。
鴨川：「見本を見せよか。IRONWORKS 24の京都本店、4月末の分や」

ひより：「残高の列、資産と費用は左、負債と純資産と収益は右に出てます」
鴨川：「第1章で習うた、ホームポジションそのままや」

::theory 残高は「ホームポジション」側に出る
残高試算表を見ると、資産（現金・備品など）と費用（給料・支払家賃など）は**借方残高**、負債（未払金・借入金）・純資産（資本金など）・収益（売上）は**貸方残高**になっている。第1章で学んだ5要素のホームポジションそのものだ。
そして、残高試算表の借方合計と貸方合計が一致するということは、次の式が成り立つことを意味する。
==資産 ＋ 費用 ＝ 負債 ＋ 純資産 ＋ 収益==
これを**試算表等式**という。両辺から費用を移せば「資産＝負債＋純資産＋（収益－費用）」。つまり、残高試算表の中には、貸借対照表と損益計算書が、まだ分かれる前の姿で詰まっているのだ。
::

::boxes 残高試算表の構造（IRONWORKS 24 京都本店・4月30日）

L a 83 資産<br>8,370,000円

::

::point 評価勘定は貸方残高
貸倒引当金（第11章）と減価償却累計額（第12章）は、資産のマイナスを表す評価勘定なので、試算表では**貸方残高**として記入する。資産だからといって借方に書かないよう注意しよう。
::

## 試算表の作り方

鴨川は、ひよりの表を裏返した。
鴨川：「もういっぺん、最初から作ってみ。今度は、わしが横で見とく」
手順は3つだけだった。ひよりは、所長の視線を感じながら、1つずつ手を動かした。

::steps 試算表を作成する手順
総勘定元帳の各勘定の借方合計・貸方合計を計算する | 前月繰越（期首の残高）も忘れずに含める
合計試算表に記入する | 各勘定の借方合計・貸方合計をそのまま写す
残高を計算する | 借方合計と貸方合計の差額を、大きいほうの側に記入する
縦に合計し、貸借の一致を確かめる | 合計試算表・残高試算表それぞれで、借方合計＝貸方合計になっているか検算する
::

## 答え合わせ ― 差額は、ミスの「指紋」を残している

鴨川：「さて、なんで9で割ったか、やな」
ひより：「はい。ずっと気になってました」
鴨川：「差額には、ミスの指紋が残っとるんや。差額と同じ金額の取引があったら、片方の転記漏れ。差額の半分の取引があったら、左右を逆に書いた。そして、9で割り切れたら――」
ひより：「数字の並びの、入れ替え？」
鴨川：「せや。98,000を89,000と書いたら、差はいくつや」
ひより：「9,000。……あ」

::solve 差額9,000円が「9で割り切れる」ことの意味
所長が使ったのは、試算表の差額からミスの種類を推理する、経理のプロの定石だ。

::table 差額からミスを推理する3つの定石
| 差額の特徴 | 疑われるミス | 例 |
| 差額そのものの金額の取引がある | 一方の側への転記漏れ | 借方に9,000円を転記し忘れた |
| 差額の半分の金額の取引がある | 貸借を逆に転記した | 借方に転記すべき4,500円を貸方に転記した（差額は2倍の9,000円になる） |
| 差額が9で割り切れる | 数字の並びの入れ替え・桁違い | 98,000円を89,000円と転記した、1,000円を10,000円と転記した |
::
数字の並び（隣り合う桁）を入れ替えたり、桁を1つずらしたりした誤りでは、正しい金額と誤った金額の差が、**必ず9の倍数**になる。たとえば98,000と89,000の差は9,000、1,000と10,000の差も9,000だ。
差額が9,000円で、貸方のほうが少ない。だから所長は、「貸方に、本来より9,000円少なく転記された金額がある。おそらく数字の入れ替えだ」と推理した。そして、カード会社からの入金が月末にまとまって届く、クレジット売掛金の貸方から探すよう言ったのだ。
実際、カード会社から振り込まれたクレジット売掛金98,000円の仕訳は正しく記録されていたが、クレジット売掛金勘定の貸方に転記する際に、ひよりは**89,000円**と数字の並びを逆にして書き写していた。カード会社の入金明細から手で転記した、1行だけの誤りだった。
1,000件の仕訳を総当たりで調べる前に、差額という「指紋」から容疑者を絞り込む。これが、プロとアマチュアの差である。
::

鴨川：「わしも若いころ、同じことで2晩、徹夜した」
所長は、湯のみを両手で包んで笑った。
鴨川：「2晩目の朝に、先輩が『9で割ってみい』と教えてくれた。それから40年、この割り算だけは忘れたことがない」
ひよりは、自分のノートの表紙の裏に、大きく「÷9」と書いた。

## 試算表では見つからない誤り

所長は、最後にもう1つ付け加えた。
鴨川：「ただな、合う試算表のほうが、怖いこともある」
ひより：「合っているのに、ですか」
鴨川：「取引を丸ごと書き忘れたら、左にも右にも載らん。合計は合う。勘定科目を間違えても、金額が同じなら合う。おかわり堂さんの横領も、試算表は3年間、毎月ぴったり合うとった」
ひよりは、丹波青果の請求書の束を思い出した。

::table 試算表で発見できない誤り
| 誤りの種類 | 例 | 発見できない理由 |
| 仕訳そのものの記録漏れ | 取引を1件まるごと記録し忘れた | 借方にも貸方にも記録がないので、貸借はそろう |
| 仕訳の二重記録 | 同じ取引を2回記録した | 借方も貸方も同額ずつ多くなる |
| 勘定科目の誤り | 未払金とすべきところを買掛金で記録した | 金額は正しく、貸借はそろう |
| 貸借逆の仕訳 | 「現金／売上」を「売上／現金」と記録した | 借方・貸方の合計はそれぞれ同額のまま |
| 貸借両方の同じ金額の誤り | 98,000円の取引を、仕訳の段階で89,000円と記録した | 借方も貸方も同じように少なくなる |
| 誤りの相殺 | 借方で1,000円多く、別の借方で1,000円少なく転記した | 誤りが打ち消し合う |
::

::danger 「合っている試算表」が、会社を欺く
第16章の横領事件を思い出してほしい。架空の仕入代金は、「仕入／普通預金」という完全に貸借の一致した仕訳で記録されていた。試算表は、3年間、毎月ぴたりと一致していた。
試算表が保証するのは「貸借が一致していること」だけで、「記録された取引が真実であること」ではない。
さらに危険なのが、試算表の差額が見つからないときに、その差額を「雑損」などに放り込んで無理やり一致させる処理だ。原因不明の差額を埋めた試算表は、見た目は健全でも、中に誤りを抱えたままになる。そして、埋められた差額の陰に、もっと大きな誤りや不正が隠れていることもある。差額は「埋めるもの」ではなく「突き止めるもの」だ。
::

::real 上場企業は、決算日から約40日で数字を外に出している
東京証券取引所の集計によると、2023年3月期に決算を迎えた上場会社2,280社が、決算の内容を発表するまでにかかった日数は、平均**40.2日**だった。最も多かった発表日は5月12日で、807社（35.4%）がこの日に発表している。
40日のあいだに、何千、何万という取引の記録を締め、決算整理を行い、監査を受け、財務諸表を完成させる。それができるのは、毎月の試算表を速く正確に出す仕組みが、1年中回っているからだ。月次の数字が1か月遅れる会社には、年度の決算を40日でまとめることはできない。

**この章の道具で読む ― 40日で締めるために、試算表を「何度も」作る**
上場会社の経理では、決算の途中で試算表を何度も作り直す。たとえば、こんな順番だ。

::steps 決算日から決算発表までの試算表（流れの一例）
決算日の数日後 | 期中の取引をすべて記録し終えた試算表を作る。貸借の一致と、前月・前年同月との増減を確かめる
2週間前後 | 減価償却・貸倒引当金・売上原価・経過勘定などの決算整理を反映し、決算整理後の試算表を作る（第18章）
3〜4週間 | 監査人の確認で見つかった修正を反映して、試算表を作り直す
約40日 | 確定した試算表から財務諸表を作り、決算を発表する
::
どの段階でも、最初に確かめるのは「貸借が一致しているか」だ。差額が出れば、この章の定石で原因を絞り込む。試算表を1回作るのに何日もかかっていたら、40日では到底間に合わない。ひよりが一晩かけた9,000円の差額を、所長が5分で見つけたことの意味は、ここにある。
::note
出典：[税務研究会「東証 2023年3月期決算発表、平均所要日数は40.2日」（2023年6月19日）](https://www.zeiken.co.jp/keieizaimu/article/no3609/ZA00036091001.php)
::
::

::cfo 月次の数字は、何日で出すべきか ― 気づくまでの時間を「お金」に換算する
おかわり堂では、これまで月次の試算表が完成するのは、翌月の25日ごろだった。第5章の牛肉の在庫の件で痛い目を見た大森は、こう言った。「月末から1か月近くたってから数字を見ても、手遅れだ」
その相談の場には、ひよりも同席していた。徹夜の翌週のことだ。佐伯は、去年1年間に起きた「気づくのが遅れた問題」を4つ挙げた。どれも、気づいた翌日から手を打てば止められる種類のものだった。
- ア　新店での仕込みすぎによる食材の廃棄（食材費の数字で気づける）
- イ　牛肉の仕入値の上昇と、値上げの判断の遅れ（食材費の数字で気づける）
- ウ　深夜帯のシフトの組みすぎによる人件費の増加（試算表でしか気づけない）
- エ　仕入先の請求ミスによる二重払い（試算表でしか気づけない）
数字を速く出すには、データの自動取込みなどの費用がかかる。逆に、四半期にまとめれば経理の作業は減る。次の視点で考えてから選んでほしい。
- 問題に**気づくまでの時間**は、数字の出し方でどう変わるか。その間、損失は積み上がり続ける
- 4つの問題は、**どの数字で**気づけるか。すべてを同じ速さで見る必要はあるか
- 速くするための**費用**は、早く気づくことで防げる損失に見合うか
::choice A. 今のまま翌月25日に出す。月次の数字こそ、正確さを最優先する
**× 正確だが、遅すぎる。**仮の設定（下の「考え方の例」）では、4つの問題の損失は合計で月250万円。気づくまで約1.8か月かかるので、損失は250万円×1.8＝**450万円**。月次の数字は、多少の見積りを含んでいても、経営の判断には十分役に立つ。完璧な数字を待つあいだに、損失は積み上がっていく。
::
::choice B. 試算表を翌月5営業日以内に出す
**○ 確実に良くなるが、それだけでは最善ではない。**仮の設定では、損失は250万円×1.25＝312.5万円、費用50万円と合わせて**約363万円**。Aより約90万円少ない。ただ、食材費の問題（ア・イ）は、試算表を待たなくても毎日の数字で気づける。そこにまで1.25か月かかるのは、もったいない。
::
::choice C. 四半期ごとにまとめて作り、その分じっくり検証する
**× 最も高くつく。**仮の設定では、損失は250万円×3.8＝950万円で、費用の節約30万円を差し引いても**約920万円**。銀行や株主への報告が四半期ごとでも、経営の計器盤は毎月、それも速く見なければならない。
::
::choice D. 試算表は翌月25日のままにし、店舗ごとの売上と食材費だけ毎日速報を出す
**○ 安くて効果が大きいが、見えない穴が残る。**仮の設定では、食材費の問題（ア・イ、月140万円）は約0.1か月で気づき、損失は14万円。だが人件費と二重払い（ウ・エ、月110万円）は約1.8か月かかり、198万円。費用30万円と合わせて**約242万円**。Bよりずっと良いが、試算表でしか見えない問題が、相変わらず約2か月遅れでしか見えない。
::
::choice E. 毎日の速報（D）と、5営業日以内の試算表（B）を組み合わせる
**◎ 問題の種類ごとに、最も速く気づける道具を当てる。**仮の設定では、食材費の問題は速報で約0.1か月（損失14万円）、人件費と二重払いは試算表で約1.25か月（損失137.5万円）。費用80万円と合わせて**約232万円**で、5つの案の中で最も小さい。
費用はDより50万円多いが、試算表を速くすることで、ウ・エの損失が約60万円減る。差はわずかに見えても、来年どんな種類の問題が起きるかは分からない。速報と試算表の2つの計器を持っておくことに価値がある。
::
::answer 考え方の例を見る
**仮の設定**で試算してみよう。どの問題も月初に始まり、1年に1回ずつ起きるとする。
::table 去年起きた問題と、毎月の損失
| 問題 | 毎月の損失 | 何で気づけるか |
| ア　新店での仕込みすぎによる食材の廃棄 | 80万円 | 食材費の数字 |
| イ　牛肉の仕入値の上昇（値上げの判断の遅れ） | 60万円 | 食材費の数字 |
| ウ　深夜帯のシフトの組みすぎによる人件費の増加 | 60万円 | 試算表（人件費） |
| エ　仕入先の請求ミスによる二重払い | 50万円 | 試算表（買掛金と支払いの照合） |
::
::table 数字の出し方と、気づくまでの時間・1年あたりの費用
| 数字の出し方 | 気づくまでの時間 | 1年あたりの費用 |
| 試算表を翌月25日に出す（今のまま） | 約1.8か月 | 0円 |
| 試算表を翌月5営業日以内に出す（データの自動取込み・見積りによる計上） | 約1.25か月 | 50万円 |
| 試算表を四半期ごとにまとめて出す | 約3.8か月 | △30万円（経理の作業が減る） |
| 店舗ごとの売上と食材費だけ、毎日速報を出す | 食材費の問題は約0.1か月。それ以外は試算表しだい | 30万円 |
::
::table 1年あたりの「気づくまでの損失」と「仕組みの費用」（単位：万円）
| 案 | 食材費の問題（ア・イ） | 試算表で見つかる問題（ウ・エ） | 仕組みの費用 | 合計 |
| A　翌月25日 | 252 | 198 | 0 | 450 |
| B　翌月5営業日 | 175 | 137.5 | 50 | 約363 |
| C　四半期ごと | 532 | 418 | △30 | 920 |
| D　毎日の速報のみ | 14 | 198 | 30 | 242 |
| E　速報＋5営業日 | 14 | 137.5 | 80 | 約232 |
::
この問題から、経営の数字を設計するときの3つの原則が見えてくる。
- **数字の価値は、正確さと速さの掛け算で決まる**：気づくのが1か月遅れれば、その間の損失がそのまま積み上がる。
- **問題の種類ごとに、見るべき数字と速さを変える**：食材費のように毎日動く数字は毎日、人件費や支払いのように試算表でしか見えない数字は月次で。すべてを同じ速さで見る必要はない。
- **仕組みの費用と、防げる損失を比べる**：速くするには費用がかかる。その費用が、気づくのが早くなることで防げる損失より小さければ、導入する価値がある。
**さらに考えよう：速く出した数字が、間違っていたら？**
5営業日で出すために見積りを使えば、月次の数字には誤差が入る。仮に、食材費の見積りの誤差で「廃棄が増えた」と誤って判断し、仕込みを減らしすぎて品切れを起こせば、それも損失になる。だから実務では、速報の数字に**どれくらいの誤差があるか**を確かめ、誤差より大きな変化だけに反応するルールを決めておく。速さを上げるほど、誤差の管理が大切になる。
目標は「**翌月5営業日以内**」の月次決算と、毎日の速報の組み合わせだ。そのための施策をまとめるとこうなる。
- **日次で記帳する**：POSレジや銀行の入出金データを、会計ソフトに毎日自動で取り込む。
- **締め日のルールを決める**：店舗からの請求書・納品書の提出期限を明確にする。
- **見積りを許容する**：月末に確定しない費用は合理的な見積額で計上し、確定後に差額を調整する。
- **月次の決算整理を行う**：主要食材の月末在庫を数え、減価償却費や賞与の月割額も毎月計上する（第18章）。
- **差額を放置しない**：試算表の差額や現金過不足は、その月のうちに原因を突き止める。
速く正確な月次決算は、経営の「計器盤」だ。計器盤の数字が1か月遅れていたら、どんな名パイロットでも墜落を避けられない。
::
::

::exam 試算表の急所
- 第2問・第3問で、期中の取引（または月初の残高と当月の取引）から合計試算表・残高試算表を作成させる問題が出る。取引を仕訳し、勘定ごとに集計する。T字勘定のメモを手早く書く練習をしよう。
- 残高は、資産・費用が借方、負債・純資産・収益が貸方。ただし貸倒引当金・減価償却累計額は貸方残高。
- 必ず最後に「借方合計＝貸方合計」を検算する。一致しないときは、差額から原因を推理する（差額そのもの・半分・9の倍数）。
- 試算表で発見できない誤り（記録漏れ・二重記録・勘定科目の誤り・貸借逆の仕訳など）を問う語群選択の問題もある。
::

::next 試算表から、精算表、そして連結精算表へ
次の第18章では、残高試算表を出発点に、決算整理を加えて損益計算書と貸借対照表を作る**精算表**を学ぶ。2級では、親会社と子会社の試算表を合算し、グループ内の取引を消去してグループ全体の決算書を作る**連結精算表**を学ぶ。
実務の世界では、試算表は**月次決算**と**予算実績管理**の土台になる。各店舗・各部門の月次の試算表を予算と比べ、差異の原因を分析して次の手を打つ。銀行や外部の専門家が会社の状況を知るために最初に求める資料の1つが、この月次の試算表である。数字の健康診断を、毎月、速く、正確に。それが強い会社の共通点だ。
::

::problem 次の誤りを、試算表の作成によって発見できるものと、発見できないものに分類しなさい。
::sort
@cats 試算表で発見できる | 試算表では発見できない
商品を掛けで売り上げた取引の仕訳を、まるごと記録し忘れた => 試算表では発見できない
買掛金の支払い50,000円を、買掛金勘定の借方に5,000円と転記した => 試算表で発見できる
備品の購入代金の後払いを、未払金ではなく買掛金で仕訳した => 試算表では発見できない
同じ仕入取引を、2回仕訳して転記した => 試算表では発見できない
::
::answer
発見できるのは「買掛金の支払い50,000円を、借方に5,000円と転記した」誤りだけ。
借方だけが45,000円少なくなるので、試算表の貸借が一致しなくなる。差額45,000円は9で割り切れる（桁違いのミス）。ほかの3つは、貸借の金額がそろったままなので発見できない。
::
::
::problem 残高試算表の貸借差額が3,600円（貸方のほうが少ない）だった。考えられる原因を、差額の推理の定石を使って2つ挙げなさい。
::answer
例：
- 貸方に転記すべき3,600円の転記漏れ（差額そのもの）
- 貸方に転記すべき1,800円を、借方に転記した（差額の半分）
- 数字の入れ替え・桁違い（3,600は9で割り切れる）。たとえば、貸方に4,000円と転記すべきところを400円と転記した（差額3,600円）
::

::summary
- 試算表は、総勘定元帳の全勘定を1枚に集めた表。記録の検証と全体像の把握が目的
- 合計試算表・残高試算表・合計残高試算表の3種類がある。残高は、資産・費用が借方、負債・純資産・収益が貸方（評価勘定は貸方）
- 試算表等式：資産＋費用＝負債＋純資産＋収益
- 貸借が一致しないときは、差額そのもの・差額の半分・9の倍数から、ミスの種類を推理する
- 記録漏れ・二重記録・勘定科目の誤り・貸借逆の仕訳などは、試算表では発見できない
- 差額は埋めるものではなく、突き止めるもの。月次の試算表は、速く正確に出すことで経営判断に役立つ
::
