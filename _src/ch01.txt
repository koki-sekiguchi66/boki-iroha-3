::mystery 口座に1億円ある会社と、1,000万円しかない会社。「豊か」なのはどっちだ？
4月1日。大川ひよりが鴨川会計事務所の正式な職員になったその日、東京で、1つの会社が生まれた。
朝6時、新宿の高速バスターミナル。夜行便から降りたばかりのひよりと一ノ瀬を、背の高い女性が出迎えた。夜行高速バス会社「ナイトオウル交通」の社長、三國遥。航空会社の運航管理で15年働き、この日、自分の会社を立ち上げた。京都に営業所を置く縁で、設立の準備から鴨川会計事務所が顧問を務めている。
三國：「ようこそ、創業の日へ。口座には**1億円**。業界紙の記者には『うちは1億円の会社です』と言っておきました」
三國は、刷り上がったばかりの名刺を2人に差し出した。同じ東京―京都線を走るライバル「ブルーナイト・エクスプレス」の口座残高は、わずか**1,000万円**だという。
三國：「ブルーナイトさんとは、10年後に並ぶつもりでした。でも、お金だけなら、今日でもう10倍です」
ひよりは素直に感心した。1億円。父の店が最後に足りなかった300万円の、30倍以上だ。
その週の金曜日、三國は2台目以降のバスの資金を相談しに、メインバンクの京和銀行・新宿支店を訪ねた。顧問として、一ノ瀬とひよりも同席した。融資担当の村井は、ブルーナイトが官報に載せている決算公告の写しを机に置き、言いにくそうに切り出した。
村井：「正直に申し上げて、豊かなのは、圧倒的にブルーナイトさんのほうです」
三國の笑顔が固まった。
三國：「……口座は、うちの10分の1ですよ？」
村井：「ええ。それでも、です」
ひよりは、思わず一ノ瀬の横顔を見た。一ノ瀬だけが、驚いていなかった。
口座残高が10分の1の会社のほうが、なぜ「豊か」なのか？
::

## 紙ナプキンのメガネ ― 資産・負債・純資産

銀行からの帰り道、新宿の喫茶店。三國が次の約束に向かったあと、ひよりはアイスコーヒーのストローを回しながら聞いた。
ひより：「1億円あるのに、どうして豊かじゃないんですか。村井さん、ちょっと失礼じゃありませんでした？」
一ノ瀬：「失礼ではありません。正確でした」
一ノ瀬は紙ナプキンを1枚取り、真ん中に縦線を1本引いた。
一ノ瀬：「会社の財産を見るときは、メガネを3つ使います。1つ目は『持っているもの』。2つ目は『返さなければならないもの』。3つ目は『差し引いて、本当に自分のものとして残るもの』です」
ひより：「持っているもの、返すもの、残るもの」
一ノ瀬：「簿記では、それぞれ**資産**、**負債**、**純資産**と呼びます」

::table 財産を見る3つのメガネ
| 要素 | ひとことで言うと | 具体例（勘定科目） |
| 資産 | 会社が持っている「プラスの財産」 | 現金、普通預金、売掛金、商品、建物、車両運搬具、土地、貸付金 |
| 負債 | 将来お金を払わなければならない「マイナスの財産」 | 借入金、買掛金、未払金 |
| 純資産 | 資産から負債を引いた「正味の財産」。株主のもの | 資本金、繰越利益剰余金 |
::

ひより：「資産って、お金のことですか」
一ノ瀬：「お金も入りますが、それだけではありません。売ればお金になる商品、あとで代金をもらえる権利、お金を稼ぐために使うバスや建物。全部、資産です」
ひより：「じゃあ、負債は借金」
一ノ瀬：「銀行からの借金が代表です。まだ払っていない仕入代金も負債になります。そして純資産は、資産から負債を引いた残り。もし今日、会社がすべての資産を売り払って借金を全部返したら、手元に残るはずの財産です。それは会社の持ち主、つまり**株主**のものです」

::point 「勘定科目」とは何か
「現金」「借入金」「資本金」のように、財産や取引の内容を表す決まった名前を**勘定科目**（かんじょうかもく）という。簿記では、すべての記録をこの勘定科目を使って行う。3級で使う勘定科目は約80種類。本書では登場するたびに1つずつ紹介し、巻末の「付録A」に一覧をまとめている。
::

## ナイトオウル交通の「設立初日」を解剖する

一ノ瀬：「では、三國さんの1億円の正体を見てみましょう」
一ノ瀬は、設立の書類の控えを鞄から出した。登記のために事務所が作った書類だ。
一ノ瀬：「この1億円は、どこから来ましたか」
ひよりは書類をめくった。
ひより：「三國さんと仲間の出資が3,000万円。銀行からの借入れが7,000万円……あ」
一ノ瀬：「そう。半分以上は、借りたお金です」

::case ナイトオウル交通株式会社 ― 設立初日（4月1日）
創業者が自分の貯金と仲間からの出資で**3,000万円**を払い込み、株式会社を設立した。さらに、夜行バス2台の購入資金として、メインバンクから**7,000万円**を借り入れた。その結果、口座には1億円が入っている。
::

一ノ瀬は、紙ナプキンの縦線の左右に、数字を書き込んだ。

::boxes ナイトオウル交通の財産状態（設立初日）
H 資産（お金の使いみち） | 負債・純資産（お金の出どころ）
L a 100 普通預金<br>1億円
R l 70 借入金<br>7,000万円
R e 30 資本金<br>3,000万円
::

ひより：「左と右、同じ1億円になってますね」
一ノ瀬：「必ずそうなります。これがいちばん大事な式です」

::formula 貸借対照表等式
資産 ＝ 負債 ＋ 純資産
1億円 ＝ 7,000万円 ＋ 3,000万円
::

一ノ瀬：「右側は、お金を『どこから集めたか』。銀行から借りたのか、株主から出してもらったのか。左側は、集めたお金を『いま何に使っているか』。今日はまだ全額が預金のままですが、来月バスを買えば、左側の1億円は『バス』に姿を変えます」
ひより：「同じお金を、出どころと使いみちの両方から見てるから、左右が一致するんですね」
一ノ瀬は、少しだけ笑った。
一ノ瀬：「今の一言が言えたら、この章の半分は終わりです」

::theory 右は「出どころ」、左は「使いみち」
貸借対照表の右側（負債・純資産）は資金の調達源泉、左側（資産）は資金の運用形態を表す。同じお金を「どこから来たか」と「どこにあるか」の2方向から見ているのだから、左右の合計は**必ず一致する**。
この「同じものを2つの側面から記録する」という発想が、次章で学ぶ**複式簿記**の核心である。
::

## 答え合わせ ― 「正味の財産」で比べる

一ノ瀬は、村井から借りてきた決算公告のコピーを紙ナプキンの横に並べた。
一ノ瀬：「ブルーナイトは創業10年目です。昔買ったバス3台の借金は、もう全部返し終わっています。2社を同じメガネで並べてみてください」
ひよりは、ナプキンの裏に表を書いた。

::table 2社の財産を比較する（同じ日の時点）
| 項目 | ナイトオウル交通 | ブルーナイト |
| 現金・預金 | 1億円 | 1,000万円 |
| バス（車両運搬具） | 0円 | 9,000万円 |
|= 資産合計 | 1億円 | 1億円 |
| 借入金 | 7,000万円 | 0円 |
|= 純資産（資産－負債） | 3,000万円 | 1億円 |
::

ひよりのペンが止まった。資産の合計は、どちらも1億円。違うのは、その下の行だった。

::solve なぜ「1,000万円の会社」のほうが豊かなのか
答えは**純資産**だ。
ナイトオウル交通の口座にある1億円のうち、7,000万円は銀行から借りたお金にすぎない。いずれ利息をつけて返さなければならない。本当に会社のもの（＝株主のもの）と言えるのは、資産1億円から負債7,000万円を引いた**3,000万円**だけだ。
一方のブルーナイトは、現金こそ1,000万円しかないが、借金ゼロでバス3台を所有している。正味の財産は**1億円**。ナイトオウルの3倍以上だ。
==「お金を持っている」ことと「豊かである」ことは違う。==銀行が見ていたのは口座残高ではなく、資産から負債を引いた純資産だったのである。
::

ひよりは紙ナプキンを見つめた。父の店も、最後の年には、口座にまとまったお金が入っていたことがある。銀行から借りた4,000万円だ。
ひより：「父は、あれを『店のお金』だと思ってたのかもしれません」
一ノ瀬：「口座の中では、借りたお金も、稼いだお金も、同じ顔をしていますからね。メガネをかけないと、見分けがつかないんです」


## 貸借対照表（B/S）― ある「瞬間」を切り取った写真

事務所に戻ると、一ノ瀬はひよりに最初の宿題を出した。
一ノ瀬：「紙ナプキンの図を、正式な形に清書してください。顧問先に渡す書類の形で」
ひより：「正式な形って、どんな形ですか」
一ノ瀬：「**貸借対照表**（たいしゃくたいしょうひょう）です。英語では Balance Sheet、略して B/S。ある日の財産の状態を写した『写真』だと思ってください。何を持っていて、誰にいくら返す義務があって、正味でいくら残るのか。それが1枚でわかります」

| 資産 | 金額 | 負債・純資産 | 金額 |
| 普通預金 | 100,000,000 | 借入金 | 70,000,000 |
|  |  | 資本金 | 30,000,000 |
|= 合計 | 100,000,000 | 合計 | 100,000,000 |
::

## 収益と費用 ― 1年間を記録した「動画」

設立したナイトオウル交通は、すぐにバス2台（合計1億円）を購入し、東京と京都を結ぶ夜行便の運行を始めた。乗客から運賃を受け取り、運転士に給料を払い、軽油を買って走る。
月次巡回で東京の本社を訪ねるたびに、ひよりは同じことを聞かれた。
三國：「で、今月は儲かってるの？」
ひよりは、清書した貸借対照表を見せようとして、手を止めた。写真には、儲かったかどうかは写っていない。帰りの新幹線で一ノ瀬に聞くと、答えはすぐに返ってきた。
一ノ瀬：「写真の次は、動画です。1年間に、何で稼いで、何に使ったか。それを見るためのメガネが、あと2つあります」

::table 会社の活動を見る2つのメガネ
| 要素 | ひとことで言うと | 具体例（勘定科目） |
| 収益 | 純資産を増やす原因（稼ぎ） | 売上、受取手数料、受取利息、受取家賃 |
| 費用 | 純資産を減らす原因（稼ぐための犠牲） | 給料、支払家賃、支払利息、減価償却費、水道光熱費 |
::

一ノ瀬：「稼ぎが**収益**、稼ぐために使ったものが**費用**です。バス会社の運賃も、簿記では『売上』という収益になります。運転士の給料や軽油の代金、銀行への利息は費用です」
ひより：「収益から費用を引いたら、儲け」
一ノ瀬：「それを**当期純利益**と呼びます」

::formula 損益計算書等式
収益 － 費用 ＝ 当期純利益
（費用が収益を上回れば、当期純損失）
::

一ノ瀬：「1年間の収益と費用をまとめた表を、**損益計算書**といいます。英語では P/L。貸借対照表が写真なら、こちらは1年分の動画です」

::table ナイトオウル交通の損益計算書（第1期：4月1日〜翌年3月31日）
| 費用 | 金額 | 収益 | 金額 |
| 給料 | 60,000,000 | 売上 | 180,000,000 |
| 燃料費 | 32,000,000 |  |  |
| 支払手数料 | 28,000,000 |  |  |
| 減価償却費 | 20,000,000 |  |  |
| 保険料・修繕費など | 17,900,000 |  |  |
| 支払利息 | 2,100,000 |  |  |
|= 当期純利益 | 20,000,000 |  |  |
|= 合計 | 180,000,000 | 合計 | 180,000,000 |
::

::note
※支払手数料は、高速道路の通行料や予約サイトへの手数料。減価償却費は、バスの価値の目減り分を費用にしたもの（第12章）。「燃料費」のように、会社は自社の事業に合った勘定科目を設定できる。試験では、問題文で指定された勘定科目を使うこと。※法人税などの税金は第14章で扱うため、ここでは省略している。
::

ひより：「利益が、費用と同じ左側に書いてあります。儲けなのに、どうして費用の側なんですか」
一ノ瀬：「利益は『収益のうち、費用に使われずに残った分』です。だから、費用と並べて足すと、右の収益とぴったりそろうんです」

## 2枚の決算書は「当期純利益」でつながっている

1年後の4月。ひよりは一ノ瀬と並んで、ナイトオウル交通の第1期の決算書を仕上げていた。損益計算書の当期純利益は2,000万円。続けて貸借対照表を組み上げたとき、ひよりは手を止めた。

::table ナイトオウル交通の貸借対照表（第1期末・3月31日）
| 資産 | 金額 | 負債・純資産 | 金額 |
| 普通預金 | 40,000,000 | 借入金 | 70,000,000 |
| 車両運搬具 | 80,000,000 | 資本金 | 30,000,000 |
|  |  | 繰越利益剰余金 | 20,000,000 |
|= 合計 | 120,000,000 | 合計 | 120,000,000 |
::

::note
※車両運搬具は、購入額1億円から1年分の価値の目減り（減価償却費）2,000万円を差し引いた金額。繰越利益剰余金は、会社が稼いだ利益の蓄積を表す純資産の勘定科目（第13章）。
::

ひより：「一ノ瀬さん、これ……純資産が、設立のときより2,000万円増えてます」
一ノ瀬：「損益計算書の利益は、いくらでしたか」
ひより：「2,000万円です。同じ数字だ」
一ノ瀬：「偶然ではありません。1年間で稼いだ利益の分だけ、株主の取り分が増えた。写真と動画は、利益の行でつながっているんです」

::boxes 期首から期末へ ― 純資産は当期純利益の分だけ増える
H 期首の純資産 | 期末の純資産
L e 30 資本金<br>3,000万円
L z 20 （まだない）
R e 30 資本金<br>3,000万円
R p 20 繰越利益剰余金<br>2,000万円<br>＝当期純利益
::

::theory 財産法と損益法 ― 同じ利益を2つのルートで計算する
当期純利益は、2つの方法で計算できる。
**財産法**：期末の純資産 － 期首の純資産 ＝ 当期純利益（5,000万円 － 3,000万円 ＝ 2,000万円）
**損益法**：収益 － 費用 ＝ 当期純利益（1億8,000万円 － 1億6,000万円 ＝ 2,000万円）
財産法は「結果として財産がいくら増えたか」を、損益法は「なぜ増えたのか（何で稼ぎ、何に使ったか）」を示す。2つのルートの答えが必ず一致するのは、簿記がすべての取引を、財産の側面と原因の側面から**同時に**記録しているからだ。
つまり、貸借対照表は「いくら増えたか」を、損益計算書は「なぜ増えたか」を語っている。この2枚は、当期純利益という1本の糸で結ばれているのである。
::

::note
※財産法の式がそのまま使えるのは、期中に株式の発行（増資）や配当がない場合。増資や配当があるときは、その影響を除いて計算する（第13章）。
::

## 取引ごとに、5つの要素はどう動くか

一ノ瀬：「財産法と損益法の答えが一致するのは、なぜだと思いますか」
ひよりが答えに詰まると、一ノ瀬はナイトオウル交通の1年分の出来事を書き出した。
一ノ瀬：「1つずつ、5つの要素のどれが動いたか、書き込んでみてください。純資産が動く出来事と、動かない出来事を見分けるのが、この章でいちばん大切な練習です」

::table 第1期の出来事と、5つの要素の動き
| 出来事 | 資産 | 負債 | 純資産 | 損益計算書 |
| 株主から3,000万円の出資を受けた | 預金 ＋3,000万 |  | 資本金 ＋3,000万 | 載らない |
| 銀行から7,000万円を借りた | 預金 ＋7,000万 | 借入金 ＋7,000万 | 変わらない | 載らない |
| バス2台を1億円で買った | 車両 ＋1億、預金 △1億 |  | 変わらない | 載らない |
| 1年間の運賃1億8,000万円を受け取った | 預金 ＋1億8,000万 |  | ＋1億8,000万 | 収益（売上） |
| 運転士の給料6,000万円を払った | 預金 △6,000万 |  | △6,000万 | 費用（給料） |
| 銀行に利息210万円を払った | 預金 △210万 |  | △210万 | 費用（支払利息） |
| （例）借入金のうち1,000万円を返した | 預金 △1,000万 | 借入金 △1,000万 | 変わらない | 載らない |
::

表を埋め終えたひよりは、純資産の列を上から指でたどった。
ひより：「純資産が動いてるのは、出資と、売上と、費用のところだけです。お金を借りても、バスを買っても、純資産は動いてない」
一ノ瀬：「利息の行は？」
ひより：「利息は費用だから、純資産が減ってます。でも、元本の返済は……動いてない」
一ノ瀬：「序章のまんぷく食堂で、借入金の返済が利益に表れなかった理由が、これです」
ひよりは、ペンを置いた。父の店から毎月出ていった返済の数百万円は、利益計算のどこにも出てこなかった。その理由が、ようやく1行の表で分かった。

::point メモ ― 純資産を動かすもの、動かさないもの
- **純資産を動かすのは、株主との取引（出資・配当）と、収益・費用だけ**。
- 借入れ、返済、モノの購入は、資産と負債の「中身の入れ替え」にすぎず、純資産は1円も動かない。
- 利息の支払いは費用なので純資産を減らすが、元本の返済は純資産を減らさない。
::

## 会計期間 ― 成績は1年ごとに区切って計算する

ひより：「さっきから『第1期』って言ってますけど、会社って、1年ごとに生まれ変わるんですか」
一ノ瀬：「生まれ変わりはしませんが、成績は1年ごとに区切ってつけます。会社は何十年も続くので、区切らないと、いつまでも通知表が出ないんです。この区切りを**会計期間**といいます」

::table 会計期間に関する用語
| 用語 | 意味 |
| 期首 | 会計期間の初日（例：4月1日） |
| 期末（決算日） | 会計期間の最終日（例：3月31日） |
| 期中 | 期首から期末までの間 |
| 前期・当期・次期 | 前の会計期間・いまの会計期間・次の会計期間 |
| 決算 | 期末に帳簿を締めて、財務諸表を作成する手続き |
::

日本の会社は4月1日〜3月31日を会計期間とすることが多いが、12月決算や9月決算の会社もある。会社が自由に決められる。試験でも「会計期間は×1年4月1日から×2年3月31日まで」のように、問題文で指定される。

::danger 現金だけを見て、負債を見なかった経営者
ある中小企業の社長は、銀行から5,000万円の融資を受けた日、「今年は過去最高の資金力だ」と宣言し、高級な社用車と豪華な社員旅行にお金を使った。
だが、融資は会社の稼ぎではない。預金（資産）と借入金（負債）が同じだけ増えただけで、**純資産は1円も増えていない**。使い込めば資産だけが減り、負債は残る。こうして負債が資産を上回った状態を**債務超過**という。この社長の会社は3年後に債務超過に陥り、事業を手放すことになった。
::

::real 倒産した会社の7割は「債務超過」だった
東京商工リサーチが、2025年に倒産した企業のうち3期分の決算を確認できた794社を分析したところ、倒産直前の決算で**債務超過**だった会社は**71.1%**にのぼった。2期前は61.8%、1期前は66.6%。倒産に向かって、純資産のマイナスが年々広がっていた。
赤字で失った現金を借入金で埋め続けると、資産の合計はほとんど変わらないまま、負債だけが積み上がり、純資産は赤字の分だけ確実に減っていく（財産法）。そして、ある期に負債が資産を上回る。純資産がマイナスの会社には、銀行は新しくお金を貸しにくい。純資産は「会社の体力」であると同時に、「困ったときに貸してもらえる力」でもある。
株式会社には、決算のたびに貸借対照表を公告する義務がある（会社法440条）。村井が机に置いたのは、この決算公告だった。
::note
出典：[LOGISTICS TODAY「倒産企業の7割が債務超過、財務悪化が加速」（2026年4月2日、東京商工リサーチの調査）](https://www.logi-today.com/931446)
::
::

::scene 第2期の4月 ― 京和銀行・新宿支店
ひよりが清書した第1期の決算書を受け取った村井は、表情をゆるめた。
村井：「利益2,000万円。純資産は5,000万円になりましたね。設立のときは資産の3割だった自前の財産が、4割を超えました」
三國：「去年は『豊かなのはブルーナイトさん』と言われましたからね。少しは追いつきましたか」
村井：「ええ。追加で5,000万円、ご用意できます」
その場で融資が決まった。金利は年3%、5年で返済する。
ひよりは手帳に書いた。預金が5,000万円増えて、借入金も5,000万円増える。純資産は、1円も変わらない。お金を借りても、会社は1円も豊かにならないのだ。
::


::cfo 追加の資料を、1社にだけ頼めるなら
村井の机に、3つのバス会社から2,000万円（期間3年）の融資の申し込みが届いている。貸せるのは1社だけ。審査の期限までに、追加の資料を求められるのは1社に1種類だけだ。村井の今の見立ては「Z社が第一候補。X社は純資産が薄すぎる」。
**前提**
- 2,000万円を3年で返してもらうには、元金だけで年に約670万円の返済が要る
- X社：資産2億円、負債1億8,000万円（純資産2,000万円）。10年続けて、年1,000万円ほどの黒字。負債のうち1億2,000万円は、親会社からの借入
- Y社：資産8,000万円、負債2,000万円（純資産6,000万円）。年200万円ほどの黒字。資産のうち3,500万円は本社の土地
- Z社：資産1億円、負債6,000万円（純資産4,000万円）。前期は1,500万円の赤字、今期は月70万円ほどの黒字。月次の試算表は、顧問税理士が毎月確かめている
::choice A. Y社に、本社の土地を今売ったらいくらになるか、査定を求める
**△ 査定がどれほど高くても、Y社が年670万円を返せるようにはならない。**年200万円の黒字では、返済は土地を売らなければ終わらない。担保は返せなかったときの備えで、返す力の代わりにはならない。どんな結果でも、Y社は選ばれない。
::
::choice B. X社に、親会社からの借入の、返す期限と返す順番の取り決めを求める
**◎ 答えしだいで、最下位が1位に入れ替わる資料を選んでいる。**親会社が「ほかの借入をすべて返し終えるまで返済を求めない」と約束していれば、その1億2,000万円は、貸す側から見れば純資産に近い。そうならX社の守りは1億4,000万円で、10年続く年1,000万円の黒字は、返済の670万円を十分に上回る。取り決めがなくても、失うのは資料1枚分の時間だけだ。
::
::choice C. Z社に、今期の月次の試算表の、勘定ごとの明細を求める
**○ 第一候補を固める資料だが、すでに税理士が毎月確かめている数字だ。**明細を見ても新しく分かることは少なく、順位が動く見込みは小さい。
::
::choice D. Z社に、前期に赤字になった原因と、その後の手当ての説明を求める
**○ 大事な問いだが、今期の黒字（年に約840万円）はすでに確かめられている。**原因は面談で聞けば足りる。限られた1枚を使うほど、結論を動かす力はない。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「どの会社に貸すか」を今決める問いではない。「1枚の資料で、今の順位が入れ替わる可能性があるのはどこか」を探す問いだ。どんな答えが返ってきても結論が変わらない資料は、どれほど丁寧でも、判断の役に立たない。
#### 手順2　前提の数字で確かめる
まず、3社が「返せるか」を、年の返済670万円と比べる。
::table compact 3社の返す力（年の返済は約670万円）
| 会社 | 年の黒字 | 返済との差 |
| X社 | 約1,000万円 | ＋330万円 |
| Y社 | 約200万円 | △470万円 |
| Z社 | 約840万円 | ＋170万円 |
::
Z社の840万円は、今期の月70万円×12か月で見積もった。Y社は、純資産がどれほど厚くても、利益から返せない。返すには土地を売るしかなく、それは貸す前から回収を当てにした貸し方だ。次に、4つの資料それぞれについて、良い答えと悪い答えが返った場合を考える。
- **A Y社の土地の査定**：高くても安くても、年200万円の黒字で670万円は返せない。順位は**動かない**
- **B X社の親会社からの借入**：返す期限も順番も後回しと分かれば、X社が1位に上がる。順位が**動く**
- **C Z社の試算表の明細**：税理士が毎月確かめていて、悪い答えが出にくい。順位は**ほぼ動かない**
- **D Z社の赤字の原因**：今期の黒字は確かめ済みで、どんな説明でも見立ては変わりにくい。順位は**ほぼ動かない**
B の答えが良ければ、1億2,000万円の借入は「ほかの借入をすべて返し終えるまで返さなくてよいお金」になる。貸す側から見れば、返済の順番で銀行より後ろにいる出資者に近い。X社の守りは2,000万円＋1億2,000万円＝1億4,000万円になり、10年続く黒字と合わせて、最も安心できる貸し先に変わる。
#### 手順3　ほかの答えに引かれる理由
C と D は「第一候補を確かめておきたい」という自然な心理から来る。だが、すでに確かめられていることを重ねても、新しく分かることは少ない。A は「土地があれば安心」という感覚から来る。担保は、返せなかったときの後始末の道具で、返す力そのものではない。
#### 持ち帰る考え方
- **答えしだいで判断が変わる資料を選ぶ**：どんな答えでも結論が同じなら、その資料に価値はない
- **返す力と担保を分ける**：返済の元は利益。土地の値打ちは、返せなかったときの備えにすぎない
- **科目の名前より、中身を見る**：同じ「負債」でも、返す期限も順番も決まっていない借入は、貸す側には純資産に近い
#### 前提が変われば
Z社の試算表を誰も確かめていなければ、第一候補の土台そのものが不確かになる。そのときは C の価値が一気に上がる。「すでに確かめられているか」は、資料の価値を決める大事な前提だ。
::

::exam 5要素の分類と、財産法・損益法の計算
- 試験では、勘定科目が5要素のどれに当たるかを即答できることが大前提。特に「受取〜」は収益、「支払〜」は費用、「未払〜」「前受〜」「〜預り金」は負債、「未収〜」「前払〜」は資産、というパターンを押さえよう。
- ただし、このパターンには**例外**がある。!!受取手形は資産、支払手形は負債!!（手形という「証券」の名前で、利息や家賃のような損益ではない。第8章）。同じく「受取商品券」は資産、「貸倒引当金」は資産のマイナス（第11章）。語尾だけで判断せず、「お金をもらう権利か、払う義務か、稼ぎか、犠牲か」を考える習慣をつけよう。
- 財産法・損益法の計算問題は、第2問の空欄補充などで出題される。期首純資産・期末純資産・収益・費用のうち3つが分かれば、残り1つを逆算できるようにしておこう。
- 当期純損失が出た場合、損益計算書では当期純損失を**右側**（収益の側）に書いて左右を一致させる。
::

::next 貸借対照表は「会社の健康診断書」
2級以降では、貸借対照表から会社の安全性を分析する。たとえば**自己資本比率**（純資産÷資産合計）は、銀行が真っ先に見る指標だ。ナイトオウル交通は、設立初日の30%から第1期末には約42%に改善した。株主から見た収益力を表す**ROE**（当期純利益÷純資産）も、本章の5要素の組み合わせにすぎない。
::

::summary
- 資産は「持っている財産」、負債は「将来払う義務」、純資産は「資産－負債＝株主のもの」
- 貸借対照表（B/S）は、ある時点の資産・負債・純資産を示す「写真」。資産＝負債＋純資産
- B/Sの右側は「お金の出どころ」、左側は「お金の使いみち」。同じお金を2方向から見るので左右が一致する
- 収益は純資産を増やす原因、費用は減らす原因。損益計算書（P/L）は1年間の「動画」
- 当期純利益は、財産法（期末純資産－期首純資産）と損益法（収益－費用）で一致する
- ホームポジション：資産・費用は左（借方）、負債・純資産・収益は右（貸方）
- 借入れでは純資産は増えない。純資産を増やすのは「利益」と「株主からの出資」だけ
::
