::mystery 口座に1億円ある会社と、1,000万円しかない会社。「豊か」なのはどっちだ？
4月1日。大川ひよりが鴨川会計事務所の正式な職員になったその日、東京で、1つの会社が生まれた。
朝6時、新宿の高速バスターミナル。夜行便から降りたばかりのひよりと一ノ瀬を、背の高い女性が出迎えた。夜行高速バス会社「ナイトオウル交通」の社長、三國遥。航空会社の運航管理で15年働き、この日、自分の会社を立ち上げた。京都に営業所を置く縁で、設立の準備から鴨川会計事務所が顧問を務めている。
「口座には**1億円**。業界紙の記者には『うちは1億円の会社です』と言っておきました」。三國は刷り上がったばかりの名刺を2人に差し出した。同じ東京―京都線を走るライバル「ブルーナイト・エクスプレス」の口座残高は、わずか**1,000万円**だという。
ひよりは素直に感心した。1億円。父の店が最後に足りなかった300万円の、30倍以上だ。
その週の金曜日、三國は2台目以降のバスの資金を相談しに、メインバンクの京和銀行・新宿支店を訪ねた。顧問として、一ノ瀬とひよりも同席した。融資担当の村井は、ブルーナイトが官報に載せている決算公告の写しを机に置き、言いにくそうに切り出した。
「正直に申し上げて、豊かなのは、圧倒的にブルーナイトさんのほうです」
三國の笑顔が固まった。ひよりは、思わず一ノ瀬の横顔を見た。一ノ瀬だけが、驚いていなかった。
口座残高が10分の1の会社のほうが、なぜ「豊か」なのか？
::

## 会社の「財産」を3つに分ける ― 資産・負債・純資産

銀行からの帰り道、新宿の喫茶店。三國が次の約束に向かったあと、ひよりは一ノ瀬に聞いた。「1億円あるのに、どうして豊かじゃないんですか」
一ノ瀬は紙ナプキンを1枚取り、真ん中に縦線を1本引いた。「会社の財産を見るときは、メガネを3つ使います。1つ目は『持っているもの』、2つ目は『返さなければならないもの』、3つ目は『差し引いて、本当に自分のものとして残るもの』です」
簿記では、ある時点の会社の財産状態を、次の3つに分けて捉える。

::table 財産を見る3つのメガネ
| 要素 | ひとことで言うと | 具体例（勘定科目） |
| 資産 | 会社が持っている「プラスの財産」 | 現金、普通預金、売掛金、商品、建物、車両運搬具、土地、貸付金 |
| 負債 | 将来お金を払わなければならない「マイナスの財産」 | 借入金、買掛金、未払金 |
| 純資産 | 資産から負債を引いた「正味の財産」。株主のもの | 資本金、繰越利益剰余金 |
::

**資産**とは、会社が持っている財産だ。お金そのもの（現金・預金）だけでなく、将来お金に変わるもの（商品・売掛金）や、お金を稼ぐために使うもの（バス・建物）も含まれる。
**負債**とは、将来お金を払う義務だ。銀行から借りたお金（借入金）や、まだ払っていない仕入代金（買掛金）がその代表である。
**純資産**とは、資産から負債を差し引いた残りだ。もし今日、会社がすべての資産を売り払って借金をすべて返したら、手元に残るはずの財産。それは会社の持ち主である**株主**のものだ。

::point 「勘定科目」とは何か
「現金」「借入金」「資本金」のように、財産や取引の内容を表す決まった名前を**勘定科目**（かんじょうかもく）という。簿記では、すべての記録をこの勘定科目を使って行う。3級で使う勘定科目は約80種類。本書では登場するたびに1つずつ紹介し、巻末の「付録A」に一覧をまとめている。
::

## ナイトオウル交通の「設立初日」を解剖する

「では、三國さんの1億円の正体を見てみましょう」。一ノ瀬は、設立の書類の控えを鞄から出した。登記のために事務所が作った書類だ。
「この1億円は、どこから来ましたか」
ひよりは書類をめくった。「三國さんと仲間の出資が3,000万円。銀行からの借入れが7,000万円……あ」
「そう。半分以上は、借りたお金です」

::case ナイトオウル交通株式会社 ― 設立初日（4月1日）
創業者が自分の貯金と仲間からの出資で**3,000万円**を払い込み、株式会社を設立した。さらに、夜行バス2台の購入資金として、メインバンクから**7,000万円**を借り入れた。その結果、口座には1億円が入っている。
::

この状態を、簿記のメガネで見るとこうなる。

::boxes ナイトオウル交通の財産状態（設立初日）
H 資産（お金の使いみち） | 負債・純資産（お金の出どころ）
L a 100 普通預金<br>1億円
R l 70 借入金<br>7,000万円
R e 30 資本金<br>3,000万円
::

左側が**資産**、右側が**負債**と**純資産**。そして、左右の合計は必ず一致する。

::formula 貸借対照表等式
資産 ＝ 負債 ＋ 純資産
1億円 ＝ 7,000万円 ＋ 3,000万円
::

この図の読み方こそ、財務分析の出発点となる視点だ。
**右側は「お金をどこから集めたか（調達源泉）」**を表す。銀行から借りたのか（負債）、株主から出してもらったのか（純資産）。
**左側は「集めたお金を何に使っているか（運用形態）」**を表す。いまは全額が預金のままだが、バスを買えば「車両運搬具」に、燃料を買えば費用に姿を変えていく。

::theory 右は「出どころ」、左は「使いみち」
貸借対照表の右側（負債・純資産）は資金の調達源泉、左側（資産）は資金の運用形態を表す。同じお金を「どこから来たか」と「どこにあるか」の2方向から見ているのだから、左右の合計は**必ず一致する**。
この「同じものを2つの側面から記録する」という発想が、次章で学ぶ**複式簿記**の核心である。
::

## 答え合わせの準備 ― 「正味の財産」で比べる

一ノ瀬は、村井から借りてきた決算公告のコピーを紙ナプキンの横に並べた。ライバルのブルーナイト・エクスプレスは創業10年目。かつて買ったバス3台の借金は、すでに完済している。2社を同じメガネで並べると、こうなる。

::table 2社の財産を比較する（同じ日の時点）
| 項目 | ナイトオウル交通 | ブルーナイト |
| 現金・預金 | 1億円 | 1,000万円 |
| バス（車両運搬具） | 0円 | 9,000万円 |
|= 資産合計 | 1億円 | 1億円 |
| 借入金 | 7,000万円 | 0円 |
|= 純資産（資産－負債） | 3,000万円 | 1億円 |
::

::solve なぜ「1,000万円の会社」のほうが豊かなのか
答えは**純資産**だ。
ナイトオウル交通の口座にある1億円のうち、7,000万円は銀行から借りたお金にすぎない。いずれ利息をつけて返さなければならない。本当に会社のもの（＝株主のもの）と言えるのは、資産1億円から負債7,000万円を引いた**3,000万円**だけだ。
一方のブルーナイトは、現金こそ1,000万円しかないが、借金ゼロでバス3台を所有している。正味の財産は**1億円**。ナイトオウルの3倍以上だ。
==「お金を持っている」ことと「豊かである」ことは違う。==銀行が見ていたのは口座残高ではなく、資産から負債を引いた純資産だったのである。
::

ひよりは紙ナプキンを見つめた。父の店も、最後の年には、口座にまとまったお金が入っていたことがある。銀行から借りた4,000万円だ。あのとき父は、それを「店のお金」だと思っていたのかもしれない。

::scene 翌週 ― 京和銀行・新宿支店の応接室
融資の書類を届けに行ったひよりに、村井は1枚の紙を差し出した。「会計事務所の新人さんなら、ちょっと考えてみませんか。今週、私の机に来ている申し込みです。社名は伏せてありますが」
3つのバス会社の、貸借対照表の要点だった。

::

::cfo あなたが村井なら ― 2,000万円を貸すのは、どの会社か
村井の机には、3つのバス会社から2,000万円の融資の申し込みが届いている。どの会社も、来月に**800万円**の支払い（借入金の返済と給料）を控えている。今月の融資枠で貸せるのは1社だけだ。
::table 3社の決算書と、村井が調べた追加の情報（単位：万円）
| 項目 | X社 | Y社 | Z社 |
| 現金・預金 | 3,000 | 200 | 1,500 |
| バス（帳簿価額） | 5,000 | 9,800 | 6,000 |
| 借入金 | 9,000 | 1,000 | 4,000 |
| 当期純利益 | △600 | 300 | 500 |
| 減価償却費 | 1,000 | 1,400 | 1,200 |
| バスを今売ったときの値段（中古業者の査定） | 4,000 | 5,500 | 5,400 |
::
銀行の審査では、帳簿の数字をそのまま使わない。村井が使う物差しは次の3つだ。
- **実態純資産**：資産を「今売れる値段」に置き換えて計算した純資産
- **債務償還年数**：（借入金－現金・預金）÷（当期純利益＋減価償却費）。借金を、本業で生む現金で何年で返せるか。銀行の目安は**10年以内**
- **来月の支払い**：手元の現金で来月の800万円を払えるか
3つを計算してから選んでほしい。
::choice A. X社 ― 現金がいちばん多い
**× 3つの物差しのすべてで最悪。**帳簿の純資産は5,000＋3,000－9,000＝△1,000万円の**債務超過**で、バスを査定額で評価し直すと△2,000万円まで広がる。本業で生む現金は、純損失△600万円＋減価償却費1,000万円＝400万円。実質の借金6,000万円（9,000万円－3,000万円）を返すのに**15年**かかる。手元の現金は、借りたお金が残っているだけだ。
::
::choice B. Y社 ― 帳簿の純資産がいちばん大きい
**◎ 査定で割り引いても、返す力は群を抜く。**気になる点はある。バスの帳簿価額9,800万円に対して、査定は5,500万円しかない。耐用年数を実態より長く見積もって、減価償却費を小さくしている疑いもある。
だが、査定額で計算し直しても、実態純資産は200＋5,500－1,000＝**4,700万円**。債務償還年数は（1,000－200）÷（300＋1,400）＝**約0.5年**。弱点は、現金200万円では来月の800万円を払えないことだが、それは「体力はあるのに、手元のお金が一時的に足りない」状態で、融資がまさに役立つ場面だ。
::
::choice C. Z社 ― 利益がいちばん大きく、現金も十分
**○ 健全だが、いま貸す必要は薄い。**実態純資産は1,500＋5,400－4,000＝2,900万円、債務償還年数は（4,000－1,500）÷（500＋1,200）＝約1.5年。どの物差しでも合格だ。しかも現金1,500万円で来月の800万円も自力で払える。安心して貸せる相手ではあるが、Z社はそもそも困っていない。急ぎの融資が意味を持つのはY社のほうだ。
::
::choice D. Y社は、帳簿のバスが査定より4,300万円も高い。決算書を信用できないので、どこにも貸さない
**△ 疑いの持ち方は正しいが、結論が早すぎる。**帳簿価額と査定額の差に気づいたのは、審査担当として満点の観察だ。だが、差を全部差し引いても、Y社の実態純資産は4,700万円、債務償還年数は約0.5年。疑わしい部分を**数字で割り引いても結論が変わらない**なら、貸してよい。次にやるべきは、耐用年数の決め方を確かめ、次の決算から見直してもらうことだ（第12章）。
::
::answer 考え方の例を見る
::table 3社を3つの物差しで並べる（単位：万円）
| 項目 | X社 | Y社 | Z社 |
| 帳簿の純資産 | △1,000 | 9,000 | 3,500 |
| 実態純資産（バスを査定額で評価） | △2,000 | 4,700 | 2,900 |
| 本業で生む現金（純利益＋減価償却費） | 400 | 1,700 | 1,700 |
| 債務償還年数 | 15年 | 約0.5年 | 約1.5年 |
| 来月の800万円を自力で払えるか | 払える（借りたお金で） | 払えない | 払える |
::
銀行の審査は、3つの段階で決算書を読み替える。
- **純資産（体力）**：マイナスなら、どれだけ現金があっても危ない（X社）。
- **実態に引き直す**：帳簿の資産が「今いくらで売れるか」を確かめ、純資産を計算し直す。減価償却が不足していれば、ここで表面化する（Y社）。
- **返す力**：利益だけでなく、減価償却費というお金の出ていかない費用を足し戻して、本業で生む現金を測る（第12章）。
銀行が貸したいのは、体力がありながら一時的に血液（現金）が足りない会社だ。体力がマイナスの会社に血液を足しても、穴の空いたバケツに水を注ぐことになる。
ひよりが「Y社です。ただ、耐用年数は確認したいです」と答えると、村井は少し意外そうな顔をして、それから笑った。「現金の多いX社を選ぶ人が、いちばん多いんですよ。それに、後半の一言まで言える新人は珍しい」
::
::

## 貸借対照表（B/S）― ある「瞬間」を切り取った写真

事務所に戻ると、一ノ瀬はひよりに最初の宿題を出した。「紙ナプキンの図を、正式な形に清書してください。顧問先に渡す書類の形で」
資産・負債・純資産の状態を1枚の表にまとめたものを、**貸借対照表**（たいしゃくたいしょうひょう）という。英語では Balance Sheet、略して **B/S**（ビーエス）と呼ぶ。
貸借対照表は、ある特定の日（ふつうは決算日）の財産状態を写した「**写真**」のようなものだ。この会社が、その瞬間に何を持ち（資産）、誰にいくら返す義務があり（負債）、正味でいくらの財産があるのか（純資産）を一目で示す。

::table ナイトオウル交通の貸借対照表（設立初日・4月1日）
| 資産 | 金額 | 負債・純資産 | 金額 |
| 普通預金 | 100,000,000 | 借入金 | 70,000,000 |
|  |  | 資本金 | 30,000,000 |
|= 合計 | 100,000,000 | 合計 | 100,000,000 |
::

## 収益と費用 ― 1年間を記録した「動画」

設立したナイトオウル交通は、すぐにバス2台（合計1億円）を購入し、東京と京都を結ぶ夜行便の運行を始めた。乗客から運賃を受け取り、運転士に給料を払い、軽油を買って走る。
月次巡回で東京の本社を訪ねるたびに、ひよりは同じことを聞かれた。三國からだ。「で、今月は儲かってるの？」
その答えを出すには、貸借対照表とは別の、もう2つのメガネが要る。会社が活動するなかで**純資産を増やす原因**と**純資産を減らす原因**を、簿記では次のように呼ぶ。

::table 会社の活動を見る2つのメガネ
| 要素 | ひとことで言うと | 具体例（勘定科目） |
| 収益 | 純資産を増やす原因（稼ぎ） | 売上、受取手数料、受取利息、受取家賃 |
| 費用 | 純資産を減らす原因（稼ぐための犠牲） | 給料、支払家賃、支払利息、減価償却費、水道光熱費 |
::

**収益**とは、商品やサービスを提供した対価として得た「稼ぎ」だ。バス会社の運賃収入も、簿記では**売上**として記録する。
**費用**とは、収益を得るために使った「犠牲」だ。運転士の給料、燃料代、銀行への利息などがこれにあたる。
収益から費用を差し引いたものが、**当期純利益**だ。

::formula 損益計算書等式
収益 － 費用 ＝ 当期純利益
（費用が収益を上回れば、当期純損失）
::

1年間の収益と費用をまとめた表を**損益計算書**（そんえきけいさんしょ）という。英語では Profit and Loss Statement、略して **P/L**（ピーエル）だ。貸借対照表が「写真」なら、損益計算書は1年間の活動を記録した「**動画**」にあたる。

::table ナイトオウル交通の損益計算書（第1期：4月1日〜翌年3月31日）
| 費用 | 金額 | 収益 | 金額 |
| 給料 | 60,000,000 | 売上 | 180,000,000 |
| 燃料費 | 32,000,000 |  |  |
| 支払手数料 | 28,000,000 |  |  |
| 減価償却費 | 20,000,000 |  |  |
| 保険料・修繕費など | 17,900,000 |  |  |
| 支払利息 | 2,100,000 |  |  |
|= 当期純利益 | 20,000,000 |  |  |
|= 合計 | 180,000,000 | 合計 | 180,000,000 |
::

::note
※支払手数料は、高速道路の通行料や予約サイトへの手数料。減価償却費は、バスの価値の目減り分を費用にしたもの（第12章）。「燃料費」のように、会社は自社の事業に合った勘定科目を設定できる。試験では、問題文で指定された勘定科目を使うこと。※法人税などの税金は第14章で扱うため、ここでは省略している。
::

損益計算書は、左側に費用、右側に収益を書き、その差額である当期純利益を**左側**に書いて、左右の合計を一致させる。利益は「収益のうち、費用に使われずに残った部分」だから、費用と同じ側に並べると左右がそろう、と考えるとよい。

## 2枚の決算書は「当期純利益」でつながっている

1年後の4月。ひよりは一ノ瀬と並んで、ナイトオウル交通の第1期の決算書を仕上げていた。損益計算書の当期純利益は2,000万円。続けて貸借対照表を組み上げたとき、ひよりは手を止めた。純資産の欄に、見覚えのある数字が現れたからだ。
第1期の終わり（3月31日）、ナイトオウル交通の貸借対照表はこうなった。

::table ナイトオウル交通の貸借対照表（第1期末・3月31日）
| 資産 | 金額 | 負債・純資産 | 金額 |
| 普通預金 | 40,000,000 | 借入金 | 70,000,000 |
| 車両運搬具 | 80,000,000 | 資本金 | 30,000,000 |
|  |  | 繰越利益剰余金 | 20,000,000 |
|= 合計 | 120,000,000 | 合計 | 120,000,000 |
::

::note
※車両運搬具は、購入額1億円から1年分の価値の目減り（減価償却費）2,000万円を差し引いた金額。繰越利益剰余金は、会社が稼いだ利益の蓄積を表す純資産の勘定科目（第13章）。
::

純資産に注目してほしい。期首は資本金3,000万円だけだったのが、期末は資本金3,000万円＋繰越利益剰余金2,000万円＝**5,000万円**に増えている。
増えた2,000万円は、損益計算書の**当期純利益2,000万円**とぴったり一致する。これは偶然ではない。

::boxes 期首から期末へ ― 純資産は当期純利益の分だけ増える
H 期首の純資産 | 期末の純資産
L e 30 資本金<br>3,000万円
L z 20 （まだない）
R e 30 資本金<br>3,000万円
R p 20 繰越利益剰余金<br>2,000万円<br>＝当期純利益
::

::theory 財産法と損益法 ― 同じ利益を2つのルートで計算する
当期純利益は、2つの方法で計算できる。
**財産法**：期末の純資産 － 期首の純資産 ＝ 当期純利益（5,000万円 － 3,000万円 ＝ 2,000万円）
**損益法**：収益 － 費用 ＝ 当期純利益（1億8,000万円 － 1億6,000万円 ＝ 2,000万円）
財産法は「結果として財産がいくら増えたか」を、損益法は「なぜ増えたのか（何で稼ぎ、何に使ったか）」を示す。2つのルートの答えが必ず一致するのは、簿記がすべての取引を、財産の側面と原因の側面から**同時に**記録しているからだ。
つまり、貸借対照表は「いくら増えたか」を、損益計算書は「なぜ増えたか」を語っている。この2枚は、当期純利益という1本の糸で結ばれているのである。
::

::note
※財産法の式がそのまま使えるのは、期中に株式の発行（増資）や配当がない場合。増資や配当があるときは、その影響を除いて計算する（第13章）。
::

## 取引ごとに、5つの要素はどう動くか

「財産法と損益法の答えが一致するのは、なぜだと思いますか」と一ノ瀬は聞いた。ひよりが答えに詰まると、一ノ瀬はナイトオウル交通の1年分の出来事を書き出した。「1つずつ、5つの要素のどれが動いたか、書き込んでみてください」
純資産が動く取引と、動かない取引を見分けることが、この章のいちばん大切な練習だ。

::table 第1期の出来事と、5つの要素の動き
| 出来事 | 資産 | 負債 | 純資産 | 損益計算書 |
| 株主から3,000万円の出資を受けた | 預金 ＋3,000万 |  | 資本金 ＋3,000万 | 載らない |
| 銀行から7,000万円を借りた | 預金 ＋7,000万 | 借入金 ＋7,000万 | 変わらない | 載らない |
| バス2台を1億円で買った | 車両 ＋1億、預金 △1億 |  | 変わらない | 載らない |
| 1年間の運賃1億8,000万円を受け取った | 預金 ＋1億8,000万 |  | ＋1億8,000万 | 収益（売上） |
| 運転士の給料6,000万円を払った | 預金 △6,000万 |  | △6,000万 | 費用（給料） |
| 銀行に利息210万円を払った | 預金 △210万 |  | △210万 | 費用（支払利息） |
| （例）借入金のうち1,000万円を返した | 預金 △1,000万 | 借入金 △1,000万 | 変わらない | 載らない |
::

表から、はっきりした法則が読み取れる。
- **純資産を動かすのは、株主との取引（出資・配当）と、収益・費用だけ**。
- 借入れ、返済、モノの購入は、資産と負債の「中身の入れ替え」にすぎず、純資産は1円も動かない。
- 利息の支払いは費用なので純資産を減らすが、元本の返済は純資産を減らさない。序章のまんぷく食堂で、借入金の返済が利益に表れなかったのはこのためだ。

::boxes 5要素のホームポジション（左＝借方、右＝貸方）

::table 5要素のホームポジション一覧

## 会計期間 ― 成績は1年ごとに区切って計算する

会社は何十年も活動を続ける。そのままでは成績をつけられないので、簿記では活動を1年ずつに区切って計算する。この区切りを**会計期間**という。

::table 会計期間に関する用語
| 用語 | 意味 |
| 期首 | 会計期間の初日（例：4月1日） |
| 期末（決算日） | 会計期間の最終日（例：3月31日） |
| 期中 | 期首から期末までの間 |
| 前期・当期・次期 | 前の会計期間・いまの会計期間・次の会計期間 |
| 決算 | 期末に帳簿を締めて、財務諸表を作成する手続き |
::

日本の会社は4月1日〜3月31日を会計期間とすることが多いが、12月決算や9月決算の会社もある。会社が自由に決められる。試験でも「会計期間は×1年4月1日から×2年3月31日まで」のように、問題文で指定される。

::danger 現金だけを見て、負債を見なかった経営者
ある中小企業の社長は、銀行から5,000万円の融資を受けた日、社員を集めて「今年は過去最高の資金力だ」と宣言し、高級な社用車と豪華な社員旅行にお金を使った。
だが、融資は会社の稼ぎではない。預金（資産）が5,000万円増えたのと同時に、借入金（負債）も5,000万円増えただけで、**純資産は1円も増えていない**。それを使い込めば、資産だけが減り、負債は残る。
こうして負債が資産を上回った状態を**債務超過**という。純資産がマイナスになり、仮にすべての資産を売っても借金を返しきれない状態だ。債務超過の会社に、銀行は新たな融資をしない。上場企業であれば、上場廃止の基準にも抵触しうる。この社長の会社は、3年後に債務超過に陥り、事業を手放すことになった。
::

::real 倒産した会社の7割は「債務超過」だった
東京商工リサーチが、2025年に倒産した企業のうち3期分の決算を確認できた794社を分析したところ、倒産直前の決算で**債務超過**だった会社は**71.1%**にのぼった。2期前は61.8%、1期前は66.6%。倒産に向かって、純資産のマイナスが年々広がっていたことになる。
純資産がマイナスの会社には、銀行は新しくお金を貸しにくい。手元の現金が尽きたとき、助けを求める先がない。純資産は「会社の体力」であると同時に、「困ったときに貸してもらえる力」でもあるのだ。

**この章の道具で読む ― 純資産は、どうやってマイナスになるのか**
倒産した会社の多くは、ある日突然、債務超過になったわけではない。2期前、1期前と、純資産が少しずつ削られていった。その過程を、本章の式「期末の純資産＝期首の純資産＋当期純利益（－当期純損失）」で追ってみよう。数字は、仕組みを示すために簡略化した中小企業の例だ（単位：万円）。

::table 赤字が3年続いた会社の、純資産の動き
| 決算期 | 資産 | 負債（うち借入金） | 純資産 | 当期純損益 |
| 3期前 | 10,000 | 8,000（6,000） | 2,000 | ― |
| 2期前 | 9,800 | 8,600（6,800） | 1,200 | △800 |
| 1期前 | 9,500 | 9,100（7,600） | 400 | △800 |
| 最新期 | 9,200 | 9,700（8,400） | △500 | △900 |
::
資産の合計は、3年でほとんど変わっていない。変わったのは中身だ。赤字で失った現金を、そのつど借入金で埋めてきたから、負債だけが積み上がり、純資産は赤字の分だけ確実に減っていく（財産法）。そして最新期、ついに負債が資産を上回る。どれだけ現金が残っていても、この会社は「全部売っても借金を返しきれない」状態にある。
こうした変化は、他社の決算書でも確かめられる。株式会社には、決算のたびに貸借対照表（大会社は損益計算書も）を公告する義務がある（会社法440条）。官報や会社のWebサイトに載る「決算公告」を何年分か並べ、純資産の欄だけを追えば、取引先の体力が落ちていく様子がわかる。村井が机に置いたのは、この決算公告だった。
::note
出典：[LOGISTICS TODAY「倒産企業の7割が債務超過、財務悪化が加速」（2026年4月2日、東京商工リサーチの調査）](https://www.logi-today.com/931446)
::

::scene 第2期の4月 ― 京和銀行・新宿支店
ひよりが清書した第1期の決算書を受け取った村井は、表情をゆるめた。「利益2,000万円。純資産は5,000万円になりましたね。設立のときは資産の3割だった自前の財産が、4割を超えました」
その場で、追加で5,000万円の融資が決まった。金利は年3%、5年で返済する。
帰りの電車で、三國はスマートフォンのメモに使い道の候補を書き出し、隣のひよりに見せた。3台目のバス。いざというときの手元資金。前からの借入金の返済。そして、1年間走り抜いてくれた運転士たちへの賞与。
「大川さん、どれがいいと思う？」
ひよりは、紙ナプキンの図を思い出しながら、1つずつ純資産の動きを計算し始めた。
::

::cfo 融資5,000万円 ― 1年後の純資産と、手元のお金を同時に読む
三國の4つの案を、数字で比べよう。借入れの瞬間、純資産は1円も変わらない（預金と借入金が同じだけ増えるだけ）。差がつくのは、そのお金を何に変えるかだ。条件は次のとおり。
- 新しい借入れは5,000万円、年3%、5年で毎年1,000万円ずつ元本を返す（1年目の利息は150万円で計算する）
- 会社全体は黒字なので、利益が増えればその**30%**の税金が増え、利益が減れば税金も30%分減る。税金は同じ年に払うものとする
- 前からの借入金7,000万円は、毎月100万円ずつ返済中。この返済は、どの案でも変わらない
- バスを買う場合、第1期の実績では1台あたり運賃から運行費を引いて**年2,100万円**が残った。減価償却費は年1,000万円。ただし乗車率しだいで、残る金額は次のように変わると見込まれる
::table 3台目のバスで残る金額の見込み（運賃－運行費）
| 場合 | 確率 | 残る金額 |
| 第1期並みに好調 | 50% | 2,100万円 |
| 乗車率が3割落ちる | 30% | 1,470万円 |
| 乗車率が半分になる | 20% | 1,050万円 |
::
4つの案それぞれについて、**1年後の純資産の増減（税引後）と、手元の預金の増減（元本の返済後）**を計算してから選んでほしい。どの案でも、新しい借入れの利息150万円はかかる。
- **A　預金のまま置いておく**：預金の利息は年0.2%
- **B　3台目のバスを買う**
- **C　前からの借入金のうち5,000万円を返す**（金利は同じ3%）
- **D　1年目をがんばった社員に、賞与と社員旅行で5,000万円報いる**
::choice A. 預金のまま置いておく
**△ 手元のお金は最も多いが、純資産は減る。**受取利息10万円－支払利息150万円＝△140万円。税金が42万円減るので、純資産は**△98万円**。預金は、借りた5,000万円から元本1,000万円と純損失98万円を引いて**＋3,902万円**残る。
いざというときの備えにはなる。だが「何のために借りるのか」を決めないまま借りると、利息だけを払い続けることになる。
::
::choice B. 3台目のバスを買う
**◎ 期待値で最も純資産を増やす。しかも最悪の場合も小さな傷ですむ。**好調なら、2,100－1,000－150＝950万円の利益、税引後**665万円**。3割落ちても税引後224万円。半分になると△100万円の損失で、税金が減って税引後**△70万円**。期待値は665×50%＋224×30%＋（△70）×20%＝**約386万円**だ。
しかも、この案では減価償却費（1,000万円）と元本の返済（1,000万円）が同額なので、**預金の増減は税引後の利益とぴったり同じ**になる。最悪の場合でも預金の減少は70万円。「失敗しても会社が傾かない賭け」になっている。
::
::choice C. 前からの借入金を5,000万円返す
**× 純資産は変わらず、預金は1,000万円減る。**返した借入金の利息150万円が減り、新しい借入金の利息150万円が増えるので、利息も税金も変わらない。純資産の増減は**ゼロ**だ。ところが資金繰りは悪くなる。前の借入金の返済（毎月100万円）は残高が減っても続くうえに、新しい借入金の元本1,000万円の返済が加わるからだ。
借り換えに意味があるのは、金利が下がるときか、**返済期間が延びて毎年の返済額が減る**ときだ。どちらでもない借り換えは、返済を二重にするだけである。
::
::choice D. 賞与と社員旅行で報いる
**× 預金は増えたように見えるが、純資産が3,600万円消える。**賞与・旅行代5,000万円と利息150万円の費用は、税金を1,545万円減らす。預金だけ見れば5,000－5,000－150＋1,545－1,000＝**＋395万円**。ところが純資産は5,150万円×（1－30%）＝**約△3,605万円**。第1期末の純資産5,000万円が、ほとんど消える。
「税金が減るから実質の負担は7割」という説明は、経営者がよく聞かされる言葉だ。だが、借りたお金で費用を払えば、残るのは借入金だけである。社員に報いるなら、稼いだ利益の範囲で行うのが筋だ。
::
::answer 考え方の例を見る
::table 4つの案の比較（1年後、単位：万円）
| 案 | 純資産の増減（税引後） | 預金の増減（元本返済後） | 最悪の場合の純資産 |
| A　預金のまま | △98 | ＋3,902 | △98 |
| B　3台目のバス | 期待値＋386 | 期待値＋386 | △70 |
| C　前の借入金の返済 | 0 | △1,000 | 0 |
| D　賞与と社員旅行 | 約△3,605 | ＋395 | 約△3,605 |
::
借入れは、それだけでは純資産を1円も増やさない。純資産を増やす方法は、本質的に2つしかない。
- **利益を出す**（収益が費用を上回る）
- **株主から出資を受ける**（株式を発行する。第13章）
借りたお金が純資産を増やすのは、それを「利息と減価償却費を払っても利益を残すもの」に変えたときだけだ。そして実務では、期待値だけでなく**最悪の場合**も必ず計算する。期待値がプラスでも、最悪の場合に会社が傾く投資はしない。DやCのように「預金」だけ、「純資産」だけを見ると判断を誤る。2つの物差しを同時に使うことが、この章の決算書の読み方そのものだ。
三國は、3台目のバスを買うことにした。同時に、第1期に稼いだお金の一部は使わずに手元に残し、序章の教訓である「いざというときの現金」も確保した。ひよりが、まんぷく食堂の話をしたからだ。実務の判断は、たいていこうした組み合わせになる。

::exam 5要素の分類と、財産法・損益法の計算
- 試験では、勘定科目が5要素のどれに当たるかを即答できることが大前提。特に「受取〜」は収益、「支払〜」は費用、「未払〜」「前受〜」「〜預り金」は負債、「未収〜」「前払〜」は資産、というパターンを押さえよう。
- ただし、このパターンには**例外**がある。!!受取手形は資産、支払手形は負債!!（手形という「証券」の名前で、利息や家賃のような損益ではない。第8章）。同じく「受取商品券」は資産、「貸倒引当金」は資産のマイナス（第11章）。語尾だけで判断せず、「お金をもらう権利か、払う義務か、稼ぎか、犠牲か」を考える習慣をつけよう。
- 財産法・損益法の計算問題は、第2問の空欄補充などで出題される。期首純資産・期末純資産・収益・費用のうち3つが分かれば、残り1つを逆算できるようにしておこう。
- 当期純損失が出た場合、損益計算書では当期純損失を**右側**（収益の側）に書いて左右を一致させる。
::

::next 貸借対照表は「会社の健康診断書」
2級以降では、貸借対照表を「流動」と「固定」に分けて、会社の安全性を分析する。たとえば**自己資本比率**（純資産÷資産合計）は、銀行が真っ先に見る指標だ。
ナイトオウル交通の自己資本比率は、設立初日の30%（3,000万円÷1億円）から、第1期末には約42%（5,000万円÷1億2,000万円）に改善した。利益を積み上げることで、会社は「借金で回す会社」から「自分の足で立つ会社」へと変わっていく。
また、株主から見た収益力を表す**ROE**（自己資本利益率＝当期純利益÷純資産）は、上場企業の経営目標として頻繁に登場する。これらはすべて、本章で学んだ5要素の組み合わせにすぎない。
::

## 確認問題

::quiz
::problem 次の勘定科目を、資産・負債・純資産・収益・費用に分類しなさい。
::sort
@cats 資産 | 負債 | 純資産 | 収益 | 費用
現金 => 資産
借入金 => 負債
資本金 => 純資産
売上 => 収益
給料 => 費用
建物 => 資産
買掛金 => 負債
受取利息 => 収益
支払家賃 => 費用
売掛金 => 資産
繰越利益剰余金 => 純資産
支払利息 => 費用
::
::answer
::table
| 要素 | 勘定科目 |
| 資産 | 現金、建物、売掛金 |
| 負債 | 借入金、買掛金 |
| 純資産 | 資本金、繰越利益剰余金 |
| 収益 | 売上、受取利息 |
| 費用 | 給料、支払家賃、支払利息 |
::
「受取〜」は収益、「支払〜」は費用になるものが多い。売掛金（あとで代金を受け取る権利）は資産、買掛金（あとで代金を支払う義務）は負債。
::
::
::problem 財産法で当期純利益を求めなさい。
期首の資産は800万円、負債は300万円だった。期末の資産は1,000万円、負債は350万円だった。期中に増資や配当はなかった。
期首純資産 [[500]] 万円 → 期末純資産 [[650]] 万円 → 当期純利益 [[150]] 万円
::answer
期首純資産 ＝ 800万円 － 300万円 ＝ **500万円**
期末純資産 ＝ 1,000万円 － 350万円 ＝ **650万円**
当期純利益 ＝ 650万円 － 500万円 ＝ **150万円**
::
::
::problem 空欄を埋めなさい。
ある会社の当期の収益総額は5,000万円、費用総額は5,300万円だった。期首の純資産は2,000万円で、期中に増資や配当はなかった。当期純 [[ア:損失]] は [[イ:300]] 万円、期末の純資産は [[ウ:1,700]] 万円である。
<!-- choices: 利益 -->
::answer
費用が収益を上回っているので、（ア）**損失**。
（イ）5,000万円 － 5,300万円 ＝ △300万円 → 当期純損失 **300**万円
（ウ）2,000万円 － 300万円 ＝ **1,700**万円
純損失の分だけ、純資産は減る。
::
::
::problem 銀行から2,000万円を借り入れ、現金で受け取った。資産・負債・純資産はそれぞれどう変化するか。
資産：[[増加する]]　負債：[[増加する]]　純資産：[[変化しない]]
<!-- choices: 減少する -->
::answer
資産（現金）が2,000万円**増加**、負債（借入金）が2,000万円**増加**。純資産は**変化しない**。
借入れは「お金の出どころ」が負債であるだけで、正味の財産を増やすものではない。
::
::

::summary
- 資産は「持っている財産」、負債は「将来払う義務」、純資産は「資産－負債＝株主のもの」
- 貸借対照表（B/S）は、ある時点の資産・負債・純資産を示す「写真」。資産＝負債＋純資産
- B/Sの右側は「お金の出どころ」、左側は「お金の使いみち」。同じお金を2方向から見るので左右が一致する
- 収益は純資産を増やす原因、費用は減らす原因。損益計算書（P/L）は1年間の「動画」
- 当期純利益は、財産法（期末純資産－期首純資産）と損益法（収益－費用）で一致する
- ホームポジション：資産・費用は左（借方）、負債・純資産・収益は右（貸方）
- 借入れでは純資産は増えない。純資産を増やすのは「利益」と「株主からの出資」だけ
::
