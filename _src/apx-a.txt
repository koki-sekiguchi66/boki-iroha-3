## 使い方

- 各表は、5つの要素ごとに勘定科目を並べている。**ホームポジション**（増えたときに書く側）は、資産・費用が借方（左）、負債・純資産・収益が貸方（右）だ。
- {{new:2027年度〜}} は2027年4月以降の試験で3級に加わる予定の科目、{{old:2027年度〜範囲外}} は2027年4月以降の試験で出題範囲から外れる見込みの科目（いずれも2025年12月公表の暫定版による）。
- 試験では、問題文で指定された勘定科目を使うこと。同じ内容でも、問題によって科目名が違うことがある。

## まぎらわしい勘定科目の見分け方

::table 間違えやすいペア
| ペア | 見分け方 |
| 売掛金 と 未収入金 | 商品の代金なら売掛金、商品以外（備品・車両など）の代金なら未収入金 |
| 買掛金 と 未払金 | 商品の代金なら買掛金、商品以外の代金なら未払金 |
| 未払金 と 未払費用 | 個別の取引で確定した債務なら未払金、継続的なサービスの未払分（決算整理）なら未払費用 |
| 前受金 と 前受収益 | 商品・サービスの代金の前受けなら前受金、継続的なサービスの収益の繰延べ（決算整理）なら前受収益 |
| 前払金 と 前払費用 | 商品の手付金なら前払金、継続的なサービスの費用の繰延べ（決算整理）なら前払費用 |
| 仮受金 と 前受金 と 預り金 | 内容不明なら仮受金、商品代金の前受けなら前受金、他人のお金を預かったなら預り金 |
| 受取手形 と 手形貸付金 | 商品代金として受け取った手形なら受取手形、お金を貸して受け取った手形なら手形貸付金 |
| 現金 と 当座預金 | 他人振出の小切手を受け取ったら現金、自己振出の小切手が戻ってきたら当座預金 |
| 通信費 と 租税公課 と 貯蔵品 | 切手は通信費、収入印紙は租税公課。決算日に未使用なら貯蔵品 |
| 租税公課 と 法人税等 | 固定資産税・印紙税などは租税公課、利益にかかる税金は法人税、住民税及び事業税 |
| 貸倒損失 と 貸倒引当金 | 当期発生の債権の貸倒れは貸倒損失、前期以前の債権はまず貸倒引当金を取り崩す |
::
