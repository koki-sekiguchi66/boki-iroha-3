::mystery 同じ利益、正反対の運命
ある年、京都で創業した2つの会社が、そろって**1,000万円**の当期純利益を計上した。
1社は、飲食店向けに食材を卸す会社。もう1社は、24時間営業のフィットネスジム。業種は違うが、どちらも売上は伸び盛りで、利益の額もまったく同じだった。
5年後。ジムは新規店舗を次々と出し、株式市場への上場を果たした。一方、食材の卸売会社は、急成長の途中で資金が尽き、倒産した。
同じ年に、同じ利益を出した2社。損益計算書の最終行は、どちらも「1,000万円」だった。2社の運命を分けたものは、いったい何だったのか？
::

## 序章の問いを、もう一度解く

最終章の問いに挑む前に、序章に戻ろう。行列の絶えない定食屋「まんぷく食堂」は、なぜ黒字のまま倒産したのか。
序章を読んだときのあなたは、「利益と現金は違う」という言葉を、まだ実感をもって理解できなかったかもしれない。だが今のあなたは、その意味を勘定科目のレベルで説明できるはずだ。

::table まんぷく食堂の「お金の出口」を、勘定科目で説明する
| お金の出口 | 仕訳 | 利益への影響 | 学んだ章 |
| 新店の内装・厨房設備 | 建物・備品 ／ 普通預金 | 買った年は影響なし。減価償却で少しずつ費用に | 第12章 |
| 新店の保証金 | 差入保証金 ／ 普通預金 | 影響なし（資産のまま） | 第9章 |
| 借入金の元本返済 | 借入金 ／ 普通預金 | 影響なし（負債の減少） | 第9章 |
| 食材在庫の増加 | 仕入 ／ 買掛金など（期末に繰越商品へ） | 期末在庫は費用にならない | 第5章 |
| 法人税等の納付 | 未払法人税等 ／ 普通預金 | 前期に費用計上済み | 第14章 |
::

どの仕訳も、借方は費用ではなく、資産の増加か負債の減少だ。だから利益は減らない。しかし貸方は「普通預金」。お金は確実に出ていく。まんぷく食堂のオーナーに足りなかったのは、この仕訳の両側を同時に見る目だった。複式簿記とは、まさにその目のことなのだ。

## 第3の財務諸表 ― キャッシュ・フロー計算書

損益計算書は「利益」を、貸借対照表は「財産の状態」を表す。そして、1年間の「現金の増減」を、その原因別に表すのが、第3の財務諸表、**キャッシュ・フロー計算書**だ（本格的には1級で学ぶ）。
キャッシュ・フロー計算書は、現金の動きを3つに分けて示す。

::table キャッシュ・フロー計算書の3つの区分
| 区分 | 内容 | 主な例 |
| 営業活動によるキャッシュ・フロー | 本業で稼いだ（失った）現金 | 商品の販売・仕入、給料・経費の支払い、法人税等の支払い |
| 投資活動によるキャッシュ・フロー | 将来のための投資に使った（回収した）現金 | 固定資産の購入・売却、貸付けと回収 |
| 財務活動によるキャッシュ・フロー | 資金の調達と返済 | 借入れと返済、株式の発行、配当の支払い |
::

なかでも重要なのが、営業活動によるキャッシュ・フローだ。これは、当期純利益から出発して、「利益とお金のズレ」を調整する形で計算できる（**間接法**）。

::formula 営業活動によるキャッシュ・フロー（間接法・3級の知識で読める簡略版）
当期純利益
＋ 減価償却費（お金が出ていかない費用）
－ 売掛金などの増加（売れたが、まだ入金されていない）
－ 在庫の増加（お金が商品の形で眠っている）
＋ 買掛金などの増加（仕入れたが、まだ支払っていない）
＋ 前受金・前受収益の増加（サービス提供前に入金された）
::

どの項目も、あなたはすでに知っている。減価償却費は第12章、売掛金は第7章、在庫は第5章、前受収益は第15章で学んだ。キャッシュ・フロー計算書とは、本書で学んだ「利益と現金のズレ」を、1枚の表に整理したものにすぎない。

## 答え合わせ ― 運命を分けたのは「お金の流れ方」

::solve 2社の「第3の財務諸表」を並べてみる
同じ1,000万円の利益を出した年の、2社のキャッシュ・フローを比べてみよう（単位：万円、簡略化）。

::table sum 利益は同じ。キャッシュ・フローは正反対
| 項目 | 食材の卸売会社 | 24時間ジム |
| 当期純利益 | 1,000 | 1,000 |
| ＋ 減価償却費 | 200 | 1,500 |
| － 売掛金の増加 | △2,500 | 0 |
| － 在庫の増加 | △600 | 0 |
| ＋ 買掛金の増加 | 700 | 0 |
| ＋ 前受収益（年払い会費）の増加 | 0 | 900 |
|= 営業活動によるキャッシュ・フロー | △1,200 | 3,400 |
| 投資活動（冷蔵倉庫／新店のマシン） | △800 | △3,000 |
| 財務活動（短期の借入れ） | 2,000 | 0 |
|= 現金の増減 | 0 | 400 |
::
卸売会社は、売上が伸びるほど売掛金と在庫が膨らみ（第7章）、本業で現金を**失っていた**。利益は出ているのに、営業活動のキャッシュ・フローはマイナス1,200万円。足りない現金を、銀行からの短期の借入れで埋め続けていた。そして数年後、金利の上昇と取引先の貸倒れ（第11章）が重なり、銀行が追加の融資を断ったとき、会社は資金繰りに行き詰まった。
ジムは、会費を前払いで受け取り（第15章）、在庫も売掛金もほとんどない。高額なマシンの減価償却費（第12章）はお金が出ていかない費用だから、利益以上の現金が手元に残る。営業活動で生んだ3,400万円で、新店のマシン3,000万円を自分の力でまかない、借金に頼らずに成長を続けた。
2社の運命を分けたのは、利益の額ではない。**利益が、どんな形で手元に残るか**――つまり、ビジネスモデルが生み出すお金の流れ方だったのである。
::

H 1年間の動き（フロー） | 期末の状態（ストック）
L r 34 損益計算書<br>収益－費用＝当期純利益

::

損益計算書の当期純利益は、貸借対照表の繰越利益剰余金に流れ込む（第19章）。キャッシュ・フロー計算書の現金の増減は、貸借対照表の現金預金の変化と一致する。3枚の財務諸表は、複式簿記という1つのエンジンから生まれた、同じ会社の3つの顔なのだ。

::cfo 就職・転職・投資の前に、決算書のどこを見るか
あなたは、ある会社への転職を考えている（あるいは、その会社の株を買おうとしている）。決算書を手に入れた。限られた時間で、どこを見れば、その会社の「本当の姿」に近づけるだろうか？
::answer
本書の知識を使えば、次の5つの問いで、多くのことが分かる。
1. **売上は伸びているか、粗利率は保たれているか**（損益計算書）：売上の成長と、売上総利益率の推移を見る。売上が伸びても粗利率が下がり続けていれば、値下げで売上を買っている可能性がある（第5章）。
2. **利益と営業キャッシュ・フローは見合っているか**（キャッシュ・フロー計算書）：利益が出ているのに、営業活動のキャッシュ・フローが何年もマイナスなら要注意だ（終章）。
3. **売掛金と在庫は、売上以上に膨らんでいないか**（貸借対照表）：回収日数や在庫日数の悪化は、資金繰りの悪化や、時に粉飾のサインになる（第5・7章）。
4. **自己資本比率は十分か、債務超過ではないか**（貸借対照表）：借金に頼りすぎていないかを見る（第1章）。
5. **手元の現金預金と借入金のバランスはどうか**（貸借対照表）：借入金から現金預金を引いた「実質的な借金」が、稼ぐ力に比べて重すぎないかを見る。
決算書は、会社が世界に向けて出している、最も正直な手紙だ。読み方を知っている人にだけ、その手紙の行間が見える。

## この先の道 ― 2級・1級、そして実務へ

3級で手に入れたのは、簿記という**OS**だ。この上に、さらに強力なアプリケーションをインストールしていくことができる。

---

最後に、ひとつだけ伝えたい。
簿記は、過去の取引を記録する技術だ。だが、本書の21の問いが示したとおり、その記録は、会社の未来を左右する。黒字倒産も、粉飾も、連鎖倒産も、上場も――すべては、日々の仕訳の積み重ねの先にある。
経済のルールは、これからも変わり続ける。紙の手形は消え、決済は電子化され、AIが仕訳を自動で切る時代が来た。それでも、500年前にヴェネツィアの商人が手にした「左右に分けて記録する」という仕組みの価値は、少しも色あせていない。むしろ、数字があふれる時代だからこそ、その数字の意味を読み解ける人の価値は、ますます高まっていく。
あなたはもう、決算書を読める。
次は、その数字を自分の手で作り、より良く変えていく側に立つ番だ。

::summary 本書のまとめ
- 簿記は、会社の成績と財産を表す財務諸表を作り、読むための技術である
- 利益と現金は違う。その違いを生むのは、設備投資・在庫・売掛金・借入金・税金・前受けなどの「時間差」
- すべての取引を左右2つの側面から記録する複式簿記は、誤りと不正を見つけ、利益と財産を同時に計算する
- 決算整理は、お金の動きの記録を、発生主義にもとづく真実の利益へと翻訳する
- 損益計算書・貸借対照表・キャッシュ・フロー計算書は、1つの会社の3つの顔。必ずつなげて読む
- 3級は終点ではなく、2級・1級、そして経営の現場へと続く道の入口である
::
