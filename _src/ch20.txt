::mystery 貸してくれと頼んだ会社が倒れ、頼まなかった会社が上場した
2月。3級のネット試験を翌週に控えた夜、ひよりは京和銀行・新宿支店の応接室にいた。ナイトオウル交通の書類を届けた帰りに、村井に呼び止められたのだ。
村井：「試験前の大川さんに、ちょうどいい問題があります。少しだけ、時間をもらえますか」
京和銀行の村井には、新人研修で必ず配る2枚の紙がある。15年前、京都の本店で融資担当になったばかりの頃に受け持った、2つの会社の決算書だ。
村井：「1社は、飲食店に食材を卸す会社。もう1社は、24時間営業のフィットネスジム。その年、2社はそろって**1,000万円**の当期純利益を出しました。どちらも、売上は伸び盛りでした」
村井：「卸売会社の社長は、毎月のように支店に来ました。『注文が増えて、仕入れが追いつかない。3か月だけ、つなぎの資金を』。黒字で、売上も伸びている。断る理由は見当たりませんでした。私は張り切って稟議書を書いて、上司の判をもらいました」
ひより：「ジムのほうは？」
村井：「一度も、融資の相談に来ませんでした」
村井は、窓の外の新宿の灯りを見た。
村井：「5年後。ジムは新店を次々と出して、上場しました。卸売会社は、急成長の途中で資金が尽きて、倒産しました。私が稟議書を書いた融資の多くは、返ってきませんでした」
同じ年に、同じ利益。損益計算書の最終行は、どちらも「1,000万円」だった。2社の運命を分けたものは何だったのか。そして、若き日の村井は、決算書のどこを見落としていたのか？
村井は、1枚目の紙だけをひよりに渡した。
村井：「2枚目は、答えを聞いてからにしましょう」
::

## 序章の問いを、もう一度解く

1枚目の紙を見つめながら、ひよりは、1年あまり前の自分に戻っていた。百万遍の交差点。シャッターに貼られたA4の紙。「ずっと黒字やったんや」という父の声。
ひより：「村井さん。この卸売会社、私の父の店に似ています」
村井：「お父さんの？」
ひより：「黒字のまま、潰れました。去年の今ごろは、どうしてなのか、ひと言も説明できませんでした」
村井：「今は？」
ひより：「……書いてみてもいいですか」
あのときのひよりは、「利益と現金は違う」という一ノ瀬の言葉を、まだ実感をもって理解できなかった。だが今なら、その意味を勘定科目のレベルで説明できる。ひよりは、村井の紙の裏に、父の店の「お金の出口」を書き出していった。

::table まんぷく食堂の「お金の出口」を、勘定科目で説明する
| お金の出口 | 仕訳 | 利益への影響 | 学んだ章 |
| 新店の内装・厨房設備 | 建物・備品 ／ 普通預金 | 買った年は影響なし。減価償却で少しずつ費用に | 第12章 |
| 新店の保証金 | 差入保証金 ／ 普通預金 | 影響なし（資産のまま） | 第9章 |
| 借入金の元本返済 | 借入金 ／ 普通預金 | 影響なし（負債の減少） | 第9章 |
| 食材在庫の増加 | 仕入 ／ 買掛金など（期末に繰越商品へ） | 期末在庫は費用にならない | 第5章 |
| 法人税等の納付 | 未払法人税等 ／ 普通預金 | 前期に費用計上済み | 第14章 |
::

書き終えて、ひよりは気づいた。どの仕訳も、借方は費用ではなく、資産の増加か負債の減少だ。だから利益は減らない。しかし貸方は「普通預金」。お金は確実に出ていく。
ひより：「父に足りなかったのは、仕訳の両側を、同時に見る目でした」
村井：「複式簿記の目、ですね」

## 第3の財務諸表 ― キャッシュ・フロー計算書

村井：「では、その目で、卸売会社とジムを見てみましょう。銀行には、利益とお金のズレを1枚にまとめた表があります。**キャッシュ・フロー計算書**。3枚目の決算書です」
ひより：「3級では、まだ習っていません」
村井：「習っていなくても、読めますよ。中身は、大川さんがこの1年で全部見てきたことですから」

::table キャッシュ・フロー計算書の3つの区分
| 区分 | 内容 | 主な例 |
| 営業活動によるキャッシュ・フロー | 本業で稼いだ（失った）現金 | 商品の販売・仕入、給料・経費の支払い、法人税等の支払い |
| 投資活動によるキャッシュ・フロー | 将来のための投資に使った（回収した）現金 | 固定資産の購入・売却、貸付けと回収 |
| 財務活動によるキャッシュ・フロー | 資金の調達と返済 | 借入れと返済、株式の発行、配当の支払い |
::

村井：「なかでも大事なのが、本業でお金を生んだかどうか、です。利益から出発して、ズレを足したり引いたりして計算します」

::formula 営業活動によるキャッシュ・フロー（間接法・3級の知識で読める簡略版）
当期純利益
＋ 減価償却費（お金が出ていかない費用）
－ 売掛金などの増加（売れたが、まだ入金されていない）
－ 在庫の増加（お金が商品の形で眠っている）
＋ 買掛金などの増加（仕入れたが、まだ支払っていない）
＋ 前受金・前受収益の増加（サービス提供前に入金された）
::

ひよりは、式を上から指でなぞった。減価償却費は、ナイトオウル交通の取締役会。売掛金は、洛北ミートの150枚の元帳。在庫は、マイナス20度の冷凍庫。前受収益は、IRONWORKS 24の12個のマス目。
ひより：「全部、知ってる顔です」

## 答え合わせ ― 運命を分けたのは「お金の流れ方」

ひよりは、卸売会社とジムの数字を、式に当てはめていった。
ひより：「卸売会社は、売上が伸びるほど、売掛金と在庫が膨らみます。洛北ミートと同じです。利益は出ていても、お金は本業で減っていく。ジムは、会費を先にもらうから、逆にお金が増える……」
村井は、黙ってうなずき、2枚目の紙を出した。

::solve 村井が見落としていた「第3の財務諸表」
ひよりの答えを聞いてから、村井は2枚目の紙を出した。2社の決算書から作り直した、その年のキャッシュ・フローが並んでいる（単位：万円、簡略化）。

::table sum 利益は同じ。キャッシュ・フローは正反対
| 項目 | 食材の卸売会社 | 24時間ジム |
| 当期純利益 | 1,000 | 1,000 |
| ＋ 減価償却費 | 200 | 1,500 |
| － 売掛金の増加 | △2,500 | 0 |
| － 在庫の増加 | △600 | 0 |
| ＋ 買掛金の増加 | 700 | 0 |
| ＋ 前受収益（年払い会費）の増加 | 0 | 900 |
|= 営業活動によるキャッシュ・フロー | △1,200 | 3,400 |
| 投資活動（冷蔵倉庫／新店のマシン） | △800 | △3,000 |
| 財務活動（短期の借入れ） | 2,000 | 0 |
|= 現金の増減 | 0 | 400 |
::
卸売会社は、売上が伸びるほど売掛金と在庫が膨らみ（第5・7章）、本業で現金を**失っていた**。利益は出ているのに、営業活動のキャッシュ・フローはマイナス1,200万円。その穴を埋めていたのが、財務活動の2,000万円、つまり村井が稟議書を書いた短期の借入れだった。「3か月だけのつなぎ」は、つなぎではなかった。売上が伸び続けるかぎり、毎年必要になるお金だったのだ。数年後、大口の得意先の倒産（第11章）で決算が赤字に転じ、銀行が追加の融資を断ったその月に、会社は資金繰りに行き詰まった。
ジムは、会費を前払いで受け取り（第15章）、在庫も売掛金もほとんどない。高額なマシンの減価償却費（第12章）はお金が出ていかない費用だから、利益以上の現金が手元に残る。営業活動で生んだ3,400万円で、新店のマシン3,000万円を自分の力でまかなった。融資の相談に来なかったのは、遠慮していたからではない。**借りる必要がなかった**のだ。
2社の運命を分けたのは、利益の額ではない。**利益が、どんな形で手元に残るか**――つまり、ビジネスモデルが生み出すお金の流れ方だった。村井は今、新人にこう教えている。「融資の申し込みが来たら、まず考えろ。このお金は、なぜ本業から生まれてこないのか、と」
::

::real キャッシュ・フロー計算書を作っている会社は、実はひと握り
キャッシュ・フロー計算書は、日本では新しい財務諸表だ。上場会社に作成が義務づけられたのは、**1999年4月以後に始まる事業年度**から。しかも今も、作成が義務づけられているのは上場会社などに限られ、会社法がすべての株式会社に求める計算書類には入っていない。日本の法人は約300万社、東京証券取引所の上場会社は約3,900社だから、0.2%にも満たない。
つまり、あなたがこれから取引し、融資し、就職するかもしれない会社の大半には、キャッシュ・フロー計算書がない。だからこそ、2期分の貸借対照表と損益計算書から、本業でお金が増えたか減ったかを自分で概算する力が武器になる。村井が新人に配る2枚目の紙も、そうやって手で作ったものだ。
::note
出典：[三井住友トラスト不動産「キャッシュフロー会計とは」](https://smtrc.jp/useful/glossary/detail/n/875)／[EY Japan「会社法（平成26年改正）第4回：計算書類」](https://www.ey.com/ja_jp/corporate-accounting/commentary/companies-act/commentary-companies-act-2016-06-03-01)／[日本取引所グループ「上場会社数・上場株式数」](https://www.jpx.co.jp/listing/co/index.html)
::

::scene 翌週 ― 京和銀行・新宿支店
村井の話を聞いた翌週。前期の決算書と、今月までの試算表を抱えて、ナイトオウル交通の三國がやって来た。顧問として、ひよりも同席している。夜行便の予約は好調で、バスをもう2台増やしたい。5年返済で1億円を借りたい、という相談だった。
村井が最初に開いたのは、損益計算書ではなかった。前期末と今月末の貸借対照表を並べて、電卓をたたく。当期純利益に、バスの減価償却費を足す。乗車券の前受金の増加を足す。
村井：「本業で、利益を大きく上回る現金を生んでいますね」
それから村井は、普通預金と前受金の残高を見比べた。
村井：「しかも、お客様から先に預かった乗車券の代金には、手をつけていない」
三國：「キャッシュ・フロー計算書は作っていないのに、そこまで分かるんですか」
村井は、ひよりのほうを見て、少しだけ笑った。ひよりは、手元の決算書の同じ欄を、もう指でなぞっていた。
村井：「2つの時点の貸借対照表があれば、だいたいは」
村井は稟議書の用紙を引き寄せた。15年前の自分なら、利益の欄から書き始めていただろう。いまは、違う欄から書き始める。
::

## 21の問いと、その答え ― 1枚の地図にする

京都へ帰る夜行バスの中で、ひよりはノートを最初のページから読み返した。ページをめくるたびに、顧問先の顔が浮かぶ。坂口の深夜のメッセージ。冷凍庫の白い息。丸富のシャッター。鳥羽の震える声。÷9の朝。
どの事件にも、答えは帳簿の中にあった。ひよりは、21の問いと答えを1枚の表に書き出した。

::table 本書の21の問い
| 章 | 問い | 答えの鍵 |
| 序章 | 満席の人気店が、黒字のまま倒産した | 利益と現金は別物。設備・保証金・返済・在庫・税金 |
| 第1章 | 口座に1億円ある会社は、金持ちか | 豊かさは純資産（資産－負債）で測る |
| 第2章 | 1億円の契約は記録せず、30万円の盗難は記録する | 簿記上の取引＝財産の増減 |
| 第3章 | レジの3,200円の不足、犯人は誰か | 現金過不足。疑う前に記録する |
| 第4章 | 残高ゼロの口座から500万円が払えた | 当座借越。マイナス残高は借金 |

| 第14章 | 年商2億円の店が消費税を払えない | 消費税は預かったお金 |

| 終章 | 同じ利益で、上場と倒産に分かれた | 第3の財務諸表、キャッシュ・フロー |

::boxes 簿記の全体像 ― 3枚の財務諸表は1つにつながっている
H 1年間の動き（フロー） | 期末の状態（ストック）
L r 34 損益計算書<br>収益－費用＝当期純利益
L k 33 キャッシュ・フロー計算書<br>現金の増減とその理由
L s 33 （期首の貸借対照表から出発）
R e 50 貸借対照表<br>繰越利益剰余金＋当期純利益
R a 50 貸借対照表<br>現金預金＝期首＋現金の増減
::

損益計算書の当期純利益は、貸借対照表の繰越利益剰余金に流れ込む（第19章）。キャッシュ・フロー計算書の現金の増減は、貸借対照表の現金預金の変化と一致する。3枚の財務諸表は、複式簿記という1つのエンジンから生まれた、同じ会社の3つの顔なのだ。


## この先の道 ― 2級・1級、そして実務へ

試験の3日前、ひよりの机に、一ノ瀬の字で書かれた1枚の紙が置いてあった。3級の先に何があるかを、1本の道にした図だ。
一ノ瀬：「受かったあとの話を、先にしておきます。3級は、地図の入口です。顧問先で出会った問題の半分は、まだ3級の道具では解けなかったはずです」
ひよりは、ナイトオウル交通のグループ会社や、おかわり堂のセントラルキッチンを思い浮かべた。
ひより：「おかわり堂とケータリングを1つにした決算書。セントラルキッチンで、牛丼1杯を作るのにいくらかかっているか……」
一ノ瀬：「それが、2級です」
3級で手に入れたのは、簿記という**OS**だ。この上に、さらに強力なアプリケーションをインストールしていくことができる。

::table 2級で学ぶ主な内容
| 分野 | 主な論点 | 本書とのつながり |
| 商業簿記 | 連結会計 | おかわり堂とケータリング子会社のグループ決算（第18章） |
| 商業簿記 | 税効果会計 | 会計上の利益と税金の計算のズレ（第14章） |
| 商業簿記 | リース会計・ソフトウェア | バスのリース、ゲーム開発費の資産計上（第12章） |
| 商業簿記 | 有価証券・外貨建取引 | 余剰資金の運用、輸入牛肉の為替リスク |
| 商業簿記 | 収益認識 | ジムの年会費、乗車券の前受け（第9・15章） |
| 商業簿記 | 引当金・株主資本等変動計算書 | 賞与・退職金への備え、純資産の変動（第10・13章） |
| 工業簿記 | 原価計算 | おかわり堂のセントラルキッチンで作る惣菜の原価 |
| 工業簿記 | 標準原価計算・CVP分析 | 原価差異の分析、深夜営業の損益分岐点（第10章） |
::

1級では、会計基準の背後にある理論、企業結合や連結の高度な論点、キャッシュ・フロー計算書、そして経営判断のための管理会計を学ぶ。その先には、公認会計士や税理士、企業の経理・財務部門など、会社の数字を扱う仕事への道が続いている。

最後に、ひとつだけ伝えたい。
簿記は、過去の取引を記録する技術だ。だが、本書の21の問いが示したとおり、その記録は、会社の未来を左右する。黒字倒産も、粉飾も、連鎖倒産も、上場も――すべては、日々の仕訳の積み重ねの先にある。
経済のルールは、これからも変わり続ける。紙の手形は消え、決済は電子化され、AIが仕訳を自動で切る時代が来た。それでも、500年前にヴェネツィアの商人が手にした「左右に分けて記録する」という仕組みの価値は、少しも色あせていない。むしろ、数字があふれる時代だからこそ、その数字の意味を読み解ける人の価値は、ますます高まっていく。
あなたはもう、決算書を読める。
次は、その数字を自分の手で作り、より良く変えていく側に立つ番だ。

::summary 本書のまとめ
- 簿記は、会社の成績と財産を表す財務諸表を作り、読むための技術である
- 利益と現金は違う。その違いを生むのは、設備投資・在庫・売掛金・借入金・税金・前受けなどの「時間差」
- すべての取引を左右2つの側面から記録する複式簿記は、誤りと不正を見つけ、利益と財産を同時に計算する
- 決算整理は、お金の動きの記録を、発生主義にもとづく真実の利益へと翻訳する
- 損益計算書・貸借対照表・キャッシュ・フロー計算書は、1つの会社の3つの顔。必ずつなげて読む
- キャッシュ・フロー計算書を作る義務があるのは上場会社などだけ。なければ、2期分の決算書から営業キャッシュ・フローを概算し、その中身（売掛金・在庫・前受金）まで確かめる
- 3級は終点ではなく、2級・1級、そして経営の現場へと続く道の入口である
::
