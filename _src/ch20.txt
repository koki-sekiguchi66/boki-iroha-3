京和銀行の村井には、新人研修で必ず配る2枚の紙がある。15年前、京都の本店で融資担当になったばかりの頃に受け持った、2つの会社の決算書だ。

卸売会社の社長は、毎月のように支店へやって来た。「注文が増えて、仕入れが追いつかない。3か月だけ、つなぎの資金を」。黒字で、売上も伸びている。断る理由は見当たらなかった。村井は張り切って稟議書を書き、上司の判をもらった。ジムの社長は、一度も融資の相談に来なかった。
5年後。ジムは新店を次々と出し、株式市場への上場を果たした。卸売会社は、急成長の途中で資金が尽き、倒産した。村井が稟議書を書いた融資の多くは、返ってこなかった。
同じ年に、同じ利益。損益計算書の最終行は、どちらも「1,000万円」だった。2社の運命を分けたものは何だったのか。そして、若き日の村井は、決算書のどこを見落としていたのか？

## 序章の問いを、もう一度解く

1枚目の紙を見つめながら、ひよりは、1年あまり前の自分に戻っていた。百万遍の交差点。シャッターに貼られたA4の紙。「ずっと黒字やったんや」という父の声。行列の絶えない定食屋「まんぷく食堂」は、なぜ黒字のまま倒産したのか。
あのときのひよりは、「利益と現金は違う」という一ノ瀬の言葉を、まだ実感をもって理解できなかった。だが今なら、その意味を勘定科目のレベルで説明できる。ひよりは、村井の紙の裏に、父の店の「お金の出口」を書き出していった。

::table まんぷく食堂の「お金の出口」を、勘定科目で説明する
| お金の出口 | 仕訳 | 利益への影響 | 学んだ章 |
| 新店の内装・厨房設備 | 建物・備品 ／ 普通預金 | 買った年は影響なし。減価償却で少しずつ費用に | 第12章 |
| 新店の保証金 | 差入保証金 ／ 普通預金 | 影響なし（資産のまま） | 第9章 |
| 借入金の元本返済 | 借入金 ／ 普通預金 | 影響なし（負債の減少） | 第9章 |
| 食材在庫の増加 | 仕入 ／ 買掛金など（期末に繰越商品へ） | 期末在庫は費用にならない | 第5章 |
| 法人税等の納付 | 未払法人税等 ／ 普通預金 | 前期に費用計上済み | 第14章 |
::

書き終えて、ひよりは気づいた。どの仕訳も、借方は費用ではなく、資産の増加か負債の減少だ。だから利益は減らない。しかし貸方は「普通預金」。お金は確実に出ていく。まんぷく食堂のオーナーに足りなかったのは、この仕訳の両側を同時に見る目だった。複式簿記とは、まさにその目のことなのだ。

## 第3の財務諸表 ― キャッシュ・フロー計算書

損益計算書は「利益」を、貸借対照表は「財産の状態」を表す。そして、1年間の「現金の増減」を、その原因別に表すのが、第3の財務諸表、**キャッシュ・フロー計算書**だ（本格的には1級で学ぶ）。
キャッシュ・フロー計算書は、現金の動きを3つに分けて示す。

::table キャッシュ・フロー計算書の3つの区分
| 区分 | 内容 | 主な例 |
| 営業活動によるキャッシュ・フロー | 本業で稼いだ（失った）現金 | 商品の販売・仕入、給料・経費の支払い、法人税等の支払い |
| 投資活動によるキャッシュ・フロー | 将来のための投資に使った（回収した）現金 | 固定資産の購入・売却、貸付けと回収 |
| 財務活動によるキャッシュ・フロー | 資金の調達と返済 | 借入れと返済、株式の発行、配当の支払い |
::

なかでも重要なのが、営業活動によるキャッシュ・フローだ。これは、当期純利益から出発して、「利益とお金のズレ」を調整する形で計算できる（**間接法**）。

::formula 営業活動によるキャッシュ・フロー（間接法・3級の知識で読める簡略版）
当期純利益
＋ 減価償却費（お金が出ていかない費用）
－ 売掛金などの増加（売れたが、まだ入金されていない）
－ 在庫の増加（お金が商品の形で眠っている）
＋ 買掛金などの増加（仕入れたが、まだ支払っていない）
＋ 前受金・前受収益の増加（サービス提供前に入金された）
::

どの項目も、あなたはすでに知っている。減価償却費は第12章、売掛金は第7章、在庫は第5章、前受収益は第15章で学んだ。キャッシュ・フロー計算書とは、本書で学んだ「利益と現金のズレ」を、1枚の表に整理したものにすぎない。

## 答え合わせ ― 運命を分けたのは「お金の流れ方」

::solve 村井が見落としていた「第3の財務諸表」
ひよりの答えを聞いてから、村井は2枚目の紙を出した。2社の決算書から作り直した、その年のキャッシュ・フローが並んでいる（単位：万円、簡略化）。

::table sum 利益は同じ。キャッシュ・フローは正反対
| 項目 | 食材の卸売会社 | 24時間ジム |
| 当期純利益 | 1,000 | 1,000 |
| ＋ 減価償却費 | 200 | 1,500 |
| － 売掛金の増加 | △2,500 | 0 |
| － 在庫の増加 | △600 | 0 |
| ＋ 買掛金の増加 | 700 | 0 |
| ＋ 前受収益（年払い会費）の増加 | 0 | 900 |
|= 営業活動によるキャッシュ・フロー | △1,200 | 3,400 |
| 投資活動（冷蔵倉庫／新店のマシン） | △800 | △3,000 |
| 財務活動（短期の借入れ） | 2,000 | 0 |
|= 現金の増減 | 0 | 400 |
::
卸売会社は、売上が伸びるほど売掛金と在庫が膨らみ（第5・7章）、本業で現金を**失っていた**。利益は出ているのに、営業活動のキャッシュ・フローはマイナス1,200万円。その穴を埋めていたのが、財務活動の2,000万円、つまり村井が稟議書を書いた短期の借入れだった。「3か月だけのつなぎ」は、つなぎではなかった。売上が伸び続けるかぎり、毎年必要になるお金だったのだ。数年後、大口の得意先の倒産（第11章）で決算が赤字に転じ、銀行が追加の融資を断ったその月に、会社は資金繰りに行き詰まった。
ジムは、会費を前払いで受け取り（第15章）、在庫も売掛金もほとんどない。高額なマシンの減価償却費（第12章）はお金が出ていかない費用だから、利益以上の現金が手元に残る。営業活動で生んだ3,400万円で、新店のマシン3,000万円を自分の力でまかなった。融資の相談に来なかったのは、遠慮していたからではない。**借りる必要がなかった**のだ。
2社の運命を分けたのは、利益の額ではない。**利益が、どんな形で手元に残るか**――つまり、ビジネスモデルが生み出すお金の流れ方だった。村井は今、新人にこう教えている。「融資の申し込みが来たら、まず考えろ。このお金は、なぜ本業から生まれてこないのか、と」
::

::real キャッシュ・フロー計算書を作っている会社は、実はひと握り
損益計算書と貸借対照表に比べると、キャッシュ・フロー計算書は、日本では新しい財務諸表だ。上場会社に作成が法律で義務づけられたのは、**1999年4月以後に始まる事業年度**から。1990年代後半の金融制度の大改革（金融ビッグバン）とともに進められた「会計ビッグバン」の中で、それまでの「資金収支表」に代えて導入された。
そして今も、作成が義務づけられているのは、有価証券報告書を出す上場会社などに限られる。会社法がすべての株式会社に作成を求める計算書類は、貸借対照表・損益計算書・株主資本等変動計算書・個別注記表の4つで、キャッシュ・フロー計算書は入っていない。日本の法人は約**300万社**（2024年度分）。東京証券取引所の上場会社は約**3,900社**だから、0.2%にも満たない。
つまり、あなたがこれから取引し、融資し、就職するかもしれない会社の大半には、キャッシュ・フロー計算書がない。だからこそ、2期分の貸借対照表と損益計算書から、本章の式で営業活動によるキャッシュ・フローを自分で概算する力が武器になる。村井が新人に配る2枚目の紙も、そうやって手で作ったものだ。
::note

::scene 翌週 ― 京和銀行・新宿支店
村井の話を聞いた翌週。前期の決算書と、今月までの試算表を抱えて、ナイトオウル交通の三國がやって来た。顧問として、ひよりも同席している。夜行便の予約は好調で、バスをもう2台増やしたい。5年返済で1億円を借りたい、という相談だった。
村井が最初に開いたのは、損益計算書ではなかった。前期末と今月末の貸借対照表を並べて、電卓をたたく。当期純利益に、バスの減価償却費を足す。乗車券の前受金の増加を足す。
「本業で、利益を大きく上回る現金を生んでいますね」。それから村井は、普通預金と前受金の残高を見比べた。「しかも、お客様から先に預かった乗車券の代金には、手をつけていない」
三國は少し驚いた顔をした。「キャッシュ・フロー計算書は作っていないのに、そこまで分かるんですか」
村井は、ひよりのほうを見て、少しだけ笑った。ひよりは、手元の決算書の同じ欄を、もう指でなぞっていた。
「2つの時点の貸借対照表があれば、だいたいは」。村井は稟議書の用紙を引き寄せた。15年前の自分なら、利益の欄から書き始めていただろう。いまは、違う欄から書き始める。

::boxes 簿記の全体像 ― 3枚の財務諸表は1つにつながっている
H 1年間の動き（フロー） | 期末の状態（ストック）
L r 34 損益計算書<br>収益－費用＝当期純利益
L k 33 キャッシュ・フロー計算書<br>現金の増減とその理由

R e 50 貸借対照表<br>繰越利益剰余金＋当期純利益
R a 50 貸借対照表<br>現金預金＝期首＋現金の増減
::

損益計算書の当期純利益は、貸借対照表の繰越利益剰余金に流れ込む（第19章）。キャッシュ・フロー計算書の現金の増減は、貸借対照表の現金預金の変化と一致する。3枚の財務諸表は、複式簿記という1つのエンジンから生まれた、同じ会社の3つの顔なのだ。

::cfo 転職先の候補は3社 ― 5年後も給料を払い続けていそうなのは、どこか
3級に合格したあなたは、経理の仕事に転職しようとしている。最終面接まで進んだ3社は、どこも「売上は伸びている、利益も出ている」と胸を張った。3社とも上場していないから、キャッシュ・フロー計算書はない。経理職の募集なので、面接で頼むと、どの会社も2期分の決算書を見せてくれた。
- **P社**：給食・弁当向けの惣菜をつくる工場。創業40年
- **Q社**：法人向けのシステム開発。この1年で大型案件を次々に受注した
- **R社**：前払い制のパーソナルトレーニングジム。今期は「12か月コースを一括前払いなら40%引き」のキャンペーンが当たり、入会者が殺到した
::table 3社の決算書の要点（単位：百万円）
| 項目 | P社 | Q社 | R社 |
| 売上高（当期） | 2,100 | 2,400 | 1,300 |
| 売上高の伸び（前期比） | +5% | +60% | +63% |
| 当期純利益 | 80 | 240 | 110 |
| 減価償却費 | 90 | 20 | 70 |
| 売掛金の増加（前期末から） | 15 | 600 | 0 |
| 前受金の増加（前期末から） | 0 | 0 | 450 |
| 設備・出店への投資 | 100 | 20 | 750 |
| 期末の売掛金 | 345 | 850 | 0 |
| 期末の前受金 | 0 | 0 | 600 |
| 期末の現金預金 | 420 | 90 | 380 |
| 期末の借入金 | 300 | 800 | 50 |
::
まず本文の式で、3社の営業活動によるキャッシュ・フローを概算してほしい。そのうえで、その現金がどこから来たのか、出どころまで確かめてから選んでほしい。
::choice A. Q社。売上は1.6倍、利益も3社で最大。伸びる会社で経験を積みたい
**× 村井が貸した卸売会社と、同じ形をしている。**営業キャッシュ・フローを概算すると、240＋20－600＝**△340百万円**。売上は1.6倍なのに、売掛金は250から850へ3倍以上に膨らんだ。売掛金÷売上高×365で回収にかかる日数を計算すると、約61日から約129日へ、倍以上に延びている。本業で失った現金は借入金で埋め、手元の現金は90しかない。
考えられる理由は2つ。得意先の支払いが滞っているか（第11章）、売上そのものが架空か（第2章のエフオーアイ）。どちらにしても、経理として入社したあなたの最初の仕事は、売掛金の中身を1件ずつ確かめることになる。
::
::choice B. R社。営業キャッシュ・フローが3社で最大で、借入金もほとんどない。この章で学んだ「お金が先に入る」強いビジネスだ
**× この章でいちばん深い落とし穴。**営業キャッシュ・フローは110＋70＋450＝**630百万円**と、たしかに3社で最大だ。だが、その7割は前受金の増加450、つまり40%引きで集めた来年分の会費の先取りである。
来年、新しい前払いが細れば、前受金は減り始め、同じ式のその項目がマイナスに変わる。利益と減価償却費が今期と同じでも、前受金が600から150に戻るだけで、営業キャッシュ・フローは180－450＝**△270百万円**に反転する。しかも期末の現金380は、前受金600より少ない。客から預かったお金は、すでに新しい店舗に姿を変えている。前払いを集め続けなければ回らない仕組みは、第9章のてるみくらぶ、第15章のミュゼプラチナムと同じ構図だ。
::
::choice C. P社。成長は遅いが、利益以上の現金を本業で稼ぎ、手元の現金が借入金を上回っている
**◎ 地味だが、いちばん強い。**営業キャッシュ・フローは80＋90－15＝**155百万円**。工場の減価償却費というお金の出ていかない費用があるから、利益のおよそ2倍の現金を本業で生んでいる。売掛金の増え方（330→345）は売上の伸びと同じペースで、無理な売り方をしていない。設備への投資100も、営業キャッシュ・フローの範囲で自力でまかなえる。手元の現金420は借入金300を上回り、いわゆる「実質無借金」だ。
年5%の成長は目立たない。それでも、5年後も給料日にきちんと給料が振り込まれている可能性は、3社でいちばん高い。
::
::choice D. 3社とも決め手に欠ける。別の会社を探す
**△ 慎重なのはよいが、P社まで見送るのはもったいない。**P社の数字は、損益計算書・貸借対照表・キャッシュ・フローのどの角度から見ても健全だ。決算書は、華やかな成長の話よりも、目立たない会社の強さを教えてくれることが多い。「派手さ」ではなく「お金の流れ方」で会社を選べるようになったことこそ、本書で手に入れた力である。
::
::answer 考え方の例を見る
本文の式で、3社の営業活動によるキャッシュ・フローを並べると、こうなる（単位：百万円）。
::table sum 3社の営業活動によるキャッシュ・フロー（概算）
| 項目 | P社 | Q社 | R社 |
| 当期純利益 | 80 | 240 | 110 |
| ＋ 減価償却費 | 90 | 20 | 70 |
| － 売掛金の増加 | △15 | △600 | 0 |
| ＋ 前受金の増加 | 0 | 0 | 450 |
|= 営業活動によるキャッシュ・フロー | 155 | △340 | 630 |
::
損益計算書だけを見れば、Q社がいちばん魅力的に見える。キャッシュ・フローの合計だけを見れば、R社がいちばん強く見える。だが、2つをつなげ、中身まで読むと評価は逆転する。Q社の利益は売掛金に、R社の現金は前受金に支えられている。前受金の増加を除くと、R社の営業キャッシュ・フローは180で、P社と大差ない。利益と同じ形の現金を、無理なく本業で生み出しているのは、P社だけだ。
決算書を手にしたら、次の5つの問いを、この順で確かめよう。どれも、本書で学んだ勘定科目の言葉で答えられる。
1. **売上は伸びているか、粗利率は保たれているか**（損益計算書）：売上が伸びても粗利率が下がり続けていれば、値下げで売上を買っている可能性がある（第5章）。
2. **利益と営業キャッシュ・フローは見合っているか**：キャッシュ・フロー計算書がなければ、2期分の貸借対照表から自分で概算する。利益が出ているのに営業キャッシュ・フローが何年もマイナスなら要注意だ（終章）。
3. **売掛金と在庫は、売上以上に膨らんでいないか**（貸借対照表）：回収日数や在庫日数の悪化は、資金繰りの悪化や、時に粉飾のサインになる（第2・5・7章）。Q社がこれにあたる。
4. **「先に入るお金」に頼りすぎていないか**：前受金の増加が営業キャッシュ・フローの大半を占めるなら、それは未来の売上の先取りだ。前受金の残高と手元の現金も比べる（第9・15章）。R社がこれにあたる。
5. **手元の現金と借入金、純資産のバランスはどうか**（貸借対照表）：借入金から現金預金を引いた「実質的な借金」が、稼ぐ力に比べて重すぎないか。自己資本比率は十分か（第1・19章）。
決算書は、会社が世界に向けて出している、最も正直な手紙だ。読み方を知っている人にだけ、その手紙の行間が見える。
::

最後に、ひとつだけ伝えたい。
簿記は、過去の取引を記録する技術だ。だが、本書の21の問いが示したとおり、その記録は、会社の未来を左右する。黒字倒産も、粉飾も、連鎖倒産も、上場も――すべては、日々の仕訳の積み重ねの先にある。
経済のルールは、これからも変わり続ける。紙の手形は消え、決済は電子化され、AIが仕訳を自動で切る時代が来た。それでも、500年前にヴェネツィアの商人が手にした「左右に分けて記録する」という仕組みの価値は、少しも色あせていない。むしろ、数字があふれる時代だからこそ、その数字の意味を読み解ける人の価値は、ますます高まっていく。
あなたはもう、決算書を読める。
次は、その数字を自分の手で作り、より良く変えていく側に立つ番だ。

::summary 本書のまとめ
- 簿記は、会社の成績と財産を表す財務諸表を作り、読むための技術である
- 利益と現金は違う。その違いを生むのは、設備投資・在庫・売掛金・借入金・税金・前受けなどの「時間差」
- すべての取引を左右2つの側面から記録する複式簿記は、誤りと不正を見つけ、利益と財産を同時に計算する
- 決算整理は、お金の動きの記録を、発生主義にもとづく真実の利益へと翻訳する
- 損益計算書・貸借対照表・キャッシュ・フロー計算書は、1つの会社の3つの顔。必ずつなげて読む
- キャッシュ・フロー計算書を作る義務があるのは上場会社などだけ。なければ、2期分の決算書から営業キャッシュ・フローを概算し、その中身（売掛金・在庫・前受金）まで確かめる
- 3級は終点ではなく、2級・1級、そして経営の現場へと続く道の入口である
::
