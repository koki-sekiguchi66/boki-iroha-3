::mystery 知識が同じ2人の、合否を分けたもの
同じ教材で、同じ時間だけ勉強した2人の受験生がいた。模擬問題を解かせると、2人とも、時間をかければほぼ満点が取れる。
ところが本番の結果は、1人が**88点で合格**、もう1人は**64点で不合格**だった。
不合格だったほうは、試験後にこう振り返った。「第2問の帳簿の問題で手が止まって、時間を使いすぎた。気づいたら残り15分。第3問の決算は半分も埋められなかった」。
知識は同じ。違ったのは、60分という限られた資源の使い方だった。
::

## 試験の基本情報

::table 日商簿記3級の概要
| 項目 | 内容 |
| 主催 | 日本商工会議所・各地の商工会議所 |
| 試験方式 | 統一試験（ペーパー試験：例年6月・11月・2月）と、ネット試験（テストセンターでのパソコン受験：随時） |
| 試験時間 | 60分 |
| 満点・合格基準 | 100点満点、70点以上で合格 |
| 出題範囲 | 商工会議所簿記検定試験 出題区分表にもとづく（2026年度は2022年度適用の区分表） |
| 持ち物 | 電卓（四則演算などの計算機能のみのもの。関数電卓などは不可）、筆記用具（統一試験） |
::

::note
※受験料、試験日、申込方法、持ち込みの細かな条件などは変更されることがある。受験前に必ず、日本商工会議所と受験地の商工会議所の公式情報を確認しよう。
::

## 出題構成と配点

::table 出題構成（例年の傾向）
| 大問 | 配点 | 主な内容 |
| 第1問 | 45点 | 仕訳問題15問（1問3点）。期中取引が中心で、証ひょうから仕訳する問題も含む |
| 第2問 | 20点 | 小問2問程度。勘定記入、補助簿の記入・選択、伝票、商品有高帳、固定資産台帳、語句の選択など |
| 第3問 | 35点 | 決算問題。財務諸表の作成、精算表の作成、決算整理後残高試算表の作成のいずれか |
::

::kpi 合格ラインの作り方（例）
第1問 | 39点／45点 | 15問中13問正解
第2問 | 10点／20点 | 半分取れれば十分
第3問 | 25点／35点 | 決算整理の7割を正確に
合計 | 74点 | 70点の合格ラインを超える
::

::theory 「全部できなくていい」という戦略
合格に必要なのは70点だ。満点ではない。第1問と第3問で合計64点以上を確保できれば、第2問は半分の10点で合格できる。
逆に、第2問の難問に時間を取られて、第1問や第3問の取れるはずの点を落とすのが、最も多い不合格パターンだ。冒頭の問いの答えも、まさにこれである。
企業が限られた予算を、最もリターンの高い事業に配分するのと同じように、受験生は60分を、最も確実に点になる問題に配分する。
::

## 時間配分と解く順番

::steps おすすめの順番と時間配分
第1問（仕訳15問）：約20分 | 1問80秒が目安。迷った問題は印をつけて飛ばし、最後に戻る
第3問（決算）：約25分 | 決算整理仕訳を先にすべて書き出してから、解答欄に記入する
第2問（帳簿など）：約10分 | 解ける小問から解く。見慣れない形式なら、取れる空欄だけを埋める
見直し：約5分 | 第1問の勘定科目と金額、第3問の合計の一致を確認する
::

::point なぜ第2問を最後にするのか
第2問は、毎回形式が変わりやすく、問題の読み取りに時間がかかる。一方、第3問は配点が大きく、出題パターンもほぼ決まっている。配点の大きい、パターンの決まった問題を先に確実に仕留める。これが時間不足による失点を防ぐ最大のコツだ。
::

## 第1問の攻略 ― 仕訳15問

::table 第1問の頻出論点
| 論点 | 出題のされ方の例 | 復習する章 |
| 現金過不足 | 原因の一部が判明、決算での整理 | 第3章 |
| 預金・小切手・小口現金 | 複数口座間の振替、小口現金の報告と補給 | 第4章 |
| 商品売買 | 諸掛り、返品、手付金の充当、消費税 | 第5・14章 |
| クレジット売掛金・受取商品券 | 手数料の計上、商品券での受取り | 第7章 |
| 手形・電子記録債権 | 発生記録、決済、手形借入れ | 第8章 |
| その他の債権債務 | 未払金、仮払金の精算、ICカード、差入保証金、役員・従業員との貸し借り | 第9章 |
| 給料・預り金 | 天引き、社会保険料の納付と法定福利費 | 第10章 |
| 貸倒れ | 当期発生と前期発生の区別、償却債権取立益 | 第11章 |
| 固定資産 | 付随費用、期中売却 | 第12章 |
| 株式・配当 | 増資、配当の決議と支払い | 第13章 |
| 税金 | 固定資産税、法人税等の中間納付、消費税の納付 | 第14章 |
| 証ひょう | 請求書・領収書・通帳からの仕訳 | 第16章 |
| 訂正仕訳 | 勘定科目や金額の誤りの訂正 | 第16章 |
::

::exam 第1問で点を落とさない5つの鉄則
1. **勘定科目は、必ず指定された語群（選択肢）から選ぶ。** 自分で科目名を作らない。
2. **「商品か、商品以外か」を最初に判定する。** 売掛金・買掛金と未収入金・未払金の区別で失点しない。
3. **金額の計算過程を問題用紙にメモする。** 利息の月割、消費税の税抜計算、減価償却の月割は、必ず式を書く。
4. **借方合計＝貸方合計を必ず確認する。** 合わなければ、どこかが間違っている。
5. **同じ側に同じ勘定科目を2回書かない。** 合計して1行にまとめる。
::

## 第2問の攻略 ― 帳簿・伝票・理論

::table 第2問の主な出題形式と攻略法
| 形式 | 攻略法 | 復習する章 |
| 勘定記入（T字勘定の空欄補充） | 前期繰越・再振替・期中取引・決算整理・次期繰越の順に、勘定の1年間の流れを再現する | 第15・19章 |
| 補助簿の選択 | まず仕訳を書き、勘定科目ごとに補助簿を当てはめる | 第16章 |
| 商品有高帳 | 払出欄は原価。先入先出法は単価ごとに行を分ける | 第6章 |
| 伝票・仕訳日計表 | 一部現金取引の起票方法を、入金・出金伝票の相手科目から判断する | 第16章 |
| 売掛金元帳・買掛金元帳 | 取引先ごとの残高と、総勘定元帳の残高の一致を使う | 第7章 |
| 固定資産台帳 | 期中取得の月割に注意して、減価償却累計額を計算する | 第12章 |
| 語句の選択（理論） | 用語の意味を、自分の言葉で説明できるようにしておく | 全章の「重要理論」 |
::

## 第3問の攻略 ― 決算

::steps 第3問を解く手順
「期中の未処理事項」を先に処理する | 仮受金の内容判明、記帳漏れ、誤記の訂正など。これを先にやらないと、売掛金や消費税の金額がずれる
決算整理仕訳をすべて書き出す | 問題用紙の余白に、決算整理事項の順に仕訳を書く。金額の計算式も書く
勘定科目ごとに金額を集計する | 試算表の金額に、仕訳の金額を同じ側なら足し、反対側なら引く
法人税等を最後に計算する | 税引前当期純利益が確定してから計算する
解答欄に記入し、合計の一致を確かめる | 精算表なら損益計算書欄と貸借対照表欄の当期純利益の一致、財務諸表なら左右の合計の一致を確認する
::

::exam 第3問の頻出ミス
- 貸借対照表の**繰越利益剰余金に当期純利益を加え忘れる**。
- 「仕入」を「売上原価」、「繰越商品」を「商品」と書き換え忘れる。
- 貸倒引当金の対象に、受取手形・電子記録債権・クレジット売掛金を含め忘れる（問題文の指示を確認）。
- 期中に取得した固定資産の減価償却を、12か月分で計算してしまう。
- 「月次決算で毎月計上している」減価償却費を、決算でもう一度1年分計上してしまう（決算では未計上の月の分だけを計上する）。
- 精算表で当期純損失のときに、利益と同じ側（損益計算書欄の借方）に書いてしまう（純損失は損益計算書欄の貸方・貸借対照表欄の借方）。
- 経過勘定の月数を数え間違える（「×年12月1日に1年分」→ 前払は翌年4月〜11月の8か月）。
- 期中に貸倒れで引当金を取り崩したのに、決算整理前の引当金残高を減らし忘れる。
- 消費税の整理で、仮受消費税と仮払消費税の左右を逆にする。
::

## ケアレスミス・ワースト10

::table よくあるケアレスミスと対策
| ミス | 対策 |
| 他人振出小切手の受取りを当座預金にする | 「他人振出の受取り＝現金」と即答できるまで反復する（第3・4章） |
| 当期発生の債権の貸倒れで引当金を取り崩す | 「いつ発生した債権か」を最初に確認する（第11章） |
| 送料を受け取る取引で、売上に含め忘れる | 「受け取る送料は売上、払う送料は発送費」（第5章） |
| 固定資産の後払いを買掛金にする | 固定資産の後払いは必ず未払金（第9章） |
| クレジット売掛金を手数料込みの金額にする | 手数料を差し引いた金額がクレジット売掛金（第7章） |
| 社会保険料の会社負担分を預り金にする | 会社負担分は法定福利費（第10章） |
| 配当の決議時に普通預金を減らす | 決議時は未払配当金、支払時に預金を減らす（第13章） |
| 再振替仕訳を忘れる | 経過勘定・貯蔵品・当座借越は、翌期首に逆仕訳（第4・15章） |
| 税込金額のまま仕入・売上を計上する | 税抜方式では、本体価格と消費税を分ける（第14章） |
| 現金過不足の残額をすべて雑益（雑損）と決めつける | 最後は貸借差額で判断する（第3章） |
::

## 2027年度からの出題区分表の改定（暫定版）

2025年12月に、日本商工会議所から、2027年4月1日以降の試験に適用する出題区分表の暫定版が公表された。受験時期によって出題範囲が変わるので注意しよう。

::table 3級の主な変更点（2025年12月公表の暫定版にもとづく）
| 区分 | 内容 |
| 削除される見込み | 紙の手形・小切手に関する論点（紙の手形・小切手が2027年3月末で利用廃止される予定のため） |
| 2級から3級へ移行 | 売上原価対立法（販売のつど売上原価勘定に振り替える方法） |
| 2級から3級へ移行 | 固定資産の除却・廃棄 |
| 2級から3級へ移行 | 定率法（基礎的な仕組みの理解を目的とした簡易な出題。200%定率法の保証率などは出題しない） |
| 整理・明記 | 普通預金の明記、クレジット売掛金に「キャッシュレス決済を含む」と追記、電子記録債権・債務を売掛金・買掛金の区分に整理 |
| リース | 3級の範囲外。支払家賃・支払地代は従来どおりの処理で出題 |
::

::note
※本書は、2026年度（2027年3月まで）の試験に適用される現行の出題区分（2022年度適用版）を網羅したうえで、上記の追加論点を第5章（売上原価対立法）と第12章（定率法・除却・廃棄）で解説している。暫定版の内容は今後更新される可能性があるため、受験前に日本商工会議所の公式サイトで最新の出題区分表を必ず確認すること。
::

## 試験直前チェックリスト

::summary 前日・当日に確認すること
- 受験票（統一試験）や予約内容（ネット試験）、本人確認書類を確認した
- 電卓の電池は十分か。使い慣れた電卓を持っていく
- 第1問→第3問→第2問の順番と、時間配分を決めた
- 各章の「試験の急所」（緑のボックス）を読み返した
- 付録Aの「まぎらわしい勘定科目の見分け方」を確認した
- しーくりくりしー、差額補充法、月割計算、経過勘定の4つの形を、白紙に書けるか試した
- 貸借対照表の繰越利益剰余金には、当期純利益を加える
::
