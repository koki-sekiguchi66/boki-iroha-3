一ノ瀬：「今年は、1社の決算を丸ごと任せます」

3月31日の夜。決算整理前の残高試算表を見た片山は、収益の合計から費用の合計を引いて、満足げにうなずいた。

その夜、ケータリングの事務所では、経理担当の小野とひよりが、決算整理の資料を机いっぱいに広げていた。棚卸しの記録、固定資産台帳、保険の契約書、銀行の借入明細。日付が変わるころ、2人で組み上げた精算表の最終行に、1つの数字が現れた。

## 決算 ― 1年間の記録を「通知表」に変える

ひよりは、片山の前に、決算整理前の試算表と、完成した決算書を並べた。
ひより：「昨日の夜、お金は1円も動いていません。動かしたのは、記録のほうです」
片山：「記録を動かしただけで、利益が172万円も減るんか」
ひより：「はい。これまでの帳簿は、まだ1年分の成績表にはなっていなかったんです。売れ残った食材は仕入に入ったまま。厨房の機械の目減りも、来年の分まで払った保険料も、まだ反映されていません」
片山：「それを、昨日の夜に直したわけか」
ひより：「はい。1年の最後に、帳簿を本当の成績の形に直すこと。それが**決算**です。中心になる直しの作業を、**決算整理**といいます」

::steps 決算の手続きの流れ
決算整理前残高試算表を作る | 期中の記録の正しさを確かめ、決算の出発点とする（第17章）
決算整理事項を確認する | 在庫の棚卸し、減価償却、経過勘定など、修正すべき事項を洗い出す
決算整理仕訳を行う | 修正を仕訳として記録し、総勘定元帳に転記する
決算整理後残高試算表・精算表を作る | 修正後の残高を確かめ、財務諸表の下書きを作る
帳簿を締め切る | 収益・費用を損益勘定に集め、当期純利益を繰越利益剰余金に振り替える（第19章）
財務諸表を作る | 損益計算書と貸借対照表を完成させる（第19章）
::

## 精算表 ― 決算の全体像を1枚で見渡す

小野が、机の上にA3の紙を広げた。
小野：「決算整理の仕訳を、1つの勘定ずつ試算表に足したり引いたりしていくと、最後に利益が出てくるの」
ひより：「左の試算表から出発して、修正を足して、右の損益計算書と貸借対照表に振り分ける……」
小野：「そう。8つの列があるから、**8桁精算表**。決算の全体が、1枚で見えるの」

::theory 精算表の記入ルール
1. **修正記入欄**：決算整理仕訳を、そのまま借方・貸方に記入する。精算表にない勘定科目（雑損・減価償却費・前払保険料など）は、表の下に行を追加して記入する。
2. **損益計算書欄・貸借対照表欄**：試算表欄の金額に修正記入欄の金額を加減して移す。**同じ側なら足し、反対側なら引く**。
3. 収益・費用の勘定は**損益計算書欄**へ、資産・負債・純資産の勘定は**貸借対照表欄**へ移す。
4. 損益計算書欄の貸方合計（収益）と借方合計（費用）の差額が**当期純利益**。損益計算書欄の**借方**と、貸借対照表欄の**貸方**に同じ金額を記入すると、両方の欄の貸借が一致する。
5. 費用のほうが多い場合は**当期純損失**。損益計算書欄の**貸方**と、貸借対照表欄の**借方**に記入する（利益の場合と左右が逆になる）。
::

::point 損益計算書欄と貸借対照表欄の「差額」が一致する理由
当期純利益は、損益計算書欄では「収益－費用」として、貸借対照表欄では「資産－（負債＋純資産）」の差額として現れる。第1章で学んだ**損益法と財産法**が、精算表の中で同時に計算され、同じ答えになるのだ。両方の欄の差額が一致しなければ、どこかに誤りがある。精算表は、それ自体が強力な検算装置である。
::

日付が変わる少し前。損益計算書の欄を足し上げると、収益合計は18,645,000円（売上18,600,000＋受取手数料45,000）、費用合計は16,645,000円。**税引前当期純利益は2,000,000円**だった。
ひより：「これで、税金が計算できます」

## 月次決算をしている場合の決算整理

説明を聞き終えた片山は、少し考えてから言った。
片山：「172万円のズレを、決算の朝に初めて知るのは、もうごめんや。毎月、分かるようにはできんのか」
ひより：「できます。毎月、小さな決算をするんです。**月次決算**といいます。減価償却費なら、1年分を12で割って、毎月計上していきます」
片山：「ほな、年度末の決算は楽になるな」
ひより：「はい。ただ、1つだけ注意があります。3月の決算のときには、もう11か月分が計上されています。そこにまた1年分を足したら、二重になってしまうんです」

::example 月次で減価償却費を計上している場合
建物の減価償却費は、年間見積額360,000円を月割で毎月計上している。決算整理前残高試算表の減価償却費は330,000円（4月〜2月の11か月分）である。決算月（3月）分も同様に計上する。
::answer
月割額＝360,000÷12＝30,000円。計上済みの11か月分330,000円に、3月分を加える。
::journal 決算月の1か月分だけを追加計上する
減価償却費 30,000 | 建物減価償却累計額 30,000
::
損益計算書の減価償却費は、330,000＋30,000＝**360,000円**（12か月分）になる。ここで1年分の360,000円を計上してしまうと、11か月分が二重に計上されるので注意しよう。
::trap
問題文の「月次で計上している」という一文を見落とさないこと。決算で追加するのは、まだ計上していない月の分だけだ。
手がかりは、決算整理前残高試算表にある。減価償却費にすでに残高があれば、月次で計上している合図である。
::
::
::

::point 問題文の「月次決算」「毎月計上」を見逃さない
月次決算をしているかどうかは、問題文の「年間見積額を月割で毎月計上している」「4月から2月までは月次決算で処理済み」といった記述で分かる。この記述があったら、決算整理前残高試算表の金額に**すでに何か月分が含まれているか**を確認し、不足する月数分だけを計上する。
::

::danger 決算整理は、粉飾の「最後の舞台」でもある
在庫をいくらと数えるか、貸倒実績率を何%とするか、耐用年数を何年とするか。決算整理の多くは見積りや判断を伴う。だから粉飾の多くは、決算整理仕訳を「書かない」か「都合よく書く」ことで行われる。決算整理のルールを正確に知る人は、粉飾の手口も見抜ける。
::

::real 「粉飾」の開示が、前年の3倍に増えた
東京商工リサーチによると、2026年1〜6月に「不適切な会計・経理」を開示した上場企業は27社・27件。そのうち架空の売上の計上などの**粉飾**が12件と、前年同期の3倍に増えた。
粉飾の多くは、期末の数字をつくる決算整理の場面で行われる。減価償却費を計上しない、期末の在庫を多く数える、引当金を積まない、来期の売上を今期に入れる。たとえば4月に届ける弁当30万円分を、3月31日に「売掛金／売上」で計上すれば、利益は30万円増える。だが前倒しの売上は、翌期の取消か翌期の売上の減少として、必ずどこかに跡が残る。だから監査人は、**決算日の前後**の売上と取消を重点的に確かめる。
::note
出典：[東京商工リサーチ「上場企業の『不適切会計』開示 27社・27件」（2026年7月24日）](https://www.tsr-net.co.jp/data/detail/1203077_1527.html)
::

::cfo 「試算表と決算書で、なぜ利益がこんなに違うのですか？」― どう説明するか
おかわり堂ケータリングは、毎月メインバンクに月次の試算表を出している。2月末（11か月分）の試算表では利益は330万円だった。決算書の当期純利益は140万円。銀行の担当者から電話が来た。
担当者：「1か月で利益が190万円も減っていますね。3月に何があったんですか」
**前提**
- 3月の営業そのものは、例年どおりだった
- 月次では、減価償却費・貸倒引当金・前払保険料などの決算整理を、まったく計上していなかった
- 銀行は、来期に追加の融資を検討している。審査には、来期の月次の試算表も使う
**考えるときの視点**
- 「3月に何かが起きた」のか、「1年分の調整が3月に集まった」のか
- 銀行がこの電話で本当に確かめたいのは、何か
::choice A. 減価償却費などの決算整理を項目ごとに示し、来期は月割で毎月計上すると伝える
**◎ 原因を正確に示し、銀行が審査に使う来期の月次の数字を信じられる形にしている。**
::
::choice B. 減価償却費などの決算整理を項目ごとに示し、原因を正確に説明する
**○ 事実は正確だが、「来期の月次の数字も実態より大きく見えるのか」という不安は残る。**銀行は来期の月次も審査に使う。
::
::choice C. 3月は例年どおりだったと伝え、決算書の数字が正しいと説明する
**△ 間違ってはいないが、なぜ190万円減ったのかに答えていない。**
::
::choice D. 次回から、決算整理を済ませた試算表だけを年に1回出すことにする
**△ 数字のずれは消えるが、月次の情報を出さなくなる。**追加の融資の審査に、不利に働く。
::
::answer 考え方の例を見る
- **「起きたこと」と「記録のしかた」を分ける**：3月に異変があったのではなく、1年分の調整が決算で計上された
- **相手が確かめたいことから考える**：銀行が知りたいのは、今後の月次の数字を信じてよいか
- **再発しない仕組みを示す**：月次でも決算整理を見積もって計上する

::exam 第3問（35点）の攻略法
- 第3問は、精算表・財務諸表（損益計算書と貸借対照表）・決算整理後残高試算表のいずれかの形で出題される。形は違っても、中身はすべて「決算整理仕訳」だ。
- **最初に、すべての決算整理仕訳を問題用紙の余白に書き出す**。いきなり解答欄に記入しない。
- 「期中の未処理事項」（仮受金の内容判明、誤記の訂正など）が決算整理事項の前に並んでいることが多い。これを先に処理しないと、貸倒引当金（売掛金の残高が変わる）や消費税の計算がずれる。
- 減価償却の期中取得分の月割、経過勘定の月数、貸倒引当金の対象債権の合計は、計算ミスの多発地帯。必ず検算する。
- 「月次決算で毎月計上している」とあれば、決算整理では未計上の月（ふつうは決算月）の分だけを計上する。1年分を計上すると二重計上になる。
- 当期純損失の場合、精算表では損益計算書欄の貸方と貸借対照表欄の借方に記入する。
- 法人税等は、すべての修正が終わった後に、税引前当期純利益から計算する。
- 精算表では、損益計算書欄と貸借対照表欄の当期純利益が一致するかを最後に確認する。一致しなければ、どこかの行の転記ミスがある。
- 時間が足りないときは、確実に取れる行（売上原価、減価償却、経過勘定など）を優先して埋める。部分点が積み上がる。
::

::next 精算表は「連結精算表」へ進化する
2級の精算表では、棚卸減耗損・商品評価損、有価証券の評価替えなど、決算整理事項がさらに増える。そして、おかわり堂とケータリング子会社のような親子会社の財務諸表を合算し、グループ内の取引を消去する**連結精算表**へと発展する。
::

::summary
- 決算整理は、期中の記録を、その期の正しい財政状態と経営成績に修正する手続き
- 3級の決算整理事項は、現金過不足・当座借越・売上原価・貸倒引当金・減価償却・消費税・法人税等・経過勘定・貯蔵品
- 月次決算で毎月計上している費用は、決算では未計上の月の分だけを追加で計上する
- 精算表は、試算表から損益計算書・貸借対照表までを1枚で作る作業表。同じ側なら足し、反対側なら引く
- 当期純利益は損益計算書欄の借方と貸借対照表欄の貸方に記入する。両欄の差額の一致が検算になる
- 決算整理で現金は動かない。だが、利益は「お金の動き」から「真実の利益」へと翻訳される
- 第3問は、まず決算整理仕訳をすべて書き出してから解答する
::
