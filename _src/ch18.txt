## 決算 ― 1年間の記録を「通知表」に変える

ひよりは、片山の前に、決算整理前の試算表と、完成した決算書を並べた。
「昨日の夜、お金は1円も動いていません。動かしたのは、記録のほうです」
「記録を動かしただけで、利益が172万円も減るんか」
「はい。これまでの帳簿は、まだ1年分の成績表にはなっていなかったんです」

期中の帳簿は、取引が起きるたびに、主にお金やモノの動きに合わせて記録されている。だが、それだけでは、その期間の本当の成績は分からない。売れ残った在庫は仕入に含まれたままだし、バスや設備の価値の目減りも、来期分まで払った保険料も、まだ反映されていない。
そこで期末に、帳簿の記録を、その期の正しい財政状態と経営成績を表す形に修正する。これが**決算**であり、その中心となる修正の手続きを**決算整理**という。

::steps 決算の手続きの流れ
決算整理前残高試算表を作る | 期中の記録の正しさを確かめ、決算の出発点とする（第17章）
決算整理事項を確認する | 在庫の棚卸し、減価償却、経過勘定など、修正すべき事項を洗い出す
決算整理仕訳を行う | 修正を仕訳として記録し、総勘定元帳に転記する
決算整理後残高試算表・精算表を作る | 修正後の残高を確かめ、財務諸表の下書きを作る
帳簿を締め切る | 収益・費用を損益勘定に集め、当期純利益を繰越利益剰余金に振り替える（第19章）
財務諸表を作る | 損益計算書と貸借対照表を完成させる（第19章）
::

## 精算表 ― 決算の全体像を1枚で見渡す

小野が、机の上にA3の紙を広げた。昨夜、2人で組み上げた表だ。
「決算整理の仕訳を、1つの勘定ずつ試算表に足したり引いたりしていくと、最後に利益が出てくるの」
片山は、紙の左端から右端まで、指で1行をたどった。

**精算表**は、決算整理前残高試算表から出発して、決算整理を加え、損益計算書と貸借対照表の数字までを1枚の表で作る作業表だ。3級で使うのは、試算表・修正記入・損益計算書・貸借対照表の各欄に借方・貸方がある**8桁精算表**である。

::theory 精算表の記入ルール
1. **修正記入欄**：決算整理仕訳を、そのまま借方・貸方に記入する。精算表にない勘定科目（雑損・減価償却費・前払保険料など）は、表の下に行を追加して記入する。
2. **損益計算書欄・貸借対照表欄**：試算表欄の金額に修正記入欄の金額を加減して移す。**同じ側なら足し、反対側なら引く**。
3. 収益・費用の勘定は**損益計算書欄**へ、資産・負債・純資産の勘定は**貸借対照表欄**へ移す。
4. 損益計算書欄の貸方合計（収益）と借方合計（費用）の差額が**当期純利益**。損益計算書欄の**借方**と、貸借対照表欄の**貸方**に同じ金額を記入すると、両方の欄の貸借が一致する。
5. 費用のほうが多い場合は**当期純損失**。損益計算書欄の**貸方**と、貸借対照表欄の**借方**に記入する（利益の場合と左右が逆になる）。
::

::point 損益計算書欄と貸借対照表欄の「差額」が一致する理由
当期純利益は、損益計算書欄では「収益－費用」として、貸借対照表欄では「資産－（負債＋純資産）」の差額として現れる。第1章で学んだ**損益法と財産法**が、精算表の中で同時に計算され、同じ答えになるのだ。両方の欄の差額が一致しなければ、どこかに誤りがある。精算表は、それ自体が強力な検算装置である。
::

片山が見た312万3,000円は、決算整理前の試算表の収益合計（18,660,000円）から費用合計（15,537,000円）を引いた数字だった。そこには、売れ残った在庫も、設備の価値の目減りも、税金も、まだ反映されていなかった。

::table sum 決算整理が当期純利益に与えた影響
| 決算整理 | 利益への影響 |
| 決算整理前の試算表で計算した利益 | 3,123,000 |
| 売上原価の算定（期末在庫が期首より40,000円多い） | 40,000 |
| 減価償却費 | △1,140,000 |

| 貯蔵品への振替 | 12,000 |
| 前払保険料（来期分を費用から除く） | 60,000 |
| 未払利息（当期分を費用に加える） | △30,000 |
| 前受手数料（来期分を収益から除く） | △15,000 |
| 法人税、住民税及び事業税 | △600,000 |

（当座借越の振替と消費税の整理は、資産・負債の間の振替なので、利益には影響しない。）
一晩で消えた172万3,000円の内訳のうち、最大のものは減価償却費の114万円だ。お金はとっくに支払っている設備の購入代金を、今期の負担分として費用に割り振ったのである。
決算整理で、新たにお金が動くことはない。だが、決算整理を経なければ、帳簿は「お金がどう動いたか」の記録にとどまり、「この1年でいくら稼いだのか」という問いには答えられない。決算整理とは、期中の記録を、発生主義と費用収益対応にもとづく**真実の利益**へと翻訳する作業なのだ。
::

## 月次決算をしている場合の決算整理

説明を聞き終えた片山は、少し考えてから言った。
「172万円のズレを、決算の朝に初めて知るのは、もうごめんや。毎月、分かるようにはできんのか」
「できます」とひよりは答えた。「毎月、小さな決算をするんです。ただ、そのときは年度末の仕訳が少し変わります」

第17章で見たように、多くの会社は1年に1回の決算だけでなく、毎月の**月次決算**で損益を把握している。その場合、減価償却費などは、年間の見込額を12か月で割った**月割額を毎月計上**していく。
すると、決算日の時点では、すでに11か月分（4月〜2月）が計上済みになっている。決算整理で計上するのは、**まだ計上していない月（決算月）の分だけ**だ。

::example 月次で減価償却費を計上している場合
建物の減価償却費は、年間見積額360,000円を月割で毎月計上している。決算整理前残高試算表の減価償却費は330,000円（4月〜2月の11か月分）である。決算月（3月）分も同様に計上する。決算整理仕訳をしなさい。
::answer
月割額＝360,000÷12＝30,000円。計上済みの11か月分330,000円に、3月分を加える。
::journal 決算月の1か月分だけを追加計上する
減価償却費 30,000 | 建物減価償却累計額 30,000
::
損益計算書の減価償却費は、330,000＋30,000＝**360,000円**（12か月分）になる。ここで1年分の360,000円を計上してしまうと、11か月分が二重に計上されるので注意しよう。
::trap
問題文の「月次で計上している」という一文を見落とさないこと。決算で追加するのは、まだ計上していない月の分だけだ。
手がかりは、決算整理前残高試算表にある。減価償却費にすでに残高があれば、月次で計上している合図である。
::
::

::point 問題文の「月次決算」「毎月計上」を見逃さない
月次決算をしているかどうかは、問題文の「年間見積額を月割で毎月計上している」「4月から2月までは月次決算で処理済み」といった記述で分かる。この記述があったら、決算整理前残高試算表の金額に**すでに何か月分が含まれているか**を確認し、不足する月数分だけを計上する。
::

::danger 決算整理は、粉飾の「最後の舞台」でもある
決算整理の多くは、見積りや判断を伴う。期末の在庫をいくらと数えるか。貸倒実績率を何%とするか。耐用年数を何年とするか。費用の未払分をどこまで計上するか。
だからこそ、粉飾決算の多くは決算整理の段階で行われる。在庫の水増し（第5章）、引当金の積み不足（第11章）、減価償却の操作（第12章）、未払費用の計上漏れ、そして来期の売上の前倒し計上（第15章）。どれも、決算整理仕訳を「書かない」か「都合よく書く」だけで実行できてしまう。
決算整理のルールを正確に知る人は、粉飾の手口も見抜ける。逆に、ルールを知らない経営者は、知らないうちに数字に欺かれる。
::

::real 「粉飾」の開示が、前年の3倍に増えた
東京商工リサーチによると、2026年1〜6月に「不適切な会計・経理」を開示した上場企業は27社・27件だった。件数は前年同期より少し減ったが、中身は悪くなっている。架空の売上の計上などの**粉飾**が12件と、前年同期の3倍に増え、経理のミスなどの「誤り」（12件）と並んだ。残る3件は着服横領だった。
粉飾の多くは、期末の数字をつくる場面、つまり決算整理で行われる。売上をどの期に入れるか、在庫をいくらと数えるか、引当金をいくら積むか。決算整理のルールが、会社の数字の信頼を支える最後の砦になっている。

**この章の道具で読む ― 片山が「312万円」を守ろうとしたら**
もし片山が、決算整理前の利益312万3,000円を何としても決算書に残したかったら、どんな手があったか。上の表を裏返すと、粉飾の典型的な手口がそのまま見えてくる。
- 減価償却費114万円を計上しない（第12章）
- 期末の在庫を多く数える（第5章）
- 貸倒引当金を積まない（第11章）
- 来期の売上を、今期に入れる
最後の手口を、仕訳で見てみよう。4月2日に届ける予定の学会の弁当30万円分を、3月31日に「届けた」ことにする。

::journal 3月31日：まだ届けていない弁当を、売上に計上する（期末の前倒し）
売掛金 300,000 | 売上 300,000
::
::journal 4月の初め：「注文の取消」などの名目で、同じ仕訳を取り消す
売上 300,000 | 売掛金 300,000
::

前倒しの売上は、翌期の初めに取り消すか、翌期の売上が同じだけ減るかのどちらかで、必ずどこかに跡が残る。だから監査人は、**決算日の前後**の売上と取消を重点的に確かめる。決算整理のルールは、利益を減らす意地悪ではない。こうした誘惑を、帳簿の構造で封じるためのものだ。
::note
出典：[東京商工リサーチ「上場企業の『不適切会計』開示 27社・27件」（2026年7月24日）](https://www.tsr-net.co.jp/data/detail/1203077_1527.html)
::

::cfo 銀行の担当者「試算表と決算書で、なぜ利益がこんなに違うのですか？」
おかわり堂ケータリングは、毎月、メインバンクに月次の試算表を提出している。2月末（4月〜2月の11か月分）の試算表では、利益は**330万円**だった。それを見て「今期は300万円を超える利益ですね」と言っていた銀行の担当者が、決算書を見て首をかしげた。「最終的な利益が140万円とは、ずいぶん減りましたね。何かあったのですか？」
片山は、来週の面談でどう答えるかを、ひよりと一緒に考えている。上の「決算整理が当期純利益に与えた影響」の表に加えて、ひよりは次のことを確かめた。
- 3月は学会や研修会が少ない閑散期で、3月1か月の営業の結果は**△17万7,000円**だった。決算整理前の年間の利益312万3,000円は、2月末までの330万円にこの3月分を加えたものだ
- 銀行が返済の力を見るときは、当期純利益に減価償却費を足し戻した「本業で生んだ現金」を使う
- 借入金は200万円、当座借越は15万円。現金預金は約577万円ある
次の視点で考えてから、最も信頼される対応を選んでほしい。
- 330万円から140万円への差は、**どんな性質のもの**からできているか（事業の悪化か、季節か、計算の時期のずれか、お金の出ていかない費用か、税金か）
- 銀行が本当に知りたいのは、利益の大きさか、**返す力**が損なわれていないかか
- 来年、同じ驚きを繰り返さないために、**月次の数字の作り方**をどう変えるか
::choice A. 「決算整理は会計のルールなので、差が出るのは仕方ありません」と答える
**△ 間違いではないが、説明になっていない。**銀行の担当者が知りたいのは、「事業に何か悪いことが起きたのか、それとも計算の違いだけなのか」だ。ルールだからと答えるだけでは、その不安は消えない。銀行が最も嫌うのは、利益が少ないことではなく、**説明できない変動**である。
::
::choice B. 190万円の差を性質ごとに分けて示し、来期から月次の試算表にも減価償却費と税金の見込みを月割で入れると約束する
**◎ 説明し、返す力を示し、再発を防ぐ。**190万円は、次の4つに分けられる。
- **3月の閑散期の営業**：△17.7万円（季節による。事業の悪化ではない）
- **お金が出ていかない費用**：減価償却費△114万円、貸倒引当金繰入△4.4万円
- **計上の時期のずれ**：売上原価＋4万円、貯蔵品＋1.2万円、前払保険料＋6万円、未払利息△3万円、前受手数料△1.5万円、現金過不足の整理△0.6万円
- **税金**：法人税等△60万円
本業で生んだ現金は、利益140万円＋減価償却費114万円＝**約254万円**。借入金と当座借越の合計215万円は、手元の現金預金約577万円で全額返せる（実質無借金）。そのうえで、来期から減価償却費（月約95万円）と法人税等の見込み（利益の30%）を毎月の試算表に計上すれば、2月末の数字がそのまま決算の目安になる。
::
::choice C. 来期は利益が減らないよう、決算整理の項目をできるだけ省く
**× 粉飾の入り口。**減価償却費を計上しない、未払利息を見落としたことにする、といった「決算整理を書かない」処理は、そのまま利益の水増しになる。上の「実際にあった話」のとおり、粉飾の多くは決算整理の段階で行われる。銀行はそれを見抜くために決算書を読んでいる。
::
::choice D. 誤解を招くので、月次の試算表の提出をやめ、年1回の決算書だけを出す
**× 信頼を自分から手放す。**月次の数字を出さない会社は、銀行から「何か隠しているのでは」と見られる。融資の条件として、月次の試算表の提出を求められていることも多い。問題は試算表を出すことではなく、試算表の作り方にある。
::
::answer 考え方の例を見る
::table 2月末の試算表から決算書までの190万円の差（単位：万円）
| 性質 | 項目 | 利益への影響 |
| 季節による営業の結果 | 3月の営業 | △17.7 |
| お金が出ていかない費用 | 減価償却費、貸倒引当金繰入 | △118.4 |
| 計上の時期のずれ | 売上原価・貯蔵品・経過勘定・現金過不足 | ＋6.1 |
| 税金 | 法人税、住民税及び事業税 | △60 |
|= 合計 |  | △190 |
::
決算整理による利益の変化を説明するときは、次の3段階で考える。
- **分解する**：利益の差を、性質の違う項目に分ける。月次の試算表との差なら、「決算月の営業の結果」と「決算整理」を最初に分けること。
- **性質を伝える**：事業の悪化によるものか、季節によるものか、計算の時期の違いによるものか、お金が出ていく費用か出ていかない費用かを区別する。銀行が知りたいのは、最終的に「返す力」が損なわれていないかだ。
- **仕組みを直す**：月次の試算表にも決算整理の考え方を取り入れ（月次決算）、年度末の「サプライズ」をなくす。
**さらに考えよう：190万円の差の中に「売上の取り消し」が入っていたら？**
仮に、2月末までに計上した売上のうち50万円が、実は3月に取り消された前倒しの売上だったとしよう（上の「実際にあった話」の手口）。これは季節や計算の時期のずれではなく、**月次の数字そのものが間違っていた**ことを意味する。銀行への説明も「時期のずれです」では済まず、どの月の数字をどう直したかを示し、再発を防ぐ仕組み（決算日前後の売上の確認）まで説明する必要がある。差を分解するのは、説明のためだけでなく、**説明できない差を見つけるため**でもある。
数字の変化を、根拠をもって説明できる会社は信頼される。片山はBの資料を作って銀行を訪ね、翌月から月次の試算表に減価償却費の月割額と、法人税等の見込額を入れ始めた。
::

::exam 第3問（35点）の攻略法
- 第3問は、精算表・財務諸表（損益計算書と貸借対照表）・決算整理後残高試算表のいずれかの形で出題される。形は違っても、中身はすべて「決算整理仕訳」だ。
- **最初に、すべての決算整理仕訳を問題用紙の余白に書き出す**。いきなり解答欄に記入しない。
- 「期中の未処理事項」（仮受金の内容判明、誤記の訂正など）が決算整理事項の前に並んでいることが多い。これを先に処理しないと、貸倒引当金（売掛金の残高が変わる）や消費税の計算がずれる。
- 減価償却の期中取得分の月割、経過勘定の月数、貸倒引当金の対象債権の合計は、計算ミスの多発地帯。必ず検算する。
- 「月次決算で毎月計上している」とあれば、決算整理では未計上の月（ふつうは決算月）の分だけを計上する。1年分を計上すると二重計上になる。
- 当期純損失の場合、精算表では損益計算書欄の貸方と貸借対照表欄の借方に記入する。
- 法人税等は、すべての修正が終わった後に、税引前当期純利益から計算する。
- 精算表では、損益計算書欄と貸借対照表欄の当期純利益が一致するかを最後に確認する。一致しなければ、どこかの行の転記ミスがある。
- 時間が足りないときは、確実に取れる行（売上原価、減価償却、経過勘定など）を優先して埋める。部分点が積み上がる。
::

::next 精算表は「連結精算表」へ進化する
2級の精算表では、棚卸減耗損・商品評価損、有価証券の評価替え、引当金の設定など、決算整理事項がさらに増える。そして、親会社と子会社の個別の財務諸表を合算し、グループ内の取引や債権債務を消去して、グループ全体の財務諸表を作る**連結精算表**へと発展する。
おかわり堂とおかわり堂ケータリングの関係が、まさに親会社と子会社だ。親会社がケータリング会社に食材を売っていれば、グループ全体で見ればそれは「社内の移動」にすぎない。連結会計では、こうしたグループ内の取引を消去して、グループとしての本当の成績を描き出す。上場企業の決算書の主役は、この**連結財務諸表**である。
::

::problem 精算表で、損益計算書欄の借方合計（当期純利益を記入する前）が8,200,000円、貸方合計が8,750,000円だった。当期純利益はいくらで、精算表のどの欄に記入するか。
当期純利益 [[550,000]] 円を、損益計算書欄の [[ア:借方]] と、貸借対照表欄の [[イ:貸方]] に記入する。
::answer
当期純利益＝8,750,000－8,200,000＝**550,000円**。
損益計算書欄の**借方**と、貸借対照表欄の**貸方**に記入する。（費用より収益が多いので、損益計算書欄の借方に差額を記入して貸借をそろえる。貸借対照表欄では、純資産の増加として貸方に記入する。）
::

::problem 決算整理事項のうち、当期純利益に影響を与えないものを2つ選びなさい。
::checks 当期純利益に影響を与えないものに、チェックをつけよう。
| 決算整理事項 | 影響しない |
| ア．当座預金の貸方残高を当座借越勘定に振り替える | ✓ |
| イ．減価償却費を計上する |  |
| ウ．仮受消費税と仮払消費税を相殺し、差額を未払消費税とする | ✓ |
| エ．保険料の前払分を計上する |  |
::
::answer
**アとウ**。どちらも資産・負債どうしの振替であり、収益・費用の勘定が登場しないので、当期純利益は変わらない。

::problem 備品の減価償却は、年間見積額144,000円を月割で毎月計上している（月次決算）。決算整理前残高試算表の減価償却費は132,000円である。決算月の分も同様に計上する。決算整理仕訳と、損益計算書に表示する減価償却費の金額を答えなさい。
損益計算書に表示する減価償却費：[[144,000]] 円（決算整理仕訳は、下の入力欄で答えよう）
::answer
月割額＝144,000÷12＝12,000円。132,000円は11か月分なので、決算月の1か月分を計上する。

::summary
- 決算整理は、期中の記録を、その期の正しい財政状態と経営成績に修正する手続き
- 3級の決算整理事項は、現金過不足・当座借越・売上原価・貸倒引当金・減価償却・消費税・法人税等・経過勘定・貯蔵品
- 月次決算で毎月計上している費用は、決算では未計上の月の分だけを追加で計上する
- 精算表は、試算表から損益計算書・貸借対照表までを1枚で作る作業表。同じ側なら足し、反対側なら引く
- 当期純利益は損益計算書欄の借方と貸借対照表欄の貸方に記入する。両欄の差額の一致が検算になる
- 決算整理で現金は動かない。だが、利益は「お金の動き」から「真実の利益」へと翻訳される
- 第3問は、まず決算整理仕訳をすべて書き出してから解答する
::
