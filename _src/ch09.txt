::mystery 1日も遅れていない支払いを、なぜ銀行は疑ったのか
3月下旬、ナイトオウル交通は、新型の3列独立シート車両を2台、計**1億円**で購入した。代金は、納車の翌月末に一括で支払う契約だ。
決算を終えて1か月がたった5月の連休明け。京和銀行の審査部から、社長の三國に硬い声で電話が入った。
審査部：「御社の決算書を拝見しました。買掛金が**1億2,000万円**もありますね。燃料や部品の仕入れの規模からすると、半年分近くになる。仕入先への支払いが、相当滞っているのではありませんか？　追加融資の判断は、いったん保留させてください」
三國は耳を疑った。ナイトオウル交通は、どの取引先にも**1日たりとも支払いを遅らせたことはない**。バスの代金も、約束どおり4月末にきちんと支払った。融資担当の村井とは信頼関係もある。だが、決算書を審査するのは、会社を直接知らない審査部の担当者だ。
三國は、すぐに鴨川会計事務所に電話をかけた。受けたのは、ひよりだった。その決算書の勘定科目の内訳を確かめたのは、ひより自身だったからだ。
三國：「大川さん、うちは1日も遅れてないのよ。どうして銀行は、支払いが滞ってるなんて言うの」
三國の声は、怒りよりも困惑に近かった。
ひより：「すぐに調べます。明日の朝、本社に伺います」
なぜ銀行は、存在しない「支払遅延」を疑ったのか？
::

その夜、ひよりは京都駅の高速バス乗り場から、ナイトオウル交通の「OWL LINER」に乗った。カーテンで仕切られた3列独立シートの暗がりで、決算書のコピーと、勘定科目の内訳表を膝に広げる。買掛金 1億2,000万円。自分のチェック印が、その横についていた。
数字は、合っていた。合っていることだけを、確かめていた。

## 「本業の商品」か、「それ以外」か ― 未収入金と未払金

バスが静岡を過ぎたあたりで、ひよりは自分が乗っている座席を見回した。新しいシートの匂いがする。この車両そのものが、いま膝の上にある決算書のどこかに載っているはずだ。
ひよりは、第7章で中西に教わったことを思い出した。商品を後払いで買ったら、買掛金。
でも、バス会社にとって、バスは商品だろうか。
ナイトオウル交通は、バスを売って儲けているわけではない。バスを走らせて、運賃で儲けている。バスは、売るための商品ではなく、商売の道具だ。
ひよりは、テキストのページを開いた。本業の商品以外のものを後払いで買ったら**未払金**（負債）。後払いで売ったら**未収入金**（資産）。

::table 後払い・後受けの勘定科目の使い分け
| 取引の対象 | 後で受け取る権利（資産） | 後で支払う義務（負債） |
| 本業の商品の売買 | 売掛金 | 買掛金 |
| 商品以外のもの（固定資産・消耗品など）の売買 | 未収入金 | 未払金 |
::

::example ナイトオウル交通の未払金・未収入金
(1) 3月25日、新型バス2台を100,000,000円で購入し、納車を受けた。代金は4月末に支払う。
(2) 4月30日、(1)の代金を普通預金から支払った。
(3) 本社で不要になった応接セット（備品、取得原価80,000円。購入したばかりで減価償却はまだ行っていない）を、80,000円で中古家具店に売却し、代金は翌月に受け取ることにした。
::answer
::journal (1) バスは商品ではない → 未払金
車両運搬具 100,000,000 | 未払金 100,000,000
::
::journal (2) 未払金の支払い
未払金 100,000,000 | 普通預金 100,000,000
::
::journal (3) 備品も商品ではない → 未収入金
未収入金 80,000 | 備品 80,000
::
(3)は、帳簿価額（取得原価80,000円）と同額で売却したので売却による損益は生じない。減価償却累計額がある固定資産の売却や、売却で損益が出るケースは第12章で学ぶ。
::trap
バスや備品のように**商品ではないもの**の後払いは、買掛金・売掛金ではなく、未払金・未収入金を使う。
「その会社が売るために仕入れたものか」で判断する。バス会社にとって、バスは商品ではなく、商売の道具だ。
::
::
::

::scene 朝6時 ― 新宿、ナイトオウル交通の経理室
経理室の明かりは、もうついていた。森下が、青い顔で待っていた。
森下：「大川さん……すみません。たぶん、僕です」
2人で仕訳帳をめくると、原因はすぐに見つかった。3月25日。バス2台の購入代金1億円が、**買掛金**で処理されていた。
森下：「請求書に『お買い上げ代金』って書いてあって。後払いだったので、仕入の代金と同じだと思って……」
ひより：「私も、合計が合ってることしか確かめてなかった。チェックの印をつけたのは、私です」
本来の買掛金は、2,000万円しかなかった。
出社してきた柏木は、2人の話を最後まで黙って聞いた。それから、静かに言った。
柏木：「銀行は、買掛金を『仕入先への未払い』として読みます。仕入れの規模に比べて買掛金が大きすぎれば、支払いを延ばしている、つまり資金繰りが苦しい、と考える。当然の読み方です」
柏木：「バスの代金は、未払金でした。それなら銀行は、設備を買った代金がまだ払われていないだけだと、一目で分かった」
柏木は、訂正した決算書とバスの売買契約書の写しを鞄に入れた。
柏木：「行きましょう。3人で頭を下げます」
::

京和銀行の応接室で、村井が審査部に事情を説明してくれた。融資は、無事に実行された。帰り道、柏木は森下とひよりに1つだけ言った。
柏木：「請求書の言葉ではなく、何を買ったのかを見て科目を決めなさい」
京都に戻ると、一ノ瀬はひよりの報告を最後まで黙って聞き、それから言った。
一ノ瀬：「チェックの印をつけるときは、数字が合っているかではなく、その数字が何を意味しているかを確かめること。今回、いちばん大事なことを学んだのは、あなたかもしれません」
ひよりは、内訳表の確認手順に1行を書き足した。「買掛金・未払金は、上位5件の相手先と中身を確認する」。

::theory 勘定科目は「読み手へのメッセージ」である
簿記で勘定科目を厳密に使い分けるのは、試験のためではない。決算書の読み手が、数字の意味を誤解しないためだ。
- 買掛金が増えていれば「仕入れが増えたか、支払いを延ばしているか」
- 未払金が増えていれば「設備投資など、本業以外の支出が後払いになっているか」
- 借入金が増えていれば「銀行などから資金を調達したか」
同じ「後で払うお金」でも、その意味はまったく違う。銀行も投資家も、勘定科目ごとに異なる問いを立てて決算書を読んでいる。正しい勘定科目は、会社の実態を正しく伝えるための**共通言語**なのである。
::

## 貸付金と借入金 ― 利息は「月割」で計算する

決算書を見直すついでに、ひよりは柏木と、ほかの「商品以外」の貸し借りの勘定も1つずつ確かめていった。
柏木：「お金を貸したら**貸付金**、借りたら**借入金**。利息は、もらえば**受取利息**、払えば**支払利息**です」
ひより：「利息は、1年分を計算すればいいんですか」
柏木：「借りていた月数で、月割にします。半年しか貸していなければ、半年分です」

::formula 利息の計算（月割）
利息 ＝ 元金 × 年利率 × 貸借期間の月数 ÷ 12
::

::example ナイトオウル交通の貸付金と借入金
(1) 10月1日、グループの車両整備会社に、2,000,000円を期間6か月・年利率3%で貸し付け、普通預金から振り込んだ。
(2) 翌年3月31日、(1)の貸付金が、利息とともに普通預金に返済された。
(3) 銀行から10,000,000円を期間1年・年利率2.4%で借り入れ、普通預金に入金された。
(4) (3)の借入金を、1年後に利息とともに普通預金から返済した。
::answer
::journal (1) 貸付け
貸付金 2,000,000 | 普通預金 2,000,000
::
::journal (2) 返済を受けた：利息は 2,000,000×3%×6/12＝30,000円
普通預金 2,030,000 | 貸付金 2,000,000
 | 受取利息 30,000
::
::journal (3) 借入れ
普通預金 10,000,000 | 借入金 10,000,000
::
::journal (4) 返済：利息は 10,000,000×2.4%×12/12＝240,000円
借入金 10,000,000 | 普通預金 10,240,000
支払利息 240,000 |
::
::trap
年利率をそのまま掛けて、1年分の利息を計上しないこと。期間が6か月なら、6/12を掛けて月割する。
返ってきた元本、返した元本は、収益でも費用でもない。損益になるのは利息の部分だけだ。
::
::
::

::note
※日数で利息を計算するよう指示がある場合は「元金×年利率×日数÷365」とする。
::

### 相手が役員・従業員なら、専用の勘定を使う

ひより：「グループ会社だけじゃなくて、社員にお金を貸すこともあるんですか」
柏木：「あります。おかわり堂さんなら、もっと多いでしょう。相手が役員や従業員なら、勘定を分けます。決算書を読む人が、いちばん気にするところですから」
ひより：「気にする？」
柏木：「会社のお金が、社長個人に流れていないか。逆に、社長が自分のお金で会社を支えていないか。銀行は、そこを真っ先に見ます」

::table 役員・従業員との貸し借り
| 相手 | 貸したとき（資産） | 借りたとき（負債） |
| 役員（取締役など） | 役員貸付金 | 役員借入金 |
| 従業員 | 従業員貸付金 | － |
::

::example おかわり堂の役員・従業員との貸し借り
(1) 店長候補の従業員に、引っ越し資金として300,000円を貸し付け、普通預金から振り込んだ。
(2) 資金繰りが苦しかった創業期、社長個人から運転資金5,000,000円を借り入れ、普通預金に入金された。
(3) 取締役の1人に、1,000,000円を貸し付け、現金で渡した。
::answer
::journal (1) 従業員への貸付け
従業員貸付金 300,000 | 普通預金 300,000
::
::journal (2) 役員（社長）からの借入れ
普通預金 5,000,000 | 役員借入金 5,000,000
::
::journal (3) 役員への貸付け
役員貸付金 1,000,000 | 現金 1,000,000
::
中小企業では、社長が個人のお金を会社に貸して資金繰りを支えることがよくある。それが**役員借入金**だ。逆に、会社のお金を役員に貸している**役員貸付金**が大きい会社は、銀行から「会社の資金が私的に使われていないか」と厳しく見られる。
::trap
相手が役員や従業員のときは、ふつうの貸付金・借入金と区別して、専用の勘定科目を使うことがある。
試験では、使える勘定科目の一覧に「役員貸付金」などがあるかを先に確かめ、あればそれを使う。
::
::
::

## 前払金と前受金 ― 「手付金」と「内金」

最後に、ひよりは決算書の負債の部で、もう1つ大きな数字に目を留めた。前受金。
ひより：「柏木さん、この前受金って……」
柏木：「乗車券です。1か月前から売っているので、まだ走っていない便の運賃が、ここに積み上がっています」
ひより：「お金はもらってるのに、負債なんですか」
柏木：「お客様を運ぶ義務が残っていますから。走るまでは、預かっているお金です」
柏木は、テキストの言葉で言い直した。先に払ったお金は、あとで商品を受け取る権利として**前払金**（資産）。先に受け取ったお金は、あとで商品を渡す義務として**前受金**（負債）。いわゆる手付金や内金だ。

::example おかわり堂の新米の契約
(1) おかわり堂は、京都・丹波の農家と、新米10トン（代金3,600,000円）の購入契約を結び、手付金500,000円を普通預金から支払った。
(2) 秋に新米10トンが納品された。代金のうち手付金を差し引いた残額は、掛けとした。
::answer
::journal (1) 手付金の支払い：前払金（資産）
前払金 500,000 | 普通預金 500,000
::
::journal (2) 納品時：前払金を充当し、残額は買掛金
仕入 3,600,000 | 前払金 500,000
 | 買掛金 3,100,000
::
契約を結んだだけでは仕訳しない（第2章）。だが、手付金を払えば「お金が出ていった」という事実があるので、仕訳が必要になる。
::trap
手付金を払った時点で、仕入を計上してはいけない。商品はまだ届いていない。
納品されたら、仕入は契約の総額3,600,000円で計上する。前払金を引いた残額を仕入にしないこと。
::
::
::

### 夜行バスの乗車券は「前受金」

柏木：「うちの商売は、前受金が主役です。乗車券は、乗る日の1か月前からWebで売れます。お客様は予約したときに払う。でも、その日はまだバスは走っていない」
ひより：「走った日に、初めて売上になる」
柏木：「そうです」

::example 京都行き「OWL LINER 21号」の運賃
(1) 7月1日、8月10日出発の東京発京都行き21号の乗車券28席分（1席9,800円）が完売し、運賃274,400円が普通預金に入金された。
(2) 8月10日、21号が運行された。
(3) 仮に、台風の接近で21号が運休となり、全額を普通預金から払い戻した場合。
::answer
::journal (1) 前受け：まだ運んでいないので負債
普通預金 274,400 | 前受金 274,400
::
::journal (2) 運行した日に、初めて売上になる
前受金 274,400 | 売上 274,400
::
::journal (3) 運休して払い戻した場合
前受金 274,400 | 普通預金 274,400
::
::trap
代金を受け取った日に、売上を計上してはいけない。売上は、バスを運行してサービスを提供した日に計上する。
払い戻しは、売上の取り消しではない。まだ売上になっていないので、前受金を減らすだけだ。
::
::
::

::danger 前受金は「お客様から預かったお金」である
前受金のビジネスは、資金繰りの面では非常に有利だ。サービスを提供する前にお金が入るので、第7章のCCCはマイナスになる。だが、そこには恐ろしい落とし穴がある。
**前受金は、まだあなたのお金ではない。**
受け取った前受金を、本来の運行費用ではなく、新規事業や借金の返済に回してしまう会社がある。平時は、次々に入ってくる新しい前受金で古い前受金の義務をまかなえるので、問題は表面化しない。だが、何かのきっかけで新規の販売が止まった瞬間、払い戻しの請求が殺到し、資金は一気に尽きる。
2020年の感染症の大流行では、多くの旅行・交通・イベント事業者が、大量の払い戻しによって深刻な資金難に陥った。前受金という負債の重さを、帳簿は正直に示しているのである。ただし、それは帳簿が正しくつけられていればの話だ。
::

::real 旅行者から預かった100億円は、どこへ消えたのか
2017年3月、格安の海外旅行で知られた旅行会社「てるみくらぶ」が、負債151億円を抱えて破産した。出発を目前に控えた旅行者が、すでに旅行代金を払い込んでいた。
東京商工リサーチは、同社の決算書を読み解いている。2016年9月期の貸借対照表で、前受金は**17億5,900万円**と記載されていた。ところが、のちに修正された貸借対照表では、前受金は**70億円**。実に3.9倍だ。つまり、旅行者から預かっていたお金という負債を、決算書の上で大幅に少なく見せていたことになる。そして破産を申し立てた時点の修正後の貸借対照表では、前受金は**100億円**に膨らんでいた。これが、旅行を申し込んだ人たちの被害額である。
前受金が帳簿に正しく載っていれば、「預かったお金に見合う預金が、会社に残っていない」ことは、数字で一目瞭然だったはずだ。前受金を少なく見せれば、負債が小さく、利益が大きく見える。前受金の記録は、預かったお金を守るための最後の防波堤なのだ。

**この章の道具で読む ― 前受金の仕訳で、何が起きていたかを再現する**
旅行会社の帳簿では、旅行代金は次の流れで記録される（数字は仕組みを示すための例。単位：万円）。

::journal ① 客Aが、3か月後の旅行代金を払い込んだ（まだ旅行は実施していない）
普通預金 100 | 前受金 100
::
::journal ② 旅行を実施した（預かっていた義務を果たしたので、ここで初めて売上になる）
前受金 100 | 売上 100
::

健全な会社なら、①で預かった100万円は、客Aの旅行の航空券やホテルの代金に使われる。ところが、資金繰りに困った会社は、客Aの100万円で、先に出発する客Bの旅行の代金を払う。帳簿では、客Bの旅行の費用として普通預金が減るだけで、客Aの前受金100万円はそのまま負債に残る。
これを続けると、前受金の残高は膨らみ続けるのに、それに見合う預金は残らない。新しい申込みが入り続けるあいだは回るが、止まった瞬間に、全員に旅行を提供することも、返金することもできなくなる。
そして、この状態を隠すいちばん簡単な方法が、②をまだ旅行が終わっていない段階で行ってしまうことだ。「前受金／売上」の仕訳を前倒しすれば、負債の前受金は小さく、売上と利益は大きく見える。決算書では前受金17億5,900万円、修正後の実態は70億円。差の約52億円は、まだ果たしていない「旅行を提供する義務」だった。前受金の残高と、手元の預金の残高。ひよりが夜行バスの中で見比べた2つの数字が、ここでも答えを握っている。
::note
出典：[東京商工リサーチ「てるみくらぶの『決算書』を読み解く」（2017年5月19日）](https://www.tsr-net.co.jp/data/detail/1188772_1527.html)
::
::

::cfo 「前受金が8,000万円ある。これで新車を買おう」― ストレステストで答える
夏の繁忙期、ナイトオウル交通の普通預金には、乗車券の前受金だけで常時8,000万円ほどが積み上がっている。社長の三國が言った。「このお金、寝かせておくのはもったいない。これを頭金にして、新車をあと2台買おう」
経理部長の柏木は、ひよりと一緒に、過去1年の動きと、起こりうる最悪の事態を整理した。
- 普通預金には、前受金のほかに会社自身のお金もある。前受金は繁忙期に多く、1〜2月の閑散期には半分以下に減る
- 感染症の流行などで**1か月全便が運休**すると、前受金はほぼ全額を払い戻すことになり、新しい予約も止まる。それでも人件費・保険料・借入金の返済などの固定費は毎月かかる
- 台風などで数日全便が運休することは、毎年のように起きる
- 新車は5年間使う。銀行からは5年返済で借りられる
三國の案のほかに、柏木とひよりは3つの案を考えた。次の視点で考えてから選んでほしい。
- 「1か月の運休」が、**前受金が最も多い時期**と、**手元のお金が最も少ない時期**に起きたら、それぞれ払い切れるか
- そのお金は「いつ返すか分からないお金」か、「当分返さなくてよいお金」か。使い道は「すぐ現金に戻るもの」か、「何年も戻らないもの」か
- いつでも引き出せることと、少しでも利息を稼ぐことは、両立するか
::choice A. 前受金のうち5,000万円を、新車2台の頭金に使う（残りは借入れ）
**× 繁忙期にも閑散期にも、最悪の事態を払い切れない。**頭金を払えば、そのお金はバスの車体に変わる。バスは売ってもすぐに現金にならない。仮の設定で試算すると、1か月の運休が繁忙期に起きても閑散期に起きても、払い戻しと固定費に3,500万円以上足りなくなる。
払い戻しができなければ、会社の信用は一夜で崩れる。上の「実際にあった話」と同じ構図だ。
::
::choice B. 新車2台は全額を5年返済の借入れで買い、普通預金には手をつけない
**◎ お金の性質と、使う期間をそろえる。**借入れで買えば、普通預金はそのまま残る。仮の設定では、繁忙期・閑散期のどちらで1か月の運休が起きても、払い戻しと固定費（借入金の返済の増加分を含む）を払い切って、約1,300万円の余裕が残る。
バスは5年かけて稼ぐ資産だから、5年で返す借入れでまかなうのが筋だ。利息はかかるが、「いつ返すか分からないお金（前受金）」を「5年間戻ってこない使い道（バス）」に充てない。これが財務の基本原則である。
::
::choice C. 最悪の事態でも払い切れる範囲の「余裕」だけを頭金にし、残りを借入れでまかなう
**○ 上級者の考え方だが、使える金額は意外に小さい。**毎日新しい予約が入り、毎日運行して前受金が売上に変わる。このサイクルが続く限り、一定額は常に手元に残る。この「滞留する資金」を活用すること自体は、多くの企業がやっている。
だが仮の設定で試算すると、最悪の事態を払い切ったあとの余裕は約1,300万円しかない。それを全部頭金に回せば、余裕はゼロになり、数日の運休の払い戻しにも耐えられない。使えるのはせいぜい数百万円で、「8,000万円を使える」という出発点とは桁が違う。
::
::choice D. 前受金は全額、1年満期の定期預金に入れて利息を稼ぎ、新車は借入れで買う
**△ 安全に見えて、肝心なときに引き出せない。**定期預金は、満期の前に引き出すと利息が減り、手続きに日数がかかることもある。払い戻しは突然、一斉にやってくる。1か月の運休が起きた日に、すぐに使えなければ意味がない。前受金は、いつでも払い戻せる普通預金で持つのが基本だ。
::
::answer 考え方の例を見る
**仮の設定**で、1か月全便が運休した場合を試算してみよう（単位：万円）。
::table 仮の設定：普通預金の中身
| 時期 | 前受金 | 会社自身のお金 | 普通預金の合計 |
| 繁忙期 | 8,000 | 4,000 | 12,000 |
| 閑散期 | 3,000 | 4,000 | 7,000 |
::
（固定費は月2,500万円。新車は1台5,000万円で、借入れは5年返済。Aは借入れが5,000万円なので元本の返済が月約80万円、Bは1億円なので月約170万円増える。）
::table 1か月全便が運休した場合に必要なお金と、手元のお金（仮の設定）
| 案 | 時期 | 普通預金 | 必要な金額（払い戻し＋固定費） | 余裕 |
| A　前受金を頭金に | 繁忙期 | 7,000 | 約10,580 | 約△3,580 |
| A　前受金を頭金に | 閑散期 | 2,000 | 約5,580 | 約△3,580 |
| B　全額を借入れ | 繁忙期 | 12,000 | 約10,670 | 約1,330 |
| B　全額を借入れ | 閑散期 | 7,000 | 約5,670 | 約1,330 |
::
まず事実を確認する。「その8,000万円は、乗客のお金です。帳簿の上では**負債**です」。
前受金のビジネスは、資金繰りの面では有利だ。だが、その有利さは「毎日新しい予約が入る」というサイクルが回っている間だけのものだ。サイクルが止まったときに何が起きるかを、数字で試してから使い道を決める。これを**ストレステスト**という。試すときは、前受金が最も多い時期と、手元のお金が最も少ない時期の**両方**で行う。
**さらに考えよう：運休したら、乗客は全員払い戻しを求めるか？**
実際には、払い戻しではなく「別の日への振り替え」を選ぶ乗客もいる。仮に半分が振り替えを選べば、繁忙期の払い戻しは4,000万円に減り、繁忙期ならAでも払い切れる計算になる（閑散期は、それでも約2,000万円足りない）。だが、それは「乗客の善意」に会社の存続を預ける計算だ。2020年の感染症の流行では、運休が数か月に及び、振り替えた乗客もいずれ払い戻しを求めた。**ストレステストの前提は、都合のよい仮定ではなく、実際に起きた最悪の事例から置く。**
そして、お金の調達と使い道は、期間をそろえる。5年使うバスは5年の借入れで、いつ返すか分からない前受金はいつでも返せる形で。三國はBを選び、新車2台を5年の借入れで買った。翌年の夏、大型の台風で東海道の便が4日間止まったとき、払い戻しの1,200万円は、普通預金からその日のうちに支払われた。
::
::

## 仮払金と仮受金 ― 「とりあえず」記録しておく勘定

帰りのバスを待つあいだ、ひよりは森下と並んでベンチに座っていた。森下はまだ、少し落ち込んでいた。
森下：「大川さん、ほかにも迷う勘定があるんです。運転士さんに、ツアーの前にお金を渡すときとか」
ひより：「何に使うか、まだ決まってないお金？」
森下：「はい。宿代がいくらになるか、帰ってくるまで分からないんです」
ひより：「それは、**仮払金**っていう勘定を使うらしいです。とりあえず渡したことだけ記録しておいて、中身が分かったら正しい勘定に振り替える。逆に、何のお金か分からないまま受け取ったら、**仮受金**」
森下：「とりあえず、っていう勘定があるんですね」
ひより：「現金過不足と、ちょっと似てます」

::example 貸切バスの長距離ツアー
(1) 運転士2名が、貸切バスで立山黒部への2泊3日のツアーに出発するにあたり、宿泊費・高速代などの概算額として現金100,000円を渡した。
(2) 運転士が帰社し、旅費交通費として86,000円を使ったと報告を受け、残額は現金で受け取った。
::answer
::journal (1) 金額が未確定なので、仮払金で処理
仮払金 100,000 | 現金 100,000
::
::journal (2) 精算：確定した費用に振り替え、残額を回収
旅費交通費 86,000 | 仮払金 100,000
現金 14,000 |
::
::trap
お金を渡した時点で、旅費交通費にしないこと。金額が確定していないので、仮払金で記録しておく。
精算のときは、仮払金を**渡した全額**（100,000円）消す。使った額の86,000円だけを消すと、仮払金が残ってしまう。
::
::
::

::point 交通系ICカードのチャージは「仮払金」
営業担当者が使う交通系ICカードに入金（チャージ）したときは、その時点では何に使うかが確定していないので、**仮払金**で処理する。後日、使用した内容が報告されたら、旅費交通費などに振り替える。
::

::journal ICカードに10,000円をチャージし、現金で支払った
仮払金 10,000 | 現金 10,000
::

::journal ICカードで電車代3,200円を支払ったと報告を受けた
旅費交通費 3,200 | 仮払金 3,200
::

::note
※問題文で「チャージ時に旅費交通費として処理する」などの指示がある場合は、それに従う。
::

森下：「この前、何の振込か分からない入金があって、困ったんです」
ひより：「それも、まずは仮受金です。分かってから、振り替えればいい」

::example 誰から振り込まれたのか分からない入金
(1) 普通預金に、内容が不明な300,000円の入金があった。
(2) 調査の結果、(1)は得意先からの売掛金の回収200,000円と、来月納品予定の商品の内金100,000円であることが判明した。
::answer
::journal (1) 内容不明の入金は、仮受金（負債）で処理
普通預金 300,000 | 仮受金 300,000
::
::journal (2) 内容が判明したら、正しい勘定に振り替える
仮受金 300,000 | 売掛金 200,000
 | 前受金 100,000
::
::trap
内容の分からない入金を、売上や雑益にしないこと。理由が分かるまでは、仮受金（負債）で預かっておく。
内金は、判明した時点でもまだ売上ではない。商品を渡すまでは前受金だ。
::
::
::

## 差入保証金 ― 返ってくるはずのお金

京都へ戻ると、おかわり堂の佐伯から相談が届いていた。北白川に新しい店を出すという。契約書の写しには、家賃の横に「保証金」の欄があった。
ひよりは、父の言葉を思い出した。
父：「保証金だけで500万円や」
あのお金は、費用として消えたのだろうか。それとも、どこかに残っていたのだろうか。
一ノ瀬：「保証金は、大家さんに預けておくお金です。家賃を払えなくなったときや、出ていくときの修理代に備えて。出ていくときには、修理代を引いて返ってきます」
ひより：「返ってくるなら……費用じゃない」
一ノ瀬：「そう。**差入保証金**という資産です」
ひよりは、しばらく黙った。父の店の保証金は、利益を1円も減らさなかった。でも、お金は確実に出ていき、店を閉めるまで戻ってこなかった。

::example おかわり堂・北白川店の出店
おかわり堂は、北白川に新店舗を借りる契約を結んだ。保証金1,800,000円（家賃の6か月分）、1か月分の家賃300,000円、不動産会社への仲介手数料300,000円を、普通預金から支払った。
::answer
::journal 保証金は資産、家賃と仲介手数料は費用
差入保証金 1,800,000 | 普通預金 2,400,000
支払家賃 300,000 |
支払手数料 300,000 |
::
::trap
支払った2,400,000円を、まるごと支払家賃にしないこと。「あとで戻ってくるか」で分ける。
- 保証金 → 退去時に戻ってくるので、資産（差入保証金）
- 家賃・仲介手数料 → 戻ってこないので、費用
::
::
::

::journal 数年後に退去し、原状回復費用200,000円を差し引かれた保証金の残額1,600,000円が普通預金に返還された
修繕費 200,000 | 差入保証金 1,800,000
普通預金 1,600,000 |
::

::point 序章を思い出そう
序章の「まんぷく食堂」が新店を出すたびに支払った保証金は、まさにこの差入保証金だ。資産なので、利益は1円も減らない。だが、お金は確実に出ていき、店を閉めるまで戻ってこない。多店舗展開する飲食店にとって、差入保証金は「利益に表れない資金の流出」の代表格である。
::

::table 本章で学んだ債権・債務のまとめ
| 場面 | 資産（権利） | 負債（義務） |
| 商品以外を後払いで売買した | 未収入金 | 未払金 |
| お金を貸し借りした | 貸付金（相手が役員なら役員貸付金、従業員なら従業員貸付金） | 借入金（相手が役員なら役員借入金） |
| 手付金・内金をやり取りした | 前払金 | 前受金 |
| 内容・金額が未確定の支払い・受取り | 仮払金 | 仮受金 |
| 敷金・保証金を差し入れた | 差入保証金 | － |
::

::exam その他の債権・債務の急所
- 「商品か、商品以外か」で、売掛金・買掛金と未収入金・未払金を使い分ける。固定資産の購入代金の後払いは必ず未払金。
- 役員との貸し借りは役員貸付金・役員借入金、従業員への貸付けは従業員貸付金。相手を見て勘定科目を選ぶ。
- 利息は「元金×年利率×月数÷12」。月数の数え間違いに注意（10月1日〜3月31日は6か月）。
- 手付金・内金を払ったら前払金、受け取ったら前受金。商品の受け渡し時に充当する。
- !!「前払金」と「前払費用」、「前受金」と「前受収益」は別物!!。前払金・前受金は**商品などの代金の一部を先に受け払いしたもの**（期中の取引）。前払費用・前受収益は、家賃・保険料・利息など**時間の経過とともに費用・収益になるものを、決算で次期分として繰り延べたもの**（第15章）。名前が似ているので、試験では語群の選び間違いが多い。
- 旅費の概算払い・ICカードのチャージは仮払金。精算時の差額（返金・追加払い）は現金などで処理する。内容不明の入金は仮受金。
- 敷金・保証金は差入保証金（資産）。仲介手数料は支払手数料、家賃は支払家賃（費用）。
::

::next 前受金は「契約負債」へ ― 収益認識という大テーマ
2級・1級では、「いつ、いくらの売上を計上するか」を定めた**収益認識に関する会計基準**を本格的に学ぶ。夜行バスの乗車券のように、代金を先に受け取ってサービスを後で提供する場合、受け取った対価は**契約負債**と呼ばれる。ポイント付きの販売、複数のサービスを組み合わせた契約、返品の可能性がある販売……。売上の計上は、実はとても奥が深い。
また2級では、建設中の建物などの代金を前払いしたときの**建設仮勘定**や、商品以外の取引で手形を使ったときの**営業外受取手形・営業外支払手形**も学ぶ。「本業か、それ以外か」という本章の視点は、上の級でもずっと使い続けることになる。
::

- 商品の後払い・後受けは売掛金・買掛金、商品以外は未収入金・未払金。勘定科目の誤りは、決算書の読み手を誤解させる
- 貸付金・借入金の利息は「元金×年利率×月数÷12」で月割計算する
- 手付金・内金は前払金（資産）・前受金（負債）。前受金は「まだ自分のお金ではない」負債である
- 内容や金額が未確定な支払いは仮払金、受取りは仮受金。確定したら正しい勘定に振り替える。ICカードのチャージは仮払金
- 敷金・保証金は差入保証金（資産）。費用にならないが、お金は出ていく
