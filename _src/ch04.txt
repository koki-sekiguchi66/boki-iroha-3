::mystery 残高ゼロの口座から、なぜ500万円の小切手が落ちたのか
2026年9月の月末。京都・洛北の食肉卸、洛北ミートの事務所は、冷蔵倉庫の機械音と、電話の声でいつも騒がしい。月次巡回に来たひよりの向かいで、経理担当の中西が、取引先の信用金庫から届いた案内を机の端に寄せた。
中西：「見てください。『小切手・手形の振出の受付を終了いたします』ですって。紙の小切手も、もうすぐおしまいです」
その最後の月に、事件は起きた。
今朝、社長の北村が、40年来の付き合いがある畜産会社に**500万円の小切手**を手渡した。先代からの習慣で、この畜産会社への支払いだけは、今も小切手なのだ。ところが午後、中西がネットバンキングを開くと、当座預金の残高は**20万円**しかなかった。大口の得意先からの入金が、3日遅れていたのだ。
中西の顔から、血の気が引いた。
中西：「不渡りになる……」
ひより：「不渡り、って」
中西：「残高が足りなくて、小切手が落ちないことです。半年で2回出したら、銀行と取引できなくなります。会社が、終わります」
ひよりは、画面の数字と中西の顔を見比べることしかできなかった。父の店のシャッターの貼り紙が、頭をよぎった。
翌日の夕方、ひよりの携帯が鳴った。中西からだ。声が震えている。
中西：「大川さん、落ちたんです。小切手が」
ひより：「落ちた……って、不渡りに？」
中西：「違います。何事もなかったみたいに、決済されてるんです。でも、口座の残高が『マイナス480万円』って出てて」
ひより：「よかった……んですよね？」
電話の向こうで、中西はしばらく黙った。
中西：「マイナス480万円の預金なんて、あるんでしょうか」
残高がほぼゼロの口座から、なぜ500万円が支払えたのか？　そして、このマイナス残高の正体は何なのか？

## 預金の基本 ― 普通預金と定期預金

事務所に戻ったひよりが一部始終を話すと、一ノ瀬はペンを置いた。
一ノ瀬：「マイナス残高の正体を知るには、まず銀行口座の種類を整理しましょう。大川さんが今月回った顧問先の口座を、全部書き出してみてください」
ひより：「アイアンワークスの普通預金、それから定期預金。洛北ミートの当座預金……。口座って、そんなに種類があるんですか」
一ノ瀬：「会社が銀行に預けているお金は、全部**預金**という資産です。ただ、使い道によって口座の種類が違います。代表的なのは3つ」

::table 会社が使う主な預金
| 種類 | 特徴 | 会社での主な使い道 |
| 普通預金 | いつでも預け入れ・引き出しができる。利息がつく | 売上の入金、給料・経費の振込、口座振替 |
| 定期預金 | 一定期間引き出せない代わりに、普通預金より利息が高い | 余裕資金の運用、借入れの担保 |
| 当座預金 | 小切手や手形の支払いに使う決済用の口座。利息はつかない | 取引先への小切手・手形による支払い |
::

ひより：「普通預金と定期預金の仕訳は、現金と同じでいいんですか」
一ノ瀬：「同じです。資産だから、増えたら借方、減ったら貸方。アイアンワークスの松尾さんから、ちょうど6月の通帳の写しが届いています。やってみましょう」

::example IRONWORKS 24の預金取引
(1) 6月分の会費のうち、口座振替分3,200,000円が普通預金に入金された。
(2) 普通預金から2,000,000円を、1年満期の定期預金に預け替えた。
(3) 定期預金2,000,000円が満期となり、利息6,000円とともに普通預金に入金された。
::answer
::journal (1) 会費の入金（ジムの売上）
普通預金 3,200,000 | 売上 3,200,000
::
::journal (2) 普通預金から定期預金へ
定期預金 2,000,000 | 普通預金 2,000,000
::
::journal (3) 満期・利息の受取り
普通預金 2,006,000 | 定期預金 2,000,000
 | 受取利息 6,000
::
預金どうしの振り替えは「資産の増加・資産の減少」。利息は収益（受取利息）だ。
::trap
(3)で普通預金に入るのは、元本と利息を合わせた2,006,000円。受取利息（収益）になるのは6,000円だけで、戻ってきた元本を収益にしてはいけない。
普通預金・定期預金・当座預金は、それぞれ別の勘定科目だ。「預金」とひとまとめにしないこと。
::
::
::

::note
※実際の預金利息には税金（源泉所得税など）が差し引かれるが、3級では問題文の指示がない限り考慮しない。
::

ひより：「最近は、小切手よりも振込のほうが多いですよね」
一ノ瀬：「ええ。ただ、振込には手数料がかかります。手数料は代金とは分けて、支払手数料という費用にします。問題は、その手数料を誰が負担するかです」

::example 振込手数料は、誰が負担するかで仕訳が変わる
洛北ミートは、仕入先の畜産会社に対する買掛金（後払いの仕入代金）500,000円を、普通預金から振り込んだ。振込手数料は660円である。
(1) 振込手数料を洛北ミートが負担する場合
(2) 振込手数料を畜産会社が負担する約束で、手数料分を差し引いて振り込んだ場合
::answer
::journal (1) 当社負担の手数料は「支払手数料」
買掛金 500,000 | 普通預金 500,660
支払手数料 660 |
::
::journal (2) 先方負担なら、手数料を差し引いた額で買掛金を消す
買掛金 500,000 | 普通預金 500,000
::
(2)では、差し引いた660円を合わせて買掛金500,000円が消え、口座からは499,340円＋手数料660円＝500,000円が出ていく。手数料は先方の負担なので、当社の費用は発生しない。
ただし、2026年1月に施行された**取適法**（改正下請法）では、対象となる下請取引で、振込手数料を受け取る側（中小の受託事業者）に負担させることが禁止された。(2)のやり方は、取引の種類によっては法律違反になる。
::trap
仕訳を書く前に「手数料はどちらが負担するか」を確かめること。当社負担のときだけ、支払手数料（費用）が出てくる。
(2)で支払手数料を計上すると、負担していない費用を計上することになる。先方負担でも、消える買掛金は500,000円全額だ。
::
::
::

### 複数の口座は「銀行名つきの勘定」で管理する

アイアンワークスの通帳の写しは、2冊あった。会費の引き落とし用の京都中央銀行と、給料の振込用の洛北信用金庫だ。
ひより：「2冊とも『普通預金』で記録したら、どっちの口座にいくらあるのか、分からなくなりませんか」
一ノ瀬：「なります。だから、口座ごとに勘定科目を分けます。銀行の名前を付けるんです」

::journal 京都中央銀行の普通預金から、洛北信用金庫の普通預金へ1,500,000円を移した
普通預金洛北信用金庫 1,500,000 | 普通預金京都中央銀行 1,500,000
::

::note
※試験では「普通預金A銀行」「当座預金B銀行」のように、問題文で指定された勘定科目を使う。指定がなければ「普通預金」でよい。
::

## 当座預金と小切手 ― 「紙1枚」で支払うための口座

ひより：「洛北ミートの口座だけ、『当座預金』でした。これは何が違うんですか」
一ノ瀬：「当座預金は、小切手で支払うための口座です。会社は銀行と契約して、小切手帳をもらいます。支払うときは、小切手に金額と署名を書いて相手に渡す。これを『振り出す』といいます」
ひより：「渡された相手は？」
一ノ瀬：「自分の銀行に持ち込みます。すると、振り出した会社の当座預金から、お金が引き落とされます」

::steps 小切手による支払いの流れ
洛北ミートが小切手を振り出す | 仕入先の畜産会社に、金額を書いた小切手を渡す
畜産会社が銀行に持ち込む | 自社の取引銀行に小切手を預ける（取立てを依頼する）
洛北ミートの当座預金から引き落とされる | 手形交換所（現在は電子交換所）を通じて決済され、代金が畜産会社の口座に入る
::

ひより：「じゃあ、北村社長が小切手を渡した日は、まだお金は減ってないんですね」
一ノ瀬：「口座の上では、まだです。でも簿記では、小切手を振り出した時点で当座預金を減らします。渡した瞬間に、支払いは済んだと考えるんです」

::journal 洛北ミートは、畜産会社から牛肉を仕入れ、代金5,000,000円を小切手を振り出して支払った
仕入 5,000,000 | 当座預金 5,000,000
::

::note
※「仕入」は、販売するための商品を買ったときに使う勘定科目（第5章）。
::

一ノ瀬：「小切手でいちばん間違えやすいのは、『誰が振り出した小切手か』です。第3章の出町柳店を思い出してください」
ひより：「学会からもらった小切手は、現金でした」
一ノ瀬：「そう。自分が振り出したのか、他人が振り出したのかで、勘定科目が変わります」

::table 小切手の仕訳 ― 誰が振り出したかで決まる
| 場面 | 仕訳で使う勘定 | 理由 |
| 自社が小切手を振り出して支払った | 当座預金（貸方） | 自社の当座預金が減る |
| 他社が振り出した小切手を受け取った | 現金（借方） | 通貨代用証券（第3章） |
| 他社振出の小切手を受け取り、ただちに当座預金に預け入れた | 当座預金（借方） | 現金を経由せず当座預金が増える |
| 自社が以前振り出した小切手を受け取った | 当座預金（借方） | 振り出したときに減らした当座預金が戻る |
::

その翌週、ひよりは中西から、得意先から受け取った小切手を3枚見せられた。
中西：「この3枚、全部違う仕訳になるって、本当ですか」
ひより：「誰が振り出したかと、受け取ったあとどうしたかを、見れば分かります」

::example 小切手の受取り3パターン
洛北ミートは、得意先の飲食店3社から売掛金（後払いの代金）をそれぞれ小切手で回収した。
(1) A社が振り出した小切手200,000円を受け取った。
(2) B社が振り出した小切手300,000円を受け取り、ただちに当座預金に預け入れた。
(3) 以前に洛北ミートがC社に振り出した小切手100,000円を、C社から受け取った。
::answer
::journal (1) 他人振出小切手 → 現金
現金 200,000 | 売掛金 200,000
::
::journal (2) ただちに当座預金へ → 当座預金
当座預金 300,000 | 売掛金 300,000
::
::journal (3) 自己振出小切手の戻り → 当座預金
当座預金 100,000 | 売掛金 100,000
::
(3)は、洛北ミートが振り出した小切手が、まだ銀行に持ち込まれないまま、別の取引の支払いとして戻ってきたケース。振り出したときに減らした当座預金を元に戻すので、当座預金の増加とする。
::trap
3つを見分ける手がかりは「誰が振り出したか」と「すぐ預けたか」の2点だけ。
- 他人が振り出した小切手を受け取った → 現金
- 受け取ってただちに当座預金に預けた → 当座預金
- 自社が振り出した小切手が戻ってきた → 当座預金（減らした分を元に戻す）
::
::
::

::point 当座預金出納帳
当座預金の入出金を詳しく記録する補助簿が**当座預金出納帳**だ。小切手の番号や、残高が借方（預金がある）か貸方（借越している）かを記入する欄がある。後で学ぶ当座借越が起きていないかを、日々確認するための帳簿である。
::

::table compact sum 当座預金出納帳（洛北ミート・9月）
| 日付 | 摘要 | 預入 | 引出 | 借／貸 | 残高 |
| 9/1 | 前月繰越 | 200,000 |  | 借 | 200,000 |
| 9/28 | 畜産会社へ買掛金支払い　小切手No.105 |  | 5,000,000 | 貸 | 4,800,000 |
| 9/30 | 得意先から売掛金回収 | 6,000,000 |  | 借 | 1,200,000 |
| 9/30 | 次月繰越 |  | 1,200,000 |  |  |
|= |  | 6,200,000 | 6,200,000 |  |  |
| 10/1 | 前月繰越 | 1,200,000 |  | 借 | 1,200,000 |
::

::note
※「借／貸」欄は、残高が預金（借方残高）なら「借」、当座借越（貸方残高）なら「貸」と書く。9月28日の時点では、残高を超える小切手を振り出したので「貸 4,800,000」（当座借越）になっている。3日遅れていた得意先の入金が9月30日に届き、借越は解消した。月末に「次月繰越」を引出欄に書いて締め切る。
::

## 答えの鍵 ― 当座借越

ひよりは、9月の当座預金出納帳の「貸 4,800,000」という行を指でなぞった。
ひより：「残高を超えて小切手を振り出したのに、銀行が払ってくれた。どうしてなんでしょう」
中西：「私にも分からないんです」
ひより：「銀行との契約書、見せてもらえますか」
中西が棚から出してきたファイルに、「当座勘定貸越約定書」という書類が挟まっていた。日付は12年前。前任の経理部長の印が押してある。
ひより：「これです。**当座借越**（とうざかりこし）」
中西：「とうざ、かりこし？」
ひより：「決めておいた限度額までなら、残高を超えても、銀行が足りない分を立て替えて払ってくれる契約です。昨日、一ノ瀬さんに教わりました」

::theory 当座借越 ― 自動で発動する「借金」
当座借越契約とは、銀行とあらかじめ取り決めた限度額（**借越限度額**）までなら、当座預金の残高を超えて小切手を振り出しても、銀行が不足分を立て替えて支払ってくれる契約だ。
残高を超えて支払った部分は、実質的には**銀行からの借入れ**である。もちろん利息もかかる。
つまり、口座の「マイナス残高」の正体は、預金ではなく**負債**なのだ。
::

::solve 残高ゼロでも小切手が落ちた理由
洛北ミートは、メインバンクと**借越限度額1,000万円の当座借越契約**を結んでいた。前任の経理部長が、万が一に備えて用意しておいた命綱だ。
当座預金の残高20万円に対して500万円の小切手が持ち込まれたため、銀行は不足する480万円を自動的に立て替えた。口座に表示された「マイナス480万円」は、預金ではなく、銀行に対する**480万円の借金**である。
命綱は機能した。だが、同時に忘れてはならない。もし限度額を超えていたら、あるいは当座借越契約がなかったら、その小切手は**不渡り**になっていた。
「つまり、あの日、洛北ミートは銀行から480万円を借りたんです」とひよりが言うと、中西はようやく笑った。「借りた覚えのない借金に、助けられたわけですね」
::

中西：「つまり、あの日、洛北ミートは銀行から480万円を借りた……」
ひより：「はい。借りた覚えのない借金に、助けられたんです」
中西は、ようやく笑った。
中西：「前の部長に、お礼を言わないと」

### 当座借越の仕訳 ― 期中と決算で扱いが変わる

中西：「でも、帳簿にはどう書けばいいんですか。『借入金』ですか」
ひより：「期中は、当座預金のままでいいそうです。残高がマイナスになっても、当座預金の勘定で記録します」

::taccount 当座預金（洛北ミート）
前日残高 200,000 | 仕入（小切手） 5,000,000
::

ひより：「右の合計が左より480万円多い。これを『貸方残高』といいます。借越の額です」
中西：「でも、マイナスの預金って、資産じゃないですよね」
ひより：「そこで、決算の日だけは、借金として表示し直します。当座借越という負債に振り替えるんです」

::journal 決算日：当座預金勘定の貸方残高4,800,000円を当座借越勘定に振り替えた
当座預金 4,800,000 | 当座借越 4,800,000
::

::note
※当座借越勘定ではなく「借入金」勘定に振り替えるよう指示されることもある。問題文の指示に従うこと。貸借対照表では「借入金」として表示する。
::

中西：「決算が終わったら、元に戻すんですか」
ひより：「はい。翌期の最初の日に、逆の仕訳をします。**再振替仕訳**といいます」

::journal 翌期首：再振替仕訳（決算日の仕訳の逆）
当座借越 4,800,000 | 当座預金 4,800,000
::

::point なぜ再振替仕訳をするのか
期中は「当座預金」1つの勘定で入出金を記録するルールだからだ。期首に戻しておけば、その後に預金が入金されたとき、いつもどおり「当座預金」で仕訳すればよく、借越が自動的に解消されていく。再振替仕訳は、第15章の経過勘定でも再び登場する、簿記の重要なテクニックだ。
::

::danger 不渡り ― 「2回」で企業は死ぬ
当座預金の残高（と借越限度額）を超える小切手や手形は、決済されずに**不渡り**になる。
不渡りを出した事実は、手形・小切手の決済網に参加する金融機関の間で共有される。そして**6か月以内に2回目の不渡りを出すと、銀行取引停止処分**となり、2年間、その会社は金融機関と当座取引も融資取引もできなくなる。仕入先は掛けで売ってくれなくなり、銀行は1円も貸してくれない。多くの企業にとって、これは**倒産と同じ意味**を持つ。
1回目の不渡りでさえ、「あの会社は危ない」という噂は一瞬で広まる。だからこそ、経理担当者は月末の当座預金残高を、文字どおり命がけで管理してきたのだ。
::

::real 140年続いた「紙の決済」が、終わろうとしている
2022年11月4日、全国銀行協会は手形・小切手の決済をデジタル化した**電子交換所**を稼働させ、全国179か所の手形交換所を廃止した。最も古いものは140年以上の歴史をもっていた。銀行の行員が紙の束を抱えて交換所に集まる光景は、このとき姿を消した。いまは各銀行が紙の手形・小切手をスキャンし、その画像データをやり取りしている。
そして紙そのものも、なくなろうとしている。全国銀行協会は、**2026年度末（2027年3月末）**までに電子交換所での手形・小切手の交換枚数をゼロにすることを最終目標に掲げる。これに合わせて多くの金融機関が「最終振出期限」を設け、たとえば紀北信用金庫や千葉信用金庫は**2026年9月30日**を期限とした。
**この章の道具で読む ― 最後の小切手と、最初の振込**
洛北ミートが畜産会社から牛肉を仕入れると、まず「仕入 5,000,000／買掛金 5,000,000」で買掛金が生まれる。支払方法が変わって違いが出るのは、その買掛金を払うときだ。2つの時代の仕訳で並べてみよう。

::journal 2026年9月まで：小切手を振り出して支払う（振り出した時点で当座預金を減らす）
買掛金 5,000,000 | 当座預金 5,000,000
::
::journal 2026年10月から：普通預金から振り込む（手数料660円は洛北ミートが負担）
買掛金 5,000,000 | 普通預金 5,000,660
支払手数料 660 |
::

変わるのは、貸方の勘定科目だけではない。小切手の時代は、「振り出した日」に帳簿の当座預金を減らし、相手が銀行に持ち込んで実際に引き落とされるのは数日後だった。この時間差のあいだに得意先の入金が間に合えば、借越を使わずに済むこともある。振込では、帳簿の日付と口座からお金が出る日が同じになる。
そしてもう1つ。当座借越は、当座預金に付く契約だ。普通預金からの振込では、残高が足りなければ、その振込はそもそも実行されない。不渡りの危険はなくなるが、「足りない日を自動で埋めてくれる命綱」も一緒に消える。紙の小切手をやめる会社は、その命綱を、借入れの枠など別の形で用意し直す必要がある。中西が下の判断を迫られたのは、ちょうどこの切り替えの月だった。
日商簿記3級も、2027年4月以降の試験から、紙の手形・小切手に関する論点を外す予定だ。ただし、仕組みがデジタルに変わっても、「支払いの約束が期日に果たされなければ、その会社は信用を失う」という本質は変わらない。電子記録債権（でんさい）にも、支払不能を2回起こすと取引停止になるルールがある（第8章）。
::note

::cfo 「借越の枠を3倍にしてもらおう」― 本当にそれが最善か？
肝を冷やした北村は、翌朝の会議で言った。ひよりも、顧問の立場で同席していた。
北村：「今回は助かった。だが次は分からない。銀行に頼んで、借越限度額を1,000万円から3,000万円に増やしてもらおう」
中西は、この半年の当座預金の動きと、関係する契約を調べてから会議に臨んだ。
- 毎月25日に、畜産会社への支払いが集中する。25日に払う約束なので、畜産会社は代金の**0.2%を値引き**してくれている（早期支払いの割引）
- 得意先からの入金は月末に集中する。残高が最も低くなるのは毎月26〜30日
- この半年に当座借越を使ったのは3回。3回とも、入金が遅れた**同じ3社**が原因だった
- 当座借越の契約は**1年ごとの更新**で、銀行は決算書を見て限度額を見直す。限度額を増やすには、**定期預金を担保に差し入れる**ことを求められている
- 9月末で小切手は使えなくなる。ただし、当座預金からの振込にも借越は使える
中西がまとめた案は4つ。
- **A　借越限度額を3,000万円に増やす**
- **B　長期で3,000万円を借り、普通預金に置いておく**
- **C　入金が遅れる3社に督促し、遅れが続けば新しい注文をでんさいか前払いに切り替えてもらう**
- **D　振込への切り替えにあわせて、畜産会社への支払日を25日から月末に移す**
次の視点で考えてから選んでほしい。
- その案は、谷ができる**原因**に効くのか、谷を**借金で埋める**だけなのか
- 目に見える利息や手数料のほかに、**見えにくいコスト**はないか（担保に入れたお金、手放す割引）
- 本当に必要になったとき、その手は**確実に使えるか**
::choice A. 借越限度額を3,000万円に増やす
**○ 保険としては安いが、「いざというとき」に頼れない。**使った日数分しか利息がかからないので、仮の設定では利息は年1万円にも満たない。見えにくいのは担保の定期預金だ。そのお金は借入金の返済などに使えないので、返していれば減らせた利息の分が実質の費用になる。仮の設定で合わせても年約16万円で、保険としては安い。
問題は、枠が毎年の更新だということだ。業績が落ちて本当に必要になったときほど、枠は削られやすい。**最も必要なときに最も消えやすい命綱**であり、入金が遅れる得意先という原因も、そのまま残る。
::
::choice B. 長期で3,000万円を借り、普通預金に置いておく
**△ 確実だが、高くつく。**使わない日も全額に利息がかかる。仮の設定では年約45万円。残高が足りなくなるのは年に数日だけなのに、1年中お金を借りっぱなしにすることになる。更新のない資金なので、枠が削られる心配がないのは長所だ。
::
::choice C. 入金が遅れる3社への督促と、支払条件の切り替え
**◎ 原因そのものに手を打つ。直接の費用はほぼゼロ。**この半年の3回の借越は、すべて3社の入金の遅れが原因だった。3社の入金が期日どおりに入れば、月末の谷はほとんど消える。
注意すべきは、3社が取引をやめてしまう場合だ。仮に1社を失えば、年に数百万円の粗利が消える。だから、いきなり条件を突きつけるのではなく、まず督促し、遅れが続く相手にだけ「でんさいなら期日どおりに確実に入金される」条件を提案する。遅れが常態化している相手は、いずれ貸倒れ（第11章）につながるおそれもある。
::
::choice D. 支払日を25日から月末に移す
**△ 谷は消えるが、4案のうち最も高い。**入金と支払いが同じ月末にそろえば、谷そのものがなくなる。一見いちばん賢い手に見える。
だが、早期支払いの割引0.2%を手放すことになる。「0.2%」は小さく見えるが、月末より約5日早く払うことへのお礼で、年率に直すと0.2%×365日÷5日＝**約15%**にもなる。仮の設定では年約192万円で、借越の利息の200倍を超える。年2.5%の借越を使ってでも、割引を受けるほうがずっと得なのだ。
::
::answer 考え方の例を見る
**仮の設定**で、1年あたりの費用を試算してみよう。
- 畜産会社への支払いは月8,000万円。借越は1回あたり約400万円を5日間、年6回使う。借越の利率は年2.5%
- 限度額を増やす条件は、定期預金1,000万円の担保（利息年0.1%）。そのお金で借入金を返していれば、年1.6%の利息を払わずに済んだ
- 長期借入れは年1.6%。3社のうち1社を失うと、粗利が年約840万円減る
::table 4つの案の1年あたりの費用と効果（仮の設定）
| 案 | 1年あたりの費用 | 3社の遅れが続いた場合 | 弱点 |
| A　借越枠の拡大 | 約16万円（担保の見えないコストを含む） | 埋められる | 毎年の更新。業績が落ちると削られる |
| B　長期借入3,000万円 | 約45万円 | 埋められる | 使わない日も利息がかかる |
| C　3社の回収改善 | ほぼゼロ | 遅れそのものがなくなる | 取引を失えば粗利が減る |
| D　支払日を月末へ | 約192万円 | 谷が消える | 早期支払いの割引を失う |
::
当座借越の「マイナス残高」は借金だ。枠を増やす（A）、先に借りておく（B）は、どちらも「足りない日を借金で埋める」手で、足りなくなる原因は残る。そしてDは、表面の金利が見えない「割引の放棄」というコストを見落とすと選んでしまう。**支払条件の割引は、年率に直して借入金利と比べる**のが実務の鉄則だ。
優先順位はこうなる。
- **原因を断つ**：入金の遅れを止める（C）
- **安い保険を残す**：小切手をやめても当座預金の口座は残し、そこから振り込むことで、いまの1,000万円の借越枠を不測の事態の保険として維持する
- **保険の弱点を知る**：借越枠は毎年見直される。業績が落ちる前に、必要なら長期の借入れ（B）に切り替える
**さらに考えよう：3社のうち1社が、取引額の大きい得意先だったら？**
その1社を失うと、粗利が年1,000万円を超えて減るとしよう。強く督促して取引を失えば、借越の費用（年十数万円）の何十倍もの損になる。この場合は、条件を変えるより先に、相手の資金繰りの事情を聞き、**与信の上限（与信枠）を決めたうえで取引を続ける**ほうがよいこともある（第11章）。回収の改善は、相手ごとの「失うものの大きさ」と比べて強さを決める。
中西は、3か月先までの**日次の資金繰り表**を作り、残高がマイナスになる日を事前に知る仕組みも整えた。表の形は、ひよりが序章で一ノ瀬に教わった資金繰り表をそのまま渡した。命綱は、使わないで済むときに最も価値がある。
::

## 小口現金 ― 現場の「小さな支払い」を仕組みで管理する

翌週、ひよりはおかわり堂本部の巡回で、佐伯から別の相談を受けた。
佐伯：「出町柳店の件以来、店の経費をレジから出すのをやめたいんです。でも、急に切れたゴミ袋や、宅配便の送料はどうしても出てきます」
ひより：「毎回、本部に申請してもらうんですか」
佐伯：「それでは、店が回りません」
一ノ瀬：「店長に、支払い専用の小さなお財布を持ってもらいましょう。**小口現金**（こぐちげんきん）です。お金を預かって支払う人を、小口係と呼びます」
佐伯：「お財布の中身は、どうやって管理するんですか」
一ノ瀬：「毎回、使った分だけ補給します。そうすれば、お財布の中身と領収書の合計は、いつも同じ額になります」

::theory 定額資金前渡法（インプレスト・システム）
小口現金の管理では、**定額資金前渡法**（インプレスト・システム）が広く使われている。
1. 会計係（本部の経理）が、一定額（例：30,000円）を小口係に前渡しする
2. 小口係は、そこから日々の小さな支払いを行い、小口現金出納帳に記録する
3. 一定期間（例：1週間）ごとに、小口係が支払いの内容を会計係に報告する
4. 会計係は、**使った金額と同額**を補給する。これで、小口現金は毎回もとの定額に戻る
「使った分だけ補給する」ので、手元の小口現金と支払いの記録の合計は、常に定額と一致する。ズレがあればすぐに分かる、よくできた仕組みだ。
::

佐伯は、さっそく今出川店で試すことにした。最初の1週間の記録が、翌週の月曜に本部に届いた。

::example おかわり堂・今出川店の小口現金
(1) 6月1日、本部の会計係は、今出川店の店長（小口係）に、小口現金として30,000円の小切手を振り出して渡した。
(2) 6月7日、店長から1週間分の支払いの報告を受けた。内訳は、郵便切手（通信費）3,000円、宅配便の送料（通信費）1,800円、ゴミ袋・洗剤（消耗品費）6,500円、銀行へのバス代（旅費交通費）460円。
(3) 報告を受けた会計係は、ただちに同額の小切手を振り出して補給した。
::answer
::journal (1) 小口現金の前渡し
小口現金 30,000 | 当座預金 30,000
::
::journal (2) 支払いの報告を受けたとき
通信費 4,800 | 小口現金 11,760
消耗品費 6,500 |
旅費交通費 460 |
::
::journal (3) 同額を補給したとき
小口現金 11,760 | 当座預金 11,760
::
報告を受けた時点で、小口現金を使った分だけ減らし、費用を計上する。補給すると、小口現金は30,000円（30,000－11,760＋11,760）に戻る。
::trap
小口係が店で支払った時点では、仕訳をしない。会計係が**報告を受けたとき**に、まとめて費用を計上する。
補給の貸方は、小切手を振り出しているので当座預金だ。現金としないこと。
::
::
::

ひより：「報告と補給を同じ日にするなら、仕訳を1本にまとめられますね」
一ノ瀬：「ええ。小口現金が減って、すぐに同じだけ増えるので、相殺されて消えます」

::point 報告と補給が「同時」の場合
「報告を受け、ただちに小切手を振り出して補給した」場合は、(2)と(3)をまとめて次のように仕訳することもできる。小口現金の減少と増加が相殺されて消えるためだ。
::

::journal 報告と補給を同時に行った場合（(2)と(3)をまとめた仕訳）
通信費 4,800 | 当座預金 11,760
消耗品費 6,500 |
旅費交通費 460 |
::

佐伯：「これで、レジのお金と経費のお金が、完全に分かれました」
ひより：「坂口くんも、喜ぶと思います」

::exam 預金・小切手・小口現金の急所
- 「小切手を振り出した」→ 当座預金の減少。「他人振出小切手を受け取った」→ 現金の増加。「ただちに当座預金に預け入れた」→ 当座預金の増加。「自己振出小切手を受け取った」→ 当座預金の増加。
- 当座借越：期中は当座預金勘定のまま（貸方残高になる）。決算日に「当座借越」または「借入金」へ振り替え、翌期首に再振替。
- 小口現金：会計係が報告を受けた時点で費用を計上する。小口係が支払っただけの時点では、会計係は仕訳をしない。
- 郵便切手は「通信費」、収入印紙は「租税公課」、電車・バス代は「旅費交通費」。小口現金の問題でよく出る勘定科目だ。
- 2027年4月以降の試験では、紙の小切手に関する論点は削除される見込み（暫定版）。ただし、!!当座預金・当座預金出納帳と、決算での当座借越の振替は2027年度以降も3級の範囲に残る!!。「小切手がなくなる＝当座預金も出ない」と早合点しないこと。最新の出題区分表を必ず確認しよう。
::

::next 「キャッシュレス」と「でんさい」の時代へ
紙の小切手と手形は、2027年3月末をめどに、金融界の取り組みとして利用廃止が予定されている。今後、企業間の支払いは銀行振込や**電子記録債権（でんさい）**（第8章）が中心になる。小口現金も、法人カードや経費精算アプリに置き換わりつつある。
だが、仕組みが変わっても本質は変わらない。「誰が・いつ・いくら払ったかを記録し、手元の残高と突き合わせる」。2級では、預金残高と銀行の記録を突き合わせる**銀行勘定調整表**を学ぶ。紙が消えても、照合と統制の技術は経理・財務の必須スキルであり続ける。
::

::summary
- 預金は資産。普通預金・定期預金・当座預金を区別し、複数口座は「普通預金〇〇銀行」のように口座別の勘定で管理できる
- 小切手を振り出したら当座預金の減少。他人振出小切手の受取りは現金、自己振出小切手の戻りは当座預金
- 当座借越は、残高を超えた支払いを銀行が立て替える契約。マイナス残高の正体は「借金」
- 期中は当座預金のまま処理し、決算日に貸方残高を当座借越（または借入金）へ振り替え、翌期首に再振替する
- 6か月以内に2回の不渡りで銀行取引停止。資金繰りの管理は会社の生命線
- 小口現金は定額資金前渡法で管理する。報告時に費用を計上し、使った分だけ補給する
