::mystery 残高ゼロの口座から、なぜ500万円の小切手が落ちたのか
2026年9月の月末。京都・洛北の食肉卸、洛北ミートの事務所は、冷蔵倉庫の機械音と、電話の声でいつも騒がしい。月次巡回に来たひよりの向かいで、経理担当の中西が、取引先の信用金庫から届いた案内を机の端に寄せた。「当金庫は、2026年9月30日をもって小切手・手形の振出の受付を終了いたします」。紙の小切手は、もうすぐ日本から消える。
その最後の月に、事件は起きた。
今朝、社長の北村が、40年来の付き合いがある畜産会社に**500万円の小切手**を手渡した。先代からの習慣で、この畜産会社への支払いだけは、今も小切手なのだ。ところが午後、中西がネットバンキングを開くと、当座預金の残高は**20万円**しかなかった。大口の得意先からの入金が、3日遅れていたのだ。
中西の顔から、血の気が引いた。ひよりは、画面の数字と中西の顔を見比べることしかできなかった。
「不渡りになる……」
小切手が残高不足で決済できなければ「不渡り」になる。半年以内に2回出せば、銀行取引停止処分。それは企業にとって、事実上の死刑宣告だ。
ところが翌日の夕方、ひよりの携帯に中西から電話が来た。「大川さん、落ちたんです。小切手が」。声が震えている。画面を更新した中西は、目を疑ったのだという。小切手は**何事もなかったかのように決済されていた**。口座の残高は「マイナス480万円」と表示されている。
「よかった……んですよね？」とひよりは聞いた。電話の向こうで、中西はしばらく黙った。「マイナス480万円の預金なんて、あるんでしょうか」
残高がほぼゼロの口座から、なぜ500万円が支払えたのか？　そして、このマイナス残高の正体は何なのか？
::

## 預金の基本 ― 普通預金と定期預金

事務所に戻ったひよりが一部始終を話すと、一ノ瀬は言った。「マイナス残高の正体を知るには、まず銀行口座の種類を整理しましょう。顧問先が使っている口座を、全部書き出してみてください」
ひよりのノートには、その月に回った顧問先の口座が並んだ。会費の引き落としに使うアイアンワークスの普通預金、余ったお金を寝かせておく定期預金、そして洛北ミートの当座預金。会社が銀行に預けているお金は、**預金**という資産だ。代表的なのは次の3つである。

::table 会社が使う主な預金
| 種類 | 特徴 | 会社での主な使い道 |
| 普通預金 | いつでも預け入れ・引き出しができる。利息がつく | 売上の入金、給料・経費の振込、口座振替 |
| 定期預金 | 一定期間引き出せない代わりに、普通預金より利息が高い | 余裕資金の運用、借入れの担保 |
| 当座預金 | 小切手や手形の支払いに使う決済用の口座。利息はつかない | 取引先への小切手・手形による支払い |
::

普通預金と定期預金の仕訳は、現金と同じ要領だ。預金が増えたら借方、減ったら貸方に書く。

::example IRONWORKS 24の預金取引
(1) 6月分の会費のうち、口座振替分3,200,000円が普通預金に入金された。
(2) 普通預金から2,000,000円を、1年満期の定期預金に預け替えた。
(3) 定期預金2,000,000円が満期となり、利息6,000円とともに普通預金に入金された。
::answer
::journal (1) 会費の入金（ジムの売上）
普通預金 3,200,000 | 売上 3,200,000
::
::journal (2) 普通預金から定期預金へ
定期預金 2,000,000 | 普通預金 2,000,000
::
::journal (3) 満期・利息の受取り
普通預金 2,006,000 | 定期預金 2,000,000
 | 受取利息 6,000
::
預金どうしの振り替えは「資産の増加・資産の減少」。利息は収益（受取利息）だ。
::
::

::note
※実際の預金利息には税金（源泉所得税など）が差し引かれるが、3級では問題文の指示がない限り考慮しない。
::

いまの会社の支払いの主役は、小切手ではなく**振込**だ。振込には手数料がかかる。手数料は「支払手数料」（費用）として、代金とは分けて記録する。

::example 振込手数料は、誰が負担するかで仕訳が変わる
洛北ミートは、仕入先の畜産会社に対する買掛金（後払いの仕入代金）500,000円を、普通預金から振り込んだ。振込手数料は660円である。
(1) 振込手数料を洛北ミートが負担する場合
(2) 振込手数料を畜産会社が負担する約束で、手数料分を差し引いて振り込んだ場合
::answer
::journal (1) 当社負担の手数料は「支払手数料」
買掛金 500,000 | 普通預金 500,660
支払手数料 660 |
::
::journal (2) 先方負担なら、手数料を差し引いた額で買掛金を消す
買掛金 500,000 | 普通預金 500,000
::
(2)では、差し引いた660円を合わせて買掛金500,000円が消え、口座からは499,340円＋手数料660円＝500,000円が出ていく。手数料は先方の負担なので、当社の費用は発生しない。
ただし、2026年1月に施行された**取適法**（改正下請法）では、対象となる下請取引で、振込手数料を受け取る側（中小の受託事業者）に負担させることが禁止された。(2)のやり方は、取引の種類によっては法律違反になる。
::
::

### 複数の口座は「銀行名つきの勘定」で管理する

IRONWORKS 24は、会費の引き落とし用に京都中央銀行、給料の振込用に洛北信用金庫と、目的別に複数の普通預金口座を持っている。口座が複数あると、「普通預金」という1つの勘定だけでは、どの口座にいくらあるのか分からなくなる。
そこで、**口座ごとに勘定科目を分けて**管理する方法がある。

::journal 京都中央銀行の普通預金から、洛北信用金庫の普通預金へ1,500,000円を移した
普通預金洛北信用金庫 1,500,000 | 普通預金京都中央銀行 1,500,000
::

::note
※試験では「普通預金A銀行」「当座預金B銀行」のように、問題文で指定された勘定科目を使う。指定がなければ「普通預金」でよい。
::

## 当座預金と小切手 ― 「紙1枚」で支払うための口座

当座預金は、**小切手**で支払いをするための口座だ。会社は銀行と当座取引契約を結び、小切手帳を受け取る。支払いのときは、小切手に金額と署名を書いて相手に渡す（これを**振り出す**という）。受け取った相手が銀行に小切手を持ち込むと、振り出した会社の当座預金から代金が引き落とされる。

::steps 小切手による支払いの流れ
洛北ミートが小切手を振り出す | 仕入先の畜産会社に、金額を書いた小切手を渡す
畜産会社が銀行に持ち込む | 自社の取引銀行に小切手を預ける（取立てを依頼する）
洛北ミートの当座預金から引き落とされる | 手形交換所（現在は電子交換所）を通じて決済され、代金が畜産会社の口座に入る
::

簿記では、**小切手を振り出した時点で、当座預金を減らす**。実際の引き落としは相手が銀行に持ち込んだときだが、振り出した瞬間に「支払いを済ませた」と考えるのだ。

::journal 洛北ミートは、畜産会社から牛肉を仕入れ、代金5,000,000円を小切手を振り出して支払った
仕入 5,000,000 | 当座預金 5,000,000
::

::note
※「仕入」は、販売するための商品を買ったときに使う勘定科目（第5章）。
::

小切手の仕訳で間違えやすいのは、「誰が振り出した小切手か」だ。

::table 小切手の仕訳 ― 誰が振り出したかで決まる
| 場面 | 仕訳で使う勘定 | 理由 |
| 自社が小切手を振り出して支払った | 当座預金（貸方） | 自社の当座預金が減る |
| 他社が振り出した小切手を受け取った | 現金（借方） | 通貨代用証券（第3章） |
| 他社振出の小切手を受け取り、ただちに当座預金に預け入れた | 当座預金（借方） | 現金を経由せず当座預金が増える |
| 自社が以前振り出した小切手を受け取った | 当座預金（借方） | 振り出したときに減らした当座預金が戻る |
::

::example 小切手の受取り3パターン
洛北ミートは、得意先の飲食店3社から売掛金（後払いの代金）をそれぞれ小切手で回収した。
(1) A社が振り出した小切手200,000円を受け取った。
(2) B社が振り出した小切手300,000円を受け取り、ただちに当座預金に預け入れた。
(3) 以前に洛北ミートがC社に振り出した小切手100,000円を、C社から受け取った。
::answer
::journal (1) 他人振出小切手 → 現金
現金 200,000 | 売掛金 200,000
::
::journal (2) ただちに当座預金へ → 当座預金
当座預金 300,000 | 売掛金 300,000
::
::journal (3) 自己振出小切手の戻り → 当座預金
当座預金 100,000 | 売掛金 100,000
::
(3)は、洛北ミートが振り出した小切手が、まだ銀行に持ち込まれないまま、別の取引の支払いとして戻ってきたケース。振り出したときに減らした当座預金を元に戻すので、当座預金の増加とする。
::
::

::point 当座預金出納帳
当座預金の入出金を詳しく記録する補助簿が**当座預金出納帳**だ。小切手の番号や、残高が借方（預金がある）か貸方（借越している）かを記入する欄がある。後で学ぶ当座借越が起きていないかを、日々確認するための帳簿である。
::

::table compact sum 当座預金出納帳（洛北ミート・10月）
| 日付 | 摘要 | 預入 | 引出 | 借／貸 | 残高 |
| 10/1 | 前月繰越 | 200,000 |  | 借 | 200,000 |
| 10/5 | 畜産会社へ買掛金支払い　小切手No.105 |  | 5,000,000 | 貸 | 4,800,000 |
| 10/20 | 得意先から売掛金回収 | 6,000,000 |  | 借 | 1,200,000 |
| 10/31 | 次月繰越 |  | 1,200,000 |  |  |
|= |  | 6,200,000 | 6,200,000 |  |  |
| 11/1 | 前月繰越 | 1,200,000 |  | 借 | 1,200,000 |
::

::note
※「借／貸」欄は、残高が預金（借方残高）なら「借」、当座借越（貸方残高）なら「貸」と書く。10月5日の時点では、残高を超える小切手が決済されたので「貸 4,800,000」（当座借越）になっている。月末に「次月繰越」を引出欄に書いて締め切る。
::

## 答えの鍵 ― 当座借越

さて、問いの答えに近づこう。ひよりは中西に頼んで、銀行との契約書のファイルを見せてもらった。「当座勘定貸越約定書」という書類が挟まっていた。日付は12年前。前任の経理部長の印が押してある。
洛北ミートの当座預金の残高はほぼゼロだったのに、500万円の小切手は決済された。それを可能にしたのが、この書類が定めた**当座借越**（とうざかりこし）という契約だ。

::theory 当座借越 ― 自動で発動する「借金」
当座借越契約とは、銀行とあらかじめ取り決めた限度額（**借越限度額**）までなら、当座預金の残高を超えて小切手を振り出しても、銀行が不足分を立て替えて支払ってくれる契約だ。
残高を超えて支払った部分は、実質的には**銀行からの借入れ**である。もちろん利息もかかる。
つまり、口座の「マイナス残高」の正体は、預金ではなく**負債**なのだ。
::

::solve 残高ゼロでも小切手が落ちた理由
洛北ミートは、メインバンクと**借越限度額1,000万円の当座借越契約**を結んでいた。前任の経理部長が、万が一に備えて用意しておいた命綱だ。
当座預金の残高20万円に対して500万円の小切手が持ち込まれたため、銀行は不足する480万円を自動的に立て替えた。口座に表示された「マイナス480万円」は、預金ではなく、銀行に対する**480万円の借金**である。
命綱は機能した。だが、同時に忘れてはならない。もし限度額を超えていたら、あるいは当座借越契約がなかったら、その小切手は**不渡り**になっていた。
「つまり、あの日、洛北ミートは銀行から480万円を借りたんです」とひよりが言うと、中西はようやく笑った。「借りた覚えのない借金に、助けられたわけですね」
::

### 当座借越の仕訳 ― 期中と決算で扱いが変わる

3級では、期中は当座預金の残高がマイナスになっても**当座預金勘定のまま処理**する。その結果、当座預金勘定が**貸方残高**になる。

::taccount 当座預金（洛北ミート）
前日残高 200,000 | 仕入（小切手） 5,000,000
::

貸方の合計（5,000,000円）が借方の合計（200,000円）を4,800,000円上回っている。これが「貸方残高4,800,000円」、つまり銀行からの借越額だ。

だが、マイナスの預金という資産は存在しない。そこで**決算日**には、貸方残高を**当座借越**（負債）または**借入金**（負債）に振り替えて、貸借対照表に負債として正しく表示する。

::journal 決算日：当座預金勘定の貸方残高4,800,000円を当座借越勘定に振り替えた
当座預金 4,800,000 | 当座借越 4,800,000
::

::note
※当座借越勘定ではなく「借入金」勘定に振り替えるよう指示されることもある。問題文の指示に従うこと。貸借対照表では「借入金」として表示する。
::

そして、翌期の最初の日（期首）には、決算日の振替仕訳と**逆の仕訳**を行って、当座預金勘定に戻す。これを**再振替仕訳**という。

::journal 翌期首：再振替仕訳（決算日の仕訳の逆）
当座借越 4,800,000 | 当座預金 4,800,000
::

::point なぜ再振替仕訳をするのか
期中は「当座預金」1つの勘定で入出金を記録するルールだからだ。期首に戻しておけば、その後に預金が入金されたとき、いつもどおり「当座預金」で仕訳すればよく、借越が自動的に解消されていく。再振替仕訳は、第15章の経過勘定でも再び登場する、簿記の重要なテクニックだ。
::

::danger 不渡り ― 「2回」で企業は死ぬ
当座預金の残高（と借越限度額）を超える小切手や手形は、決済されずに**不渡り**になる。
不渡りを出した事実は、手形・小切手の決済網に参加する金融機関の間で共有される。そして**6か月以内に2回目の不渡りを出すと、銀行取引停止処分**となり、2年間、その会社は金融機関と当座取引も融資取引もできなくなる。仕入先は掛けで売ってくれなくなり、銀行は1円も貸してくれない。多くの企業にとって、これは**倒産と同じ意味**を持つ。
1回目の不渡りでさえ、「あの会社は危ない」という噂は一瞬で広まる。だからこそ、経理担当者は月末の当座預金残高を、文字どおり命がけで管理してきたのだ。
::

::real 140年続いた「紙の決済」が、終わろうとしている
2022年11月4日、全国銀行協会は手形・小切手の決済をデジタル化した**電子交換所**を稼働させ、全国179か所の手形交換所を廃止した。最も古いものは140年以上の歴史をもっていた。銀行の行員が紙の束を抱えて交換所に集まる光景は、このとき姿を消した。いまは各銀行が紙の手形・小切手をスキャンし、その画像データをやり取りしている。
そして紙そのものも、なくなろうとしている。全国銀行協会は、**2026年度末（2027年3月末）**までに電子交換所での手形・小切手の交換枚数をゼロにすることを最終目標に掲げる。これに合わせて多くの金融機関が「最終振出期限」を設け、たとえば紀北信用金庫や千葉信用金庫は**2026年9月30日**を期限とした。
**この章の道具で読む ― 最後の小切手と、最初の振込**
洛北ミートが畜産会社に払う500万円の買掛金を、2つの時代の仕訳で並べてみよう。

::journal 2026年9月まで：小切手を振り出して支払う（振り出した時点で当座預金を減らす）
買掛金 5,000,000 | 当座預金 5,000,000
::
::journal 2026年10月から：普通預金から振り込む（手数料660円は洛北ミートが負担）
買掛金 5,000,000 | 普通預金 5,000,660
支払手数料 660 |
::

変わるのは、貸方の勘定科目だけではない。小切手の時代は、「振り出した日」に帳簿の当座預金を減らし、相手が銀行に持ち込んで実際に引き落とされるのは数日後だった。この時間差のあいだに得意先の入金が間に合えば、借越を使わずに済むこともある。振込では、帳簿の日付と口座からお金が出る日が同じになる。
そしてもう1つ。当座借越は、当座預金に付く契約だ。普通預金からの振込では、残高が足りなければ、その振込はそもそも実行されない。不渡りの危険はなくなるが、「足りない日を自動で埋めてくれる命綱」も一緒に消える。紙の小切手をやめる会社は、その命綱を、借入れの枠など別の形で用意し直す必要がある。中西が下の判断を迫られたのは、ちょうどこの切り替えの月だった。
日商簿記3級も、2027年4月以降の試験から、紙の手形・小切手に関する論点を外す予定だ。ただし、仕組みがデジタルに変わっても、「支払いの約束が期日に果たされなければ、その会社は信用を失う」という本質は変わらない。電子記録債権（でんさい）にも、支払不能を2回起こすと取引停止になるルールがある（第8章）。
::note
出典：[ビジネス+IT（2022年11月4日、時事通信）](https://www.sbbit.jp/article/refers/98719)、[全国銀行協会（2026年6月5日）](https://www.zenginkyo.or.jp/news/2026/n060501/)、[三菱UFJ銀行「手形・小切手の電子化」](https://www.bk.mufg.jp/info/tegata_kogitte_denshika2.html)
::
::

::cfo 「借越の枠を3倍にしてもらおう」― 本当にそれが最善か？
肝を冷やした北村は、翌朝の会議で言った。ひよりも、顧問の立場で同席していた。「今回は助かった。だが次は分からない。銀行に頼んで、借越限度額を1,000万円から3,000万円に増やしてもらおう」
中西は、この半年の当座預金の動きを調べてから会議に臨んだ。わかったのは次のことだ。
- 毎月25日ごろに仕入先への支払いが集中し、得意先からの入金は月末に集中する。残高が最も低くなるのは毎月26〜30日
- 当座借越を使ったのは半年で3回。平均すると、1回あたり約400万円を5日間
- 入金が遅れた得意先は、いつも同じ3社。合わせて毎月約2,000万円の売掛金がある
- 9月末で小切手が使えなくなるので、畜産会社への支払いは、どのみち振込に切り替える必要がある
取れる手は4つ。費用と効果を見比べて、最初に打つべき手を選んでほしい。
::choice A. 借越限度額を3,000万円に増やす（借越の利率は年2.5%、使った日数分だけ利息がかかる）
**○ 保険としては安いが、根本は治らない。**今の使い方なら、利息は「400万円×2.5%×5日÷365日×年6回」で年約8,000円にすぎない。保険料としては安い。
ただし、借越はあくまで借金で、銀行はいつでも枠を見直せる。業績が落ちて本当に必要になったときほど、枠は削られやすい。**最も必要なときに最も消えやすい命綱**なのだ。それに、入金が遅れる得意先という原因は、そのまま残る。
::
::choice B. 長期で3,000万円を借り、普通預金に置いておく（金利は年1.6%）
**△ 確実だが、高くつく。**使わない日も3,000万円全額に利息がかかり、年48万円（3,000万円×1.6%）。借越枠の利息の約60倍だ。残高が足りなくなるのは毎月数日だけなのに、1年中お金を借りっぱなしにすることになる。
::
::choice C. 入金が遅れる3社に督促し、遅れが続く店には新しい注文を前払いかでんさいでお願いする
**◎ 原因そのものに手を打つ。**ズレの出発点は、入金が遅れる3社だ。毎月約2,000万円の売掛金が数日早く入るだけで、月末の谷はほとんど埋まる。遅れが常態化している相手は、いずれ貸倒れ（第11章）につながるおそれもある。回収の管理は、資金繰りと与信管理を同時に改善する。
::
::choice D. 振込への切り替えにあわせて、仕入先への支払日を25日から月末に移す
**○ タイミングを合わせる上手な手。**入金が月末に集まるなら、支払いも月末に寄せれば、谷そのものが浅くなる。どうせ振込に切り替える今が、交渉の好機だ。ただし、仕入先にとっては入金が遅れることになる。長年の取引先に一方的に押しつけず、事情を説明して合意を得ることが前提である。
::
::answer 考え方の例を見る
当座借越の「マイナス残高」は借金だ。枠を増やす（A）、先に借りておく（B）は、どちらも「足りない日を借金で埋める」手で、足りなくなる原因は残る。
優先順位はこうなる。
- **原因を断つ**：入金の遅れを止める（C）
- **タイミングを合わせる**：支払日と入金日を近づける（D）
- **保険をかける**：それでも残る不測の事態には、使った分だけ利息がかかる借越枠を備える（A）
中西は、3か月先までの**日次の資金繰り表**を作り、残高がマイナスになる日を事前に知る仕組みも整えた。表の形は、ひよりが序章で一ノ瀬に教わった資金繰り表をそのまま渡した。命綱は、使わないで済むときに最も価値がある。
::
::

## 小口現金 ― 現場の「小さな支払い」を仕組みで管理する

翌週、ひよりはおかわり堂本部の巡回で、佐伯から別の相談を受けた。「出町柳店の件以来、店の経費をレジから出すのをやめたいんです」。現場の小さな支払いの管理方法だ。
おかわり堂の各店舗では、毎日のように細かい支払いが発生する。宅配便の送料、急に切れたゴミ袋、郵便切手、店長の銀行への交通費……。第3章で見たように、これをレジの売上金から払うと、現金過不足の原因になる。
そこで、会社は各店舗の店長に、少額の支払い専用の現金をあらかじめ渡しておく。これを**小口現金**（こぐちげんきん）という。お金を預かって支払いを担当する人を**小口係**（用度係）と呼ぶ。

::theory 定額資金前渡法（インプレスト・システム）
小口現金の管理では、**定額資金前渡法**（インプレスト・システム）が広く使われている。
1. 会計係（本部の経理）が、一定額（例：30,000円）を小口係に前渡しする
2. 小口係は、そこから日々の小さな支払いを行い、小口現金出納帳に記録する
3. 一定期間（例：1週間）ごとに、小口係が支払いの内容を会計係に報告する
4. 会計係は、**使った金額と同額**を補給する。これで、小口現金は毎回もとの定額に戻る
「使った分だけ補給する」ので、手元の小口現金と支払いの記録の合計は、常に定額と一致する。ズレがあればすぐに分かる、よくできた仕組みだ。
::

::example おかわり堂・今出川店の小口現金
(1) 6月1日、本部の会計係は、今出川店の店長（小口係）に、小口現金として30,000円の小切手を振り出して渡した。
(2) 6月7日、店長から1週間分の支払いの報告を受けた。内訳は、郵便切手（通信費）3,000円、宅配便の送料（通信費）1,800円、ゴミ袋・洗剤（消耗品費）6,500円、銀行へのバス代（旅費交通費）460円。
(3) 報告を受けた会計係は、ただちに同額の小切手を振り出して補給した。
::answer
::journal (1) 小口現金の前渡し
小口現金 30,000 | 当座預金 30,000
::
::journal (2) 支払いの報告を受けたとき
通信費 4,800 | 小口現金 11,760
消耗品費 6,500 |
旅費交通費 460 |
::
::journal (3) 同額を補給したとき
小口現金 11,760 | 当座預金 11,760
::
報告を受けた時点で、小口現金を使った分だけ減らし、費用を計上する。補給すると、小口現金は30,000円（30,000－11,760＋11,760）に戻る。
::
::

::point 報告と補給が「同時」の場合
「報告を受け、ただちに小切手を振り出して補給した」場合は、(2)と(3)をまとめて次のように仕訳することもできる。小口現金の減少と増加が相殺されて消えるためだ。
::

::journal 報告と補給を同時に行った場合（(2)と(3)をまとめた仕訳）
通信費 4,800 | 当座預金 11,760
消耗品費 6,500 |
旅費交通費 460 |
::

::note
※小口現金出納帳は、左端に「受入」欄があるのが特徴。支払いは内訳欄（費目別の列）にも記入し、週末に費目ごとの合計を出して会計係に報告する。補給のタイミング（週末に補給するか、翌週の初めに補給するか）は問題文で確認しよう。
::

::exam 預金・小切手・小口現金の急所
- 「小切手を振り出した」→ 当座預金の減少。「他人振出小切手を受け取った」→ 現金の増加。「ただちに当座預金に預け入れた」→ 当座預金の増加。「自己振出小切手を受け取った」→ 当座預金の増加。
- 当座借越：期中は当座預金勘定のまま（貸方残高になる）。決算日に「当座借越」または「借入金」へ振り替え、翌期首に再振替。
- 小口現金：会計係が報告を受けた時点で費用を計上する。小口係が支払っただけの時点では、会計係は仕訳をしない。
- 郵便切手は「通信費」、収入印紙は「租税公課」、電車・バス代は「旅費交通費」。小口現金の問題でよく出る勘定科目だ。
- 2027年4月以降の試験では、紙の小切手に関する論点は削除される見込み（暫定版）。最新の出題区分表を必ず確認しよう。
::

::next 「キャッシュレス」と「でんさい」の時代へ
紙の小切手と手形は、2027年3月末をめどに、金融界の取り組みとして利用廃止が予定されている。今後、企業間の支払いは銀行振込や**電子記録債権（でんさい）**（第8章）が中心になる。小口現金も、法人カードや経費精算アプリに置き換わりつつある。
だが、仕組みが変わっても本質は変わらない。「誰が・いつ・いくら払ったかを記録し、手元の残高と突き合わせる」。2級では、預金残高と銀行の記録を突き合わせる**銀行勘定調整表**を学ぶ。紙が消えても、照合と統制の技術は経理・財務の必須スキルであり続ける。
::

::summary
- 預金は資産。普通預金・定期預金・当座預金を区別し、複数口座は「普通預金〇〇銀行」のように口座別の勘定で管理できる
- 小切手を振り出したら当座預金の減少。他人振出小切手の受取りは現金、自己振出小切手の戻りは当座預金
- 当座借越は、残高を超えた支払いを銀行が立て替える契約。マイナス残高の正体は「借金」
- 期中は当座預金のまま処理し、決算日に貸方残高を当座借越（または借入金）へ振り替え、翌期首に再振替する
- 6か月以内に2回の不渡りで銀行取引停止。資金繰りの管理は会社の生命線
- 小口現金は定額資金前渡法で管理する。報告時に費用を計上し、使った分だけ補給する
::
