## この本の特徴

この本は、試験に受かるためだけの教科書ではない。もちろん、日商簿記3級の出題範囲はすべてカバーしている。だが、それ以上に目指しているのは、あなたが**数字の裏にある「会社の生と死」を読めるようになること**だ。
本書は、1人の新人の1年間の物語だ。父の定食屋が黒字のまま倒産したことをきっかけに、京都の鴨川会計事務所に入った大川ひより。簿記の知識ゼロから出発した彼女は、深夜の高速バス、学生街の牛丼チェーン、24時間ジム、食肉卸、赤字のSaaS企業という5つの顧問先を訪ね歩き、そこで起きる事件を、帳簿の中から解いていく。あなたも、ひよりと一緒に仕訳を切りながら、簿記のルールがどのように会社を守り、あるいは見落とされたときにどう会社を殺すのかを、1章ずつ確かめてほしい。各章の「実際にあった話」では、現実の事件を、その章で学ぶ仕訳とT字勘定で再現している。

::kpi
収録 | 21章＋付録4本 | 3級の全論点を網羅
問い | 21の問い | 各章の冒頭で提示
演習 | 確認問題・仕訳道場・模擬試験 | すべて解答・解説つき
::

## 7種類のボックス

各章は、次のボックスを組み合わせて構成されている。色と役割を覚えておくと、復習のときに目的の情報へ一瞬でたどり着ける。

::mystery 各章は「問い」から始まる
身近な会社で起こる、直感に反する出来事。その理由を考えることが、各章の入り口になる。答えは、章の後半の「答え合わせ」で明かされる。
::

::theory 重要理論は青いボックスに
簿記のルールの「なぜ」を説明する、最も大切な理論。2級・1級でもそのまま使う知識なので、ここだけは必ず理解してから先へ進もう。
::

::danger 「経営の落とし穴」は赤いボックスに
会計処理を誤ったり、数字の裏の事実を見落としたりしたとき、会社がどんな危機に陥るかを描く。ルールが生まれた理由は、たいていここにある。
::

::real 「実際にあった話」は、上に黒い線の入った白いボックスに
物語の会社は架空だが、そこで起きる出来事には、現実の手本がある。黒字のまま倒産した上場企業、客の前払い金を使い込んで破綻した旅行会社、在庫の水増しが発覚したメーカー。各章のテーマにつながる実際の事件を、報道・統計資料へのリンクつきで紹介し、「この章の道具で読む」で、その事件の取引をその章の仕訳とT字勘定で再現する。
::

::cfo 「判断してみよう」は黄色のボックスに
数字のついた資料を読んで、経営者や経理担当者、銀行員の立場で判断する**実務の発展問題**。3級の試験範囲を超えて、資金繰り表、ストレステスト、財務制限条項、与信管理、内部統制の設計など、現場で実際に求められる判断に踏み込む。選択肢には、どれも「もっともらしい理由」がついていて、資料の数字を自分で計算しなければ正解にたどり着けない。1つ選ぶと、その判断がどんな結果を招くかと、考え方の例が開く。
試験対策だけが目的なら後回しにしてもよいが、ここで迷った経験は、2級・1級や実務で必ず生きる。電卓と紙を用意して、1問10〜15分かけて取り組んでほしい。
::choice A. 選ぶ前に、自分の判断の理由を一言メモしておく
**◎ それがいちばん効く。**解説を読んだとき、自分の考えのどこが違っていたのかが、はっきり分かる。数字を使って理由を書けたなら、もう本書の狙いどおりだ。
::
::choice B. 考えずに、とりあえず選んで解説を読む
**△ もったいない。**解説は読める。だが、迷わずに選んだ答えからは、ほとんど何も残らない。どの問題も、計算しないと見えない「落とし穴」が仕込んである。資料の数字で計算してから選んでみよう。
::
::answer
こんなふうに、どれかを選ぶと、その結果と考え方の例が開く。まず自分の頭で考えることが、最も効果的な学習法だ。
::
::

::exam 試験の急所は緑のボックスに
出題パターン、ひっかけ、時間短縮のテクニック。試験直前は、緑のボックスだけを拾い読みするのも効果的だ。
::

::next 2級・1級・実務へのつながりは紫のボックスに
3級の知識が、上の級や実際のビジネスでどう発展するかを予告する。今は読み飛ばしてもかまわない。
::

::point 例題と確認問題は「TRY」で手を動かして解ける
- **仕訳**：勘定科目をドラッグで記入欄へ入れ（またはタップしてから記入欄をタップ）、金額を入力して「答え合わせ」する。
- **空欄**：計算問題や、帳簿・精算表・財務諸表の空欄に数字を入力する。勘定科目や語句の空欄は、タップして選択肢から選ぶ。
- **分類・チェック表**：項目をドラッグで分類先へ移したり、当てはまるマスにチェックをつけたりする。
ネット試験と同じように、自分の手で答えを作ってから解説を開こう。
::

本文には、ほかにも次のような仕掛けがある。

- **勘定科目をタップ**：本文で点線の下線がついた勘定科目をタップすると、読み方・5つの要素のどれか・意味を確認できる。
- **シミュレーター**：第6章（先入先出法と移動平均法）、第7章（CCCと運転資金）、第12章（定額法と定率法）では、数字を動かして結果がどう変わるかを確かめられる。
- **模擬試験モード**：付録Dでは、60分のタイマーで本試験形式の問題を解き、大問ごとの得点と、復習すべき章をその場で確認できる。

仕訳とT字勘定は、次のような表で示す。左の青い列が**借方**、右の赤い列が**貸方**だ。

::journal 例：牛肉30万円分を、代金は後払い（掛け）で仕入れた
仕入 300,000 | 買掛金 300,000
::

::taccount 現金
前期繰越 500,000 | 仕入 120,000
売上 380,000 | 次期繰越 760,000
= 880,000 | 880,000
::

## おすすめの学習の進め方

::steps 合格までの4ステップ
1周目：物語として通読する | 確認問題は飛ばしてよい。まずは「なぜそうなるのか」をつかむ。序章から終章まで、一気に読み切ることを優先しよう
2周目：仕訳を手で書く | 各章の例題と確認問題を、紙に仕訳を書きながら解く。解答を見る前に必ず自分で書くこと
仕訳道場で反復する | 付録Cの仕訳問題を、1問30秒以内で解けるまで繰り返す。第1問（45点）はここで決まる
決算問題と模擬試験で仕上げる | 第18・19章の総合例題と付録Bの攻略法を確認したら、付録Dの模擬試験を「模擬試験モード」で60分で解き、間違えた章を復習する。そのうえで、ネット試験の模擬問題や過去問で時間配分を体に覚え込ませる
::
