::mystery 年商2億円の人気店を追い詰めた、1枚の納付書
京都・四条烏丸。濃厚な鶏白湯スープで行列が絶えないラーメン店「麺屋とりの巣」は、市内に5店舗を構え、年間の売上は税込で**2億2,000万円**に達していた。創業者の鳥羽は、ラーメン雑誌の取材でこう語った。「売上はぜんぶ、新しい店とスープの研究につぎ込んでいます」。
決算から2か月後の5月。顧問の鴨川会計事務所から、1通のメールが届いた。今期の消費税の申告書ができました、納付期限は5月31日です。納めるべき消費税は**1,200万円**。送ったのは、申告書の計算を任された、ひよりだった。
10分後、事務所の電話が鳴った。鳥羽の声は上ずっていた。「1,200万円？　そんなお金、どこにもないで」
鳥羽は、会社の預金口座を開いていた。残高は**300万円**。6号店の内装工事の代金を、先月払ったばかりだった。
売上は過去最高。店はいつも満席。不正もない。それなのに、なぜ1,200万円が払えないのか。そもそも、この1,200万円は、いったい誰のお金だったのか？
受話器を置いたひよりの手は、少し震えていた。計算は何度も確かめた。間違ってはいない。それなのに、自分の作った数字が、1つの店を追い詰めている。
::

## 会社が払う税金は、3種類に分けて考える

「計算が正しいなら、あなたが悪いわけではありません」と一ノ瀬は言った。「ただ、鳥羽さんに説明する責任はあります。明日、一緒に店に行きましょう。その前に、税金の地図を頭に入れておいてください」
会社に関わる税金を整理しておこう。簿記では、税金を次の3つに分けて処理する。

::table 会社に関わる税金の3分類
| 分類 | 主な税金 | 勘定科目 |
| ①費用になる税金 | 固定資産税、自動車税、印紙税 | 租税公課（費用） |
| ②利益にかかる税金 | 法人税、住民税、事業税 | 法人税、住民税及び事業税 |
| ③預かる税金 | 消費税、源泉所得税 | 仮受消費税・仮払消費税、所得税預り金 |
::

①は、事業を営むために払う「経費」としての税金。②は、会社が稼いだ利益に対してかかる税金。③は、会社が負担するのではなく、客や従業員が負担する税金を、会社が一時的に預かって納める税金だ。この区別が、問いを解く鍵になる。

## 費用になる税金 ― 租税公課

その夜、ひよりは事務所の書庫で、ほかの顧問先の納付書の控えをめくった。ナイトオウル交通のファイルには、車庫の固定資産税と、バス20台分の自動車税の納付書が並んでいた。
どれも、会社が自分の負担で納める税金だ。鳥羽の1,200万円とは、性質が違う。

**固定資産税**は、土地・建物・事業用の設備などを持っていることに対してかかる税金だ。**自動車税**は自動車の所有者に、**印紙税**は領収書や契約書などの文書を作ったときにかかる（収入印紙を貼って納める）。
これらは、事業を営むための経費と同じ性質なので、**租税公課**（そぜいこうか・費用）で処理する。

::example ナイトオウル交通の租税公課
(1) 車庫の土地・建物に対する固定資産税の納税通知書（年税額1,200,000円）を受け取り、第1期分300,000円を普通預金から納付した。
(2) バス20台分の自動車税1,000,000円を、普通預金から納付した。
(3) 貸切バスの代金の領収書に貼るため、収入印紙20,000円分を現金で購入した。
::answer
::journal (1) 固定資産税は租税公課（納付した分を計上）
租税公課 300,000 | 普通預金 300,000
::
::journal (2)
租税公課 1,000,000 | 普通預金 1,000,000
::
::journal (3) 収入印紙の購入も租税公課
租税公課 20,000 | 現金 20,000
::
::trap
税金の種類で勘定科目が変わる。固定資産税・自動車税・印紙税は、費用の租税公課だ。法人税等や消費税は、別の勘定で処理する。
収入印紙は租税公課、郵便切手は通信費。似ているが、勘定科目は異なる。
::
::
::

::note
※固定資産税の納税通知書を受け取った時点で、年税額の全額を「租税公課／未払金」と計上し、納付のつど未払金を減らす方法もある。問題文の指示に従おう。また、決算日に使わずに残っている収入印紙や郵便切手は、「貯蔵品」として資産に振り替える（第15章）。
::

## 利益にかかる税金 ― 法人税、住民税及び事業税

次のページには、11月の日付の納付書があった。金額は600万円。
ひよりは首をかしげた。決算は3月だ。利益が決まる前に、どうして税金を納めているのだろう。
翌朝、一ノ瀬に聞くと、答えは短かった。「前払いです。だから、費用にはまだできません」

会社が利益を出すと、その利益に対して**法人税**（国税）、**住民税**（地方税）、**事業税**（地方税）がかかる。簿記では、この3つをまとめて**法人税、住民税及び事業税**（法人税等）という勘定で処理する。
法人税等は、決算で利益が確定してから計算する。ただし、前期の税額が一定以上の会社は、期の途中で、前期の実績をもとにした税額の半分ほどを先に納める（**中間申告・中間納付**）。

::steps 法人税等の1年間の流れ
期の途中：中間納付 | 前期の実績などにもとづき、税額の一部を先に納める。まだ当期の税額は確定していないので「仮払法人税等」（資産）とする
決算日：当期の税額を計上 | 当期の利益にもとづく年税額を「法人税、住民税及び事業税」（費用）として計上し、中間納付額を差し引いた残りを「未払法人税等」（負債）とする
決算後：確定申告・納付 | 原則として決算日から2か月以内に申告し、未払法人税等を納付する
::

::example ナイトオウル交通の法人税等
(1) 11月、法人税等の中間申告を行い、6,000,000円を普通預金から納付した。
(2) 3月31日の決算で、当期の法人税等の年税額が14,000,000円と計算された。
(3) 5月、確定申告を行い、未払分を普通預金から納付した。
::answer
::journal (1) 中間納付：仮払法人税等（資産）
仮払法人税等 6,000,000 | 普通預金 6,000,000
::
::journal (2) 決算：年税額を計上し、中間納付額との差額を未払法人税等とする
法人税、住民税及び事業税 14,000,000 | 仮払法人税等 6,000,000
 | 未払法人税等 8,000,000
::
::journal (3) 確定納付
未払法人税等 8,000,000 | 普通預金 8,000,000
::
::trap
中間納付した6,000,000円を、その時点で費用にしないこと。年税額が決まるまでは、仮払法人税等（資産）で記録する。
決算で未払法人税等にするのは、年税額の14,000,000円全額ではない。中間納付を引いた残りの8,000,000円だ。
::
::
::

::point 損益計算書での位置
法人税等は、損益計算書の最後のほうで、**税引前当期純利益**から差し引かれる。
税引前当期純利益 － 法人税、住民税及び事業税 ＝ 当期純利益
日本の会社の利益にかかる税金の負担率（実効税率）は、規模などにより異なるが、おおむね30%前後だ。利益の約3割は、翌年に現金で出ていく。序章で見た「税金は利益が出た後から来る」という罠の正体である。
::

## 預かる税金 ― 消費税

いよいよ問いの核心、**消費税**だ。翌日の昼下がり、営業前の麺屋とりの巣のカウンターで、ひよりは鳥羽の前に1杯分のレシートを置いた。「ラーメン1杯990円。このうち90円は、お店のお金ではありません」

::theory 消費税を負担するのは「最終消費者」、納めるのは「事業者」
消費税は、商品やサービスを消費する人（最終消費者）が負担する税金だ。だが、消費者が自分で税務署に納めるわけではない。商品の売り手である事業者が、代金と一緒に消費税を受け取り、それを**預かって**国に納める。
しかも消費税は、生産から販売までの各段階でかかる。そこで各事業者は、「売上で預かった消費税」から「仕入れや経費で支払った消費税」を差し引いた**差額だけ**を納める（仕入税額控除）。こうして、各段階の事業者が少しずつ納めた消費税の合計が、最終消費者の負担した消費税と一致する仕組みになっている。
::

::table compact 1杯の牛丼をめぐる消費税のバトンリレー（税率10%で単純化）
| 段階 | 売値（税抜） | 受け取った消費税 | 支払った消費税 | 納める消費税 |
| 洛北ミート → おかわり堂 | 200円 | 20円 | 0円 | 20円 |
| おかわり堂 → 客 | 500円 | 50円 | 20円 | 30円 |
|= 合計 |  |  |  | 50円（＝客が負担した消費税） |
::

::note
※実際には、食材の仕入れや持ち帰りの飲食料品には軽減税率（8%）が適用されるなど、取引ごとに税率が異なる。ここでは仕組みを示すため、税率を10%に統一している。
::

### 税抜方式の仕訳 ― 「仮払」と「仮受」で預かりを管理する

「90円が店のお金やないなら、帳簿にはどう書いてあるんや」と鳥羽は聞いた。
ひよりは、レシートの裏に仕訳を書いた。売上の行と、もう1行。
「売上は900円です。90円は、別の勘定に分けて記録します」

3級では、消費税を売上や仕入と区別して記録する**税抜方式**を学ぶ。
- 仕入れや経費で支払った消費税 → **仮払消費税**（資産）
- 売上で受け取った消費税 → **仮受消費税**（負債）

::example おかわり堂の消費税
(1) 洛北ミートから牛肉を仕入れ、代金432,000円（税抜400,000円、食料品なので軽減税率8%の消費税32,000円）は掛けとした。
(2) 1日の売上は、店内飲食分が税抜500,000円（消費税10%）、持ち帰り分が税抜300,000円（消費税8%）で、代金は現金で受け取った。
::answer
::journal (1) 支払った消費税は「仮払消費税」
仕入 400,000 | 買掛金 432,000
仮払消費税 32,000 |
::
::journal (2) 受け取った消費税は「仮受消費税」：50,000円＋24,000円＝74,000円
現金 874,000 | 売上 800,000
 | 仮受消費税 74,000
::
売上・仕入は**税抜**の金額で記録し、消費税の部分は仮払消費税・仮受消費税として別に記録する。!!買掛金・売掛金・現金は、相手と実際にやり取りする税込の金額!!になる点に注意しよう。初学者は、買掛金まで税抜で書いてしまいがちだ。こうすることで、「預かっている消費税」と「支払った消費税」が帳簿の上で常に見えるようになる。
::trap
税率を取り違えないこと。食料品の仕入れと持ち帰りは8%、店内飲食は10%だ。
売上・仕入は税抜、買掛金・売掛金・現金は税込で記録する。相手とやり取りする金額は、いつも税込である。
::
::
::

::note
※牛丼チェーンでは、同じ牛丼でも店内で食べれば10%、持ち帰れば8%の消費税がかかる（軽減税率）。3級の試験では、問題文で示された税率（通常は10%）で計算すればよい。
::

### 決算 ― 差額が「納める消費税」になる

鳥羽は、レシートの裏の仕訳を見ていた。
「ほな、預かった分を全部、国に渡すんか。うちかて、鶏ガラや麺を買うときに消費税を払うてるで」
「はい。だから、納めるのは差額です」とひよりは言った。「預かった消費税から、支払った消費税を引きます」

決算では、仮受消費税と仮払消費税を相殺し、その差額を**未払消費税**（負債）として計上する。

::journal 決算：仮受消費税の残高が5,200,000円、仮払消費税の残高が3,100,000円だった
仮受消費税 5,200,000 | 仮払消費税 3,100,000
 | 未払消費税 2,100,000
::

::journal 確定申告にもとづき、未払消費税2,100,000円を普通預金から納付した
未払消費税 2,100,000 | 普通預金 2,100,000
::

::note
※仮払消費税のほうが多いときは、差額が税務署から還付される。この還付を受ける権利は「未収還付消費税」（資産）で処理する。
::

## 答え合わせ ― 1,200万円は、最初から「客のお金」だった

::solve 経営者は、預かったお金を自分の売上だと思って使っていた
麺屋とりの巣の年間売上、税込2億2,000万円。そのうち**2,000万円は、客から預かった消費税**だった。店の本当の売上（税抜）は2億円だ。
一方、食材や光熱費、家賃などの支払いに含まれていた消費税は800万円。差し引き**1,200万円**を、店は国に納めなければならない。

::table 麺屋とりの巣の消費税（年間）
| 項目 | 金額 |
| 売上で受け取った消費税（仮受消費税） | 2,000万円 |
| 仕入れ・経費で支払った消費税（仮払消費税） | △800万円 |
|= 納めるべき消費税（未払消費税） | 1,200万円 |
::
鳥羽は、税込の売上がすべて店のお金だと思い、新店の内装や設備に次々と使っていた。だが、そのうち1,200万円は、**最初から国に納めるために客から預かっていたお金**だった。
しかもラーメン店は、売上に占める人件費の割合が高い。**給料には消費税がかからない**ため、人件費が多い事業ほど、差し引ける消費税（仮払消費税）が少なくなり、納める消費税が大きくなる。
税抜方式で仮受消費税を毎日記録していれば、「このお金は預かりものだ」ということが、帳簿の上で常に見えていたはずだ。
::

鳥羽は、カウンターの上のレシートを長いあいだ見ていた。「1杯ごとに90円、国の財布を預かってたわけか。それを、6号店の壁紙に使うてしもうた」
事務所は、鳥羽と一緒に税務署へ相談に行き、納付を分割にしてもらう手続きを進めた。

::danger 消費税の滞納は、倒産の入り口
消費税は、赤字でも納めなければならない税金だ。法人税は利益が出なければかからないが、消費税は「預かった額－支払った額」で決まるため、利益と関係なく発生する。
そのため、資金繰りに苦しむ会社ほど消費税を滞納しやすい。例年、新たに発生する国税の滞納額のうち、最も大きな割合を占めているのが消費税だ。滞納すれば延滞税がかかり、やがて預金や売掛金が差し押さえられる。取引先や銀行に差し押さえが知られれば、信用は一気に失われる。
消費税で倒れる会社に共通するのは、**税込の売上を「自分のお金」だと思っている**ことだ。
::

::real 国税の滞納のおよそ4割は、消費税
国税庁が2026年8月に公表した「令和7年度の租税滞納状況」によると、2025年度に新しく発生した国税の滞納額は**9,935億円**。年度末の滞納残高は**9,847億円**で、そのうち消費税は**3,893億円**。所得税の3,948億円とほぼ並び、全体のおよそ4割を占めている。
消費税は、事業者が申告して納める機会の多い税で、しかも赤字でも納める必要がある。客から預かったお金を、売上と一緒に日々の支払いに使ってしまえば、納付の月にお金が足りなくなる。滞納の多さは、「預かったお金」を切り分けて管理することの難しさを、そのまま映している。

**この章の道具で読む ― 滞納は、帳簿のどこに残るのか**
麺屋とりの巣の決算整理では、1年分の仮受消費税と仮払消費税を相殺し、差額を未払消費税（負債）にした。

::journal 決算日：仮受消費税と仮払消費税を相殺し、納める額を未払消費税とする
仮受消費税 20,000,000 | 仮払消費税 8,000,000
 | 未払消費税 12,000,000
::

期限の5月31日に全額を納めれば、「未払消費税／普通預金」の仕訳で、この負債は消える。滞納した会社では、ここが消えない。分割で一部ずつ納めても、未払消費税の残高は、次の決算の貸借対照表にまで居座る。

::taccount 未払消費税（分割で納付している場合）
6月 普通預金（1回目の納付） 2,000,000 | 決算で計上 12,000,000
7月 普通預金（2回目の納付） 2,000,000 |
 |
::

しかも、期限を過ぎて納めた分には、遅れた日数に応じて延滞税がかかる。延滞税は、預かった消費税とは違い、会社自身が負担する費用だ（一般に「租税公課」などで処理する）。預かったお金を使ってしまった代償は、追加の費用として損益計算書にまで表れる。
全国の滞納残高のうち消費税3,893億円という数字は、こうした「消えない未払消費税」を、日本中の帳簿から足し合わせた姿だと言える。
::note

::cfo 来年の納付で、二度とつまずかないために ― 「二重の負担」を見抜く
今年の1,200万円は、税務署と相談して、6月から**毎月100万円ずつ12回**の分割で納めることになった（遅れた分の延滞税は別にかかる）。鳥羽は、ひよりに言った。「来年は同じ失敗をしたくない。どうしたらええか、教えてくれ」
ひよりは、一ノ瀬に確かめながら材料をそろえた。
- 来期も、売上と経費は今期とほぼ同じ見込み。毎月、税込の売上からすべての支払いを済ませたあとにお金が残るが、その一部は客から預かった消費税だ
- 前の年の消費税額が一定以上の会社は、翌年、期の途中で消費税を前払いする**中間申告**が必要になる。今年の税額は大きかったので、来期は年に何回か、前払いの納付がある
- 食材の一部は、インボイス（適格請求書）を発行できない小さな農家（免税事業者）から仕入れている。こうした仕入れに含まれる消費税は、一部しか差し引けない
- 鳥羽は、7号店の準備のための積立ても始めたいと考えている
次の視点で考えてから選んでほしい。
- 来期の1年間、毎月残るお金から、**何が、いつ**出ていくか。今年の分と来期の分を分けて考えたか
- その案は、「預かったお金を使い込む」**構造そのもの**を変えるか
- 効果の**大きさ**は、問題の大きさに見合っているか
::choice A. 来期の消費税の分を毎月「納税専用口座」に移し、残りは新店の準備などに自由に使う
**○ 来期の分の手当てとしては正しいが、今年の分割を忘れている。**仮の設定（下の「考え方の例」）では、毎月100万円を移せば、3か月で300万円がたまり、中間申告の納付にちょうど間に合う。確定申告の残り300万円もそろう。考え方は正しい。
だが来期は、今年の1,200万円の分割納付（毎月100万円）も続いている。250万円から、来期の分100万円と今年の分100万円を引けば、自由に使えるのは**月50万円**だ。150万円を使えば、毎月100万円ずつ足りなくなり、半年後にはまた納付ができなくなる。
::
::choice B. 毎月残るお金は新店の準備に使い、納付のたびに銀行から借りて払う
**× 納付の回数が増える来期は、ますます綱渡りになる。**来期は、分割納付が毎月、中間申告が3か月ごとにある。そのたびに借りるのは現実的ではない。「税金を借金で払う会社」に、銀行は毎回すんなり貸してくれるとは限らない。断られたら、その瞬間に滞納だ。預かったお金を使い込む構造そのものが、何も変わっていない。
::
::choice C. 消費税の負担を取り戻すため、全メニューを50円値上げする
**× 消費税のしくみを取り違えている。**値上げで売上が増えれば、預かる消費税も同じ割合で増える。値上げは利益の対策にはなっても、「納付の月にお金がない」というタイミングの問題は解決しない。消費税は店のコストではなく、客から預かって納めるお金なのだ。
::
::choice D. インボイスを発行できない農家との取引をやめ、発行できる仕入先に切り替える
**△ 理屈は正しいが、効果は小さい。**2026年10月からは、免税事業者からの仕入れに含まれる消費税のうち70%しか差し引けない。仮の設定では、差し引けない額は年30万円。仕入先を変えれば、この30万円は減らせるかもしれない。だが月にすれば2万5,000円で、毎月の「二重の負担」100万円の前では誤差に近い。こだわりの野菜の質や、長年の関係を手放すほどの理由にはならない。
::
::choice E. 来期の分に加えて、今年の分割の分も毎月確保し、7号店の積立ては分割が終わるまで見送る
**◎ 来期に出ていくお金を、すべて書き出した答え。**毎月の250万円のうち、来期の消費税の分100万円は納税専用口座へ、今年の分割100万円は納付へ。自由に使えるのは月50万円なので、7号店の積立て（月100万円）は、分割が終わる1年後まで待つ。
中間申告の納付月（3か月ごと）と、分割の納付日を資金繰り表に書き込んでおけば、「お金はあるのに、その日に足りない」も防げる。
::
::answer 考え方の例を見る
**仮の設定**で試算してみよう。
- 毎月、支払いをすべて済ませたあとに残るお金は約250万円。そのうち約100万円は、客から預かった消費税
- 今年の1,200万円は、6月から毎月100万円ずつ12回の分割で納める
- 中間申告：今年の税額をもとに、来期は3か月ごとに約300万円（年3回で約900万円）を納め、確定申告で残りの約300万円を納める
- 免税事業者からの仕入れは年1,100万円（税込）。含まれる消費税100万円のうち30%は差し引けない
- 7号店の積立ては月100万円を考えている
::table 来期の毎月のお金の行き先（単位：万円）
| 項目 | 金額 |
| 支払いをすべて済ませたあとに残るお金 | 250 |
| 来期の消費税の分（納税専用口座へ。中間申告3回と確定申告に充てる） | △100 |
| 今年の消費税の分割納付 | △100 |
|= 自由に使えるお金 | 50 |
::
ポイントは、「預かったお金」を、帳簿の上でも口座の上でも切り分けること。そして、**来年出ていくお金を、制度のルールまで含めてすべて書き出す**ことだ。
- **月次で未払消費税を計算する**：毎月の試算表で、仮受消費税から仮払消費税を引き、その月に積み上がった「納めるべき消費税」を把握する。税抜方式で記帳していれば、この数字は帳簿にそのまま出てくる。
- **中間申告を忘れない**：一度大きな税額を納めると、翌年から納付の回数が増える。滞納した会社が翌年に再びつまずくのは、多くの場合、この「前払い」と「去年の分割」が重なるからだ。
- **資金繰り表に納付予定を入れる**：法人税等と消費税の納付月は、毎年ほぼ決まっている。設備投資の計画と重ならないようにする。
**さらに考えよう：来期の売上が2割落ちたら？**
中間申告の前払いは、**今年の税額**をもとに決まる。来期の売上が落ちて、実際の消費税が少なくなっても、前払いは今年の水準のまま求められる（払いすぎた分は、確定申告で戻ってくる）。つまり、売上が落ちてお金が苦しい年ほど、前払いが重くのしかかる。この場合、税務署に届け出て、来期の実績で計算し直した金額で中間申告をする方法（仮決算による中間申告）もある。**制度のルールを知っていれば、資金繰りの打ち手が1つ増える。**
そして、経営判断の場では、売上を**税抜**で語る習慣をつける。「年商2億2,000万円の店」ではなく「年商2億円の店」。それだけで、使ってよいお金の感覚は大きく変わる。鳥羽は翌月から、納税専用の口座を開き、7号店の計画を1年先に延ばした。
::
::

::point 電子契約なら、収入印紙はいらない
印紙税は、契約書や領収書などの「紙の文書」を作ったときにかかる税金だ。そのため、電子契約で契約書をデータのまま取り交わした場合は、課税文書の「作成」にあたらず、収入印紙は不要とされている。たとえば、請負契約書や不動産の売買契約書には、金額に応じて数千円から数万円の印紙が必要になる。契約の多い会社が電子契約に切り替えると、租税公課（印紙代）がまとめて減ることになる。ただし、電子契約のデータを紙に印刷して署名し、それを原本として使えば、印紙が必要になることがある。
::

::exam 税金の急所
- 固定資産税・自動車税・印紙税（収入印紙）は「租税公課」。法人税等とは別の勘定。
- 法人税等の中間納付は「仮払法人税等」。決算で「法人税、住民税及び事業税／仮払法人税等・未払法人税等」。
- 消費税（税抜方式）：仕入時は仮払消費税、売上時は仮受消費税。決算で相殺し、差額を「未払消費税」。
- 問題文の金額が「税込」か「税抜」かを必ず確認する。税込440,000円（税率10%）なら、税抜400,000円・消費税40,000円。
- 精算表・貸借対照表では、未払法人税等・未払消費税は負債。仮払消費税・仮受消費税は決算整理後には残らない。
::

::next 「会計上の利益」と「税金の計算上の利益」は違う
法人税は、会計上の利益をそのまま使って計算するわけではない。税法には独自のルールがあり、たとえば会計上は費用にした貸倒引当金や減価償却費の一部が、税金の計算では費用として認められないことがある。こうして計算された税金の計算上の利益を**課税所得**という。
会計上の利益と課税所得のズレを調整し、損益計算書の税金費用を「会計上の利益」に見合った金額に近づける技術が、2級・1級で学ぶ**税効果会計**だ。上場企業の決算書の「法人税等調整額」という項目を理解できるようになると、決算書をもう一段深く読めるようになる。
::

- 税金は「費用になる税金（租税公課）」「利益にかかる税金（法人税等）」「預かる税金（消費税・源泉所得税）」の3つに分けて考える

- 法人税等：中間納付は仮払法人税等、決算で年税額を計上し、残りを未払法人税等とする
- 消費税（税抜方式）：支払った分は仮払消費税、受け取った分は仮受消費税。決算で相殺し、差額を未払消費税とする
- 消費税は客から預かったお金。税込売上を自分のお金と思うと、納付のときに資金が足りなくなる
