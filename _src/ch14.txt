::mystery 年商2億円の人気店を追い詰めた、1枚の納付書
京都・四条烏丸。濃厚な鶏白湯スープで行列が絶えないラーメン店「麺屋とりの巣」は、市内に5店舗を構え、年間の売上は税込で**2億2,000万円**に達していた。創業者の鳥羽は、ラーメン雑誌の取材でこう語った。
鳥羽：「売上はぜんぶ、新しい店とスープの研究につぎ込んでいます」
決算から2か月後の5月。顧問の鴨川会計事務所から、1通のメールが届いた。今期の消費税の申告書ができました、納付期限は5月31日です。納めるべき消費税は**1,200万円**。送ったのは、申告書の計算を任された、ひよりだった。
10分後、事務所の電話が鳴った。
鳥羽：「大川さん？　1,200万円って、何かの間違いやろ。そんなお金、どこにもないで」
鳥羽は、会社の預金口座を開いていた。残高は**300万円**。6号店の内装工事の代金を、先月払ったばかりだった。
鳥羽：「利益かて、そんなに出てへん。なんで1,200万も税金を払わなあかんのや」
売上は過去最高。店はいつも満席。不正もない。それなのに、なぜ1,200万円が払えないのか。そもそも、この1,200万円は、いったい誰のお金だったのか？
受話器を置いたひよりの手は、少し震えていた。計算は何度も確かめた。間違ってはいない。それなのに、自分の作った数字が、1つの店を追い詰めている。
::

## 会社が払う税金は、3種類に分けて考える

一ノ瀬：「計算が正しいなら、あなたが悪いわけではありません」
ひより：「でも、鳥羽さんのお店が……」
一ノ瀬：「ただ、鳥羽さんに説明する責任はあります。明日、一緒に店に行きましょう。その前に、税金の地図を頭に入れておいてください」
一ノ瀬は、ホワイトボードに3つの箱を描いた。
一ノ瀬：「会社に関わる税金は、3つに分けて考えます。1つ目は、商売の経費として払う税金。2つ目は、儲けにかかる税金。3つ目は、自分ではなく、お客さんや従業員が負担する税金を、会社が預かって納めるもの」
ひより：「消費税は……」
一ノ瀬：「3つ目です。そこが、明日の話のすべてです」

::table 会社に関わる税金の3分類
| 分類 | 主な税金 | 勘定科目 |
| ①費用になる税金 | 固定資産税、自動車税、印紙税 | 租税公課（費用） |
| ②利益にかかる税金 | 法人税、住民税、事業税 | 法人税、住民税及び事業税 |
| ③預かる税金 | 消費税、源泉所得税 | 仮受消費税・仮払消費税、所得税預り金 |
::

## 費用になる税金 ― 租税公課

その夜、ひよりは事務所の書庫で、ほかの顧問先の納付書の控えをめくった。ナイトオウル交通のファイルには、車庫の固定資産税と、バス20台分の自動車税の納付書が並んでいた。
土地や建物を持っていればかかる**固定資産税**。車を持っていればかかる**自動車税**。契約書や領収書を作るときに収入印紙を貼って納める**印紙税**。どれも、会社が自分の負担で納める税金だ。商売を続けるための経費と同じなので、**租税公課**（そぜいこうか）という費用にする。
鳥羽の1,200万円とは、性質が違う。

::example ナイトオウル交通の租税公課
(1) 車庫の土地・建物に対する固定資産税の納税通知書（年税額1,200,000円）を受け取り、第1期分300,000円を普通預金から納付した。
(2) バス20台分の自動車税1,000,000円を、普通預金から納付した。
(3) 貸切バスの代金の領収書に貼るため、収入印紙20,000円分を現金で購入した。
::answer
::journal (1) 固定資産税は租税公課（納付した分を計上）
租税公課 300,000 | 普通預金 300,000
::
::journal (2)
租税公課 1,000,000 | 普通預金 1,000,000
::
::journal (3) 収入印紙の購入も租税公課
租税公課 20,000 | 現金 20,000
::
::trap
税金の種類で勘定科目が変わる。固定資産税・自動車税・印紙税は、費用の租税公課だ。法人税等や消費税は、別の勘定で処理する。
収入印紙は租税公課、郵便切手は通信費。似ているが、勘定科目は異なる。
::
::
::

::note
※固定資産税の納税通知書を受け取った時点で、年税額の全額を「租税公課／未払金」と計上し、納付のつど未払金を減らす方法もある。問題文の指示に従おう。また、決算日に使わずに残っている収入印紙や郵便切手は、「貯蔵品」として資産に振り替える（第15章）。
::

## 利益にかかる税金 ― 法人税、住民税及び事業税

次のページには、11月の日付の納付書があった。金額は600万円。
ひよりは首をかしげた。決算は3月だ。利益が決まる前に、どうして税金を納めているのだろう。
翌朝、一ノ瀬に聞くと、答えは短かった。
一ノ瀬：「前払いです。だから、費用にはまだできません」
ひより：「儲けにかかる税金を、儲けが決まる前に？」
一ノ瀬：「去年の実績から、だいたいこれくらいだろうという額を、半分先に納めるんです。**中間納付**といいます。決算で本当の税額が決まったら、差額を払う」
会社の利益には、**法人税**、**住民税**、**事業税**がかかる。簿記では3つをまとめて、**法人税、住民税及び事業税**（法人税等）という勘定で処理する。

::steps 法人税等の1年間の流れ
期の途中：中間納付 | 前期の実績などにもとづき、税額の一部を先に納める。まだ当期の税額は確定していないので「仮払法人税等」（資産）とする
決算日：当期の税額を計上 | 当期の利益にもとづく年税額を「法人税、住民税及び事業税」（費用）として計上し、中間納付額を差し引いた残りを「未払法人税等」（負債）とする
決算後：確定申告・納付 | 原則として決算日から2か月以内に申告し、未払法人税等を納付する
::

::example ナイトオウル交通の法人税等
(1) 11月、法人税等の中間申告を行い、6,000,000円を普通預金から納付した。
(2) 3月31日の決算で、当期の法人税等の年税額が14,000,000円と計算された。
(3) 5月、確定申告を行い、未払分を普通預金から納付した。
::answer
::journal (1) 中間納付：仮払法人税等（資産）
仮払法人税等 6,000,000 | 普通預金 6,000,000
::
::journal (2) 決算：年税額を計上し、中間納付額との差額を未払法人税等とする
法人税、住民税及び事業税 14,000,000 | 仮払法人税等 6,000,000
 | 未払法人税等 8,000,000
::
::journal (3) 確定納付
未払法人税等 8,000,000 | 普通預金 8,000,000
::
::trap
中間納付した6,000,000円を、その時点で費用にしないこと。年税額が決まるまでは、仮払法人税等（資産）で記録する。
決算で未払法人税等にするのは、年税額の14,000,000円全額ではない。中間納付を引いた残りの8,000,000円だ。
::
::
::

::point 損益計算書での位置
法人税等は、損益計算書の最後のほうで、**税引前当期純利益**から差し引かれる。
税引前当期純利益 － 法人税、住民税及び事業税 ＝ 当期純利益
日本の会社の利益にかかる税金の負担率（実効税率）は、規模などにより異なるが、おおむね30%前後だ。利益の約3割は、翌年に現金で出ていく。序章で見た「税金は利益が出た後から来る」という罠の正体である。
::

## 預かる税金 ― 消費税

翌日の昼下がり、営業前の麺屋とりの巣。カウンターの向こうで、鶏ガラの寸胴が湯気を上げている。鳥羽は、腕を組んだまま座っていた。
鳥羽：「で、なんで1,200万なんや」
ひよりは、鳥羽の前に1杯分のレシートを置いた。
ひより：「ラーメン1杯990円。このうち90円は、お店のお金ではありません」
鳥羽：「……は？」
ひより：「消費税です。消費税を負担しているのは、ラーメンを食べたお客さんです。でも、お客さんは自分で税務署に行けません。だから、お店がラーメン代と一緒に受け取って、預かって、あとで国に納めるんです」
鳥羽：「預かっとる、だけ？」
ひより：「はい。1杯ごとに、90円ずつ」

::theory 消費税を負担するのは「最終消費者」、納めるのは「事業者」
消費税は、商品やサービスを消費する人（最終消費者）が負担する税金だ。だが、消費者が自分で税務署に納めるわけではない。商品の売り手である事業者が、代金と一緒に消費税を受け取り、それを**預かって**国に納める。
しかも消費税は、生産から販売までの各段階でかかる。そこで各事業者は、「売上で預かった消費税」から「仕入れや経費で支払った消費税」を差し引いた**差額だけ**を納める（仕入税額控除）。こうして、各段階の事業者が少しずつ納めた消費税の合計が、最終消費者の負担した消費税と一致する仕組みになっている。
::

ひより：「鳥羽さんのお店も、鶏ガラや麺を仕入れるとき、業者さんに消費税を払っていますよね。だから、納めるのは全部じゃなくて、預かった分から払った分を引いた差額です」

::table compact 1杯の牛丼をめぐる消費税のバトンリレー（税率10%で単純化）
| 段階 | 売値（税抜） | 受け取った消費税 | 支払った消費税 | 納める消費税 |
| 洛北ミート → おかわり堂 | 200円 | 20円 | 0円 | 20円 |
| おかわり堂 → 客 | 500円 | 50円 | 20円 | 30円 |
|= 合計 |  |  |  | 50円（＝客が負担した消費税） |
::

::note
※実際には、食材の仕入れや持ち帰りの飲食料品には軽減税率（8%）が適用されるなど、取引ごとに税率が異なる。ここでは仕組みを示すため、税率を10%に統一している。
::

### 税抜方式の仕訳 ― 「仮払」と「仮受」で預かりを管理する

鳥羽：「90円が店のお金やないなら、帳簿にはどう書いてあるんや」
ひよりは、レシートの裏に仕訳を書いた。売上の行と、もう1行。
ひより：「売上は900円です。90円は、**仮受消費税**という別の勘定に分けて記録します。預かりものだから、負債です」
鳥羽：「仕入れのときに払うた分は？」
ひより：「そっちは**仮払消費税**。あとで差し引ける分だから、資産です」
鳥羽：「うちの帳簿、そう書いてあったか」
ひよりは、首を横に振った。とりの巣の帳簿は、売上も仕入も、税込のまま記録されていた。

::example おかわり堂の消費税
(1) 洛北ミートから牛肉を仕入れ、代金432,000円（税抜400,000円、食料品なので軽減税率8%の消費税32,000円）は掛けとした。
(2) 1日の売上は、店内飲食分が税抜500,000円（消費税10%）、持ち帰り分が税抜300,000円（消費税8%）で、代金は現金で受け取った。
::answer
::journal (1) 支払った消費税は「仮払消費税」
仕入 400,000 | 買掛金 432,000
仮払消費税 32,000 |
::
::journal (2) 受け取った消費税は「仮受消費税」：50,000円＋24,000円＝74,000円
現金 874,000 | 売上 800,000
 | 仮受消費税 74,000
::
売上・仕入は**税抜**の金額で記録し、消費税の部分は仮払消費税・仮受消費税として別に記録する。!!買掛金・売掛金・現金は、相手と実際にやり取りする税込の金額!!になる点に注意しよう。初学者は、買掛金まで税抜で書いてしまいがちだ。こうすることで、「預かっている消費税」と「支払った消費税」が帳簿の上で常に見えるようになる。
::trap
税率を取り違えないこと。食料品の仕入れと持ち帰りは8%、店内飲食は10%だ。
売上・仕入は税抜、買掛金・売掛金・現金は税込で記録する。相手とやり取りする金額は、いつも税込である。
::
::
::

::note
※牛丼チェーンでは、同じ牛丼でも店内で食べれば10%、持ち帰れば8%の消費税がかかる（軽減税率）。3級の試験では、問題文で示された税率（通常は10%）で計算すればよい。
::

### 決算 ― 差額が「納める消費税」になる

鳥羽は、レシートの裏の仕訳を見ていた。
鳥羽：「ほな、預かった分を全部、国に渡すんか。うちかて、鶏ガラや麺を買うときに消費税を払うてるで」
ひより：「はい。だから、納めるのは差額です。預かった消費税から、支払った消費税を引きます。決算で2つを相殺して、残った分を**未払消費税**にします」

::journal 決算：仮受消費税の残高が5,200,000円、仮払消費税の残高が3,100,000円だった
仮受消費税 5,200,000 | 仮払消費税 3,100,000
 | 未払消費税 2,100,000
::

::journal 確定申告にもとづき、未払消費税2,100,000円を普通預金から納付した
未払消費税 2,100,000 | 普通預金 2,100,000
::

::note
※仮払消費税のほうが多いときは、差額が税務署から還付される。この還付を受ける権利は「未収還付消費税」（資産）で処理する。
::

## 答え合わせ ― 1,200万円は、最初から「客のお金」だった

::solve 経営者は、預かったお金を自分の売上だと思って使っていた
麺屋とりの巣の年間売上、税込2億2,000万円。そのうち**2,000万円は、客から預かった消費税**だった。店の本当の売上（税抜）は2億円だ。
一方、食材や光熱費、家賃などの支払いに含まれていた消費税は800万円。差し引き**1,200万円**を、店は国に納めなければならない。

::table 麺屋とりの巣の消費税（年間）
| 項目 | 金額 |
| 売上で受け取った消費税（仮受消費税） | 2,000万円 |
| 仕入れ・経費で支払った消費税（仮払消費税） | △800万円 |
|= 納めるべき消費税（未払消費税） | 1,200万円 |
::
鳥羽は、税込の売上がすべて店のお金だと思い、新店の内装や設備に次々と使っていた。だが、そのうち1,200万円は、**最初から国に納めるために客から預かっていたお金**だった。
しかもラーメン店は、売上に占める人件費の割合が高い。**給料には消費税がかからない**ため、人件費が多い事業ほど、差し引ける消費税（仮払消費税）が少なくなり、納める消費税が大きくなる。
税抜方式で仮受消費税を毎日記録していれば、「このお金は預かりものだ」ということが、帳簿の上で常に見えていたはずだ。
::

鳥羽は、カウンターの上のレシートを長いあいだ見ていた。
鳥羽：「1杯ごとに90円、国の財布を預かってたわけか。それを、6号店の壁紙に使うてしもうた」
ひより：「人件費の多いお店ほど、納める額は大きくなります。お給料には、消費税がかからないので」
鳥羽：「うちは、ほとんど人件費と鶏ガラやからな……」
長い沈黙のあと、鳥羽はぽつりと言った。
鳥羽：「大川さん。あんたが悪いんやない。わしが、知らんかっただけや」
事務所は、鳥羽と一緒に税務署へ相談に行き、納付を分割にしてもらう手続きを進めた。

::danger 消費税の滞納は、倒産の入り口
法人税は利益が出なければかからないが、消費税は「預かった額－支払った額」で決まるため、赤字でも納めなければならない。資金繰りに苦しむ会社ほど滞納しやすく、延滞税がかかり、やがて預金や売掛金が差し押さえられる。消費税で倒れる会社に共通するのは、**税込の売上を「自分のお金」だと思っている**ことだ。
::

::real 国税の滞納のおよそ4割は、消費税
国税庁が2026年8月に公表した「令和7年度の租税滞納状況」によると、2025年度末の国税の滞納残高は**9,847億円**で、そのうち消費税は**3,893億円**。所得税の3,948億円とほぼ並び、全体のおよそ4割を占めている。
消費税は赤字でも納める必要がある。客から預かったお金を、売上と一緒に日々の支払いに使ってしまえば、納付の月にお金が足りなくなる。期限に納められなければ、決算で計上した未払消費税は次の決算まで残り続け、遅れた日数に応じた延滞税という、会社自身が負担する費用まで加わる。滞納の多さは、「預かったお金」を切り分けて管理することの難しさを、そのまま映している。
::note
出典：[山田&パートナーズ「令和7年度 租税滞納状況について」（2026年8月31日、国税庁の公表資料の解説）](https://www.yamada-partners.jp/tax-topics/r080831)
::
::


::point 電子契約なら、収入印紙はいらない
印紙税は、契約書や領収書などの「紙の文書」を作ったときにかかる税金だ。そのため、電子契約で契約書をデータのまま取り交わした場合は、課税文書の「作成」にあたらず、収入印紙は不要とされている。たとえば、請負契約書や不動産の売買契約書には、金額に応じて数千円から数万円の印紙が必要になる。契約の多い会社が電子契約に切り替えると、租税公課（印紙代）がまとめて減ることになる。ただし、電子契約のデータを紙に印刷して署名し、それを原本として使えば、印紙が必要になることがある。
::

::cfo 来年の消費税に、どう備えるか
今年の1,200万円は、分割で納めることになった。鳥羽は「来年は同じ失敗をせえへん」と言う。ひよりが考えた備え方は4つある。
**前提**
- とりの巣の売上（税込）は年2億2,000万円。仕入や経費で払う消費税は、売上の約4%にあたる
- 来年は、分割の返済（月100万円）と中間納付が秋に重なり、お金に余裕がない
- 毎月の記帳は鴨川会計事務所が担当し、翌月10日には月次の試算表ができる
**考えるときの視点**
- 預かっている消費税と、実際に納める消費税の差は、どのくらいか
- お金に余裕のない年に、多すぎる積み立ては何を起こすか
::choice A. 売上の10%を、毎日別の口座へ移す
**△ 分かりやすいが、仕入や経費で払った消費税を差し引いていない。**実際に納めるのは売上の約6%なので、毎年900万円近く積み立てすぎる。余裕のない来年は、それが資金繰りを詰まらせる。
::
::choice B. 毎月の試算表で仮受と仮払の差額を確かめ、その額を別口座へ移す
**◎ 実際に納める額を、毎月の記録から見積もって移している。**記帳はすでに月次でできているので、手間もほとんど増えない。
::
::choice C. 中間納付の額だけを、毎月積み立てる
**○ 秋の重なりには備えられるが、確定納付の分は残らない。**今年と同じつまずきが、決算のあとに起きうる。
::
::choice D. 決算の1か月前に、会計事務所に納付額を計算してもらう
**△ 気づくのが遅い。**お金は1年かけて使われている。
::
::answer 考え方の例を見る
- **納める額で備える**：預かった額ではなく、差し引いたあとの納める額を積み立てる
- **積み立てすぎも害になる**：余裕のない年には、多すぎる積み立てが別の支払いを詰まらせる
- **すでにある記録を使う**：毎月の試算表があれば、手間を増やさずに正確な額が分かる
::
::

::exam 税金の急所
- 固定資産税・自動車税・印紙税（収入印紙）は「租税公課」。法人税等とは別の勘定。
- 法人税等の中間納付は「仮払法人税等」。決算で「法人税、住民税及び事業税／仮払法人税等・未払法人税等」。
- 消費税（税抜方式）：仕入時は仮払消費税、売上時は仮受消費税。決算で相殺し、差額を「未払消費税」。
- 問題文の金額が「税込」か「税抜」かを必ず確認する。税込440,000円（税率10%）なら、税抜400,000円・消費税40,000円。
- 精算表・貸借対照表では、未払法人税等・未払消費税は負債。仮払消費税・仮受消費税は決算整理後には残らない。
::

::next 「会計上の利益」と「税金の計算上の利益」は違う
法人税は、会計上の利益をそのまま使って計算するわけではない。税法独自のルールで計算した利益を**課税所得**という。会計上の利益とのズレを調整する技術が、2級・1級で学ぶ**税効果会計**だ。
::

::summary
- 税金は「費用になる税金（租税公課）」「利益にかかる税金（法人税等）」「預かる税金（消費税・源泉所得税）」の3つに分けて考える
- 固定資産税・自動車税・印紙税は租税公課（費用）
- 法人税等：中間納付は仮払法人税等、決算で年税額を計上し、残りを未払法人税等とする
- 消費税（税抜方式）：支払った分は仮払消費税、受け取った分は仮受消費税。決算で相殺し、差額を未払消費税とする
- 消費税は客から預かったお金。税込売上を自分のお金と思うと、納付のときに資金が足りなくなる
::
