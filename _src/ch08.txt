::mystery 黒字の老舗精肉店は、なぜ1枚の紙で倒れたのか
11月の終わりの朝、所長室から鴨川の声がした。
鴨川：「大川さん、ちょっと付き合うてくれるか」
行き先は告げられなかった。所長は、黙ってコートを羽織り、市バスに乗った。
京都・錦市場のほど近くに、創業70年の精肉店「丸富」があった。鴨川会計事務所が、先代のころから30年以上、帳簿を見てきた顧問先だ。3代目の店主・富岡は、料亭や割烹に高級和牛を卸し、決算は毎年黒字。借金もほとんどない優良企業だった。
得意先のなかで最も大きかったのが、市内に5店舗を構える料亭グループだ。支払いは昔ながらの**約束手形**で、期日は120日後。富岡の金庫には、その手形が合わせて**2,800万円分**しまわれていた。期日になれば、確実に現金に変わるはずの紙だった。
ある年の10月、その料亭グループが倒産した。
手形は1枚残らず**不渡り**になった。悪いことに、富岡はその手形の入金をあてにして、自分も仕入先の畜産業者に手形を振り出していた。その期日は11月末だ。
入るはずの2,800万円が入らない。支払うはずの手形の期日は迫る。銀行は追加の融資を断った。そして——。
錦市場の人波を抜けた先で、丸富のシャッターは下りていた。A4の紙が1枚、貼られている。ひよりは足を止めた。1年前の11月、百万遍の交差点で見たのと、同じ大きさの紙だった。
裏口で2人を迎えた富岡は、深く頭を下げた。
富岡：「先生、すんません。帳簿は、最後まできれいにつけてました」
鴨川は、黙って富岡の肩に手を置いた。
富岡：「借金もない。毎年黒字や。それやのに、紙切れ数枚で、70年が終わってしもた」
黒字で、借金もなかった老舗を倒したのは、たった数枚の「紙切れ」だった。なぜ、手形はこれほど恐ろしいのか？
::

## 約束手形 ― 「期日に必ず払います」という証書

帰りの市バスの中で、鴨川は鞄から1枚の紙を出した。富岡から預かってきた約束手形だ。表には料亭グループの名前と、2,800万円のうちの1枚分の金額。裏には、銀行が貼った「不渡」の付箋がついている。
鴨川：「よう見とき。これが、黒字の店を潰した紙や」
ひより：「ただの紙に見えます」
鴨川：「ただの紙やない。『この日に、この金額を、必ず払います』という約束を、法律が後ろから支えとる紙や。払わんかったら、不渡り。払えんかった会社は、銀行と取引できんようになる」
ひより：「それだけ強い約束なら、もらう側は安心ですね」
鴨川：「そうや。だから、みんな安心して手形をもろた。安心して、その入金をあてにした。そこが落とし穴やった」

::point メモ ― 約束手形とは
**約束手形**（やくそくてがた）とは、振り出した人（**振出人**）が、受け取った人（**名あて人**＝受取人）に対して、決められた**期日**に、決められた**金額**を支払うことを約束する証書だ。掛取引の約束は口約束や請求書にすぎないが、手形は法律（手形法）にもとづく強力な証書で、期日に支払わなければ「不渡り」という重い制裁が待っている。
::

::steps 約束手形の流れ
おかわり堂が手形を振り出す | 洛北ミートから牛肉を仕入れ、代金として「3か月後の期日に支払う」約束手形を渡す
洛北ミートが手形を受け取る | 期日まで手形を保管する。期日前に銀行で取立てを依頼する
期日に決済される | おかわり堂の当座預金から引き落とされ、洛北ミートの当座預金に入金される
::

### 手形の仕訳 ― 受け取ったら「受取手形」、振り出したら「支払手形」

事務所に戻ったひよりは、丸富の帳簿を開いた。富岡の几帳面な字で、手形を受け取った日と、振り出した日の仕訳が並んでいる。
鴨川：「受け取った手形と、自分が振り出した手形。同じ紙でも、帳簿の上では正反対のものや。富岡さんは、その両方を持っとった」
ひより：「受け取った手形は、あとでお金をもらえる権利だから、資産。振り出した手形は、払う義務だから、負債」
鴨川：「名前は、**受取手形**と**支払手形**や」

::example おかわり堂と洛北ミートの手形取引
(1) おかわり堂は、洛北ミートから牛肉800,000円を仕入れ、代金は約束手形を振り出して支払った。
(2) 3か月後の期日に、(1)の手形が決済され、おかわり堂の当座預金から引き落とされた（洛北ミートの当座預金に入金された）。
同じ取引を、おかわり堂と洛北ミートの両方の立場で処理する。
::answer
::journal (1) おかわり堂（手形を振り出した＝支払手形の増加）
仕入 800,000 | 支払手形 800,000
::
::journal (1) 洛北ミート（手形を受け取った＝受取手形の増加）
受取手形 800,000 | 売上 800,000
::
::journal (2) おかわり堂（手形代金を支払った＝支払手形の減少）
支払手形 800,000 | 当座預金 800,000
::
::journal (2) 洛北ミート（手形代金を受け取った＝受取手形の減少）
当座預金 800,000 | 受取手形 800,000
::
::trap
手形を振り出したのに「買掛金」、受け取ったのに「売掛金」としないこと。手形を使った時点で、勘定科目は支払手形・受取手形に変わる。
同じ取引でも、立場が変われば仕訳は左右が入れ替わる。問題文の主語がどちらの会社かを確かめよう。
::
::
::

ひより：「すでにある売掛金を、あとから手形でもらうこともあるんですか」
鴨川：「よくある。そのときは、売掛金を消して、受取手形に入れ替える。中身は同じ貸しでも、紙の強さが変わるんや」

::point 売掛金・買掛金を手形で決済する場合
すでにある売掛金・買掛金の支払いのために手形をやり取りすることも多い。この場合は、売掛金（または買掛金）を減らし、受取手形（または支払手形）を増やす。
::

::journal 洛北ミートは、居酒屋チェーンAに対する売掛金1,200,000円について、同社振出の約束手形を受け取った
受取手形 1,200,000 | 売掛金 1,200,000
::

::journal 居酒屋チェーンA側の仕訳（買掛金の支払いのため約束手形を振り出した）
買掛金 1,200,000 | 支払手形 1,200,000
::

::theory 「掛け」と「手形」は、同じ債権でも何が違うのか
売掛金も受取手形も「後で代金を受け取る権利」という点では同じだ。違いは**強制力**にある。
掛けの代金が支払われなくても、すぐに大きな制裁はない。督促し、交渉し、最後は裁判で取り立てるしかない。一方、手形が期日に決済されなければ不渡りとなり、振出人は銀行取引停止という社会的な死刑に直面する（第4章）。だから手形の振出人は、何があっても期日に支払おうとする。
この強制力ゆえに、手形は「確実に回収できる債権」として、銀行に持ち込んで期日前に現金化（割引）したり、他の支払いに回したり（裏書譲渡）することもできた。これらは2級で学ぶ論点だ。
::

## 受取手形記入帳と支払手形記入帳

丸富の金庫には、受け取った手形の明細を1枚ずつ書き留めた帳面が残っていた。富岡が几帳面につけていた、**受取手形記入帳**だ。
ひより：「1枚ずつ、振出人と期日と銀行が書いてあります」
鴨川：「手形は、1枚ごとに中身が違うからな。払う手形のほうは、**支払手形記入帳**につける。富岡さんは、どっちも最後の日まで、1行も抜かさんとつけとった」
ひよりは、記入帳の最後のページをめくった。てん末の欄に、細い字で「不渡」と書かれた行が、いくつも並んでいた。

::table compact 受取手形記入帳（洛北ミート）
| 日付 | 手形種類 | 手形番号 | 摘要 | 支払人 | 振出人 | 振出日 | 満期日 | 支払場所 | 手形金額 | てん末 |
| 6/10 | 約手 | 18 | 売上 | おかわり堂 | おかわり堂 | 6/10 | 9/10 | 京都中央銀行 | 800,000 | 9/10 入金 |
| 7/31 | 約手 | 25 | 売掛金 | 居酒屋A | 居酒屋A | 7/31 | 10/31 | 洛北信用金庫 | 1,200,000 |  |
::

::note
※「摘要」欄には、手形を受け取ったときの仕訳の相手勘定（売上・売掛金など）が書かれる。「てん末」欄には、その手形がどうなったか（入金・不渡りなど）を記入する。第2問では、この記入帳から仕訳を読み取る問題がよく出る。たとえば上の1行目からは「受取手形 800,000 ／ 売上 800,000」と「当座預金 800,000 ／ 受取手形 800,000」の2つの仕訳が読み取れる。
::

## 答え合わせ ― 手形は「信用の連鎖」でできている

::solve 不渡りは、ドミノのように倒れていく
老舗精肉店を倒したのは、手形の強制力そのものだった。
精肉店は、料亭グループから受け取った手形の入金を前提に、自らも畜産業者へ手形を振り出していた。手形を受け取った側は、さらにその入金をあてにして、別の支払いの計画を立てる。手形は、多くの会社の資金繰りを**数珠つなぎ**にしていたのである。
料亭グループが倒れると、受取手形2,800万円は一瞬で回収不能になった。それでも、精肉店が振り出した手形は、期日に必ず決済しなければならない。払えなければ不渡りだ。銀行は「回収不能の手形を抱えた会社」に追加融資をしなかった。こうして、黒字の精肉店も不渡りを出し、**連鎖倒産**に至った。
手形は、期日に支払われる限り、強力で便利な道具だ。しかしその強制力は、裏を返せば「1社の倒産が、手形でつながった会社を次々と道連れにする」仕組みでもあった。
::

事務所に戻ると、鴨川は丸富の最後の決算書を、ひよりの机に置いた。
鴨川：「受取手形2,800万円。この1行が、店の資産の半分近くを占めとった。わしは毎年、この数字を見とったんや」
ひより：「所長は、気づいてたんですか」
鴨川は、窓の外を見たまま言った。
鴨川：「1社に頼りすぎや、とは言うた。でも、手形を断れとまでは、言えんかった。料亭さんとは、先代からの付き合いやったからな」
しばらく、事務所に音がなかった。
鴨川：「帳簿は、全部正しかった。正しい帳簿でも、読む人が手を打たんかったら、店は守れん。大川さん、それだけは覚えとき」

::danger 「手形サイト」という時限爆弾
手形の振出日から満期日までの期間を**手形サイト**という。日本では長年、90日や120日、ときにはそれ以上の長い手形サイトが当たり前だった。
立場の強い大企業が、下請けの中小企業に長い手形で支払う。中小企業は、代金を受け取れるまで何か月も待たされ、その間の資金繰りは自分で何とかしなければならない。手形を銀行で割り引けば現金化できるが、そのぶん手数料（割引料）を取られる。
こうした慣行は「中小企業の資金繰りを圧迫している」と問題視され、国は手形サイトの短縮を指導してきた。そして2026年1月に施行された改正下請法（**中小受託取引適正化法**、通称「取適法」）では、対象となる取引での**手形による支払いそのものが禁止**された。
::

::real 2026年1月、法律が「手形払い」を禁じた
2025年5月に成立した改正下請法は、名前を「**中小受託取引適正化法**」（取適法）に改め、2026年1月1日に施行された。中小企業庁や公正取引委員会の説明によると、主な変更点は次のとおりだ。
- 対象となる取引で、**手形による支払いを禁止**。電子記録債権やファクタリングなども、支払期日までに代金の全額を現金で受け取ることが難しいものは認められない
- 支払期日は、物品などを受け取った日から**60日以内**が原則
- **振込手数料**を、受け取る側の中小企業に負担させることを禁止
- 運送の委託を新たに対象に加え、従業員数（300人、役務の委託などは100人）による区分も設けた
**この章の道具で読む ― 120日の手形が、60日以内の振込に変わると**
取適法の対象になる取引で、仕訳がどう変わるかを見てみよう。たとえば、おかわり堂のケータリング子会社が、仕出し弁当に詰めて売る煮物などの惣菜100万円分を、自社のレシピで中小の食品工場に作ってもらった（製造委託）。惣菜は、弁当の一部として売るための**商品**なので、受け取ったときに「仕入／買掛金」で買掛金が生まれる。支払方法の違いが表れるのは、その買掛金を払うときだ。

::journal ① 惣菜の納品を受けた（ここで買掛金が生まれる。支払方法が変わっても、この仕訳は同じ）
仕入 1,000,000 | 買掛金 1,000,000
::
::journal ② これまで：①の買掛金を、約束手形（サイト120日）を振り出して支払っていた
買掛金 1,000,000 | 支払手形 1,000,000
::
::journal ③ さらに120日後：手形の期日に、当座預金から引き落とされる
支払手形 1,000,000 | 当座預金 1,000,000
::
::journal ②' 2026年1月から：①の買掛金を、受け取った日から60日以内に振込で支払う（手数料は委託した側が負担）
買掛金 1,000,000 | 普通預金 1,000,660
支払手数料 660 |
::

これまでは①→②→③の3本の仕訳で、買掛金が支払手形に姿を変え、お金が実際に出ていくのは納品から約4か月後だった。新しいルールでは①→②'の2本で終わり、60日以内にお金が出ていく。
::note
※委託したものが売るための商品ではない場合は、勘定科目が変わる。たとえば弁当の掛け紙の印刷を委託したなら、掛け紙は商品ではないので、納品のときは「消耗品費／**未払金**」となり、支払いは「未払金／普通預金」になる（第9章）。「何を受け取ったか」で、納品のときの勘定科目が決まり、その後の支払いの仕訳も決まる。
::

食品工場の側から見ると、違いはもっとはっきりする。これまでは、惣菜を納めて「売掛金」を計上し（売掛金／売上）、それが手形の受け取りで「受取手形」に変わってから4か月待ち、そのあいだの材料費や給料を自分で立て替えていた。待てなければ、銀行に割引料を払って手形を期日前に現金化した。新しいルールでは、遅くとも60日以内に、手数料を差し引かれない全額が預金に入る。帳簿の上では、受取手形という勘定が消え、売掛金がそのまま普通預金に変わる。
丸富が抱えていた2,800万円の手形も、もし60日以内の現金払いだったら、倒産の時点で残っていた金額は半分ほどで済んでいたはずだ。もっとも、取適法が対象にするのは、製造・修理・情報成果物の作成・役務の提供・運送といった「**委託**」の取引だ。洛北ミートが飲食店に肉を売るような、ふつうの商品の売買はそのまま対象にはならない。売買の支払条件は、当事者どうしの交渉で決まる。
::note
出典：[中小企業庁 ミラサポplus「中小受託取引適正化法（取適法）」](https://mirasapo-plus.go.jp/infomation/30416/)、[長崎県（公正取引委員会の説明資料）](https://www.pref.nagasaki.jp/shared/uploads/2025/11/1764136904.pdf)

## 電子記録債権・電子記録債務 ― 紙を使わない「手形」

丸富のような倒産を防ぐ仕組みは、あるのだろうか。次の巡回の日、ひよりは洛北ミートの中西に聞いてみた。中西は、ネットバンキングの画面を開いて見せてくれた。
中西：「うちはもう、紙の手形はほとんど使ってません。代わりに、これです。**でんさい**」
ひより：「でんさい？」
中西：「電子記録債権です。銀行のシステムに『この会社が、この日に、いくら払う』と記録すると、それが手形の代わりになるんです。紙がないから、なくしたり盗まれたりしない。印紙もいりません」
ひより：「払えなかったら？」
中西：「手形と同じです。期日に払えなかったら、不渡りと同じような処分を受けます」

::table 紙の手形と電子記録債権の比較
| 項目 | 約束手形 | 電子記録債権 |
| 形 | 紙の証書 | 電子債権記録機関の記録 |
| 発生のさせ方 | 手形を振り出して渡す | 取引銀行を通じて発生記録を請求する |
| 収入印紙 | 必要（金額による） | 不要 |
| 紛失・盗難のリスク | ある | ない |
| 分割 | できない | 必要な金額だけ分割して譲渡・割引できる |
| 債権者の勘定 | 受取手形 | 電子記録債権 |
| 債務者の勘定 | 支払手形 | 電子記録債務 |
::

::example 洛北ミートと電子記録債権
(1) おかわり堂は、洛北ミートに対する買掛金500,000円の支払いのため、取引銀行を通じて電子記録債務の発生記録を行った。洛北ミートは、取引銀行から電子記録債権の発生記録の通知を受けた。
(2) 支払期日が到来し、おかわり堂の当座預金から洛北ミートの当座預金に500,000円が支払われた。
同じ取引を、両方の会社の立場で処理する。
::answer
::journal (1) おかわり堂（買掛金が電子記録債務に変わる）
買掛金 500,000 | 電子記録債務 500,000
::
::journal (1) 洛北ミート（売掛金が電子記録債権に変わる）
電子記録債権 500,000 | 売掛金 500,000
::
::journal (2) おかわり堂（期日に決済）
電子記録債務 500,000 | 当座預金 500,000
::
::journal (2) 洛北ミート（期日に入金）
当座預金 500,000 | 電子記録債権 500,000
::
::trap
発生記録のときに、仕入や売上をもう一度計上してはいけない。すでにある買掛金・売掛金が、電子記録債務・電子記録債権に**名前を変えるだけ**だ。
債権（もらう側・資産）と債務（払う側・負債）を取り違えないこと。
::
::
::

::point 電子記録債権の仕訳は「手形の仕訳の科目を置き換えるだけ」
受取手形 → 電子記録債権、支払手形 → 電子記録債務、と置き換えれば、仕訳の形は手形とまったく同じだ。3級では、売掛金・買掛金の決済のために発生記録を行うパターンが中心になる。
::

## 手形貸付金・手形借入金 ― お金の貸し借りに使う手形

電子記録債権の画面を閉じる前に、中西はもう1つ教えてくれた。
中西：「うちも昔は、銀行から運転資金を借りるたびに、手形を書いて渡していました」
ひより：「肉を買ったわけでもないのに、手形を書くんですか」
中西：「ええ。この場合の手形は、代金の支払いではなく、借用証書の代わりなんです。だから帳簿でも、商品の手形とは分けて、**手形借入金**にします。貸す側は**手形貸付金**です」

::example 洛北ミートの手形借入れ
(1) 洛北ミートは、京都中央銀行から運転資金3,000,000円を借り入れ、同額の約束手形を振り出して渡した。利息45,000円を差し引かれた残額が当座預金に入金された。
(2) 期日に、借入金を当座預金から返済した。
::answer
::journal (1) 手形を振り出してお金を借りた（利息は先に差し引かれた）
当座預金 2,955,000 | 手形借入金 3,000,000
支払利息 45,000 |
::
::journal (2) 返済
手形借入金 3,000,000 | 当座預金 3,000,000
::
::trap
お金を借りるために振り出した手形は、「支払手形」ではなく**手形借入金**だ。支払手形は、商品の代金の支払いに使う。
利息を先に差し引かれても、返す義務があるのは額面の3,000,000円。負債を入金額の2,955,000円にしないこと。
::
::
::

::journal 貸す側（手形を受け取ってお金を貸した）の例：取引先に現金500,000円を貸し付け、同額の約束手形を受け取った
手形貸付金 500,000 | 現金 500,000
::

::point 「受取手形」と「手形貸付金」の使い分け
同じ約束手形でも、**商品売買の代金**として受け取ったら受取手形、**お金を貸した**ときに受け取ったら手形貸付金だ。手形を見るのではなく、**取引の目的**を見て勘定科目を選ぶ。支払手形と手形借入金の関係も同じである。
::

## 紙の手形の「終わり」と、試験への影響

年が明けて、鴨川は丸富の金庫に残っていた手形帳を、ひよりに見せた。使われなかった用紙が、半分ほど残っている。
鴨川：「この紙も、あと少しで役目を終える」
ひより：「紙の手形が、なくなるんですか」
鴨川：「2027年の3月で、銀行の世界から消える。富岡さんの店には、間に合わんかったけどな」

::timeline 手形・小切手をめぐる主な動き
2013年 | でんさいネットが業務を開始 | 電子記録債権の普及が始まる
2022年11月 | 全国の手形交換所が「電子交換所」に移行 | 紙の手形・小切手の交換を電子化
2026年1月 | 改正下請法（取適法）が施行 | 対象取引での手形払いが禁止される
!2027年3月末 | 紙の手形・小切手の利用廃止（予定） | 金融界が電子的な決済手段への全面移行をめざす
2027年4月 | 簿記検定の新しい出題区分表（暫定版）を適用 | 3級の「手形」の区分は削除され、電子記録債権・債務は売掛金・買掛金の区分に整理される見込み
::

::note
※2026年度（2027年3月まで）の試験では、約束手形・受取手形記入帳・支払手形記入帳・手形貸付金・手形借入金は引き続き出題範囲に含まれる。2027年4月以降に受験する人は、日本商工会議所が公表する最新の出題区分表を必ず確認しよう。電子記録債権・電子記録債務は、2027年度以降も3級の範囲に残る見込みだ。
::

::cfo 「来月から、でんさいの120日払いで」― 資金と貸倒れの両方で考える
2026年11月。洛北ミートの大口得意先、居酒屋チェーンAの経理部長から連絡が来た。「紙の手形はもう使えなくなるので、来月からは**でんさい**でお支払いします。期日はこれまでの手形と同じ、120日後で」
居酒屋チェーンAへの売上は、毎月1,200万円。北村と中西は、ひよりを交えて対応を考えた。丸富のことは、北村も知っていた。「富岡さんとこみたいには、なりとうない」
判断の材料は次のとおりだ。
- 電子記録債権は、銀行で期日前に資金化（**割引**）できる。期日までの日数に応じて割引料がかかる
- 割引した電子記録債権が期日に支払われなかった場合、洛北ミートは銀行にその金額を返さなければならない（**遡求**（そきゅう）**義務**。2級で学ぶ）
- 居酒屋チェーンAの信用は、信用調査会社の評点で見ると「平均的」。倒産すれば、受け取っているでんさいは、ほぼ回収できない
- 期日が長いほど、居酒屋チェーンAに対する未回収の債権（**与信額**）は大きくなる。毎月の売上が、期日の日数分たまっていく
次の視点で考えてから選んでほしい。
- 割引で「お金」は早く入る。では、居酒屋チェーンAが倒れたときの「損失」はどうなるか
- 期日を縮めると、**資金繰り**と**貸倒れのリスク**のそれぞれに何が起きるか
- 「倒産の確率がゼロではない相手」と、どう付き合うのが合理的か
::choice A. 120日のでんさいを受け入れ、受け取ったらすぐに全額を割引して現金化する
**× お金は早く入るが、リスクは1円も消えていない。**割引すれば、資金繰りは今月から楽になる。仮の設定（下の「考え方の例」）では、割引料は年**約95万円**。
落とし穴は遡求義務だ。割引しても、居酒屋チェーンAが期日に払えなければ、洛北ミートが銀行に返さなければならない。常に抱える与信額は1,200万円×4か月＝**4,800万円**のままで、予想損失は4,800万円×2%＝約96万円。費用と合わせて年約190万円を払いながら、丸富と同じ形のリスクを抱え続けることになる。
::
::choice B. でんさいへの切り替えを機に、期日を60日に縮めてもらうよう交渉する
**◎ 制度の切り替えを、条件を見直す機会に変える。**期日が60日になれば、与信額は**2,400万円**に半減する。予想損失は約48万円、必要なときだけ割引しても費用は最大で約47万円。資金と貸倒れの両方のリスクが、同時に半分になる。
相手にとっても、支払方法を変える手間は同じだ。「法律でも60日以内が原則になりつつある」という流れを示し、長年の取引の実績を材料に交渉できる。なお、食材の売買は取適法の対象外なので、法律で強制はできない。あくまで交渉だ。
::
::choice C. 翌月末の振込に切り替えてもらう代わりに、代金を1%値引きする
**△ 効くが、割高。**回収は約60日になり、与信額はBと同じ2,400万円になる。だが値引きは年144万円（1,200万円×12か月×1%）。値引きで短くなる60日分の資金2,400万円に対して、**年6%**のコストだ。洛北ミートの借入金利（年1.8%前後）よりかなり高い。値引きは利益を直接削るうえ、一度下げた値段は戻しにくい。
::
::choice D. 倒産の確率が2%もある相手とは、取引を縮小する
**× 確率の読み方を誤り、売上を失う。**平均的な評点の会社の倒産確率は、仮に年2%とすると「50社に1社」。取引先としては平均的な水準だ。月1,200万円の売上は洛北ミートの8%にあたる大口で、粗利率10%なら年1,440万円の粗利を生んでいる。予想損失（120日でも約96万円）の15倍だ。
リスクが気になるなら、取引をやめるのではなく、**与信額を小さくする**（期日を縮める、与信枠を決める）のが筋である。相手の信用に具体的な不安が出てきたら、そのときに取引の量を見直せばよい（第11章）。
::
::answer 考え方の例を見る
**仮の設定**で試算してみよう。割引料は年2%、居酒屋チェーンAが1年以内に倒産する確率は2%、粗利率は10%とする。予想損失は「常に抱える与信額×倒産確率」で計算する。
::table 居酒屋チェーンAへの対応の比較（1年あたり）
| 案 | 常に抱える与信額 | 資金化の費用 | 貸倒れの予想損失 | 合計 |
| A　120日・すぐ全額割引 | 4,800万円 | 約95万円 | 約96万円 | 約191万円 |
| B　60日に短縮（必要なときだけ割引） | 2,400万円 | 最大約47万円 | 約48万円 | 最大約95万円 |
| C　振込＋1%値引き | 2,400万円 | 144万円 | 約48万円 | 約192万円 |
| D　取引縮小 | － | － | － | 粗利年1,440万円を失う |
::
紙の手形からでんさいへの切り替えは、手間とリスクを減らす。しかし、**期日が同じなら、寝かせているお金の量も、相手が倒れたときの損失も変わらない**。そして割引は「お金を早く受け取る」手段であって、「リスクを手放す」手段ではない。遡求義務があるかぎり、割引した債権の貸倒れのリスクは、最後まで自分に残る。
**さらに考えよう：居酒屋チェーンAの倒産確率が20%に上がったら？**
120日のままなら、予想損失は4,800万円×20%＝960万円。年1,440万円の粗利の3分の2が、予想損失で消える計算だ。60日に縮めても480万円。ここまで危なくなると、期日の短縮だけでは足りない。与信枠で残高の上限を決め、新しい注文は前払いに切り替え、取引の量そのものを絞る段階に入る（第11章）。**相手の危うさが変われば、同じ取引でも最善の手が変わる。**だから与信は、一度決めて終わりではなく、定期的に見直す。
資金繰りと貸倒れの両方を本当に軽くするのは、回収までの日数を縮め、与信額を小さくすることだ。2027年3月の紙の手形・小切手の廃止に向けて、多くの会社が支払方法を見直している。中西は「この機会を逃したら、120日の条件はこの先も続く」と北村を説得し、Bの交渉に臨んだ。結果は、間を取って90日。それでも、与信額は4,800万円から3,600万円に減り、毎月寝かせていたお金のうち約1,200万円が手元に戻ってきた。
::
::

::exam 手形・電子記録債権の急所
- 商品売買の代金 → 受取手形・支払手形。お金の貸し借り → 手形貸付金・手形借入金。
- 電子記録債権・債務は、手形の仕訳の科目を置き換えるだけ。発生記録で売掛金・買掛金が電子記録債権・債務に変わる。
- 手形記入帳は「摘要」欄（相手勘定）と「てん末」欄（その後どうなったか）から仕訳を読み取る。
- 手形の裏書・割引・不渡り・更改は2級の範囲。3級では出題されない。
- 2027年4月以降の試験では、紙の手形に関する論点は削除される見込み（暫定版）。受験時期に応じて最新の出題区分表を確認すること。
::

::next 「でんさい」の譲渡・割引と、サプライチェーン・ファイナンス
2級では、電子記録債権を期日前に銀行で資金化する**割引**や、仕入先への支払いに充てる**譲渡**の処理を学ぶ。割引では、期日までの利息相当額が**電子記録債権売却損**という費用になる。
実務では、大企業が自社の信用力を使って、取引先の中小企業が売掛債権を低いコストで早期に資金化できるようにする**サプライチェーン・ファイナンス**も広がっている。手形の時代には「長いサイトを押しつける」ことが強者の論理だったが、これからは「取引先の資金繰りを支え、サプライチェーン全体を強くする」ことが企業の財務部門に求められる。決済手段の変化は、企業間の力関係そのものを変えつつあるのだ。
::

::summary
- 約束手形は、期日に支払うことを約束する強力な証書。受け取ったら受取手形（資産）、振り出したら支払手形（負債）
- 手形の不渡りは、取引先を道連れにする「連鎖倒産」の引き金になってきた
- 受取手形記入帳・支払手形記入帳は手形の明細を記録する補助簿。「摘要」と「てん末」から仕訳を読み取る
- 電子記録債権・債務は、紙の手形に代わる電子的な債権・債務。仕訳の形は手形と同じ
- お金の貸し借りに使う手形は、手形貸付金・手形借入金で処理する
- 2026年1月の取適法施行で下請取引の手形払いが禁止され、紙の手形・小切手は2027年3月末で利用廃止の予定。2027年度の試験から「手形」の区分は削除される見込み
::
